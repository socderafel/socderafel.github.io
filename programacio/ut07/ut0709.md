# 7.9 Sentències precompilades (PreparedStatement)

Per a solucionar el problema de crear sentències sql complexes, s'utilitza **`PreparedStatement`**.

*JDBC* disposa d'un objecte derivat del `Statement` que es anomena `PreparedStatement`, al que es li passa la sentència *SQL* en el moment de crear-lo, no en el moment d'executar la sentència (com pasava amb `Statement`). I a més aquesta sentència pot admetre paràmetres, el que ens pot anar molt bé en determinades ocasions.

De qualsevol mode, `PreparedStatement` presenta avantatges sobre el seu antecesor `Statement` quan ens toque treballar amb sentències que es hagen d'executar diverses vegades. La raó és que qualsevol sentència *SQL*, quan s'envia al *SGBD* serà compilada abans de ser ejecutada.

- Utilitzant un objecte `Statement`, cada vegada que fem una ejecució d'una sentència, ja siga vía `executeUpdate` o bé vía `executeQuery`, el *SGBD* la compilará, ja que li arribarà en forma de cadena de caràcters.

- En canvi, en `PreparedStament` la sentència mai varia i per tant es pot compilar i guardar dins del mateix objecte, per la qual cosa les següents vegades que s'execute no caldrà compilar-se. Açò reducirá sensiblement el temps d'ejecució.

En alguns sistemes gestors, a més, usar `PreparedStatements` pot arribar a suposar més avantatges, ja que utilitzen la seqüència de bytes de la sentència per a detectar si es tracta d'una sentència nova o ja es ha servido amb anterioritat. D'aquesta manera es propicia que el sistema guarde les respostes en la memòria caché, de manera que es puguen lliurar de forma més ràpida.

La principal diferència dels objectes `PreparedStatement` en relació als `Statement`, és que en els primers es els passa la sentència *SQL* predefinida en el moment de crear-lo. Com la sentència queda predefinida, ni els mètodes `executeUpdate` ni `executeQuery` requerirán cap paràmetre. És a dir, justo al revés que en el `Statement`.

Els **paràmetres de la sentència** es marcarán amb el símbol d'interrogació (**`?`**). S'identificarán per la posició que ocupen en la sentència, començant a comptar des de l'esquerra a partir del número 1. El valor dels paràmetres es asignará utilitzant el mètode específic, d'acord amb el tipus de dades a assignar. El nom empezará per `set` i continuará amb el nom del tipus de dades (exemples: `setString`, `setInt`, `setLong`, `setBoolean` …). Tots aquests mètodes segueixen la mateixa sintaxi:

```java
setXXXX(<posiciónEnLaSentenciaSQL>, <valor>);
```

Aquest és el mateix mètode per a inserir un usuari però usant `PreparedStatement`:

```sql
public void insertUserPrepared(String nombre, String contraseña){ 
    PreparedStatement st = null; 
    String sql = "INSERT INTO usuarios (nombre, contraseña) VALUES (?, ?)";

    try { 
        st = con.prepareStatement(sql); 
        st.setString(1, nombre);
        st.setString(2, contraseña);
        st.executeUpdate(sql); 

    } catch (SQLException e) {
        System.out.println("ERROR al insertar el usuario: " + e.getMessage()); 

    } finally { 
        try{ 
            //Siempre se debe cerrar todo lo abierto
            if (st != null) {
                st.close(); 
            }
        } catch(java.sql.SQLException ex){ 
            System.out.println("ERROR: " + e.getMessage());
        }
    }
}
```

Podem observar que, ara, a més, la sentència sql és molt més fàcil d'escriure.

#### 📌 DbConnect.java

```java
public class DbConnect {
    // JDBC URL, usuario y contraseña de la base de datos  
    private static final String JDBC_URL = "jdbc:mysql://localhost:3306/pr_ana";
    private static final String USUARIO = "pr_ana";
    private static final String CONTRASEÑA = "1234";

    private static DbConnect dbInstance; //Variable para almacenar la unica instancia de la clase
    private static java.sql.Connection conexion;

    private DbConnect() {
        // El Constructor es privado!!
    }

    public static DbConnect getInstance(){
        //Si no hay ninguna instancia...
        if(dbInstance == null){
            dbInstance = new DbConnect();
        }
        return dbInstance;
    }

    public static java.sql.Connection getConnection(){
        if(conexion == null){
            try {
                conexion = java.sql.DriverManager.getConnection(JDBC_URL, USUARIO, CONTRASEÑA);
                System.out.println("Conexión realizada SINGLETON");

            } catch (java.sql.SQLException ex) {
                System.out.println("ERROR al conectar: " + ex.getMessage());
            }
        }
        return conexion;
    }
}
```

#### 📌 AlumnoRepository.java

```sql
import java.sql.*;

public class AlumnoRepository {

    public int agregarAlumnoPrepared(String nombre, int edad) throws SQLException {
        int id = 0;
        String sql = "INSERT INTO alumnos (nombre, edad) VALUES (?, ?)";
        Connection con = DbConnect.getInstance().getConnection();
        try (PreparedStatement pst = con.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {

            pst.setString(1,nombre);
            pst.setInt(2, edad);

            int filasInsertadas = pst.executeUpdate();
            if (filasInsertadas > 0) {
                ResultSet rs = pst.getGeneratedKeys();
                if (rs.next()) {
                    id = rs.getInt(1);
                    System.out.println("Alumno insertado con id: " + id);
                }
            }
        } 

        return id;
    }

    public void listarAlumnos() throws SQLException{
        Connection con = DbConnect.getInstance().getConnection();
        try (Statement st = con.createStatement()) {
            ResultSet rs = st.executeQuery("SELECT * FROM alumnos");
            //Recorrer datos devueltos
            while (rs.next()) {
                String nombre = rs.getString("nombre");
                int edad = rs.getInt("edad");

                System.out.println("El alumno " + nombre + " tiene " +edad + " años.");
            }
        } 
    }

    public void obtenerAlumnoId(int id) throws SQLException {

        String sql = "SELECT * FROM alumnos WHERE id = ?";
        Connection con = DbConnect.getInstance().getConnection();

        try (PreparedStatement pst = con.prepareStatement(sql)) {

            pst.setInt(1, id);

            try (ResultSet rs = pst.executeQuery()) {

                if (rs.next()) {
                    String nombre = rs.getString("nombre");
                    int edad = rs.getInt("edad");

                    System.out.println("Alumno:");
                    System.out.println("ID: " + id);
                    System.out.println("Nombre: " + nombre);
                    System.out.println("Edad: " + edad);
                } else {
                    System.out.println("No existe ningún alumno con id " + id);
                }
            }
        }
    }

    public void eliminarAlumnoId(int id) throws SQLException {

        String sql = "DELETE FROM alumnos WHERE id = ?";
        Connection con = DbConnect.getInstance().getConnection();
        try (PreparedStatement pst = con.prepareStatement(sql)) {

            pst.setInt(1, id);

            int filasEliminadas = pst.executeUpdate();

            if (filasEliminadas > 0) {
                System.out.println("Alumno con id '" + id + "' eliminado.");
            } else {
                System.out.println("No se encontró ningún alumno con el id '" + id);
            }
        }
    }  
}
```

import java.sql.*;
import java.util.*;

public class Test {

            alumnoDAO.listarAlumnos();

            System.out.println("ERROR al conectar: " + ex.getMessage());
        }         
    }
}
