# 1.5 Operadors i expressions (incl. Operador Ternario ? :)

## 1. Operadors Aritmétics

Els **Operadors Aritmétics** permeten realitzar operacions matemàtiques:

| Operador | Ús | Operació |
| --- | --- | --- |
| + | A + B | Suma |
| - | A - B | Resta |
| * | A * B | Multiplicació |
| / | A / B | Divisió |
| % | A % B | Mòdul o resta d'una divisió entera |

> **📌 Exemple:**
> 

```java
double num1, num2, suma, resta, producto, division, resto;
num1 =8;
num2 =5;
suma = num1 + num2;      // 13
resta = num1 - num2;     // 3
producto = num1 * num2;  // 40
division = num1 / num2;  // 1.6
resto = num1 % num2;     // 3
```

## 2. Operadors Relacionals

Els **Operadors Relacionals** permeten avaluar *(la resposta és un booleà: true o false)* la igualtat dels operands:

| Operador | Ús | Operació |
| --- | --- | --- |
| < | A < B | A menor que B |
| > | A > B | A major que B |
| <= | A <= B | A menor o igual que B |
| >= | A >= B | A major o igual que B |
| != | A != B | A distint de B |
| == | A == B | A igual a B |

> **📌 Per exemple:**
> 

```java
int valor1 = 10;
int valor2 = 3;
boolean compara;
compara = valor1 > valor2;  // true
compara = valor1 < valor2;  // false
compara = valor1 >= valor2; // true
compara = valor1 <= valor2; // false
compara = valor1 == valor2; // false
compara = valor1 != valor2; // true
```

## 3. Operadors Lògics

Els **Operadors Lògics** permeten realitzar operacions lògiques:

| Operador | Maneig | Operació |
| --- | --- | --- |
| && o & | A && B ó A & B | A AND B. El resultat serà true si tots dos operadors són true i false en cas contrari. |
| \|\| o \| | A \|\| B ó A \| B | A OR B. El resultat serà false si tots dos operands són false i true en cas contrari |
| ! | !A | NOT A. Si l'operant és true el resultat és false i si l'operant és false el resultat és true. |
| ^ | A ^ B | A XOR B. El resultat serà true si un operant és true i l'un altre false, i false en cas contrari. |

> **📌 Exemple:**
> 

```java
double sueldo = 1400;
int edad = 34;
boolean logica;

logica = (sueldo>1000 & edad<40);   //true
logica = (sueldo>1000 && edad>40);  //false
logica = (sueldo>1000 | edad>40);   //true
logica = (sueldo<1000 || edad>40);  //false
logica = !(edad<40);                //false
logica = (sueldo>1000 ^ edad>40);   //true
logica = (sueldo<1000 ^ edad>40);   //false
```

Per a representar resultats d'operadors Lògics també es poden usar taules de veritat a les que convé acostumbrar-se:

| A | B | A && B | A \|\| B | !A |
| --- | --- | --- | --- | --- |
| false | false | *false* | *false* | *true* |
| true | false | *false* | *true* | *false* |
| false | true | *false* | *true* | *true* |
| true | true | *true* | *true* | *false* |

> **📌 `&` o `&&`? `|` o `||`?**
> 

> Encara que produeixen el mateix resultat lògic, hi ha una diferència clau en com els avalua Java:

| Operador | Nom | Comportament |
| --- | --- | --- |
| `&&` | AND cortocircuito | Si el **primer operant és `false`**, Java **no avalua el segon** |
| `&` | AND bit a bit | **Sempre avalua els dos** operands |
| `\|\|` | OR cortocircuito | Si el **primer operant és `true`**, Java **no avalua el segon** |
| `\|` | OR bit a bit | **Sempre avalua els dos** operands |

> **Per què importa?** Amb `&&` i `||` el programa és més eficient i evita errors:

```java
int[] numeros = null;

// Con &  → ERROR: evalúa ambos lados aunque numeros sea null
if (numeros != null & numeros.length > 0) { ... }

// Con && → SEGURO: si numeros es null, no llega a mirar .length
if (numeros != null && numeros.length > 0) { ... }
```

> **Regla pràctica:** usa sempre `&&` i `||` per a condicions lògiques. Reserva `&` i `|` només per a operacions a nivell de bits.

## 4. Operadors Unarios o Unitarios

Els **Operadors Unarios** o **Unitarios** permeten realitzar incrementos i decrementos:

| Operador | Ús | Operació |
| --- | --- | --- |
| ++ | A++ o ++A | Increment de A |
| -- | A-- o --A | Decremento de A |

> **📌 Exemple:**
> 

```java
int m = 5, n = 3;
m++; // 6
n--; // 2
```

> **📌 Prefix (++A) vs. sufix (A++)**
> 

> La posició de l'operador canvia **quan** s'aplica l'increment:

> - **Prefix (`++A`)** → primer incrementa, després usa el nou valor.

> - **Sufix (`A++`)** → primer usa el valor actual, després incrementa.

```java
int A = 1, B;

B = ++A;
// Paso 1: A se incrementa → A vale 2
// Paso 2: B recibe el valor de A → B vale 2
// Resultado: A=2, B=2

B = A++;
// Paso 1: B recibe el valor ACTUAL de A → B vale 2
// Paso 2: A se incrementa → A vale 3
// Resultado: A=3, B=2
```

## 5. Operadors de Assignació

Els **Operadors de Assignació** permeten assignar valors:

| Operador | Ús | Operació |
| --- | --- | --- |
| = | A = B | Assignació (*com ja hem vist*) |
| += | A += B | Suma i assignació. L'operació A+=B equival a A=A+B |
| -= | A -= B | Resta i assignació. L'operació A-=B equival a A=A-B |
| *= | A *= B | Multiplicació i assignació. L'operació A*=B equival a A=A*B |
| %= | A %= B | Mòdul i assignació. L'operació A%=B equival a A=A%B |
| /= | A /= B | Divisió i assignació. L'operació A/=B equival a A=A/B |

> **📌 Exemple:**
> 

```java
int dato1 = 10, dato2 = 2, dato;
dato=dato1;   // dato vale 10
dato2+=dato1; // dato2 vale 12
dato2-=dato1; // dato2 vale 2
dato2*=dato1; // dato2 vale 20
dato2/=dato1; // datos2 vale 2
dato1%=dato2; // dato1 vale0
```

> **📌 Prioritat d'operadors**
> 

> Els operadors tenen diferent Prioritat per la qual cosa és interessant utilitzar parèntesis per a controlar les operacions sense necessitat de dependre de la prioritat dels operadors.

## 6. Operador condicional `?:`

El **operador condicional** `?:` serveix per a avaluar una condició i retornar un resultat en funció de si és vertadera o falsa aquesta condició. És l'únic operador ternario de Java, i com tal, necessita tres operands per a formar una expressió:

- El **primer operant** es sitúa a l'esquerra del símbol d'interrogació, i sempre serà una expressió booleana, també anomenada **condició**. 

- El **següent operant** es sitúa a la dreta del símbol d'interrogació i abans dels dos punts, i és el valor que retornarà l'operador condicional **si la condició és vertadera**. 

- El **últim operant**, que apareix després dels dos punts, és l'expressió del qual resultat es retornarà **si la condició evaluada és falsa**.

```java
condición ? exp1 : exp2
```

> **📌 Exemple,  en l'expressió:**
> 

```java
(x>y)?x:y;
```

> Es avalua la condició de si x és major que i, en cas afirmativo es retorna el valor de la variable x, i en cas contrari es retorna el valor de i.

> **📌 Exemple per a calcular què número és major:**
> 

```java
int mayor, exp1 = 15, exp2 = 25;
mayor=(exp1>exp2)?exp1:exp2;
// mayor valdrá 25
```

### 6.1. Ternarios imbricats i indentació (*Clean Code*)

Quan necessitem triar entre **tres o més opcions**, podem encadenar un altre operador ternario després dels dos punts (`:`). Perquè el codi siga llegible i fàcil de mantindre, **mai l'escribas en una sola línia llarga**; indéntalo en diverses línies alineant els signes `?` i `:` com una escala de decisió:

> **📌 ☕ Exemple de ternario imbricat bé indentat:**
> 

```java
int numero = 0;

// ❌ Mal: difícil de leer en una sola línea
// String signo = (numero > 0) ? "Positivo" : (numero < 0) ? "Negativo" : "Cero";

// ✅ Bien: indentado por niveles de decisión
String signo = (numero > 0) ? "Positivo"
             : (numero < 0) ? "Negativo"
             : "Cero";

System.out.println("El número es: " + signo);
```


## 7. Prevalencia d'operadors

Els operadors tenen diferent **Prioritat** per la qual cosa és interessant utilitzar parèntesis per a controlar les operacions sense necessitat de dependre de la prioritat dels operadors.

Prevalencia d'operadors, ordenats d'adalt a abaix de més a menys prioritat:

| Descripció | Operadors |
| --- | --- |
| operadors posfijos | op++ op-- |
| operadors unarios | ++op --op +op -op ~ ! |
| multiplicació i divisió | * / % |
| suma i resta | + - |
| desplazament | << >> >>> |
| operadors relacionals | < > <= => |
| equivalencia | == != |
| operador AND | & |
| operador XOR | ^ |
| operador OR | \| |
| AND booleà | && |
| OR booleà | \|\| |
| condicional | ?: |
| operadors d'assignació | = += -= *= /= %= &= ^= \|= <<= >>= >>>= |

> **📌 Exemple:**
> 

```java
int x, y1 = 6, y2 = 2, y3 =8;
x = y1 + y2 * y3;   // 22
x = (y1 + y2) * y3; // 64
```
