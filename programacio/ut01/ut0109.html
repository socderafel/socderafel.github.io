1.10 Novedades de Java 25

1. Novedades y Modernización en Java 25

A lo largo de sus más de 30 años de historia, Java ha sido conocido por su robustez, estabilidad y gran adopción empresarial. No obstante, una de las críticas más habituales por parte de quienes se inician en la programación ha sido su excesiva verbosidad: para escribir el clásico programa de bienvenida (Hola Mundo), era obligatorio explicar conceptos avanzados como clases, modificadores de acceso (public), métodos de clase (static), paso de argumentos por consola (String[] args) y flujos del sistema (System.out.println).

A través del proyecto Amber de OpenJDK, Java ha evolucionado de forma espectacular con las versiones modernas y culminando en Java 25 (LTS). Esta versión consolida una serie de características pensadas para reducir drásticamente la curva de aprendizaje inicial (lo que se conoce en la comunidad como "paving the on-ramp"), permitiendo escribir código directo, limpio y legible desde el primer día, sin perder la potencia orientada a objetos en proyectos complejos.

¿Cómo puedes saber la versión de Java instalada en tu ordenador?
Código Java
JAVA 
Escribe en la terminal o símbolo del sistema:
java --version

2. Clases Declaradas Implícitamente (Implicitly Declared Classes)

Hasta hace poco, en Java era una regla inmutable que todo el código debía estar obligatoriamente dentro de una clase declarada explícitamente, y el nombre de dicha clase pública debía coincidir de manera exacta con el nombre del fichero .java.

En Java 25 ya no es necesario escribir la declaración de la clase (class MiClase { ... }) si estamos creando un programa de nivel de entrada o un script de un solo archivo.

2.1. ¿Cómo funciona?

Podemos crear un archivo fuente (por ejemplo, Calculadora.java) y escribir variables y métodos directamente en el cuerpo del archivo:

Código Java
JAVA 
// Archivo: Calculadora.java (¡Sin public class Calculadora!)

double impuesto = 0.21;

double calcularTotal(double base) {
    return base * (1 + impuesto);
}

void main() {
    System.out.println("Precio final: " + calcularTotal(100));
}
  • ¿Qué hace el compilador? El compilador de Java genera automáticamente una clase en bytecode (utilizando el nombre del fichero) para contener todos los métodos y campos definidos a nivel superior.
  • ¿Se pueden seguir definiendo métodos auxiliares? Sí. Cualquier método o variable fuera del main pasa a ser miembro de esa clase generada implícitamente.
  • Compatibilidad: No se rompe el código tradicional. Si defines una clase explícita public class MiPrograma, funciona exactamente igual que antes. La clase implícita es una facilidad para arrancar rápidamente y eliminar ruido visual.

3. Cabecera Simplificada del Método main (Instance Main Methods)

Junto con la eliminación de la declaración forzosa de la clase, Java 25 flexibiliza por completo el punto de entrada de las aplicaciones: el método main.

3.1. Comparativa: El clásico main vs El nuevo main

Tradicionalmente se requería una firma larga e intimidatoria:

Código Java
JAVA 
// Java tradicional
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}

En Java 25 podemos escribir simplemente:

Código Java
JAVA 
// Java 25
void main() {
    IO.println("Hola Mundo");
}

3.2. ¿Qué simplificaciones se han aplicado?

  1. Sin public: Ya no es obligatorio que el método sea público; puede tener visibilidad de paquete (package-private por defecto).
  2. Sin static (Métodos de instancia): El método ya no necesita ser estático. La máquina virtual (JVM) puede instanciar la clase de forma automática y ejecutar el método main como un método de instancia.
  3. Sin String[] args: Si nuestro programa no va a recibir argumentos por la línea de comandos, no hace falta declarar el array de parámetros.

3.3. Orden de resolución de la JVM

Para garantizar total compatibilidad hacia atrás, si en un archivo conviven distintas firmas de arranque, la JVM selecciona el método según el siguiente orden de prioridad:

Prioridad Firma del método main Descripción
1º static void main(String[] args) Firma clásica estándar de Java.
2º static void main() Estático, sin necesidad de argumentos de línea de comandos.
3º void main(String[] args) Método de instancia con argumentos.
4º void main() Método de instancia mínimo y simplificado.

4. Entrada y Salida Simplificada: La Clase IO

Uno de los mayores dolores de cabeza para los alumnos que se inician en Java era la entrada y salida de datos por consola:

  • Tener que memorizar System.out.println(...) para imprimir texto.
  • Tener que importar java.util.Scanner, crear una instancia vinculada a System.in (Scanner sc = new Scanner(System.in);) y gestionar los habituales problemas de desbordamiento de búfer (cuando tras nextInt() quedaba un salto de línea residual que arruinaba la llamada a nextLine()).

Java 25 resuelve esto mediante la incorporación de la clase java.io.IO, cuyos métodos estáticos están disponibles de forma directa en las clases implícitas.

4.1. Salida por consola: print() y println()

Ya no es necesario escribir System.out.println(). Podemos invocar directamente a println() y print():

Código Java
JAVA 
void main() {
    IO.print("Calculando...");
    IO.println(" ¡Listo!");
    IO.println(42);
}

4.2. Lectura de teclado: readln()

Para capturar datos del usuario desde el teclado, la clase IO proporciona el método readln():

Código Java
JAVA 
void main() {
    // Puede recibir un mensaje que se muestra al usuario antes de la lectura:
    String nombre = IO.readln("Introduce tu nombre: ");

    IO.println("¡Bienvenido/a, " + nombre + "!");
}

Ventajas frente a Scanner:

  • Sin objetos ni inicialización: No requiere crear ningún objeto (new Scanner(...)).
  • Mensaje integrado (prompt): Se le puede pasar la pregunta directamente como argumento sin necesidad de hacer un print() previo.
  • Sin problemas de búfer: readln() lee una línea completa cada vez, evitando los errores clásicos de saltos de línea residuales al alternar números y texto.

4.3. Lectura y Conversión de Números

readln() siempre devuelve un objeto de tipo String. Cuando deseamos leer un entero (int) o un decimal (double), combinamos readln() con los métodos de conversión estándar vistos en el tema de tipos de datos (Integer.parseInt y Double.parseDouble):

Código Java
JAVA 
void main() {
    // Lectura de un número entero
    int edad = Integer.parseInt(IO.readln("¿Cuántos años tienes? "));

    // Lectura de un número decimal
    double altura = Double.parseDouble(IO.readln("¿Cuánto mides en metros (ej. 1.75)? "));

    IO.println("Edad en meses: " + (edad * 12));
    IO.println("Estatura: " + altura + " m");
}

¿Y si quiero usar la clase IO dentro de una clase tradicional?

En una clase tradicional con public class Ejemplo, puedes importar sus métodos estáticos o llamarla explícitamente:

Código Java
JAVA 
import static java.io.IO.*;

public class Ejemplo {
    public static void main(String[] args) {
        String ciudad = IO.readln("¿De qué ciudad eres? ");
        IO.println("Vives en: " + ciudad);
    }
}

5. Otras Novedades Destacadas

Además de las clases implícitas y la entrada/salida simplificada, Java ha incorporado en sus últimas versiones varias características que hacen que el código sea mucho más limpio, expresivo y seguro:

5.1. Importación Automática de Módulos (import module java.base)

En las clases implícitas de Java 25, todo el módulo java.base se importa automáticamente. Esto significa que tienes acceso directo sin escribir ningún import a:

  • Colecciones: List, ArrayList, Map, Set.
  • Entrada/Salida: IO, Path, Files.
  • Utilidades: Random, Math, Objects.

En clases explícitas, puedes importar todas las librerías estándar en una sola línea gracias a la sintaxis de importación modular:

Código Java
JAVA 
import module java.base;

5.2. Bloques de Texto Multilínea (Text Blocks)

Permiten escribir cadenas de caracteres que ocupan varias líneas sin tener que concatenar con + ni usar secuencias \n:

Código Java
JAVA 
void main() {
    String menu = """
        ========================
           MENÚ DE LA APLICACIÓN
        ========================
        1. Iniciar partida
        2. Cargar puntuaciones
        3. Configuración
        4. Salir
        """;
    IO.println(menu);
}

5.3. Expresiones switch Modernas

El tradicional switch con sentencias case, break y riesgo de fallthrough se transforma en una expresión concisa que devuelve valores directamente mediante el operador flecha (->):

Código Java
JAVA 
void main() {
    int dia = 3;
    String nombreDia = switch (dia) {
        case 1 -> "Lunes";
        case 2 -> "Martes";
        case 3 -> "Miércoles";
        case 4 -> "Jueves";
        case 5 -> "Viernes";
        case 6, 7 -> "Fin de semana";
        default -> "Día no válido";
    };
    IO.println("Hoy es: " + nombreDia);
}

6. Ejemplo Completo: Programa Interactivo en Java 25

Veamos un ejemplo completo que pone en práctica todas estas novedades en un único archivo limpio y sin artificios:

Ejemplo: Ficha de Registro de Usuario

Código Java
JAVA 
// Archivo: Registro.java
// Sin declaración de clase ni imports innecesarios

// Campo a nivel de archivo (miembro de la clase implícita)
String academia = "IES Informática";

// Función auxiliar
boolean esMayorDeEdad(int edad) {
    return edad >= 18;
}

// Punto de entrada simple
void main() {
    println("=== REGISTRO EN " + academia + " ===");

    String nombre = readln("Introduce tu nombre: ");
    int edad = Integer.parseInt(readln("Introduce tu edad: "));
    double notaMedia = Double.parseDouble(readln("Introduce tu nota previa: "));

    println("\n--- Resumen del Alumno ---");
    println("Nombre: " + nombre);
    println("Edad: " + edad + (esMayorDeEdad(edad) ? " (Mayor de edad)" : " (Menor de edad)"));
    println("Nota de acceso: " + notaMedia);

    println("\n¡Registro completado con éxito!");
}
Código Java
JAVA 
=== REGISTRO EN IES Informática ===
Introduce tu nombre: Lucía
Introduce tu edad: 19
Introduce tu nota previa: 8.75

--- Resumen del Alumno ---
Nombre: Lucía
Edad: 19 (Mayor de edad)
Nota de acceso: 8.75

¡Registro completado con éxito!
