# 1.10 Novetats de Java 25

## 1. Novetats i Modernizació en Java 25

Al llarg dels seus més de 30 anys d'història, **Java** ha sigut conegut pel seu robustez, estabilitat i gran adopció empresarial. No obstant això, una de les crítiques més habituals per part de quienes es inician en la programació ha sigut el seu **excesiva verbositat**: per a escriure el clàssic programa de bienvenida (*Hola Món*), era obligatori explicar conceptes avançats com classes, modificadors d'accés (`public`), mètodes de classe (`static`), pas d'arguments per consola (`String[] args`) i fluxos del sistema (`System.out.println`).

A través del projecte **Amber** de OpenJDK, Java ha evolucionado de forma espectacular amb les versions modernes i culminant en **Java 25 (LTS)**. Aquesta versió consolida una sèrie de característiques pensades per a reduir drásticament la curva d'aprenentatge inicial (el que es coneix en la comunitat com *"paving the on-ramp"*), permetent escriure codi directe, limpio i llegible des del primer dia, sense perdre la potència orientada a objectes en projectes complexos.

## 2. Classes Declarades Implícitament (*Implicitly Declared Classes*)

Fins a fa poc, en Java era una regla inmutable que **tot el codi debía estar obligatòriament dins d'una classe declarada explícitament**, i el nom d'aquesta classe pública debía coincidir de manera exacta amb el nom del fitxer `.java`.

En Java 25 ja **no és necessari escriure la declaració de la classe** (`class MiClase { ... }`) si estem creant un programa de nivell d'entrada o un script d'un només fitxer.

### 2.1. Com funciona?

Podem crear un fitxer font (per exemple, `Calculadora.java`) i escriure variables i mètodes directament en el cos del fitxer:

```java
// Archivo: Calculadora.java (¡Sin public class Calculadora!)

double impuesto = 0.21;

double calcularTotal(double base) {
    return base * (1 + impuesto);
}

void main() {
    System.out.println("Precio final: " + calcularTotal(100));
}
```

- **Què fa el compilador?** El compilador de Java genera automàticament una classe en *bytecode* (utilitzant el nom del fitxer) per a contindre tots els mètodes i camps definits a nivell superior.

- **Es poden seguir definint mètodes auxiliares?** Sí. Qualsevol mètode o variable fóra del `main` passa a ser membre d'eixa classe generada implícitament.

- **Compatibilitat:** No es rompe el codi tradicional. Si defines una classe explícita `public class MiPrograma`, funciona exactament igual que abans. La classe implícita és una facilitat per a arrancar ràpidament i eliminar soroll visual.

## 3. Capçalera Simplificada del Mètode `main` (*Instance Main Methods*)

Juntament amb l'eliminació de la declaració forzosa de la classe, Java 25 flexibiliza per complet el punt d'entrada de les aplicacions: el mètode `main`.

### 3.1. Comparativa: El clàssic `main` vs El nou `main`

Tradicionalment es requería una firma llarga i intimidatoria:

```java
// Java tradicional
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}
```

En Java 25 podem escriure simplement:

```java
// Java 25
void main() {
    IO.println("Hola Mundo");
}
```

### 3.2. Què simplificacions s'han aplicat?

1. **Sense `public`:** Ja no és obligatori que el mètode siga públic; pot tindre visibilitat de paquet (*package-private* per defecte).

1. **Sense `static` (Mètodes d'instància):** El mètode ja no necessita ser estàtic. La màquina virtual (JVM) pot instanciar la classe de forma automàtica i executar el mètode `main` com un mètode d'instància.

1. **Sense `String[] args`:** Si el nostre programa no va a rebre arguments per la línia de comandes, no fa falta declarar l'array de paràmetres.

### 3.3. Ordre de resolució de la JVM

Per a garantir total compatibilitat cap a arrere, si en un fitxer conviven distintes firmas d'arrencada, la JVM selecciona el mètode segons el següent ordre de prioritat:

| Prioritat | Firma del mètode `main` | Descripció |
| --- | --- | --- |
| **1º** | `static void main(String[] args)` | Firma clàssica estàndard de Java. |
| **2º** | `static void main()` | Estàtic, sense necessitat d'arguments de línia de comandes. |
| **3º** | `void main(String[] args)` | Mètode d'instància amb arguments. |
| **4º** | `void main()` | Mètode d'instància mínim i simplificado. |

## 4. Entrada i Eixida Simplificada: La Classe `IO`

Un dels majors dolors de cabeza per als alumnes que es inician en Java era l'entrada i eixida de dades per consola:

- Tindre que memoritzar `System.out.println(...)` per a imprimir text.

- Tindre que importar `java.util.Scanner`, crear una instància vinculada a `System.in` (`Scanner sc = new Scanner(System.in);`) i gestionar els habituals **problemes de desbordament de búfer** (quan després de `nextInt()` quedava un salt de línia residual que arruinava l'anomenada a `nextLine()`).

Java 25 resol açò mitjançant la incorporació de la classe **`java.io.IO`**, dels quals mètodes estátics estan disponibles de forma directa en les classes implícitas.

### 4.1. Eixida per consola: `print()` i `println()`

Ja no és necessari escriure `System.out.println()`. Podem invocar directament a `println()` i `print()`:

```java
void main() {
    IO.print("Calculando...");
    IO.println(" ¡Listo!");
    IO.println(42);
}
```

### 4.2. Lectura de teclat: `readln()`

Per a capturar dades de l'usuari des del teclat, la classe `IO` proporciona el mètode **`readln()`**:

```java
void main() {
    // Puede recibir un mensaje que se muestra al usuario antes de la lectura:
    String nombre = IO.readln("Introduce tu nombre: ");

    IO.println("¡Bienvenido/a, " + nombre + "!");
}
```

#### Avantatges enfront de `Scanner`:

- **Sense objectes ni inicializació:** No requereix crear cap objecte (`new Scanner(...)`).

- **Missatge integrat (*prompt*):** Es li pot passar la pregunta directament com argument sense necessitat de fer un `print()` previo.

- **Sense problemes de búfer:** `readln()` llegix una línia completa cada vegada, evitant els errors clásics de salts de línia residuals a l'alternar números i text.

### 4.3. Lectura i Conversió de Números

`readln()` sempre retorna un objecte de tipus `String`. Quan deseamos llegir un enter (`int`) o un decimal (`double`), combinamos `readln()` amb els mètodes de conversió estàndard vistos en el tema de tipus de dades (`Integer.parseInt` i `Double.parseDouble`):

```java
void main() {
    // Lectura de un número entero
    int edad = Integer.parseInt(IO.readln("¿Cuántos años tienes? "));

    // Lectura de un número decimal
    double altura = Double.parseDouble(IO.readln("¿Cuánto mides en metros (ej. 1.75)? "));

    IO.println("Edad en meses: " + (edad * 12));
    IO.println("Estatura: " + altura + " m");
}
```

> **📌 I si vull usar la classe `IO` dins d'una classe tradicional?**
> 

> En una classe tradicional amb `public class Ejemplo`, pots importar els seus mètodes estátics o llamar-l'explícitament:

```java
import static java.io.IO.*;

public class Ejemplo {
    public static void main(String[] args) {
        String ciudad = IO.readln("¿De qué ciudad eres? ");
        IO.println("Vives en: " + ciudad);
    }
}
```

## 5. Altres Novetats Destacades

A més de les classes implícitas i l'entrada/eixida simplificada, Java ha incorporat en els seus últimes versions diverses característiques que fan que el codi siga molt més limpio, expresivo i segur:

### 5.1. Importació Automàtica de Mòduls (`import module java.base`)

En les classes implícitas de Java 25, **tot el mòdul `java.base` es importa automàticament**. Açò significa que tens accés directe sense escriure cap `import` a:

- Col·leccions: `List`, `ArrayList`, `Map`, `Set`.

- Entrada/Eixida: `IO`, `Path`, `Files`.

- Utilitats: `Random`, `Math`, `Objects`.

En classes explícitas, pots importar totes les llibreries estàndard en una sola línia gràcies a la sintaxi d'importació modular:

```java
import module java.base;
```

### 5.2. Blocs de Text Multilínea (*Text Blocks*)

Permeten escriure cadenes de caràcters que ocupen diverses línies sense tindre que concatenar amb `+` ni usar seqüències `\n`:

```java
void main() {
    String menu = """
        ========================
           MENÚ DE LA APLICACIÓN
        ========================
        1. Iniciar partida
        2. Cargar puntuaciones
        3. Configuración
        4. Salir
        """;
    IO.println(menu);
}
```

### 5.3. Expressions `switch` Modernes

El tradicional `switch` amb sentències `case`, `break` i risc de fallthrough es transforma en una expressió concisa que retorna valors directament mitjançant l'operador fletxa (`->`):

```java
void main() {
    int dia = 3;
    String nombreDia = switch (dia) {
        case 1 -> "Lunes";
        case 2 -> "Martes";
        case 3 -> "Miércoles";
        case 4 -> "Jueves";
        case 5 -> "Viernes";
        case 6, 7 -> "Fin de semana";
        default -> "Día no válido";
    };
    IO.println("Hoy es: " + nombreDia);
}
```

## 6. Exemple Complet: Programa Interactivo en Java 25

Vegem un exemple complet que posa en pràctica totes aquestes novetats en un únic fitxer limpio i sense artificios:

> **📌 Exemple: Fitxa de Registre de Usuari**
> 

#### 📌 Java (Java 25)

```java
// Archivo: Registro.java
// Sin declaración de clase ni imports innecesarios

// Campo a nivel de archivo (miembro de la clase implícita)
String academia = "IES Informática";

// Función auxiliar
boolean esMayorDeEdad(int edad) {
    return edad >= 18;
}

// Punto de entrada simple
void main() {
    println("=== REGISTRO EN " + academia + " ===");

    String nombre = readln("Introduce tu nombre: ");
    int edad = Integer.parseInt(readln("Introduce tu edad: "));
    double notaMedia = Double.parseDouble(readln("Introduce tu nota previa: "));

    println("\n--- Resumen del Alumno ---");
    println("Nombre: " + nombre);
    println("Edad: " + edad + (esMayorDeEdad(edad) ? " (Mayor de edad)" : " (Menor de edad)"));
    println("Nota de acceso: " + notaMedia);

    println("\n¡Registro completado con éxito!");
}
```

#### 📌 Resultat per Consola

```java
=== REGISTRO EN IES Informática ===
Introduce tu nombre: Lucía
Introduce tu edad: 19
Introduce tu nota previa: 8.75

--- Resumen del Alumno ---
Nombre: Lucía
Edad: 19 (Mayor de edad)
Nota de acceso: 8.75

¡Registro completado con éxito!
```
