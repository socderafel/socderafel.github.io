1.1 Piensa como un programador y diseña algoritmos

1. Piensa como un programador y diseña algoritmos

La programación es, en esencia, una forma sistemática de resolver problemas mediante ordenadores. Para que un problema sea resoluble por una computadora, debe poder expresarse de forma mecánica y automática, sin ambigüedades.

1.1. Resolución de Problemas: El Método de Polya

El matemático George Polya formuló un método heurístico de cuatro operaciones mentales para resolver problemas, el cual se alinea perfectamente con las fases de desarrollo de software:

Fase del Método de Polya Operación en Programación Objetivo principal
1. Entender el problema Analizar el problema Comprender qué se pide, identificar datos de entrada y resultados esperados.
2. Trazar un plan Diseñar un algoritmo Encontrar una secuencia lógica de pasos para resolver el problema.
3. Ejecutar el plan Codificar el programa Traducir el algoritmo diseñado a un lenguaje de programación (ej. Java).
4. Revisar Depurar y verificar Probar el programa con distintos casos para corregir fallos y optimizarlo.

1.2. ¿Qué es un Algoritmo?

Un algoritmo es un conjunto de pasos o instrucciones lógicas, ordenadas y acotadas, diseñadas para resolver un problema o realizar una tarea.

Ejemplo

Un ejemplo de un algoritmo clásico y sencillo de la vida cotidiana son los pasos a seguir para desayunar:

Código Java
JAVA 
Inicio
    Sentarse en la mesa
    Servir café con leche y azúcar
    Si tengo tiempo Entonces
        Mientras tenga apetito Hacer
            Untar mantequilla y mermelada en una tostada
            Comer la tostada
        Fin Mientras
    Fin Si
    Beber café con leche
    Levantarse
Fin

1.2.1. Características Fundamentales de un Algoritmo

  • Generalidad: Debe servir para resolver cualquier caso del problema (usando variables), no solo uno concreto.
  • Finitud: Debe terminar obligatoriamente tras un número determinado de pasos.
  • Definibilidad: Cada paso debe ser claro y no dar pie a dobles interpretaciones (sin ambigüedades).
  • Eficiencia: Debe resolver el problema consumiendo el mínimo tiempo y recursos posibles.

1.3. Representación de Algoritmos

Los algoritmos son independientes de los lenguajes de programación y del hardware. Para diseñarlos antes de programar, se utilizan principalmente dos métodos estructurados:

1.3.1. Pseudocódigo

Es un lenguaje descriptivo intermedio entre el lenguaje humano y el de programación, ideal para estructurar la lógica sin preocuparse por la sintaxis estricta del compilador.

Ejemplo: Mostrar dos números ordenados de menor a mayor:

    Leer (A, B)
    Si (A > B) Entonces
        Escribir (B, A)

1.4. Algoritmos frente a Programas

La diferencia fundamental es que un algoritmo es la lógica abstracta de solución, mientras que un programa es la plasmación física de dicho algoritmo escrita en un lenguaje de programación específico para que la computadora pueda ejecutarlo.

Cuando un problema es complejo, aplicamos la estrategia de "Divide y vencerás" con dos variantes:

  • Diseño descendente (Top-Down): Descomponer un problema grande en subproblemas más sencillos.
  • Diseño modular: Resolver cada subproblema de forma independiente mediante módulos o subprogramas para luego integrarlos.

1.2 Java

1. ¿Qué y cómo es Java?

Java es un lenguaje sencillo de aprender, con una sintaxis parecida a la de C++, pero en la que se han eliminado elementos complicados y que pueden originar errores. Java es un lenguaje orientado a objetos, con lo que elimina muchas preocupaciones al programador y permite la utilización de gran cantidad de bibliotecas ya definidas, evitando reescribir código que ya existe. Es un lenguaje de programación creado para satisfacer nuevas necesidades que los lenguajes existentes hasta el momento no eran capaces de solventar.

Una de las principales virtudes de Java es su independencia del hardware, ya que el código que se genera es válido para cualquier plataforma. Este código será ejecutado sobre una máquina virtual denominada Maquina Virtual Java (MVJ o JVM – Java Virtual Machine), que interpretará el código convirtiéndolo a código específico de la plataforma que lo soporta. De este modo el programa se escribe una única vez y puede hacerse funcionar en cualquier lugar. Lema del lenguaje: "Write once, run everywhere".

Antes de que apareciera Java, el lenguaje C era uno de los más extendidos por su versatilidad. Pero cuando los programas escritos en C aumentaban de volumen, su manejo comenzaba a complicarse. Mediante las técnicas de programación estructurada y programación modular se conseguían reducir estas complicaciones, pero no era suficiente.

Fue entonces cuando la Programación Orientada a Objetos (POO) entra en escena, aproximando notablemente la construcción de programas al pensamiento humano y haciendo más sencillo todo el proceso. Los problemas se dividen en objetos que tienen propiedades e interactúan con otros objetos, de este modo, el programador puede centrarse en cada objeto para programar internamente los elementos y funciones que lo componen.

Las características principales de lenguaje Java se resumen a continuación:

  • El código generado por el compilador Java es independiente de la arquitectura.

  • Está totalmente orientado a objetos.

  • Su sintaxis es similar a C y C++.

  • Es distribuido, preparado para aplicaciones TCP/IP.

  • Dispone de un amplio conjunto de bibliotecas.

  • Es robusto, realizando comprobaciones del código en tiempo de compilación y de ejecución.

  • La seguridad está garantizada, ya que las aplicaciones Java no acceden a zonas delicadas de memoria o de sistema. (ejem, ejem!).

2. Estructura y Bloques Fundamentales de un Programa Java

En Java, toda instrucción ejecutable se organiza en clases y métodos.

Ejemplo: HolaMundo

Veamos el clásico ejemplo para mostrar un saludo por consola:

Código Java
JAVA 
public class HolaMundo {
    // Punto de entrada: el método main es lo primero que ejecuta Java
    public static void main(String[] args) {
        /* Muestra el mensaje por pantalla e introduce 
        un salto de línea al final */
        System.out.println("Hola Mundo!");
    }
}

  • Clase (public class HolaMundo): En Java, el nombre de la clase pública debe coincidir exactamente con el nombre del archivo (HolaMundo.java).
  • Método main: Es el punto de inicio obligatorio de cualquier aplicación Java estándar.
  • Instrucciones: Todas las sentencias y llamadas a métodos terminan obligatoriamente con punto y coma (;).

2.1. Sangrado o Indentación

La indentación consiste en dejar una sangría en el margen izquierdo de cada línea dentro de un bloque { ... }. Esto mejora drásticamente la lectura del código.

  • Se recomienda usar entre 2 y 4 espacios (o un tabulador).
  • Se aconseja limitar el ancho de las líneas de código a unos 70-90 caracteres para que quepan completas en cualquier pantalla o editor sin necesidad de scroll horizontal.

3. Compilar y ejecutar un programa Java. Uso de la consola.

Veamos los pasos para compilar e interpretar nuestro primer programa escrito en lenguaje Java:

Paso 1. Creación del código fuente --> Paso 2. Compilación del programa --> Paso 3. Ejecución del programa.

Paso 1: Creación del código fuente

Abrimos un editor de texto (da igual cual sea, siempre que sea capaz de almacenar “texto sin formato” en código ASCII). Una vez abierto escribiremos nuestro primer programa, que mostrará un texto “Hola Mundo” en la consola. De momento no te preocupes si no entiendes lo que escribes, más adelante le daremos sentido. Ahora solo queremos ver si podemos ejecutar java en nuestro equipo.

El código de nuestro programa en Java será el siguiente:

Código Java
JAVA 
/* Ejemplo Hola Mundo */
public class HolaMundo {
    public static void main(String[ ] arg) {
        System.out.println("Hola Mundo");
    }
}

A continuación guardamos nuestro archivo y le ponemos como nombre HolaMundo.java. Debemos seguir una norma dictada por Java, hemos de hacer coincidir nombre del archivo y nombre del programa, tanto en mayúsculas como en minúsculas, y la extensión del archivo habrá de ser siempre .java.

Debemos recordar exactamente la ruta donde guardamos el archivo de ejemplo HolaMundo.java.

Paso 2: Compilación del programa

Vamos a proceder a compilar e interpretar este pequeño programa Java (no te preocupes si todavía no entiendes el significado de las palabras compilar e interpretar, lo verás en el módulo de Entornos de Desarrollo). Para ello usaremos la consola. Una vez en la consola debemos colocarnos en la ruta donde previamente guardamos el archivo HolaMundo.java.

A continuación daremos la instrucción para que se realice el proceso de compilación del programa, para lo que escribiremos javac HolaMundo.java, donde javac es el nombre del compilador (java compiler) que transformará el programa que hemos escrito nosotros en lenguaje Java al lenguaje de la máquina virtual Java (bytecode), dando como resultado un nuevo archivo HolaMundo.class que se creará en este mismo directorio. Comprueba que no aparezca ningún error y que javac esté instalado en tu sistema (desde la consola lo puedes comprobar con el comando javac --version y debería aparece el número de versión que tienes instalada). Si aparecen los dos archivos tanto HolaMundo.java (código fuente) como HolaMundo.class (bytecode creado por el compilador) puedes continuar.

Terminal / Consola
BASH 
$ javac HolaMundo.java

Paso 3: Ejecución del programa

Finalmente, vamos a pedirle al intérprete que ejecute el programa, es decir, que transforme el código de la máquina virtual Java en código máquina interpretable por nuestro ordenador y lo ejecute. Para ello escribiremos en la ventana consola: java HolaMundo.

El resultado será que se nos muestra la cadena Hola Mundo. Si logramos visualizar este texto en pantalla, ya hemos desarrollado nuestro primer programa en Java.

Terminal / Consola
BASH 
$ java HolaMundo

1.3 Variables, identificadores, convenciones

1. Variables

Una variable es un espacio reservado en la memoria del ordenador que tiene un nombre, un tipo y un valor. Gracias a ella, el programa puede guardar datos y recuperarlos más adelante.

Toda variable queda definida por tres características:

Característica Descripción
Nombre (identificador) Permite referenciar la variable en el código
Tipo de dato Indica qué clase de información almacena (int, double, String…)
Valor El dato concreto guardado en ese momento

Ejemplo

Código Java
JAVA 
int edad = 17;          // nombre: edad       |  tipo: int     |  valor: 17
String nombre = "Ana";  // nombre: nombre     |  tipo: String  |  valor: "Ana"
double precio = 9.99;   // nombre: precio     |  tipo: double  |  valor: 9.99

1.1.Ámbito (scope) de una variable

El ámbito o scope es la zona del código donde una variable es accesible. En Java, una variable declarada dentro de un bloque { } solo existe dentro de ese bloque.

Ejemplo

Código Java
JAVA 
public static void main(String[] args) {
    int x = 10;          // x es accesible en todo el método main

    if (x > 5) {
        int y = 20;      // y solo existe dentro de este bloque if
        System.out.println(x + y); // correcto
    }

    System.out.println(y); // ERROR: y no existe aquí
}

2. Constantes

Una constante es como una variable, pero su valor no puede cambiar una vez asignado. Se usa para datos fijos que deben permanecer igual durante toda la ejecución del programa.

En Java se declaran con la palabra clave final:

Ejemplo

Código Java
JAVA 
final double PI = 3.14159;
final int TAM_MAX = 100;
final String MENSAJE_ERROR = "Operación no permitida";

Si intentamos cambiar su valor, el compilador lo impide:

Ejemplo

Código Java
JAVA 
final int MAX = 50;
MAX = 60;   // ERROR: no se puede reasignar una constante

2.1. ¿Cuándo usar una constante en lugar de una variable?

  • Cuando el valor nunca debe cambiar (el valor de π, un límite máximo, un código de error, etc.)
  • Para evitar escribir el mismo número "mágico" en varios sitios del código.
  • Para que el código sea más legible: TAM_MAX comunica más que un 100 suelto.

Ejemplo

Código Java
JAVA 
// Sin constante — ¿qué significa 365?
int diasAnio = dias * 365;

// Con constante — queda claro y no puede cambiar por error
final int DIAS_POR_ANIO = 365;
int diasAnio = dias * DIAS_POR_ANIO;

3. Identificadores

Un identificador es el nombre que le damos a un elemento del programa: una variable, una constante, una clase, un método, etc.

3.1. Reglas obligatorias en Java

Para que un identificador sea válido, debe cumplir estas reglas sin excepción:

  • Solo puede contener letras, dígitos, _ y $.
  • Debe empezar por una letra, _ o $ (nunca por un dígito).
  • No puede contener espacios.
  • Distingue mayúsculas de minúsculas: edad y Edad son identificadores distintos.
  • No puede coincidir con una palabra reservada de Java (int, class, for, etc.)
Identificador ¿Válido? Motivo
numAlumnos ✅ Correcto
_contador ✅ Empieza por _
3errores ❌ Empieza por dígito
mi variable ❌ Contiene espacio
class ❌ Es palabra reservada
$precio ✅ Técnicamente válido (no recomendado)

Nota sobre Unicode: Java acepta letras de cualquier alfabeto (griego, árabe, etc.), por lo que identificadores como ατη son válidos. En la práctica, se usan siempre letras del alfabeto latino para garantizar compatibilidad.

4. Convenciones de nombrado

Las convenciones no son obligatorias, pero todo el mundo las sigue en Java. Respetarlas hace el código más legible y profesional.

4.1. lowerCamelCase — variables y métodos

Empieza en minúscula. Cada palabra siguiente comienza en mayúscula. Sin guiones ni espacios.

Ejemplo

Código Java
JAVA 
// Variables
int numAlumnos;
double precioFinal;
String nombreCompleto;

// Métodos
void calcularMedia() { ... }
int obtenerEdad() { ... }

4.2. UpperCamelCase — clases

Empieza en mayúscula. Igual que el anterior pero la primera letra también va en mayúscula.

Ejemplo

Código Java
JAVA 
class Alumno { ... }
class CuentaBancaria { ... }
class GestorDeArchivos { ... }

4.3. UPPER_SNAKE_CASE — constantes

Todo en mayúsculas, palabras separadas por _.

Todas las constantes deben seguir esta nomenclatura

Ejemplo

Código Java
JAVA 
final int TAM_MAX = 100;
final double PI = 3.14159;
final String RUTA_FICHERO = "/datos/alumnos.txt";

5. Palabras reservadas

Las palabras reservadas (keywords) son términos que Java usa internamente. No se pueden usar como identificadores.

Están organizadas por categoría para que sea más fácil memorizarlas:

Categoría Palabras
Tipos de dato boolean, byte, char, double, float, int, long, short
Control de flujo if, else, switch, case, default, for, while, do, break, continue, return
Clases y objetos class, interface, extends, implements, new, this, super, instanceof, enum
Modificadores public, private, protected, static, final, abstract, synchronized, volatile, transient, strictfp, native
Gestión de errores try, catch, finally, throw, throws
Paquetes package, import
Otros void, const, goto, assert

Ejemplo de error frecuente

Código Java

¿& o &&? ¿| o ||?

Aunque producen el mismo resultado lógico, hay una diferencia clave en cómo los evalúa Java:

Operador Nombre Comportamiento
&& AND cortocircuito Si el primer operando es false, Java no evalúa el segundo
& AND bit a bit Siempre evalúa los dos operandos
|| OR cortocircuito Si el primer operando es true, Java no evalúa el segundo
| OR bit a bit Siempre evalúa los dos operandos

¿Por qué importa? Con && y || el programa es más eficiente y evita errores:

Código Java
JAVA 
int[] numeros = null;

// Con &  → ERROR: evalúa ambos lados aunque numeros sea null
if (numeros != null & numeros.length > 0) { ... }

// Con && → SEGURO: si numeros es null, no llega a mirar .length
if (numeros != null && numeros.length > 0) { ... }

Regla práctica: usa siempre && y || para condiciones lógicas. Reserva & y | solo para operaciones a nivel de bits.

6. Operador condicional ?:

El operador condicional ?: sirve para evaluar una condición y devolver un resultado en función de si es verdadera o falsa dicha condición. Es el único operador ternario de Java, y como tal, necesita tres operandos para formar una expresión:

  • El primer operando se sitúa a la izquierda del símbolo de interrogación, y siempre será una expresión booleana, también llamada condición.
  • El siguiente operando se sitúa a la derecha del símbolo de interrogación y antes de los dos puntos, y es el valor que devolverá el operador condicional si la condición es verdadera.
  • El último operando, que aparece después de los dos puntos, es la expresión cuyo resultado se devolverá si la condición evaluada es falsa.
Código Java
JAVA 
condición ? exp1 : exp2

Ejemplo, en la expresión:

Código Java
JAVA 
(x>y)?x:y;

Se evalúa la condición de si x es mayor que y, en caso afirmativo se devuelve el valor de la variable x, y en caso contrario se devuelve el valor de y.

Ejemplo para calcular qué número es mayor:

Código Java
JAVA 
int mayor, exp1 = 15, exp2 = 25;
mayor=(exp1>exp2)?exp1:exp2;
// mayor valdrá 25

    JAVA

2. La clase Random

A diferencia de Math.random(), que únicamente devuelve un valor double en el rango $[0.0, 1.0)$ y requiere operaciones de escalado y casting, la clase Random ofrece métodos directos y más cómodos, como nextInt().

    2º) Instanciar el objeto generador (habitualmente llamado ran o rnd):

1. Introducción: De Tipos Primitivos a Clases (Wrappers)

En Java existen dos grandes categorías de tipos de datos:

  1. Tipos primitivos (int, double, char, boolean...): Almacenan directamente el valor puro en la memoria rápida (pila o stack). Son muy ligeros y rápidos, pero no son objetos: carecen de atributos y métodos. No es posible escribir numero.algo().
  2. Tipos referenciados u Objetos (Clases): Almacenan una referencia (puntero) a un objeto ubicado en la memoria dinámica (heap). Disponen de métodos de utilidad incorporados para operar, consultar y transformar la información.

Para salvar esta limitación, Java incluye en su paquete fundamental java.lang (disponible automáticamente sin necesidad de import) una Clase Envoltorio (Wrapper class) para cada uno de los 8 tipos primitivos:

Tipo Primitivo Clase Envoltorio (Wrapper) Tamaño en memoria Ejemplo de método estático útil
byteByte8 bitsByte.parseByte("10")
shortShort16 bitsShort.MAX_VALUE
intInteger32 bitsInteger.parseInt("42")
longLong64 bitsLong.parseLong("10000000000")
floatFloat32 bitsFloat.parseFloat("3.14F")
doubleDouble64 bitsDouble.parseDouble("19.99")
charCharacter16 bitsCharacter.isDigit('7')
booleanBoolean1 bitBoolean.parseBoolean("true")

⚡ Autoboxing y Unboxing automático

Java convierte automáticamente entre el primitivo y su clase envoltorio sin necesidad de instanciar manualmente:

Código Java

import java.util.Scanner;

public class ClasificadorCaracter {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un solo carácter por teclado: ");
        char entrada = sc.next().charAt(0);

        if (Character.isDigit(entrada)) {
            System.out.println("-> Es un DÍGITO NUMÉRICO (0-9).");
        } else if (Character.isLetter(entrada)) {
            System.out.println("-> Es una LETRA ALFABÉTICA.");
            if (Character.isUpperCase(entrada)) {
                System.out.println("   Está en MAYÚSCULAS.");
            } else {
                System.out.println("   Está en MINÚSCULAS.");
            }
            // Uso de operador ternario para alternar mayúscula/minúscula

                                                          : Character.toUpperCase(entrada);
            System.out.println("   Su opuesto es: " + opuesto);
        } else if (Character.isWhitespace(entrada)) {
            System.out.println("-> Es un espacio en blanco o tabulador.");
        } else {
            System.out.println("-> Es un SÍMBOLO o SIGNO DE PUNTUACIÓN.");
        }

        sc.close();
    }
}

Caso Práctico 1: Validador de Formato de DNI / NIF

Comprobar que una cadena introducida cumple con el formato estándar español (8 números seguidos de 1 letra mayúscula):

Código Java
JAVA 
package ut1.practicas;

import java.util.Scanner;

public class ValidadorDniSimple {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce tu DNI/NIF completo (ej. 12345678Z): ");
        String dni = sc.nextLine().trim().toUpperCase();

        // 1. Validar longitud exacta de 9 caracteres
        if (dni.length() != 9) {
            System.out.println("❌ Error: El DNI debe tener exactamente 9 caracteres.");
        } else {
            // 2. Extraer la parte numérica y la letra final
            String parteNumerica = dni.substring(0, 8);
            char letraFinal = dni.charAt(8);

            // 3. Validar con Character que el último sea una letra
            if (!Character.isLetter(letraFinal)) {
                System.out.println("❌ Error: El último carácter debe ser una letra.");
            } else {
                // 4. Convertir los primeros 8 caracteres a entero con Integer.parseInt
                int numeroDni = Integer.parseInt(parteNumerica);
                System.out.println("✅ Formato válido. Número: " + numeroDni + " | Letra: " + letraFinal);
            }
        }

        sc.close();
    }
}

Caso Práctico 2: Validador de Seguridad de Contraseña

Verificar si una contraseña cumple los requisitos mínimos de seguridad:

  • Longitud mínima de 8 caracteres.
  • Al menos un dígito numérico (Character.isDigit).
  • Al menos una letra mayúscula (Character.isUpperCase).
  • Al menos una letra minúscula (Character.isLowerCase).
Código Java
JAVA 
package ut1.practicas;

import java.util.Scanner;

public class ValidadorPassword {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce tu nueva contraseña: ");
        String password = sc.nextLine();

        if (password.length() < 8) {
            System.out.println("❌ Contraseña demasiado corta (mínimo 8 caracteres).");
        } else {
            boolean tieneNumero = false;
            boolean tieneMayuscula = false;
            boolean tieneMinuscula = false;

            // Recorremos la cadena carácter a carácter con charAt(i)
            for (int i = 0; i < password.length(); i++) {
                char actual = password.charAt(i);

                if (Character.isDigit(actual)) {
                    tieneNumero = true;
                } else if (Character.isUpperCase(actual)) {
                    tieneMayuscula = true;
                } else if (Character.isLowerCase(actual)) {
                    tieneMinuscula = true;
                }
            }

            // Comprobación final
            if (tieneNumero && tieneMayuscula && tieneMinuscula) {
                System.out.println("✅ Contraseña FUERTE y válida.");
            } else {
                System.out.println("⚠️ Contraseña DÉBIL. Debe incluir al menos:");
                if (!tieneNumero)    System.out.println("   - Un número");
                if (!tieneMayuscula) System.out.println("   - Una letra mayúscula");
                if (!tieneMinuscula) System.out.println("   - Una letra minúscula");
            }
        }

        sc.close();
    }
}

2. Clases Declaradas Implícitamente (Implicitly Declared Classes)

Hasta hace poco, en Java era una regla inmutable que todo el código debía estar obligatoriamente dentro de una clase declarada explícitamente, y el nombre de dicha clase pública debía coincidir de manera exacta con el nombre del fichero .java.

En Java 25 ya no es necesario escribir la declaración de la clase (class MiClase { ... }) si estamos creando un programa de nivel de entrada o un script de un solo archivo.

2.1. ¿Cómo funciona?

Podemos crear un archivo fuente (por ejemplo, Calculadora.java) y escribir variables y métodos directamente en el cuerpo del archivo:

Código Java
JAVA 
// Archivo: Calculadora.java (¡Sin public class Calculadora!)

double impuesto = 0.21;

double calcularTotal(double base) {
    return base * (1 + impuesto);
}

void main() {
    System.out.println("Precio final: " + calcularTotal(100));
}
  • ¿Qué hace el compilador? El compilador de Java genera automáticamente una clase en bytecode (utilizando el nombre del fichero) para contener todos los métodos y campos definidos a nivel superior.
  • ¿Se pueden seguir definiendo métodos auxiliares? Sí. Cualquier método o variable fuera del main pasa a ser miembro de esa clase generada implícitamente.
  • Compatibilidad: No se rompe el código tradicional. Si defines una clase explícita public class MiPrograma, funciona exactamente igual que antes. La clase implícita es una facilidad para arrancar rápidamente y eliminar ruido visual.

3. Cabecera Simplificada del Método main (Instance Main Methods)

Junto con la eliminación de la declaración forzosa de la clase, Java 25 flexibiliza por completo el punto de entrada de las aplicaciones: el método main.

3.1. Comparativa: El clásico main vs El nuevo main

Tradicionalmente se requería una firma larga e intimidatoria:

Código Java
JAVA 
// Java tradicional
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}

En Java 25 podemos escribir simplemente:

Código Java
JAVA 
// Java 25
void main() {
    IO.println("Hola Mundo");
}

3.2. ¿Qué simplificaciones se han aplicado?

  1. Sin public: Ya no es obligatorio que el método sea público; puede tener visibilidad de paquete (package-private por defecto).
  2. Sin static (Métodos de instancia): El método ya no necesita ser estático. La máquina virtual (JVM) puede instanciar la clase de forma automática y ejecutar el método main como un método de instancia.
  3. Sin String[] args: Si nuestro programa no va a recibir argumentos por la línea de comandos, no hace falta declarar el array de parámetros.

3.3. Orden de resolución de la JVM

Para garantizar total compatibilidad hacia atrás, si en un archivo conviven distintas firmas de arranque, la JVM selecciona el método según el siguiente orden de prioridad:

Prioridad Firma del método main Descripción
1º static void main(String[] args) Firma clásica estándar de Java.
2º static void main() Estático, sin necesidad de argumentos de línea de comandos.
3º void main(String[] args) Método de instancia con argumentos.
4º void main() Método de instancia mínimo y simplificado.

4. Entrada y Salida Simplificada: La Clase IO

Uno de los mayores dolores de cabeza para los alumnos que se inician en Java era la entrada y salida de datos por consola:

  • Tener que memorizar System.out.println(...) para imprimir texto.
  • Tener que importar java.util.Scanner, crear una instancia vinculada a System.in (Scanner sc = new Scanner(System.in);) y gestionar los habituales problemas de desbordamiento de búfer (cuando tras nextInt() quedaba un salto de línea residual que arruinaba la llamada a nextLine()).

Java 25 resuelve esto mediante la incorporación de la clase java.io.IO, cuyos métodos estáticos están disponibles de forma directa en las clases implícitas.

4.1. Salida por consola: print() y println()

Ya no es necesario escribir System.out.println(). Podemos invocar directamente a println() y print():

Código Java
JAVA 
void main() {
    IO.print("Calculando...");
    IO.println(" ¡Listo!");
    IO.println(42);
}

4.2. Lectura de teclado: readln()

Para capturar datos del usuario desde el teclado, la clase IO proporciona el método readln():

Código Java
JAVA 
void main() {
    // Puede recibir un mensaje que se muestra al usuario antes de la lectura:
    String nombre = IO.readln("Introduce tu nombre: ");

    IO.println("¡Bienvenido/a, " + nombre + "!");
}

Ventajas frente a Scanner:

  • Sin objetos ni inicialización: No requiere crear ningún objeto (new Scanner(...)).
  • Mensaje integrado (prompt): Se le puede pasar la pregunta directamente como argumento sin necesidad de hacer un print() previo.
  • Sin problemas de búfer: readln() lee una línea completa cada vez, evitando los errores clásicos de saltos de línea residuales al alternar números y texto.

4.3. Lectura y Conversión de Números

readln() siempre devuelve un objeto de tipo String. Cuando deseamos leer un entero (int) o un decimal (double), combinamos readln() con los métodos de conversión estándar vistos en el tema de tipos de datos (Integer.parseInt y Double.parseDouble):

Código Java
JAVA 
void main() {
    // Lectura de un número entero
    int edad = Integer.parseInt(IO.readln("¿Cuántos años tienes? "));

    // Lectura de un número decimal
    double altura = Double.parseDouble(IO.readln("¿Cuánto mides en metros (ej. 1.75)? "));

    IO.println("Edad en meses: " + (edad * 12));
    IO.println("Estatura: " + altura + " m");
}

¿Y si quiero usar la clase IO dentro de una clase tradicional?

En una clase tradicional con public class Ejemplo, puedes importar sus métodos estáticos o llamarla explícitamente:

Código Java
JAVA 
import static java.io.IO.*;

public class Ejemplo {
    public static void main(String[] args) {
        String ciudad = IO.readln("¿De qué ciudad eres? ");
        IO.println("Vives en: " + ciudad);
    }
}

1.11 Creación y uso de métodos

1. ¿Qué es una clase en Java?

Hasta ahora hemos escrito pequeños programas en Java donde todo el código se colocaba dentro de un bloque con la palabra reservada class:

Código Java
JAVA 
public class MiPrimerPrograma {
    public static void main(String[] args) {
        System.out.println("Hola!");
    }
}

En Java, todo el código debe residir obligatoriamente dentro de una clase.

Para entenderlo de forma sencilla en esta primera unidad:

  • Una clase es el "contenedor" principal de nuestro programa. Actúa como una caja organizada que agrupa tanto datos (variables) como acciones o funciones (métodos).
  • El archivo en disco debe llamarse exactamente igual que la clase pública y terminar en .java (por ejemplo, MiPrimerPrograma.java).
  • Más adelante, en la UT 4, profundizaremos en la Programación Orientada a Objetos (POO) y veremos que las clases también sirven de molde o plantilla para fabricar "objetos". Pero de momento, nos basta con ver la clase como la unidad organizativa donde guardamos nuestro programa y sus funciones.

2. El punto de entrada: ¿Qué es el método main?

Cuando le pedimos a la máquina virtual de Java (JVM) que ejecute un programa, ¿por dónde empieza a leer las instrucciones?

Java no ejecuta el archivo de arriba abajo sin más; busca una "puerta de entrada" especial y obligatoria: el método main.

Código Java
JAVA 
public static void main(String[] args) {
    // Aquí empieza a ejecutarse nuestro programa
}
  • public: Es un modificador de acceso. Indica que este método puede ser llamado desde fuera de la clase (en este caso, por la propia máquina virtual de Java).
  • static: Significa que el método pertenece a la clase y puede ejecutarse directamente sin necesidad de crear un objeto previo en memoria.
  • void: Indica el tipo de dato devuelto. void significa "vacío" o "nada"; es decir, este método realiza tareas pero no devuelve ningún resultado a quien lo llamó.
  • main: Es el identificador o nombre reservado por convenio que Java reconoce como inicio de la aplicación.
  • String[] args: Es un array de cadenas de texto que permite recibir parámetros desde la consola o terminal al iniciar el programa (por ahora no nos preocuparemos por él).

3. ¿Por qué crear otros métodos dentro de la clase?

A medida que nuestros programas crecen, escribir todo el código de forma continua dentro de main se convierte en una mala práctica: el código se vuelve difícil de leer, largo y casi imposible de mantener o depurar.

Un método es un bloque de instrucciones con un nombre asociado que realiza una tarea concreta y que puede ser ejecutado tantas veces como sea necesario desde cualquier punto del programa.

Las principales ventajas de dividir el código en métodos son:

  1. Modularidad ("Divide y vencerás"): Descomponemos un problema grande y complejo en subtareas pequeñas, comprensibles e independientes.
  2. Reutilización (Principio DRY - Don't Repeat Yourself): Escribimos la lógica una sola vez y la llamamos cuantas veces haga falta en vez de duplicar líneas de código.
  3. Claridad y legibilidad: Un método main bien diseñado se lee casi como un índice de un libro, delegando los detalles en métodos auxiliares con nombres autoexplicativos.

4. ¿Qué significa static en un método?

En la declaración de los métodos que crearemos en esta unidad verás siempre la palabra clave static:

Código Java
JAVA 
public static void saludar() { ... }
public static int sumar(int a, int b) { ... }

4.1. Método de clase vs. Método de objeto

En Java existen dos tipos de métodos:

  1. Métodos de objeto (o de instancia): Requieren crear previamente un objeto en la memoria con el operador new para poder ser utilizados (los estudiaremos a fondo en la UT 4).
  2. Métodos de clase (static): Pertenecen a la propia clase y no necesitan crear ningún objeto para poder ser ejecutados.

4.2. La regla de oro en la UT 1

El método main es estático (static). En Java existe una regla estricta:

[!IMPORTANT] Regla del contexto estático Un método static solo puede llamar directamente a otros métodos que también sean static dentro de la misma clase.

Si intentas llamar a un método normal (no estático) desde main sin haber creado un objeto, el compilador mostrará el clásico error:

Código Java
JAVA 
non-static method noSePuedeLlamar() cannot be referenced from a static context

Por esta razón, durante la UT 1 y la UT 2, todos los métodos auxiliares que declaremos en nuestra clase llevarán la palabra reservada static.

Métodos estáticos que ya conoces

Ya has utilizado métodos estáticos de la biblioteca estándar de Java sin darte cuenta:

  • Math.sqrt(25) o Math.pow(2, 3): Invocados directamente usando el nombre de la clase Math.
  • Integer.parseInt("123"): Invocado directamente sobre la clase Integer.

5. Anatomía y sintaxis de un método

Un método en Java se compone de dos partes fundamentales: la cabecera (o firma) y el cuerpo.

Código Java
JAVA 
[modificadores]  <tipoDevuelto>  <nombreMétodo> ( [<parámetros>] ) {
    // Cuerpo del método: instrucciones ejecutables
    [return <valor>;]
}
Código Java
JAVA 
// Ejemplo de método completo:
public static int calcularDoble(int numero) {
    int resultado = numero * 2;
    return resultado;
}

Desglosemos cada elemento:

5.1. Modificadores

Indican la visibilidad y características del método. * En nuestros métodos de la UT 1 usaremos habitualmente public static o simplemente static.

5.2. Tipo de dato devuelto (return type)

Indica qué tipo de información va a devolver el método una vez termine su ejecución: * Si devuelve un dato, se especifica su tipo: primitivos (int, double, boolean, char...) o de referencia (String). * Si el método realiza una acción pero no devuelve ningún valor, se utiliza obligatoriamente la palabra clave void.

5.3. Nombre del método

Sigue la convención camelCase: * Debe comenzar con una letra minúscula. * Por convenio, se recomienda que sea un verbo que describa la acción que realiza: calcularTotal, mostrarMenu, esPar, obtenerMayor.

5.4. Lista de parámetros

Son los datos que el método necesita recibir del exterior para trabajar. * Van entre paréntesis ( ) separados por comas. * Cada parámetro debe indicar obligatoriamente su tipo y su nombre: (int base, int altura). * Si el método no necesita recibir información, los paréntesis se dejan vacíos: ( ).

5.5. Cuerpo del método

Es el bloque encerrado entre llaves { }. Contiene las sentencias Java, declaraciones de variables locales y estructuras de control necesarias para cumplir su tarea.

5.6. La sentencia return

Permite devolver el resultado final al punto del programa donde se llamó al método: * Si el método define un tipo de retorno distinto de void, es obligatorio que termine con un return seguido de un valor o expresión del tipo prometido. * En cuanto se ejecuta una sentencia return, el método finaliza de inmediato, devolviendo el control al código llamante. * Si el método es void, no hace falta poner return (aunque se puede usar return; en solitario para salir antes del método si se cumple alguna condición).

Diferencia crucial: imprimir (println) no es devolver (return)

Uno de los errores más frecuentes al iniciarse en la programación es confundir mostrar por pantalla con devolver un valor:

  • System.out.println(...): Muestra texto en la consola para que el usuario humano lo lea, pero el programa no puede "guardar" esa salida para hacer otros cálculos.
  • return valor: Pasa el dato internamente a quien invocó el método para que pueda guardarlo en una variable, compararlo o usarlo en otra operación matemática.

6. Parámetros y paso de información

Es importante distinguir entre dos conceptos:

  1. Parámetro formal: Es la variable que se declara en la cabecera del método al definirlo. Funciona como una variable local dentro del método.
  2. Argumento (o parámetro real): Es el valor concreto que se le envía al método en el momento exacto de llamarlo (invocación).
Código Java
JAVA 
// 'numero' es el PARÁMETRO FORMAL
public static int elevarAlCuadrado(int numero) {
    return numero * numero;
}

public static void main(String[] args) {
    int x = 5;
    // 'x' (o el valor 5) es el ARGUMENTO real
    int resultado = elevarAlCuadrado(x);
}

Paso de parámetros por valor

En Java, los tipos primitivos se pasan siempre por valor. Esto significa que el método recibe una copia del dato. Si el método modifica el valor de su parámetro local, la variable original en main no se ve afectada.

7. Los cuatro tipos de métodos según parámetros y retorno

Dependiendo de si necesitan datos de entrada y de si devuelven un resultado, podemos clasificar los métodos en cuatro categorías:

Caso 1: Sin parámetros y sin retorno (void)

Son métodos que realizan una acción fija, como mostrar información o un menú:

Código Java
JAVA 
public static void mostrarSeparador() {
    System.out.println("----------------------------------------");
}

Llamada desde main:

Código Java
JAVA 
mostrarSeparador();

Caso 2: Con parámetros y sin retorno (void)

Reciben datos del exterior pero no devuelven nada; suelen procesar esos datos para mostrarlos en pantalla:

Código Java
JAVA 
public static void saludarUsuario(String nombre, int edad) {
    System.out.println("Hola " + nombre + ", tienes " + edad + " años.");
}

Llamada desde main:

Código Java
JAVA 
saludarUsuario("Carlos", 20);

Caso 3: Sin parámetros y con retorno

No necesitan datos de entrada, pero calculan o generan un valor que devuelven al programa principal:

Código Java
JAVA 
public static double obtenerNumeroPi() {
    return 3.14159265;
}

Llamada desde main:

Código Java
JAVA 
double pi = obtenerNumeroPi();
System.out.println("El valor de PI es: " + pi);

Caso 4: Con parámetros y con retorno

Son los métodos más habituales y potentes: reciben datos, los procesan y devuelven el resultado final:

Código Java
JAVA 
public static int calcularMayor(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

public static boolean esPar(int numero) {
    return numero % 2 == 0;
}

Llamada desde main:

Código Java
JAVA 
int mayor = calcularMayor(15, 27);
System.out.println("El mayor es: " + mayor); // Imprime 27

if (esPar(mayor)) {
    System.out.println("Además es par.");
}

8. ¿Cómo y dónde se colocan los métodos dentro del código?

Un programa Java básico con métodos sigue esta estructura:

Código Java
JAVA 
public class NombreClase {

    // 1. Método principal (main)
    public static void main(String[] args) {
        // Invocación a otros métodos
    }

    // 2. Otros métodos estáticos auxiliares (al mismo nivel)
    public static void metodoA() {
        ...
    }

    public static int metodoB(int x) {
        ...
    }
}

[!CAUTION] ¡Nunca anides métodos! En Java no se puede declarar un método dentro de otro método. Los métodos se declaran unos detrás de otros, dentro del cuerpo de la clase { ... }, pero nunca dentro del cuerpo de main ni de ningún otro método.

9. Ejemplo integrador completo

Veamos un programa completo donde aplicamos todo lo aprendido: una pequeña aplicación que calcula estadísticas de dos números:

Código Java
JAVA 
public class CalculadoraEstadistica {

    // Método principal: orquesta la ejecución
    public static void main(String[] args) {
        int num1 = 12;
        int num2 = 8;

        imprimirCabecera();

        // Llamamos a los métodos y recogemos sus resultados
        int suma = sumar(num1, num2);
        double media = calcularMedia(num1, num2);
        int mayor = obtenerMaximo(num1, num2);

        // Mostramos los resultados
        System.out.println("Números evaluados: " + num1 + " y " + num2);
        System.out.println("Suma: " + suma);
        System.out.println("Media: " + media);
        System.out.println("El mayor de los dos es: " + mayor);

        if (esPositivo(num1)) {
            System.out.println(num1 + " es positivo.");
        }
    }

    // 1. Sin parámetros y sin retorno
    public static void imprimirCabecera() {
        System.out.println("========================================");
        System.out.println("   ESTADÍSTICAS BÁSICAS DE NÚMEROS      ");
        System.out.println("========================================");
    }

    // 2. Con parámetros y con retorno (int)
    public static int sumar(int a, int b) {
        return a + b;
    }

    // 3. Con parámetros y con retorno (double)
    public static double calcularMedia(int a, int b) {
        return (a + b) / 2.0; // Usamos 2.0 para evitar la división entera
    }

    // 4. Con parámetros y lógica condicional
    public static int obtenerMaximo(int a, int b) {
        if (a >= b) {
            return a;
        } else {
            return b;
        }
    }

    // 5. Con parámetros y retorno booleano
    public static boolean esPositivo(int n) {
        return n > 0;
    }
}

10. Resumen de errores frecuentes y cómo evitarlos

Error habitual Causa Solución
Olvidar la palabra static Llamar a un método no estático desde main. Añadir el modificador static en la cabecera del método.
Definir un método dentro de main Intentar crear funciones locales dentro de las llaves de main. Mover la definición del método fuera de main, como miembro de la clase.
Falta de sentencia return Declarar que el método devuelve un tipo (int, String...) pero no incluir return. Asegurarse de que todos los caminos del código devuelven un valor del tipo adecuado.
Código inalcanzable (Unreachable code) Colocar sentencias después de una instrucción return. Todo código después de return nunca se ejecutará. Colocarlo antes.
Confundir orden o tipos de argumentos Llamar a metodo(String, int) pasando metodo(int, String). Respetar rigurosamente el número, tipo y orden de los parámetros definidos.
