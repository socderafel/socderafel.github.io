1.5 Clases Envoltorio (Wrappers), Character y String

📌 Información Curricular y Resultados de Aprendizaje

Resultados de Aprendizaje: RA1 (Reconoce la estructura de un programa informático, identificando los tipos de datos del lenguaje) y RA3 (Escribe y depura código con estructuras de control).

Criterios de Evaluación: CEb (Identificación de tipos de datos básicos y objetos), CEd (Operadores y conversiones), CEf (Librerías de clases estándar de Java) y CEg (Sintaxis y convenciones Clean Code).

1. Introducción: De Tipos Primitivos a Clases (Wrappers)

En Java existen dos grandes categorías de tipos de datos:

  1. Tipos primitivos (int, double, char, boolean...): Almacenan directamente el valor puro en la memoria rápida (pila o stack). Son muy ligeros y rápidos, pero no son objetos: carecen de atributos y métodos. No es posible escribir numero.algo().
  2. Tipos referenciados u Objetos (Clases): Almacenan una referencia (puntero) a un objeto ubicado en la memoria dinámica (heap). Disponen de métodos de utilidad incorporados para operar, consultar y transformar la información.

Para salvar esta limitación, Java incluye en su paquete fundamental java.lang (disponible automáticamente sin necesidad de import) una Clase Envoltorio (Wrapper class) para cada uno de los 8 tipos primitivos:

Tipo Primitivo Clase Envoltorio (Wrapper) Tamaño en memoria Ejemplo de método estático útil
byteByte8 bitsByte.parseByte("10")
shortShort16 bitsShort.MAX_VALUE
intInteger32 bitsInteger.parseInt("42")
longLong64 bitsLong.parseLong("10000000000")
floatFloat32 bitsFloat.parseFloat("3.14F")
doubleDouble64 bitsDouble.parseDouble("19.99")
charCharacter16 bitsCharacter.isDigit('7')
booleanBoolean1 bitBoolean.parseBoolean("true")

⚡ Autoboxing y Unboxing automático

Java convierte automáticamente entre el primitivo y su clase envoltorio sin necesidad de instanciar manualmente:

Código Java
JAVA 
Integer numObjeto = 10;        // Autoboxing: de int primitivo a objeto Integer
int numPrimitivo = numObjeto;  // Unboxing: de objeto Integer a int primitivo

Nota: Desde Java 9, el uso de constructores explícitos como new Integer(10) está oficialmente obsoleto y desaconsejado.

2. La Clase Character: Inspección y Validación de Caracteres

El tipo primitivo char almacena un único carácter Unicode entre comillas simples ('a', '5', '#'). Al ser primitivo, no tiene métodos propios.

Para saber si un carácter introducido por el usuario es una letra, un número, un espacio o un signo de puntuación, recurrimos a los métodos estáticos de la clase Character.

2.1. Métodos de comprobación booleana (is...)

Se invocan directamente como Character.metodo(variableChar) y devuelven true o false:

Método Devuelve Descripción Ejemplo (char c = '9';)
Character.isDigit(c)booleanComprueba si es un dígito numérico ('0' al '9').Character.isDigit('9') → true
Character.isLetter(c)booleanComprueba si es una letra alfabética (incluye tildes, 'ñ' y Unicode).Character.isLetter('9') → false
Character.isLetterOrDigit(c)booleanComprueba si es alfanumérico (letra o dígito).Character.isLetterOrDigit('@') → false
Character.isWhitespace(c)booleanComprueba si es espacio en blanco, tabulador (\t) o salto de línea (\n).Character.isWhitespace(' ') → true
Character.isUpperCase(c)booleanComprueba si la letra está en mayúscula.Character.isUpperCase('A') → true
Character.isLowerCase(c)booleanComprueba si la letra está en minúscula.Character.isLowerCase('a') → true

2.2. Métodos de transformación (to...)

Método Devuelve Descripción Ejemplo
Character.toUpperCase(c)charConvierte el carácter a mayúscula (si no es letra, lo mantiene igual).Character.toUpperCase('b') → 'B'
Character.toLowerCase(c)charConvierte el carácter a minúscula.Character.toLowerCase('G') → 'g'

2.3. Ejemplo práctico: Clasificar la pulsación del usuario

El siguiente programa pide un carácter y muestra su clasificación exacta combinando Character con el operador condicional:

Código Java
JAVA 
package ut1.caracteres;

import java.util.Scanner;

public class ClasificadorCaracter {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce un solo carácter por teclado: ");
        char entrada = sc.next().charAt(0);

        if (Character.isDigit(entrada)) {
            System.out.println("-> Es un DÍGITO NUMÉRICO (0-9).");
        } else if (Character.isLetter(entrada)) {
            System.out.println("-> Es una LETRA ALFABÉTICA.");
            if (Character.isUpperCase(entrada)) {
                System.out.println("   Está en MAYÚSCULAS.");
            } else {
                System.out.println("   Está en MINÚSCULAS.");
            }
            // Uso de operador ternario para alternar mayúscula/minúscula
            char opuesto = Character.isUpperCase(entrada) ? Character.toLowerCase(entrada)
                                                          : Character.toUpperCase(entrada);
            System.out.println("   Su opuesto es: " + opuesto);
        } else if (Character.isWhitespace(entrada)) {
            System.out.println("-> Es un espacio en blanco o tabulador.");
        } else {
            System.out.println("-> Es un SÍMBOLO o SIGNO DE PUNTUACIÓN.");
        }

        sc.close();
    }
}

3. Clases Numéricas (Integer, Double): Conversión y Constantes

En aplicaciones reales (y formularios web), los datos leídos del teclado o de una petición web llegan siempre en formato de texto (String). Las clases numéricas aportan las funciones esenciales de conversión (parsing).

3.1. Conversión de texto (String) a número primitivo (parseInt, parseDouble)

Código Java
JAVA 
// Conversión de String a números primitivos
String textoEdad = "19";
int edad = Integer.parseInt(textoEdad); // Devuelve int primitivo 19

String textoPrecio = "49.95";
double precio = Double.parseDouble(textoPrecio); // Devuelve double primitivo 49.95

⚠️ Error común: NumberFormatException

Si la cadena no contiene un formato numérico válido (por ejemplo Integer.parseInt("hola") o Integer.parseInt("12.5") al intentar meter decimales en un entero), Java lanzará una excepción NumberFormatException y detendrá el programa. Más adelante en la UT2 aprenderemos a capturarlo con try-catch.

3.2. Conversión de número a texto (String)

Código Java
JAVA 
int codigo = 404;

// Opción 1: Método estático de la clase envoltorio
String textoCodigo1 = Integer.toString(codigo);

// Opción 2 (Recomendada y universal para cualquier tipo):
String textoCodigo2 = String.valueOf(codigo);

3.3. Constantes límite del sistema

Las clases envoltorio permiten consultar los límites numéricos de la máquina:

Código Java
JAVA 
System.out.println("Entero máximo: " + Integer.MAX_VALUE); //  2.147.483.647
System.out.println("Entero mínimo: " + Integer.MIN_VALUE); // -2.147.483.648

System.out.println("Decimal máximo: " + Double.MAX_VALUE); // 1.7976931348623157E308

4. La Clase String: Métodos Esenciales de Inspección y Manipulación

La clase String representa secuencias alfanuméricas inmutables. Cuenta con métodos nativos para examinar y manipular cadenas.

4.1. Métodos fundamentales de consulta

Método Devuelve Descripción Ejemplo (String s = "DAW 1º";)
s.length()intNúmero total de caracteres de la cadena.s.length() → 6
s.charAt(i)charCarácter situado en el índice i (base 0).s.charAt(0) → 'D'
s.isEmpty()booleantrue si la longitud es 0 ("")."".isEmpty() → true

🔗 El puente entre String y Character

Gracias a s.charAt(i), podemos extraer cualquier carácter de una cadena de texto para examinarlo inmediatamente con los métodos de Character:

Código Java
JAVA 
String matricula = "4589LKT";
char primerCaracter = matricula.charAt(0); // '4'
boolean esNumero = Character.isDigit(primerCaracter); // true

4.2. Métodos de comparación (¡Regla de oro: NUNCA usar ==!)

Los objetos en Java no se comparan con el operador == (porque compararía sus direcciones de memoria en el heap, no el contenido de sus caracteres). Siempre debemos usar los métodos de comparación:

Método Devuelve Descripción
s1.equals(s2)booleantrue si ambas cadenas son exactamente idénticas respetando mayúsculas/minúsculas.
s1.equalsIgnoreCase(s2)booleantrue si coinciden ignorando diferencias entre mayúsculas y minúsculas.
s1.compareTo(s2)intComparación lexicográfica (alfabética). Devuelve 0 si son iguales, < 0 si s1 va antes, > 0 si va después.

4.3. Búsqueda y Subcadenas

Método Devuelve Descripción Ejemplo (String s = "IES Catadau";)
s.contains(texto)booleanComprueba si la subcadena está contenida en el texto.s.contains("Cata") → true
s.startsWith(prefijo)booleanComprueba si empieza por dicho prefijo.s.startsWith("IES") → true
s.endsWith(sufijo)booleanComprueba si termina por dicho sufijo.s.endsWith(".java") → false
s.indexOf(texto)intPosición de la primera coincidencia (o -1 si no existe).s.indexOf("Catadau") → 4
s.substring(inicio)StringExtrae el texto desde el índice inicio hasta el final.s.substring(4) → "Catadau"
s.substring(inicio, fin)StringExtrae desde inicio (incluido) hasta fin (excluido).s.substring(0, 3) → "IES"

5. Casos Prácticos Completos

Caso Práctico 1: Validador de Formato de DNI / NIF

Comprobar que una cadena introducida cumple con el formato estándar español (8 números seguidos de 1 letra mayúscula):

Código Java
JAVA 
package ut1.practicas;

import java.util.Scanner;

public class ValidadorDniSimple {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce tu DNI/NIF completo (ej. 12345678Z): ");
        String dni = sc.nextLine().trim().toUpperCase();

        // 1. Validar longitud exacta de 9 caracteres
        if (dni.length() != 9) {
            System.out.println("❌ Error: El DNI debe tener exactamente 9 caracteres.");
        } else {
            // 2. Extraer la parte numérica y la letra final
            String parteNumerica = dni.substring(0, 8);
            char letraFinal = dni.charAt(8);

            // 3. Validar con Character que el último sea una letra
            if (!Character.isLetter(letraFinal)) {
                System.out.println("❌ Error: El último carácter debe ser una letra.");
            } else {
                // 4. Convertir los primeros 8 caracteres a entero con Integer.parseInt
                int numeroDni = Integer.parseInt(parteNumerica);
                System.out.println("✅ Formato válido. Número: " + numeroDni + " | Letra: " + letraFinal);
            }
        }

        sc.close();
    }
}

Caso Práctico 2: Validador de Seguridad de Contraseña

Verificar si una contraseña cumple los requisitos mínimos de seguridad:

  • Longitud mínima de 8 caracteres.
  • Al menos un dígito numérico (Character.isDigit).
  • Al menos una letra mayúscula (Character.isUpperCase).
  • Al menos una letra minúscula (Character.isLowerCase).
Código Java
JAVA 
package ut1.practicas;

import java.util.Scanner;

public class ValidadorPassword {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Introduce tu nueva contraseña: ");
        String password = sc.nextLine();

        if (password.length() < 8) {
            System.out.println("❌ Contraseña demasiado corta (mínimo 8 caracteres).");
        } else {
            boolean tieneNumero = false;
            boolean tieneMayuscula = false;
            boolean tieneMinuscula = false;

            // Recorremos la cadena carácter a carácter con charAt(i)
            for (int i = 0; i < password.length(); i++) {
                char actual = password.charAt(i);

                if (Character.isDigit(actual)) {
                    tieneNumero = true;
                } else if (Character.isUpperCase(actual)) {
                    tieneMayuscula = true;
                } else if (Character.isLowerCase(actual)) {
                    tieneMinuscula = true;
                }
            }

            // Comprobación final
            if (tieneNumero && tieneMayuscula && tieneMinuscula) {
                System.out.println("✅ Contraseña FUERTE y válida.");
            } else {
                System.out.println("⚠️ Contraseña DÉBIL. Debe incluir al menos:");
                if (!tieneNumero)    System.out.println("   - Un número");
                if (!tieneMayuscula) System.out.println("   - Una letra mayúscula");
                if (!tieneMinuscula) System.out.println("   - Una letra minúscula");
            }
        }

        sc.close();
    }
}
