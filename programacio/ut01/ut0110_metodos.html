1.11 Creación y uso de métodos

1. ¿Qué es una clase en Java?

Hasta ahora hemos escrito pequeños programas en Java donde todo el código se colocaba dentro de un bloque con la palabra reservada class:

Código Java
JAVA 
public class MiPrimerPrograma {
    public static void main(String[] args) {
        System.out.println("Hola!");
    }
}

En Java, todo el código debe residir obligatoriamente dentro de una clase.

Para entenderlo de forma sencilla en esta primera unidad:

  • Una clase es el "contenedor" principal de nuestro programa. Actúa como una caja organizada que agrupa tanto datos (variables) como acciones o funciones (métodos).
  • El archivo en disco debe llamarse exactamente igual que la clase pública y terminar en .java (por ejemplo, MiPrimerPrograma.java).
  • Más adelante, en la UT 4, profundizaremos en la Programación Orientada a Objetos (POO) y veremos que las clases también sirven de molde o plantilla para fabricar "objetos". Pero de momento, nos basta con ver la clase como la unidad organizativa donde guardamos nuestro programa y sus funciones.

2. El punto de entrada: ¿Qué es el método main?

Cuando le pedimos a la máquina virtual de Java (JVM) que ejecute un programa, ¿por dónde empieza a leer las instrucciones?

Java no ejecuta el archivo de arriba abajo sin más; busca una "puerta de entrada" especial y obligatoria: el método main.

Código Java
JAVA 
public static void main(String[] args) {
    // Aquí empieza a ejecutarse nuestro programa
}
  • public: Es un modificador de acceso. Indica que este método puede ser llamado desde fuera de la clase (en este caso, por la propia máquina virtual de Java).
  • static: Significa que el método pertenece a la clase y puede ejecutarse directamente sin necesidad de crear un objeto previo en memoria.
  • void: Indica el tipo de dato devuelto. void significa "vacío" o "nada"; es decir, este método realiza tareas pero no devuelve ningún resultado a quien lo llamó.
  • main: Es el identificador o nombre reservado por convenio que Java reconoce como inicio de la aplicación.
  • String[] args: Es un array de cadenas de texto que permite recibir parámetros desde la consola o terminal al iniciar el programa (por ahora no nos preocuparemos por él).

3. ¿Por qué crear otros métodos dentro de la clase?

A medida que nuestros programas crecen, escribir todo el código de forma continua dentro de main se convierte en una mala práctica: el código se vuelve difícil de leer, largo y casi imposible de mantener o depurar.

Un método es un bloque de instrucciones con un nombre asociado que realiza una tarea concreta y que puede ser ejecutado tantas veces como sea necesario desde cualquier punto del programa.

Las principales ventajas de dividir el código en métodos son:

  1. Modularidad ("Divide y vencerás"): Descomponemos un problema grande y complejo en subtareas pequeñas, comprensibles e independientes.
  2. Reutilización (Principio DRY - Don't Repeat Yourself): Escribimos la lógica una sola vez y la llamamos cuantas veces haga falta en vez de duplicar líneas de código.
  3. Claridad y legibilidad: Un método main bien diseñado se lee casi como un índice de un libro, delegando los detalles en métodos auxiliares con nombres autoexplicativos.

4. ¿Qué significa static en un método?

En la declaración de los métodos que crearemos en esta unidad verás siempre la palabra clave static:

Código Java
JAVA 
public static void saludar() { ... }
public static int sumar(int a, int b) { ... }

4.1. Método de clase vs. Método de objeto

En Java existen dos tipos de métodos:

  1. Métodos de objeto (o de instancia): Requieren crear previamente un objeto en la memoria con el operador new para poder ser utilizados (los estudiaremos a fondo en la UT 4).
  2. Métodos de clase (static): Pertenecen a la propia clase y no necesitan crear ningún objeto para poder ser ejecutados.

4.2. La regla de oro en la UT 1

El método main es estático (static). En Java existe una regla estricta:

[!IMPORTANT] Regla del contexto estático Un método static solo puede llamar directamente a otros métodos que también sean static dentro de la misma clase.

Si intentas llamar a un método normal (no estático) desde main sin haber creado un objeto, el compilador mostrará el clásico error:

Código Java
JAVA 
non-static method noSePuedeLlamar() cannot be referenced from a static context

Por esta razón, durante la UT 1 y la UT 2, todos los métodos auxiliares que declaremos en nuestra clase llevarán la palabra reservada static.

Métodos estáticos que ya conoces

Ya has utilizado métodos estáticos de la biblioteca estándar de Java sin darte cuenta:

  • Math.sqrt(25) o Math.pow(2, 3): Invocados directamente usando el nombre de la clase Math.
  • Integer.parseInt("123"): Invocado directamente sobre la clase Integer.

5. Anatomía y sintaxis de un método

Un método en Java se compone de dos partes fundamentales: la cabecera (o firma) y el cuerpo.

Código Java
JAVA 
[modificadores]  <tipoDevuelto>  <nombreMétodo> ( [<parámetros>] ) {
    // Cuerpo del método: instrucciones ejecutables
    [return <valor>;]
}
Código Java
JAVA 
// Ejemplo de método completo:
public static int calcularDoble(int numero) {
    int resultado = numero * 2;
    return resultado;
}

Desglosemos cada elemento:

5.1. Modificadores

Indican la visibilidad y características del método. * En nuestros métodos de la UT 1 usaremos habitualmente public static o simplemente static.

5.2. Tipo de dato devuelto (return type)

Indica qué tipo de información va a devolver el método una vez termine su ejecución: * Si devuelve un dato, se especifica su tipo: primitivos (int, double, boolean, char...) o de referencia (String). * Si el método realiza una acción pero no devuelve ningún valor, se utiliza obligatoriamente la palabra clave void.

5.3. Nombre del método

Sigue la convención camelCase: * Debe comenzar con una letra minúscula. * Por convenio, se recomienda que sea un verbo que describa la acción que realiza: calcularTotal, mostrarMenu, esPar, obtenerMayor.

5.4. Lista de parámetros

Son los datos que el método necesita recibir del exterior para trabajar. * Van entre paréntesis ( ) separados por comas. * Cada parámetro debe indicar obligatoriamente su tipo y su nombre: (int base, int altura). * Si el método no necesita recibir información, los paréntesis se dejan vacíos: ( ).

5.5. Cuerpo del método

Es el bloque encerrado entre llaves { }. Contiene las sentencias Java, declaraciones de variables locales y estructuras de control necesarias para cumplir su tarea.

5.6. La sentencia return

Permite devolver el resultado final al punto del programa donde se llamó al método: * Si el método define un tipo de retorno distinto de void, es obligatorio que termine con un return seguido de un valor o expresión del tipo prometido. * En cuanto se ejecuta una sentencia return, el método finaliza de inmediato, devolviendo el control al código llamante. * Si el método es void, no hace falta poner return (aunque se puede usar return; en solitario para salir antes del método si se cumple alguna condición).

Diferencia crucial: imprimir (println) no es devolver (return)

Uno de los errores más frecuentes al iniciarse en la programación es confundir mostrar por pantalla con devolver un valor:

  • System.out.println(...): Muestra texto en la consola para que el usuario humano lo lea, pero el programa no puede "guardar" esa salida para hacer otros cálculos.
  • return valor: Pasa el dato internamente a quien invocó el método para que pueda guardarlo en una variable, compararlo o usarlo en otra operación matemática.

6. Parámetros y paso de información

Es importante distinguir entre dos conceptos:

  1. Parámetro formal: Es la variable que se declara en la cabecera del método al definirlo. Funciona como una variable local dentro del método.
  2. Argumento (o parámetro real): Es el valor concreto que se le envía al método en el momento exacto de llamarlo (invocación).
Código Java
JAVA 
// 'numero' es el PARÁMETRO FORMAL
public static int elevarAlCuadrado(int numero) {
    return numero * numero;
}

public static void main(String[] args) {
    int x = 5;
    // 'x' (o el valor 5) es el ARGUMENTO real
    int resultado = elevarAlCuadrado(x);
}

Paso de parámetros por valor

En Java, los tipos primitivos se pasan siempre por valor. Esto significa que el método recibe una copia del dato. Si el método modifica el valor de su parámetro local, la variable original en main no se ve afectada.

7. Los cuatro tipos de métodos según parámetros y retorno

Dependiendo de si necesitan datos de entrada y de si devuelven un resultado, podemos clasificar los métodos en cuatro categorías:

Caso 1: Sin parámetros y sin retorno (void)

Son métodos que realizan una acción fija, como mostrar información o un menú:

Código Java
JAVA 
public static void mostrarSeparador() {
    System.out.println("----------------------------------------");
}

Llamada desde main:

Código Java
JAVA 
mostrarSeparador();

Caso 2: Con parámetros y sin retorno (void)

Reciben datos del exterior pero no devuelven nada; suelen procesar esos datos para mostrarlos en pantalla:

Código Java
JAVA 
public static void saludarUsuario(String nombre, int edad) {
    System.out.println("Hola " + nombre + ", tienes " + edad + " años.");
}

Llamada desde main:

Código Java
JAVA 
saludarUsuario("Carlos", 20);

Caso 3: Sin parámetros y con retorno

No necesitan datos de entrada, pero calculan o generan un valor que devuelven al programa principal:

Código Java
JAVA 
public static double obtenerNumeroPi() {
    return 3.14159265;
}

Llamada desde main:

Código Java
JAVA 
double pi = obtenerNumeroPi();
System.out.println("El valor de PI es: " + pi);

Caso 4: Con parámetros y con retorno

Son los métodos más habituales y potentes: reciben datos, los procesan y devuelven el resultado final:

Código Java
JAVA 
public static int calcularMayor(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

public static boolean esPar(int numero) {
    return numero % 2 == 0;
}

Llamada desde main:

Código Java
JAVA 
int mayor = calcularMayor(15, 27);
System.out.println("El mayor es: " + mayor); // Imprime 27

if (esPar(mayor)) {
    System.out.println("Además es par.");
}

8. ¿Cómo y dónde se colocan los métodos dentro del código?

Un programa Java básico con métodos sigue esta estructura:

Código Java
JAVA 
public class NombreClase {

    // 1. Método principal (main)
    public static void main(String[] args) {
        // Invocación a otros métodos
    }

    // 2. Otros métodos estáticos auxiliares (al mismo nivel)
    public static void metodoA() {
        ...
    }

    public static int metodoB(int x) {
        ...
    }
}

[!CAUTION] ¡Nunca anides métodos! En Java no se puede declarar un método dentro de otro método. Los métodos se declaran unos detrás de otros, dentro del cuerpo de la clase { ... }, pero nunca dentro del cuerpo de main ni de ningún otro método.

9. Ejemplo integrador completo

Veamos un programa completo donde aplicamos todo lo aprendido: una pequeña aplicación que calcula estadísticas de dos números:

Código Java
JAVA 
public class CalculadoraEstadistica {

    // Método principal: orquesta la ejecución
    public static void main(String[] args) {
        int num1 = 12;
        int num2 = 8;

        imprimirCabecera();

        // Llamamos a los métodos y recogemos sus resultados
        int suma = sumar(num1, num2);
        double media = calcularMedia(num1, num2);
        int mayor = obtenerMaximo(num1, num2);

        // Mostramos los resultados
        System.out.println("Números evaluados: " + num1 + " y " + num2);
        System.out.println("Suma: " + suma);
        System.out.println("Media: " + media);
        System.out.println("El mayor de los dos es: " + mayor);

        if (esPositivo(num1)) {
            System.out.println(num1 + " es positivo.");
        }
    }

    // 1. Sin parámetros y sin retorno
    public static void imprimirCabecera() {
        System.out.println("========================================");
        System.out.println("   ESTADÍSTICAS BÁSICAS DE NÚMEROS      ");
        System.out.println("========================================");
    }

    // 2. Con parámetros y con retorno (int)
    public static int sumar(int a, int b) {
        return a + b;
    }

    // 3. Con parámetros y con retorno (double)
    public static double calcularMedia(int a, int b) {
        return (a + b) / 2.0; // Usamos 2.0 para evitar la división entera
    }

    // 4. Con parámetros y lógica condicional
    public static int obtenerMaximo(int a, int b) {
        if (a >= b) {
            return a;
        } else {
            return b;
        }
    }

    // 5. Con parámetros y retorno booleano
    public static boolean esPositivo(int n) {
        return n > 0;
    }
}

10. Resumen de errores frecuentes y cómo evitarlos

Error habitual Causa Solución
Olvidar la palabra static Llamar a un método no estático desde main. Añadir el modificador static en la cabecera del método.
Definir un método dentro de main Intentar crear funciones locales dentro de las llaves de main. Mover la definición del método fuera de main, como miembro de la clase.
Falta de sentencia return Declarar que el método devuelve un tipo (int, String...) pero no incluir return. Asegurarse de que todos los caminos del código devuelven un valor del tipo adecuado.
Código inalcanzable (Unreachable code) Colocar sentencias después de una instrucción return. Todo código después de return nunca se ejecutará. Colocarlo antes.
Confundir orden o tipos de argumentos Llamar a metodo(String, int) pasando metodo(int, String). Respetar rigurosamente el número, tipo y orden de los parámetros definidos.
