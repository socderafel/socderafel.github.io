3.2.2 Problemas de recorrido, búsqueda y ordenación en arrays

Muchos de los algoritmos fundamentales en programación estructurada sobre arrays se clasifican en tres grandes categorías:

  • a) Problemas de recorrido: Exigen procesar o examinar todos los elementos del array (sumas, medias, transformaciones, conteos).
  • b) Problemas de búsqueda: Determinan si existe algún elemento que cumpla una condición dada, deteniéndose en cuanto se halla.
  • c) Problemas de ordenación: Reorganizan los elementos según un criterio de orden (ascendente o descendente).

a) Problemas de recorrido de un array

Se consideran problemas de recorrido aquellos que, para su resolución, exigen el tratamiento sistemático de todos los elementos del array. El recorrido puede organizarse de forma ascendente (de izquierda a derecha), descendente (de derecha a izquierda) o con pasos específicos.

1. Recorrido clásico con índice (bucle for tradicional)

Utiliza una variable entera i que actúa como subíndice (0, 1, ..., array.length - 1):

Ejemplo: Pluviosidad Media Ascendente

Código Java
JAVA 
public static double pluviosidadMediaAscendente(double lluvia[]) {
    double suma = 0;

    // Recorremos el array de forma ascendente con índice i (0 .. length-1)
    for (int i = 0; i < lluvia.length; i++) {
        suma += lluvia[i];
    }
    return suma / lluvia.length;
}

Ejemplo: Recorrido Descendente y Cálculo de Máximo

Para recorrer de final a principio comenzamos en lluvia.length - 1 y decrementamos hasta 0:

Código Java
JAVA 
public static double pluviosidadMediaDescendente(double lluvia[]) {
    double suma = 0;

    // Recorremos el array de forma descendente (length-1 .. 0)
    for (int i = lluvia.length - 1; i >= 0; i--) {
        suma += lluvia[i];
    }
    return suma / lluvia.length;
}

Y para hallar el valor máximo, inicializamos con la primera posición y comparamos a partir del índice 1:

Código Java
JAVA 
public static double pluviosidadMaxima(double[] lluvia) {
    // Suponemos que el máximo se produjo el primer día
    double max = lluvia[0];

    // Recorremos desde la posición 1 comparando
    for (int i = 1; i < lluvia.length; i++) {
        if (lluvia[i] > max) {
            max = lluvia[i];
        }
    }
    return max;
}

2. El bucle for-each (Enhanced for loop)

A partir de Java 5, se introdujo una estructura de control especializada denominada bucle for-each o bucle for mejorado. Su propósito fundamental es hacer el código más limpio, legible y seguro cuando necesitamos recorrer una estructura de datos de principio a fin.

💡 ¿Por qué usar for-each?

  • Adiós a los índices manuales: No necesitas declarar int i = 0; i < array.length; i++.
  • Inmune a desbordamientos: Es imposible cometer el típico error de novato ArrayIndexOutOfBoundsException (por ejemplo, escribir accidentalmente <= length).
  • Legibilidad directa: Se lee en lenguaje natural: "Para cada elemento del array, haz...".

Sintaxis general del for-each

Código Java
JAVA 
// Sintaxis general del bucle for-each
for (TipoElemento variableTemporal : arrayOEstructura) {
    // Código a ejecutar para cada elemento
    // "variableTemporal" toma automáticamente el valor de cada celda
}

Ejemplo comparativo: Calcular la media con for-each

Observa cómo la función de pluviosidad media se reduce a su mínima expresión:

Código Java
JAVA 
public static double pluviosidadMediaForEach(double[] lluvia) {
    double suma = 0;

    // "Para cada valor 'dia' de tipo double que haya dentro del array 'lluvia'"
    for (double dia : lluvia) {
        suma += dia;
    }
    return suma / lluvia.length;
}

Recorrido de arrays de objetos y cadenas (String[])

El bucle for-each brilla especialmente con arrays de referencias a objetos, como listas de nombres:

Código Java
JAVA 
// Array de Strings (Objetos)
String[] alumnos = {"Marc", "Laia", "Pau", "Elena", "Vicent"};

// Recorrido limpio sin necesidad de índices
for (String alumno : alumnos) {
    System.out.println("Alumno matriculado: " + alumno.toUpperCase());
}

3. ¿Cómo recorrer un String con for-each?

🔍 Pregunta frecuente en clase: "¿Puedo usar for-each directamente sobre un String?"

En Java, String es un objeto de texto inmutable y no implementa directamente la interfaz Iterable. Por lo tanto, escribir for (char c : "Hola") provoca un error de compilación inmediato.

Sin embargo, ahora que dominas los arrays, dispones de dos soluciones inmediatas muy potentes:

Opción A: Recorrer carácter a carácter con .toCharArray()

El método toCharArray() de la clase String genera un array estático char[] que sí podemos recorrer limpiamente con for-each:

Código Java
JAVA 
String texto = "IES Mestre Ramon Esteve";
int vocales = 0;

// ❌ for (char c : texto) -> ¡ERROR DE COMPILACIÓN! String no es directamente un array

// ✅ Convertimos el String a un array de caracteres char[] con .toCharArray()
for (char c : texto.toLowerCase().toCharArray()) {
    if ("aeiouáàéèíóòú".indexOf(c) != -1) {
        vocales++;
    }
}

System.out.println("Total de vocales: " + vocales);

Opción B: Recorrer palabra a palabra con .split()

Si lo que deseamos es procesar cada palabra de una frase, split(" ") trocea el texto devolviendo un String[]:

Código Java
JAVA 
String frase = "Programar en Java mola molt";

// .split(" ") divide el texto por espacios y devuelve un String[]
for (String palabra : frase.split(" ")) {
    System.out.println("Palabra: " + palabra + " (" + palabra.length() + " letras)");
}

4. ⚠️ ¡CUIDADO! La trampa de examen: El for-each es de SOLO LECTURA

💥 Error clásico de principiante: Intentar modificar el array dentro de un for-each

En cada iteración del bucle for-each, la variable del bucle recibe una COPIA del valor contenido en la celda del array. Modificar la variable local no modifica el array original:

Código Java
JAVA 
int[] notas = {4, 5, 3};

// ❌ INTENTO FALLIDO: Intentar modificar el array con for-each
for (int n : notas) {
    n = n + 1; // ¡Solo modifica la variable local 'n'! NO altera el array.
}
// El array 'notas' sigue siendo {4, 5, 3}

// ✅ FORMA CORRECTA: Si necesitas modificar celdas, usa el 'for' con índice:
for (int i = 0; i < notas.length; i++) {
    notas[i] = notas[i] + 1; // Acceso directo a la celda de memoria
}
// Ahora el array 'notas' sí es {5, 6, 4}

🔗 Conexión pedagógica con las Estructuras Dinámicas (Tema 3.5)

El bucle for-each cobra todavía mayor relevancia cuando se estudian las colecciones dinámicas (como ArrayList, HashSet o LinkedList en el Tema 3.5). La misma sintaxis que acabamos de ver para arrays estáticos funciona de idéntica manera para cualquier colección de Java gracias a la interfaz Iterable.

b) Problemas de búsqueda en arrays

Se denominan problemas de búsqueda a aquellos que determinan si existe algún elemento que cumpla cierta propiedad dentro del array. A diferencia del recorrido completo, en la búsqueda no siempre es necesario examinar todo el array: el elemento puede hallarse en la primera posición, en medio, o no existir.

1. Búsqueda ascendente (Búsqueda secuencial)

Iniciamos en el índice 0 y avanzamos hasta encontrar la coincidencia o agotar el array:

Ejemplo: Primer día sin lluvia

Código Java
JAVA 
// Devolvemos el subíndice del primer componente cuyo valor sea cero
// Si ningún día fue cero, devolvemos -1
public static int primerDiaSinLluvia(double lluvia[]) {
    int i = 0;
    boolean encontrado = false;

    while (i < lluvia.length && !encontrado) {
        if (lluvia[i] == 0) {
            encontrado = true;
        } else {
            i++;
        }
    }

    if (encontrado) {
        return i;
    } else {
        return -1;
    }
}

2. Búsqueda descendente

Partimos de la última posición (array.length - 1) y retrocedemos hacia la posición 0:

Ejemplo: Último día sin lluvia

Código Java
JAVA 
public static int ultimoDiaSinLluvia(double lluvia[]) {
    int i = lluvia.length - 1;
    boolean encontrado = false;

    while (i >= 0 && !encontrado) {
        if (lluvia[i] == 0) {
            encontrado = true;
        } else {
            i--;
        }
    }

    if (encontrado) {
        return i;
    } else {
        return -1;
    }
}

3. Búsqueda binaria o dicotómica (Arrays Ordenados)

Si el array ya se encuentra previamente ordenado, la búsqueda secuencial elemento a elemento resulta ineficiente. La búsqueda binaria divide el espacio de búsqueda a la mitad en cada paso, logrando una eficiencia de O(log₂ N) (en un array de 1.000.000 de elementos, requiere un máximo de 20 comparaciones en lugar de un millón).

Ejemplo: Búsqueda binaria de edades

Código Java
JAVA 
public static boolean hayAlguienDe36(int edad[]) {
    // 'izq' y 'der' acotan el subintervalo de búsqueda
    int izq = 0;
    int der = edad.length - 1;
    boolean encontrado = false;

    while (izq <= der && !encontrado) {
        int m = (izq + der) / 2; // Posición central
        if (edad[m] == 36) {
            encontrado = true; // ¡Encontrado!
        } else if (edad[m] > 36) {
            der = m - 1;       // Buscar en la mitad izquierda
        } else {
            izq = m + 1;       // Buscar en la mitad derecha
        }
    }

    return encontrado;
}

c) Problemas de ordenación en arrays

Permiten reorganizar los datos de menor a mayor o viceversa. Se dividen en algoritmos iterativos (burbuja, selección directa, inserción) y algoritmos recursivos divide y vencerás (mergeSort, quickSort).

Método de Selección Directa (Selection Sort)

En cada iteración i, busca el elemento menor que queda a la derecha e intercambia posiciones:

Código Java
JAVA 
public static void seleccionDirecta(int v[]) {
    for (int i = 0; i < v.length - 1; i++) {
        // Localizamos el elemento mínimo que debe ocupar la posición i
        int posMin = i;
        for (int j = i + 1; j < v.length; j++) {
            if (v[j] < v[posMin]) {
                posMin = j;
            }
        }
        // Intercambio de valores (swap)
        int aux = v[posMin];
        v[posMin] = v[i];
        v[i] = aux;
    }
}
