# 3.2.4 La classe java.util.Arrays

La llibreria `Arrays` en Java pertany al paquet `java.util` i proporciona un conjunt de mètodes estátics dissenyats per a facilitar el treball amb arrays. Aquesta classe permet realitzar operacions comuns de forma eficient, com ordenar, cercar, emplenar i comparar arrays, així com convertirlos en representacions de text. 

**Gràcies a Arrays, moltes tasques que abans requerían bucles i lògica addicional es poden realitzar de manera més directa i clara.**

A més, `Arrays` ofereix suport per a la manipulació d'arrays multidimensionals, permetent treballar amb matrius complexes de forma més senzilla i segura. El seu ús contribuye a que el codi siga més llegible i menys propenso a errors, convirtiéndose en una eina fonamental per a qualsevol programador que necesite manejar col·leccions de dades lineals o tabulars en Java.

Algunes de les funcions més útils són: 

## a) toString

Converteix un array en una representació de cadena llegible.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploToString {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4};
        System.out.println(Arrays.toString(numeros));
    }
}
```

#### 📌 Eixida

```java
[1, 2, 3, 4]
```

## b) sort

Ordena els elements d'un array en ordre ascendent.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploSort {
    public static void main(String[] args) {
        int[] numeros = {4, 2, 1, 3};
        Arrays.sort(numeros);
        System.out.println(Arrays.toString(numeros));
    }
}
```

#### 📌 Eixida

```java
[1, 2, 3, 4]
```

## c) equals

Comprova si dos arrays són iguals element per element.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploEquals {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = {1, 2, 3};
        System.out.println(Arrays.equals(a, b));
    }
}
```

#### 📌 Eixida

```java
true
```

## d) binarySearch

Cerca un element en un array ordenat i retorna el seu índex.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploBinarySearch {
    public static void main(String[] args) {
        int[] numeros = {1, 3, 5, 7, 9};
        int indice = Arrays.binarySearch(numeros, 5);
        System.out.println(indice);
    }
}
```

#### 📌 Eixida

```java
2
```

## e) fill

Emplena un array complet o un rang amb un valor específic.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploFill {
    public static void main(String[] args) {
        int[] numeros = new int[5];
        Arrays.fill(numeros, 7);
        System.out.println(Arrays.toString(numeros));
    }
}
```

#### 📌 Eixida

```java
[7, 7, 7, 7, 7]
```

## f) copyOf

Còpia un array en un altre array de mida determinat.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploCopyOf {
    public static void main(String[] args) {
        int[] original = {1, 2, 3};
        int[] copia = Arrays.copyOf(original, 5);
        System.out.println(Arrays.toString(copia));
    }
}
```

#### 📌 Eixida

```java
[1, 2, 3, 0, 0]
```

## d) copyOfRange

Còpia un rang d'elements d'un array en un nou array.

#### 📌 Java

```java
import java.util.Arrays;

public class EjemploCopyOfRange {
    public static void main(String[] args) {
        int[] original = {1, 2, 3, 4, 5};
        int[] rango = Arrays.copyOfRange(original, 1, 4); // de la posición 1 a la 3
        System.out.println(Arrays.toString(rango));
    }
}
```

#### 📌 Eixida

```java
[2, 3, 4]
```

> **📌 Paràmetres de la funció**
> 

> En `copyOfRange`, els números indiquen el rang de posicions de l'array que es vol copiar.

```java
Arrays.copyOfRange(array, desde, hasta);
```

> - `desde` → índex inicial inclòs

> - `hasta` → índex final excluido (no es còpia).

> Llavors, es copian els números:

```java
desde ≤ índice < hasta
```
