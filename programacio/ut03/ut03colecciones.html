1. De Arrays Estáticos a Estructuras Dinámicas

Hasta ahora, para almacenar secuencias de elementos hemos utilizado arrays tradicionales (ej. int[] numeros = new int[5];). Aunque son ultrarrápidos y eficientes en memoria, presentan tres limitaciones críticas en aplicaciones reales:

  1. Tamaño fijo e inmutable: La capacidad se fija al instanciar y no puede alterarse. Si se llena, hay que reservar un array nuevo más grande y copiar los elementos a mano uno a uno.
  2. Sin operaciones de alto nivel incorporadas: Insertar en una posición intermedia, eliminar compactando el hueco o buscar sin un bucle manual exige escribir algoritmos auxiliares.
  3. Desperdicio o escasez de memoria: Sobredimensionar ("por si acaso") malgasta memoria; quedarse corto provoca errores de desbordamiento de índice (ArrayIndexOutOfBoundsException).

Para solucionar esto, Java incorpora en su paquete estándar java.util el Java Collections Framework (JCF): un ecosistema unificado de interfaces, clases e implementaciones de estructuras dinámicas de datos que redimensionan automáticamente su espacio en la memoria dinámica (Heap) según las necesidades del programa.

⚠️ Colecciones y Tipos Primitivos: ¡Uso obligatorio de Wrappers!

Las colecciones de Java solo pueden almacenar objetos, nunca tipos primitivos directos. Gracias al Autoboxing, utilizamos sus clases envoltorio (Wrappers):

Código Java
JAVA 
// ❌ Error de compilación: los genéricos no admiten primitivos
// List<int> lista = new ArrayList<int>();

// ✅ Correcto (usando clase envoltorio Integer):
List<Integer> lista = new ArrayList<>();
lista.add(10); // Autoboxing automático: de int a Integer

💡 Regla de oro de arquitectura: Polimorfismo de Interfaces

Declara siempre las variables con el tipo de la interfaz más general (List, Set, Map) e instancia con la clase concreta (ArrayList, HashSet, HashMap). De este modo tu código desacopla el diseño de la implementación interna:

Código Java
JAVA 
// ✅ Práctica recomendada por Clean Code (Polimorfismo de Interfaces):
List<String> alumnos = new ArrayList<>();
Set<String> codigos = new HashSet<>();
Map<String, Double> notas = new HashMap<>();

// ⚠️ Desaconsejado (acoplamiento rígido a la clase concreta):
ArrayList<String> alumnosMal = new ArrayList<>();

3. Listas (List): Elementos Ordenados y Duplicados

Una Lista (List<E>) representa una secuencia indexada de elementos:

  • Características: Permite elementos repetidos (duplicados), mantiene el orden de inserción y permite acceso por índice numérico posicional base 0.

3.1. Comparativa técnica: ArrayList vs LinkedList

Característica ArrayList LinkedList
Estructura interna Array dinámico redimensionable internamente. Nodos doblemente enlazados en memoria.
Acceso aleatorio (get(i)) ⚡ Ultrarrápido O(1) por puntero directo. 🐢 Lento O(n), recorre nodo a nodo.
Inserción/Borrado al final ⚡ Rápido O(1) amortizado. ⚡ Rápido O(1).
Inserción/Borrado al inicio/medio 🐢 Lento O(n) (desplaza todos los elementos). ⚡ Rápido O(1) (reconecta enlaces de nodos).
Recomendación estándar Uso por defecto en el 95% de aplicaciones. Ideal para colas, pilas o inserciones masivas continuas.

3.2. Métodos fundamentales de List en acción

Código Java
JAVA 
package ut3.colecciones;

import java.util.ArrayList;
import java.util.List;

public class EjemploListas {
    public static void main(String[] args) {
        List<String> lenguajes = new ArrayList<>();

        // 1. Inserción (al final o en posición específica)
        lenguajes.add("Java");
        lenguajes.add("Python");
        lenguajes.add("JavaScript");
        lenguajes.add(1, "TypeScript"); // Inserta en posición 1 desplazando el resto

        // 2. Consulta y tamaño
        System.out.println("Total elementos: " + lenguajes.size()); // 4
        System.out.println("Elemento en índice 0: " + lenguajes.get(0)); // Java
        System.out.println("¿Contiene Python?: " + lenguajes.contains("Python")); // true
        System.out.println("Posición de Java: " + lenguajes.indexOf("Java")); // 0

        // 3. Modificación
        lenguajes.set(2, "Kotlin"); // Sustituye el valor del índice 2

        // 4. Eliminación (por índice o por objeto exacto)
        lenguajes.remove(0); // Elimina por índice
        lenguajes.remove("Python"); // Elimina por coincidencia de objeto

        // 5. Estado y vaciado
        System.out.println("¿Lista vacía?: " + lenguajes.isEmpty());
        lenguajes.clear(); // Elimina todos los elementos
    }
}

4. Pilas (Stacks - LIFO) y Colas (Queues - FIFO)

Son estructuras restringidas diseñadas para modelar flujos de trabajo secuenciales en la lógica de negocio:

PILA (LIFO: Last In, First Out) 
   |             |
   |   Dato 3    |  <-- Cima (push / pop)
   |   Dato 2    |
   |   Dato 1    |
   +-------------+
(El último en entrar sale primero: Deshacer / Undo)
COLA (FIFO: First In, First Out) 
Entrada --> [ C | B | A ] --> Salida
                          
(El primero en entrar es el primero en ser atendido:
turnos de clientes, cola de impresión, buffers)

4.1. Pilas: LIFO (Last In, First Out)

⚠️ Aviso sobre la clase obsoleta java.util.Stack

Aunque Java incluye históricamente la clase Stack, es una clase legacy desaconsejada. La propia documentación oficial de Oracle recomienda utilizar la interfaz moderna Deque implementada mediante ArrayDeque:

Código Java
JAVA 
package ut3.colecciones;

import java.util.ArrayDeque;
import java.util.Deque;

public class EjemploPila {
    public static void main(String[] args) {
        // Uso recomendado oficial de Oracle: Deque implementado por ArrayDeque
        Deque<String> pilaNavegacion = new ArrayDeque<>();

        // Apilar elementos en la cima (push)
        pilaNavegacion.push("https://iesramonesteve.es");
        pilaNavegacion.push("https://aules.edu.gva.es");
        pilaNavegacion.push("https://github.com");

        // Consultar cima sin extraer (peek)
        System.out.println("Página actual: " + pilaNavegacion.peek()); // github.com

        // Desapilar al pulsar botón 'Atrás' (pop)
        System.out.println("Cerrando: " + pilaNavegacion.pop()); // Extrae github.com
        System.out.println("Regresando a: " + pilaNavegacion.peek()); // aules.edu.gva.es
    }
}

4.2. Colas: FIFO (First In, First Out)

En Java se utiliza la interfaz Queue implementada habitualmente con LinkedList o ArrayDeque:

Código Java
JAVA 
package ut3.colecciones;

import java.util.LinkedList;
import java.util.Queue;

public class EjemploCola {
    public static void main(String[] args) {
        Queue<String> colaAtencion = new LinkedList<>();

        // 1. Encolar clientes al final (offer)
        colaAtencion.offer("Cliente 1: Ana Asins");
        colaAtencion.offer("Cliente 2: Bernat Gómez");
        colaAtencion.offer("Cliente 3: Carla Navarro");

        // 2. Consultar el siguiente sin retirarlo
        System.out.println("Siguiente en turno: " + colaAtencion.peek());

        // 3. Desencolar por orden estricto de llegada (poll)
        while (!colaAtencion.isEmpty()) {
            String atendido = colaAtencion.poll();
            System.out.println("-> Atendiendo en ventanilla a: " + atendido);
        }
    }
}

4.3. Comparativa de métodos: Pila vs Cola

Operación Método en Pila (Deque) Método en Cola (Queue) Comportamiento si está vacía
Insertar push(e) offer(e) Añade el elemento a la estructura.
Extraer pop() poll() pop() lanza excepción; poll() devuelve null.
Consultar peek() peek() Devuelve el elemento cima/frontal sin retirarlo.

5. Conjuntos (Set): Elementos Únicos sin Duplicados

Un Conjunto (Set<E>) es una colección que garantiza matemáticamente la no repetición de elementos. Si intentas insertar un elemento duplicado con .add(), Java devolverá false y no modificará el conjunto.

5.1. Implementaciones principales de Set

Implementación Ordenación de los elementos Rendimiento Caso de uso típico
HashSet Sin orden garantizado (usa tabla Hash interna). ⚡ O(1) Ultrarrápido Eliminar duplicados donde el orden no importe.
LinkedHashSet Mantiene el orden de inserción exacto. ⚡ O(1) Rápido Eliminar duplicados respetando el orden en que llegaron.
TreeSet Ordenados automáticamente (alfabético/numérico) o por Comparator. ⚖️ O(log n) Equilibrado Listas de valores únicos siempre ordenados automáticamente.

5.2. Eliminación de duplicados y ordenación alfabética

Código Java
JAVA 
package ut3.colecciones;

import java.util.*;

public class EjemploSets {
    public static void main(String[] args) {
        List<String> ciudadesConDuplicados = List.of(
            "Valencia", "Alicante", "Castellón", "Valencia", "Alicante"
        );

        // 1. Eliminar duplicados instantáneamente con HashSet (sin orden fijo):
        Set<String> unicas = new HashSet<>(ciudadesConDuplicados);
        System.out.println("HashSet (sin duplicados): " + unicas);

        // 2. TreeSet: sin duplicados y ordenados alfabéticamente de forma automática:
        Set<String> ordenadas = new TreeSet<>(ciudadesConDuplicados);
        System.out.println("TreeSet (alfabético): " + ordenadas);
        // Salida: [Alicante, Castellón, Valencia]
    }
}

5.3. Operaciones matemáticas de conjuntos (Álgebra de conjuntos)

Los métodos de Set permiten resolver operaciones complejas de conjuntos en una sola instrucción:

Código Java
JAVA 
Set<Integer> conjuntoA = new HashSet<>(Set.of(1, 2, 3, 4));
Set<Integer> conjuntoB = new HashSet<>(Set.of(3, 4, 5, 6));

// 1. UNIÓN (A ∪ B)
Set<Integer> union = new HashSet<>(conjuntoA);
union.addAll(conjuntoB); // [1, 2, 3, 4, 5, 6]

// 2. INTERSECCIÓN (A ∩ B)
Set<Integer> interseccion = new HashSet<>(conjuntoA);
interseccion.retainAll(conjuntoB); // [3, 4]

// 3. DIFERENCIA (A - B)
Set<Integer> diferencia = new HashSet<>(conjuntoA);
diferencia.removeAll(conjuntoB); // [1, 2]

6. Mapas / Diccionarios (Map): Estructura Clave-Valor

Un Mapa (Map<K, V>) asocia parejas de datos formadas por una clave única (Key) y un valor asociado (Value):

  • Las claves no pueden duplicarse. Si insertas una clave ya existente mediante put(), se sobrescribe su valor anterior.
  • Los valores sí pueden repetirse.

6.1. Implementaciones de Map

  • HashMap: La opción estándar de máxima velocidad (tiempo constante O(1)). No garantiza ningún orden en las claves.
  • LinkedHashMap: Recuerda el orden de inserción de las parejas.
  • TreeMap: Mantiene las claves permanentemente ordenadas por su orden natural o Comparator (tiempo O(log n)).

6.2. Métodos esenciales de Map

Código Java
JAVA 
package ut3.colecciones;

import java.util.HashMap;
import java.util.Map;

public class EjemploMap {
    public static void main(String[] args) {
        // Clave: DNI (String) -> Valor: Nombre de alumno (String)
        Map<String, String> usuarios = new HashMap<>();

        // 1. Insertar o actualizar (put)
        usuarios.put("12345678A", "Laura Martínez");
        usuarios.put("87654321B", "Marc Esteve");
        usuarios.put("11223344C", "Nuria Soler");

        // Si repetimos la clave, se actualiza el valor asociado:
        usuarios.put("12345678A", "Laura Martínez Gómez");

        // 2. Obtener un valor por clave (get)
        System.out.println("Usuario con DNI 87654321B: " + usuarios.get("87654321B"));

        // 3. Obtener con valor por defecto si no existe (getOrDefault)
        String resultado = usuarios.getOrDefault("99999999Z", "Usuario no registrado");
        System.out.println("Búsqueda DNI 99999999Z: " + resultado);

        // 4. Comprobaciones de existencia rápidas O(1)
        System.out.println("¿Existe el DNI 11223344C?: " + usuarios.containsKey("11223344C")); // true
        System.out.println("¿Existe el nombre Marc?: " + usuarios.containsValue("Marc Esteve")); // true

        // 5. Eliminar por clave
        usuarios.remove("11223344C");
        System.out.println("Total usuarios activos: " + usuarios.size());
    }
}

7. Formas Profesionales de Recorrer Colecciones (Iteración)

7.1. Bucle for-each (Recomendado para solo lectura)

Sintaxis limpia y directa cuando solo queremos consultar elementos sin alterar la colección:

List<String> frutas = List.of("Manzana", "Plátano", "Naranja");
for (String fruta : frutas) {
    System.out.println("Fruta: " + fruta);
}

7.2. El peligro del for-each: ConcurrentModificationException

💥 ¡Regla de oro: NUNCA elimines elementos de una lista dentro de su propio bucle for-each!

El siguiente código compila perfectamente, pero fallará críticamente en ejecución:

Código Java
JAVA 
List<String> frutas = new ArrayList<>(List.of("Manzana", "Plátano", "Naranja"));

// ❌ ERROR CRÍTICO EN EJECUCIÓN: Lanza ConcurrentModificationException
for (String fruta : frutas) {
    if (fruta.equals("Plátano")) {
        frutas.remove(fruta); // ¡FALLO! Modificar la lista durante su propia iteración
    }
}

7.3. La solución segura: Iterator o removeIf()

Para eliminar elementos de manera segura durante el recorrido disponemos de dos vías estándar:

Código Java
JAVA 
// ✅ Opción 1: Con Iterator (Clásica y universal en todas las versiones de Java)
Iterator<String> it = frutas.iterator();
while (it.hasNext()) {
    String fruta = it.next();
    if (fruta.equals("Plátano")) {
        it.remove(); // Seguro: el iterador actualiza su puntero interno
    }
}

// ✅ Opción 2: Con removeIf y expresión Lambda (Moderna y recomendada desde Java 8)
frutas.removeIf(fruta -> fruta.equals("Plátano"));

7.4. Cómo recorrer un Map (Claves, Valores y Parejas)

Un Map no implementa Iterable de forma directa, por lo que se itera a través de sus vistas de colección:

Código Java
JAVA 
Map<String, Double> precios = Map.of("Pan", 1.20, "Leche", 0.95, "Café", 2.50);

// Forma 1 (La más eficiente): Recorrer parejas Clave - Valor con entrySet()
for (Map.Entry<String, Double> entrada : precios.entrySet()) {
    System.out.println("Producto: " + entrada.getKey() + " -> " + entrada.getValue() + " €");
}

// Forma 2: Con forEach y expresión Lambda concisa
precios.forEach((producto, precio) -> {
    System.out.printf("%-10s : %5.2f €%n", producto, precio);
});

9. Casos Prácticos Completos y Resueltos

Caso Práctico 1: Simulación de Cola de Soporte (FIFO) y Pila de Deshacer (LIFO)

Código Java
JAVA 
package ut3.practicas;

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.LinkedList;
import java.util.Queue;

public class GestionSoporteTecnico {
    public static void main(String[] args) {
        // COLA (FIFO): Los tickets se atienden en riguroso orden de llegada
        Queue<String> colaTickets = new LinkedList<>();
        colaTickets.offer("Ticket #101: Fallo al iniciar sesión");
        colaTickets.offer("Ticket #102: Error 404 en el checkout");
        colaTickets.offer("Ticket #103: Olvido de contraseña");

        // PILA (LIFO): Historial de acciones realizadas para permitir 'Deshacer'
        Deque<String> historialAcciones = new ArrayDeque<>();

        System.out.println("=== ATENDIENDO TICKETS (COLA FIFO) ===");
        while (!colaTickets.isEmpty()) {
            String ticketActual = colaTickets.poll();
            System.out.println("-> Procesando: " + ticketActual);
            historialAcciones.push("Atendido " + ticketActual);
        }

        System.out.println("\n=== HISTORIAL DE ACCIONES PARA DESHACER (PILA LIFO) ===");
        while (!historialAcciones.isEmpty()) {
            System.out.println("<- Deshaciendo última acción: " + historialAcciones.pop());
        }
    }
}

Caso Práctico 2: Contador de Frecuencia de Palabras con Map y Set

Código Java
JAVA 
package ut3.practicas;

import java.util.*;

public class AnalizadorTextoWeb {
    public static void main(String[] args) {
        String texto = "java es genial y aprender java es divertido con programacion en java";

        // 1. Separamos palabras con expresión regular (espacios en blanco)
        String[] palabras = texto.toLowerCase().split("\\s+");

        // 2. Usamos un Map para contabilizar frecuencias
        Map<String, Integer> frecuencias = new HashMap<>();
        for (String p : palabras) {
            frecuencias.put(p, frecuencias.getOrDefault(p, 0) + 1);
        }

        // 3. Mostramos palabras ordenadas alfabéticamente usando un TreeMap
        Map<String, Integer> frecuenciasOrdenadas = new TreeMap<>(frecuencias);

        System.out.println("=== FRECUENCIA DE PALABRAS ===");
        System.out.printf("%-15s : %s%n", "PALABRA", "APARICIONES");
        System.out.println("---------------------------------");
        for (Map.Entry<String, Integer> entry : frecuenciasOrdenadas.entrySet()) {
            System.out.printf("%-15s : %d veces%n", entry.getKey(), entry.getValue());
        }

        // 4. Mostrar vocabulario único sin duplicados usando un Set
        Set<String> palabrasUnicas = new TreeSet<>(Arrays.asList(palabras));
        System.out.println("\nTotal de palabras únicas: " + palabrasUnicas.size());
        System.out.println("Vocabulario: " + palabrasUnicas);
    }
}
