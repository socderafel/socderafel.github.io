## 1. Errors de Compilació vs Temps de Ejecució (*Runtime Exceptions*)

A l'hora de programar en Java, ens enfrentamos a dos naturalezas d'errors radicalment distintes:

  
1. **Errors de compilació (sintaxi):** Són detectats pel compilador (`javac`) abans de que el programa arribe a executar-se (ej: falta un punt i coma `;`, una variable no declarada o un error tipográfic en una paraula clau). Visual Studio Code els subraya en roig inmediatament.
  
1. **Errors en temps d'ejecució (Excepcions o *Runtime Exceptions*):** El programa compila a la perfecció sense cap error sintáctic, però **durant l'ejecució real** ocorre un esdeveniment imprevisto (ej: l'usuari escriu `"hola"` quan `Scanner` esperava un número, o intentem dividir entre zero `10 / 0`). Si no es controlen, la Màquina Virtual de Java (JVM) aborta el programa bruscament i mostra una traça d'error en la consola.

## 2. La Vía Recomanada en Bucles: Validació Preventiva amb `Scanner` (*Clean Code*)

> **📌 💡 Regla de Oro de la Industria: *«Exceptions should be exceptional»***
> 

> **Mai utilices excepcions per a controlar el flux normal i habitual d'un programa.** Que un usuari es equivoque al teclear en la consola no és una catástrofe de programari excepcional; és una situació perfectament previsible.

> Per això, en aquest bloc de **Estructures de control i Bucles**, la forma més limpia, eficient i elegante de validar dades és la **validació preventiva** mitjançant els mètodes d'inspecció de la classe `Scanner` i bucles `while`.

### 2.1. Mètodes d'inspecció de `Scanner`

  
- `sc.hasNextInt()`: Retorna `true` si l'usuari ha introduït un número enter vàlid.
  
- `sc.hasNextDouble()`: Retorna `true` si ha introduït un número decimal vàlid.
  
- `sc.hasNextBoolean()`: Retorna `true` si ha introduït `"true"` o `"false"`.

### 2.2. El patró estàndard de validació amb bucle `while`

```java
package ut2.validacion;

import java.util.Scanner;

public class ValidacionPreventiva {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int edad = 0;

        System.out.print("Introduce tu edad (número entero positivo): ");

        // 1. Mientras lo que haya en el buffer NO sea un entero, avisamos y descartamos:
        while (!sc.hasNextInt()) {
            System.out.println("⚠️ Error: Debes escribir un número entero, no texto ni símbolos.");
            sc.next(); // ⚠️ Crucial: descartar la entrada incorrecta para vaciar el buffer
            System.out.print("Prueba otra vez: ");
        }

        // 2. Cuando llegamos aquí, la entrada es un entero válido 100% garantizado:
        edad = sc.nextInt();

        // 3. Validación de rango lógico con condicionales normales:
        if (edad >= 18 && edad <= 120) {
            System.out.println("✅ Acceso concedido. Tienes " + edad + " años.");
        } else if (edad < 18 && edad >= 0) {
            System.out.println("🚫 Acceso denegado: Eres menor de edad (" + edad + " años).");
        } else {
            System.out.println("❌ Error: La edad introducida no es biológicamente válida.");
        }

        sc.close();
    }
}
```

> **📌 ⚠️ Cura amb el vaciado del buffer de Scanner!**
> 

> Dins del cos del `while (!sc.hasNextInt())` és **estrictament obligatori** incloure `sc.next();` o `sc.nextLine();`. Si l'olvides, el dada incorrecte es queda atascado en el buffer del teclat i el bucle es convertirá en un **bucle infinit**.

## 3. Introducció Defensiva a `try-catch-finally`

Malgrat la validació preventiva, existeixen situacions on certes operacions no poden verificar-se prèviament amb un simple `if`, o on una conversió de text a número pot fallar. Per a aquests casos, Java proporciona l'estructura **`try-catch-finally`**:

```java
try {
    // Bloque protegido: código que podría provocar un fallo imprevisto
} catch (TipoDeExcepcion e) {
    // Bloque de rescate: código que se ejecuta solo si ocurre ese error específico
} finally {
    // Bloque opcional: se ejecuta SIEMPRE (haya o no haya habido error)
}
```

## 5. ✍️ Exercicis Pràctics de la Unitat (UT2)

> **📌 Exercici 1: Calculadora de Divisions Segura (`CalculadoraDivisionSegura.java`)**
> 

> Desenvolupa una aplicació de consola especialitzada en divisions enteras:

  
> 1. Solicita a l'usuari per teclat dos números enters: el **dividendo** i el **divisor**.
  
> 1. Implementa la divisió en un mètode independent: `public static int dividir(int a, int b) throws ArithmeticException`.
  
> 1. Gestiona de forma diferenciada:
    

      
>   - La divisió per zero (`ArithmeticException`).
      
>   - La introducció de lletres o símbols (`InputMismatchException`).
    

  
  
> 1. Utilitza un bloc `finally` per a assegurar el tancament del `Scanner` i emitir un missatge de tancament d'operació.

```java
package ut2.actividades;

import java.util.InputMismatchException;
import java.util.Scanner;

public class CalculadoraDivisionSegura {
    public static int dividir(int dividendo, int divisor) throws ArithmeticException {
        return dividendo / divisor;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        try {
            System.out.print("Introduce el dividendo (entero): ");
            int dividendo = sc.nextInt();

            System.out.print("Introduce el divisor (entero): ");
            int divisor = sc.nextInt();

            int cociente = dividir(dividendo, divisor);
            System.out.println("✅ Resultado de la división entera: " + cociente);
        } catch (ArithmeticException e) {
            System.err.println("⚠️ Error aritmético: Indeterminación matemática (no se puede dividir por 0).");
        } catch (InputMismatchException e) {
            System.err.println("⚠️ Error de formato: Has introducido letras o símbolos en lugar de números.");
        } finally {
            sc.close();
            System.out.println("🔒 Operación finalizada.");
        }
    }
}
```

> **📌 Exercici 2: Conversor de Preus amb Auditoría de Seguretat (`ConversorPreciosSeguro.java`)**
> 

> Desenvolupa un sistema capaç de convertir preus introduïts com text:

  
> 1. L'usuari introdueix el preu d'un producte en format text (ej: `"24.95"`).
  
> 1. Intenta convertir-lo a número decimal amb `Double.parseDouble()`.
  
> 1. Captura l'excepció `NumberFormatException` si l'usuari introdueix comes `,` o lletres, mantenint en tal cas l'últim preu vàlid registrat.
  
> 1. Utilitza obligatòriament un bloc `finally` per a emitir el missatge de registre d'auditoría.

```java
package ut2.actividades;

import java.util.Scanner;

public class ConversorPreciosSeguro {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double ultimoPrecioValido = 0.0;

        System.out.print("Introduce el precio del producto (ej. 24.95): ");
        String texto = sc.nextLine();

        try {
            double precio = Double.parseDouble(texto);
            if (precio <= 0) {
                System.out.println("⚠️ Aviso: El precio debería ser mayor que cero.");
            } else {
                ultimoPrecioValido = precio;
                System.out.printf("✅ Precio registrado correctamente: %.2f €%n", ultimoPrecioValido);
            }
        } catch (NumberFormatException e) {
            System.err.println("⚠️ Error: '" + texto + "' no tiene formato decimal válido (usa el punto '.' para decimales).");
            System.out.println("   Se mantendrá el último precio válido: " + ultimoPrecioValido + " €");
        } finally {
            System.out.println("📋 Auditoría: Registro de conversión de precio completado.");
            sc.close();
        }
    }
}
```
