# 0.5 GitHub Desktop

## 1. GitHub Desktop

**GitHub Desktop** és una aplicació gratuïta de codi obert que ajuda a treballar amb codi hospedado en GitHub o altres serveis d'hospedatge de *Git*. Amb *GitHub Desktop*, pots realitzar comandes de *Git*, com confirmar i inserir canvis, en una interfície gràfica d'usuari, en lloc de mitjançant la línia de comandes. 

Més informació en [Sobre GitHub d'escriptori](https://docs.github.com/es/desktop/installing-and-configuring-github-desktop/overview/about-github-desktop).

    

![github desktop](../img/img_ut00_githubdesktop.png)

### 1.1. Instal·lació GitHub Desktop

Descarrega de la pàgina oficial de [GitHub Desktop](https://desktop.github.com/). 

Descarrega l'instalable en funció del sistema operatiu en el que estés.

    

![github desktop](../img/img_ut00_githubdesktop2.png)

### 1.2. Inici de sessió

Després de la instal·lació pots iniciar sessió amb la teua compta de GitHub. Per a això, primer es et redirigirá a la pàgina web oficial de GitHub, on podràs introduir les teues dades d'accés. 

Seguidament, has de **autoritzar GitHub Desktop** perquè l'aplicació acceda mitjançant la teua compta i als teus repositorios. Per a això, fes clic en el botó “*Authorize desktop*”.

Una vegada es et haja redirigido a *GitHub Desktop*, pots completar el procés d'inici de sessió introducent un nom de compta i una adreça de correu electrònic o transfirent les dades corresponents des de la teua compta de GitHub. Al fer clic en el botó “*Finish*”, accederás a la interfície d'usuari de *GitHub Desktop*.

Ara podem clonar el nostre repositorio de *GitHub* en un local:

    

![github desktop](../img/img_ut00_githubdesktop3.png)

    

![github desktop](../img/img_ut00_githubdesktop4.png)

Elegimos, del nostre repositorios remotos en *GitHub*, el que volem clonar; i pulsamos "*Clone*":

    

![github desktop](../img/img_ut00_githubdesktop5.png)

Quan estiga clonado el nostre repositorio (*punt 1*) podrem observar si existeixen modificacions a *pujar* al nostre repositorio remoto (*punt 2*). Si és així, posem un nom al nostre *commit* (*punt 3*) i pulsamos "*Commit to master*" (*punt 4*). En aquest moment tenim el *commit* realitzat en el nostre repositorio local; listo per a actualitzar al repositorio remoto en *GitHub*. 

    

![github desktop](../img/img_ut00_githubdesktop6.png)

Per a pujar aquest(us) *commits* a remoto, pulsarem el botó "*Publish branch*", i el canvi estarà listo en el repositorio de *GitHub*:

    

![github desktop](../img/img_ut00_githubdesktop7.png)
