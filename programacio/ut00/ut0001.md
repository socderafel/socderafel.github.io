# 0.1 Introducció

Bienvenits al curs de **Programació** **PRG** del *Cicle Formativo Superior de Desenvolupament de Aplicacions Web* **DAW**.

Abans d'entrar en materia, seria convenient i interessant introduir *un parell* de conceptes per a realitzar el nostre treball en classe i en casa de forma més organitzada.

Aquesta primera unitat estarà dedicada a aquest menester. En ella, comentarem, a mode "*manual de supervivencia*", conceptes com: 

| PROGRAMARI |  |  |
| --- | --- | --- |
| **Git** | ![git](../img/img_ut00_git.png) | Sistema de control de versions |
| **Github** | ![github](../img/img_ut00_github.png) | Plataforma web per a allotjar i compartir projectes de programari i codi font |
| **Github Desktop ** | ![githubdesktop](../img/img_ut00_githubdesktop.png) | Aplicació gratuïta en que es pot realitzar comandes de Git, com confirmar i inserir canvis, en una interfície gràfica d'usuari, en lloc de mitjançant la línia de comandes |
| **Visual Studio Code** | ![vscode](../img/img_ut00_vscode.png) | Editor de codi font desenvolupat per *Microsoft* |
| **Antigravity** | ![antigravity](../img/img_ut00_antigravity.png) | Editor de codi font desenvolupat per *Google* |
