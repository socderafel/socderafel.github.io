# ☕ Programació (Java)

Apunts, exemples de codi i exercicis del mòdul de **Programació** en llenguatge Java per a **1r DAW / 1r DAM**.

---

## 📑 Índex d'Unitats de Treball

1. **[UT1 - Introducció a Java, Tipus de Dades i E/S per Consola (`printf`)](./ut1-java-basic.md)**
   * Estructura d'un projecte en VSCode, paquets, variables primitives, operadors i format d'eixida tabulat amb `System.out.printf`.
2. **[Temari Complet UD1 a UD12 — Programació Java (1r DAW/DAM)](../biblioteca-cicles/03_DAW_DAM/1daw-dam-prg-programacio-java.md)**
   * Desglossament complet de les 12 Unitats Didàctiques (Introducció, E/S, Estructures de Control, Programació Modular, Arrays i Estructures Estàtiques, Col·leccions Dinàmiques, POO I i II, Excepcions, Fitxers, Bases de Dades JDBC, Interfícies Gràfiques, Projecte Integrador i reptes de *ProgramaMe / JO-EL*).
3. **[Mòdul Complementari — Entorns de Desenvolupament (IDEs, Git, Testing i UML)](../biblioteca-cicles/03_DAW_DAM/1daw-dam-ed-entorns-desenvolupament.md)**
   * Configuració d'IDEs, control de versions amb Git, depuració, proves unitàries i diagrames de classes.

## ⚠️ Criteris Generals de Correcció de Codi

| Criteri | Pes | Descripció |
| :--- | :---: | :--- |
| **1. Funcionament i Lògica** | **4 pts** | El programa resol el problema sense errors d'execució. |
| **2. Tipus de Dades i Operadors** | **2 pts** | Ús òptim de tipus primitius i operadors lògics/aritmètics. |
| **3. Convencions i Neteja** | **2 pts** | Classes en `PascalCase`, variables en `camelCase` i bona indentació. |
| **4. Entrada / Eixida (E/S)** | **2 pts** | Missatges clars i eixida tabulada amb `printf`. |

> **Nota important:** Si el codi `.java` no compila per errors de sintaxi, la puntuació de l'apartat de funcionament serà **0**.
