A sistemes operatius Linux, **Postfix** és el servidor de transport de correu (**MTA**) més respectat del món per la seua arquitectura modular basada en processos independents i la seua extrema seguretat front a atacs de desbordament de memòria.

---

## 1. Instal·lació de Postfix a Debian/Ubuntu

Durant la instal·lació, el paquet `debconf` llança un assistent de configuració interactiu:

```bash
sudo apt update
sudo apt install -y postfix mailutils
```

Opcions seleccionades a l'assistent:
- **Tipus general de configuració:** *Lloc d'Internet (Internet Site)*.
- **Nom del sistema de correu (*System mail name*):** El nom de domini corporatiu complet (ex: `iesrafael.local`).

---

## 2. El Fitxer de Configuració Central: `/etc/postfix/main.cf`

Totes les directives crítiques de funcionament del servidor s'ajusten a `/etc/postfix/main.cf`:

```ini
# Nom FQDN complet del propi servidor
myhostname = mail.iesrafael.local

# Nom del domini que apareixerà després de l'arrova als correus enviats
mydomain = iesrafael.local
myorigin = $mydomain

# Dominis per als quals aquest servidor acceptarà i emmagatzemarà missatges localment
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain

# Xarxes locals de confiança autoritzades per enviar correus cap a l'exterior
mynetworks = 127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128 192.168.10.0/24

# Interfícies on escolta el servei (totes les targetes)
inet_interfaces = all
inet_protocols = ipv4

# Directori de bústia per a cada usuari en format Maildir
home_mailbox = Maildir/
```

> [!CAUTION]
> **El perill de l'Open Relay (Relé Obert):**
> La directiva `mynetworks` és d'una importància vital. Si s'estableix `mynetworks = 0.0.0.0/0`, qualsevol persona o bot d'Internet podrà utilitzar el teu servidor per enviar milions de correus brossa (SPAM) amb la teua adreça IP. El teu servidor serà inclòs immediatament en totes les llistes negres mundials (RBL) i bloquejat permanentment!

---

## 3. Gestió i Verificació del Servei

```bash
# Comprovar la sintaxi de la configuració
sudo postfix check

# Reiniciar el servei
sudo systemctl restart postfix
sudo systemctl status postfix
```

---

## 4. Enviament de Prova per Terminal

Mitjançant el paquet `mailutils`, podem enviar un correu de prova ràpid des de la consola sense obrir cap client gràfic:

```bash
echo "Aquest és el text del correu de prova de 2n SMX" | mail -s "Prova Postfix" alumne1@iesrafael.local
```

Comprovar el registre del sistema per confirmar que el correu s'ha enviat correctament:
```bash
sudo tail -f /var/log/mail.log
```
Un lliurament reeixit mostrarà la línia: `status=sent (delivered to maildir)`.
