# 0.6 guia para aprender a programar

Algunos consejos para aprender a programar o para pasar de un lenguaje a otro

Com apendre a programar

Les paraules claus sòn paciencia, constancia i humiltat.

Ningu pot apendre si no vol ser ensenyat

La primera cosa que cal fer abans de començar a programar és coneixer la sintaxi del llenguatge que anem autilitzar.

La sintaxi no s’ha d’entendre, s’ha d’apendre.

Si no coneguem les normes no podrem emprar-les i les normes sempre s’aplicaran per aixo s’anomenen normes.

Primera fase(les dades)

Coneixer les normes per anomenar els identificadors

Coneixer els tipus de les dades que podrem emprar

Diferenciar entre constants i variables

Coneixer com es declaren les distintes estructures de dades que podem utilitzar

Coneixer els operadors matemàtics i els operadors lògics

Segona fase(les instruccions)

Cal coneixer la sintaxi de tots els tipus d’instrucció

Inicialització

Assignació

Instruccions d’entrada

Instruccions d’eixida

Bifurcacions

Simples

Compostes

Multiples

Bucles

Controlats per condicions --> while

Controlats percontadors --> for

Tercera fase(els subprogrames)

Coneixer els tipus de subprogrames i les seues característiques

Prototips

Variables locals, globals i paràmetres

Invocació

Programa principal
