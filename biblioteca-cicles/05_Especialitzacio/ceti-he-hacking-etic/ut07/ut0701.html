● Quan volem comprovar la connectivitat, tots solem utilitzar la instrucció Ping, una ferramenta que envia paquets ICMP (Internet Control Message Protocol) a un servidor específic, per saber si la comunicació és correcta o hi ha algun problema. ● Tanmateix, Ping és una instrucció molt senzilla i no permet quasi cap modificació dels paquets, ni utilitzar altres protocols per a l'enviament d'informació.

● Hping3 és una aplicació més avançada, que ens va a permetre modificar els paquets que s'envien a través del protocol TCP/IP, de manera que podrem disposar d'un control molt major d'aquests paquets, podent adaptar-los en funció de les nostres necessitats. Hacking ètic 1r CIBER HPING3 INTRODUCCIÓ

● Hping3 és una aplicació de terminal per a Linux que ens permetrà analitzar i ensamblar fàcilment paquets TCP/IP. ● A diferència d'una instrucció Ping convencional, que s'utilitza per enviar paquets ICMP, aquesta aplicació permet l'enviament de paquets TCP, UDP i RAW-IP.

● Junt a l'anàlisi dels paquets, Hping3 es pot utilitzar també amb altres fins de seguretat com, per exemple, per provar l'eficàcia d'un firewall a través de diferents protocols, la detecció de paquets sospitosos o modificats i, inclús, la protecció davant atacs DoS (denegació de servei) d'un sistema o d'un firewall.

Hacking ètic 1r CIBER HPING3 DEFINICIÓ

● Algunes de les principals utilitats que té Hping3 són les següents: ○ Comprovar la seguretat i el funcionament dels firewalls. ○ Utilitzar-la com una aplicació d’escaneig avançat de ports, encara que és millor utilitzar Nmap per a realitzar aquesta tasca. ○ Proves de xarxa utilitzant diferents protocols, fragmentació, etc.

○ Descobrir el MTU (Unitat de Transmissió Màxima) en la ruta de forma manual. ○ Traceroute avançat utilitzant tots els protocols admesos. ○ Petjada digital remota del sistema operatiu. ○ Comprovar el temps de distància. ○ Auditoria de piles TCP/IP. Hacking ètic 1r CIBER HPING3 DEFINICIÓ

● Degut a la gran quantitat de possibilitats d'aquesta ferramenta, en aquesta presentació vos indicaré les principals utilitats i com aplicar-les. ● Aquesta ferramenta, podria dir-se que és un «ping» vitaminat, i que podem utilitzar una gran quantitat d'opcions avançades amb l'objectiu d'atacar a un host, comprovar si tenim un port obert i molt més.

● El programa Hping3 disposa de diversos modes d’escaneig de ports. El que més destaca és l’enviament de paquets TCP directament, ja que és el mode per defecte de Hping3, però també tenim la possibilitat d'enviar dades via UDP, ICMP i fins i tot a RAW IP, entre altres.

● El mode per defecte és TCP (Transmission Control Protocol). ● −0 // −−rawip: mode RAW IP (enviar paquets en protocols IP, excepte en TCP i UDP). ● −1 // −−icmp: mode ICMP (Internet Control Message Protocol). ● −2 // −−udp: mode UDP (User Datagram Protocol). ● −8 // −−scan: mode SCAN.

● −9 // −−listen: mode “escoltar”. Hacking ètic 1r CIBER HPING3 UTILITATS: MODES D’ESCANEIG DE PORTS

● Els diferents tipus d’escaneig de ports amb TCP són els següents: ○ −S // −−syn: estableix el flag SYN (1). ○ −A // −−ack: estableix el flag ACK (3). ○ NULL: no té assignat cap flag (4). ○ −X // −−xmas: estableix el flag XMAS (5). ○ −F // −−fin: estableix el flag FIN (6).

○ −R // −−rst: estableix el flag RST. ○ −P // −−push: estableix el flag PUSH. ○ −U // −−urg: estableix el flag URG. ○ −Y // −−ymas: estableix el flag YMAS. Hacking ètic 1r CIBER HPING3 UTILITATS: ESCANEIG DE PORTS AMB TCP

● Aquesta ferramenta també ens permet enviar paquets baix el protocol TCP, al més pur estil Nmap. Per fer un escaneig d’un port a través del mètode SYN, de TCP, hem d’utilitzar la següent instrucció: hping3 −S [domini / ip] −p [port] ○ −S // −−syn: estableix el flag SYN.

○ −p: port de destí dels paquets. ● El resultat d'aquest test ens tornarà un flag SA, que correspon a SYN/ACK, és a dir, que la comunicació ha sigut acceptada o, el que és el mateix, que el port està obert. En cas contrari, si el valor és RA correspon a RST/ACK, la comunicació no s'ha realitzat correctament perquè el port està tancat o filtrat.

● Per fer un escaneig d’un port a través del mètode FIN, de TCP, hem d’utilitzar la següent instrucció: hping3 −F [domini / ip] −p [port destí] −s [port local] ○ −F // −−fin: estableix el flag FIN. ○ −p: port de destí dels paquets. ○ −s: port local, a partir del qual comença l’escaneig.

● En una connexió TCP, el flag FIN s'utilitza per iniciar el programa de tancament de la connexió. En el cas de que no rebem una resposta, voldrà dir que el port està obert. Normalment, els firewalls tornen a enviar un paquet RST+ACK per indicar que el port està tancat.

● Hping3 utilitza TCP com a protocol predeterminat. L'ús de la instrucció -2, o -- udp, especifica que Hping funcione en mode UDP, enviant paquets UDP al port objectiu. Hacking ètic 1r CIBER HPING3 UTILITATS: ESCANEIG DE PORTS AMB UDP

HPING3 UTILITATS: ESCANEIG DE PORTS AMB UDP

● És possible utilitzar aquesta ferramenta per modificar els paquets que enviem i introduir un missatge personalitzat de forma similar a una signatura (firma). Per fer això, hem d’utilitzar la següent instrucció: hping3 [domini / ip] −d [longitud] −E [fitxer de text] ○ −d: Longitud del missatge que volem introduir.

○ −E: Fitxer d’on agafarem la signatura que volem introduir als paquets. ● Aquesta ordre introduirà dins dels paquets de Ping el contingut del fitxer de text indicat. També podem utilitzar altres paràmetres, per exemple, −p per indicar el port de destí d’aquests paquets o −2 per enviar els paquets amb el protocol UDP.

Hacking ètic 1r CIBER HPING3 UTILITATS: GENERAR PETICIONS PER PROVAR LA PROTECCIÓ DOS I DDOS

● Hping3 també ens permetrà comprovar l'estabilitat del nostre sistema davant d'atacs de xarxa com DoS (Denegació de Servei) i DDoS (Denegació de Servei Distribuïda) generant proves reals, ja siga cap a localhost com cap a un altre servidor dins (o fora) de la xarxa.

● Per a realitzar un atac DoS, introduim el paràmetre −−flood per a que els paquets s'enviïn en temps real de manera massiva: hping3 −−flood [domini / ip] ○ −−flood: Hping3 envia paquets el més ràpid possible, sense tindre en compte de mostrar les respostes entrants.

Hacking ètic 1r CIBER HPING3 UTILITATS: GENERAR PETICIONS PER PROVAR LA PROTECCIÓ DOS I DDOS

● Igualment, podem afegir el paràmetre −−rand−source, per a que els paquets s'enviïn des de direccions IPs d’origen aleatòri i, així, poder ser indetectables i no es puga descobrir la direcció IP de la màquina que realitza l’atac. ● D'aquesta manera podrem comprovar, en primer lloc, si el nostre firewall funciona i, en segon lloc, com respon el nostre sistema davant d'un intent d'atac DDoS.

● Per a poder provar-ho, s’utilitzarà la següent instrucció: hping3 −−rand−source −−flood [domini / ip] ○ −−rand−source: Hping3 envia paquets amb una adreça d'origen aleatòria. Hacking ètic 1r CIBER HPING3 UTILITATS: GENERAR PETICIONS PER PROVAR LA PROTECCIÓ DOS I DDOS

● En tan sols un parell de segons, podem arribar a generar més de 25.000 paquets, per la qual cosa hem d’anar molt amb compte, ja que és possible que la nostra xarxa es quede bloquejada i inservible. ● Amb les anteriors instruccions, es començaran a generar un gran nombre de paquets (gràcies al paràmetre --flood) amb un fals origen (gràcies al paràmetre rand-source), que s'enviaran de forma contínua al servidor de destí (que serà el nostre objectiu).

● D'aquesta manera, podrem comprovar la robustesa d’un sistema davant dels atacs DoS i DDoS, ja que, si el sistema deixa de funcionar o es bloqueja, és possible que es produïsca un error de configuració. Hacking ètic 1r CIBER HPING3 UTILITATS: GENERAR PETICIONS PER PROVAR LA PROTECCIÓ DOS I DDOS

Hacking ètic 1r CIBER HPING3 UTILITATS: MANIPULACIÓ I ENVIAMENT DE PAQUETS TCP ● Hping3 té una funcionalitat molt interessant, que és la generació i enviament de paquets manipulats cap als nostres objectius, podent manipular les IPs i els ports de les connexions, de gran utilitat per falsificar tràfic en la xarxa.

● És a dir, podem enviar paquets a una xarxa on la direcció d’origen no siga la del nostre ordinador, i així ser indetectables. ● Per a realitzar aquest procés, s’utilitza la següent instrucció: hping3 −a [domini/ip falsa d’origen] −s [port fals d’origen] −p [port destí] [domini/ip destí] ○ −a: direcció IP d’origen (s'introdueix una direcció falsa).

○ −s: port d’origen dels paquets (s'introdueix un port fals). ○ −p: port de destí dels paquets.
