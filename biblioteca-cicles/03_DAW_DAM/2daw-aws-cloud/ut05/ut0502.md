## El Servei Elastic Load Balancing (ELB)

**Elastic Load Balancing (ELB)** distribueix automàticament el trànsit d'aplicacions entrant entre múltiples destinacions (*targets*), com instàncies Amazon EC2, contenidors (ECS/EKS) o adreces IP, en una o més Zones de Disponibilitat:
- Ofereix un **punt d'entrada únic** per als clients mitjançant un nom de domini DNS gestionat per AWS.
- Monitoritza de forma contínua la salut de les instàncies.
- Descarrega de feina els servidors web gestionant la **terminació de xifratge SSL/TLS** mitjançant certificats d'AWS Certificate Manager (ACM).

---

## Comparativa: Application Load Balancer (ALB) vs Network Load Balancer (NLB)

AWS ofereix diversos tipus de balancejadors segons la capa del model OSI en què operen:

| Característica | Application Load Balancer (ALB) | Network Load Balancer (NLB) |
| :--- | :--- | :--- |
| **Capa del Model OSI** | **Capa 7 (Aplicació)** | **Capa 4 (Transport)** |
| **Protocols Suportats** | **HTTP, HTTPS, gRPC, WebSockets** | **TCP, UDP, TLS** |
| **Rendiment i Latència** | Latència d'uns pocs mil·lisegons. | **Latència ultra baixa (microsegons)**, capaç de gestionar milions de peticions per segon. |
| **Inspecció de Paquets** | **Inspecciona el contingut HTTP:** Encapçalats, cookies, paràmetres de consulta i mètodes HTTP. | No inspecciona el contingut d'aplicació (només IPs i ports TCP/UDP). |
| **Encaminament Intel·ligent** | Pot encaminar per ruta d'URL (ex: `/api` vs `/pagaments`) o per nom de host (ex: `api.empresa.com`). | Encaminament ràpid basat únicament en adreces IP i ports. |
| **Adreça IP Estàtica** | Utilitza un nom DNS; les seues IPs públiques canvien dinàmicament segons l'escala. | **Adreces IP estàtiques o IP Elàstica (EIP)** dedicada per Zona de Disponibilitat. |

---

## Quin Balancejador Triar?
- **Tria ALB:** Per a la immensa majoria d'aplicacions web, serveis RESTful, APIs en Node.js/PHP/Java i microserveis basats en contenidors.
- **Tria NLB:** Per a connexions de videojocs multijugador per UDP, servidors de correu SMTP/IMAP, sistemes IoT d'alt volum o si el client exigeix obligatòriament una adreça IP estàtica fixa al tallafocs corporatiu.
