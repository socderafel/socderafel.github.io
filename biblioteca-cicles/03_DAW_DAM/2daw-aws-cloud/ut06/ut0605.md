## Bases de Dades Autogestionades a EC2 vs Amazon RDS

Instal·lar MySQL o PostgreSQL manualment sobre una instància EC2 implica que el teu equip ha de gestionar les còpies de seguretat diàries, aplicar els pegats de seguretat del sistema operatiu, configurar la replicació a mà i gestionar els canvis en cas de desastre (*failover*).

**Amazon Relational Database Service (RDS)** és un servei administrat que automatitza aquestes tasques complexes:
- Suporta els principals motors relacionals: **MySQL, PostgreSQL, MariaDB, Oracle i Microsoft SQL Server** (a més del motor natiu d'alt rendiment d'Amazon: **Amazon Aurora**).
- Còpies de seguretat automatitzades (*Automated Backups*) amb recuperació puntual en el temps (*Point-in-Time Recovery*).
- Aplicació automàtica de pegats de manteniment en finestres horàries programades.

## Alta Disponibilitat: Amazon RDS Multi-AZ (*Disaster Recovery*)

El desplegament **Multi-AZ** està dissenyat exclusivament per a garantir l'alta disponibilitat i la tolerància a fallades davant desastres:

```
              [ Aplicació Web (Backend) ]
                          |
             (Connexió al DNS de la BBDD)
                          |
                          ▼
            +---------------------------+
            |  Instància RDS Primària   | (Ubicada a AZ-a)
            |    (Lectura i Escriptura) |
            +---------------------------+
                          |
             Replicació Síncrona Fàsica
                          |
                          ▼
            +---------------------------+
            |  Instància RDS Standby    | (Ubicada a AZ-b)
            |    (Passiva / En espera)  |
            +---------------------------+
```

- **Com funciona?** Tota escriptura a la base de dades primària es replica de forma **síncrona** a una instància secundària en espera (*Standby*) en una altra Zona de Disponibilitat.
- **Failover Automàtic:** Si la instància primària cau o la zona 'a' perd l'electricitat, AWS canvia el registre DNS de la base de dades automàticament cap a la màquina secundària en 60-120 segons sense cap canvi de codi a l'aplicació web!
- **Important:** La instància Standby **NO serveix trànsit de lectura**; està purament en espera passiva.

## Escalabilitat de Rendiment: Rèpliques de Lectura (*Read Replicas*)

Mentre que Multi-AZ serveix per a disponibilitat, les **Rèpliques de Lectura** serveixen per a **escalabilitat de consultes pesades**:

```
                       [ Aplicació Web ]
                         /                      Escriptures  /             \  Consultes pesades
                       ▼               ▼
           +---------------+       +-----------------------+
           | RDS Primària  |------>| RDS Rèplica Lectura 1 | (AZ-a o una altra regió)
           +---------------+ (Asínc) +-----------------------+
                                   | RDS Rèplica Lectura 2 | (AZ-b)
                                   +-----------------------+
```

- **Replicació Asíncrona:** Les escriptures es reflecteixen de forma asíncrona a les rèpliques.
- Poden tenir fins a 5 o 15 rèpliques de lectura.
- **Desconnexió de càrrega:** L'aplicació web envia els `INSERT`/`UPDATE` a la primària i distribueix els `SELECT` entre les rèpliques.
- Poden ser **promocionades a base de dades primària independent** si cal.
