## Fonaments d'Amazon S3

**Amazon Simple Storage Service (Amazon S3)** és un servei d'emmagatzematge d'objectes que ofereix escalabilitat líder al sector, disponibilitat de dades, seguretat i rendiment:
- **Emmagatzematge d'Objectes:** A diferència dels discs durs tradicionals, no hi ha carpetes ni sectors de disc reals. Cada arxiu s'emmagatzema com un **objecte** compost per les dades del fitxer, les seues metadades i una clau d'identificació única (*Key* o ruta).
- **Capacitat il·limitada:** Pots emmagatzemar tants petabytes com vulgues sense necessitat de provisionar mida prèvia. Un sol objecte pot tenir una mida de fins a **5 Terabytes**.
- **Contenidors (Buckets):** Els fitxers es guarden dins de **Buckets**. El nom d'un bucket ha de ser **únic a nivell global a tot el món** (com un nom de domini d'Internet) i només admet lletres minúscules, números i guions.

---

## Allotjament Web Estàtic (*Static Website Hosting*)

Amazon S3 permet allotjar llocs web estàtics (formats exclusivament per HTML, CSS, JavaScript, imatges i fonts tipogràfiques) sense necessitat de mantenir cap servidor Apache, Nginx o instància EC2:
- **Cost ridícul:** Només pagues pels gigabytes emmagatzemats i per les peticions web rebudes (sovint pocs cèntims d'euro al mes).
- **Escalabilitat instantània:** Pot atendre milions de peticions concurrents de forma nativa sense necessitat de balancejadors ni Auto Scaling.
- **Com s'activa?**
  1. Habilitar l'opció *Static website hosting* a les propietats del bucket.
  2. Indicar el document d'índex (`index.html`) i el document d'error (`error.html` o `404.html`).
  3. Desactivar el bloqueig d'accés públic (*Block Public Access*).
  4. Adjuntar una **Bucket Policy** en format JSON que concedisca permís `s3:GetObject` a qualsevol persona (`Principal: "*"`).

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PermisLecturaPublicaWebEstatica",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::el-meu-bucket-web-daw/*"
    }
  ]
}
```
