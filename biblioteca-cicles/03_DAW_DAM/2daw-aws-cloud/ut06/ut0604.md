## La Necessitat d'un Emmagatzematge Compartit al Núvol

Un volum Amazon EBS només es pot connectar a un únic servidor alhora dins d'una única Zona de Disponibilitat. Què ocorre si tens un clúster d'Auto Scaling amb 10 servidors web Apache en diferents AZs que necessiten compartir la mateixa carpeta de codi font de WordPress (`/wp-content/uploads/`) o dades d'usuaris?

Per a resoldre aquest problema s'utilitza **Amazon Elastic File System (Amazon EFS)**:
- Un sistema de fitxers completament administrat, elàstic i basat en el protocol estàndard de xarxa **NFSv4 (Network File System)** per a instàncies Linux.
- **Accés Concurrent Massiu:** Centenars de servidors EC2 poden muntar el mateix sistema de fitxers EFS i llegir/escriure dades de manera simultània.
- **Resiliència Multi-AZ Nativa:** Les dades d'EFS es repliquen de forma automàtica i transparent a través de múltiples Zones de Disponibilitat de la regió.

---

## Comparativa: EBS vs S3 vs EFS

| Característica | Amazon EBS | Amazon S3 | Amazon EFS |
| :--- | :--- | :--- | :--- |
| **Model de dades** | Emmagatzematge en **Blocs** | Emmagatzematge d'**Objectes** | Sistema de **Fitxers jeràrquic** |
| **Protocol d'accés** | Bus PCIe / SATA virtual | Web API HTTP/HTTPS (REST) | Protocol de xarxa **NFSv4** |
| **Connexió concurrent** | Només a 1 instància (Multi-Attach io2 té límits). | Accés universal per milions de clients. | **Centenars d'instàncies EC2 simultànies**. |
| **Àmbit d'ús** | Una sola Zona de Disponibilitat (AZ). | Global per Regió / Món. | **Multi-AZ a tota la Regió**. |
| **Cas d'ús típic** | Sistema operatiu d'EC2, bases de dades locals. | Fitxers estàtics, imatges, vídeos, backups. | **Carpetes compartides CMS (WordPress), directoris d'usuari /home**. |

---

## Objectius de Muntatge (*Mount Targets*)

Per connectar instàncies EC2 a un sistema de fitxers EFS:
1. Es crea un **Mount Target** a cadascuna de les subxarxes de la VPC.
2. Cada Mount Target té el seu propi **Security Group**, que ha de permetre el trànsit d'entrada pel **port 2049 (NFS)** exclusivament des del Security Group dels servidors web.
3. A la instància Linux s'utilitza la comanda estàndard de muntatge o la utilitat d'ajuda d'AWS `amazon-efs-utils`:

```bash
# Instal·lació de la utilitat EFS
sudo dnf install -y amazon-efs-utils

# Muntatge segur xifrat amb TLS
sudo mount -t efs -o tls fs-0123456789abcdef0:/ /var/www/html/compartit
```
