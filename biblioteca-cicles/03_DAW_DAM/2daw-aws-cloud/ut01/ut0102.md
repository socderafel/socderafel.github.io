## La Piràmide dels Models de Servei al Núvol

El Cloud Computing estructura la distribució de recursos tecnològics en tres capes o models de servei fonamentals segons el grau de control i gestió que assumeix el client davant del proveïdor:

```
               ▲
              /              /   \      SaaS (Software as a Service)
            / SaaS\     - Ús directe del programari d'usuari final
           /-------\    (Gmail, Salesforce, Microsoft 365)
          /  PaaS            /  (Plataf) \  PaaS (Platform as a Service)
        /-------------\ - Entorn d'execució i eines de desplegament
       /     IaaS      \ (AWS Elastic Beanstalk, Heroku, Firebase)
      / (Infraestruc)        /-------------------\ IaaS (Infrastructure as a Service)
    /                     \ - Maquinari virtual, xarxes i discs
   /_______________________\ (Amazon EC2, Amazon VPC, AWS EBS)
```

| :--- | :---: | :---: | :---: | :---: |

| **Dades de l'Aplicació** | Client | **Client** | **Client** | Proveïdor |

| **Xarxa Física i Centre de Dades** | Client | Proveïdor | Proveïdor | Proveïdor |

## Detall dels Models de Servei

### 1. IaaS (Infrastructure as a Service)
- **Definició:** Ofereix accés a recursos de xarxa, ordinadors virtuals o maquinari dedicat i espai d'emmagatzematge de dades.
- **Nivell de control:** Màxim control sobre el sistema operatiu, les configuracions de xarxa i els paquets de programari.
- **Exemples a AWS:** **Amazon EC2**, **Amazon VPC**, **Amazon EBS**.
- **Ideal per a:** Equips d'administració de sistemes que necessiten migrar servidors corporatius antics sense modificar-ne l'arquitectura (*Lift and Shift*).

### 2. PaaS (Platform as a Service)
- **Definició:** El proveïdor s'encarrega de la gestió del maquinari subjacent, el sistema operatiu, les actualitzacions i el programari base (*runtime*). El desenvolupador només es preocupa de desplegar el codi font i les dades.
- **Nivell de control:** Mitjà. Centrat exclusivament en l'aplicació.
- **Exemples a AWS:** **AWS Elastic Beanstalk**, **AWS App Runner**, **AWS Lambda** (*Serverless PaaS/FaaS*).
- **Ideal per a:** Desenvolupadors web que volen llançar aplicacions ràpidament sense gestionar configuracions de Linux o Windows.

### 3. SaaS (Software as a Service)
- **Definició:** Producte completament desenvolupat, executat i administrat pel proveïdor de serveis.
- **Nivell de control:** Només configuració d'usuari final i gestió de perfils.
- **Exemples:** Google Workspace, Slack, Dropbox, Amazon QuickSight.
