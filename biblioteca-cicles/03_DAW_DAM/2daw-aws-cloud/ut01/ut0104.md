## Fonament del Model de Responsabilitat Compartida

La seguretat i el compliment normatiu a AWS és una tasca compartida entre **AWS** i el **Client**. Aquesta diferenciació fonamental s'expressa mitjançant la fórmula clàssica:

> **AWS és responsable de la seguretat DEL núvol.**  
> **El Client és responsable de la seguretat EN el núvol.**

```
+--------------------------------------------------------------------------+
|                     RESPONSABILITAT DEL CLIENT                           |
|                        "Seguretat EN el Núvol"                           |
+--------------------------------------------------------------------------+
|  - Dades del Client (Xifratge en trànsit TLS i en repòs KMS)             |
|  - Gestió d'Identitats i Accessos (IAM, usuaris, MFA, polítiques)         |
|  - Sistema Operatiu de les instàncies (Parxes de seguretat, actualitz.)   |
|  - Configuració de Xarxa i Tallafocs (Security Groups, NACLs, regles)    |
+--------------------------------------------------------------------------+
|                      RESPONSABILITAT D'AWS                               |
|                        "Seguretat DEL Núvol"                             |
+--------------------------------------------------------------------------+
|  - Programari Base: Hipervisors (KVM/Nitro), microcodi, APIs d'AWS       |
|  - Computació, Emmagatzematge i Xarxes físiques                          |
|  - Infraestructura Global: Regions, Zones de Disponibilitat (AZ)         |
|  - Seguretat Física dels Centres de Dades (Guàrdies, biometria, energia) |
+--------------------------------------------------------------------------+
```

---

## Variació de la Responsabilitat segons el Tipus de Servei

La línia divisòria entre el que gestiona el client i el que gestiona AWS es desplaça segons el nivell d'abstracció del servei utilitzat:

### 1. Serveis d'Infraestructura (Com Amazon EC2)
- El client gestiona: El sistema operatiu hoste, la instal·lació de qualsevol paquet, les actualitzacions de seguretat de l'OS, el tallafocs del servidor (Security Groups) i l'arquitectura d'usuaris.
- AWS gestiona: La infraestructura física, l'hipervisor Nitro i les instal·lacions del centre de dades.

### 2. Serveis Gestionats / PaaS (Com Amazon RDS)
- El client gestiona: L'optimització de les consultes SQL, la definició d'esquemes de taules, les regles d'accés de xarxa i l'usuari/contrasenya de connexió.
- AWS gestiona: La instal·lació del motor de base de dades (MySQL/PostgreSQL), l'aplicació de parxes del sistema operatiu del servidor de dades i les còpies de seguretat automatitzades.

### 3. Serveis Serverless / Abstractes (Com Amazon S3 o AWS Lambda)
- El client gestiona: L'accés a les dades mitjançant permisos IAM i polítiques de bucket, el xifratge de les dades i el codi que puja a Lambda.
- AWS gestiona: Absolutament tota la infraestructura subjacent, l'escalat automàtic, l'alta disponibilitat física i la resiliència del maquinari.
