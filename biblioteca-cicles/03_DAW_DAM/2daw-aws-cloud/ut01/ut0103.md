## Classificació dels Models de Desplegament

Els models de desplegament defineixen la ubicació de la infraestructura, qui té accés als recursos i quin nivell d'aïllament i propietat s'estableix:

```
+-----------------------------------------------------------------+
|                    MODELS DE DESPLEGAMENT                       |
+-------------------+--------------------+------------------------+
|   Núvol Públic    |    Núvol Privat    |      Núvol Híbrid      |
|  (Public Cloud)   |  (Private Cloud)   |     (Hybrid Cloud)     |
|                   |                    |                        |
| - Propietat d'AWS | - Infraestructura  | - Connexió segura      |
| - Recursos        |   d'ús exclusiu    |   entre On-Premises    |
|   compartits      | - Centre propi o   |   i AWS (VPN /         |
| - Accés per       |   proveïdor host   |   Direct Connect)      |
|   Internet        | - Màxim control    | - Flexibilitat total   |
+-------------------+--------------------+------------------------+
```

---

## Comparativa Detallada de Models

### 1. Núvol Públic (*Public Cloud*)
- **Descripció:** Serveis i recursos operats per un proveïdor tercer (com AWS, Azure, Google Cloud) que es lliuren a través d'Internet de manera compartida.
- **Avantatges:** Zero inversió inicial de capital, escalabilitat pràcticament infinita, alta fiabilitat i absència total de manteniment del maquinari físic.
- **Inconvenients:** Dependència del proveïdor i possibles reptes en organitzacions amb normatives extremes de privacitat que exigeixen custòdia física del disc.

### 2. Núvol Privat (*Private Cloud*)
- **Descripció:** Infraestructura de computació en el núvol operada per a l'ús exclusiu d'una sola organització. Pot estar ubicada al centre de dades físic de l'empresa (*on-premises*) o allotjada per un proveïdor extern dedicat.
- **Avantatges:** Control absolut sobre la seguretat física, compliment normatiu rígid i personalització profunda de maquinari.
- **Inconvenients:** Alts costos de capital (CapEx), manteniment continu per part del personal intern i elasticitat molt limitada.

### 3. Núvol Híbrid (*Hybrid Cloud*)
- **Descripció:** Entorn que connecta de forma segura i coordinada un núvol privat o infraestructura local amb un o més núvols públics.
- **Mecanismes de connexió a AWS:**
  - **AWS Site-to-Site VPN:** Túnel xifrat IPSec a través de la xarxa pública d'Internet.
  - **AWS Direct Connect:** Enllaç de fibra física dedicat i privat que interconnecta directament el centre de dades de l'empresa amb la xarxa d'AWS sense travessar Internet públic, garantint ample de banda massiu i latència ultrabaixa.
- **Casos d'ús típics:** *Cloud Bursting* (atendre pics imprevistos de trànsit al núvol públic mentre la base de dades crítica roman al centre de dades local privat).

### 4. Multicloud
- **Descripció:** Ús simultani de dos o més proveïdors de núvol públic diferents (per exemple, executar el frontend web a AWS i els models d'intel·ligència artificial a Google Cloud Platform). Evita el bloqueig del proveïdor (*Vendor Lock-in*).
