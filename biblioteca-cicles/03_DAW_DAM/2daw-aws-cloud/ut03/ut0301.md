## Concepte d'Amazon Virtual Private Cloud (VPC)

Una **Amazon VPC** és una xarxa virtual privada dedicada exclusivament al teu compte d'AWS. Està completament aïllada de forma lògica de les altres xarxes virtuals del núvol d'AWS.

- Equival a tenir el teu propi centre de dades corporatiu tradicional, amb la diferència que utilitza la infraestructura altament escalable i elàstica d'AWS.
- **Àmbit:** Una VPC està limitada a una **única Regió** (però s'estén per totes les Zones de Disponibilitat d'aquesta regió).
- Permet controlar completament l'entorn de xarxa: selecció del rang d'adreces IP privades, creació de subxarxes, configuració de taules d'encaminament i passarel·les de xarxa.

---

## Blocs CIDR i Rangs Privats RFC 1918

Quan es crea una VPC cal assignar-li un bloc d'adreces IPv4 principal mitjançant la notació **CIDR (Classless Inter-Domain Routing)**. El protocol estàndard d'Internet (RFC 1918) recomana utilitzar els següents rangs privats no encaminables a Internet públic:

| Rang Privat RFC 1918 | Màscara per Defecte | Nombre Total d'Adreces IP |
| :--- | :--- | :--- |
| `10.0.0.0` a `10.255.255.255` | `10.0.0.0/8` | 16.777.216 adreces (molt habitual en VPCs: `10.0.0.0/16`) |
| `172.16.0.0` a `172.31.255.255` | `172.16.0.0/12` | 1.048.576 adreces (utilitzat per la VPC per defecte d'AWS: `172.31.0.0/16`) |
| `192.168.0.0` a `192.168.255.255` | `192.168.0.0/16` | 65.536 adreces (rangs típics domèstics i petites xarxes) |

### Límits de Mida a AWS
- La mida d'un bloc CIDR a una VPC d'AWS pot anar des d'una màscara **`/16`** (65.536 adreces IP, la més gran permesa) fins a una màscara **`/28`** (16 adreces IP, la més petita permesa).
- El bloc CIDR principal no es pot modificar ni reduir fàcilment un cop creat (tot i que es poden afegir blocs secundaris).

## Les 5 Adreces IP Reservades per AWS

En qualsevol xarxa IP tradicional, es reserven 2 adreces (xarxa i difusió). Tanmateix, en **totes les subxarxes d'AWS es reserven obligatòriament 5 adreces IP**:

Si tenim una subxarxa `10.0.1.0/24` (256 adreces teòriques):
1. **`10.0.1.0`:** Adreça de xarxa (Network address).
2. **`10.0.1.1`:** Reservada per AWS per a l'encaminador de la VPC (*VPC Router*).
3. **`10.0.1.2`:** Reservada per AWS per al servei de resolució DNS intern (AmazonProvidedDNS).
4. **`10.0.1.3`:** Reservada per AWS per a ús futur.
5. **`10.0.1.255`:** Adreça de difusió de xarxa (*Network broadcast*), no admesa a VPC.

Per tant, a una subxarxa `/24`, el nombre d'adreces útils per a les teues instàncies EC2 serà sempre **`256 - 5 = 251 adreces`**.
