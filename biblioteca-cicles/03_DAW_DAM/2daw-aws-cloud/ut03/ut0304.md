## La Defensa en Profunditat a la Xarxa d'AWS

A Amazon Web Services, el trànsit de xarxa està protegit per dues capes de tallafocs virtuals complementàries:
1. **Network ACLs (NACLs):** Primera línia de defensa perimetral a nivell de **subxarxa**.
2. **Security Groups (SG):** Segona línia de defensa individualitzada a nivell d'**interfície de xarxa de la instància (ENI)**.

```
       Trànsit d'Internet entrant
                 |
                 ▼
     +-----------------------+
     |  Network ACL (NACL)   |  <--- Nivell de Subxarxa (Stateless / Sense estat)
     +-----------------------+
                 |
                 ▼
     +-----------------------+
     | Security Group (SG)   |  <--- Nivell d'Instància (Stateful / Amb estat)
     +-----------------------+
                 |
                 ▼
        [ Instància EC2 ]
```

## Taula Comparativa Fonamental: Security Groups vs NACLs

Aquesta és una de les comparatives més transcendents en les certificacions oficials d'AWS i en el disseny d'arquitectures segures:

| Característica | Grup de Seguretat (*Security Group*) | Llista de Control d'Accés (*Network ACL*) |
| :--- | :--- | :--- |
| **Nivell d'operació** | **Nivell d'Instància** (Interfície de xarxa virtual ENI). | **Nivell de Subxarxa** (Totes les instàncies de la subxarxa). |
| **Estat (*Statefulness*)** | **Amb estat (*Stateful*):** Les respostes al trànsit permès s'autoritzen automàticament de sortida. | **Sense estat (*Stateless*):** Cal permetre explícitament tant el trànsit d'entrada com el de sortida (ports efímers). |
| **Tipus de regles** | **Només regles de PERMISSIÓ (`Allow`).** Tot el que no estiga permès explícitament queda bloquejat. | **Regles de PERMISSIÓ (`Allow`) i de DENEGACIÓ (`Deny`).** Permet bloquejar adreces IP atacants concretes. |
| **Ordre d'avaluació** | S'avaluen **totes les regles conjuntament** abans de prendre una decisió. | S'avaluen en **ordre numèric estricte** (de menor a major: regla 100, regla 200). La primera regla que coincideix s'aplica immediatament. |
| **Estat inicial per defecte** | Per defecte: bloqueja tot el trànsit d'entrada i permet tot el de sortida. | La NACL per defecte d'AWS permet tot el trànsit d'entrada i sortida (*Rule \**: Deny). |

---

## Cas d'Ús: Bloqueig d'un Atacant amb NACL

Imagina que un servidor web rep un atac de denegació de servei (DDoS) des de l'adreça IP fixa `198.51.100.25`.
- **Amb Security Groups:** No pots bloquejar aquesta IP directament, ja que els Security Groups només admeten regles `Allow`.
- **Amb Network ACLs:** Pots crear una regla `Rule 50: Deny IPv4 198.51.100.25/32` a la NACL de la subxarxa. Com que el número 50 s'avalua abans que la regla `Rule 100: Allow All`, els paquets de l'atacant seran descartats abans d'arribar ni tan sols a la interfície de la màquina!
