## La Jerarquia Geogràfica Global d'AWS

La infraestructura mundial d'Amazon Web Services està organitzada en tres nivells físics complementaris:

```
+-------------------------------------------------------------------------+
|                          REGIONS D'AWS                                  |
|   (Àrees geogràfiques del món com Irlanda 'eu-west-1', Espanya          |
|    'eu-south-2' o Virgínia del Nord 'us-east-1')                         |
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   |                  ZONES DE DISPONIBILITAT (AZ)                   |   |
|   |                                                                 |   |
|   |   +-----------------------+     +-----------------------+       |   |
|   |   |        eu-west-1a     |     |        eu-west-1b     |       |   |
|   |   |   (Centres de dades   |     |   (Centres de dades   |       |   |
|   |   |    físics separats)   |<--->|    físics separats)   |       |   |
|   |   +-----------------------+     +-----------------------+       |   |
|   |                     Fibra òptica d'ultra baixa latència         |   |
|   +-----------------------------------------------------------------+   |
+-------------------------------------------------------------------------+
|                  PUNTS DE PRESÈNCIA (EDGE LOCATIONS)                    |
|   (Centenars de servidors perimetrals arreu del món per a CloudFront)   |
+-------------------------------------------------------------------------+
```

---

## 1. Regions d'AWS
Una **Regió** és una ubicació física al món on AWS té múltiples Zones de Disponibilitat. Cada regió està completament aïllada de les altres per evitar que una catàstrofe natural o fallada d'energia en una zona afecti altres parts del planeta.

### Criteris de Selecció d'una Regió per al Desplegament
1. **Compliment legal i sobirania de dades:** El Reglament General de Protecció de Dades (RGPD/GDPR) exigeix que les dades personals de ciutadans europeus romanguin a la Unió Europea (ex: `eu-south-2` a l'Aragó o `eu-central-1` a Frankfurt).
2. **Latència:** Com més a prop dels usuaris finals estiguen els servidors, menor serà el temps d'anada i tornada de la xarxa (*ping*).
3. **Disponibilitat de serveis:** Les regions noves poden trigar mesos a incorporar els serveis més recents d'AWS.
4. **Cost:** Els preus dels serveis varien lleugerament segons els impostos i costos elèctrics locals de cada país.

---

## 2. Zones de Disponibilitat (AZ - *Availability Zones*)
Cada Regió conté com a mínim **tres Zones de Disponibilitat**. Una AZ està formada per un o diversos centres de dades discrets, amb generadors dièsel propis, connexió a diferents centrals elèctriques i xarxes redundants.
- Les AZ estan separades físicament per desenes de quilòmetres per protegir-se d'inundacions o talls d'energia locals.
- Estan interconnectades mitjançant enllaços de fibra òptica privada amb latències inferiors a 1 o 2 mil·lisegons.
- **Bona pràctica d'Alta Disponibilitat (Multi-AZ):** Desplegar sempre els servidors web i les bases de dades repartits entre un mínim de dues AZs diferents.

---

## 3. Punts de Presència (*Edge Locations*) i CloudFront
Són centenars de centres de distribució de continguts situats a les principals ciutats del món (com Madrid, Barcelona, París, Tòquio).
- Utilitzats pel servei de CDN **Amazon CloudFront** i pel servei DNS **Amazon Route 53**.
- Guarden en memòria cau (*caching*) fitxers estàtics (imatges, vídeos, fulls CSS, JavaScript) a mil·lisegons dels usuaris finals, reduint dràsticament la càrrega dels servidors centrals.
