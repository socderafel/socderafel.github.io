## Anatomia d'una Política IAM en Format JSON

Els permisos a AWS no s'assignen verbalment ni amb números octals, sinó mitjançant **Documents JSON** anomenats **Polítiques de Seguretat IAM**.

Una política està formada per una o més declaracions (*Statements*):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PermisLecturaS3ProjecteWeb",
      "Effect": "Allow",
      "Action": [
        "s3:GetObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::el-meu-bucket-daw-2026",
        "arn:aws:s3:::el-meu-bucket-daw-2026/*"
      ]
    }
  ]
}
```

---

## Elements Clau d'una Declaració (*Statement*)

1. **`Sid` (Statement ID):** Identificador opcional descriptiu i llegible per humans.
2. **`Effect`:** Defineix si la declaració concedeix o rebutja l'accés. Només admet dos valors: **`Allow`** o **`Deny`**.
3. **`Action`:** Llista de crides d'API o operacions específiques que s'avaluen (ex: `ec2:StartInstances`, `rds:CreateDBInstance`, `s3:*`).
4. **`Resource`:** L'objecte o conjunt d'objectes concrets sobre els quals s'aplica l'acció, identificats mitjançant el seu **ARN (Amazon Resource Name)**:
   - Format estàndard: `arn:partition:service:region:account-id:resource-id`
5. **`Condition` (Opcional):** Regles addicionals que s'han de complir perquè la declaració tingui efecte (per exemple: exigir que la petició provinga d'una IP corporativa concreta `aws:SourceIp` o que l'usuari hagi iniciat sessió amb MFA `aws:MultiFactorAuthPresent`).

---

## El Principi del Menor Privilegi (*Least Privilege*)

És la màxima regla d'or de la seguretat en arquitectures al núvol:
> «Concedeix exclusivament els permisos mínims indispensables que un usuari, aplicació o servei necessita per realitzar la seua tasca concreta, durant el temps estrictament necessari, i res més.»

Mai s'ha d'adjuntar la política `AdministratorAccess` (`Action: "*", Resource: "*"`) a desenvolupadors o aplicacions per mandra de configurar els permisos correctes!

---

## Mecanisme d'Avaluació de Permisos d'AWS

Quan es rep una sol·licitud a l'API d'AWS, el motor d'autorització segueix aquesta lògica estricta:
1. **Denegació per defecte (*Implicit Deny*):** Inicialment, totes les peticions estan denegades.
2. **Denegació explícita (*Explicit Deny*):** Si qualsevol política aplicable conté un `Deny`, la petició es rebutja immediatament sense mirar res més.
3. **Permissió explícita (*Explicit Allow*):** Si hi ha un `Allow` i cap `Deny`, la petició s'autoritza.
4. Si no hi ha cap `Allow`, es manté la denegació implícita.
