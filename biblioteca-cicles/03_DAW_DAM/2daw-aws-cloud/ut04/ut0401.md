## Fonaments d'Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** proporciona capacitat de computació redimensionable i sota demanda al núvol.
- Permet als desenvolupadors web oblidar-se d'adquirir maquinari físic, facilitant el llançament de tants servidors virtuals com siguen necessaris per atendre el trànsit d'una aplicació.
- **Sistema Nitro d'AWS:** Les instàncies modernes d'EC2 s'executen sobre l'arquitectura d'hipervisor maquinari **AWS Nitro**, que descarrega les tasques de seguretat, xarxa i emmagatzematge a targetes PCIe dedicades, lliurant pràcticament el 100% de la CPU i memòria del xip físic a les màquines virtuals del client.

## Cicle de Vida d'una Instància EC2

El cicle de vida descriu la transició d'estats que experimenta un servidor des de la seua creació fins a la seua destrucció:

```
               [ Llançament ]
                     |
                     ▼
                 +---------+
                 | Pending | (S'assigna maquinari físic i IP)
                 +---------+
                     |
                     ▼
  +------------> +---------+ <-----------+
  |              | Running |              | (Instància operativa)
  |              +---------+              |
  |                |     |                |
(Start)     (Stop) |     | (Reboot)       |
  |                ▼     +----------------+
  |              +---------+
  +------------- | Stopped | (Memòria RAM alliberada, disc EBS conservat)
                 +---------+
                     |
                     ▼ (Terminate)
                 +------------+
                 | Terminated | (Instància destruïda permanentment)
                 +------------+
```

### Estats Principals:
1. **Pending:** La instància s'està preparant; AWS busca un servidor amfitrió físic adequat i li assigna una IP.
2. **Running:** La màquina està completament encesa i funcional. Es factura per cada segon d'execució.
3. **Stopped:** El sistema operatiu s'ha aturat de forma neta. S'allibera la CPU i la memòria RAM físiques (es deixa de facturar per computació). El volum EBS persisteix (es continua facturant l'espai de disc).
4. **Rebooting:** Reinici suau del sistema operatiu (manté la mateixa adreça IP pública i privada).
5. **Terminated:** La instància s'ha esborrat de manera definitiva. La seua ranura s'elimina i el volum EBS arrel s'esborra (tret que s'hagi marcat l'opció `DeleteOnTermination: false`).

## Les Imatges de Màquina d'Amazon (AMI)

Una **AMI (Amazon Machine Image)** és la plantilla mestra que conté el programari necessari per iniciar una instància:
- Una plantilla per al volum arrel (sistema operatiu com Ubuntu 24.04, Amazon Linux 2023 o Windows Server 2022).
- Permisos de llançament que determinen quins comptes d'AWS poden utilitzar la plantilla.
- Un mapatge de dispositius de blocs (*Block Device Mapping*) que especifica quins volums de disc s'adjuntaran.

### Tipus d'AMIs:
- **AMIs de la Comunitat i Quick Start:** Imatges oficials mantingudes per AWS, Canonical, Red Hat, etc.
- **AWS Marketplace:** Imatges preconfigurades amb programari de tercers (com WordPress, GitLab o servidors de bases de dades amb llicència).
- **AMIs Personalitzades (*Golden AMIs*):** Imatges creades per la teua pròpia empresa que ja porten tota la configuració corporativa, eines de seguretat i dependències instal·lades.
