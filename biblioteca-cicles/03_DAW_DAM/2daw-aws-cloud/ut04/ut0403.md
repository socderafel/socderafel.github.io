## La Matriu de Models de Compra a Amazon EC2

Un dels errors més comuns en les empreses novelles és utilitzar exclusivament el preu estàndard sota demanda (*On-Demand*), pagant fins a un 70% o 90% més del que és necessari. AWS ofereix quatre models de compra principals adaptats a diferents cicles de vida d'aplicació:

```
+-------------------------------------------------------------------------+
|                      MODELS DE COMPRA A AMAZON EC2                      |
+-------------------+--------------------+--------------------------------+
|    On-Demand      |   Savings Plans    |          Spot Instances        |
|                   |  / Reservades (RI) |                                |
| - Sense compromís | - Compromís de 1   | - Descomptes de fins al 90%    |
| - Màxima          |   o 3 anys         | - Capacitat excedent d'AWS     |
|   flexibilitat    | - Estalvi fins 72% | - Poden ser interrompudes amb  |
| - Pagament per    | - Càrregues de     |   un avís de 2 minuts          |
|   segons d'ús     |   base constants   | - Per a processament per lots  |
+-------------------+--------------------+--------------------------------+
```

---

## Comparativa Detallada de Models de Facturació

### 1. Instàncies Sota Demanda (*On-Demand Instances*)
- **Característiques:** Es paga pel temps de computació per segons (mínim 60 segons) sense cap mena de pagament inicial ni compromís a llarg termini.
- **Quan utilitzar-les?** Càrregues de treball a curt termini, impredictibles, aplicacions que s'estan desenvolupant per primera vegada o per a atendre pics inesperats de trànsit.

### 2. AWS Savings Plans i Instàncies Reservades (RI)
- **Característiques:** Oferixen un descompte de fins a un **72%** respecte als preus On-Demand a canvi de comprometre's a un consum constant (mesurat en dòlars per hora en els *Savings Plans*, o instàncies específiques en les *RI*) durant un període de **1 o 3 anys**.
- **Opcions de pagament:**
  - *All Upfront:* Es paga el 100% de l'any per avançat (màxim estalvi).
  - *Partial Upfront:* Es paga una part inicial i la resta mensualment.
  - *No Upfront:* Sense pagament inicial, es paga una quota mensual constant amb descompte.
- **Quan utilitzar-les?** Càrregues de treball constants i estables que han d'estar enceses les 24 hores del dia els 365 dies de l'any (com el servidor web principal o la base de dades central de producció).

### 3. Instàncies Spot (*Spot Instances*)
- **Característiques:** Permeten aprofitar la capacitat sobrant i no utilitzada dels centres de dades d'AWS amb descomptes de fins al **90%**.
- **El factor clau (Interrupció):** Si la demanda de clients On-Demand augmenta i AWS necessita la màquina, la instància Spot pot ser finalitzada o aturada per AWS amb només **2 minuts d'avís previ** (*2-minute warning*).
- **Quan utilitzar-les?** Càrregues flexibles que poden tolerar talls sobtats: renderitzat de vídeo, anàlisi de genòmica, pipelines d'integració contínua (CI/CD) o càrregues distribuïdes darrere d'una cua de missatges (Amazon SQS).

### 4. Amfitrions Dedicats (*Dedicated Hosts*)
- Servidors físics complets dedicats exclusivament a un client. Utilitzats principalment per satisfer estrictes requisits legals d'aïllament físic o per aprofitar llicències de programari propi per sòcol/nucli (*Bring Your Own License - BYOL* de Microsoft o Oracle).
