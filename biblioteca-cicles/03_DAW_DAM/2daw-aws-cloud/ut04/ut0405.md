## Automatització del Llançament: Scripts User Data

El concepte d'**Aprovisionament Desatès (*Bootstrapping*)** consisteix en automatitzar completament la instal·lació i configuració de programari en un servidor en el moment exacte de la seua creació, sense intervenció manual de cap operador.

Quan es llança una instància EC2, el camp **User Data** permet introduir un script en Bash (o PowerShell en Windows):
- S'executa una sola vegada durant el primer cicle d'arrencada de la màquina.
- S'executa amb privilegis d'administrador (`root`), de manera que no cal utilitzar la comanda `sudo`.
- Els registres de l'execució d'aquest script es desen automàticament al fitxer `/var/log/cloud-init-output.log` per a la seua depuració en cas d'error.

---

## Exemple d'Script User Data per a Servidor Web LAMP

```bash
#!/bin/bash
# Actualització de repositoris del sistema
dnf update -y

# Instal·lació del servidor web Apache, PHP i mòduls
dnf install -y httpd php php-mysqlnd git

# Arrencada i activació del servei Apache per a que arrenque amb el sistema
systemctl start httpd
systemctl enable httpd

# Creació d'una pàgina web senzilla dinàmica de benvinguda
cat <<EOF > /var/www/html/index.php
<!DOCTYPE html>
<html>
<head><title>Servidor Web Desplegat amb User Data</title></head>
<body>
  <h1>Hola des d'AWS EC2!</h1>
  <p>Instància aprovisionada automàticament amb èxit.</p>
  <p>Versió de PHP: <?php echo phpversion(); ?></p>
</body>
</html>
EOF
```

## Estratègies d'Imatge: Bootstrap Dinàmic vs Golden AMI

A l'hora d'escalar servidors web ràpidament davant pics de demanda sobtats, existeixen dues estratègies contraposades:

```
+-------------------------------------------------------------------------+
|                  ESTRATÈGIES D'APROVISIONAMENT WEB                      |
+------------------------------------+------------------------------------+
|   Opció A: Bootstrap pur (User Data)|   Opció B: Golden AMI (Imatge d'Or) |
+------------------------------------+------------------------------------+
| - AMI base estàndard d'AWS.        | - Imatge prèviament compilada amb  |
| - A cada arrencada es descarreguen |   totes les dependències i codi ja |
|   paquets amb apt/dnf i git.       |   preinstal·lats al disc.          |
| - Desavantatge: Triga de 3 a 7 min | - Avantatge: La màquina arrenca i  |
|   a estar disponible i depèn de la |   està llesta per servir trànsit   |
|   xarxa externa per a paquets.     |   en menys de 30 segons.           |
+------------------------------------+------------------------------------+
```

En entorns d'alta disponibilitat i grups d'Auto Scaling amb balanceig de càrrega, **la millor pràctica és combinar una Golden AMI** (que conté el 95% del sistema base i llibreries pesades) **amb un petit script User Data final** (que obté l'última versió del codi font o secrets de configuració).
