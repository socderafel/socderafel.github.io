# 4.6 Empaquetado de classes i llibreries (packages)

Conforme els nostres programes es van fent més grans, el número de classes va crecent. Introduir totes les classes en un únic directori no ajuda a que estiguen bé organitzades, el millor és fer grups de classes, de forma que totes les classes que estiguen relacionades o traten sobre un mateix tema estiguen en el mateix grup.

Un **paquet** de classes és una agrupació de classes que considerem que estan relacionades entre sí o tracten d'un tema comú.

> **📌 Accés a mètodes d'un mateix paquet**
> 

> Les classes d'un mateix paquet tenen un accés privilegiado als atributs i mètodes d'altres classes d'aquest paquet. És per això per la qual cosa es considera que els paquets són també, en cert mode, unitats d'encapsulació i ocultació d'informació.

Java ens ajuda a organitzar les classes en paquets. En cada fitxer `.java` que fem, al principi, podem indicar a què paquet pertany la classe que fem en eixe fitxer.

Els paquets es declaran utilitzant la paraula clau `package` seguida del nom del paquet.

Per a establir el paquet al que pertany una classe cal posar una sentència de declaració com la següent al principi de la classe:

```java
package Nombre_de_Paquete;
```

Per exemple, si decidimos agrupar en un paquet `ejemplos` un programa anomenat `Bienvenida`, pondríamos en el nostre fitxer `Bienvenida.java` el següent:

```java
package ejemplos;

public class Bienvenida {
    [...]
}
```

El codi és exactament igual que com hem vingut fent fins a ara, solament hem afegit la línia `package ejemplos;` al principi.

## Sentència `import`

Quan volem utilitzar una classe que està en un paquet distint a la classe que estem utilitzant, es sol utilitzar la sentència `import`. Per exemple, si volem utilitzar la classe `Scanner` que està en el paquet `java.util` de la Biblioteca de Classes de Java, haurem d'utilitzar aquesta sentència:

```java
import java.util.Scanner;
```

Es poden importar totes les classes d'un paquet, així:

```java
import java.awt.*;
```

Aquesta sentència ha d'aparèixer al principi de la classe, justo després de la sentència package, si ésta existiese.

També podem utilitzar la classe sense sentència `import`, en del qual cas cada vegada que vulguem usar-l'hem d'indicar la seua ruta completa:

```java
java.util.Scanner teclado = new java.util.Scanner (System.in);
```

Fins a ací tot correcte. No obstant això, al treballar amb paquets, Java ens obliga a organitzar els directoris, compilar i executar de certa forma perquè tot funcione adequadament.

## Llibreries Java

Quan descargamos l'entorn de compilació i ejecució de Java, obtenim la API de Java. Com ja sabem, es tracta d'un conjunt de bibliotecas que ens proporciona paquets de classes útils per als nostres programes. Utilitzar les classes i mètodes de la Biblioteca de Java ens va ayudar a reduir el temps de desenvolupament considerablement, per la qual cosa és important que aprendamos a consultar-la i conozcamos les classes més utilitzades. Exemple:

```java
import java.lang.System; // Se importa la clase System.
import java.awt.*;       // Se importa todas las clases del paquete awt;
```

Els paquets més importants que ofereix el llenguatge Java són:

| Paquet o llibreria | Descripció |
| --- | --- |
| **java.io** | Conté les classes que gestionen l'entrada i eixida, ja siga per a manipular fitxers, llegir o escriure en pantalla, en memòria, etc. Aquest paquet conté per exemple la classe BufferedReader que s'utilitza per a l'entrada per teclat. |
| **java.lang** | Conté les classes bàsiques del llenguatge. Aquest paquet no és necessari importar-lo, ja que és importado automàticament pel entorn d'ejecució. En aquest paquet es troba la classe Object, que serveix com arrel per a la jerarquia de classes de Java, o la classe System que ja hem utilitzat en alguns exemples i que representa al sistema en el que es està executant l'aplicació. També podem trobar en aquest paquet les classes que "envuelven" els tipus primitius de dades. El que proporciona una sèrie de mètodes per a cada tipus de dada d'utilitat, com per exemple les conversions de dades. |
| **java.util** | Biblioteca de classes d'utilitat general per al programador. Aquest paquet conté per exemple la classe Scanner utilitzada per a l'entrada per teclat de diferents tipus de dades, la classe Date, per al tractament de dates, etc. |
| **java.math** | Conté eines per a manipulacions matemàtiques. |
| **java.awt** | Inclou les classes relacionades amb la construcció d'interfícies d'usuari, és a dir, les que ens permeten construir finestres, caixes de text, botons, etc. Algunes de les classes que podem trobar en aquest paquet són Button, TextField, Frame, Label, etc. |
| **java.swing** | Conté un altre conjunt de classes per a la construcció d'interfícies avançades d'usuari. Els components que es engloban dins d'aquest paquet es denominen components Swing, i suponen una alternativa molt més potent que AWT per a construir interfícies d'usuari. |
| **java.net** | Conjunt de classes per a la programació en la xarxa local i Internet. |
| **java.sql** | Conté les classes necessàries per a programar en Java l'accés a les bases de dades. |
| **java.security** | Biblioteca de classes per a implementar mecanismes de seguretat. |

Com es pot comprovar Java ofereix una completa jerarquia de classes organitzades a través de paquets.
