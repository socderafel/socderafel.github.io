## 1. Concepte i Justificació de Varargs (Java 5+)

Abans de la introducció dels **arguments variables (*Varargs*)** en Java 5, si un mètode havia de poder rebre un nombre indefinit de paràmetres, el programador estava obligat a crear prèviament un array de manera explícita abans de cridar el mètode:

```java
// Enfocament antic incòmode
int[] arguments = new int[]{10, 20, 30};
calcularSuma(arguments);
```

Amb la sintaxi de punts suspensius `Tipus... nomVariable`, Java permet invocar el mètode passant una llista arbitrària d'arguments separats per comes, o fins i tot passar un array directament o no passar cap argument:

```java
public class UtilitatsCalcul {

    /**
     * Calcula la suma de qualsevol quantitat d'arguments enters.
     */
    public static int sumar(int... valors) {
        int acumulador = 0;
        // Internament, la variable 'valors' es gestiona exactament com un int[]
        for (int v : valors) {
            acumulador += v;
        }
        return acumulador;
    }

    public static void main(String[] args) {
        System.out.println(sumar());                  // 0 arguments -> Retorna 0
        System.out.println(sumar(10));                // 1 argument  -> Retorna 10
        System.out.println(sumar(10, 20, 30, 40, 50));// 5 arguments -> Retorna 150
        
        int[] notes = {8, 9, 10};
        System.out.println(sumar(notes));             // Admet també un array existent
    }
}
```

## 2. Regles Sintàctiques Específiques de Varargs

Perquè el compilador puga analitzar les signatures de forma unívoca sense cap ambigüitat:

1. **Un sol paràmetre Varargs per mètode:** Està terminantment prohibit declarar dos paràmetres variables en el mateix mètode (`void f(int... a, String... b)` és il·legal).
2. **Posició final obligatòria:** El paràmetre Varargs ha de ser **imperativament l'últim de la llista de paràmetres formals**.

```java
// Correcte: paràmetres fixos primer, Varargs al final
public static void registrarNotes(String nomAlumne, String modul, double... qualificacions) {
    System.out.printf("Alumne: %s | Mòdul: %s | Total Notes: %d%n", nomAlumne, modul, qualificacions.length);
}

// INCORRECTE: Error de compilació
// public static void metodeIncorrecte(int... dades, String nom) { }
```

---

## 3. Implementació Interna i Rendiment

Quan el compilador troba una invocació d'un mètode Varargs:
1. Construeix automàticament un array nou al Heap (`new Tipus[]{arg1, arg2, ...}`).
2. Empaqueta els arguments en l'array.
3. Transmet l'array creat al mètode.

*Implicació de rendiment:* Tot i la seua immensa comoditat sintàctica, en mètodes crítics d'alt rendiment que s'executen milions de vegades per segon en bucles estrets, crear un array nou en cada invocació pot saturar innecessàriament el Garbage Collector. En aquests casos extrems, s'acostuma a sobrecarregar versions de 1, 2 i 3 paràmetres fixos combinats amb la versió Varargs de reserva.
