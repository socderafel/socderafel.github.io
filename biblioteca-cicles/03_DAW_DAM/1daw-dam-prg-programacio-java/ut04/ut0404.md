# 4.4.1 Estructura i miembros d'una classe

En unitats anteriors ja es indicó que per a declarar una classe en Java s'usa la paraula reservada `class`. En la declaració d'una classe vas a trobar:

- **Capçalera de la classe**. Composta per una sèrie de modificadors d'accés, la paraula reservada `class` i el nom de la classe.

- **Cos de la classe**. En ell es especifican els distints miembros de la classe: atributs i mètodes. És a dir, el contingut de la classe.

```java
public class NombreDeLaClase [herencia] [interfaces]
{
    // Atributos de la clase
    ...

    // Métodos de la clase
    ...
}
```

El cos de la classe és on es declaran els atributs que caracteritzen als objectes de la classe i on es defineix i implementa el comportament d'aquests objectes; és a dir, on es declaran i implementan els mètodes.

## 1. Declaració d'una classe

La declaració d'una classe en Java té la següent estructura general:

```java
// Cabecera de la clase
[modificadores] class <NombreClase> [herencia] [interfaces] {
    // Cuerpo de la clase
    //    Declaración de los atributos
    //    Declaración de los métodos
}
```

Un exemple bàsic però complet podria ser:

```java
class Punto {
    // Atributos
    private int x,y;

    // Métodos
    int obtenerX () {
        return x;
    }
    int obtenerY() {
        return y;
    }
    void establecerX (int nuevoX) {
        x = nuevoX;
    }
    void establecerY (int nuevoY) {
        y = nuevoY;
    }
}
Math.random()
```

En aquest cas es tracta d'una classe molt senzilla en la que el cos de la classe (entre claus) conté el codi i les declaracions necessàries perquè els objectes que es construyan (basándose en aquesta classe) puguen funcionar apropiadament en un programa (declaracions d'atributs per a contindre l'estat de l'objecte i mètodes que implementen el comportament de la classe i els objectes creats a partir d'ella).

Si et fixes en els distints programes que es han desenvolupat en els exemples de les unitats anteriors, podràs observar que cada un d'eixos programes era en sí mateix una classe Java: es declaraven amb la paraula reservada `class` i contenían alguns atributs (variables) així com alguns mètodes (com a mínim el mètode `main`).

En l'exemple anterior hem vist el mínim que es ha d'indicar en la capçalera d'una classe (el nom de la classe i la paraula reservada `class`). Es pot proporcionar bastant més informació mitjançant modificadors i altres indicadors com per exemple el nom del seu superclase (si és que eixa classe hereda d'una altra), si implementa algun interfície i algunes coses més que irás aprendent poc a poc.

A l'hora d'implementar una classe Java (*escribirla en un fitxer amb un editor de textos o amb alguna eina integrada com per exemple VS Code, Netbeans o Eclipse*) has de tindre en compte: 

- Per convenio, es ha decidido que en llenguatge Java els noms de les classes han de de començar per una lletra mayúscula. Així, cada vegada que observes en el codi una paraula amb la primera lletra en mayúscula sabrás que es tracta d'una classe sense necessitat de tindre que cercar la seua declaració. A més, si el nom de la classe està format per diverses paraules, cada una d'elles també tindrà la seua primera lletra en mayúscula. Seguint aquesta recomanació, alguns exemples de noms de classes podrien ser: Recta, Circulo, Cotxe, CocheDeportivo, Jugador, JugadorFutbol, AnimalMarino, Animalacuatic, etc.

- El fitxer en el que es troba una classe Java ha de tindre el mateix nom que eixa classe si volem poder utilitzar-la des d'altres classes que es troben fora d'eixe fitxer (classe principal del fitxer).

- Tant la definició com la implementació d'una classe s'inclou en el mateix fitxer (fitxer `.java`). En altres llenguatges com per exemple C++, definició i implementació podrien anar en fitxers separats (*per exemple en C++, serien sendos fitxers amb extensions `.h` i `.cpp`*).

## 2. Capçalera d'una classe

En general, la declaració d'una classe pot incloure els següents elements i en el següent ordre:

1. **Modificadors** tals com `public`, `abstract` o `final`.

1. El **nom de la classe** (amb la primera lletra de cada paraula en majúscules, per convenio).

1. El **nom del seu classe madre** (*superclase*), si és que es especifica, precedido per la paraula reservada `extends` (*"estén" o "hereda de"*).

1. Una llista separada per comes de **interfícies** que són implementades per la classe, precedida per la paraula reservada `implements` ("implementa").

1. El cos de la classe, tancat entre claus `{...}`.

La sintaxi completa d'una capçalera (els quatre primers punts) queda de la forma:

```java
[modificadores] class <NombreClase> [extends <NombreSuperClase>][implements <NombreInterface1>][[implements <NombreInterface2>] ...] {
```

En l'exemple anterior de la classe Punt teníamos la següent capçalera:

```java
class Punto {
```

En aquest cas no hi ha modificadors, ni indicadors d'herència, ni implementació d'interfícies. Tan només la paraula reservada `class` i el nom de la classe. És el mínim que pot haver en la capçalera d'una classe.

L'herència i les interfícies les verás més avant. Veurem ara quins són els modificadors que es poden indicar al crear la classe i què efectes tenen. 

Els **modificadors** de classe són:

```java
[public] [final | abstract]
```

Vegem què significat té cada un d'ells:

- Modificador `public`: indica que la classe és visible (es poden crear objectes d'eixa classe) des de qualsevol una altra classe. És a dir, des de qualsevol una altra part del programa. Si no es especifica aquest modificador, la classe només podrà ser utilitzada des de classes que estiguen en el mateix paquet. El concepte de paquet el veurem més avant. **Només pot haver una classe public (classe principal) en un fitxer `.java`**. El resta de classes que es definan en eixe fitxer no seran públiques.

- Modificador `abstract`: indica que la classe és abstracta. **Una classe abstracta no és instanciable**. És a dir, no és possible crear objectes d'eixa classe (caldrà utilitzar classes que hereden d'ella). En aquest moment és possible que et parezca que no tinga sentit que açò puga succeir (*si no pots crear objectes d'eixa classe, per a què la vols?*), però pot resultar útil a l'hora de crear una jerarquia de classes. Açò el verás també més avant a l'estudiar el concepte d'herència.

- Modificador `final`: indica que no podràs crear classes que hereden d'ella. També volverás a aquest modificador quan estudies el concepte d'herència. **Els modificadors final i abstract són excluyentes (només es pot utilitzar un d'ells)**.

Tots aquests modificadors i paraules reservades les anirem veient poc a poc, així que no et preocupes massa per intentar entendre totes elles en aquest moment.

En l'exemple anterior de la classe Punt tindríem una classe que seria només visible (utilizable) des del mateix paquet en el que es troba la classe (modificador d'accés per omisió o de paquet, o `package`). Des de fora d'eixe paquet no seria visible o accesible. Per a poder utilitzar-la des de qualsevol part del codi del programa bastaría amb afegir l'atribut `public`: 

```java
public class Punto{
    ...
}
```

## 3. Cos d'una classe

Com ja has vist anteriorment, el cos d'una classe es troba tancat entre claus i conté la declaració i implementació dels seus miembros. Els miembros d'una classe poden ser:

- **Atributs**, que especifican els *dades* que podrà contindre un objecte de la classe.

- **Mètodes**, que implementan les *accions* que es podran realitzar amb un objecte de la classe.

Una classe pot no contindre en la seua declaració atributs o mètodes, però ha de de contindre almenys un dels dos (**la classe no pot ser buida***).

En l'exemple anterior on es definía una classe `Punto`, tindríem els següents atributs:

- Atribut `x`, de tipus `int`.

- Atribut `y`, de tipus `int`.

És a dir, dos valors de tipus enter. Qualsevol objecte de la classe `Punto` que siga creat emmagatzemarà en el seu interior dos números enters (`x` e `y`). Cada objecte diferent de la classe `Punto` contendrá sendos valors `x` e `y`, que podran coincidir o no amb el contingut d'altres objectes d'eixa mateixa classe `Punto`.

Per exemple, si es han declarat diversos objectes de tipus `Punto`:

```java
Punto p1, p2, p3;
```

Sabremos que cada un d'eixos objectes `p1`, `p2` i `p3` contendrán un parell de coordenades (`x`, `y`) que defineixen l'estat d'eixe objecte. Pot que eixos valors coincidan amb els d'altres objectes de tipus `Punto`, o pot que no, però en qualsevol cas seran objectes diferents creats a partir del mateix molde (de la mateixa classe).

D'altra banda, la classe `Punto` també definía una sèrie de mètodes:

- 

`java
  int obtenerX () {
      return x;
  }`

- 

`java
  int obtenerY() {
      return i;
  }`

- 

`java
  void establecerX (int nuevoX) {
      x= nuevoX; 
  }`

- 

`java
  void establecerY (int nuevoY) {
      i= nuevoY; 
  }`

Cada un d'eixos mètodes pot ser anomenat des de qualsevol objecte que siga una instància de la classe `Punto`. Es tracta d'operacions que permeten manipular les dades (*atributs*) continguts en l'objecte bé per a calcular altres dades o bé per a modificar els propis atributs.
