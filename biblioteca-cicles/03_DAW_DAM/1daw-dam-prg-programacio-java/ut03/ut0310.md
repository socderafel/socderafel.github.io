# 3.10 ExamenPRG

```java
public class ExamenPRG {

	public static void main(String[] args) {

		//1.- Crear calculadora

		Calculadora c1 = new Calculadora("src/ficheroExamen.txt");

		

		//2.- Cargar operaciones desde fichero

		c1.cargarFichero();

		

		//3.- Calcular el resultado de las operaciones

		for (Operacion operacion : c1.listaOperaciones) {

			operacion.calcular();

		}

		

		//4.- Imprimir las operaciones con el resultado

		for (Operacion operacion : c1.listaOperaciones) {

			System.out.println(operacion);

		}	

		//5.- Guardar las operaciones en fichero

		c1.guardarFichero();

		

	}

}
```
