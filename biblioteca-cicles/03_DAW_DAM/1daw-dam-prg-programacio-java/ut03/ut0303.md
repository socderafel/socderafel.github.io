# 3.2.2 Recorregut, cerca i ordenació en arrays

Molts dels algoritmes fonamentals en programació estructurada sobre arrays es classifiquen en tres grans categories:

  
- **a) Problemes de recorregut:** Exigen processar o examinar tots els elements de l'array (sumas, mitjanes, transformacions, conteos).
  
- **b) Problemes de cerca:** Determinan si existeix algun element que complisca una condició donada, deteniéndose en cuanto es halla.
  
- **c) Problemes d'ordenació:** Reorganizan els elements segons un criteri d'ordre (ascendent o descendent).

## a) Problemes de recorregut d'un array

Es consideran problemes de recorregut aquells que, per a la seua resolució, exigen el **tractament sistemátic de tots els elements de l'array**. El recorregut pot organizar-se de forma ascendent (d'esquerra a dreta), descendent (de dreta a esquerra) o amb passos específics.

### 1. Recorregut clàssic amb índex (bucle `for` tradicional)

Utilitza una variable entera `i` que actua com subíndice (`0, 1, ..., array.length - 1`):

> **📌 Exemple: Pluviositat Mitjana Ascendent**
> 

```java
public static double pluviosidadMediaAscendente(double lluvia[]) {
    double suma = 0;

    // Recorremos el array de forma ascendente con índice i (0 .. length-1)
    for (int i = 0; i < lluvia.length; i++) {
        suma += lluvia[i];
    }
    return suma / lluvia.length;
}
```

> **📌 Exemple: Recorregut Descendent i Càlcul de Màxim**
> 

> Per a recórrer de final a principi comenzamos en `lluvia.length - 1` i decrementamos fins a `0`:

```java
public static double pluviosidadMediaDescendente(double lluvia[]) {
    double suma = 0;

    // Recorremos el array de forma descendente (length-1 .. 0)
    for (int i = lluvia.length - 1; i >= 0; i--) {
        suma += lluvia[i];
    }
    return suma / lluvia.length;
}
```

> I per a hallar el valor màxim, inicializamos amb la primera posició i comparamos a partir de l'índex 1:

```java
public static double pluviosidadMaxima(double[] lluvia) {
    // Suponemos que el máximo se produjo el primer día
    double max = lluvia[0];

    // Recorremos desde la posición 1 comparando
    for (int i = 1; i < lluvia.length; i++) {
        if (lluvia[i] > max) {
            max = lluvia[i];
        }
    }
    return max;
}
```

### 2. El bucle `for-each` (Enhanced for loop)

A partir de Java 5, es introdujo una estructura de control especialitzada denominada **bucle for-each** o *bucle for mejorado*. El seu propòsit fonamental és **fer el codi més limpio, llegible i segur** quan necessitem recórrer una estructura de dades de principi a fi.

> **📌 💡 Per què usar `for-each`?**
> 

  
> - **Adiós als índexs manuals:** No necesitas declarar `int i = 0; i < array.length; i++`.
  
> - **Inmune a desbordaments:** És impossible cometer el típic error de novato `ArrayIndexOutOfBoundsException` (per exemple, escriure accidentalment `<= length`).
  
> - **Legibilitat directa:** Es llegix en llenguatge natural: *"Per a cada element de l'array, fes..."*.

#### Sintaxi general del `for-each`

```java
// Sintaxis general del bucle for-each
for (TipoElemento variableTemporal : arrayOEstructura) {
    // Código a ejecutar para cada elemento
    // "variableTemporal" toma automáticamente el valor de cada celda
}
```

#### Exemple comparativo: Calcular la mitjana amb `for-each`

Observa com la funció de pluviositat mitjana es redueix a la seua mínima expressió:

```java
public static double pluviosidadMediaForEach(double[] lluvia) {
    double suma = 0;

    // "Para cada valor 'dia' de tipo double que haya dentro del array 'lluvia'"
    for (double dia : lluvia) {
        suma += dia;
    }
    return suma / lluvia.length;
}
```

#### Recorregut d'arrays d'objectes i cadenes (`String[]`)

El bucle `for-each` brilla especialment amb arrays de referències a objectes, com llistes de noms:

```java
// Array de Strings (Objetos)
String[] alumnos = {"Marc", "Laia", "Pau", "Elena", "Vicent"};

// Recorrido limpio sin necesidad de índices
for (String alumno : alumnos) {
    System.out.println("Alumno matriculado: " + alumno.toUpperCase());
}
```

### 3. Com recórrer un `String` amb `for-each`?

> **📌 🔍 Pregunta freqüent en classe: *"Puc usar for-each directament sobre un String?"***
> 

> En Java, `String` és un objecte de text inmutable i **no implementa directament la interfície Iterable**. Per tant, escriure `for (char c : "Hola")` provoca un error de compilació immediat.

> No obstant això, ara que dominas els arrays, dispones de dos solucions inmediatas molt potents:

#### Opció A: Recórrer caràcter a caràcter amb `.toCharArray()`

El mètode `toCharArray()` de la classe `String` genera un array estàtic `char[]` que sí podem recórrer limpiament amb `for-each`:

```java
String texto = "IES Mestre Ramon Esteve";
int vocales = 0;

// ❌ for (char c : texto) -> ¡ERROR DE COMPILACIÓN! String no es directamente un array

// ✅ Convertimos el String a un array de caracteres char[] con .toCharArray()
for (char c : texto.toLowerCase().toCharArray()) {
    if ("aeiouáàéèíóòú".indexOf(c) != -1) {
        vocales++;
    }
}

System.out.println("Total de vocales: " + vocales);
```

#### Opció B: Recórrer paraula a paraula amb `.split()`

Si el que deseamos és processar cada paraula d'una frase, `split(" ")` trocea el text devolvent un `String[]`:

```java
String frase = "Programar en Java mola molt";

// .split(" ") divide el texto por espacios y devuelve un String[]
for (String palabra : frase.split(" ")) {
    System.out.println("Palabra: " + palabra + " (" + palabra.length() + " letras)");
}
```

### 4. ⚠️ CURA! La trampa d'examen: El `for-each` és de NOMÉS LECTURA

> **📌 💥 Error clàssic de principiante: Intentar modificar l'array dins d'un `for-each`**
> 

> En cada iteració del bucle `for-each`, la variable del bucle rep una **CÒPIA** del valor contingut en la cel·la de l'array. **Modificar la variable local no modifica l'array original**:

```java
int[] notas = {4, 5, 3};

// ❌ INTENTO FALLIDO: Intentar modificar el array con for-each
for (int n : notas) {
    n = n + 1; // ¡Solo modifica la variable local 'n'! NO altera el array.
}
// El array 'notas' sigue siendo {4, 5, 3}

// ✅ FORMA CORRECTA: Si necesitas modificar celdas, usa el 'for' con índice:
for (int i = 0; i < notas.length; i++) {
    notas[i] = notas[i] + 1; // Acceso directo a la celda de memoria
}
// Ahora el array 'notas' sí es {5, 6, 4}
```

### 5. Taula de Decisió: Quan usar `for` clàssic i quan `for-each`?

Utilitza aquesta guía ràpida per a saber exactament què bucle escollir en cada situació:

| Situació de programació | Bucle ideal | Justificació tècnica |
| --- | --- | --- |
| **Només lectura / Recorregut total** Calcular sumas, mitjanes, mostrar dades, cercar el valor màxim | ✅ for-each | Codi molt més limpio i conciso. Impossible sufrir `ArrayIndexOutOfBoundsException`. |
| **Modificar les cel·les de l'array** Assignar nous valors: `array[i] = valor;` | ⚙️ for clàssic | El `for-each` només té una còpia local del valor. Per a escriure en memòria fa falta l'índex `[i]`. |
| **Necesitas saber la posició exacta** Ej: "El client moroso es troba en la posició 4" | ⚙️ for clàssic | El `for-each` no expone l'índex de la iteració actual. |
| **Recorregut invers o amb salts** Del final al principi (`i--`) o de dos en dos (`i += 2`) | ⚙️ for clàssic | El `for-each` recorre estrictament d'esquerra a dreta d'un en un. |
| **Recórrer 2 arrays en paralelo** Ej: `nombres[i]` i `calificaciones[i]` | ⚙️ for clàssic | Es necessita el mateix índex `i` per a coordinar totes dues estructures de dades. |
| **Estructures Dinàmiques (Tema 3.5: List, Set...)** Recórrer col·leccions dinàmiques de Java (JCF) | 🌟 for-each | És l'estàndard universal de Java per a recórrer qualsevol estructura que implement `Iterable`. |

> **📌 🔗 Connexió pedagógica amb les Estructures Dinàmiques (Tema 3.5)**
> 

> El bucle `for-each` cobra encara major relevancia quan es estudian les col·leccions dinàmiques (com `ArrayList`, `HashSet` o `LinkedList` en el Tema 3.5). La mateixa sintaxi que acabamos de veure per a arrays estátics funciona d'idéntica manera per a qualsevol col·lecció de Java gràcies a la interfície `Iterable`.

## b) Problemes de cerca en arrays

Es denominen problemes de cerca a aquells que determinan **si existeix algun element que complisca certa propietat** dins de l'array. A diferència del recorregut complet, en la cerca **no sempre és necessari examinar tot l'array**: l'element pot hallar-se en la primera posició, en mitjà, o no existir.

### 1. Cerca ascendent (Cerca seqüencial)

Iniciamos en l'índex 0 i avanzamos fins a trobar la coincidencia o agotar l'array:

> **📌 Exemple: Primer dia sense lluvia**
> 

```java
// Devolvemos el subíndice del primer componente cuyo valor sea cero
// Si ningún día fue cero, devolvemos -1
public static int primerDiaSinLluvia(double lluvia[]) {
    int i = 0;
    boolean encontrado = false;

    while (i < lluvia.length && !encontrado) {
        if (lluvia[i] == 0) {
            encontrado = true;
        } else {
            i++;
        }
    }

    if (encontrado) {
        return i;
    } else {
        return -1;
    }
}
```

### 2. Cerca descendent

Partim de la última posició (`array.length - 1`) i retrocedemos cap a la posició 0:

> **📌 Exemple: Últim dia sense lluvia**
> 

```java
public static int ultimoDiaSinLluvia(double lluvia[]) {
    int i = lluvia.length - 1;
    boolean encontrado = false;

    while (i >= 0 && !encontrado) {
        if (lluvia[i] == 0) {
            encontrado = true;
        } else {
            i--;
        }
    }

    if (encontrado) {
        return i;
    } else {
        return -1;
    }
}
```

### 3. Cerca binària o dicotómica (Arrays Ordenats)

Si l'array ja es troba **prèviament ordenat**, la cerca seqüencial element a element resulta ineficiente. La **cerca binària** divideix l'espai de cerca a la mitad en cada pas, logrant una eficiència de **O(log₂ N)** (en un array de 1.000.000 d'elements, requereix un màxim de 20 comparacions en lloc d'un milió).

> **📌 Exemple: Cerca binària d'edades**
> 

```java
public static boolean hayAlguienDe36(int edad[]) {
    // 'izq' y 'der' acotan el subintervalo de búsqueda
    int izq = 0;
    int der = edad.length - 1;
    boolean encontrado = false;

    while (izq <= der && !encontrado) {
        int m = (izq + der) / 2; // Posición central
        if (edad[m] == 36) {
            encontrado = true; // ¡Encontrado!
        } else if (edad[m] > 36) {
            der = m - 1;       // Buscar en la mitad izquierda
        } else {
            izq = m + 1;       // Buscar en la mitad derecha
        }
    }

    return encontrado;
}
```

## c) Problemes d'ordenació en arrays

Permeten reorganitzar les dades de menor a major o viceversa. Es divideixen en algoritmes iterativos (burbuja, selecció directa, inserció) i algoritmes recursivos divideix i vencerás (mergeSort, quickSort).

### Mètode de Selecció Directa (Selection Sort)

En cada iteració `i`, cerca l'element menor que queda a la dreta i intercambia posicions:

```java
public static void seleccionDirecta(int v[]) {
    for (int i = 0; i < v.length - 1; i++) {
        // Localizamos el elemento mínimo que debe ocupar la posición i
        int posMin = i;
        for (int j = i + 1; j < v.length; j++) {
            if (v[j] < v[posMin]) {
                posMin = j;
            }
        }
        // Intercambio de valores (swap)
        int aux = v[posMin];
        v[posMin] = v[i];
        v[i] = aux;
    }
}
```
