## 1. El Bucle while: Avaluació Pre-Test

El bucle `while` avalua la seua condició de control **abans** d'entrar al cos del bloc d'instruccions. Si la condició avalua a `false` des del primer moment, **el cos del bucle mai s'arriba a executar**.

```java
int intentsRestants = 3;

while (intentsRestants > 0) {
    System.out.println("Intent número: " + (4 - intentsRestants));
    // Pas d'actualització CRÍTIC cap a la condició de sortida:
    intentsRestants--;
}
```

### Prevenció de Bucles Infinits
Un bucle infinit és una fallada algorítmica greu on la condició de permanència roman permanentment en `true`, consumint el 100% d'un fil de CPU i bloquejant l'aplicació. Per a garantir la finitud:
1. Ha d'existir una o més variables de control.
2. La condició ha de dependre d'eixes variables.
3. A l'interior del cos del bucle **ha d'existir una modificació que acoste progressivament l'estat cap a la condició de terminació**.

## 2. El Bucle do-while: Avaluació Post-Test

El bucle `do-while` inverteix l'ordre d'avaluació: primer s'executa el cos d'instruccions i **al final de la volta s'avalua la condició**. Com a conseqüència matemàtica, **el cos s'executa sempre com a mínim 1 vegada**, fins i tot si la condició és falsa des del principi.

```java
import java.util.Scanner;

Scanner teclat = new Scanner(System.in);
int opcio;

do {
    System.out.println("
=== MENÚ PRINCIPAL ===");
    System.out.println("1. Donar d'alta un alumne");
    System.out.println("2. Consultar expedient");
    System.out.println("0. Sortir");
    System.out.print("Tria una opció: ");
    
    opcio = teclat.nextInt();
} while (opcio != 0); // Atenció: requereix obligatòriament punt i coma al final!

System.out.println("Gràcies per utilitzar l'aplicació.");
```

## 3. Taula Comparativa: while vs do-while

| Característica | Bucle `while` (Pre-Test) | Bucle `do-while` (Post-Test) |
| :--- | :--- | :--- |
| **Moment de comprovació** | Abans d'entrar a cada iteració. | Al final de cada iteració. |
| **Mínim d'execucions** | **0 vegades** (pot no entrar mai). | **1 vegada** (garantida). |
| **Sintaxi de tancament** | `while (cond) { ... }` (sense `;`) | `do { ... } while (cond);` (requereix `;` final) |
| **Casos d'ús típics** | Lectura de fitxers, cerca de registres en xarxa, algorismes matemàtics de convergència. | Validació d'entrades de formulari per teclat, menús interactius de consola. |
