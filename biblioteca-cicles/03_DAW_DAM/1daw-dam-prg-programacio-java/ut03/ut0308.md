# 3.8 TableroTest

```java
public class TableroTest {

	public static void main(String[] args) {

		TableroLeds tled1 = new TableroLeds(3,3);

		tled1.mostrar();

		

		tled1.encenderLed(1, 1);

		tled1.encenderLed(3,3);

		

		tled1.mostrar();

		

		tled1.encenderLed(4,4);

		

		tled1.apagarLed(0,0);

		tled1.apagarLed(1,1);

		

		tled1.mostrar();

	}

}
```
