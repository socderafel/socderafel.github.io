## 1. El Switch Tradicional i el Perill del Fall-Through

La sentència `switch` s'utilitza per a seleccionar una branca d'execució entre múltiples alternatives en funció del valor exacte d'una variable. Tipus permesos: `byte`, `short`, `char`, `int`, enumerats `enum` i cadenes `String` (des de Java 7).

En el format clàssic heretat de C, les branques utilitzen dos punts `:` i requereixen la paraula clau `break`. Si s'oblida el `break`, s'esdevé el fenomen de **caiguda accidental (*fall-through*)**: l'execució continua caient per les línies del cas següent encara que la seua etiqueta no coincidisca.

```java
// Format Clàssic (Vulnerable a fall-through)
int diaSetmana = 1;
switch (diaSetmana) {
    case 1:
        System.out.println("Dilluns");
        break; // Imprescindible! Si s'omet, imprimiria també "Dimarts"
    case 2:
        System.out.println("Dimarts");
        break;
    default:
        System.out.println("Altre dia");
        break;
}
```

## 2. La Revolució de Java 14: Switch Expressions amb Fletxa (`->`)

A partir de Java 14, el W3C i el comitè JCP van estandarditzar les **Switch Expressions**, una de les millores sintàctiques més elegants del llenguatge:
- Utilitza la sintaxi de fletxa `->`.
- **Elimina completament el fall-through**: s'executa exclusivament la instrucció o bloc de la dreta de la fletxa sense necessitat d'escriure cap `break`.
- Admet múltiples etiquetes separades per coma en una sola línia.
- **Pot actuar com una expressió que retorna directament un valor** a una variable.

```java
String tipusDia = switch (diaSetmana) {
    case 1, 2, 3, 4, 5 -> "Laborable";
    case 6, 7          -> "Cap de setmana";
    default            -> "Dia no vàlid";
};
```

---

## 3. Retorn de Valors en Blocs Multilínia: La Paraula Clau `yield`

Quan la lògica d'un cas concret necessita executar diversos càlculs previs abans de generar el valor de sortida, s'empren claus `{ }` i s'utilitza la paraula clau `yield` per a emetre el resultat de l'expressió:

```java
int codiModul = 101;

int horesLectives = switch (codiModul) {
    case 101 -> {
        System.out.println("Mòdul troncal de primer curs.");
        yield 256; // Retorna 256 com a resultat de l'expressió
    }
    case 102 -> 192;
    case 103 -> 96;
    default -> {
        System.err.println("Codi desconegut.");
        yield 0;
    }
};
```
