## 1. Concepte d'Array en Java com a Objecte del Heap

Un **array** és una estructura de dades homogènia (tots els seus elements són del mateix tipus), de mida estàtica fixa i ordenada seqüencialment per un índex numèric que comença sempre en la posició `0`.

A diferència de llenguatges de baix nivell com C, on un array és un punter nu sense control, en Java un array és un **autèntic objecte gestionat per la JVM** que s'allotja a la memòria dinàmica (*Heap*), amb comprovació estricta de límits en temps d'execució (*bounds checking*) i metadades com el camp immutable `.length`.

```java
// 1. Declaració (Només reserva la variable de referència a la pila Stack)
int[] qualificacions; // Sintaxi estàndard preferida en Java
// int qualificacions[]; // Sintaxi estil C (desaconsellada)

// 2. Instanciació (Reserva física de l'objecte al Heap mitjançant l'operador new)
qualificacions = new int[5]; // Array de 5 enters

// 3. Declaració, instanciació i inicialització amb literals (Inline)
String[] moduls = {"PRG", "BBDD", "LMSGI", "ED", "SI"};
```

---

## 2. Valors d'Inicialització per Defecte

Quan un array s'instancia amb `new Tipus[mida]`, la JVM inicialitza automàticament totes les seues posicions als seus valors neutres de memòria:
- Tipus numèrics (`byte`, `short`, `int`, `long`): s'inicialitzen a `0`.
- Tipus de coma flotant (`float`, `double`): s'inicialitzen a `0.0`.
- Caràcters (`char`): s'inicialitzen a `'\u0000'` (caràcter nul).
- Booleans (`boolean`): s'inicialitzen a `false`.
- Tipus objectes o de referència (`String`, classes pròpies): s'inicialitzen a `null`.

---

## 3. Accés per Índex i l'Atribut length

L'accés a cada posició s'efectua mitjançant claudàtors `array[index]`:
- El primer element es troba a l'índex `0`.
- L'últim element es troba a l'índex `array.length - 1`.

> [!CAUTION] L'Excepció ArrayIndexOutOfBoundsException
> Si s'intenta accedir a un índex negatiu (`array[-1]`) o a un índex igual o superior a la seua longitud (`array[array.length]`), la JVM avorta immediatament la instrucció llançant una **`java.lang.ArrayIndexOutOfBoundsException`**. Això impedeix atacs de seguretat de desbordament de buffer (*buffer overflow*) habituals en altres llenguatges.
