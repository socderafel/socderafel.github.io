## 1. Algorismes de Cerca sobre Vectors

La cerca és l'operació algorítmica que consisteix a localitzar la posició d'un element clau dins d'una col·lecció o determinar la seua absència:

### Cerca Lineal o Seqüencial
Recorre l'array d'esquerra a dreta comparant cada element amb el valor buscat:
- **Requisit:** Cap. Funciona sobre arrays desordenats.
- **Complexitat:** $O(N)$ en el pitjor dels casos (cal comparar tots els elements).

```java
public static int cercaLineal(int[] dades, int clau) {
    for (int i = 0; i < dades.length; i++) {
        if (dades[i] == clau) {
            return i; // Retorna la posició de la primera coincidència
        }
    }
    return -1; // Retorna -1 si no s'ha trobat
}
```

### Cerca Binària (Dicotòmica)
Aplica la tècnica de «Divideix i Venceràs»: compara el valor buscat amb l'element central de l'interval; si és menor, descarta la meitat dreta; si és major, descarta l'esquerra:
- **Requisit OBLIGATORI:** L'array ha d'estar **prèviament ordenat**.
- **Complexitat:** $O(\log N)$. Per a 1.000.000 d'elements, troba el valor en com a màxim 20 comparacions!

```java
public static int cercaBinaria(int[] dades, int clau) {
    int esquerra = 0;
    int dreta = dades.length - 1;

    while (esquerra <= dreta) {
        int mig = esquerra + (dreta - esquerra) / 2; // Evita overflow d'enters
        if (dades[mig] == clau) return mig;
        if (dades[mig] < clau) esquerra = mig + 1;
        else dreta = mig - 1;
    }
    return -1;
}
```

## 2. L'Algorisme d'Ordenació per Bombolla (Bubble Sort)

L'**ordenació per bombolla** és l'algorisme pedagògic clàssic que recorre repetidament l'array, comparant elements adjacents i intercanviant-los (*swap*) si estan en l'ordre incorrecte. En cada passada completa, l'element més gran «puja com una bombolla» cap a la seua posició final a la dreta:

```java
public static void ordenarPerBombolla(int[] dades) {
    int n = dades.length;
    boolean hiHaHagutIntercanvis;

    for (int i = 0; i < n - 1; i++) {
        hiHaHagutIntercanvis = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (dades[j] > dades[j + 1]) {
                // Intercanvi (Swap) mitjançant variable auxiliar
                int temporal = dades[j];
                dades[j] = dades[j + 1];
                dades[j + 1] = temporal;
                hiHaHagutIntercanvis = true;
            }
        }
        // Optimització: si en una passada no s'ha fet cap canvi, l'array ja està ordenat!
        if (!hiHaHagutIntercanvis) break;
    }
}
```

*Anàlisi de Rendiment:* Complexitat de $O(N^2)$. És un algorisme ineficient per a grans volums de dades en comparació amb algorismes avançats com Quicksort o Mergesort ($O(N \log N)$), però molt útil per la seua senzillesa i caràcter *in-place* (no requereix memòria auxiliar).
