## El Problema Històric de l'Alliberament de Recursos

Fins a Java 6, el patró estàndard per a tancar fitxers, sockets de xarxa o connexions a bases de dades requeria un bloc `finally` amb comprovacions feixugues de punters nuls i nous blocs `try-catch` anidats, donant lloc a un codi propens a errors i fuites de recursos:

```java
// Forma antiga i feixuga (Java 6 i anteriors)
Scanner scanner = null;
try {
    scanner = new Scanner(new File("dades.txt"));
    // Operacions de lectura...
} catch (FileNotFoundException e) {
    System.err.println("Fitxer no trobat.");
} finally {
    if (scanner != null) {
        scanner.close(); // Si això fallava, requeria altre try-catch intern!
    }
}
```

---

## La Solució Moderna: `try-with-resources` (ARM)

Introduït en Java 7 (*Automatic Resource Management*), permet declarar i instanciar els recursos **dins dels parèntesis de la instrucció `try`**. La màquina virtual garanteix que tots els recursos oberts es **tancaran automàticament** en finalitzar el bloc (amb èxit o amb excepció), en ordre invers al de la seua obertura:

```java
// Forma moderna, neta i segura (Java 7+)
try (Scanner scanner = new Scanner(new File("dades.txt"));
     PrintWriter writer = new PrintWriter(new File("eixida.txt"))) {
    while (scanner.hasNextLine()) {
        writer.println(scanner.nextLine().toUpperCase());
    }
} catch (IOException e) {
    System.err.println("Error operant amb els fitxers: " + e.getMessage());
}
// scanner i writer han sigut tancats de manera automàtica i segura pel compilador!
```

---

## La Interfície `java.lang.AutoCloseable`

Perquè un objecte puga ser gestionat per un `try-with-resources`, la seua classe ha d'implementar la interfície `AutoCloseable`, la qual conté un únic mètode:

```java
public interface AutoCloseable {
    void close() throws Exception;
}
```

Podem crear els nostres propis serveis gestionables automàticament:

```java
public class ConnexioSensor implements AutoCloseable {
    public ConnexioSensor(String adrecaIp) {
        System.out.println("Obrint connexió amb sensor a " + adrecaIp);
    }

    public double llegirTemperatura() {
        return 23.5;
    }

    @Override
    public void close() {
        System.out.println("Tancant el canal del sensor i alliberant port.");
    }
}
```
