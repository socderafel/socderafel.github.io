El usuario irá introduciendo números por teclado, y el ordenador le irá dando pistas: "mi número es mayor" o "mi número es menor", hasta que el usuario acierte. Entonces el ordenador le felicitará y le comunicará el número de intentos que necesitó para acertar el número secreto.

A continuación podéis ver como funciona la clase Random. El siguiente algoritmo imprime por pantalla 5 números aleatorios comprendidos entre 0 y 100.

```java
import java.util.Random;
public class ClaseRandom {
public static void main(String[] args) {
Random x = new Random();
for(int i=0; i<5; i++){
System.out.println(x.nextInt(100));
}
}
}
```
