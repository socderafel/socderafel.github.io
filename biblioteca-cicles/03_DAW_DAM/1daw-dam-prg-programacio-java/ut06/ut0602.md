## 1. La Interfície List<E> i el Concepte de Seqüència Indexada

Una **Llista (`List<E>`)** és una col·lecció ordenada seqüencialment que:
- Permet **elements duplicats**.
- Conserva rigorosament l'**ordre d'inserció** dels elements.
- Permet l'**accés posicional basat en un índex numèric de base 0** mitjançant els mètodes `get(index)` i `set(index, element)`.

Les dues implementacions fonamentals del JCF són **`ArrayList`** i **`LinkedList`**.

---

## 2. ArrayList: El Vector Dinàmic Redimensionable

Internament, una instància de `ArrayList` manté un array estàndard `Object[]`:
- **Capacitat Inicial:** Per defecte té una capacitat per a 10 elements.
- **Creixement Dinàmic:** Quan l'array intern s'omple, la classe crea automàticament un nou array un 50% més gran ($	imes 1.5$), copia tots els elements antics mitjançant una operació de memòria d'alta velocitat (`System.arraycopy`) i descarta l'anterior.

```java
import java.util.List;
import java.util.ArrayList;

// Programem cap a la interfície List!
List<String> ciutats = new ArrayList<>();

ciutats.add("València"); // Afegeix al final (Temps amortitzat O(1))
ciutats.add("Alacant");
ciutats.add("Castelló de la Plana");

ciutats.add(1, "Gandia"); // Insereix a l'índex 1 (Desplaça la resta cap a la dreta: O(N))
String primera = ciutats.get(0); // Accés directe immediat en temps constant: O(1)
ciutats.remove("Alacant"); // Cerca i eliminació amb desplaçament: O(N)
```

## 3. LinkedList: La Llista Doblement Enllaçada

A diferència de l'ArrayList, un `LinkedList` no utilitza cap array continu en memòria. Cada element es guarda a l'interior d'un objecte independent anomenat **Node**, que emmagatzema la dada i conté **dos punters (referències)**:
- Un punter cap al node anterior (`prev`).
- Un punter cap al node següent (`next`).

A més d'implementar `List`, `LinkedList` implementa la interfície `Deque<E>` (cua de doble extrem), fet que la fa ideal per a implementar **Piles (Stacks)** i **Cues (Queues)** amb els mètodes `addFirst()`, `addLast()`, `pollFirst()`, `pollLast()`.

### Taula de Complexitat Temporal (Notació Big-O)

| Operació | `ArrayList` | `LinkedList` | Raonament Tècnic |
| :--- | :--- | :--- | :--- |
| **Accés per índex (`get(i)`)** | **$O(1)$ (Instantani)** | $O(N)$ (Lent) | ArrayList calcula la posició a la memòria en 1 cicle; LinkedList ha de recórrer els nodes d'un en un des de l'inici. |
| **Inserció al final (`add(e)`)**| **$O(1)$ amortitzat** | **$O(1)$** | Ambdues són ràpides al final. |
| **Inserció al principi (`add(0, e)`)** | $O(N)$ | **$O(1)$** | ArrayList ha de moure tots els elements cap a la dreta; LinkedList només canvia dos punters de memòria. |
| **Consum de Memòria RAM** | **Molt baix i compacte** | Alt | LinkedList consumeix el triple de memòria per l'overhead de crear un objecte Node amb dos punters per cada dada. |
