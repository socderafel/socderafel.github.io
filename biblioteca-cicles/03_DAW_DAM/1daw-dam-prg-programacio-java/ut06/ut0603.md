## 1. La Interfície Set<E> i el Concepte de Conjunt Matemàtic

La interfície **`Set<E>`** modela l'abstracció matemàtica d'un conjunt d'elements:
- **No admet mai elements duplicats**: si intentem afegir un element que ja existeix, el mètode `add()` el rebutja retornant `false` sense alterar el conjunt.
- **No disposa d'accés per índex numèric**: no existeixen mètodes `get(i)` ni `set(i, e)`.

---

## 2. HashSet: Velocitat Màxima mitjançant Taules Hash

`HashSet` és la implementació més ràpida i utilitzada de `Set`:
- **Rendiment:** Inserció, cerca (`contains`) i eliminació en **temps constant $O(1)$**.
- **Ordre:** **No garanteix cap ordre**; els elements poden aparèixer en un ordre completament caòtic o canviar en afegir nous elements.

```java
import java.util.Set;
import java.util.HashSet;

Set<String> dniAlumnat = new HashSet<>();
dniAlumnat.add("12345678A");
dniAlumnat.add("87654321B");
boolean afegit = dniAlumnat.add("12345678A"); // Retorna FALSE! Rebutja el duplicat automàticament.
```

### El Contracte Obligatori: `equals()` i `hashCode()`
Perquè un `HashSet` funcione correctament amb classes pròpies (com una classe `Alumne`), és **estrictament obligatori sobreescriure ambdós mètodes**:
1. Si dos objectes són iguals segons `equals()`, han de retornar obligatòriament exactament el mateix número enter en `hashCode()`.
2. Si falla aquesta regla, `HashSet` emmagatzemarà duplicats en recipients (*buckets*) diferents, trencant la integritat de dades.

---

## 3. TreeSet: Conjunts Ordenats sobre Arbres Roig-Negre

`TreeSet` implementa la subinterfície `NavigableSet`:
- **Elements Únics i Sempre Ordenats:** Els elements s'ordenen automàticament segons el seu ordre natural (mitjançant la interfície `Comparable`) o un `Comparator` personalitzat.
- **Estructura Interna:** Arbre binari de cerca autobalançat (**Arbre Roig-Negre** / *Red-Black Tree*).
- **Rendiment:** Temps logarítmic **$O(\log N)$** per a operacions d'inserció i cerca.

```java
import java.util.Set;
import java.util.TreeSet;

Set<Integer> puntuacions = new TreeSet<>();
puntuacions.add(50);
puntuacions.add(10);
puntuacions.add(80);

// En recórrer-lo, s'imprimeix estrictament ordenat: [10, 50, 80]
for (int p : puntuacions) {
    System.out.println(p);
}
```
