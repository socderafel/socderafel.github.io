# 6.3 Serialització d'objectes

Java facilita l'emmagatzematge i transmissió de l'estat d'un objecte mitjançant un mecanisme conegut amb el nom de serialització.

La serialització d'un objecte consisteix en generar una seqüència de bytes llista per al seu emmagatzematge o transmissió. Després, mitjançant la deserializació, l'estat original de l'objecte es pot reconstruir.

Perquè un objecte siga serializable, ha d'implementar la interfície `java.io.Serializable` (que l'únic que fa és marcar l'objecte com serializable, sense que tinguem que implementar cap mètode).

```java
import java.io.*;

public class Persona implements Serializable {

    private String nombre;
    transient private int edad; //No se guardará al serializar
    private double salario;
    private Persona tutor;
    [...]
}
```

- 

Perquè un objecte siga serializable, totes les seues variables d'instància han de ser serializables.

- 

Tots els tipus primitius en Java són serializables per defecte (igual que els arrays i altres molts tipus estàndard).

- 

Quan volem evitar que qualsevol camp persista en un fitxer, el marcamos com transitorio (**`transient`**). No podem marcar cap mètode transitorio, només camps.

- Per a llegir o escriure de/en un fitxer binari que inclou informació seriarizable s'utilitzarà els *streams*  **ObjectInpuStream** i **ObjectOutputStream** amb els mètodes **`readObject()`** i **`writeObject(ClaseSerializada obj)`** respectivament.

> **📌  **
> 

> El fitxer amb els objectes serialitzats emmagatzema les dades en un format propi de Java, per la qual cosa no es pot llegir fàcilment amb un simple editor de text (ni editar).

<details markdown="1">

<summary>💡 Exemple: serialització</summary>

```java
package UT06.P3_Serializacion;

import java.io.*;

public class Persona implements Serializable {

  private String nombre;
  transient private int edad; //No se guardará al serializar
  private double salario;
  private Persona tutor;

  public Persona(String nom, double salari) {
     this.nombre = nom;
     this.salario = salari;
     edad = 0;
     tutor = null;
  }

  public String getNombre() {
     return nombre;
  }

  public int getEdad() {
     return edad;
  }

  public double getSalario() {
     return salario;
  }

  public Persona getTutor() {
     return tutor;
  }

  public void incrementaEdad() {
     edad++;
  }

  public void asignaTutor(Persona p) {
     tutor = p;
  }
}
```

Ara detallamos la classe per a serialitzar o guardar la informació en un fitxer mitjançant el stream **ObjectOutputStream**:

```java
package UT06.P3_Serializacion;

import java.io.*;

public class Guardar {

  public static void main(String args[]) {
     ObjectOutputStream salida;
     Persona p1, p2, p3, p4;

     p1 = new Persona("Vicent", 1200.0);
     p2 = new Persona("Mireia", 1800.0);
     p3 = new Persona("Josep", 2100.0);
     p4 = new Persona("Marta", 850.0);

     p1.asignaTutor(p2);
     p2.asignaTutor(p3);
     p3.asignaTutor(p4);

     try {
        salida = new ObjectOutputStream(new FileOutputStream("empleados.ser"));
        salida.writeObject(p1);
        salida.close();

     } catch (IOException e) {
        System.out.println("ERROR: Algún problema guardando a disco.");
     }
  }
}
```

Com la classe `Persona` implementa `Serializable` significa que `p1` i tots els objectes referenciats per ell (com `p2`, `p3`, `p4`) seran serialitzats en cadena.
