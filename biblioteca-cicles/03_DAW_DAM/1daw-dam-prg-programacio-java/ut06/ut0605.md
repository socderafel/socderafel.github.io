# 6.5 Maneig del sistema de fitxers i carpetes (File / NIO)

## 1. La classe File

La classe `File` és una representació abstracta de fitxers i carpetes. Quan creem en Java un objecte de la classe `File` en representació d'un fitxer o carpeta concrets, no creem el fitxer al que es representa; és a dir, l'objecte `File` representa al fitxer o carpeta de disc, però no és el fitxer o carpeta de disc.

La classe `File` disposa de mètodes que permeten realitzar determinades operacions sobre els fitxers. Podríem, per exemple, crear un objecte de tipus `File` que represente a `c:\datos\libros.txt` (o `/home/abc/datos/libros.txt`) i, a través d'eixe objecte `File`, realitzar consultes relativas al fitxer `libros.txt`, com la seua mida, atributs, etc; o realitzar operacions sobre ell: borrar-lo, renombrar-lo, …

## 2. Constructors

La classe `File` té diversos constructors, que permeten referir-se, de diverses formes, al fitxer que volem representar:

| Mètode | Descripció |
| --- | --- |
| `public File (String ruta)` | Crea l'objecte `File` a partir de la ruta indicada. Si es tracta d'un fitxer haurà d'indicar la ruta i el nom. |
| `public File (String ruta, String nombre)` | Permet indicar de forma separada la ruta del fitxer i el seu nom. |
| `public File (File ruta, String nombre)` | Permet indicar de forma separada la ruta del fitxer i el seu nom. En aquest cas la ruta està representada per un altre objecte File. |
| `public File (URI uri)` | Crea l'objecte File a partir d'un objecte [URI](https://es.wikipedia.org/wiki/Identificador_de_recursos_uniforme) (Uniform Resource Identifier). Un URI permet representar un element seguint una sintaxi concreta, un estàndard. |

## 3. Mètodes

Ací exponemos alguns mètodes interesantes. Hi ha altres que pots consultar en la documentació de Java.

| **Relacionats amb el nom del fitxer** |  |
| --- | --- |
| `String getName()` | Retorna el nom del fitxer o directori al que representa l'objecte (només el nom, sense la ruta). |
| `String getPath()` | Retorna la ruta del fitxer o directori. La ruta obtenida és dependiente del sistema; és a dir, contendrá el caràcter de separació de directoris que estiga establit per defecte. Aquest separador està definit en public `static final String separator`. |
| `String getAbsolutePath()` | Retorna la ruta absoluta del fitxer o directori. |
| `String getParent()` | Retorna la ruta del directori en que es troba el fitxer o directori representat. Retorna `null` si no hi ha directori pare. |

| **Per a fer comprobacions** |  |
| --- | --- |
| `boolean exists()` `boolean canWrite()` `boolean canRead()` `boolean isFile()` `boolean isDirectory()` | Permet averiguar si el fitxer existeix. Permet averiguar si es pot escriure en el. Permet averiguar si es pot llegir d'ell. Permet averiguar si es tracta d'un fitxer o Permet averiguar dsi es tracta d'un directori. |

| **Obtindre informació d'un fitxer** |  |
| --- | --- |
| `long length` | Retorna el mida en bytes del fitxer. El resultat és indefinido si es consulta sobre un directori o una unitat. |
| `long lastModified` | Retorna la data de la última modificació del fitxer. Retorna el número de milisegundos transcurrits des del 1 de gener de 1970 |

| **Per a treballar amb directoris** |  |
| --- | --- |
| `boolean mkdir()` | Crea el directori al qual representa l'objecte File. |
| `boolean mkdirs()` | Crea el directori al qual representa l'objecte File, incloent tots aquells que siguen necessaris i no existisquen. |
| `String[] list()` | Retorna un array de `Strings` amb els noms dels fitxers i directoris que conté el directori al que representa l'objecte File. |
| `String[] list(FileNameFilter filtro)` | Retorna un array de `Strings` amb els noms dels fitxers i directoris que conté el directori al que representa l'objecte File i que compleixen amb determinat filtre. |
| `public File[] listFiles()` | Retorna un array d'objectes `File` que representen als fitxers i carpetes continguts en el directori al que es refereix l'objecte File. |

| **Per a fer canvis** |  |
| --- | --- |
| `boolean renameTo(File nuevoNombre)` | Permet reanomenar un fitxer. Cal tindre en compte que l'operació pot fracasar per moltes raons, i que serà dependiente del sistema (per exemple: que no es puga mover el fitxer d'un lloc a un altre, que ja existisca un fitxer que coincideix amb el nou, etc). El mètode retorna *true* només si l'operació es ha realitzat amb èxit. Existeix un mètode move en la classe Files per a mover fitxers d'una forma independent del sistema. |
| `boolean delete()` | Elimina el fitxer o la carpeta a la que representa l'objecte File. Si es tracta d'una carpeta haurà d'estar buida. Retorna *true* si l'operació té èxit. |
| `boolean createNewFile()` | Crea un fitxer buit. Retorna *true* si l'operació es realitza amb èxit. |
| `File createTempFile(String prefijo, String sufijo)` | Crea un fitxer buit en la carpeta de fitxers temporals. El nom portarà el prefix i sufix indicats. Retorna l'objecte File que representa al nou fitxer. |

<details markdown="1">

<summary>💡 Exemple: maneig de fitxers i carpetes</summary>

```java
package UT06.P5_Manejo;

import java.io.*;
import java.util.*;

public class P5_1_Manejo {

  public static void main(String[] args) {
     Scanner tec = new Scanner(System.in);
     System.out.println("Introduce ruta absoluta de una carpeta");
     String nombreCarpeta = tec.nextLine();
     //Creamos objeto File para representar a la carpeta
     File car = new File(nombreCarpeta);
     //Comprobamos si existe
     if (car.exists()) {
        //¿Es una carpeta?
        if (car.isDirectory()) {
           if (car.canRead()) 
               System.out.println("Lectura permitida");
           else
               System.out.println("Lectura no permitida");

           if (car.canWrite())
               System.out.println("Escritura permitida");
           else
               System.out.println("Escritura no permitida");

           if (car.isHidden())
               System.out.println("Carpeta aoculta");
           else
               System.out.println("Carpeta visible");

           System.out.println("---- Contenido de la carpeta ----");
           File[] contenido = car.listFiles();
           for (File f : contenido) {
               System.out.println(f.getName());
           }
        } else {
            System.out.println("ERROR: " + car.getAbsolutePath() + " No es una carpeta");
        }
     } else {
         System.out.println("ERROR: No existe la carpeta/archivo " + car.getAbsolutePath());
     }
  }
}
```
