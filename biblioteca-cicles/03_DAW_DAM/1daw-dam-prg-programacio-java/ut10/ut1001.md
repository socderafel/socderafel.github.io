## El Model de Canonades de Dades (*Streams*)

En el paquet original `java.io`, la transmissió d'informació entre una aplicació Java i un dispositiu extern (fitxer a disc, sòcol de xarxa, consola o memòria) es modela com un **flux de dades (*Stream*)**: una seqüència ordenada de dades que flueix d'un extrem origen a un extrem destí.

```
+-------------+      canonada de transmissió      +---------------------+
| Origen      | ===============================> | Destí               |
| (Ex: Disc)  |      flux seqüencial unidireccional | (Ex: Memòria Java)  |
+-------------+                                   +---------------------+
```

---

## Les Quatre Classes Abstractes Fonamentals

El disseny de `java.io` s'articula en una matriu orthogonal de dues dimensions: **direcció** (Entrada / Eixida) i **unitat de dada** (Bytes de 8 bits / Caràcters Unicode de 16 bits):

| Tipus de Dada | Fluxos d'Entrada (Llegir) | Fluxos d'Eixida (Escriure) | Ús Principal |
| :--- | :--- | :--- | :--- |
| **Bytes (8 bits)** | `java.io.InputStream` | `java.io.OutputStream` | Imatges (PNG/JPEG), vídeos, àudio, arxius binaris i dades de xarxa en brut. |
| **Caràcters (Unicode 16 bits)** | `java.io.Reader` | `java.io.Writer` | Text pla, fitxers CSV, XML, JSON i codificacions internacionals (UTF-8). |

---

## El Pont entre Bytes i Caràcters: `InputStreamReader` i `OutputStreamWriter`

Quan tenim una font de bytes física (per exemple un fitxer a disc o la connexió a un servidor web) i volem interpretar-la com a text segons una codificació concreta (com UTF-8), utilitzem les classes pont:

```java
// Obrim un flux de bytes i el convertim a flux de caràcters especificant UTF-8
FileInputStream fis = new FileInputStream("missatge.txt");
InputStreamReader isr = new InputStreamReader(fis, StandardCharsets.UTF_8);

int caracterLlegit;
while ((caracterLlegit = isr.read()) != -1) {
    char lletra = (char) caracterLlegit;
    System.out.print(lletra);
}
isr.close();
```
