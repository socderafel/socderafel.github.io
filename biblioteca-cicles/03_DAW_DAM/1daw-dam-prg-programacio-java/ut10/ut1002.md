## Per Què Utilitzar Memòries Intermèdies (*Buffering*)?

Accedir físicament al suport d'emmagatzematge magnètic o d'estat sòlid és milers de vegades més lent que operar en la memòria RAM. Si utilitzem un `FileReader` directe per a llegir un llibre de 500.000 caràcters caràcter a caràcter, es faran 500.000 accessos al sistema d'arxius!

**`BufferedReader`** i **`BufferedWriter`** resolen aquest problema mitjançant una memòria intermèdia en RAM (habitualment 8 KB). Quan demanem dades, el buffer llegeix un bloc sencer de disc; les següents lectures es fan instantàniament des de la RAM.

```
Disc Dur / SSD ===[Bloc de 8192 bytes]===> Buffer en RAM ===[readLine()]===> Aplicació Java
```

## Lectura de Fitxers Línia a Línia

El mètode estrella de `BufferedReader` és `readLine()`, que retorna una línia completa com a `String` o `null` quan arriba al final del fitxer:

```java
File fitxer = new File("informe.txt");

try (BufferedReader br = new BufferedReader(new FileReader(fitxer, StandardCharsets.UTF_8))) {
    String linia;
    int numeroLinia = 1;
    while ((linia = br.readLine()) != null) {
        System.out.printf("%04d: %s%n", numeroLinia++, linia);
    }
} catch (IOException e) {
    System.err.println("Error llegint el fitxer: " + e.getMessage());
}
```

## Escriptura Formatada: `BufferedWriter` vs `PrintWriter`

Per a escriure text disposem de dues opcions molt populars:

1. **`BufferedWriter`:** Molt eficient, proporciona `write(String)` i `newLine()` per a afegir salts de línia independents del sistema operatiu (CRLF en Windows, LF en Linux).
2. **`PrintWriter`:** Afegeix comoditat oferint mètodes idèntics a la consola (`print()`, `println()`, `printf()`):

```java
try (PrintWriter pw = new PrintWriter(new BufferedWriter(new FileWriter("factura.txt", StandardCharsets.UTF_8)))) {
    pw.println("--- FACTURA COMERCIAL ---");
    pw.printf("Producte: %-20s Preu: %8.2f €%n", "Portàtil i7", 899.95);
    pw.printf("Producte: %-20s Preu: %8.2f €%n", "Ratolí USB", 15.50);
} catch (IOException e) {
    System.err.println("Error escrivint la factura: " + e.getMessage());
}
```

> **Mode Afegir (*Append*):** Si no volem sobreescriure el fitxer sinó afegir dades al final, passem `true` al constructor: `new FileWriter("fitxer.txt", true)`.
