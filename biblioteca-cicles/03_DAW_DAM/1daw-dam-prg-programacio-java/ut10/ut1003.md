## La Revolució de Java NIO.2 (`java.nio.file`)

Introduït en Java 7, el paquet `java.nio.file` va modernitzar completament l'antiga classe `java.io.File`, la qual patia de serioses limitacions: mètodes booleans que fallaven silenciosament sense llançar excepcions detallades, lentitud en la navegació de directoris i manca de suport per a atributs i enllaços simbòlics.

NIO.2 s'estructura al voltant de dues entitats clau:
1. **`java.nio.file.Path`:** Interfície que representa una ruta jeràrquica a un fitxer o directori (substitut modern de `File`).
2. **`java.nio.file.Files`:** Classe d'utilitats estàtiques amb centenars d'operacions d'alt nivell.

## Operacions Habituals amb `Path` i `Files`

### Creació de Rutes
```java
// Mitjançant Path.of() (Java 11+) o Paths.get()
Path ruta = Path.of("projecte", "configuracio", "app.properties");
System.out.println("Nom fitxer: " + ruta.getFileName());
System.out.println("Directori pare: " + ruta.getParent());
System.out.println("És absoluta?: " + ruta.isAbsolute());
```

### Operacions de Fitxers amb `Files`
```java
Path origen = Path.of("dades.txt");
Path desti = Path.of("copia_dades.txt");

// Comprovacions
if (Files.exists(origen)) {
    System.out.println("Mida: " + Files.size(origen) + " bytes");
    
    // Còpia atòmica o sobreescrivint si ja existeix
    Files.copy(origen, desti, StandardCopyOption.REPLACE_EXISTING);
}

// Creació de directoris complets (crea tots els pares intermedis)
Path nouDirectori = Path.of("logs", "2026", "novembre");
Files.createDirectories(nouDirectori);
```

## Lectura i Escriptura Declarativa d'Alt Nivell

Per a fitxers de mida xicoteta o mitjana, `Files` ofereix mètodes que realitzen tot el cicle d'obertura, memòria intermèdia, codificació UTF-8 i tancament automàtic en **una sola línia**:

```java
Path fitxer = Path.of("notes.txt");

// Llegir tot el fitxer com a llista de cadenes
List<String> linies = Files.readAllLines(fitxer, StandardCharsets.UTF_8);

// Llegir tot el fitxer com una única String (Java 11+)
String contingutComplet = Files.readString(fitxer, StandardCharsets.UTF_8);

// Escriure una llista de cadenes
List<String> dades = List.of("Línia 1", "Línia 2", "Línia 3");
Files.write(fitxer, dades, StandardCharsets.UTF_8, StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```
