## Dades Primitives en Format Binari: `DataInputStream` i `DataOutputStream`

Fins ara hem guardat números com a cadenes de caràcters de text (per exemple el número enter 12345678 ocupa 8 caràcters = 8 bytes en text). En format binari, un `int` de Java ocupa **exactament 4 bytes físics fixos** a la memòria i al disc, amb màxima eficiència de compactació.

Les classes `DataOutputStream` i `DataInputStream` permeten llegir i escriure tipus primitius directament en format binari natiu de Java:

```java
// Escriptura binària
try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("jugador.dat"))) {
    dos.writeInt(101);          // 4 bytes
    dos.writeUTF("Marc");       // Longitud + caràcters UTF
    dos.writeDouble(9540.75);   // 8 bytes
    dos.writeBoolean(true);     // 1 byte
}

// Lectura binària: ÉS OBLIGATORI LLEGIR EXACTAMENT EN EL MATEIX ORDRE!
try (DataInputStream dis = new DataInputStream(new FileInputStream("jugador.dat"))) {
    int id = dis.readInt();
    String nom = dis.readUTF();
    double puntuacio = dis.readDouble();
    boolean actiu = dis.readBoolean();
    System.out.printf("Jugador: %d - %s (%.2f pts, Actiu: %b)%n", id, nom, puntuacio, actiu);
}
```

## Accés Aleatori a Fitxers: `RandomAccessFile`

Tots els fluxos ordinaris són estrictament seqüencials: per a llegir el byte número 500 cal llegir abans els 499 anteriors.

La classe **`RandomAccessFile`** trenca aquesta restricció i permet posicionar un punter de lectura/escriptura de fitxer en **qualsevol posició arbitrària** de manera instantània mitjançant el mètode `seek(long posicio)`:

```java
// Obrir en mode lectura/escriptura ("rw")
try (RandomAccessFile raf = new RandomAccessFile("registres.bin", "rw")) {
    // Cada registre té una mida fixa de 32 bytes
    long registreDesitjat = 5; // El 6é registre (0-indexat)
    long offset = registreDesitjat * 32;

    // Saltem directament a la posició sense llegir el contingut anterior
    raf.seek(offset);

    int codi = raf.readInt();
    double saldo = raf.readDouble();
    System.out.println("Registre recuperat a la posició " + offset + ": Codi=" + codi + ", Saldo=" + saldo);

    // Sobreescrivim el saldo directament a la mateixa posició
    raf.seek(offset + 4); // Saltem el codi (4 bytes)
    raf.writeDouble(saldo + 100.0);
}
```
