# 1.3 Variables, identificadors i convencions (Clean Code)

## 1. Variables

Una **variable** és un espai reservat en la memòria de l'ordinador que té un nom, un tipus i un valor. Gràcies a ella, el programa pot guardar dades i recuperar-los més avant.

Tota variable queda definida per tres característiques:

| Característica | Descripció |
| --- | --- |
| **Nom** (identificador) | Permet referenciar la variable en el codi |
| **Tipus de dada** | Indica què classe d'informació emmagatzema (`int`, `double`, `String`…) |
| **Valor** | El dada concret guardat en eixe moment |

> **📌 Exemple**
> 

```java
int edad = 17;          // nombre: edad       |  tipo: int     |  valor: 17
String nombre = "Ana";  // nombre: nombre     |  tipo: String  |  valor: "Ana"
double precio = 9.99;   // nombre: precio     |  tipo: double  |  valor: 9.99
```

### 1.1.Àmbit (scope) d'una variable

El **àmbit** o **scope** és la zona del codi on una variable és accesible. En Java, una variable declarada dins d'un bloc `{ }` només existeix dins d'eixe bloc.

> **📌 Exemple**
> 

```java
public static void main(String[] args) {
    int x = 10;          // x es accesible en todo el método main

    if (x > 5) {
        int y = 20;      // y solo existe dentro de este bloque if
        System.out.println(x + y); // correcto
    }

    System.out.println(y); // ERROR: y no existe aquí
}
```

## 2. Constants

Una **constant** és com una variable, però el seu valor **no pot canviar** una vegada assignat. S'usa per a dades fixos que han de permanecer igual durant tota l'ejecució del programa.

En Java es declaran amb la paraula clau `final`:

> **📌 Exemple**
> 

```java
final double PI = 3.14159;
final int TAM_MAX = 100;
final String MENSAJE_ERROR = "Operación no permitida";
```

Si intentem canviar el seu valor, el compilador l'impedeix:

> **📌 Exemple**
> 

```java
final int MAX = 50;
MAX = 60;   // ERROR: no se puede reasignar una constante
```

### 2.1. Quan usar una constant en lloc d'una variable?

- Quan el valor **mai ha de canviar** (el valor de π, un límit màxim, un codi d'error, etc.)

- Per a evitar escriure el mateix número "mágic" en diversos llocs del codi.

- Perquè el codi siga **més llegible**: `TAM_MAX` comunica més que un `100` suelto.

> **📌 Exemple**
> 

```java
// Sin constante — ¿qué significa 365?
int diasAnio = dias * 365;

// Con constante — queda claro y no puede cambiar por error
final int DIAS_POR_ANIO = 365;
int diasAnio = dias * DIAS_POR_ANIO;
```

## 3. Identificadors

Un **identificador** és el nom que li donem a un element del programa: una variable, una constant, una classe, un mètode, etc.

### 3.1. Regles obligatòries en Java

Perquè un identificador siga vàlid, ha de complir aquestes regles sense excepció:

- Només pot contindre **lletres, dígitos, `_` i `$`**.

- Ha de **començar per una lletra**, `_` o `$` (mai per un dígito).

- **No pot contindre espais**.

- **Distingeix majúscules de minúscules**: `edad` i `Edad` són identificadors distints.

- **No pot coincidir amb una paraula reservada** de Java (`int`, `class`, `for`, etc.)

| Identificador | Vàlid? | Motiu |
| --- | --- | --- |
| `numAlumnos` | ✅ | Correcte |
| `_contador` | ✅ | Comença per `_` |
| `3errores` | ❌ | Comença per dígito |
| `mi variable` | ❌ | Conté espai |
| `class` | ❌ | És paraula reservada |
| `$precio` | ✅ | Técnicament vàlid (no recomanat) |

**Nota sobre Unicode:** Java accepta lletres de qualsevol alfabeto (griego, árabe, etc.), per la qual cosa identificadors com `ατη` són vàlids. En la pràctica, s'usen sempre lletres de l'alfabeto latino per a garantir compatibilitat.

## 4. Convencions de nombrado

Les convencions no són obligatòries, però **tot el món les segueix** en Java. Respetar-les fa el codi més llegible i professional.

### 4.1. lowerCamelCase — variables i mètodes

Comença en **minúscula**. Cada paraula següent comença en mayúscula. Sense guions ni espais.

> **📌 Exemple**
> 

```java
// Variables
int numAlumnos;
double precioFinal;
String nombreCompleto;

// Métodos
void calcularMedia() { ... }
int obtenerEdad() { ... }
```

### 4.2. UpperCamelCase — classes

Comença en **mayúscula**. Igual que l'anterior però la primera lletra també va en mayúscula.

> **📌 Exemple**
> 

```java
class Alumno { ... }
class CuentaBancaria { ... }
class GestorDeArchivos { ... }
```

### 4.3. UPPER_SNAKE_CASE — constants

Tot en **majúscules**, paraules separades per `_`. 

**Totes les constants han de seguir aquesta nomenclatura**

> **📌 Exemple**
> 

```java
final int TAM_MAX = 100;
final double PI = 3.14159;
final String RUTA_FICHERO = "/datos/alumnos.txt";
```

### 4.4. Comparativa: bé vs. malament

| Nom no correcte | Nom correcte | Tipus |
| --- | --- | --- |
| `x` | `edadAlumno` | variable |
| `Cl33` | `fichaCliente` | variable |
| `METODO` | `calcularMedia` | mètode |
| `mi_clase` | `GestorAlumnos` | classe |
| `maximo` | `VALOR_MAXIMO` | constant |

**Regla d'oro:** el nom ha de deixar clar **què conté o què fa**, sense necessitat de llegir el resta del codi.

## 5. Paraules reservades

Les **paraules reservades** (*keywords*) són termes que Java usa internament. **No es poden usar com identificadors**.

Estan organitzades per categoria perquè siga més fàcil memorizar-les:

| Categoria | Paraules |
| --- | --- |
| **Tipus de dada** | `boolean`, `byte`, `char`, `double`, `float`, `int`, `long`, `short` |
| **Control de flux** | `if`, `else`, `switch`, `case`, `default`, `for`, `while`, `do`, `break`, `continue`, `return` |
| **Classes i objectes** | `class`, `interface`, `extends`, `implements`, `new`, `this`, `super`, `instanceof`, `enum` |
| **Modificadors** | `public`, `private`, `protected`, `static`, `final`, `abstract`, `synchronized`, `volatile`, `transient`, `strictfp`, `native` |
| **Gestió d'errors** | `try`, `catch`, `finally`, `throw`, `throws` |
| **Paquets** | `package`, `import` |
| **Altres** | `void`, `const`*, `goto`*, `assert` |

> **📌 Exemple d'error freqüent**
> 

```java
int class = 5;      // ERROR: 'class' es palabra reservada
int for = 10;       // ERROR: 'for' es palabra reservada

int miClase = 5;    // correcto
int contador = 10;  // correcto
```
