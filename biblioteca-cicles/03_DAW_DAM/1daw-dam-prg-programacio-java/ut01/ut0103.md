## 1. Desglossament Estructural d'una Classe en Java

Tot codi executable en Java ha de residir obligatòriament a l'interior d'una **Classe**. A diferència d'altres llenguatges que admeten funcions globals soltes, Java és un llenguatge orientat a objectes pur des de la seua estructura arrel.

```java
package es.iesmonastil.daw;

/**
 * Classe principal de demostració del mòdul de Programació.
 * Exemplifica l'estructura canònica d'un programa en Java 21.
 * 
 * @author Equip Docent d'Informàtica
 * @version 1.0.0
 */
public class HolaMon {

    /**
     * Punt d'entrada únic per a l'execució de l'aplicació per part de la JVM.
     * 
     * @param args Arguments transmesos a través de la línia d'ordres de consola.
     */
    public static void main(String[] args) {
        // Instrucció de sortida per la consola estàndard del sistema
        System.out.println("Benvinguts al Cicle Formatiu de DAW i DAM!");
        System.out.println("Iniciant el mòdul de Programació en Java...");
    }
}
```

### Anàlisi dels Components Fonamentals

1. **`package es.iesmonastil.daw;`:** Declara el paquet (espai de noms) al qual pertany la classe. En el sistema de fitxers, la classe ha d'estar ubicada en una estructura de carpetes que coincidisca exactament amb el paquet (`es/iesmonastil/daw/HolaMon.java`).
2. **`public class HolaMon`:**
   - `public`: Modificador d'accés que permet que la classe siga visible des de qualsevol altre paquet del programa.
   - `class`: Paraula clau que defineix una nova plantilla de dades i comportament.
   - `HolaMon`: Nom de la classe. **Regla d'or:** Si la classe és `public`, el fitxer ha d'anomenar-se obligatòriament `HolaMon.java` (amb estricta coincidència de majúscules i minúscules).
3. **`public static void main(String[] args)`:**
   - `public`: Accessible lliurement per la JVM des de fora del paquet.
   - `static`: Pertany a la classe mateixa; no requereix crear una instància (`new HolaMon()`) per a cridar-lo.
   - `void`: Tipus de retorn; indica que el mètode no retorna cap dada en finalitzar la seua execució.
   - `main`: Nom universal establert per l'estàndard com a punt d'arrencada de qualsevol aplicació independent.
   - `String[] args`: Vector de cadenes de text que recull els paràmetres passats per consola en executar el programa (`java HolaMon arg1 arg2`).
4. **`System.out.println(...)`:** Crida a l'objecte de sortida estàndard del sistema (`out`) definit en la classe `System` per a imprimir una línia de text seguida d'un salt de línia.

## 2. Tipologia de Comentaris i Documentació Tècnica amb Javadoc

En enginyeria de programari professional, el codi s'ha de documentar de manera estandarditzada:
- **Comentari d'una sola línia:** `// Comentari breu d'aclariment`
- **Comentari multilínia:** `/* Bloc de comentari explicatiu */`
- **Comentari de documentació Javadoc:** `/** ... */`

L'eina oficial `javadoc` analitza aquests blocs especials i genera automàticament un lloc web complet en HTML5 amb la documentació de l'API de les classes del projecte.

### Etiquetes Javadoc Canòniques
- `@author`: Nom de l'autor o equip de desenvolupament.
- `@version`: Versió actual de la classe o mòdul.
- `@param nomParam`: Descripció detallada de cadascun dels paràmetres rebuts per un mètode.
- `@return`: Descripció del valor de retorn generat pel mètode.
- `@throws NomExcepcio` (o `@exception`): Descripció de les condicions d'error que provoquen que el mètode llance una excepció.
- `@see`: Enllaç o referència creuada cap a una altra classe o mètode relacionat.

```bash
# Comanda per a generar la documentació HTML a la carpeta docs/
javadoc -d docs -author -version es/iesmonastil/daw/HolaMon.java
```
