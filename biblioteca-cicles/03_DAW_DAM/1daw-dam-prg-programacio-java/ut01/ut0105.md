## 1. El Paper de l'IDE en el Desenvolupament Professional

Tot i que qualsevol programa en Java es pot escriure amb un simple editor de text pla i compilar amb `javac` en la consola, un **Entorn de Desenvolupament Integrat (IDE)** augmenta de manera exponencial la productivitat de l'equip de programació:
- **Assistència i Autocompletat Intel·ligent:** Detecció d'errors sintàctics en temps real mentre s'escriu el codi (*on-the-fly syntax checking*).
- **Refactorització Segura de Codi:** Reanomenar classes, mètodes o camps en milers de fitxers simultàniament amb garantia d'integritat referencial.
- **Depurador Visual Integrat (*Visual Debugger*):** Execució pas a pas, punts d'interrupció condicionals (*breakpoints*) i inspecció del contingut de la memòria en temps real.
- **Integració amb Eines de Construcció:** Suport directe per a Maven, Gradle i control de versions amb Git.

Els IDEs líders en el mercat actual de Java són **IntelliJ IDEA** (JetBrains), **Visual Studio Code** (Microsoft, amb el Java Extension Pack) i **Eclipse IDE**.

## 2. Estructura Estàndard de Projectes Java (Convenció Maven/Gradle)

En l'ecosistema empresarial, els projectes s'organitzen seguint una jerarquia de directoris estandarditzada universalment:

```
el-meu-projecte/
├── pom.xml                   (Fitxer de configuració de Maven)
├── build.gradle              (O fitxer de configuració de Gradle)
└── src/
    ├── main/
    │   ├── java/             (Codi font Java de l'aplicació)
    │   │   └── es/iesmonastil/daw/
    │   │       ├── Principal.java
    │   │       └── model/Usuari.java
    │   └── resources/        (Fitxers auxiliars: configs, SQL, imatges)
    │       └── aplicacio.properties
    └── test/
        └── java/             (Codis de proves unitàries amb JUnit 5)
            └── es/iesmonastil/daw/PrincipalTest.java
```

## 3. Gestió de la Compilació i Empaquetat: Fitxers JAR

Un fitxer **JAR** (Java Archive) és un paquet comprimit en format ZIP estàndard que agrupa múltiples fitxers de Bytecode `.class`, recursos multimèdia i fitxers de configuració en un únic arxiu portable.

### El Manifest (`META-INF/MANIFEST.MF`)
Perquè un arxiu JAR siga executable directament amb doble clic o mitjançant `java -jar aplicacio.jar`, ha de contindre un fitxer manifest que declare la seua classe principal:
```manifest
Manifest-Version: 1.0
Main-Class: es.iesmonastil.daw.Principal
```

```bash
# Creació d'un JAR executable des de la línia d'ordres
jar --create --file aplicacio.jar --main-class es.iesmonastil.daw.Principal -C bin/ .

# Execució del paquet JAR autònom
java -jar aplicacio.jar
```
