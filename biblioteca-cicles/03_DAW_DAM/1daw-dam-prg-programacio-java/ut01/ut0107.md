Ideas para resolver problemas

Leer entrada Juez usa OpenJDK 7, el comportamiento de split() en String, cambió a partir de Java 8. En Java se recomienda leer este problema con next() de Scanner. Problema A-Eligiendo la sede del mundial (1)

Contar sedes y máximo de votos: Una posible solución en Java, utilizar HashMap. Si solo una sede tiene el máximo de votos, es la respuesta. Si dos o más sedes tienen el máximo de votos, EMPATE. Problema A-Eligiendo la sede del mundial (2)

Leemos el total de plazas. Restamos al total de plazas las plazas de cada una de las 6 confederaciones. Imprimimos las plazas restantes. Problema B - Plazas disponibles en el mundial

Eliminar ceros a la izquierda. Ideas pasar de carácter a entero Carácter es un número ASCII, restamos ‘0’.

```java
int x= cadena.charAt(i)-‘0’;
```

Otra estrategia int x=Integer. parseInt(cadena.charAt(i)) Problema C - Verificación de las entradas (1)

Para algoritmo, primer dígito es impar (más a la izquierda). Impar: multiplica por 3 y suma el menor dígito derecha o 0 si no hay. Par: multiplica por 2 y suma el mayor dígito a su izquierda o 0 si no hay. Problema C - Verificación de las entradas (2)

Leer eventos. Podemos ignorar texto. La entrada está ordenada. Algoritmo ventana deslizante de al menos el tamaño de la consulta. Ideas como probar todas las combinaciones, TLE. Problema D - Eventos de los partidos (1)

Si la consulta es de “al menos Q eventos”, ventana será de tamaño Q o superior. Prioridad (al menos Q eventos): Menor recorrido temporal. Mismo recorrido -> más eventos. Mismo recorrido y eventos -> La que empiece antes. Problema D - Eventos de los partidos (2)

Leer Partidos, para N equipos: partidos= (n * (n - 1) / 2) Calcular puntos, goles a favor, en contra de cada equipo. Algoritmo de ordenación rápido (MergeSort, QSort, etc.) Problema E - Fase de grupos (1)

Si hay Q clasificados, comprobar que ninguno de los Q+1 primeros equipos empatan con otro a todo. Si es así, no podemos sacar clasificación, entonces EMPATE. Si ninguno empata, mostramos Q primeros equipos. Problema E - Fase de grupos (2)

Si hay N equipos, cada iteración, leemos N/2 partidos y eliminamos al equipo que corresponda. Posible estrategia, rellenar nuevo array cada iteración. Repetimos hasta tener N=1, que es el equipo ganador. Problema F - Fase final
