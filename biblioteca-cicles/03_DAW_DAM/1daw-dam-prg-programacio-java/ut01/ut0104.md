## 1. La Importància de les Convencions en Equips de Desenvolupament

En l'àmbit professional, el programari es llegeix deu vegades més sovint del que s'escriu. Seguir una guia d'estil unificada (com la guia oficial d'Oracle o la *Google Java Style Guide*) redueix la càrrega cognitiva durant les revisions de codi (*code reviews*), facilita la detecció primerenca de defectes i assegura la mantenibilitat de projectes a llarg termini.

---

## 2. Convencions de Nomenclatura Estàndard en Java

Java utilitza de manera universal el sistema de majúscules intercalades (*CamelCase*), reservant el subratllat exclusivament per a constants:

| Element de Codi | Convenció d'Estil | Regles i Bones Pràctiques | Exemples Correctes |
| :--- | :--- | :--- | :--- |
| **Classes i Interfícies** | **UpperCamelCase** (PascalCase) | Noms o substantius; comencen sempre en Majúscula; eviten acrònims tot en majúscules. | `CompteBancari`, `GestorPagaments`, `ClientHttp` |
| **Mètodes** | **lowerCamelCase** | Verbs o frases verbals; comencen en minúscula; expressen de manera inequívoca l'acció realitzada. | `calcularSalariNet()`, `enviarCorreu()`, `esMajorEdat()` |
| **Variables i Atributs** | **lowerCamelCase** | Noms descriptius en minúscula; eviten noms d'una sola lletra (llevat de comptadors com `i`, `j` en bucles xicotets). | `edatAlumne`, `preuAmbIva`, `totalHoresCurs` |
| **Constants** (`static final`) | **SCREAMING_SNAKE_CASE** | Totes les lletres en MAJÚSCULES amb paraules separades per guió baix `_`. | `PI`, `MAX_INTENTS_LOGIN`, `IVA_GENERAL` |
| **Paquets (*Packages*)** | **lower_case** continu | Lletres minúscules contínues sense guions; utilitzen el nom de domini corporatiu invertit. | `es.iesmonastil.projecte.model`, `com.oracle.net` |

## 3. Principis de Codi Net (Clean Code) i Format

- **Sangratge i Indentació:** S'utilitzen 4 espais per nivell d'indentació (o 2 espais segons l'estil Google). Mai s'han de barrejar tabuladors i espais en blanc.
- **Posició de Claus (Estil K&R - Kernighan & Ritchie):** La clau d'obertura `{` es col·loca sempre al final de la línia de declaració; la clau de tancament `}` s'alinea verticalment amb l'inici de la sentència que obria el bloc:
  ```java
  // Correcte (Estil estàndard de Java)
  if (nota >= 5.0) {
      System.out.println("Aprovat");
  } else {
      System.out.println("Suspens");
  }
  ```
- **Llargària Màxima de Línia:** Recomanat no superar els 100 o 120 caràcters per línia per a evitar desplaçaments horitzontals innecessaris.
- **Evitar Nombres Màgics (*Magic Numbers*):** Mai s'han d'incrustar valors numèrics literals sense context enmig dels càlculs; cal declarar constants autoexplicatives:
  ```java
  // Incorrecte
  double total = preu * 1.21;
  
  // Correcte i Net
  private static final double PERCENTATGE_IVA = 0.21;
  double total = preu * (1 + PERCENTATGE_IVA);
  ```
