# 1.4 Tipus de dades primitius

## 1. Tipus de dades primitius

Els tipus de dades s'utilitzen per a declarar variables i que el compilador sepa d'antemano què tipus d'informació contendrá la variable.

Java disposa dels següents tipus de dades simples:

| **Tipus** | **Representació** | **Rang de valors** | **Valor per defecte** | **Classe associada** | **Exemple de declaració** |
| --- | --- | --- | --- | --- | --- |
| `byte` | Enter amb signe | -128 a 127 | 0 | `Byte` | `byte a;` |
| `short` | Enter amb signe | -32.768 a 32.767 | 0 | `Short` | `short b, c = 3;` |
| `int` | Enter amb signe | -2.147.483.648 a 2.147.483.647 | 0 | `Integer` | `int d = -30;` `int e = 0xC125; // 0x indica hexadecimal` |
| `long` | Enter amb signe | -9,2×1018 a 9,2×1018 | 0 | `Long` | `long b = 46240;` `long b = 5L; // la L indica que es long` |
| `float` | Decimal precisió simple | -3,4×10-38 a 3,4×1038 | 0.0 | `Float` | `float pi = 3.14F; // la F indica float` |
| `double` | Decimal precisió doble | -1,8×10-308 a 1,8×10308 | 0.0 | `Double` | `double millon = 1e6;` `double z = .123; // la parte entera 0 se puede omitir` |
| `char` | Caràcter Unicode | `\u0000` a `\uFFFF` | `\u0000` | `Character` | `char car1 = 'c';` `char car2 = 99; // 'c' equivale al ASCII 99` `char letra = '\u0063'; // código unicode de 'c'` |
| `boolean` | Dada lògic | `true` o `false` | `false` | `Boolean` | `boolean primero;` `boolean par = false;` |

### 1.2. Inicializació: variables locals vs. globals

> **📌 Variables locals vs. globals**
> 

#### 📌 Variable local (ha d'inicializar-se)

```java
public class ClaseEjemplo {
    public static void main(String[] args) {
        int a;
        System.out.println(a); // ERROR: variable local no inicializada
    }
}
```

#### 📌 Variable global (té valor per defecte)

```java
public class ClaseEjemplo {
    static int a; // atributo de clase → valor por defecto: 0
    public static void main(String[] args) {
        System.out.println(a); // correcto: imprime 0
    }
}
```

## 2. Tipus referenciats

A partir dels huit tipus primitius, Java permet construir altres tipus més complexos anomenats **tipus referenciats**. En lloc d'emmagatzemar el dada directament, aquestes variables guarden la **adreça de memòria** on es troba el dada.

Els tipus referenciats més habituals són:

| Tipus | Descripció |
| --- | --- |
| **Arrays** | Llista d'elements del mateix tipus (`int[]`, `String[]`…) |
| **Objectes** | Instàncies de classes (`Cuenta`, `Alumno`…) |
| **String** | Cadena de text (tratada de forma especial per Java) |
| Col·leccions | `List`, `Map`, `Set`… (es verán en unitats posteriors) |

> **📌 Declaració de tipus referenciats**
> 

```java
int[] arrayDeEnteros;   // referencia a un array de enteros
Cuenta cuentaCliente;   // referencia a un objeto de tipo Cuenta
```

### 2.1. El tipus `String`

Encara que técnicament és un objecte (tipus referenciado), Java el tracta de forma especial: pot usar-se **com si fóra un tipus primitiu**.

> **📌 El tipus String**
> 

```java
String mensaje = "El primer programa";
String nombre = "Ana";
int longitud = nombre.length(); // los String tienen métodos propios
```

### 2.2. Mostrar dades per pantalla

Per a mostrar valors per consola s'usa `System.out`:

| Mètode | Comportament |
| --- | --- |
| `System.out.print(…)` | Mostra el text **sense** salt de línia al final |
| `System.out.println(…)` | Mostra el text **amb** salt de línia al final |

> **📌 Mostrar dades per pantalla**
> 

```java
String nombre = "Ana";
int edad = 17;

System.out.print("Nombre: ");
System.out.println(nombre);         // Nombre: Ana
System.out.println("Edad: " + edad); // Edad: 17
```

## 3. Tipus enumerats (`enum`)

Els tipus enumerats permeten declarar una variable que només pot prendre un conjunt **restringido i predefinido** de valors. Són útils quan hi ha un número fix d'opcions possibles (dies de la setmana, estacions, estats…).

Es declaran amb la paraula clau `enum`:

> **📌 Declaració de tipus enumerats**
> 

```java
public enum Dia { Lunes, Martes, Miercoles, Jueves, Viernes, Sabado, Domingo }
```

Els valors de l'enum són constants, per això es escriuen en `UpperCamelCase` o, segons el context, en `MAYUSCULAS`.

### 3.1. Ús bàsic

> **📌 Exemple de tipus enumerats**
> 

#### 📌 Java

```java
public class TiposEnumerados {
    public enum Dia { Lunes, Martes, Miercoles, Jueves, Viernes, Sabado, Domingo }

    public static void main(String[] args) {
        Dia diaActual   = Dia.Martes;
        Dia diaSiguiente = Dia.Miercoles;

        System.out.println("Hoy es: " + diaActual);
        System.out.println("Mañana es: " + diaSiguiente);
    }
}
```

#### 📌 Resultat

```java
Hoy es: Martes
Mañana es: Miercoles
```

Per a accedir a un valor de l'enum s'usa `NombreEnum.Valor`. El compilador controla que només es asignen valors vàlids, evitant errors en temps d'ejecució.

**Nota:** En Java un `enum` no és un simple llistat — té el mateix tractament que una classe, per la qual cosa pot incloure mètodes, constructors i atributs propis. El veurem en unitats més avançades.

## 4. Literals

Un **literal** és un valor concret escrit directament en el codi. Pot ser de qualsevol tipus primitiu, `null` o `String`.

> **📌 Exemples de literals**
> 

```java
int edad       = 17;          // literal entero
double precio  = 9.99;        // literal decimal
char letra     = 'A';         // literal carácter
boolean activo = true;        // literal booleano
String texto   = "Hola";      // literal String
Object obj     = null;        // literal nulo
```

## 5. Seqüències d'escape

Dins d'un literal de tipus `char` o `String` hi ha caràcters que no es poden escriure directament (salt de línia, tabulador, cometes…). Per a representar-los s'usen **seqüències d'escape**, que comencen sempre amb `\`:

| Seqüència | Significat |
| --- | --- |
| `\n` | Salt de línia |
| `\t` | Tabulador horitzontal |
| `\r` | Retorn de carro |
| `\\` | Barra diagonal inversa (`\`) |
| `\"` | Cometes dobles (`"`) |
| `\'` | Cometes simples (`'`) |
| `\b` | Retroceso (*backspace*) |
| `\f` | Salt de pàgina |
| `\uXXXX` | Caràcter Unicode (p. ej. `\u0041` = `'A'`) |

> **📌 Exemple d'ús**
> 

```java
System.out.println("Línea 1\nLínea 2");   // salto de línea
System.out.println("Col1\tCol2\tCol3");   // columnas con tabulador
System.out.println("Dice: \"Hola\"");     // comillas dentro de String
char barra = '\\';                        // el carácter \
```

> **📌 💡 I si necessitem saber si un char és un número o una lletra?**
> 

> Els tipus primitius com `int` o `char` no tenen mètodes propis. Per a inspeccionar-los (per exemple `Character.isDigit()` o `Character.isLetter()`) o convertir text a número (`Integer.parseInt()`), Java proporciona les **Classes Embolcall (*Wrappers*)** i la classe `String`.
