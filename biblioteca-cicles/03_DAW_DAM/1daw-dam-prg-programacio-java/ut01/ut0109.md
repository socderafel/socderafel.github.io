# 1.9 EjemploTreeMap

```java
package ____PROGRAMAME_REGIONAL_160424;

import java.util.Collections;

import java.util.TreeMap;

/*

 * ¿Qué es un TreeMap? 

 * 

 * Es una estructura de datos similar a un diccionario HASHMAP

 * que almacena elementos como pares clave-valor, pero

 * con la peculiaridad de ORDENARLOS POR CLAVE

 * 

 */

public class EjemploTreeMap {

	public static void main(String[] args) {

		// Creamos el TreeMap con clave-valor

		// Por defecto ordenada de forma DESCENDENTE

		TreeMap<Integer,String> personas = new TreeMap<Integer, String>();

		

		// Si queremos orden ASCENDENTE

		//TreeMap<Integer,String> personas = new TreeMap<Integer, String>(Collections.reverseOrder());

		// Añadimos datos al TreeMap

		// Conforme los añade los va ordenando automáticamente

		personas.put(34, "Anakin");

		personas.put(30, "Leia");

		personas.put(50, "Chiwaka");

		personas.put(32, "Yoda");

		personas.put(32, "Jedi"); // Sobrescribe a Yoda (no puede haber dos claves igual)

		

		// Recorre el TreeMap y muestra el contenido (que estará ordenado)

		for (Integer edad : personas.keySet()) {

			System.out.println(personas.get(edad) + ": " + edad);

		}

	}

}
```
