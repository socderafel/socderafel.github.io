## El Concepte de Transacció i les Propietats ACID

Una **transacció** és un conjunt d'una o més sentències SQL que han d'executar-se com una unitat lògica de treball indivisible. Una transacció ha de satisfer les propietats **ACID**:
- **Atomicitat (*Atomicity*):** O es completen amb èxit totes les operacions o no se n'aplica cap ("tot o res").
- **Consistència (*Consistency*):** La transacció porta la base de dades d'un estat vàlid a un altre estat vàlid respectant totes les regles d'integritat.
- **Aïllament (*Isolation*):** Les operacions d'una transacció són invisibles per a altres transaccions concurrents fins que s'ha confirmat.
- **Durabilitat (*Durability*):** Un cop confirmada la transacció, els seus canvis són permanents i sobreviuran fins i tot a una fallada sobtada del sistema.

## Gestió Transaccional en JDBC

Per defecte, qualsevol connexió JDBC opera en mode **autocommit**: cada sentència DML que s'executa es confirma immediatament i de manera irreversible a la base de dades.

Per a controlar transaccions complexes de negoci, hem de seguir el patró:

```java
Connection conn = null;
try {
    conn = DriverManager.getConnection(URL, USUARI, PASSWORD);

    // 1. Desactivem l'autocommit per a iniciar la transacció manualment
    conn.setAutoCommit(false);

    // 2. Executem la primera operació: Restar 500 € del compte d'origen
    try (PreparedStatement psResta = conn.prepareStatement(
            "UPDATE comptes SET saldo = saldo - ? WHERE iban = ?")) {
        psResta.setDouble(1, 500.0);
        psResta.setString(2, "ES11223344");
        psResta.executeUpdate();
    }

    // 3. Executem la segona operació: Sumar 500 € al compte de destí
    try (PreparedStatement psSuma = conn.prepareStatement(
            "UPDATE comptes SET saldo = saldo + ? WHERE iban = ?")) {
        psSuma.setDouble(1, 500.0);
        psSuma.setString(2, "ES99887766");
        psSuma.executeUpdate();
    }

    // 4. Si tot ha funcionat correctament, CONFIRMEM els canvis de forma atòmica
    conn.commit();
    System.out.println("Transferència confirmada amb èxit.");

} catch (SQLException e) {
    // 5. Si qualsevol operació falla, DESFEM completament qualsevol canvi parcial
    if (conn != null) {
        try {
            conn.rollback();
            System.err.println("S'ha desfet la transacció (Rollback) a causa de: " + e.getMessage());
        } catch (SQLException ex) {
            System.err.println("Error en fer rollback: " + ex.getMessage());
        }
    }
} finally {
    // 6. Restaurem el mode autocommit i tanquem la connexió
    if (conn != null) {
        try {
            conn.setAutoCommit(true);
            conn.close();
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```
