## El Paper de la Interfície `ResultSet`

Quan executem una consulta `SELECT` mitjançant `ps.executeQuery()`, el motor de base de dades retorna un objecte **`java.sql.ResultSet`**.

Un `ResultSet` és un cursor lògic que apunta inicialment **just abans de la primera fila** del conjunt de registres obtinguts.

```
       ResultSet (Cursor inicial: abans de la primera fila)
             |
             v  [rs.next()]
+----+----------------------+---------+
| ID | NOM                  | SALDO   |  <--- Fila 1 (retorna true)
+----+----------------------+---------+
| ID | NOM                  | SALDO   |  <--- Fila 2 (retorna true)
+----+----------------------+---------+
             v  [rs.next()]
        (Fi de dades: retorna false)
```

---

## Navegació i Mapatge de Tipus

El mètode principal de navegació és **`rs.next()`**:
- Desplaça el cursor a la següent fila.
- Retorna `true` si hi ha una nova fila vàlida disponible.
- Retorna `false` quan ja no queden més files al conjunt.

Per a obtindre els valors de cada columna s'utilitzen els mètodes `get` tipats, podent fer servir el nom de la columna o el seu número de posició (1-indexat):

```java
String sql = "SELECT id, nom, saldo, data_alta FROM clients WHERE actiu = ?";

List<Client> llistaClients = new ArrayList<>();

try (PreparedStatement ps = connexio.prepareStatement(sql)) {
    ps.setBoolean(1, true);

    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            // Extracció tipada de dades
            int id = rs.getInt("id");
            String nom = rs.getString("nom");
            double saldo = rs.getDouble("saldo");
            LocalDate dataAlta = rs.getDate("data_alta").toLocalDate();

            // Mapatge a un objecte pur de domini Java (DTO/Model)
            Client c = new Client(id, nom, saldo, dataAlta);
            llistaClients.add(c);
        }
    }
}
```

---

## Tancament Segur de Cursors

Un `ResultSet` manté un cursor obert i bloqueja recursos en el servidor de base de dades. És fonamental incloure'l sempre en una estructura **`try-with-resources`** per a garantir el seu tancament immediat tan bon punt finalitze la lectura.
