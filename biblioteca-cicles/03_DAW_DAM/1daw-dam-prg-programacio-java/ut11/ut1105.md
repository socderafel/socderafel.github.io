## La Necessitat del Desacoblament Arquitectònic

Mesclar sentències SQL i consultes JDBC directament dins dels botons d'una interfície gràfica o dins de la lògica de negoci empresarial és un greu antipatró de disseny (*codi espagueti*). Si demà es canvia el motor de base de dades o el nom d'una taula, caldria refer tot el projecte.

L'arquitectura per capes divideix l'aplicació en responsabilitats ben delimitades:
1. **Capa de Presentació (UI / Controlador):** Interactua amb l'usuari.
2. **Capa de Lògica de Negoci (Service):** Aplica regles de domini, càlculs i polítiques d'empresa.
3. **Capa d'Accés a Dades (DAO):** Responsable exclusiva de comunicar-se amb el magatzem físic de dades.

## Els Components del Patró DAO

```
[ Capa de Negoci (Servei) ]
            |
            | usa la interfície abstracta
            v
<<interface>> UsuariDAO  <---------+
            ^                      |
            | implementa           | transfereix objectes purs de dades
            |                      v
   UsuariDAOJDBCImpl <--------> [ Usuari (Model / DTO) ]
            |
    Sentències SQL
            v
 [ Base de Dades MySQL ]
```

### 1. Model / DTO (*Data Transfer Object*)
Una classe pura Java (POJO) que representa l'entitat de negoci (ex: `Producte`).

### 2. La Interfície DAO
Defineix les operacions abstractes CRUD (Create, Read, Update, Delete) sense cap detall d'implementació:

```java
public interface ProducteDAO {
    void inserir(Producte p) throws SQLException;
    Producte obtindrePerId(int id) throws SQLException;
    List<Producte> obtindreTots() throws SQLException;
    boolean actualitzar(Producte p) throws SQLException;
    boolean esborrar(int id) throws SQLException;
}
```

### 3. La Implementació Concreta DAO
La classe que conté el codi JDBC real (`PreparedStatement`, `ResultSet`, SQL):

```java
public class ProducteDAOImpl implements ProducteDAO {
    private final Connection connexio;

    public ProducteDAOImpl(Connection connexio) {
        this.connexio = connexio;
    }

    @Override
    public Producte obtindrePerId(int id) throws SQLException {
        String sql = "SELECT id, nom, preu, estoc FROM productes WHERE id = ?";
        try (PreparedStatement ps = connexio.prepareStatement(sql)) {
            ps.setInt(1, id);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return new Producte(
                        rs.getInt("id"),
                        rs.getString("nom"),
                        rs.getDouble("preu"),
                        rs.getInt("estoc")
                    );
                }
            }
        }
        return null;
    }
    // Implementació de la resta de mètodes CRUD...
}
```
