## L'Arquitectura de Connexió de Java

**JDBC (Java Database Connectivity)** és una especificació d'accés a dades que defineix un conjunt uniforme d'interfícies (`Connection`, `Statement`, `PreparedStatement`, `ResultSet`) contingudes en el paquet fonamental `java.sql`.

Això permet que els programadors Java puguen escriure codi idèntic independentment de si la base de dades resident al servidor és MySQL, PostgreSQL, Oracle, MariaDB o SQLite.

```
+-------------------------------------------------------------+
|                     Aplicació Java (Codi de Negoci)         |
+-------------------------------------------------------------+
                              |
                     API JDBC (java.sql.*)
                              |
+-------------------------------------------------------------+
|           Gestor de Controladors (DriverManager / SPI)      |
+-------------------------------------------------------------+
                              |
       +----------------------+----------------------+
       |                                             |
[Driver MySQL (JDBC Type 4)]             [Driver PostgreSQL]
       |                                             |
       v                                             v
 Servidor MySQL (Port 3306)              Servidor PostgreSQL (5432)
```

---

## Estructura de la Cadena de Connexió (JDBC URL)

Cada motor de base de dades s'identifica mitjançant una adreça de localització uniforme (**JDBC URL**) amb el format:

`jdbc:subprotocol://servidor:port/nom_base_dades?parametres`

Exemples reals:
- **MySQL:** `jdbc:mysql://localhost:3306/botiga_db?useSSL=false&serverTimezone=UTC`
- **PostgreSQL:** `jdbc:postgresql://192.168.1.50:5432/inventari_db`
- **SQLite (local en fitxer):** `jdbc:sqlite:dades/empresa.sqlite`

---

## Obertura d'una Connexió

Des de Java 6 i l'estàndard JDBC 4.0, ja no és necessari invocar manualment `Class.forName()`. El gestor `DriverManager` detecta automàticament els controladors disponibles al *classpath* (mecanisme Service Provider Interface - SPI):

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class GestorConnexio {
    private static final String URL = "jdbc:mysql://localhost:3306/empresa_db";
    private static final String USUARI = "app_user";
    private static final String CONTRASENYA = "P@ssw0rd2026!";

    public static Connection obtindreConnexio() throws SQLException {
        // Retorna un objecte físic de connexió activa amb la base de dades
        return DriverManager.getConnection(URL, USUARI, CONTRASENYA);
    }
}
```
