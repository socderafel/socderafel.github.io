## El Model d'Esdeveniments en JavaFX

Una aplicació amb interfície gràfica és **guiada per esdeveniments (*Event-Driven*)**: el programa no segueix un flux seqüencial rígid, sinó que roman en espera passiva fins que l'usuari interacciona (fa clic en un botó, prem una tecla o mou el ratolí).

Quan això ocorre, la JVM construeix un objecte que estén de `javafx.event.Event` i el transmet al component objectiu.

---

## Gestió d'Accions amb Expressions Lambda

La interfície funcional `EventHandler<ActionEvent>` conté el mètode abstracte `handle(ActionEvent event)`. Gràcies a les expressions lambda de Java 8, associar codi a un clic de botó és una operació elegant i d'una sola línia:

```java
Button botoCalcular = new Button("Calcular Total");

// Implementació moderna amb expressió lambda
botoCalcular.setOnAction(e -> {
    try {
        double preu = Double.parseDouble(txtPreu.getText());
        int quantitat = Integer.parseInt(txtQuantitat.getText());
        double total = preu * quantitat;
        lblResultat.setText(String.format("Import total: %.2f €", total));
    } catch (NumberFormatException ex) {
        lblResultat.setText("Error: Introdueix valors numèrics vàlids.");
    }
});
```

## Propietats Observables i Enllaç Reactiu (*Binding*)

JavaFX introdueix el concepte de **Propietats Observables** (`StringProperty`, `IntegerProperty`, `BooleanProperty`, `DoubleProperty`).

El mecanisme de **Binding** permet lligar el valor d'una propietat a una altra de manera reactiva: si la primera canvia, la segona s'actualitza instantàniament:

### 1. Enllaç Unidireccional
```java
TextField txtNom = new TextField();
Label lblSalutacio = new Label();

// La salutació s'actualitza automàticament a cada lletra que l'usuari tecleja!
lblSalutacio.textProperty().bind(txtNom.textProperty());
```

### 2. Deshabilitació Condicional Reactiva de Botons
Podem bloquejar un botó d'enviament mentre un camp de text estiga buit sense escriure cap listener manual:

```java
TextField txtDni = new TextField();
Button botoEnviar = new Button("Tramitar Sol·licitud");

// El botó s'inhabilita automàticament si el camp de text està buit
botoEnviar.disableProperty().bind(txtDni.textProperty().isEmpty());
```
