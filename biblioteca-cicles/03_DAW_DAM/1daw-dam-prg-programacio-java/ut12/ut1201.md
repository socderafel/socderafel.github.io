## La Metàfora Teatral de JavaFX

JavaFX utilitza una intuïtiva analogia del món del teatre per a estructurar les seues aplicacions gràfiques:

```
+-------------------------------------------------------------+
| Stage (Finestra física del SO: títol, vora, tancar)        |
|  +-------------------------------------------------------+  |
|  | Scene (L'escena visible continguda a la finestra)     |  |
|  |   +-------------------------------------------------+ |  |
|  |   | Node Arrel (Root Node - Ex: BorderPane, VBox)   | |  |
|  |   |   - Controls interactius: Botons, Text, Taules  | |  |
|  |   +-------------------------------------------------+ |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

1. **`Stage` (L'Escenari):** Representa la finestra superior del sistema operatiu (finestra principal `primaryStage`).
2. **`Scene` (L'Escena):** És el contenidor de tot el graf d'elements visuals que es mostren dins d'un `Stage`. Un mateix escenari pot canviar d'escena (per exemple per a passar de la pantalla de login al panell d'administració).
3. **`Node` (Els Actors):** Cada element visual individual (botó, etiqueta, camp de text, gràfic).

## El Cicle de Vida d'una Aplicació JavaFX

Tota aplicació gràfica ha d'estendre la classe abstracta **`javafx.application.Application`**. La màquina virtual gestiona automàticament tres mètodes fonamentals en el seu cicle de vida:

1. **`init()`:** S'executa primer en un fil de càrrega per a inicialitzar dades prèvies o connexions (opcional).
2. **`start(Stage primaryStage)`:** **Obligatori.** S'executa en el fil gràfic (*JavaFX Application Thread*) per a construir i mostrar la interfície.
3. **`stop()`:** S'executa en tancar l'aplicació per a alliberar recursos i tancar connexions (opcional).

```java
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.StackPane;
import javafx.stage.Stage;

public class HolaJavaFX extends Application {

    @Override
    public void start(Stage primaryStage) {
        // 1. Creem els components visuals
        Label etiqueta = new Label("Benvinguts a JavaFX modern!");

        // 2. Creem el contenidor arrel
        StackPane root = new StackPane();
        root.getChildren().add(etiqueta);

        // 3. Creem l'escena especificant amplada i alçada en píxels
        Scene scene = new Scene(root, 400, 250);

        // 4. Configurem i mostrem l'escenari
        primaryStage.setTitle("La Meva Primera App JavaFX");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        // Llançador estàndard que arrenca el runtime de JavaFX
        launch(args);
    }
}
```
