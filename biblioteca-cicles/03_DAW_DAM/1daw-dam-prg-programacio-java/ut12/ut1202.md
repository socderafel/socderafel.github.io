## El Concepte d'Arbre de Nodes (*Scene Graph*)

La interfície d'una aplicació JavaFX s'estructura com un **arbre jeràrquic dirigit acíclic** anomenat **Scene Graph**:
- **Node Arrel (*Root Node*):** L'element superior de l'escena (habitualment un panell de disseny o Layout).
- **Nodes Branca (*Branch Nodes*):** Contenidors intermedis que agrupen altres contenidors o controls.
- **Nodes Fulla (*Leaf Nodes*):** Components terminals d'interacció visual (botons, etiquetes, camps de text).

---

## Els Principals Panells de Disposició (*Layout Panes*)

JavaFX prohibeix el posicionament absolut fix amb coordenades rígides (perquè es trencaria en redimensionar la finestra o canviar de resolució). En el seu lloc s'utilitzen gestors de disposició adaptatius:

| Panell de Disseny | Principi de Disposició | Cas d'Ús Típic |
| :--- | :--- | :--- |
| **`VBox`** | Apila els elements fills de forma **vertical** (un davall de l'altre). | Menús laterals, formularis lineals. |
| **`HBox`** | Col·loca els elements fills de forma **horitzontal** (un al costat de l'altre). | Barres d'eines, botoneres inferiors (Acceptar/Cancel·lar). |
| **`BorderPane`** | Divideix l'espai en 5 regions: `Top`, `Bottom`, `Left`, `Right`, `Center`. | Estructura mestra d'aplicacions complexes. |
| **`GridPane`** | Organitza els components en una quadrícula bidimensional de files i columnes. | Formularis d'entrada amb etiquetes i camps alineats. |
| **`StackPane`** | Superposa els elements uns damunt dels altres en l'eix Z. | Missatges emergents damunt d'imatges, indicadors de càrrega. |

---

## Exemple d'Organització amb `BorderPane` i `GridPane`

```java
BorderPane layoutPrincipal = new BorderPane();

// Capçalera superior
Label titol = new Label("Panell de Gestió d'Usuaris");
layoutPrincipal.setTop(titol);

// Formulari central amb quadrícula
GridPane formulari = new GridPane();
formulari.setHgap(10); // Separació horitzontal en píxels
formulari.setVgap(10); // Separació vertical en píxels

formulari.add(new Label("Nom d'usuari:"), 0, 0); // Columna 0, Fila 0
formulari.add(new TextField(), 1, 0);            // Columna 1, Fila 0

formulari.add(new Label("Correu electrònic:"), 0, 1);
formulari.add(new TextField(), 1, 1);

layoutPrincipal.setCenter(formulari);

// Botonera inferior alineada a la dreta
HBox botons = new HBox(15, new Button("Netejar"), new Button("Guardar"));
botons.setAlignment(Pos.CENTER_RIGHT);
layoutPrincipal.setBottom(botons);
```
