## El Patró Model-Vista-Controlador (MVC) en JavaFX

Construir interfícies gràfiques programant manualment cada botó i disseny en codi Java pur produeix classes rígides i difícils de mantindre. L'estàndard professional de la indústria separa l'aplicació en tres rols:

```
+-------------------------------------------------------------+
|                          VISTA                              |
|           Fitxer FXML declaratiu basat en XML               |
|      (Dissenyat visualment amb Gluon SceneBuilder)          |
+-------------------------------------------------------------+
                              ^
                              | vinculació mitjançant @FXML
                              v
+-------------------------------------------------------------+
|                       CONTROLADOR                           |
|               Classe pura Java controladora                 |
|       (Gestiona esdeveniments, accions i inicialització)    |
+-------------------------------------------------------------+
                              ^
                              | consulta i modifica dades
                              v
+-------------------------------------------------------------+
|                          MODEL                              |
|           Classes de negoci i persistència (DAO)            |
+-------------------------------------------------------------+
```

## El Llenguatge Declaratiu FXML

Un fitxer **FXML** és un document XML que descriu la disposició de components de l'arbre de nodes:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<?import javafx.scene.control.*?>
<?import javafx.scene.layout.*?>

<VBox xmlns="http://javafx.com/javafx"
      xmlns:fx="http://javafx.com/fxml"
      fx:controller="com.empresa.controllers.PrincipalController"
      spacing="15" alignment="CENTER">

    <Label text="Benvingut al Sistema" />
    <TextField fx:id="txtUsuari" promptText="Usuari..." />
    <Button fx:id="btnAccedir" text="Iniciar Sessió" onAction="#gestionarAccedir" />
    <Label fx:id="lblEstat" />

</VBox>
```

## La Classe Controladora i l'Anotació `@FXML`

El controlador és una classe Java ordinària que vincula els elements del fitxer XML mitjançant l'anotació **`@FXML`**:

```java
package com.empresa.controllers;

import javafx.fxml.FXML;
import javafx.fxml.Initializable;
import javafx.scene.control.Button;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;
import java.net.URL;
import java.util.ResourceBundle;

public class PrincipalController implements Initializable {

    // Vinculació amb els identificadors fx:id de l'arxiu FXML
    @FXML private TextField txtUsuari;
    @FXML private Button btnAccedir;
    @FXML private Label lblEstat;

    @Override
    public void initialize(URL location, ResourceBundle resources) {
        // Codi d'inicialització que s'executa automàticament després de carregar el FXML
        lblEstat.setText("Introdueix les teues credencials.");
    }

    // Vinculació amb l'atribut onAction="#gestionarAccedir"
    @FXML
    private void gestionarAccedir() {
        String usuari = txtUsuari.getText();
        if (usuari.isBlank()) {
            lblEstat.setText("Error: L'usuari és obligatori.");
        } else {
            lblEstat.setText("Sessió iniciada amb l'usuari: " + usuari);
        }
    }
}
```

## Càrrega del FXML en l'Aplicació Principal

La classe `FXMLLoader` transforma el fitxer XML en el graf de nodes real al Heap:

```java
public class App extends Application {
    @Override
    public void start(Stage stage) throws Exception {
        FXMLLoader loader = new FXMLLoader(getClass().getResource("/vistes/principal.fxml"));
        Parent root = loader.load();

        Scene scene = new Scene(root, 600, 400);
        stage.setTitle("Aplicació MVC amb FXML");
        stage.setScene(scene);
        stage.show();
    }
}
```
