## El Catàleg de Controls de JavaFX

JavaFX proporciona una extensa biblioteca de controls d'usuari continguts en el paquet `javafx.scene.control`:
- **Entrada de Text:** `TextField` (text en una sola línia), `PasswordField` (text emmascarat amb punts), `TextArea` (text multillínia amb scroll).
- **Selecció i Opcions:** `CheckBox` (caselles de verificació múltiples independents), `RadioButton` (agrupats en un `ToggleGroup` per a opcions mútuament excloents), `ComboBox<T>` (llistes desplegables de selecció).
- **Visualització i Acció:** `Label` (etiquetes de text i icones), `Button` (botons d'acció), `ProgressBar` (indicadors de progrés).

## El Component Estrella: `TableView<T>`

`TableView` és el component més potent per a la visualització empresarial de col·leccions de dades en forma de taula amb columnes redimensionables i ordenació dinàmica en fer clic a les capçaleres.

### 1. Definició de Columnes (`TableColumn`)
Cada columna s'enllaça a un atribut del model de dades mitjançant una factoria de valor de cel·la (`PropertyValueFactory`):

```java
TableView<Producte> taula = new TableView<>();

// Columna 1: Codi
TableColumn<Producte, Integer> colId = new TableColumn<>("Identificador");
colId.setCellValueFactory(new PropertyValueFactory<>("id"));

// Columna 2: Nom
TableColumn<Producte, String> colNom = new TableColumn<>("Descripció del Producte");
colNom.setCellValueFactory(new PropertyValueFactory<>("nom"));

// Columna 3: Preu
TableColumn<Producte, Double> colPreu = new TableColumn<>("Preu Unitari (€)");
colPreu.setCellValueFactory(new PropertyValueFactory<>("preu"));

taula.getColumns().addAll(colId, colNom, colPreu);
```

### 2. Alimentació amb `ObservableList`
Les taules i llistes de JavaFX no utilitzen simples `ArrayList`, sinó una **`ObservableList`** (creada amb `FXCollections.observableArrayList()`). Això permet que la taula es redibuixe automàticament si afegim o eliminem un element de la llista sense haver de refrescar la pantalla manualment:

```java
ObservableList<Producte> dades = FXCollections.observableArrayList(
    new Producte(1, "Portàtil Dell", 799.0, 10),
    new Producte(2, "Monitor 27''", 220.5, 25),
    new Producte(3, "Teclat Mecànic", 65.0, 40)
);

taula.setItems(dades);
```
