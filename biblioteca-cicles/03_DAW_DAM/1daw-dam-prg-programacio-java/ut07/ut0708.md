# 7.8 Esborrat de registres (DELETE)

Per a eliminar un registre només cal desplazar el cursor al registre desitjat i anomenar al mètode:

- **`void deleteRow()`**: elimina el registre actual del *ResultSet* i també de la base de dades.

El següent codi esborra el tercer registre de la taula `clientes`:

```sql
// Creamos un Statement scrollable y modificable
Statement stmt = conn.createStatement(ResultSet.TYPE_SCROLL_SENSITIVE, ResultSet.CONCUR_UPDATABLE);

// Ejecutamos un SELECT y obtenemos la tabla clientes en un ResultSet
String sql = "SELECT * FROM clientes";
ResultSet rs = stmt.executeQuery(sql);

// Desplazamos el cursor al tercer registro
rs.absolute(3)
rs.deleteRow();
```
