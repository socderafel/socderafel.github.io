## El Significat de `static` en Java

Per defecte, cada atribut i mètode d'una classe pertany a cada **instància concreta** que es crea en memòria. No obstant això, quan declarem un membre com a **`static`**, aquest passa a pertànyer a la **classe en si mateixa**, compartint-se per totes les instàncies.

```
+-------------------------------------------------------+
|                    CLASSE MATEMATICA                  |
|  [Memòria de Metadades / Metaspace]                   |
|  - static double PI = 3.1415926535                    |
|  - static double sumar(double a, double b)            |
+-------------------------------------------------------+
        ^
        | Invocació directa sense instanciar: Matematica.sumar(5, 7)
```

## Tipus de Membres Estàtics

### 1. Variables Estàtiques (Variables de Classe)
Existeix una única instància d'aquesta variable en tota la màquina virtual Java, sense importar quants objectes es creen. És ideal per a comptadors globals o generadors d'identificadors únics:

```java
public class Empleat {
    // Variable estàtica compartida per a generar IDs autoincrementals
    private static int seguentId = 1001;

    // Atributs d'instància particulars
    private int id;
    private String nom;

    public Empleat(String nom) {
        this.id = seguentId++; // Assigna l'ID i incrementa el comptador comú
        this.nom = nom;
    }

    public int getId() { return id; }
    public String getNom() { return nom; }
}
```

### 2. Mètodes Estàtics (Mètodes de Classe)
Són mètodes que poden ser invocats directament mitjançant el nom de la classe, sense necessitat de crear cap objecte previ amb `new` (com `Math.sqrt()` o `Integer.parseInt()`):

> **Regla Crítica:** Un mètode `static` **NO pot accedir directament a atributs ni mètodes d'instància**, ni pot utilitzar la paraula clau `this`, perquè no s'executa en el context de cap objecte particular!

```java
public class Validador {
    // Mètode pur d'utilitat
    public static boolean esNifValid(String nif) {
        if (nif == null || nif.length() != 9) return false;
        // Lògica de comprovació del dígit de control
        return true;
    }
}
```

### 3. Constants Globals: `public static final`
Quan combinem `public`, `static` i `final`, definim constants universals accessibles des de qualsevol punt del codi que no poden canviar el seu valor un cop inicialitzades. Per convenció s'escriuen en majúscules separades per guió baix:

```java
public class Configuracio {
    public static final String VERSIO_SISTEMA = "2.4.0";
    public static final int TEMPS_EXPIRACIO_SEGONS = 3600;
}
```
