## 1. El Sistema de Tipus de Java i els 8 Tipus Primitius

En Java, totes les dades es classifiquen en dues grans categories: **Tipus Primitius** (que emmagatzemen directament el valor binari pur a la pila d'execució *Stack*) i **Tipus de Referència** (que emmagatzemen la direcció de memòria d'un objecte allotjat a la memòria dinàmica *Heap*).

Hi ha exactament **8 tipus de dades primitius**, les dimensions i comportaments dels quals estan rigorosament estandarditzats i no varien entre sistemes operatius:

| Tipus | Mida en Memòria | Valors Mínim i Màxim / Rang | Valor per Defecte | Exemple de Literal |
| :--- | :--- | :--- | :--- | :--- |
| `byte` | 8 bits (1 byte) | $-128$ a $127$ | `0` | `(byte) 42` |
| `short` | 16 bits (2 bytes) | $-32.768$ a $32.767$ | `0` | `(short) 1024` |
| `int` | 32 bits (4 bytes) | $-2.147.483.648$ a $2.147.483.647$ (aprox $\pm 2 	imes 10^9$) | `0` | `100_000` |
| `long` | 64 bits (8 bytes) | $-2^{63}$ a $2^{63} - 1$ | `0L` | `5_000_000_000L` (requereix sufix `L`) |
| `float` | 32 bits (4 bytes) | Coma flotant simple precisió IEEE 754 | `0.0f` | `3.1416f` (requereix sufix `f`) |
| `double` | 64 bits (8 bytes) | Coma flotant doble precisió IEEE 754 | `0.0d` | `3.141592653589793` |
| `char` | 16 bits (2 bytes) | Un sol caràcter Unicode (`\u0000` a `\uffff`, 0 a 65.535) | `\u0000` | `'A'`, `'\n'`, `'\u00e0'` |
| `boolean`| 1 bit lògic | `true` o `false` | `false` | `true`, `false` |

## 2. Literals Numèrics i Separadors Digitals

Java permet escriure literals en múltiples bases numèriques i millorar la llegibilitat de grans xifres mitjançant guions baixos (`_`):

```java
// Bases numèriques
int decimal = 26;          // Base 10
int octal = 032;           // Base 8 (comença amb 0)
int hexadecimal = 0x1A;    // Base 16 (comença amb 0x)
int binari = 0b0001_1010;  // Base 2 (comença amb 0b, Java 7+)

// Separadors per a alta llegibilitat (sense impacte en la compilació)
long targetaCredit = 4556_1234_8901_2345L;
double distanciaMetres = 1_495_978.707_000;
```

## 3. Inferència de Tipus de Variables Locals: `var`

A partir de Java 10, es va introduir la paraula clau `var` per a reduir la verbositat del codi mantenint el **tipatge estàtic al 100%**:
- El compilador `javac` infereix el tipus estàtic exacte de la variable a partir de l'expressió d'inicialització.
- **No és tipatge dinàmic com JavaScript o Python**: una vegada deduït el tipus, la variable no pot emmagatzemar cap dada d'un altre tipus.

```java
var nomAlumne = "Laura Soler";           // Inferred com a String
var horesSetmanals = 4;                 // Inferred com a int
var mitjana = 8.75;                     // Inferred com a double
var connexio = new ArrayList<String>(); // Evita repetir el tipus a l'esquerra

// nomAlumne = 45; // ERROR DE COMPILACIÓ: Tipus incompatibles (int no pot passar a String)
```

> [!CAUTION] Limitacions Estrictes de `var`
> `var` només es pot utilitzar en **variables locals declarades i inicialitzades simultàniament a l'interior d'un mètode**. Està absolutament prohibit en: atributs de classe, paràmetres de mètodes, tipus de retorn de mètodes o variables sense inicialitzar (`var x;` és invàlid).
