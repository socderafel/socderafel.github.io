## La Superclasse Universal: `java.lang.Object`

En Java, tota classe que definim deriva de forma directa o indirecta de la classe arrel **`java.lang.Object`**. Aquesta classe proporciona mètodes fonamentals que regeixen el comportament de qualsevol entitat en memòria:

| Mètode | Comportament per Defecte d'Object | Comportament quan es Sobreescriu |
| :--- | :--- | :--- |
| `boolean equals(Object obj)` | Compara referències de memòria (`this == obj`) | Compara la igualtat de l'estat o contingut lògic dels atributs |
| `int hashCode()` | Retorna un enter basat en l'adreça de memòria de la JVM | Retorna un enter calculat a partir dels camps clau de negoci |
| `String toString()` | Retorna `NomClasse@Hexadecimal` | Retorna una descripció textual humana comprensible |

## El Contracte `equals()` i `hashCode()`

Quan treballem amb col·leccions basades en hash com `HashSet` o `HashMap`, aquest contracte és **sagrat**:

> **Regla d'or:** Si `a.equals(b)` és `true`, aleshores `a.hashCode()` ha de ser **obligatòriament igual** a `b.hashCode()`.

```java
import java.util.Objects;

public class Client {
    private String nif;
    private String nom;

    public Client(String nif, String nom) {
        this.nif = nif;
        this.nom = nom;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true; // Mateixa adreça de memòria
        if (o == null || getClass() != o.getClass()) return false; // Tipus diferent
        Client client = (Client) o;
        return Objects.equals(nif, client.nif); // Dos clients són iguals si tenen el mateix NIF
    }

    @Override
    public int hashCode() {
        return Objects.hash(nif); // El hash es calcula a partir del mateix camp clau
    }
}
```

## Comparació i Ordenació: `Comparable` vs `Comparator`

Quan volem ordenar una llista d'objectes (`Collections.sort(llista)`):

1. **`Comparable<T>` (Ordre Natural):** S'implementa en la pròpia classe i obliga a escriure `compareTo(T altre)`:
   - Retorna número negatiu si `this < altre`.
   - Retorna 0 si `this.equals(altre)`.
   - Retorna número positiu si `this > altre`.
2. **`Comparator<T>` (Ordre Personalitzat):** Permet definir múltiples criteris externs sense tocar la classe original (per exemple, ordenar per cognom, per salari descendent, per edat, etc.):

```java
// Utilitzant lambda moderna o Comparator.comparing
llistaClients.sort(Comparator.comparing(Client::getNom));
```
