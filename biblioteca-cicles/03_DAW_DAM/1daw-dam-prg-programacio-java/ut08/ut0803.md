## El Paper de les Interfícies en Java

Una **interfície** (`interface`) és un contracte de comportament 100% formal. Estableix **què** ha de fer una classe, però no **com** ho ha de fer. Les interfícies resolen dues necessitats cabdals del desenvolupament de programari:
1. **Desacoblament:** Permet que dos components de programari interactuen a través d'una interfície comuna sense conéixer els detalls interns l'un de l'altre.
2. **Herència Múltiple de Tipus:** Una classe en Java només pot estendre una única superclasse (`extends`), però pot implementar **totes les interfícies que desitge** (`implements Interficie1, Interficie2, Interficie3`).

---

## Anatomia d'una Interfície Moderna (Java 8+)

Des de Java 8 i posteriors, les interfícies han evolucionat notablement:

```java
public interface ReproductorsMedia {
    // 1. Constants (són automàticament public static final)
    int VOLUM_MAXIM = 100;

    // 2. Mètodes abstractes ordinaris (són automàticament public abstract)
    void reproduir();
    void pausar();
    void aturar();

    // 3. Mètodes default (amb implementació per defecte reutilitzable per les classes)
    default void reiniciar() {
        aturar();
        reproduir();
        System.out.println("Reproductor reiniciat.");
    }

    // 4. Mètodes estàtics d'utilitat
    static boolean esVolumValid(int volum) {
        return volum >= 0 && volum <= VOLUM_MAXIM;
    }
}
```

---

## Implementació en Classes Concretes

Quan una classe implementa una interfície, utilitza la paraula clau `implements`:

```java
public class ReproductorMp3 implements ReproductorsMedia {
    private String arxiuActual;

    public ReproductorMp3(String arxiu) {
        this.arxiuActual = arxiu;
    }

    @Override
    public void reproduir() {
        System.out.println("Reproduint MP3: " + arxiuActual);
    }

    @Override
    public void pausar() {
        System.out.println("Pausat MP3: " + arxiuActual);
    }

    @Override
    public void aturar() {
        System.out.println("Aturat MP3.");
    }
    // El mètode reiniciar() s'hereta directament gràcies a la definició default!
}
```
