## Què és el Polimorfisme?

El mot **polimorfisme** prové del grec i significa "moltes formes". En programació orientada a objectes, el polimorfisme és la capacitat que té una referència de tipus superclasse o interfície d'apuntar a instàncies de qualsevol de les seues subclasses o implementacions:

```java
// Assignació polimòrfica: La variable és del tipus general Figura, però l'objecte real és Cercle
Figura f1 = new Cercle("Roig", 5.0);
Figura f2 = new Rectangle("Blau", 4.0, 6.0);

// Ambdós responen a la mateixa ordre calcularArea(), però cadascun amb la seua pròpia lògica
System.out.println("Àrea f1: " + f1.calcularArea());
System.out.println("Àrea f2: " + f2.calcularArea());
```

---

## Resolució Dinàmica de Mètodes (*Late Binding*)

Quan el compilador veu `f1.calcularArea()`, només verifica que la classe `Figura` té declarat el mètode `calcularArea()`. No sap quina versió concreta s'ha d'executar.

En temps d'execució, la màquina virtual Java inspecciona l'adreça de memòria de l'objecte real al Heap, comprova la seua taula de mètodes virtuals (*vtable*) i executa el mètode de la subclasse que corresponga. Aquest procés s'anomena **enllaç dinàmic (*late binding*)**.

---

## Càstings de Referències i Operador `instanceof`

Quan tenim una variable d'una superclasse, només podem cridar als mètodes declarats en eixa superclasse. Si volem accedir a mètodes exclusius de la subclasse, cal realitzar un **càsting descendent (*downcasting*)**.

Per a evitar l'error fatal `ClassCastException`, cal verificar prèviament el tipus real de l'objecte mitjançant l'operador `instanceof`.

### Modern: Pattern Matching per a `instanceof` (Java 16+)
En versions antigues calia fer la comprovació i després el càsting en dues línies. Amb el modern **Pattern Matching**, la comprovació i la declaració de la variable tipada es fan en un sol pas:

```java
// Forma clàssica antiga (Java 7 / 8)
if (figura instanceof Cercle) {
    Cercle c = (Cercle) figura; // Càsting manual explícit
    System.out.println("Radi: " + c.getRadi());
}

// Forma moderna (Java 16+) amb Pattern Matching
if (figura instanceof Cercle c) {
    // La variable 'c' ja està creada i disponible amb tipus Cercle!
    System.out.println("Radi: " + c.getRadi());
}
```
