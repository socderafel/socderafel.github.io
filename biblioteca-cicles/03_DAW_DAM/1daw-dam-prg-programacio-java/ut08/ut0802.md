## Què és una Classe Abstracta?

En el disseny d'aplicacions complexes ens trobem sovint amb conceptes molt generals que no tenen una representació concreta al món real. Per exemple, té sentit instanciar una "Figura Geomètrica" genèrica? No: podem dibuixar un *Cercle*, un *Rectangle* o un *Triangle*, però una "Figura" en abstracte no té una forma determinada.

Una **classe abstracta** és una classe declarada amb la paraula clau `abstract` que:
1. **NO es pot instanciar directament** amb `new`.
2. Pot contindre tant mètodes ordinaris completament implementats (amb codi dins de `{}`) com **mètodes abstractes** (sense cos, finalitzats en punt i coma `;`).
3. Serveix com a base fonamental per a forçar que totes les subclasses derivades implementen de manera obligatòria els mètodes abstractes declarats.

```
                  +---------------------------+
                  |  abstract class Figura    |
                  |  - color: String          |
                  |  + abstract calcularArea()|
                  +---------------------------+
                                |
                 +--------------+--------------+
                 |                             |
      +----------------------+      +----------------------+
      |    class Cercle      |      |   class Rectangle    |
      |  - radi: double      |      |  - base, alcada      |
      |  + calcularArea() {} |      |  + calcularArea() {} |
      +----------------------+      +----------------------+
```

---

## Exemple d'Implementació

```java
public abstract class Figura {
    private String color;

    public Figura(String color) {
        this.color = color;
    }

    public String getColor() {
        return color;
    }

    // Mètode abstracte: NO té cos de codi. Les subclasses estan OBLIGADES a implementar-lo!
    public abstract double calcularArea();

    public abstract double calcularPerimetre();
}
```

```java
public class Rectangle extends Figura {
    private double base;
    private double alcada;

    public Rectangle(String color, double base, double alcada) {
        super(color);
        this.base = base;
        this.alcada = alcada;
    }

    @Override
    public double calcularArea() {
        return base * alcada;
    }

    @Override
    public double calcularPerimetre() {
        return 2 * (base + alcada);
    }
}
```

Si una subclasse que estén una classe abstracta no implementa **tots** els mètodes abstractes heretats, la subclasse també ha de ser declarada obligatòriament com a `abstract`.
