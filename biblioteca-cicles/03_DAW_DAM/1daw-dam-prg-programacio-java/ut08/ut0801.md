## El Concepte d'Herència (*Inheritance*)

L'**herència** és un mecanisme clau que permet definir una classe nova (**subclasse** o classe derivada) a partir d'una classe existent (**superclasse** o classe base). La subclasse hereta tots els camps i mètodes accessibles de la superclasse, podent:
1. Reutilitzar el codi de la superclasse sense duplicar-lo.
2. Afegir nous atributs i mètodes especialitzats.
3. Modificar el comportament de mètodes heretats mitjançant la **sobreescriptura** (*overriding*).

En Java, l'herència expressa una relació de tipus **"és-un" (*is-a*)**: un `Gos` *és un* `Animal`, un `Gerent` *és un* `Empleat`.

> **Restricció Clau de Java:** Java **NO suporta herència múltiple de classes**. Una classe només pot estendre directament una única superclasse (`extends ClasseUnica`).

---

## Sintaxi d'Extensió i Ús de `super`

```java
// Superclasse base
public class Empleat {
    private String nif;
    private String nom;
    private double souBase;

    public Empleat(String nif, String nom, double souBase) {
        this.nif = nif;
        this.nom = nom;
        this.souBase = souBase;
    }

    public double calcularSouNet() {
        return souBase * 0.82; // Retenció IRPF base
    }

    // Getters i Setters...
}
```

```java
// Subclasse especialitzada
public class Gerent extends Empleat {
    private double bonusResponsabilitat;

    public Gerent(String nif, String nom, double souBase, double bonus) {
        // Crida obligada al constructor de la superclasse en la primera línia
        super(nif, nom, souBase);
        this.bonusResponsabilitat = bonus;
    }

    // Sobreescriptura del mètode de la superclasse
    @Override
    public double calcularSouNet() {
        // Podem aprofitar el càlcul de la superclasse usant super.metode()
        double souBaseNet = super.calcularSouNet();
        return souBaseNet + (bonusResponsabilitat * 0.80);
    }
}
```

---

## La Importància de l'Anotació `@Override`

L'anotació `@Override` no és estrictament obligatòria perquè el codi compile, però és una **bona pràctica crítica d'enginyeria**. Indica al compilador que la intenció expressa del programador és sobreescriure un mètode de la superclasse. Si escrivim malament el nom o els paràmetres (per exemple `calcularSou(double factor)` en lloc de `calcularSouNet()`), el compilador llançarà un error immediat evitant errors silenciosos de sobrecàrrega involuntària.
