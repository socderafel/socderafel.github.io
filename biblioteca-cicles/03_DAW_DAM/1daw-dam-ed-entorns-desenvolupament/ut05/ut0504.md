**JUnit** és el marc de proves unitàries més utilitzat del món a l'ecosistema Java. La seua versió actual, **JUnit 5 (JUnit Jupiter)**, ofereix un model d'anotacions elegant i una bateria potent d'assercions per verificar el comportament dels mètodes de manera completament automatitzada.

---

## 🏷️ Cicle de Vida d'un Test en JUnit 5

```java
import org.junit.jupiter.api.*;
import static org.junit.jupiter.api.Assertions.*;

class CalculadoraTest {

    private Calculadora calc;

    @BeforeAll
    static void abansDeTot() {
        // S'executa una sola vegada abans de tots els tests de la classe
    }

    @BeforeEach
    void inicialitzar() {
        // S'executa ABANS de CADA test individual
        calc = new Calculadora();
    }

    @Test
    @DisplayName("Suma simple de dos enters positius")
    void testSumarPositius() {
        int resultat = calc.sumar(4, 6);
        assertEquals(10, resultat, "La suma de 4 + 6 hauria de ser 10");
    }

    @Test
    @DisplayName("La divisió per zero ha de llançar ArithmeticException")
    void testDivisioPerZero() {
        assertThrows(ArithmeticException.class, () -> {
            calc.dividir(10, 0);
        });
    }

    @AfterEach
    void netejar() {
        // S'executa DESPRÉS de CADA test individual
    }

    @AfterAll
    static void finalDeTot() {
        // S'executa una sola vegada al final de tota la suite
    }
}
```

---

## 🔍 Assercions Principals (`org.junit.jupiter.api.Assertions.*`)

- `assertEquals(esperat, real)` : Comprova la igualtat de valors o objectes (`equals`).
- `assertNotEquals(esperat, real)` : Comprova que siguen diferents.
- `assertTrue(condicio)` : Comprova que l'expressió siga certa.
- `assertFalse(condicio)` : Comprova que l'expressió siga falsa.
- `assertNull(objecte)` / `assertNotNull(objecte)` : Comprova si és nul o no nul.
- `assertThrows(Excepcio.class, executable)` : Verifica que s'haja llançat una excepció concreta.
