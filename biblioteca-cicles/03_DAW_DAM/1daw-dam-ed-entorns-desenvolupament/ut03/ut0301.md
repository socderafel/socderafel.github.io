A principis dels anys 90 existien desenes de mètodes i notacions diferents per dissenyar programari orientat a objectes (el mètode Booch, OMT de Rumbaugh, OOSE d'Ivar Jacobson), provocant una "guerra de metodologies" que confonia la indústria. A mitjans d'eixa dècada, aquests tres autors (coneguts com els *Tres Amigos*) van unificar els seus treballs a Rational Software, donant lloc a l'**UML (Unified Modeling Language)**, adoptat com a estàndard oficial per l'**OMG (Object Management Group)** en 1997.

---

## 🧭 Els 14 Diagrames d'UML (Versió 2.5)

UML és un llenguatge de modelat visual que es divideix en dues grans branques:

```
┌────────────────────────────────────────────────────────┐
│  LLENGUATGE DE MODELAT UNIFICAT (UML 2.5)              │
├────────────────────────────────────────────────────────┤
│ 1. DIAGRAMES ESTRUCTURALS (Estat Estàtic)              │
│    - Diagrama de Classes (el més important)            │
│    - Diagrama d'Objectes                               │
│    - Diagrama de Components                            │
│    - Diagrama de Desplegament                          │
│    - Diagrama de Paquets                               │
│    - Diagrama d'Estructures Compostes                  │
│    - Diagrama de Perfils                               │
├────────────────────────────────────────────────────────┤
│ 2. DIAGRAMES DE COMPORTAMENT (Estat Dinàmic)           │
│    - Diagrama de Casos d'Ús                            │
│    - Diagrama d'Activitats                             │
│    - Diagrama d'Estats (State Machine)                 │
│    - Diagrames d'Interacció:                           │
│        * Diagrama de Seqüència                         │
│        * Diagrama de Comunicació                       │
│        * Diagrama Global d'Interacció                  │
│        * Diagrama de Temps                             │
└────────────────────────────────────────────────────────┘
```
