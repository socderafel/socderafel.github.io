La reutilització de codi i el polimorfisme són els pilars del paradigma de la programació orientada a objectes. UML proporciona símbols inequívocs per representar la **jerarquia d'herència (generalització)** i la implementació de contractes abstractes (**interfícies**).

---

## 🔺 La Relació de Generalització / Herència

- Es representa amb una **línia sòlida que acaba en una fletxa triangular buida** que apunta cap a la **superclasse**.
- **Semàntica `ÉS-UN` (*IS-A*):** La subclasse hereta automàticament tots els atributs i mètodes públics i protegits de la superclasse.
- **Classes Abstractes:** Aquelles que tenen algun mètode sense implementar i no es poden instanciar directament. S'escriuen amb el nom en *cursiva* o amb l'etiqueta `{abstract}`.

```
                  ┌──────────────────────┐
                  │    FiguraGeometrica  │ (En cursiva = Abstracta)
                  ├──────────────────────┤
                  │ # x : int            │
                  │ # y : int            │
                  ├──────────────────────┤
                  │ + dibuixar() : void  │ (En cursiva = Mètode abstracte)
                  └──────────▲───────────┘
                             │ (Fletxa triangular buida)
              ┌──────────────┴──────────────┐
              │                             │
    ┌──────────────────┐          ┌──────────────────┐
    │     Cercle       │          │    Rectangle     │
    ├──────────────────┤          ├──────────────────┤
    │ - radi : double  │          │ - base : double  │
    │                  │          │ - alcada : double│
    ├──────────────────┤          ├──────────────────┤
    │ + dibuixar()     │          │ + dibuixar()     │
    └──────────────────┘          └──────────────────┘
```

---

## 🔌 Interfícies i Relació de Realització

Una **interfície** és un conjunt de signatures de mètodes que defineixen un contracte que altres classes han de complir:
- Es representa com una classe amb l'estereotip `<<interface>>`.
- La relació entre la classe implementadora i la interfície s'anomena **Realització**: es representa amb una **línia discontínua que acaba en una fletxa triangular buida** que apunta a la interfície.
- *(També es pot representar mitjançant la notació "lollipop" / piruleta: un cercle unit a una línia).*
