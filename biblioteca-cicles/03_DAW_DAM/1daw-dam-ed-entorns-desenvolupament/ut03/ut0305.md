El disseny de diagrames de classes UML no té sentit si no existeix una correspondència directa, matemàtica i biunívoca amb el codi font en llenguatges com Java, C# o TypeScript. Dominar la **traducció sistemàtica d'esquemes a codi (Enginyeria Directa)** i de **codi a esquemes (Enginyeria Inversa)** és una competència professional indispensable.

---

## 🔄 Regles de Correspondència UML $\rightarrow$ Java

| Element en Diagrama UML | Implementació en Codi Java |
| :--- | :--- |
| **Classe simple** | `public class NomClasse Ellipsis` |
| **Classe abstracta** | `public abstract class NomClasse Ellipsis` |
| **Interfície `<<interface>>`** | `public interface NomInterficie Ellipsis` |
| **Herència (Generalització)** | `public class Subclasse extends Superclasse Ellipsis` |
| **Realització d'Interfície** | `public class Classe implements Interficie1, Interficie2 Ellipsis` |
| **Atribut privat `- edat : int`** | `private int edat;` |
| **Atribut públic `+ nom : String`** | `public String nom;` |
| **Associació 1 a 1 (navegable)** | `private Desti desti;` (com a atribut de classe) |
| **Associació 1 a Molts (`0..*`)** | `private List<Desti> llistaDestins = new ArrayList<>();` |

---

## 🛠️ Enginyeria Inversa i Eines CASE

- **Enginyeria Directa (Forward Engineering):** L'IDE o eina CASE genera automàticament l'esquelet de les classes Java (fitxers `.java`, camps, getters, setters i signatures de mètodes) a partir del diagrama gràfic.
- **Enginyeria Inversa (Reverse Engineering):** L'eina escaneja una carpeta amb codi font Java ja existent i construeix de manera automàtica el diagrama de classes UML amb totes les seues associacions i herències.
- **Eines Destacades:**
  - Plugin **PlantUML** (disponible per a IntelliJ IDEA, VS Code i Eclipse).
  - **Visual Paradigm**.
  - **StarUML**.
