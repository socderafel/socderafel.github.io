Una **classe** és la descripció abstracta d'un conjunt d'objectes que comparteixen els mateixos atributs, operacions, relacions i semàntica. En UML, una classe es representa visualment com un **rectangle dividit en tres compartiments horitzontals**:

```
┌────────────────────────────────────────────────────────┐
│                    NomDeLaClasse                       │
├────────────────────────────────────────────────────────┤
│ - atributPrivat : TipusDada                           │
│ + atributPublic : TipusDada = valorPerDefecte          │
│ # atributProtegit : TipusDada                          │
│ ~ atributPaquet : TipusDada                            │
├────────────────────────────────────────────────────────┤
│ + metodePublic() : void                                │
│ + calcularTotal(quantitat : int, preu : double) : double│
│ - validarDades() : boolean                             │
└────────────────────────────────────────────────────────┘
```

---

## 🔒 Modificadors de Visibilitat

L'encapsulament s'expressa mitjançant quatre símbols prefixats:
- **`+` Públic (Public):** Accessible des de qualsevol altra classe del sistema.
- **`-` Privat (Private):** Només accessible des de l'interior de la pròpia classe.
- **`#` Protegit (Protected):** Accessible des de la pròpia classe i des de les seues subclasses heretades.
- **`~` Paquet (Package / Default):** Accessible des de qualsevol classe que pertanya al mateix paquet.

---

## 🏷️ Sintaxi Formal d'Atributs i Mètodes

- **Sintaxi d'Atribut:**
  `visibilitat nom : tipus [multiplicitat] = valorInicial`
  *(Si l'atribut és estàtic / de classe se **subratlla**).*
- **Sintaxi d'Operació / Mètode:**
  `visibilitat nom(paràmetre1 : tipus, ...) : tipusRetorn`
  *(Si el mètode és estàtic se **subratlla**; si és abstracte s'escriu en **cursiva**).*
