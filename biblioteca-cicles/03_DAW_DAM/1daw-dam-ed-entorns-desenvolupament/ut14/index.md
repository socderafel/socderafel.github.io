Dado el código sin documentar empleado1.java, se pide documentar el código para genere una documentación igual a la aportada en la carpeta javadoc Ojo: Observa que debes documentar también los atributos y añadir código html en los comentarios

public class Empleado {

//Atributos

private String nombre;

private String apellido;

private int edad;

private double salario;

//Metodos publicos

public boolean plus(double sueldoPlus) {

boolean aumento = false;

if (edad > 40 && compruebaNombre()) {

salario += sueldoPlus;

aumento = true;

}

return aumento;

}

//Metodos privados

private boolean compruebaNombre() {

if (nombre.equals("")) {

return false;

}

return true;

}

//Constructores

public Empleado() {

this("", "", 0, 0);

}

public Empleado(String nombre, String apellido, int edad, double salario) {

this.nombre = nombre;

this.apellido = apellido;

this.edad = edad;

this.salario = salario;

}

}

Refactorizar.

Refactoring Guru.

¿Qué es refactorizar?

Acoplamiento y cohesión..

El

acoplamiento y la cohesió

n, con conceptos que nos ayudan a saber como hacer una buena refactorización. Son conceptos anteriores a la POO, que se aplicaban a programas modulares hechos a base de funciones y procedimientos, es decir, se originaron con la programación estructurada. Aunque estos conceptos se originaron en la programación estructurada, siguen siendo fundamentales en la POO y se utilizan para evaluar la calidad del diseño del software. Un diseño con alta cohesión y bajo acoplamiento tiende a ser más fácil de entender, mantener y modificar, lo que contribuye a un código más robusto y escalable.

Patrones de diseño..

¿Qué son los patrones de diseño?

Bad Smells.

Se conoce como

Bad Smell o Code Smell (mal olor

) a algunos indicadores o sintomas del código que posiblemente ocultan un problema más profundo. Los bad smells no son errores de código, bugs, ya que no impiden que el programa funcione correctamente, pero son indicadores de fallos en el diseño del código que dificultan el posterior mantenimiento del mismo y aumentan el riesgo de errores futuros.
