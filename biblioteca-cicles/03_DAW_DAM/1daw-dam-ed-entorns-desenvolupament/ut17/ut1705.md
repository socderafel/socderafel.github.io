# 17.5 Coevaluación

El proyecto se desarrollará con JavaScript, HTML y CSS, además de JSON y XML que serán necesarios para el correcto desarrollo del mismo. No solo se valorará que se cumplan los requisitos técnicos y los requerimientos del cliente, si no que la solución propuesta sea visualmente atractiva.

Cada equipo tendrá un cliente con el que deberá acordar los requisitos del proyecto.

El desarrollo del proyecto se realizará con GitHub. Aunque el uso que se le de a la herramienta no se valorará, se recomienda utilizarla para agilizar el proceso de creación del software de manera conjunta.

La gestión del proyecto se realizará en la plataforma Trello, donde se deberán detallar la tareas a realizar, su reparto dentro del equipo y la estimación de la duración de cada una de ellas. Cada día se realizará una captura del estado del tablero Kanban para ver su evolución. Estas capturas se entregarán junto a la documentación final del proyecto.

Durante la fase de análisis, se deberán crear los siguientes diagramas:

Diagrama de clases.

Diagrama de secuencia.

Diagrama de actividades.

Estos diagramas también se adjuntarán a la documentación final del proyecto junto a la explicación pertinente de cada uno si es necesario.

Por último, se deberá documentar el software con alguna herramienta para JavaScript similar a JavaDoc para Java a elección del equipo de desarrollo. El uso de esta herramienta se indicará en la documentación del proyecto.

Finalmente, se deberá entregar un archivo ZIP con la documentación del proyecto en PDF (siguiendo la plantilla indicada) y todos los archivos necesarios para la ejecución de la solución propuesta también comprimidos.
