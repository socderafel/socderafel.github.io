Un **Entorn Integrat de Desenvolupament (IDE - Integrated Development Environment)** és una aplicació que proporciona serveis integrals als programadors per facilitar totes les tasques del cicle de codificació sota una mateixa interfície gràfica d'usuari.

---

## 🧩 Components Clau d'un IDE

Un IDE modern integra en un únic espai de treball:

1. **Editor de Codi Font Intel·ligent:**
   - **Ressaltat de sintaxi (*Syntax Highlighting*):** Acoloreix paraules clau, tipus de dades, comentaris i cadenes de text.
   - **Autocompletat contextual (*IntelliSense* o *Code Completion*):** Suggereix mètodes, variables i propietats vàlides segons l'abast del codi.
   - **Detecció d'errors en temps real:** Senyala errors sintàctics amb línies ondulades vermelles abans fins i tot de compilar.
   - **Refactorització automatitzada:** Canvia noms de variables o extreu mètodes arreu de tot el projecte de manera coherent.
2. **Compilador / Intèrpret Integrat:** Permet compilar i executar el programa amb un sol clic (`Ctrl + F9` o `Shift + F10`) sense necessitat d'obrir la consola de comandaments.
3. **Depurador (*Debugger*):** Eina essencial per detindre el programa en temps d'execució, analitzar la memòria i corregir fallades lògiques.
4. **Gestor de Projectes i Sistemes de Construcció:** Integració nativa amb Maven, Gradle, Ant o npm.
5. **Control de Versions:** Clients visuals per a Git, permetent fer *commits*, visualitzar branques i resoldre conflictes de fusió.

## 🥊 Comparativa dels Principals IDEs del Mercat

| IDE | Desenvolupador | Llenguatges Principals | Característiques Destacades |
| :--- | :--- | :--- | :--- |
| **IntelliJ IDEA** | JetBrains | Java, Kotlin, Scala, Groovy | Considerat l'estàndard d'or en Java. Autocompletat i anàlisi estàtica extraordinàriament potents. Versió Community (Open Source) i Ultimate. |
| **Eclipse** | Eclipse Foundation | Java, C++, PHP | Molt estès en l'àmbit empresarial clàssic. Basat en una arquitectura modular de milers de plugins. |
| **NetBeans** | Apache Software Foundation | Java, PHP, HTML5 | IDE oficial de Java durant anys. Molt fàcil de configurar per a principiants i amb excel·lent dissenyador gràfic Swing GUI. |
| **Visual Studio Code (VS Code)** | Microsoft | Poliglota (JS, TS, Python, Java...) | Editor de codi ultralleuger que, mitjançant el *Java Extension Pack*, s'utilitza com a IDE complet molt ràpid i modern. |
