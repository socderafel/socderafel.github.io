El codi font més brillant és inútil si ningú sap com utilitzar-lo. En l'ecosistema Java, la documentació tècnica de les classes, mètodes i biblioteques s'estandarditza mitjançant l'eina **Javadoc**, que extreu automàticament comentaris estructurats directament del codi font per generar un lloc web d'**API en format HTML**.

---

## 📝 Estructura dels Comentaris Javadoc

Un bloc de comentari Javadoc comença obligatòriament amb `/**` (barra i dos asteriscs) i acaba amb `*/`:

```java
/**
 * Representa un compte bancari amb suport per a operacions transaccionals.
 * 
 * @author Joan Bataller
 * @version 2.1
 * @since 1.0
 */
public class CompteBancari {

    /**
     * Realitza una transferència de fons cap a un compte destí.
     * 
     * @param desti Compte bancari receptor dels diners. No pot ser nul.

     * @return true si la transferència s'ha completat amb èxit, false en cas contrari.
     * @throws SaldoInsuficientException Si el saldo actual és menor que la quantitat.
     * @throws IllegalArgumentException Si el compte destí és nul o l'import negatiu.
     * @see #ingressar(double)
     */
    public boolean transferir(CompteBancari desti, double quantitat) 
            throws SaldoInsuficientException {
        // Lògica del mètode
        return true;
    }
}
```

## 🏷️ Etiquetes Javadoc Principals

| Etiqueta | Àmbit | Propòsit |
| :--- | :--- | :--- |
| **`@author`** | Classe / Interfície | Especifica l'autor o equip que ha creat la classe. |
| **`@version`** | Classe / Interfície | Versió actual del programari. |
| **`@param nom descripció`** | Mètode / Constructor | Descriu cadascun dels paràmetres que rep el mètode. |
| **`@return descripció`** | Mètode | Descriu el valor retornat (no s'utilitza en mètodes `void`). |
| **`@throws tipus motiu`** | Mètode / Constructor | Detalla quina excepció es pot produir i per quina causa. |
| **`@deprecated motiu`** | Qualsevol element | Avisa que un mètode està en desús i serà eliminat en versions futures. |
| **`@see referència`** | Qualsevol element | Proporciona un enllaç creuat cap a un altre mètode o classe afí. |

---

## ⚙️ Generació de la Documentació HTML

Podem compilar la documentació Javadoc de tres maneres:
1. **Des de la línia d'ordres:**
   ```bash
   javadoc -d docs/ -encoding UTF-8 -docencoding UTF-8 -charset UTF-8 src/main/java/com/empresa/*.java
   ```
2. **Mitjançant l'IDE:** A IntelliJ IDEA: menú *Tools* $\rightarrow$ *Generate JavaDoc...*.
3. **Mitjançant Maven:** Executant `mvn javadoc:javadoc` a través del plugin oficial `maven-javadoc-plugin`.
