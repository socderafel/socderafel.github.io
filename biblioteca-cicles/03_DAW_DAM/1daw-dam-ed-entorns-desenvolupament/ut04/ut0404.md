El **Diagrama d'Activitats** és l'equivalent modern i avançat d'UML als tradicionals diagrames de flux (*flowcharts*). És especialment idoni per modelar la lògica de procediments algorítmics complexos, processos de negoci (*workflows*) i activitats que s'executen de manera **concurrent o paral·lela**.

---

## 🔀 Notació i Elements Gràfics

1. **Estat Inicial:** Cercle negre sòlid (●).
2. **Acció / Activitat:** Rectangle amb les quatre cantonades arrodonides.
3. **Node de Decisió / Fusió:** Un rombe (◇). Té un flux d'entrada i múltiples d'eixida amb condicions de guarda (`[sí]`, `[no]`).
4. **Bifurcació (*Fork*) i Sincronització (*Join*):**
   - Una **barra gruixuda negra**.
   - **Fork:** Divideix un únic flux en múltiples branques concurrents.
   - **Join:** Espera que totes les branques concurrents hagen acabat per continuar en un sol flux unificat.
5. **Estat Final d'Activitat:** Cercle negre sòlid encerclat per un anell exterior (🎯).

---

## 🏊 Carrils de Responsabilitat (*Swimlanes*)

Quan en un procés participen diferents departaments o sistemes, el diagrama es divideix en columnes o files anomenades **carrils de natació (Swimlanes / Partitions)**. Cada acció es col·loca dins del carril de l'actor o subsistema responsable d'executar-la:

```
┌──────────────────────┬──────────────────────┬──────────────────────┐
│       CLIENT         │      MAGATZEM        │     COMPTABILITAT    │
├──────────────────────┼──────────────────────┼──────────────────────┤
│  (●)                 │                      │                      │
│   │                  │                      │                      │
│  [ Fer Comanda ]     │                      │                      │
│   │                  │                      │                      │
│   └─────────────────►│ [ Preparar Paquet ]  │                      │
│                      │   │                  │                      │
│                      │   └─────────────────►│ [ Generar Factura ]  │
│                      │                      │   │                  │
│                      │                      │  (🎯)                │
└──────────────────────┴──────────────────────┴──────────────────────┘
```
