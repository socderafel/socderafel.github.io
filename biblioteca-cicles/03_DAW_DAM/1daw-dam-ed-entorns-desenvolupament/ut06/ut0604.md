El vertader superpoder de Git rau en la seua capacitat de crear **branques (*branches*)** lleugeres i ultra ràpides. Una branca permet aïllar el desenvolupament d'una nova funcionalitat sense alterar la branca principal de producció, permetent a dotzenes de programadors treballar en paral·lel de manera col·laborativa a través de plataformes com **GitHub** o **GitLab**.

---

## 🌿 Concepte de Branca (*Branch*) a Git

A Git, una branca no és una còpia física de fitxers en disc; és simplement un **punter mòbil de 41 bytes** cap a un commit determinat. El punter especial **`HEAD`** indica a quina branca estem treballant actualment.

```bash
# Crear una nova branca per a una funcionalitat
git branch feature-login

# Canviar a la nova branca (sintaxi moderna)
git switch feature-login
# (O bé la sintaxi clàssica: git checkout feature-login)

# Crear i canviar en un sol pas:
git switch -c feature-login
```

---

## 🔀 Fusions de Branques (*Merge*) i Conflictes

Un cop finalitzada la funcionalitat a la branca auxiliar, es torna a la branca principal (`main` o `master`) i es fusiona:

```bash
git switch main
git merge feature-login
```

### 1. Fusió d'Avanç Ràpid (*Fast-Forward*)
Si la branca principal no ha rebut cap commit nou des que es va crear la branca filla, Git simplement avança el punter de `main` cap al final. És neta i immediata.

### 2. Conflicte de Fusió (*Merge Conflict*)
Si dos programadors han modificat les mateixes línies del mateix fitxer en branques diferents, Git no pot endevinar quin canvi és el bo. La fusió s'atura i Git marca el fitxer amb delimitadors de conflicte:
```
<<<<<<< HEAD (branca actual main)
double descompte = 0.15;
=======
double descompte = 0.20;
>>>>>>> feature-promocio (branca que intentem fusionar)
```
- **Resolució:** El programador edita el fitxer manualment a l'IDE, escull el codi final, esborra les marques `<<<<<<<`, `=======` i `>>>>>>>`, i fa `git add` i `git commit`.

---

## ☁️ Treball Col·laboratiu amb GitHub

- **`git clone <url>` :** Descarrega una còpia completa d'un repositori remot de GitHub al disc local.
- **`git push origin main` :** Puja els commits locals cap al repositori remot a GitHub.
- **`git pull origin main` :** Descarrega els nous commits de GitHub i els fusiona al repositori local.
- **Pull Request (PR) / Merge Request:** Mecanisme clau de GitHub on un programador sol·licita formalment revisar i fusionar la seua branca en la branca principal del projecte, permetent debat en línia i revisió de codi (*Code Review*).
