Creat en 2005 per Linus Torvalds per gestionar el desenvolupament del nucli de Linux, **Git** és el sistema de control de versions (*VCS - Version Control System*) més potent i estès del món. A diferència dels sistemes centralitzats antics (CVS, Subversion), Git és un sistema **distribuït**: cada membre de l'equip disposa d'una còpia completa i autònoma de tot l'historial del projecte al seu propi disc dur.

---

## 🏛️ Les Tres Àrees de Treball de Git

Per dominar Git cal entendre com viatgen els fitxers entre els seus tres estats principals:

```
┌─────────────────────┐       ┌─────────────────────┐       ┌─────────────────────┐
│  WORKING DIRECTORY  │       │    STAGING AREA     │       │  LOCAL REPOSITORY   │
│  (Directori Treball)│       │  (Índex / Staged)   │       │   (Commits Locals)  │
└──────────┬──────────┘       └──────────┬──────────┘       └──────────┬──────────┘
           │                             │                             │
           │  git add fitxer.java        │                             │
           ├────────────────────────────►│                             │
           │                             │  git commit -m "missatge"   │
           │                             ├────────────────────────────►│
           │                             │                             │
           │◄──────────────────────────────────────────────────────────┤
           │               git checkout / git restore                  │
```

1. **Working Directory (Directori de Treball):** Els fitxers reals que veus i edites al teu disc dur i a l'IDE.
2. **Staging Area / Index (Àrea de Preparació):** La "sala d'espera". On prepares els canvis concrets que formaran part del pròxim lliurament mitjançant `git add`.
3. **Local Repository (Repositori Local - `.git`):** La base de dades interna on Git emmagatzema de manera permanent les fotografies de l'estat del projecte (**commits**) mitjançant hashes criptogràfics SHA-1.

## 💻 El Cicle Bàsic de Comandes Git

```bash
# 1. Inicialitzar un nou repositori local a la carpeta actual
git init

# 2. Configurar la identitat de l'autor
git config --global user.name "El Teu Nom"
git config --global user.email "el.teu.email@alu.edu.gva.es"

# 3. Inspeccionar l'estat dels fitxers
git status

# 4. Afegir canvis a l'àrea de preparació (Staging)
git add fitxer.java
git add .               # Afig tots els fitxers modificats de la carpeta

# 5. Confirmar el lliurament amb un missatge descriptiu
git commit -m "feat(calculadora): afegir suport per a operacions de multiplicacio"

# 6. Visualitzar l'historial de canvis
git log --oneline --graph
```

## 🙈 El Fitxer `.gitignore`

Fitxer situat a l'arrel del repositori que indica a Git quins fitxers i carpetes **mai s'han de rastrejar**. En un projecte Java típic:
```gitignore
# Binaris i construcció
target/
bin/
*.class
*.jar

# Fitxers de configuració personal de l'IDE
.idea/
*.iml
.vscode/
.settings/
.project

# Fitxers del sistema operatiu
.DS_Store
Thumbs.db
```
