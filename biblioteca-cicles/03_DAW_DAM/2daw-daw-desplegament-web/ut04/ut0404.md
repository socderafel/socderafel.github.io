## El Protocol OpenSSH en Servidors Web

L'accés a la consola d'ordres d'un servidor web de producció i la transferència de fitxers segura es canalitza de manera universal mitjançant **SSH** (*Secure Shell*, RFC 4251-4254). OpenSSH proporciona un canal xifrat extrem a extrem que protegeix contra la intercepció de credencials (*sniffing*), la manipulació de dades en trànsit (*man-in-the-middle*) i l'usurpació d'identitat.

A més de shell interactiu, OpenSSH integra de manera nativa dos mecanismes essencials per al desplegament:
- **SCP (*Secure Copy*):** Transferència ràpida de fitxers punt a punt.
- **SFTP (*SSH File Transfer Protocol*):** Protocol complet d'accés i gestió remota de fitxers amb capacitats de llistat, canvi de permisos i navegació interactiva.

## Autenticació Criptogràfica: Parells de Claus Asimètriques

L'ús de contrasenyes tradicionals és susceptible a atacs de força bruta (*brute-force*), diccionari i filtracions. L'estàndard professional de la indústria consisteix a emprar **criptografia asimètrica de clau pública**:

1. **Clau Privada:** Es guarda exclusivament a l'equip local del desenvolupador (habitualment a `~/.ssh/id_ed25519`), protegida amb una frase de pas (*passphrase*). **Mai s'ha de compartir ni pujar a cap servidor o repositori**.
2. **Clau Pública:** Es pot difondre obertament i s'afegeix al fitxer `~/.ssh/authorized_keys` del compte d'usuari al servidor de destinació.

### Generació de claus d'alta seguretat (ED25519)
ED25519 (basat en corbes el·líptiques EdDSA) és el tipus de clau preferit per la seua velocitat, brevetat i màxima robustesa davant atacs criptogràfics:

```bash
# Generació de clau a l'ordinador local del desenvolupador
ssh-keygen -t ed25519 -C "desplegament@meuprojecte.com"

# Còpia automatitzada de la clau pública cap al servidor remot
ssh-copy-id -i ~/.ssh/id_ed25519.pub deployer@203.0.113.10
```

## Securització del Dimoni SSH (`/etc/ssh/sshd_config`)

Un cop verificat l'accés amb claus asimètriques, cal endurir (*hardening*) la configuració del servidor a `/etc/ssh/sshd_config`:

```ini
# Desactivació de l'inici de sessió de root directe
PermitRootLogin no

# Desactivació de l'autenticació per contrasenya (només claus permeses)
PasswordAuthentication no
PubkeyAuthentication yes

# Nombre màxim d'intents d'autenticació
MaxAuthTries 3

# Port personalitzat (opcional, per a reduir soroll de brossa automatitzada)
# Port 2222
```

Després d'editar, comprovem la sintaxi i reiniciem el servei:
```bash
sudo sshd -t
sudo systemctl restart sshd
```
