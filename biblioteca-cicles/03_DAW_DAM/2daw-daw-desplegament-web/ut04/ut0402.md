## El Servidor vsftpd (*Very Secure FTP Daemon*)

En sistemes basats en Debian i Ubuntu Server, el paquet de servidor FTP més reconegut per la seua velocitat, estabilitat i resistència davant vulnerabilitats de seguretat és **vsftpd**. La seua arquitectura està dividida en petits processos amb privilegis mínims per a mitigar riscos d'execució de codi remot.

### Instal·lació bàsica
```bash
sudo apt update
sudo apt install -y vsftpd
sudo systemctl enable --now vsftpd
```

El fitxer de configuració mestre es troba a `/etc/vsftpd.conf`.

---

## Configuració de Producció en `/etc/vsftpd.conf`

Per a un desplegament web professional, cal desactivar l'accés anònim, permetre l'escriptura als usuaris locals autoritzats, habilitar el mode passiu amb un rang fix de ports i forçar el xifratge TLS:

```ini
# Desactivació d'accés anònim i activació d'usuaris locals
anonymous_enable=NO
local_enable=YES
write_enable=YES

# Màscara per defecte de creació de fitxers (022 = fitxers 644, directoris 755)
local_umask=022

# Missatge de benvinguda i registre de transferències
dirmessage_enable=YES
xferlog_enable=YES
xferlog_file=/var/log/vsftpd.log
connect_from_port_20=YES

# Configuració estricta del Mode Passiu (PASV)
pasv_enable=YES
pasv_min_port=40000
pasv_max_port=40100
pasv_address=203.0.113.10   # IP pública del servidor web si està darrere de NAT
```

## Securització amb FTPS (TLS/SSL)

Transmetre les credencials d'usuari i els fitxers d'un portal web en text pla és inadmissible. Per a xifrar la sessió FTP mitjançant TLS (FTPS explícit), s'utilitza un certificat digital (com els de Let's Encrypt o un certificat autofirmat per a laboratoris):

```bash
# Generació de certificat de laboratori (si no disposem de certificat públic)
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048   -keyout /etc/ssl/private/vsftpd.pem   -out /etc/ssl/certs/vsftpd.pem
```

Afegim les següents directives a `/etc/vsftpd.conf`:
```ini
# Habilitació de TLS/SSL
ssl_enable=YES
allow_anon_ssl=NO
force_local_data_ssl=YES
force_local_logins_ssl=YES

# Versions de protocol segures (evitar SSLv2, SSLv3 i TLSv1.0)
ssl_tlsv1_2=YES
ssl_tlsv1_3=YES
ssl_sslv2=NO
ssl_sslv3=NO

# Ruta al certificat i clau privada
rsa_cert_file=/etc/ssl/certs/vsftpd.pem
rsa_private_key_file=/etc/ssl/private/vsftpd.pem

# Xifrats segurs
ssl_ciphers=HIGH
```

### Obertura de ports al tallafoc (UFW)
```bash
sudo ufw allow 20/tcp
sudo ufw allow 21/tcp
sudo ufw allow 40000:40100/tcp
sudo ufw reload
```
