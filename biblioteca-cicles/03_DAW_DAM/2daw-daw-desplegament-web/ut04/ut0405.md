## Sincronització Diferencial Avançada amb Rsync

Quan es desplega una aplicació web complexa amb centenars de fitxers i imatges, eines clàssiques com `scp` o `cp` copien la totalitat dels fitxers en cada execució, malgastant amplada de banda i provocant temps de caiguda (*downtime*). 

**Rsync** (*Remote Sync*) és l'estàndard de referència per a sincronització en entorns Linux. Utilitza un algorisme d'actualització delta capaç de calcular blocs modificats i enviar únicament les diferències binàries dels fitxers alterats.

### Sintaxi clau de Rsync
```bash
rsync [OPCIONS] ORIGEN DESTINACIÓ
```

### Opcions fonamentals per a Desplegament Web
- `-a` (*archive*): Preserva recursivitat, enllaços simbòlics, permisos, propietaris, grups i marques temporals.
- `-v` (*verbose*): Mostra per consola el detall dels fitxers transferits.
- `-z` (*compress*): Comprimeix les dades durant el trànsit per la xarxa.
- `--delete`: Elimina a la carpeta de destinació aquells fitxers que hagen estat esborrats en l'origen (evita acumulació de fitxers brossa o orfes en producció).
- `-e ssh`: Canalitza tot el trànsit a través d'un túnel xifrat OpenSSH.
- `--exclude`: Ignora fitxers temporals, arxius de configuració local o el directori de Git (`.git/`, `node_modules/`, `.env`).

```bash
# Exemple de comanda de sincronització de desplegament web
rsync -avz --delete   --exclude='.git/'   --exclude='node_modules/'   --exclude='.env'   -e "ssh -p 22 -i /home/deployer/.ssh/deploy_key"   ./dist/ deployer@servidor.com:/var/www/elmeulloc/
```

> **Atenció a la barra final (`/`):**
> - `./dist/`: Sincronitza el contingut interior de la carpeta directament a la destinació.
> - `./dist`: Copia la carpeta `dist` sencera creant un nou nivell `/var/www/elmeulloc/dist/`.

## Automatització en Scripts de Desplegament i Gestió de Permisos

En finalitzar la pujada de fitxers, és habitual que el procés de desplegament execute comandaments remots per a reassignar la propietat dels fitxers a l'usuari del servidor web (`www-data`) i netejar les memòries cau:

```bash
#!/bin/bash
set -e

SERVER="prod-web.empresa.val"
USER="deployer"
DEST_PATH="/var/www/app-produccio"

echo "[1/3] Construint aplicació web..."
npm run build

echo "[2/3] Sincronitzant fitxers amb rsync..."
rsync -avz --delete ./build/ ${USER}@${SERVER}:${DEST_PATH}/

echo "[3/3] Ajustant permisos i recarregant servidor..."
ssh ${USER}@${SERVER} "sudo chown -R www-data:www-data ${DEST_PATH} && sudo systemctl reload nginx"

echo "Desplegament finalitzat amb èxit!"
```
