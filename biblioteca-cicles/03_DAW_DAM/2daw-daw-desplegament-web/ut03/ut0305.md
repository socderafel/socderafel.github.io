## El Desenvolupament Web Modern amb Python

Python s'ha consolidat com un dels llenguatges més utilitzats tant per a grans plataformes web com per a APIs de serveis d'intel·ligència artificial i ciència de dades (Django, Flask, FastAPI):
- El servidor de desenvolupament integrat (`python manage.py runserver` o `flask run`) és **exclusivament per a desenvolupament** monousuari; no és segur, ràpid ni resilient per a rebre trànsit real d'Internet.
- En producció cal utilitzar un **Servidor d'Aplicacions WSGI o ASGI dedicat**.

---

## 1. Gunicorn (*Green Unicorn*): El Servidor WSGI de Referència
- **Gunicorn** és un servidor HTTP i WSGI pur per a entorns Unix basat en el model de treballadors pre-fork:
  - Un procés mestre gestiona un conjunt de processos fills (*workers*).
  - Cada petició s'assigna a un treballador lliure.
  - Fórmula recomanada de processos treballadors: **`Workers = (2 * Nombre de Nuclis CPU) + 1`**.
- Exemple de comanda per a Django:
  ```bash
  gunicorn --workers 3 --bind 127.0.0.1:8000 el_meu_projecte.wsgi:application
  ```

---

## 2. Uvicorn: L'Estandard Asíncron ASGI per a FastAPI
Mentre que WSGI és estrictament sincrònic i bloquejant, l'aparició de la programació asíncrona (`asyncio`) a Python va donar lloc a l'especificació **ASGI**:
- **Uvicorn** és una implementació ASGI ultraràpida construïda sobre `uvloop` (un bucle d'esdeveniments basat en la biblioteca C `libuv`, la mateixa que fa funcionar Node.js).
- Permet que una sola instància atengui milers de peticions concurrents i connexions de llarga durada (WebSockets) sense crear nous fils de memòria.

### L'Arquitectura Màxima: Gunicorn gestionant Treballadors Uvicorn
En entorns corporatius amb FastAPI es combina la robustesa del procés mestre de Gunicorn amb l'eficiència asíncrona dels treballadors Uvicorn:
```bash
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker --bind unix:/run/fastapi.sock
```

---

## Integració com a Servei Systemd darrere de Nginx

```ini
# /etc/systemd/system/meuprojecte.service
[Unit]
Description=Gunicorn daemon per al projecte Python
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/meuprojecte
ExecStart=/var/www/meuprojecte/venv/bin/gunicorn --workers 3 --bind unix:/run/meuprojecte.sock wsgi:app
Restart=always

[Install]
WantedBy=multi-user.target
```

Nginx rep el trànsit HTTPS al port 443 i fa un `proxy_pass http://unix:/run/meuprojecte.sock;`, creant una arquitectura de màxim rendiment, seguretat i aïllament.
