## Introducció a Apache Tomcat

**Apache Tomcat** és un servidor web i un contenidor de servlets de codi obert desenvolupat per l'Apache Software Foundation que implementa les especificacions de **Jakarta Servlet**, **Jakarta Server Pages (JSP)** i **Jakarta WebSocket**:
- A diferència d'un servidor complet d'aplicacions Jakarta EE (com WildFly o WebLogic), Tomcat és un contenidor lleuger especialitzat exclusivament en la capa web d'aplicacions Java.
- S'executa sobre la **Màquina Virtual de Java (JVM)**, el rendiment de la qual està condicionat directament pels paràmetres de memòria del *Java Heap* (`-Xms` i `-Xmx`).

---

## Empaquetat i Estructura d'un Arxiu Web WAR (*Web Application Archive*)

Les aplicacions web en Java s'empaqueten habitualment en un únic fitxer comprimit en format ZIP amb extensió **`.war`**:

```
el-meu-projecte.war
  ├── index.jsp                     (Pàgina d'inici)
  ├── css/ i js/                    (Recursos estàtics)
  └── WEB-INF/                      (Directori privat protegit, inaccessible directament des del navegador)
        ├── web.xml                 (Descriptor de desplegament de l'aplicació)
        ├── classes/                (Classes Java compilades .class i controladors Servlet)
        └── lib/                    (Fitxers .jar de biblioteques de tercers, ex: mysql-connector.jar)
```

### El Desplegament Automàtic (*Hot Deployment*):
Tomcat supervisa el directori `/opt/tomcat/webapps/`:
- Quan es copia un fitxer `projecte.war` dins de `webapps/`, Tomcat el descomprimeix automàticament en una carpeta del mateix nom i l'arrenca en calent sense reiniciar el servei.
- L'aplicació quedarà accessible immediatament sota el context URL: `http://servidor:8080/projecte/`.

---

## Arquitectura de Producció: Tomcat darrere de Nginx / Apache (Connectors AJP vs HTTP)

A les empreses mai s'exposa el port `8080` de Tomcat directament a Internet. S'utilitza una arquitectura mixta:
- **Nginx o Apache al davant:** Atén les connexions públiques als ports 80/443, serveix fitxers estàtics i gestiona el certificat TLS.
- **Tomcat al darrere:** Rep exclusivament les peticions que requereixen processament Java mitjançant un proxy invers:
  - **Proxy HTTP:** `proxy_pass http://127.0.0.1:8080;` a Nginx.
  - **Connector AJP (Apache JServ Protocol - port 8009):** Protocol binari optimitzat d'alt rendiment entre el mòdul `mod_proxy_ajp` d'Apache i Tomcat.
