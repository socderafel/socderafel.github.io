## Què és PHP-FPM?

**PHP-FPM (FastCGI Process Manager)** és la implementació avançada, altament eficient i estàndard de referència per a l'execució d'aplicacions PHP en entorns corporatius de producció:
- S'executa com un servei independent del sistema operatiu (`systemd: php8.3-fpm`).
- Permet desacoblar el servidor web (Nginx o Apache) de l'intèrpret de codi PHP.
- Gestiona piscines de processos (*pools*) dedicades, permetent aïllar diferents llocs web sota diferents usuaris de Linux per a màxima seguretat.

---

## Configuració de les Piscines (*Pools*) de PHP-FPM

A les distribucions basades en Debian/Ubuntu, la configuració de la piscina per defecte es troba a `/etc/php/8.3/fpm/pool.d/www.conf`:

```ini
[www]
; Usuari i grup del sistema que executa els processos PHP
user = www-data
group = www-data

; Socket de comunicació local UNIX (més ràpid que TCP 127.0.0.1:9000)
listen = /run/php/php8.3-fpm.sock
listen.owner = www-data
listen.group = www-data
listen.mode = 0660

; Gestor de processos (pm): static, dynamic o ondemand
pm = dynamic

; Nombre màxim de processos concurrents
pm.max_children = 50

; Processos llançats a l'arrencada
pm.start_servers = 5

; Processos inactius mínims en espera
pm.min_spare_servers = 5

; Processos inactius màxims en espera
pm.max_spare_servers = 10

; Reiniciar processos periòdicament per prevenir fuites de memòria
pm.max_requests = 1000
```

## Integració de PHP-FPM amb Nginx

Com que Nginx no té cap mòdul PHP integrat a la seua memòria, tota petició a un fitxer `.php` es passa al servei PHP-FPM mitjançant directives FastCGI:

```nginx
server {
    listen 80;
    server_name www.elmeuprojecte.org;
    root /var/www/elmeuprojecte/html;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # Encaminament de fitxers PHP cap al socket de PHP-FPM
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

## Acceleració amb Zend OPcache

PHP és un llenguatge interpretat: en cada petició, el motor Zend llegeix el fitxer de text, l'analitza lèxicament i sintàcticament, i el compila a **Opcodes** (instruccions binàries de baix nivell de la màquina virtual de PHP).
- **Zend OPcache:** Guarda aquests opcodes compilats directament a la memòria RAM compartida del servidor.
- En les peticions posteriors, el fitxer s'executa a l'instant des de la RAM sense haver de llegir el disc dur ni tornar a compilar el codi, **multiplicant la velocitat per 3 o 4 vegades**.
