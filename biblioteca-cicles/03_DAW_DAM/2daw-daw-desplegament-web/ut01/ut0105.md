## La Zona Desmilitaritzada (DMZ) en Xarxes Corporatives

En seguretat perimetral, una **DMZ (Demilitarized Zone)** és una subxarxa aïllada situada entre la xarxa pública d'Internet (insegura) i la xarxa interna privada de l'organització (on resideixen les dades confidencials i bases de dades).

```
 Internet Públic
       │
       ▼
[ Tallafocs Extern ]  (Permet només ports 80 HTTP i 443 HTTPS)
       │
       ▼
+-------------------------------------------------------------+
|                     ZONA PERIMETRAL DMZ                     |
|  - Proxies Inversos (Nginx / HAProxy)                       |
|  - Servidors Web Frontend Públics                           |
|  - Servidors de Transferència SFTP                          |
+-------------------------------------------------------------+
       │
       ▼
[ Tallafocs Intern ]  (Permet només trànsit des de la DMZ cap a ports concrets)
       │
       ▼
+-------------------------------------------------------------+
|                     XARXA PRIVADA INTERNA                   |
|  - Servidors d'Aplicacions Backend                          |
|  - Servidors de Bases de Dades (MySQL / PostgreSQL)         |
|  - Emmagatzematge Centralitzat (NFS / SAN)                  |
+-------------------------------------------------------------+
```

- **Principi d'aïllament:** Si un atacant troba una vulnerabilitat a Apache i aconsegueix una shell a la DMZ, el tallafocs intern li impedeix connectar-se directament a la base de dades o a les màquines internes dels empleats.

## El Proxy Invers (*Reverse Proxy*) com a Escut

Mentre que un proxy directe tradicional (*Forward Proxy*) s'utilitza perquè els treballadors d'una oficina naveguin cap a Internet protegint la seua identitat, un **Proxy Invers** es col·loca davant dels nostres propis servidors per protegir-los del món exterior:
1. **Ocultació d'adreces internes:** El món exterior només veu la IP del proxy; les adreces reals dels servidors d'aplicacions romanen completament invisibles.
2. **Defensa contra atacs web:** Integra mòduls de seguretat (WAF - *Web Application Firewall* com ModSecurity) que filtren atacs d'injecció SQL (SQLi), Cross-Site Scripting (XSS) i limiten la taxa de peticions (*Rate Limiting*) per frenar atacs de força bruta.
3. **Memòria cau de continguts estàtics:** Allibera els servidors d'aplicacions de servir imatges i estils CSS.

---

## Criptografia i Certificats Digitals TLS/SSL

En l'actualitat, el desplegament web sobre HTTP pla està completament prohibit per estàndards de seguretat i penalitzat pels motors de cerca com Google:
- **Xifratge en Trànsit:** El protocol **TLS (Transport Layer Security)**, successor de SSL, garanteix confidencialitat (les dades viatgen xifrades), integritat (ningú pot modificar els paquets) i autenticació (l'usuari sap que està connectant-se al banc autèntic i no a una còpia fraudulenta).
- **Entitats de Certificació (CA):** Autoritats que emeten i signen digitalment els certificats (com Let's Encrypt, DigiCert, Sectigo).
- **Terminació TLS:** El proxy invers s'encarrega de validar el certificat i desxifrar la connexió HTTPS perimetralment.
