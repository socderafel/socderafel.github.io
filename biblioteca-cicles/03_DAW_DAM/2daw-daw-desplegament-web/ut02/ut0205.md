## La Revolució de Let's Encrypt i el Protocol ACME

Fins a l'any 2015, obtenir un certificat digital SSL/TLS per a un lloc web era un procés manual, feixuc i molt car (entre 50 i 300 euros anuals per domini). Això feia que la majoria de llocs web funcionassen sobre HTTP vulnerable.

La fundació sense ànim de lucre **ISRG (Internet Security Research Group)**, amb el suport de la Fundació Linux, Mozilla, Cisco i Google, va crear **Let's Encrypt**:
- Una **Entitat de Certificació (CA)** pública, gratuïta, automatitzada i oberta.
- Utilitza el protocol estàndard **ACME (Automated Certificate Management Environment)**: permet que un agent programari instal·lat al servidor sol·liciti, valide, instal·le i renove automàticament els certificats sense cap intervenció humana.
- **Validesa dels certificats:** Els certificats de Let's Encrypt tenen una validesa de **90 dies** (per forçar l'automatització i minimitzar el dany si una clau privada és compromesa).

## Tipus de Desafiaments de Validació de Domini (DCV)

Abans d'emetre un certificat, Let's Encrypt ha de comprovar que el sol·licitant és l'amo del domini:

```
+-----------------------------------------------------------------+
|             DESAFIAMENTS D'AUTENTICACIÓ ACME                    |
+--------------------------------+--------------------------------+
|     Desafiament HTTP-01        |      Desafiament DNS-01        |
|                                |                                |
| 1. Let's Encrypt demana una    | 1. Let's Encrypt demana un     |
|    clau criptogràfica token.   |    valor secret TXT.           |
| 2. Certbot crea el fitxer a:   | 2. Certbot afegeix el registre |
|    /.well-known/acme-challenge |    _acme-challenge al DNS.     |
| 3. Let's Encrypt fa un GET per | 3. Let's Encrypt consulta els  |
|    Internet al port 80 HTTP.   |    servidors DNS arrel.        |
| - Ideal per a servidors web    | - Ideal per a dominis comodí   |
|   individuals amb IP pública.  |   (*.empresa.com) o xarxes     |
|                                |   privades sense port 80 obert.|
+--------------------------------+--------------------------------+
```

## L'Eina Oficial: Certbot

**Certbot** (desenvolupat per l'EFF - Electronic Frontier Foundation) és el client ACME de referència:

```bash
# Instal·lació de Certbot mitjançant snap (recomanat per l'EFF)
sudo snap install --classic certbot
sudo ln -s /snap/bin/certbot /usr/bin/certbot

# Obtenció i configuració automàtica per a Apache
sudo certbot --apache -d elmeudomini.com -d www.elmeudomini.com

# Obtenció i configuració automàtica per a Nginx
sudo certbot --nginx -d elmeudomini.com -d www.elmeudomini.com

# Simulació de renovació automàtica (Dry Run)
sudo certbot renew --dry-run
```

Certbot configura automàticament un temporitzador de systemd (`certbot.timer`) o una tasca de cron que s'executa dues vegades al dia per renovar automàticament qualsevol certificat al qual li queden menys de 30 dies de validesa.
