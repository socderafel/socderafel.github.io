## Autenticació Bàsica HTTP (*HTTP Basic Authentication*)

Sovint cal protegir panells d'administració interns, documentació privada o entorns de proves abans que siguen públics. L'**Autenticació Bàsica HTTP** és un mecanisme natiu del protocol HTTP gestionat directament pel servidor web:
- El servidor respon amb un codi `401 Unauthorized` i la capçalera `WWW-Authenticate: Basic realm="Zona Restringida"`.
- El navegador mostra una finestra emergent nativa demanant usuari i contrasenya.
- **Important:** Les credencials viatgen codificades en Base64 (que NO és xifratge); per tant, **és obligatori utilitzar HTTPS** per evitar que les contrasenyes siguen interceptades a la xarxa.

### Creació del Fitxer de Contrasenyes amb `htpasswd`:
```bash
# Crear un fitxer nou amb el primer usuari (xifrat amb algorisme bcrypt per defecte)
sudo htpasswd -c -B /etc/apache2/.htpasswd administrador

# Afegir un segon usuari sense sobreescriure el fitxer (sense la -c)
sudo htpasswd -B /etc/apache2/.htpasswd professor
```

### Configuració al Servidor Apache:
```apache
<Directory /var/www/elmeulloc/privat>
    AuthType Basic
    AuthName "Accés Restringit al Panell d'Administració"
    AuthUserFile /etc/apache2/.htpasswd
    Require valid-user
</Directory>
```

## Directives Descentralitzades: El Fitxer `.htaccess`

Un fitxer `.htaccess` permet als desenvolupadors web definir directives de configuració a nivell de carpeta sense tenir accés als fitxers principals de configuració del sistema operatiu (`/etc/apache2/`):
- **Com s'habilita?** Mitjançant la directiva `AllowOverride All` al bloc `<Directory>`.
- **Rendiment:** Si s'activa `AllowOverride All`, Apache ha de comprovar l'existència d'un fitxer `.htaccess` a cada directori i subdirectori per a cada petició, la qual cosa redueix el rendiment.
- **Nginx:** Nginx **NO suporta fitxers `.htaccess`** per motius estrictes de rendiment i seguretat; totes les regles s'han d'escriure als fitxers de configuració centrals de Nginx.

---

## Enduriment (*Hardening*) de Servidors Web

1. **Ocultació d'Informació del Servidor (*Banner Grabbing*):**
   Els atacants escanegen la versió exacta d'Apache o Nginx per buscar vulnerabilitats conegudes (CVEs):
   - A Apache: `ServerTokens Prod` i `ServerSignature Off`.
   - A Nginx: `server_tokens off;`.
2. **Permisos de Fitxers:**
   Els fitxers web han de ser propietat de l'usuari desenvolupador i el grup del servidor web (`www-data`). Els fitxers mai han de tenir permisos `777`:
   - Directoris: `chmod 755` (rwxr-xr-x).
   - Fitxers regulars: `chmod 644` (rw-r--r--).
   - Fitxers de configuració amb credencials (`.env`, `wp-config.php`): `chmod 600` o `640`.
