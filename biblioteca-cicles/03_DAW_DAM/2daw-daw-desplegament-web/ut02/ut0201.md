## Introducció a Apache HTTP Server

**Apache HTTP Server** (habitualment conegut com `httpd` o `apache2`) és el servidor web de codi obert més veterà, madur i àmpliament estès a la història d'Internet:
- Desenvolupat i mantingut per l'**Apache Software Foundation**.
- Arquitectura altament modular: qualsevol funcionalitat (seguretat, reescriptura de rutes, compressió, llenguatges) es carrega com un mòdul dinàmic (*Dynamic Shared Object* - DSO).

---

## Els Mòduls de Multiprocessament (MPM)

El comportament intern d'Apache a l'hora de gestionar les connexions de xarxa està determinat pel mòdul **MPM (Multi-Processing Module)** seleccionat:

| Mòdul MPM | Model de Concurrència | Avantatges i Inconvenients | Recomanació d'Ús |
| :--- | :--- | :--- | :--- |
| **`mpm_prefork`** | **Multiprocés pur (sense fils).** Crea un procés independent complet per a cada petició. | **Aïllament absolut:** Si un procés falla, cap altre es veu afectat. Permet llibreries no segures per a fils (*non-thread-safe* com `mod_php`). **Inconvenient:** Consum brutal de memòria RAM; molt mala escalabilitat concurrent. | Sistemes antics que requereixen obligatòriament `mod_php` antic. |
| **`mpm_worker`** | **Híbrid (Multiprocés + Multifil).** Cada procés llança desenes de fils (*threads*) que atenen peticions. | Consum de memòria RAM molt inferior a Prefork; suporta moltes més connexions simultànies. Requereix mòduls *thread-safe*. | Càrregues de treball generals amb PHP-FPM o servidors intermediaris. |
| **`mpm_event`** | **Basat en Worker + Gestió asíncrona d'esdeveniments.** | Dedica fils especialitzats a escoltar connexions persistents (*Keep-Alive*) inactives, alliberant els fils de treball per a peticions actives. | **L'opció per defecte i recomanada** a Apache 2.4 en producció combinat amb PHP-FPM. |

## Estructura de Fitxers a Debian / Ubuntu

A les distribucions basades en Debian, la configuració d'Apache es divideix de forma neta i modular sota el directori `/etc/apache2/`:

```
/etc/apache2/
  ├── apache2.conf          (Fitxer de configuració principal)
  ├── ports.conf            (Defineix els ports d'escolta: Listen 80 i 443)
  ├── mods-available/       (Tots els mòduls instal·lats al sistema)
  ├── mods-enabled/         (Enllaços simbòlics als mòduls activats)
  ├── sites-available/      (Tots els Virtual Hosts configurats)
  ├── sites-enabled/        (Enllaços simbòlics als Virtual Hosts activats)
  └── conf-available/       (Fragments de configuració global)
```

### Comandes d'Administració Modular de Debian:
- `sudo a2enmod rewrite ssl`: Activa els mòduls de reescriptura i SSL creant l'enllaç simbòlic.
- `sudo a2dismod autoindex`: Desactiva el mòdul d'indexació de carpetes per seguretat.
- `sudo a2ensite el-meu-lloc.conf`: Activa un Virtual Host.
- `sudo a2dissite 000-default.conf`: Desactiva el lloc per defecte.
- `sudo apache2ctl configtest` (o `apachectl -t`): **Comprova la sintaxi de tots els fitxers abans de reiniciar**.
- `sudo systemctl reload apache2`: Recarrega la configuració sense tallar les connexions existents.
