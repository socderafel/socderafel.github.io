## Què és un Amfitrió Virtual (*Virtual Host*)?

El concepte de **Virtual Host (vHost)** permet allotjar i servir múltiples llocs web completament diferents i independents des d'una única màquina física i una sola instància d'Apache en execució.

Hi ha tres mecanismes per diferenciar els llocs:
1. **Basats en Nom (Name-based Virtual Hosts):** És el model estàndard absolut a Internet. Múltiples llocs comparteixen la mateixa adreça IP i el mateix port (80 o 443), diferenciant-se pel nom de domini FQDN enviat a la capçalera `Host:` d'HTTP.
2. **Basats en IP:** Cada lloc web té assignada una targeta o adreça IP diferent a la màquina.
3. **Basats en Port:** Un lloc respon al port 80, un altre al port 8080, un altre al port 8081.

---

## Anatomia d'un Fitxer de Virtual Host en Apache

Els fitxers es desen habitualment a `/etc/apache2/sites-available/nom-del-lloc.conf`:

```apache
<VirtualHost *:80>
    # Domini principal
    ServerName www.projectedaw.org
    
    # Àlies o dominis alternatius
    ServerAlias projectedaw.org dev.projectedaw.org
    
    # Correu de contacte de l'administrador
    ServerAdmin webmaster@projectedaw.org
    
    # Directori arrel físic on resideixen els fitxers web
    DocumentRoot /var/www/projectedaw/html
    
    # Directori d'accés i configuracions de seguretat
    <Directory /var/www/projectedaw/html>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
    
    # Registres personalitzats per a este lloc
    ErrorLog ${APACHE_LOG_DIR}/projectedaw_error.log
    CustomLog ${APACHE_LOG_DIR}/projectedaw_access.log combined
</VirtualHost>
```

---

## Directives Fonamentals d'un Virtual Host

- **`<VirtualHost IP:PORT>`:** Delimita el bloc del lloc web virtual. `*:80` indica que escolta en qualsevol IP de la màquina al port 80.
- **`ServerName`:** El nom de domini complet (FQDN) que ha de coincidir amb la petició de l'usuari.
- **`ServerAlias`:** Noms de domini alternatius o comodins (`*.domini.com`).
- **`DocumentRoot`:** La ruta absoluta del sistema de fitxers on es troba el fitxer `index.html` o `index.php`.
- **`<Directory ruta>`:** Defineix les regles de seguretat per a eixe directori físic:
  - `Options -Indexes`: **Molt important per seguretat**. Evita que si no hi ha fitxer `index.html`, Apache lliste tots els fitxers de la carpeta com un explorador d'arxius.
  - `AllowOverride All`: Permet que els fitxers descentralitzats `.htaccess` sobreescriguin directives de configuració (com rutes amigables a Laravel o WordPress).
  - `Require all granted`: Permet l'accés públic a tothom.
