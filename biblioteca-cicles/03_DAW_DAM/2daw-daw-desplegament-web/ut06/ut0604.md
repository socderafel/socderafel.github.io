## La Revolució dels Contenidors en el Desplegament Web

Tradicionalment, desplegar una aplicació web implicava instal·lar a mà a cada màquina les versions exactes d'Apache, PHP, Node.js, biblioteques del sistema i mòduls C, donant lloc a l'habitual problema *"A la meua màquina sí que funciona, però en producció falla"*.

**Docker** encapsula l'aplicació juntament amb el seu entorn d'execució, biblioteques, binaris i fitxers de configuració en una **imatge immutable**. El contenidor resultant s'executa de manera aïllada sobre el mateix nucli (*kernel*) del sistema operatiu, compartint recursos amb un consum de CPU i memòria dràsticament inferior al d'una màquina virtual clàssica.

## Creació d'Imatges Mínimes amb *Multi-Stage Builds*

Per a una aplicació web de frontend (com React o Vue) servida per Nginx, una imatge que continga Node.js i totes les dependències de compilació pot ocupar més de 1 GB. Mitjançant construccions multietapa en un únic `Dockerfile`, reduïm la imatge final a només 25 MB:

```dockerfile
# ETAPA 1: Construcció i compilació (utilitza Node.js complet)
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# ETAPA 2: Imatge final de producció (només Nginx lleuger)
FROM nginx:alpine
# Copiem exclusivament els fitxers estàtics generats a l'etapa 1
COPY --from=builder /app/dist /usr/share/nginx/html
# Copiem la configuració optimitzada de Nginx
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## Orquestració Multicontenidor amb Docker Compose

La majoria d'aplicacions web requereixen almenys tres serveis interconnectats: un servidor web/proxy, el servidor d'aplicacions i la base de dades. Amb **Docker Compose** es declaren i s'engeguen amb una sola comanda (`docker compose up -d`):

Exemple de `docker-compose.yml`:
```yaml
version: '3.8'

services:
  reverse-proxy:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - certs:/etc/ssl/certs:ro
    depends_on:
      - web-app
    networks:
      - xarxa-web

  web-app:
    build:
      context: ./backend
      dockerfile: Dockerfile
    environment:
      - NODE_ENV=production
      - DB_HOST=db
      - DB_NAME=portal
      - DB_USER=appuser
      - DB_PASS_FILE=/run/secrets/db_password
    restart: unless-stopped
    depends_on:
      - db
    networks:
      - xarxa-web
      - xarxa-interna

  db:
    image: postgres:16-alpine
    environment:
      - POSTGRES_DB=portal
      - POSTGRES_USER=appuser
      - POSTGRES_PASSWORD_FILE=/run/secrets/db_password
    volumes:
      - dades-db:/var/lib/postgresql/data
    restart: unless-stopped
    networks:
      - xarxa-interna

volumes:
  dades-db:
  certs:

networks:
  xarxa-web:
  xarxa-interna:
    internal: true # Aquesta xarxa no té eixida a Internet per seguretat màxima!
```
