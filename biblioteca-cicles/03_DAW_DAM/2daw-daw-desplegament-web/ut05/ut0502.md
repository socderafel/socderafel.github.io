## El Dimoni BIND9 (*Berkeley Internet Name Domain*)

**BIND9** és el programari de servidor DNS més estès i testat de la història d'Internet. S'executa com un dimoni anomenat `named` en entorns Linux i suporta tant la funció de servidor autoritatiu mestre/esclau com la de servidor cau recursiu i seguretat DNSSEC.

### Instal·lació a Ubuntu/Debian
```bash
sudo apt update
sudo apt install -y bind9 bind9utils bind9-doc
sudo systemctl enable --now named
```

L'estructura de fitxers de BIND9 a `/etc/bind/` es divideix en:
- `named.conf`: Fitxer principal que inclou els altres arxius mitjançant directives `include`.
- `named.conf.options`: Opcions globals, rutes de treball, ports d'escolta i reenviadors (*forwarders*).
- `named.conf.local`: Declaració de les zones locals mestres i esclaves.
- `named.conf.default-zones`: Zones arrel i de loopback estàndards.

---

## Declaració d'una Zona Mestra Directa

Per a fer que el nostre servidor siga autoritatiu per al domini de desplegament `projecteweb.val`, editem `/etc/bind/named.conf.local`:

```
zone "projecteweb.val" {
    type master;
    file "/etc/bind/db.projecteweb.val";
};
```

---

## Estructura del Fitxer de Zona (`/etc/bind/db.projecteweb.val`)

Els fitxers de zona segueixen la sintaxi d'enregistrament de recursos (Resource Records - RR):

```ini
$TTL    86400           ; TTL per defecte de la zona (24 hores)
@       IN      SOA     ns1.projecteweb.val. admin.projecteweb.val. (
                        2026110401      ; Sèrie (Data YYYYMMDDNN) - Incrementar a cada canvi!
                        3600            ; Refresh (1 hora)
                        1800            ; Retry (30 minuts)
                        604800          ; Expire (1 setmana)
                        86400 )         ; Negative Cache TTL (1 dia)

; Servidors de Noms (NS)
@       IN      NS      ns1.projecteweb.val.
@       IN      NS      ns2.projecteweb.val.

; Registres d'Amfitrió IPv4 (A)
ns1     IN      A       192.168.10.2
ns2     IN      A       192.168.10.3
@       IN      A       192.168.10.100    ; projecteweb.val apunta a la IP web
prod    IN      A       192.168.10.100
staging IN      A       192.168.10.101

; Àlies Canònics (CNAME)
www     IN      CNAME   @
app     IN      CNAME   prod.projecteweb.val.

; Servidors de Correu (MX) amb Prioritat
@       IN      MX  10  mail.projecteweb.val.
mail    IN      A       192.168.10.50

; Registres de Text (TXT) per a seguretat SPF i verificacions
@       IN      TXT     "v=spf1 mx ip4:192.168.10.50 -all"
```

### Validació de Sintaxi i Recàrrega
Abans de reiniciar el servei, és vital comprovar que no hi ha errades tipogràfiques:
```bash
# Validació de la configuració general
sudo named-checkconf

# Validació específica del fitxer de zona
sudo named-checkzone projecteweb.val /etc/bind/db.projecteweb.val

# Recàrrega neta de zones amb rndc
sudo rndc reload
```
