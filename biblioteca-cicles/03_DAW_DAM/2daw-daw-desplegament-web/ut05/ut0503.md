## Resolució Inversa: El Domini `in-addr.arpa` i Registres PTR

La **resolució inversa** és l'operació contrària a la resolució directa: donada una adreça IP, determina quin nom de domini canònic li correspon. Aquesta resolució és imprescindible en entorns de desplegament per a la validació de servidors de correu electrònic (prevenció de spam), auditories de seguretat en servidors web i connexions SSH segures.

Per a IPv4, les zones inverses utilitzen el domini especial `.in-addr.arpa`. Els octets de la subxarxa s'escriuen en **ordre invers**:
Per a la subxarxa `192.168.10.0/24`, el nom de zona és `10.168.192.in-addr.arpa`.

### Declaració de Zona Inversa a `/etc/bind/named.conf.local`
```
zone "10.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.192.168.10";
};
```

### Fitxer de Zona Inversa (`/etc/bind/db.192.168.10`)
```ini
$TTL    86400
@       IN      SOA     ns1.projecteweb.val. admin.projecteweb.val. (
                        2026110401 3600 1800 604800 86400 )
@       IN      NS      ns1.projecteweb.val.

; Registres Punters de Resolució Inversa (PTR)
2       IN      PTR     ns1.projecteweb.val.
100     IN      PTR     prod.projecteweb.val.
101     IN      PTR     staging.projecteweb.val.
```

## Reenviadors DNS (*Forwarders*)

Quan un servidor DNS s'ubica en una xarxa local d'empresa o laboratori, no convé que execute cerques recursives completes cap a les arrels d'Internet per a dominis externs com `google.com` o `github.com`. Es configuren **reenviadors** (*forwarders*) a `/etc/bind/named.conf.options`:

```
options {
    directory "/var/cache/bind";

    forwarders {
        1.1.1.1;
        8.8.8.8;
    };
    forward only; // Reenvia exclusivament als servidors indicats

    dnssec-validation auto;
    listen-on-v6 { any; };
};
```

## Eines de Diagnòstic de Resolució: `dig`, `host` i `nslookup`

El desplegament d'aplicacions web requereix verificar amb precisió la correcta resolució de registres des de la línia d'ordres:

### 1. `dig` (*Domain Information Grok*) - L'eina professional
```bash
# Consulta estàndard del registre A cap al servidor local
dig @127.0.0.1 www.projecteweb.val

# Consulta de registres específics (MX, CNAME, TXT)
dig @127.0.0.1 projecteweb.val MX +short

# Consulta de resolució inversa (paràmetre -x)
dig @127.0.0.1 -x 192.168.10.100 +short
# Retorna: prod.projecteweb.val.

# Rastreig iteratiu complet des de l'arrel (+trace)
dig www.gva.es +trace
```

### 2. `host` i `nslookup` (eines ràpides)
```bash
host -t A www.projecteweb.val 127.0.0.1
nslookup www.projecteweb.val 127.0.0.1
```
