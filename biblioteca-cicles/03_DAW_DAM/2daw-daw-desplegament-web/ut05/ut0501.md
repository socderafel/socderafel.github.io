## Fonaments del Sistema de Noms de Domini (DNS)

El **DNS** (*Domain Name System*, definit a les RFC 1034 i 1035) és una base de dades jeràrquica i altament distribuïda a escala mundial la funció fonamental de la qual és traduir noms de domini llegibles per als humans (com `www.gva.es`) en adreces IP numèriques utilitzades pels protocols d'encaminament de xarxa (com `193.144.127.80` o `2a00:1508:...`).

Sense DNS, cada aplicació web hauria de ser contactada per la seua adreça IP directa, la qual cosa impossibilitaria canvis d'infraestructura transparents, balanceig geogràfic o allotjament virtual basat en amfitrions (*Virtual Hosting*).

---

## L'Estructura Jeràrquica de l'Espai de Noms

L'arbre DNS s'organitza en nivells jeràrquics de dreta a esquerra, delimitats per punts:

```
                            . (Arrel / Root)
                           /        |                                .com      .es      .org  (TLD - Top Level Domains)
                        /                               empresa.com      gva.es         (SLD - Second Level Domains)
                  /     \            /                  www      app       edu     aules   (Subdominis / FQDNs)
```

1. **Arrel (*Root Domain* - `.`):** El vèrtex superior de l'arbre. Gestionat per 13 clústers mundials de servidors arrel (des de la `a.root-servers.net` fins a la `m.root-servers.net`), replicats mitjançant adreçament *Anycast*.
2. **Dominis de Primer Nivell (*Top-Level Domains* - TLDs):**
   - **gTLD (Genèrics):** `.com`, `.org`, `.net`, `.info`.
   - **ccTLD (Geogràfics de codi de país):** `.es`, `.cat`, `.eu`, `.uk`.
3. **Dominis de Segon Nivell (*Second-Level Domains* - SLDs):** El nom registrat per una entitat o empresa (per exemple `gva.es`, `iesmontduver.es`).
4. **Subdominis i FQDN (*Fully Qualified Domain Name*):** Identificadors complets d'un servei concret dins de l'arbre, com `aules.edu.gva.es.`. El punt final denota l'arrel de l'arbre.

---

## Servidors Autoritatius vs Servidors Recursius

En una resolució DNS intervenen dos rols d'amfitrió clarament diferenciats:

- **Servidor Recursiu (*Resolver*):** Habitualment proporcionat per l'ISP o proveïdors públics (com `1.1.1.1` de Cloudflare o `8.8.8.8` de Google). Rep la petició del client web i fa tota la seqüència d'indagacions iteratives fins a obtindre la resposta definitiva, guardant-la en la seua memòria cau local (*cache*) durant el temps definit pel TTL (*Time To Live*).
- **Servidor Autoritatiu:** És el servidor que conté els fitxers de zona originals amb les dades oficials d'un domini determinat. No fa consultes a tercers; respon amb certesa absoluta sobre els registres dels quals és responsable.

```
 [ Client Web ] ---> [ Servidor Recursiu ] ---> 1. Consulta Servidor Arrel (.)
                            |              <---    "Vés al TLD .es"
                            |              ---> 2. Consulta TLD .es
                            |              <---    "Vés a l'autoritatiu de gva.es"
                            |              ---> 3. Consulta Autoritatiu gva.es
                            |              <---    "aules.edu.gva.es té IP 193.144.127.80"
                            v
                     Retorna IP al client (i emmagatzema a la memòria cau TTL)
```
