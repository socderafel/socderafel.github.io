## Protocols de Transferència de Fitxers

La publicació de documentació tècnica, pàgines web i el desplegament d'arxius en servidors remots es realitza mitjançant protocols de transferència de xarxa:

```
[ Client FileZilla / WinSCP ]
             |
             +---- Port 21 (FTP Clàssic) ----> [ Servidor FTP ]  (TEXT PLA INSEGUR!)
             |
             +---- Port 22 (SFTP / SSH) -----> [ Servidor SSH ]  (CANAL TOTALMENT XIFRAT)
             |
             +---- Port 990 (FTPS / TLS) ----> [ Servidor FTPS ] (XIFRATGE TLS)
```

---

## Comparativa d'Arquitectures de Transferència

| Protocol | Port per Defecte | Seguretat i Xifratge | Descripció Tècnica |
| :--- | :---: | :--- | :--- |
| **FTP** | 21 (control) + 20 (dades) | **Nul·la (Text pla).** Insegur. | Protocol històric (RFC 959). Les credencials i dades viatgen en clar per la xarxa. |
| **FTPS** | 990 / 21 explícit | **Alta (TLS / SSL).** | FTP clàssic protegit mitjançant certificats digitals TLS (idèntic a com HTTPS protegeix HTTP). |
| **SFTP** | 22 | **Alta (SSH-2).** | Subsistema de fitxers sobre el protocol segur SSH (*SSH File Transfer Protocol*). Requereix un sol port. |

## Eines Col·laboratives al Núvol i Instruments de Recollida de Dades

El treball en equip modern en entorns tecnològics requereix:
1. **Emmagatzematge i Sincronització Compartida:** Plataformes com Nextcloud (lliure i autogestionada), Google Drive o Microsoft OneDrive, amb gestió de rols (*Lector*, *Comentador*, *Editor*) i caducitat d'enllaços.
2. **Formularis Web per a Recollida de Dades:** Creació d'enquestes tècniques i formularis de petició d'incidències mitjançant eines interactives (Microsoft Forms, Google Forms, Typeform, LimeSurvey), canalitzant les respostes directament a fulls de càlcul per al seu tractament automatitzat.
