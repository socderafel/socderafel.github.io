## El Marc Legal del Programari i la Propietat Intel·lectual

Tot programari informàtic és una obra d'enginyeria protegida per la legislació de propietat intel·lectual. En adquirir o descarregar un programa, el que s'obté en realitat és un **contracte de llicència d'ús (EULA / Software License)** que estableix els drets i limitacions de l'usuari.

```
+-------------------------------------------------------------+
|                     TIPOLOGIES DE LLICÈNCIA                 |
+-------------------------------------------------------------+
               |                               |
               v                               v
    PROGRAMARI PROPIETARI             PROGRAMARI DE CODI OBERT
  - Codi font secret (tancat)       - Codi font accessible i públic
  - Prohibida la redistribució      - Llibertat de modificació
  - Llicència per usuari/equip      - Comunitat col·laborativa
               |                               |
       +-------+-------+               +-------+-------+
       |               |               |               |
   Comercial        Freeware       Copyleft (GPL)   Permissives (MIT)
 (MS Office)     (Acrobat Reader)  (LibreOffice)     (VS Code core)
```

## Les 4 Llibertats del Programari Lliure (FSF)

Definides per Richard Stallman i la Free Software Foundation (FSF):
1. **Llibertat 0:** Llibertat d'executar el programa per a qualsevol propòsit (sense restriccions d'ús comercial, educatiu o militar).
2. **Llibertat 1:** Llibertat d'**estudiar com funciona el programa** i adaptar-lo a les teues necessitats (requereix accés obligatori al codi font).
3. **Llibertat 2:** Llibertat de **redistribuir còpies** per a ajudar el teu veí.
4. **Llibertat 3:** Llibertat de **millorar el programa i fer públiques les teues millores** perquè tota la comunitat se'n beneficie.

## Comparativa de Suites Ofimàtiques

| Característica | Microsoft 365 (Office) | LibreOffice | Google Workspace |
| :--- | :--- | :--- | :--- |
| **Model de Llicència** | Propietari de pagament per subscripció (SaaS) | Programari Lliure (LGPLv3 / MPL) Gratuït | Propietari Freemium al núvol |
| **Format Principal** | OpenXML (.docx, .xlsx, .pptx) | OpenDocument (.odt, .ods, .odp - ISO 26300) | Propietari al núvol exportable |
| **Execució** | Escriptori natiu + Web reduïda | Escriptori natiu local 100% offline | Basat 100% en navegador web |
| **Privadesa de Dades** | Servidors Microsoft Cloud | Local a la teua màquina física | Servidors Google Cloud |
