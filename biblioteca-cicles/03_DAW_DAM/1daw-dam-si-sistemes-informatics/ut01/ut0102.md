## El Concepte d'Estil Tipogràfic i Estructura Semàntica

En la redacció de memòries de projectes informàtics i manuals d'usuari, aplicar format manualment línia a línia (canviar la mida de font, posar negreta o color) és un error greu que impedeix l'automatització.

Els **estils semàntics** defineixen el rol de cada bloc de text:
- **Títol 1 (Encapçalament 1 / Heading 1):** Apartats principals de primer nivell.
- **Títol 2 (Encapçalament 2 / Heading 2):** Subapartats.
- **Cos de text (Normal):** Pàgrafs ordinaris d'explicació.
- **Codi font / Monospai:** Fragments d'ordres de terminal o línies de codi.

```
+-------------------------------------------------------------+
|                     ESTRUCTURA D'ESTILS                     |
|                                                             |
|   Heading 1: "1. Arquitectura del Sistema"                 |
|     Heading 2: "1.1 Servidor Web Apache"                   |
|       Cos de text: Paràgraf descriptiu explicatiu...        |
|     Heading 2: "1.2 Servidor de Base de Dades MySQL"       |
+-------------------------------------------------------------+
                              |
               generació automàtica instantània
                              v
+-------------------------------------------------------------+
|            TAULA DE CONTINGUTS (ÍNDEX AUTOMÀTIC)            |
|   1. Arquitectura del Sistema ......................... Pàg 3|
|     1.1 Servidor Web Apache ........................... Pàg 3|
|     1.2 Servidor de Base de Dades MySQL ............... Pàg 5|
+-------------------------------------------------------------+
```

## Seccions, Capçaleres i Peus de Pàgina Independents

Un document professional requereix que la portada **no porte número de pàgina**, que l'índex utilitze numeració romana (`i`, `ii`, `iii`) i que el cos principal comence a la pàgina 1 amb numeració aràbiga.

Això s'aconsegueix inserint **Salts de Secció** (pàgina següent) i desvinculant l'opció *"Enllaçar a l'anterior"* en les capçaleres i peus de pàgina de cada secció.

---

## Preservació a Llarg Termini: PDF/A (ISO 19005)

Quan es lliura una memòria tècnica a un client o a una administració pública, el format PDF ordinari no és suficient, ja que pot enllaçar tipus de lletra del sistema operatiu local o dependre d'arxius externs.

L'estàndard **PDF/A** (PDF for Archiving) imposa regles estrictes:
1. **Fonts 100% incrustades:** Tots els caràcters tipogràfics han d'estar continguts físicament dins de l'arxiu.
2. **Prohibició de codi executable:** No es permeten scripts en JavaScript ni continguts multimèdia externs que puguen quedar obsolets o ser vectors d'atac.
3. **Colors independents de maquinari:** S'utilitzen perfils de color estandarditzats (ICC) per a garantir que el document es veja exactament igual en qualsevol pantalla o impressora en el futur.
