## Dues Filosofies d'Administració en Xarxes Locals

A l'hora d'organitzar els ordinadors, usuaris i recursos d'una xarxa local, existeixen dos models arquitectònics radicalment oposats:

```
MODEL GRUP DE TREBALL (Peer-to-Peer)          MODEL DOMINI (Client / Servidor Centralitzat)
+-----------------------------------+         +-----------------------------------+
| Ordinador 1      Ordinador 2      |         |   CONTROLADOR DE DOMINI (DC)      |
| [SAM local]      [SAM local]      |         |   Base de dades centralitzada     |
|   - userA            - userB      |         |   Active Directory (NTDS.dit)     |
|   - pass1            - pass2      |         |   - Tots els usuaris corporatius  |
|                                   |         |   - Polítiques de seguretat (GPO) |
| Ordinador 3      Ordinador 4      |         +-----------------------------------+
| [SAM local]      [SAM local]      |                           |
+-----------------------------------+                           v (Autenticació Kerberos)
(Cadascun gestiona la seua seguretat.                 +-----------------------+
 Descentralitzat, inmanejable > 10 PCs)               | Clients del Domini    |
                                                      | (PC1, PC2, PC3, PC4)  |
                                                      +-----------------------+
```

---

## El Model de Grup de Treball (*Workgroup*)

- **Descentralització absoluta:** Tots els equips tenen el mateix rang jeràrquic (cap és superior a un altre, relació d'igual a igual *Peer-to-Peer*).
- **Seguretat local:** Cada ordinador té la seua pròpia base de dades local de seguretat (**SAM - Security Account Manager** en Windows o `/etc/passwd` i `/etc/shadow` en Linux).
- **Problema greu d'administració:** Si l'usuari "Laura" vol accedir a carpetes compartides en 10 equips diferents, el seu compte i la seua contrasenya han de ser creats manualment als 10 equips. Si canvia la contrasenya, cal canviar-la als 10 llocs!
- **Àmbit d'aplicació:** Xarxes domèstiques o microempreses de menys de 5 a 10 equips.

---

## El Model de Domini de Xarxa (*Domain Architecture*)

- **Centralització absoluta:** Tota la informació d'usuaris, grups, equips, impressores i polítiques de seguretat resideix en una **única base de dades centralitzada** allotjada en un o més servidors anomenats **Controladors de Domini (*Domain Controllers - DC*)**.
- **Autenticació única (*Single Sign-On - SSO*):** L'usuari només té un compte de domini únic (`empresa\laura`). Pot iniciar sessió a qualsevol ordinador connectat al domini amb les seues mateixes credencials, i el servidor DC s'encarrega de validar-la mitjançant el protocol criptogràfic **Kerberos**.
- **Control central:** L'administrador pot canviar una contrasenya, bloquejar un usuari acomiadat o aplicar una política de seguretat a milers d'ordinadors des d'una única pantalla de gestió en qüestió de segons.
