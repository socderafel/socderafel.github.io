## Què és un Servei de Directori?

Un **Servei de Directori** és una base de dades jeràrquica especialitzada, optimitzada per a lectures molt ràpides i consultes complexes, que emmagatzema informació sobre tots els **objectes de la xarxa** (usuaris, grups, equips, impressores, servidors i recursos) i les seues relacions i atributs.

---

## Active Directory Domain Services (AD DS)

**Active Directory** és el servei de directori de Microsoft Windows Server. La seua arquitectura jeràrquica s'estructura en:

```
+-------------------------------------------------------------+
|                          BOSC (Forest)                      |
|           Límit màxim de seguretat i esquema comú           |
|  +-------------------------------------------------------+  |
|  | ARBRE DE DOMINI (Tree)                                |  |
|  |   - Domini Arrel: empresa.local                       |  |
|  |   - Subdomini fill: sucursal.empresa.local            |  |
|  |   - Subdomini fill: dev.empresa.local                 |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
```

### Components Clau d'Active Directory
1. **Controlador de Domini (DC):** Servidor físic o virtual que executa el rol AD DS i allotja una còpia de la base de dades `ntds.dit`. En entorns empresarials és obligatori tindre almenys dos DCs per domini per a oferir **alta disponibilitat i rèplica**.
2. **Dependència de DNS:** Active Directory no pot funcionar sense un servidor **DNS**. Els clients utilitzen registres SRV de DNS per a localitzar físicament on estan els controladors de domini a la xarxa.
3. **El Catàleg Global (GC):** Magatzem que manté una còpia parcial de només lectura de tots els objectes de tots els dominis del bosc per a permetre cerques ràpides entre dominis.

---

## La Solució Lliure: Samba 4 AD DC en Linux

En entorns de programari lliure, el projecte **Samba 4** va aconseguir la fita d'enginyeria inversa d'actuar com un **Controlador de Domini d'Active Directory 100% compatible** amb el protocol de Microsoft:
- Permet que ordinadors amb Windows 10/11 i Linux s'unisquen al domini de Samba com si fóra un Windows Server natiu.
- Integra servidor DNS intern o BIND9, servidor Kerberos (Heimdal/MIT) i servidor LDAP.
- Es pot administrar remotament des d'un ordinador client Windows utilitzant les eines oficials de Microsoft **RSAT (*Remote Server Administration Tools*)**.
