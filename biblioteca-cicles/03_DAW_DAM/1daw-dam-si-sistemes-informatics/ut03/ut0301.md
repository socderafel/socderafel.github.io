## Què és un Sistema Operatiu?

Un **Sistema Operatiu (SO)** és el programari base més important d'un ordinador. Actua com a **intermediari indispensable** entre el maquinari físic i les aplicacions d'usuari, complint dues funcions fonamentals:
1. **Administrador de recursos:** Gestiona de manera eficient i equitativa la CPU, la memòria RAM, l'emmagatzematge secundari i els dispositius d'E/S entre tots els processos en concurrència.
2. **Màquina ampliada o virtual:** Ofereix una abstracció neta i d'alt nivell (fitxers, sockets, processos) ocultant la complexitat física dels registres i senyals del maquinari.

```
+-------------------------------------------------------------+
|               Aplicacions d'Usuari (Browser, IDE, Joc)      |
+-------------------------------------------------------------+
                              |
                    CRIDES AL SISTEMA (System Calls)
                              |
+-------------------------------------------------------------+
|                      SISTEMA OPERATIU                       |
|  +-------------------------------------------------------+  |
|  | Nucli (Kernel):                                       |  |
|  | - Gestió de Processos (Planificador / Scheduler)      |  |
|  | - Gestió de Memòria (Paginació / Memòria Virtual)     |  |
|  | - Sistema de Fitxers (VFS / Drivers de fitxer)        |  |
|  | - Controladors de Maquinari (Device Drivers)          |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
                              |
                        MAQUINARI FÍSIC
                 (CPU, Memòria RAM, Disc, Xarxa)
```

---

## Separació d'Anells de Seguretat de la CPU

Per a protegir la integritat del sistema operatiu, les CPUs modernes x86/x64 implementen anells de protecció per maquinari (*Protection Rings*):
- **Ring 0 (Mode Kernel / Privilegiat):** El nucli del sistema operatiu té accés absolut a totes les instruccions de la CPU i a qualsevol adreça de la memòria física.
- **Ring 3 (Mode Usuari / No Privilegiat):** Les aplicacions d'usuari tenen prohibit executar instruccions crítiques (com manipular la taula de pàgines o aturar interrupcions) i tenen l'accés a memòria restringit al seu propi espai virtual aïllat.

Quan un programa vol escriure un fitxer al disc dur o connectar-se a una web, invoca una **crida al sistema (*System Call* o `syscall`)**, la qual provoca una interrupció per programari que commuta temporalment la CPU al mode privilegiat per a executar l'ordre de forma segura.

---

## Tipologies de Nuclis (*Kernel Architectures*)

1. **Nucli Monolític (Linux, BSD, clàssic Unix):** Tots els serveis del sistema (planificador, sistemes de fitxers, xarxa i controladors de dispositiu) s'executen junts en el mateix espai de memòria privilegiat de Ring 0. Màxima velocitat d'execució.
2. **Microkernel (Minix, QNX):** Només els serveis absolutament bàsics (comunicació IPC i memòria elemental) resideixen a Ring 0. Els controladors i sistemes de fitxers s'executen com a servidors aïllats en Ring 3. Màxima estabilitat i seguretat, però amb un cost de rendiment per canvis de context.
3. **Nucli Híbrid (Windows NT, macOS XNU):** Combina l'estabilitat del microkernel amb la velocitat de mòduls crítics carregats a l'espai de nucli.
