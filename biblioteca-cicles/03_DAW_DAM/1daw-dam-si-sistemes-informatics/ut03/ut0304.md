## Fonaments de la Virtualització

La **virtualització** és la tecnologia que permet crear representacions basades en programari (abstraccions virtuals) de servidors, emmagatzematge, xarxes i màquines completes, permetent que múltiples sistemes operatius s'executen de forma totalment **aïllada i simultània** sobre un únic conjunt de maquinari físic.

El cor de la virtualització és l'**Hipervisor (*Virtual Machine Monitor - VMM*)**.

---

## Classificació dels Hipervisors

```
HIPERVISOR TIPUS 1 (Bare-Metal)         HIPERVISOR TIPUS 2 (Hosted)
+-----------------------------+         +-----------------------------+
| Màquines Virtuals (VM1, VM2)|         | Màquines Virtuals (VM1, VM2)|
+-----------------------------+         +-----------------------------+
| HIPERVISOR TIPUS 1          |         | HIPERVISOR TIPUS 2          |
| (Proxmox, ESXi, Hyper-V core|         | (VirtualBox, VMware Workst.)|
+-----------------------------+         +-----------------------------+
| MAQUINARI FÍSIC DIRECTE     |         | Sistema Operatiu Amfitrió   |
| (CPU, RAM, Discs, Xarxa)    |         | (Windows 11, Ubuntu Desktop)|
+-----------------------------+         +-----------------------------+
                                        | MAQUINARI FÍSIC DIRECTE     |
                                        +-----------------------------+
```

1. **Tipus 1 (Natiu / Bare-Metal):** S'instal·la directament sobre el metall buit de la màquina servidora. No hi ha cap sistema operatiu amfitrió intermediari, la qual cosa ofereix el màxim rendiment, mínima latència i màxima densitat de càrrega. (Ex: VMware ESXi, Proxmox VE / KVM, Microsoft Hyper-V Server).
2. **Tipus 2 (Allotjat / Hosted):** S'executa com una aplicació ordinària dins d'un sistema operatiu d'escriptori convencional. Molt útil per a desenvolupament, proves de programari i laboratoris d'aprenentatge. (Ex: Oracle VirtualBox, VMware Workstation / Fusion).

---

## Modes de Xarxa Virtual en Hipervisors

Com es connecta la màquina virtual (Guest) amb la màquina física (Host) i amb la xarxa corporativa?

| Mode de Xarxa Virtual | Accés a Internet | Comunicació amb el Host físic | Visible des de la xarxa externa LAN |
| :--- | :---: | :---: | :---: |
| **NAT (Network Address Translation)** | **Sí** | No directe (només amb reenviament de ports) | **No** (oculta darrere la IP del host) |
| **Adaptador Pont (*Bridged Adapter*)** | **Sí** | **Sí** | **Sí** (rep una IP pròpia del mateix router físic com si fóra un PC independent) |
| **Només-Amfitrió (*Host-Only*)** | **No** | **Sí** (crea una xarxa privada exclusiva entre Host i VMs) | **No** (totalment aïllada del món exterior) |
| **Xarxa Interna (*Internal Network*)** | **No** | **No** | **No** (només comunicació entre VMs de la mateixa xarxa interna) |

---

## Eines de Màquina Virtual: Guest Additions / VMware Tools

Per a obtindre el màxim rendiment d'una màquina virtual és imprescindible instal·lar els paquets de controladors especials del fabricant (**Guest Additions** en VirtualBox):
- Resolució de pantalla dinàmica autoajustable al redimensionar la finestra.
- Integració fluida del punter del ratolí sense necessitat de capturar-lo.
- Carpetes compartides entre el sistema amfitrió i el virtualitzat.
- Portapapers compartit bidireccional (copiar i apegar text) i arrossegar fitxers (*Drag and Drop*).
