## Esquemes de Particionament: MBR vs GPT

Abans que un disc dur puga contindre sistemes de fitxers o sistemes operatius, ha de ser dividit en una o més àrees lògiques anomenades **particions**:

```
+-------------------------------------------------------------+
|              ESQUEMA MBR (Master Boot Record - 1983)        |
|  - Situat al sector 0 físic (512 bytes).                    |
|  - Conté: Codi d'arrencada (446 bytes) + Taula de 4         |
|    particions (64 bytes: 4 x 16 bytes) + Signatura 0x55AA.   |
|  - Màxim 4 particions primàries (o 3 primàries + 1 estesa   |
|    amb particions lògiques).                                |
|  - Límit de capacitat d'adreçament: 2.2 TB.                 |
+-------------------------------------------------------------+
                              vs
+-------------------------------------------------------------+
|             ESQUEMA GPT (GUID Partition Table - UEFI)       |
|  - Adreçament per sectors LBA de 64 bits.                   |
|  - Fins a 128 particions primàries independents en Windows.  |
|  - Suport de mides astronòmiques (fins a 9.4 Zettabytes).   |
|  - Redundància i integritat: Taula GPT de seguretat de      |
|    reserva (Backup GPT Header) al final físic del disc.     |
|  - Suma de verificació CRC32 per a detectar corrupcions.    |
+-------------------------------------------------------------+
```

---

## La Partició EFI System Partition (ESP)

En sistemes UEFI amb taula GPT, és **obligatòria** l'existència d'una partició especial anomenada **ESP (*EFI System Partition*)**:
- Formatada obligatòriament en sistema de fitxers **FAT32**.
- Mida típica: entre 100 MB i 512 MB.
- Conté els binaris d'arrencada dels diferents sistemes operatius en carpetes separades:
  - `/EFI/Microsoft/Boot/bootmgfw.efi` (Windows)
  - `/EFI/ubuntu/grubx64.efi` (Ubuntu Linux)

Aquesta arquitectura és immensament superior a l'antiga MBR perquè **elimina el conflicte d'arrencada**: instal·lar Linux no esborra el fitxer d'arrencada de Windows, cadascun viu en el seu propi subdirectori de l'ESP!

---

## Configuració d'Arrencada Dual (*Dual-Boot*) amb GRUB2

El gestor d'arrencada per excel·lència en entorns lliures és **GRUB2 (*Grand Unified Bootloader*)**:
1. En arrencar, llegeix el fitxer de configuració `/boot/grub/grub.cfg`.
2. Presenta un menú interactiu per a triar entre iniciar el nucli Linux o transferir el control (*chainloader*) a Windows Boot Manager.
3. El paquet `os-prober` s'encarrega d'escanejar automàticament totes les particions del disc per a detectar altres sistemes operatius i afegir-los al menú de GRUB mitjançant l'ordre `sudo update-grub`.
