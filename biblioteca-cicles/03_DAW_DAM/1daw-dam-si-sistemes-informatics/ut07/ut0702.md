## Manipulació Eficient de l'Arbre de Directoris

La manipulació de fitxers i directoris mitjançant el terminal requereix dominar les comandes estàndard POSIX i els seus paràmetres més potents:
- `mkdir -p /projectes/2026/daw/docs`: Crea tota l'estructura de directoris intermedis automàticament sense llançar error si ja existeixen.
- `cp -ra /origen /desti`: Còpia recursiva conservant intactes els permisos, propietaris i marques temporals originals (*archive mode*).
- `rm -rf /directori`: Eliminació recursiva i forçada (cal extremar precaucions).
- `find /var/www -type f -name "*.php" -size +1M`: Cerca potent en profunditat filtrant per tipus, nom, mida o temps de modificació.

## Enllaços al Sistema de Fitxers: Durs vs Simbòlics

En els sistemes de fitxers de Linux (ext4, XFS, Btrfs), cada fitxer té un identificador numèric intern anomenat **node-i (inode)**, que emmagatzema les metadades físiques (blocs al disc, mida, permisos, usuari) excepte el nom del fitxer.

```
+-------------------------------------------------------+
|  Enllaç Dur (Hard Link):                              |
|  [Nom Fitxer 1] ----> [ Inode 1045 ] <---- [Nom Fitxer 2] |
|                              |                        |
|                        [Blocs de Dades]               |
+-------------------------------------------------------+
|  Enllaç Simbòlic (Symlink):                           |
|  [Fitxer .lnk] ----> "Ruta: /var/log/fitxer.log"      |
|                              |                        |
|                        [ Inode 2088 ]                 |
+-------------------------------------------------------+
```

1. **Enllaç Dur (`ln fitxer_original nou_enllac`):**
   - Crea una nova entrada de directori que apunta al *mateix* inode.
   - Si s'esborra el fitxer original, les dades no es perden mentre quede com a mínim un enllaç apuntant a l'inode.
   - Limitacions: No pot apuntar a directoris ni travessar sistemes de fitxers diferents (particions distintes).
2. **Enllaç Simbòlic o Toli (`ln -s fitxer_original enllac_simbolic`):**
   - És un fitxer nou independent que conté un punter de text a una ruta.
   - Pot apuntar tant a fitxers com a directoris i travessar qualsevol disc o partició de xarxa.
   - Si s'esborra o mou l'original, l'enllaç queda trencat (*broken symlink*).

## Permisos Estàndard POSIX i Llistes de Control d'Accés (ACL)

### Permisos Estàndard (`chmod`, `chown`)
Cada fitxer o directori posseeix permisos per a tres tipus d'usuaris: **Propietari (u)**, **Grup (g)** i **Altres (o)**.
Els valors octals són:
- Lectura (`r`): 4
- Escriptura (`w`): 2
- Execució (`x`): 1

Per exemple, `chmod 755 script.sh` atorga `rwx` (7) al propietari, `r-x` (5) al grup i `r-x` (5) a la resta.

### Llistes de Control d'Accés (ACLs)
Quan el model bàsic d'un sol usuari i un sol grup resulta insuficient (per exemple, si cal donar permís d'escriptura a un segon grup d'auditors sense fer-los amos del fitxer), s'utilitzen les eines POSIX ACL:
```bash
# Consultar els permisos detallats d'un recurs
getfacl /projectes/desenvolupament

# Donar permís d'escriptura al grup 'comptabilitat' mitjançant ACL
setfacl -m g:comptabilitat:rwx /projectes/desenvolupament

# Eliminar totes les regles addicionals d'ACL
setfacl -b /projectes/desenvolupament
```
