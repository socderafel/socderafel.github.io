## Anatomia d'un Script en Bash

Un script en Bash és un fitxer de text executable que conté una successió estructurada d'ordres interpretades pel terminal.
- **Shebang (`#!/bin/bash`):** La primera línia absoluta de l'arxiu. Indica al nucli del sistema quin intèrpret s'ha d'utilitzar per a executar el codi.
- **Permisos d'execució:** Perquè un fitxer siga executable cal atorgar-li el permís corresponent (`chmod +x script.sh`).

---

## Variables i Paràmetres Especials

En Bash no cal declarar els tipus de dades. Per a assignar valor **no es poden deixar espais al voltant del signe igual (`=`)**:

```bash
#!/bin/bash
# Declaració correcta
NOM="Ausiàs"
EDAT=22

# Lectura de variables amb el símbol de dòlar
echo "Hola, em dic $NOM i tinc $EDAT anys."
```

### Paràmetres Posicionals i Especials
Quan s'executa un script amb arguments (per exemple: `./desplegar.sh entorn_prod v2.0`):
- **`$0`:** El nom de l'script que s'està executant (`./desplegar.sh`).
- **`$1`, `$2`, `$3`...:** Els arguments passats per línia d'ordres en ordre seqüencial.
- **`$#`:** El nombre total d'arguments passats a l'script.
- **`$*` o `$@`:** La llista completa de tots els arguments passats.
- **`$?`:** El **codi de retorn (exit status)** de l'última comanda executada (`0` significa èxit absolut; qualsevol valor superior a 0 indica un error).

## Estructures de Control de Flux

### Condicionals (`if - then - elif - else - fi`)
La comprovació de condicions es realitza habitualment amb claudàtors `[ ... ]` (comanda `test` integrada):

```bash
#!/bin/bash
if [ -f "/etc/nginx/nginx.conf" ]; then
    echo "El servidor web està instal·lat."
elif [ -d "/etc/apache2" ]; then
    echo "Apache trobat."
else
    echo "No s'ha detectat cap servidor web conegut."
    exit 1
fi
```

Operadors de comparació freqüents:
- Cadenes: `[ "$A" = "$B" ]`, `[ -z "$CADENA" ]` (cadena buida).
- Nombres: `-eq` (igual), `-ne` (diferent), `-lt` (menor), `-gt` (major), `-le`, `-ge`.
- Fitxers: `-f` (és fitxer regular), `-d` (és directori), `-e` (existeix), `-r` (llegible), `-w` (escrivible), `-x` (executable).

---

### Bucles (`for` i `while`)

```bash
# Bucle For iterant sobre una llista o resultat de comanda
for FITXER in *.log; do
    echo "Comprimint: $FITXER"
    gzip "$FITXER"
done

# Bucle While llegint un fitxer línia per línia
while IFS= read -r LINIA; do
    echo "Usuari a crear: $LINIA"
done < llista_usuaris.txt
```
