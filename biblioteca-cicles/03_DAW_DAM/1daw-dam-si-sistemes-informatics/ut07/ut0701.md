## La Consola d'Ordres (CLI) enfront de la Interfície Gràfica (GUI)

En entorns de producció i servidors de computació empresarial (núvol AWS, Azure, GCP o centres de dades privats), les interfícies gràfiques d'usuari (GUI) s'eliminen intencionadament per a:
1. **Reduir la superfície d'atac:** Menys biblioteques i codi exposat a vulnerabilitats de seguretat.
2. **Estalviar recursos crítics:** Una GUI consumeix entre 500 MB i 2 GB de memòria RAM i cicles continus de CPU innecessàriament.
3. **Facilitar l'automatització:** Qualsevol acció realitzada mitjançant comandes pot ser programada, parametritzada i executada sobre centenars de servidors simultàniament.

## Intèrprets de Comandes: Bash vs PowerShell

| Característica | GNU Bash (Bourne-Again Shell) | Microsoft PowerShell 7 (pwsh) |
| :--- | :--- | :--- |
| **Model de dades** | Flux continu de text pur (cadenes de caràcters ASCII/UTF-8). | **Objectes .NET** enriquits amb mètodes i propietats tipades. |
| **Entorn nadiu** | Distribucions Linux (Debian, Ubuntu, RHEL) i macOS. | Windows (versió 5.1/Desktop) i Multiplataforma (PS 7 Core). |
| **Filosofia de processament** | Utilització d'eines externes especialitzades (`grep`, `awk`, `sed`, `cut`). | Cmdlets natius integrats amb format `Verb-Nom` (`Get-Process`, `Set-Service`). |
| **Integració al sistema** | Crides a sistema POSIX i manipulació de fitxers de text pla. | Accés natiu a l'API de Windows, WMI, CIM i biblioteques .NET. |

## Descriptors de Fitxers i Redireccions en Bash

Tot procés d'usuari en un entorn Unix/Linux s'inicia amb tres canals o descriptors de comunicació estàndard:
- **`stdin` (Descriptor 0):** Entrada estàndard (per defecte, el teclat de l'operador).
- **`stdout` (Descriptor 1):** Sortida estàndard per a missatges normals (per defecte, la pantalla).
- **`stderr` (Descriptor 2):** Sortida d'errors per a missatges de fallada o diagnòstic (per defecte, la pantalla).

```bash
# Sobreescriure la sortida estàndard en un fitxer
echo "Iniciant procés" > registre.txt

# Afegir contingut al final del fitxer sense esborrar l'anterior (append)
echo "Nou missatge" >> registre.txt

# Redirigir només els errors a un fitxer apart
comanda_erronia 2> errors.log

# Redirigir tant stdout com stderr al mateix destí
comanda_complexa &> tot.log

# Descartar completament qualsevol missatge d'error enviant-lo al forat negre
find / -name "*.conf" 2> /dev/null
```

## Filtres i Canonades (*Pipes*)

L'operador de canonada `|` permet encadenar la sortida d'un programa amb l'entrada del següent, generant línies de processament modulars i altament eficients:
- **`grep`:** Cerca patrons de text mitjançant expressions regulars (`grep -i "error" /var/log/syslog`).
- **`wc`:** Compta línies, paraules o caràcters (`wc -l fitxer.txt`).
- **`sort`:** Ordena alfabèticament o numèricament (`sort -n`).
- **`uniq`:** Elimina línies duplicades contigües (`uniq -c` compta ocurrències).
- **`head` / `tail`:** Mostra les primeres o darreres línies d'un flux (`tail -f` monitoritza canvis en viu).
