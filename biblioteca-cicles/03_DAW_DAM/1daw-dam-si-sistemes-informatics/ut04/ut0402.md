## Dues Filosofies Radicals d'Organització de Fitxers

L'organització espacial dels fitxers és completament diferent entre el món UNIX/Linux i el món Windows:

```
FILOSOFIA WINDOWS (Lletres d'unitat)           FILOSOFIA LINUX / UNIX (Arbre Únic Arrel /)
+------------------------------------+         +------------------------------------+
|  C:\ (Disc del Sistema)            |         |  / (Arrel Única del Sistema)       |
|    ├── Windows\System32            |         |  ├── bin (Ordres essencials)       |
|    ├── Program Files               |         |  ├── etc (Fitxers de configuració) |
|    └── Users\Marc                  |         |  ├── home\marc (Carpeta personal)  |
|  D:\ (Disc de Dades / SSD extern)  |         |  ├── var\log (Fitxers de registre) |
|    └── Projectes                   |         |  ├── dev (Dispositius com fitxers) |
|  E:\ (Memòria USB)                 |         |  └── mnt o media (Punts de muntatge|
+------------------------------------+         |      on s'integren discs i USBs)   |
                                               +------------------------------------+
```

---

## L'Estàndard FHS de Linux (Filesystem Hierarchy Standard)

En Linux, **absolutament tot és un fitxer** i tots els discs, particions i recursos es munten en un únic arbre jeràrquic que penja de la barra arrel `/`:
- **`/bin` i `/sbin`:** Binaris executables essencials del sistema (comandes d'administració a `/sbin`).
- **`/etc`:** Fitxers de **configuració del sistema** en format text pla (`/etc/passwd`, `/etc/fstab`, `/etc/network`).
- **`/home`:** Directoris personals dels usuaris ordinaris.
- **`/root`:** Directori personal de l'administrador del sistema.
- **`/var`:** Dades variables que creixen en temps d'execució (bases de dades a `/var/lib/mysql`, webs a `/var/www/html`, registres d'auditoria a `/var/log`).
- **`/dev`:** Fitxers especials de dispositiu (ex: `/dev/sda` disc SATA, `/dev/nvme0n1` disc NVMe).
- **`/proc` i `/sys`:** Sistemes de fitxers virtuals pseudo-temporals generats en RAM pel nucli per a consultar l'estat del maquinari i els processos en temps real.

---

## Punts de Muntatge (*Mount Points*) i el Fitxer `/etc/fstab`

En Linux, per a fer accessible una partició de disc o recurs compartit, s'associa a una carpeta buida anomenada **punt de muntatge**:
`mount /dev/sdb1 /mnt/dades`

El fitxer de configuració crític **`/etc/fstab` (*File Systems Table*)** estableix quines particions es munten automàticament a l'arrencada utilitzant el seu identificador únic universal (**UUID**):
```
UUID=3a7b8c9d-1234-5678-9abc-def012345678  /mnt/dades  ext4  defaults,noatime  0  2
```
