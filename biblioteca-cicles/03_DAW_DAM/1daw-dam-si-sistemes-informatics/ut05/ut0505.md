## Serveis de Configuració i Resolució Essencials

Perquè un equip puga navegar i operar de forma transparent a la xarxa, depèn de dos serveis fonamentals de la Capa d'Aplicació:

### 1. El Protocol DHCP (*Dynamic Host Configuration Protocol* - Ports UDP 67/68)
Automatitza el lliurament de configuració de xarxa mitjançant el procés **DORA**:
- **Discover:** El client acabat d'engegar envia un broadcast cercant un servidor DHCP.
- **Offer:** Els servidors DHCP responen oferint una adreça IP disponible d'un rang o àmbit (*pool*).
- **Request:** El client tria una oferta i sol·licita formalment la seua assignació en lloguer (*lease*).
- **Acknowledge (ACK):** El servidor confirma l'assignació enviant la IP, la màscara, la **Porta d'Enllaç (*Gateway*)** i els servidors **DNS**.

### 2. El Servei DNS (*Domain Name System* - Port UDP 53)
La guia telefònica d'Internet: tradueix noms de domini fàcilment memoritzables per humans (com `www.gva.es`) a les seues adreces IP numèriques equivalents (com `193.144.127.45`):
- Registres clau: **A** (IPv4), **AAAA** (IPv6), **CNAME** (àlies o sobrenom), **MX** (servidor de correu) i **PTR** (resolució inversa d'IP a nom).

## Eines de Diagnòstic i Verificació de Xarxa

L'administrador de sistemes disposa d'un arsenal d'ordres de terminal indispensables per a trobar fallades de connectivitat:

```
[ Comprovació IP local ]  -->  [ Prova de Gateway ]  -->  [ Prova de DNS ]  -->  [ Prova d'Internet ]
  ip a (Linux)                  ping 192.168.1.1          nslookup domini.es      ping 8.8.8.8
  ipconfig (Windows)
```

| Comanda Linux | Comanda Windows | Finalitat Tècnica |
| :--- | :--- | :--- |
| `ip addr` / `ip a` | `ipconfig /all` | Mostra les adreces IP, màscares i adreces MAC de totes les interfícies de xarxa actives. |
| `ping adreca` | `ping adreca` | Envia paquets ICMP Echo Request per a mesurar latència (RTT en ms) i pèrdua de paquets. |
| `traceroute adreca` | `tracert adreca` | Mostra tots els encaminadors intermedis (salts) per on passa el paquet fins al destí. |
| `ss -tulpn` | `netstat -ano` | Mostra tots els ports de xarxa oberts a l'ordinador a l'escolta (*Listening*) i connexions actives. |
| `dig domini` / `nslookup`| `nslookup domini` | Realitza consultes directes als servidors DNS per a verificar la resolució de registres. |
