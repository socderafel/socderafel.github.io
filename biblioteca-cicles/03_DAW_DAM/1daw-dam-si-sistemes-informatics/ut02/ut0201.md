## El Model Fonamental de Von Neumann

Proposat pel matemàtic John von Neumann en 1945, constitueix la base teòrica de pràcticament tots els ordinadors digitals moderns. El seu principi revolucionari va ser el concepte de **programa emmagatzemat**: tant les dades a processar com les instruccions del programa resideixen en la mateixa memòria física unificada.

```
+-------------------------------------------------------------+
|             UNITAT CENTRAL DE PROCESSAMENT (CPU)            |
|  +-------------------------------------------------------+  |
|  | Unitat de Control (UC):                               |  |
|  |   - Comptador de Programa (PC): Adreça pròxima instr. |  |
|  |   - Registre d'Instrucció (RI): Instrucció actual     |  |
|  |   - Descodificador i Seqüenciador de control          |  |
|  +-------------------------------------------------------+  |
|  +-------------------------------------------------------+  |
|  | Unitat Aritmeticològica (ALU): Operacions matemàtiques|  |
|  | Banc de Registres Generals i Acumulador               |  |
|  +-------------------------------------------------------+  |
+-------------------------------------------------------------+
               ^                       ^
               | Bus de Control        | Bus de Dades
               | Bus d'Adreces         |
               v                       v
+-----------------------------+ +-----------------------------+
|    MEMÒRIA PRINCIPAL (RAM)  | |  SUBSISTEMA D'ENTRADA/EIXIDA|
| - Cel·les adreçables        | | - Controladors de ports     |
| - Dades i instruccions      | | - Teclat, disc, pantalla    |
+-----------------------------+ +-----------------------------+
```

## Els Tres Busos del Sistema

La comunicació entre la CPU, la memòria RAM i els perifèrics d'E/S s'efectua a través d'un conjunt de pistes elèctriques paral·leles anomenades **busos**:

1. **Bus de Dades (Bidireccional):** Transporta la informació real (valors o instruccions de codi màquina). La seua amplada (ex: 64 bits) determina quants bits es transfereixen en un únic cicle.
2. **Bus d'Adreces (Unidireccional des de la CPU):** Transporta l'adreça física de la cel·la de memòria o dispositiu d'E/S amb el qual es vol interactuar. Un bus d'adreces de $n$ bits permet adreçar directament $2^n$ bytes de memòria física (un bus de 32 bits adreça com a màxim 4 GB; un bus de 64 bits permet milions de Terabytes).
3. **Bus de Control (Bidireccional):** Transporta senyals de sincronització i ordres de control (lectura/escriptura `R/W`, senyals de rellotge `CLK`, peticions d'interrupció `IRQ` i reconeixements `ACK`).

---

## El Cicle d'Instrucció de la CPU

Per a executar qualsevol ordre, la CPU repeteix contínuament un cicle de tres fases:
1. **Cerca (*Fetch*):** La UC llegeix de la memòria RAM la instrucció apuntada pel Comptador de Programa (PC) i la diposita en el Registre d'Instrucció (RI). S'incrementa el PC.
2. **Descodificació (*Decode*):** El descodificador interpreta el codi d'operació de la instrucció i localitza els operands.
3. **Execució (*Execute*):** L'ALU realitza el càlcul o l'operació lògica i el resultat s'emmagatzema en un registre o a la memòria RAM.
