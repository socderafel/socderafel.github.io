## La Revolució de l'Emmagatzematge: Magnètic vs Estat Sòlid

L'emmagatzematge secundari ha sigut històricament el gran **coll d'ampolla** dels ordinadors:

```
+-------------------------------------------------------------+
|                 DISC DUR MAGNÈTIC (HDD)                     |
|  - Mecànic: plats giratoris a 5400/7200 RPM i capçals mòbils|
|  - Latència mecànica elevada: 10 a 15 ms de cerca (seek)    |
|  - Rendiment aleatori: 75 - 150 IOPS                        |
|  - Taxa seqüencial màxima: ~150 - 250 MB/s                  |
+-------------------------------------------------------------+
                              vs
+-------------------------------------------------------------+
|               UNITAT D'ESTAT SÒLID (SSD NVMe)               |
|  - Electrònic: xips de memòria flash NAND (TLC/QLC)         |
|  - Latència pràcticament nul·la: ~0.02 ms (microsegons)     |
|  - Rendiment aleatori: 500.000 - 1.000.000 IOPS             |
|  - Taxa seqüencial màxima: 3500 - 7500 MB/s (PCIe 4.0)      |
+-------------------------------------------------------------+
```

---

## Interfícies i Formats Físics

1. **SATA III (6 Gbps):**
   - Utilitza el protocol clàssic **AHCI** (dissenyat originàriament per a discs durs mecànics, amb una única cua de 32 ordres).
   - Velocitat màxima teòrica limitada pel bus a **550 - 600 MB/s**.
   - Format típic de 2.5 polzades.
2. **M.2 NVMe (Non-Volatile Memory Express):**
   - Format físic compacte en forma de petita targeta que es connecta directament a la placa base (factors de forma 2280: 22 mm d'ample per 80 mm de llarg).
   - El protocol **NVMe** està dissenyat des de zero per a memòria flash i concurrència massiva: admet fins a **64.000 cues de 64.000 ordres cadascuna**.
   - Connectat directament al bus PCIe (x4 línies).

---

## Mètriques Clau de Fiabilitat i Rendiment

- **IOPS (Input/Output Operations Per Second):** Nombre d'operacions d'accés a blocs petits (típicament 4 KB) per segon. És la dada que determina la fluïdesa del sistema operatiu i la velocitat de les bases de dades.
- **TBW (Terabytes Written):** Quantitat total acumulada de terabytes de dades que es poden escriure a la memòria flash abans que les cel·les comencen a degradar-se per desgast físic.
- **TRIM:** Ordre que envia el sistema operatiu a l'SSD per a indicar quins blocs de dades ja no contenen informació vàlida i poden ser esborrats internament en segon pla (*garbage collection* del firmware de l'SSD).
