## La Placa Base (Motherboard): El Centre Neuràlgic

La **placa base** és el circuit imprès principal que interconnecta físicament i elèctricament tots els components del sistema informàtic:

```
+-------------------------------------------------------------+
|                         PLACA BASE                          |
|                                                             |
|   +-------------------+         +-----------------------+   |
|   | Sòcol CPU (Socket)| <=====> | Ranures RAM (DIMM)    |   |
|   | (LGA / AM5)       |         | Controlador integrat  |   |
|   +-------------------+         +-----------------------+   |
|             ^                                               |
|             | Línies directes PCIe                          |
|             v                                               |
|   +-----------------------------------------------------+   |
|   | Ranures PCIe x16 (Targeta Gràfica GPU dedicada)     |   |
|   +-----------------------------------------------------+   |
|             |                                               |
|             | Bus DMI / UMI d'alta velocitat                |
|             v                                               |
|   +-----------------------------------------------------+   |
|   | Xipset / Concentrador de Controladors (PCH)         |   |
|   | - Ports SATA, USB, Ethernet, Àudio, PCIe secundari  |   |
|   +-----------------------------------------------------+   |
+-------------------------------------------------------------+
```

---

## Tipologies de Sòcol de CPU: LGA vs PGA

- **LGA (Land Grid Array - Intel i modern AMD AM5):** Els pins de contacte elèctrics es troben **a la pròpia placa base**, mentre que el processador només té punts de contacte daurats plans. Evita doblegar pins al processador, però requereix màxima cura en manipular la placa base.
- **PGA (Pin Grid Array - AMD històric com AM4):** Els pins es troben a la part inferior del xip del processador i s'insereixen en els orificis del sòcol de la placa base.

---

## El Bus PCI Express (PCIe)

PCIe és la interfície d'interconnexió sèrie punt a punt que ha substituït tots els antics busos (PCI, AGP). Funciona mitjançant **carrils de dades (*lanes*)**:
- **x1:** 1 carril (per a targetes de xarxa o so bàsiques).
- **x4:** 4 carrils (habitual per a unitats SSD M.2 NVMe).
- **x16:** 16 carrils en paral·lel (per a targetes gràfiques d'alt rendiment).

Cada generació duplica l'amplada de banda:
- **PCIe 3.0:** ~1 GB/s per carril.
- **PCIe 4.0:** ~2 GB/s per carril (~32 GB/s en x16).
- **PCIe 5.0:** ~4 GB/s per carril (~64 GB/s en x16).

---

## Sistemes d'Alimentació i Gestió Tèrmica

1. **Font d'Alimentació (PSU):** Converteix el corrent altern de la xarxa (230 V AC) en corrents continus estables (+12 V, +5 V, +3.3 V DC). L'eficiència es mesura amb la certificació **80 PLUS** (Bronze, Silver, Gold, Platinum, Titanium).
2. **Refrigeració:** La potència de disseny tèrmic (**TDP - Thermal Design Power**) indica la quantitat màxima de calor que el sistema de dissipació ha d'evacuar (refrigeració per aire amb tubs de calor *heatpipes* o refrigeració líquida tot-en-un AIO).
