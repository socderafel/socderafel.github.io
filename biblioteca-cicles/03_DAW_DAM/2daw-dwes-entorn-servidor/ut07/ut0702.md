# 7.2 U7 Class exercises

1. Create a SOAP web service using the database jardineria. The service will allow you to: - List all offices - List office given the city - Create new office - Delete an office
2. Create a SOAP client to consume the webservice created. It's not necessary to create an UI for testing purposes. You can use dummy data.
3. Using PHP code, call a webservice without Auth using GET.
4. Using PHP code, call a webservice without Auth using POST.
5. Using Laravel code, call a webservice using GET and POST (as in 4-5).
