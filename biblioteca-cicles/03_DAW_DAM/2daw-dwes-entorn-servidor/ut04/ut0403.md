# 4.3 U4 Class exercises

1. Using the DB *Jardineria* provided in Aules, create a webpage (index.php) where you can see the name and first surname of all the employees.
2. At the right of every name, add an edit and delete button.
3. Using the database *Jardineria* , create a webpage where you can see all the articles from the *Articulos*table with all the details. Add at the right of every article an "add to the cart" button. When the user click on it, you have to add this article to the cart. The cart webpage will be accessible through a link in this page.
4. The cart webpage has to contain the code and the name of the article and a select to decide how many you need. You have to also add to every article in the cart the possibility to be removed. All these actions have to be kept when you reload the webpage. You need to include a link to come back to the articles webpage.
