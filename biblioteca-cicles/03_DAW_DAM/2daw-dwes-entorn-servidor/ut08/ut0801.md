# 8.1 Hybrid applications

---

Unit 8 Hybrid applications 2nd DAW - DWES

2 DAW - DWES What is an hybrid application?

- Hybrid concept in tech has several meanings.
- When talking about web applications, an hybrid application is the one

that can integrate other applications into their own.

2 DAW - DWES Third Party Applications

- Programs or services that run “out of the box”.
- They run out of our application but are integrated through API’s,

SDK’s or libraries.

- They allow us to access to functionalities, data or resources that we

don’t have in our own app or that improve the user experience.

2 DAW - DWES Third Party Applications

- You can use the work done by other developers to add functionalities

or improve the user experience.

- i.e. Login using Facebook, Google, Github, etc
- Laravel provide developers some integrated packages to deal with 3rd

party apps.

- https://laravel.com/docs/10.x/socialite

2 DAW - DWES Third Party Applications

- Also other developers have created libraries to work with 3rd party

apis

- https://github.com/srmklive/laravel-paypal
- https://github.com/dcblogdev/laravel-dropbox
- As developers, our function is to read, understand and apply what

other developers have already done for us.
