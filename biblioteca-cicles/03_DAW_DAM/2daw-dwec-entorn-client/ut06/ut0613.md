# 6.13 Evaluación RA6.f - Sergio

1. Store Pattern

Es vol crear una miniaplicació que gestione un

tema global (clar/fosc)

compartit entre components, utilitzant un store manual.

storeTheme.js

Crea

storeTheme.js

amb:

Estat reactiu:

theme

(string) → valors possibles:

"light"

o

"dark"

(inicialment

"light"

)

Accions:

toggleTheme()

→ alterna entre

"light"

i

"dark"

setTheme(value)

→ estableix el tema si

value

és

"light"

o

"dark"

(si no, no fa res)

ThemeIndicator.vue

Component que:

Mostra el tema actual amb el text:

Tema actual: LIGHT

o

Tema actual: DARK

Mostra una pista extra segons el tema:

Si és

"light"

:

“Mode lectura”

Si és

"dark"

:

“Mode nocturn”

(Tot el text ha de vindre de l’estat del store.)

ThemeToolbar.vue

Component que conté:

Un botó

“Canviar tema”

→ crida

toggleTheme()

Dos botons:

“Light”

i

“Dark”

→ criden

setTheme("light")

i

setTheme("dark")

El botó del tema actiu ha d’aparéixer

deshabilitat

(disabled)

El component

App.vue

ha d’aplicar una classe al contenidor principal:

class="app light"

si el tema és

"light"

class="app dark"

si el tema és

"dark"
