## De la Guia d'Estil al Sistema de Disseny (*Design System*)

Històricament, les empreses generaven manuals d'identitat corporativa estàtics en PDF que recollien el logotip, la paleta de colors i les tipografies autoritzades. En el món del programari web, això és insuficient.

Un **Sistema de Disseny (*Design System*)** és un ecosistema complet i viu format per principis de disseny, patrons de comportament, llibreries de components visuals (en Figma/Penpot) i el seu reflex exacte en **codi reutilitzable** (components React/Vue/Web Components i variables CSS). Actua com el pont de comunicació únic i indissoluble entre dissenyadors i desenvolupadors frontend.

Exemples famosos de referència: *Material Design* (Google), *Human Interface Guidelines* (Apple), *Carbon Design System* (IBM) o *Atlassian Design System*.

## La Metodologia *Atomic Design* de Brad Frost

Per a construir interfícies escalables, el dissenyador Brad Frost va proposar inspirar-se en la química molecular per a descompondre els components d'una web:

```
 [ Àtoms ] ---> [ Molècules ] ---> [ Organismes ] ---> [ Plantilles ] ---> [ Pàgines ]
```

1. **Àtoms:** Elements bàsics indivisibles (una etiqueta de text, un camp `<input>`, un botó, una icona o una paleta de color).
2. **Molècules:** Grups simples d'àtoms combinats que funcionen com una unitat operativa (un formulari de cerca compost per una etiqueta + camp de text + botó).
3. **Organismes:** Components complexos formats per la unió de molècules i àtoms (la capçalera del lloc web que conté el logotip, el cercador i la barra de navegació).
4. **Plantilles (*Templates*):** Disposició estructural de la pàgina que connecta organismes en una reixeta sense contingut real.
5. **Pàgines:** Instàncies específiques de les plantilles plenes amb continguts, imatges i dades reals del negoci.

## Fitxes de Disseny (*Design Tokens*)

Els **Design Tokens** són les variables atòmiques independents de la plataforma que emmagatzemen les decisions visuals fonamentals: colors, mides de tipografia, espaiats, radis de curvatura i ombres.
S'emmagatzemen en format JSON i es compilen automàticament mitjançant eines com *Style Dictionary* tant per a CSS/SCSS (com variables natives `:root { --color-primary: #1e40af; }`), com per a Android (XML) o iOS (Swift):

```json
{
  "color": {
    "brand": {
      "primary": { "value": "#1e40af" },
      "secondary": { "value": "#f59e0b" }
    }
  },
  "spacing": {
    "sm": { "value": "8px" },
    "md": { "value": "16px" }
  }
}
```
