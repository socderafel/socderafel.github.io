# 8.46 Tarea 18

Continuando con el ejemplo anterior modificar el proyecto para que cargue 3 imágenes distintas en función de la resolución del viewport. ​

​

Tendréis que hacer uso de la segmentación de las media queries para cargar las diferentes imágenes.

<!DOCTYPE html>

<html lang="es">

<head>

<meta charset="UTF-8">

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>Página Responsive con Imágenes Distintas</title>

<style>

/* MÓVIL - Menos de 576px */

body {

margin: 0;

font-family: Arial, sans-serif;

}

header {

background-color: #ff6b6b;

color: white;

padding: 20px;

text-align: center;

font-size: 20px;

}

picture {

display: block;

text-align: center;

}

img {

width: 90%;

max-width: 400px;

display: block;

margin: 15px auto;

}

p {

color: black;

font-size: 16px;

padding: 20px;

text-align: left;

}

/* TABLET - Desde 576px */

@media (min-width: 576px) {

header {

background-color: #4ecdc4;

font-size: 24px;

text-align: left;

}

img {

width: 60%;

max-width: 450px;

}

p {

color: #333;

font-size: 18px;

text-align: center;

}

}

/* DESKTOP - Desde 768px */

@media (min-width: 768px) {

header {

background-color: #95e1d3;

color: #333;

font-size: 28px;

text-align: right;

font-family: Georgia, serif;

}

img {

width: 40%;

max-width: 500px;

}

p {

color: #555;

font-size: 20px;

padding: 30px;

text-align: justify;

font-family: Georgia, serif;

}

}

</style>

</head>

<body>

<header>

Mi Página Web Responsive

</header>

<!-- Elemento picture con 3 imágenes diferentes -->

<picture>

<!-- Desktop: desde 768px -->

<source media="(min-width: 768px)" srcset="Designer_1.jpeg">

<!-- Tablet: desde 576px hasta 767px -->

<source media="(min-width: 576px)" srcset="Designer_2.jpeg">

<!-- Móvil: por defecto (menos de 576px) -->

<img src="Designer_3.jpeg" alt="Imagen responsive">

</picture>

<p>

Este diseño responsive ahora carga 3 imágenes diferentes según

el tamaño de pantalla. En móvil (< 576px) carga imagen-movil.jpg,

en tablet (576px-767px) carga imagen-tablet.jpg, y en desktop

(≥ 768px) carga imagen-desktop.jpg. El navegador solo descarga

la imagen que corresponde a tu pantalla, ahorrando datos.

</p>

</body>

</html>
