## 📌 8.45 Tarea 17

Crear una página web (index.html) que contenga:​

Un encabezado.​

Una imagen.​

Un párrafo. ​

​

Utilizar media queries para ajustar los estilos (tamaño, color, fuente, posición) según el tamaño de la pantalla.​

Las resoluciones para el cambio de estilo serán: 576px y 768px.​

Crear los estilos necesarios que abarquen todas las resoluciones.

Ejemplo clase:

<!DOCTYPE html>

<html lang="es">

<head>

<meta charset="UTF-8">

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>Página Responsive</title>

<style>

/* MÓVIL - Menos de 576px */

body {

margin: 0;

font-family: Arial, sans-serif;

}

header {

background-color: #ff6b6b;

color: white;

padding: 20px;

text-align: center;

font-size: 20px;

}

img {

width: 50%;

max-width: 400px;

display: block;

margin: 15px auto;

}

p {

color: black;

font-size: 16px;

padding: 20px;

text-align: left;

}

/* TABLET - Desde 576px */

@media (min-width: 576px) {

header {

background-color: #4ecdc4;

font-size: 24px;

text-align: left;

}

img {

width: 60%;

max-width: 450px;

}

p {

color: #333;

font-size: 18px;

text-align: center;

}

}

/* DESKTOP - Desde 768px */

@media (min-width: 768px) {

header {

background-color: #95e1d3;

color: #333;

font-size: 28px;

text-align: right;

font-family: Georgia, serif;

}

img {

width: 40%;

max-width: 500px;

}

p {

color: #555;

font-size: 20px;

padding: 30px;

text-align: justify;

font-family: Georgia, serif;

}

}

</style>

</head>

<body>

<header>

Mi Página Web Responsive

</header>

<img src="pajaro_1.jpg" alt="Pájaro">

<p>

Este es un ejemplo simple de diseño responsive. En móvil el fondo

del encabezado es rojo. En tablet (desde 576px) cambia a azul

turquesa. En desktop (desde 768px) cambia a verde claro. Los

tamaños de letra, colores y posiciones también cambian según el

tamaño de la pantalla.

</p>

</body>

</html>

la imagen que corresponde a tu pantalla, ahorrando datos.

## 📌 8.47 Tarea 19

Continuando con el ejemplo anterior modificar el proyecto para que cargue 3 imágenes distintas en función de la resolución del viewport. ​

​

Tendréis que hacer uso de la segmentación de las media queries para cargar las diferentes imágenes.

<!DOCTYPE html>

<html lang="es">

<head>

<meta charset="UTF-8">

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<title>Ejercicio de Unidades de Viewport con Imágenes</title>

<style>

/* Estilos generales */

body {

font-family: Arial, sans-serif;

margin: 0;

padding: 20px;

background-color: #f0f0f0;

}

header {

background-color: #3F51B5; /* Color azul */

color: white;

padding: 10px;

text-align: center;

}

/* Estilo de las secciones */

.box {

margin: 20px 0;

padding: 20px;

color: white;

border-radius: 8px;

}

/* Nueva sección para imágenes responsive */

.box-image {

background-color: #9C27B0; /* Color morado para móvil */

text-align: center;

}

.box-image picture {

display: block;

margin: 20px 0;

}

.box-image img {

max-width: 100%;

height: auto;

border-radius: 8px;

box-shadow: 0 4px 8px rgba(0, 0, 0, 0.3);

}

.image-info {

margin-top: 15px;

font-size: 14px;

font-style: italic;

}

.image-info::before {

content: "Móvil: ";

font-weight: bold;

}

/* Estilo para el cuadro en px */

.box-px {

width: 300px; /* Ancho fijo en píxeles */

height: 100px; /* Alto fijo en píxeles */

background-color: #FF5722; /* Color naranja */

}

/* Estilo para el cuadro en vw */

.box-vw {

width: 50vw; /* Ancho del 50% del viewport */

height: 100px; /* Alto fijo en píxeles */

background-color: #4CAF50; /* Color verde */

}

/* Estilo para el cuadro en vh */

.box-vh {

width: 300px; /* Ancho fijo en píxeles */

height: 50vh; /* Alto del 50% del viewport */

background-color: #FFC107; /* Color amarillo */

}

/* TABLET - Desde 576px */

@media (min-width: 576px) {

.box-image {

background-color: #00BCD4; /* Color cian para tablet */

}

.image-info::before {

content: "Tablet: ";

font-weight: bold;

}

}

/* DESKTOP - Desde 768px */

@media (min-width: 768px) {

.box-image {

background-color: #009688; /* Color verde azulado para desktop */

}

.image-info::before {

content: "Desktop: ";

font-weight: bold;

}

}

</style>

</head>

<body>

<header>

<h1>Ejercicio de Unidades de Viewport</h1>

</header>

<main>

<!-- Sección con imágenes responsive según viewport -->

<section class="box box-image">

<h2>Imágenes Responsive según Viewport</h2>

<picture>

<!-- Desktop: desde 768px - Carga Designer_3.jpeg -->

<source media="(min-width: 768px)" srcset="Designer_3.jpeg">

<!-- Tablet: desde 576px hasta 767px - Carga Designer_2.jpeg -->

<source media="(min-width: 576px)" srcset="Designer_2.jpeg">

<!-- Móvil: por defecto (menos de 576px) - Carga Designer_1.jpeg -->

<img src="Designer_1.jpeg" alt="Imagen responsive según viewport">

</picture>

<p class="image-info">La imagen cambia según el tamaño de tu pantalla</p>

</section>

<section class="box box-px">

<h2>Tamaño en píxeles (px)</h2>

<p>Este cuadro tiene un ancho y alto fijos en píxeles.</p>

</section>

<section class="box box-vw">

<h2>Tamaño en Viewport Width (vw)</h2>

<p>Este cuadro ocupa el 50% del ancho de la ventana del navegador.</p>

</section>

<section class="box box-vh">

<h2>Tamaño en Viewport Height (vh)</h2>

<p>Este cuadro ocupa el 50% de la altura de la ventana del navegador.</p>

</section>

</main>

</body>

</html>
