## El Model de Caixa (*CSS Box Model*)

En el motor de renderització del navegador web, tot element HTML genera una caixa rectangular composta per quatre capes concèntriques:

```
+----------------------------------------------------+
|                      MARGIN                        |
|  +----------------------------------------------+  |
|  |                   BORDER                     |  |
|  |  +----------------------------------------+  |  |
|  |  |                PADDING                 |  |  |
|  |  |  +----------------------------------+  |  |  |
|  |  |  |             CONTENT              |  |  |  |
|  |  |  |       (Amplada x Alçada)         |  |  |  |
|  |  |  +----------------------------------+  |  |  |
|  |  +----------------------------------------+  |  |
|  +----------------------------------------------+  |
+----------------------------------------------------+
```

### La Propietat `box-sizing`
- **`content-box` (valor històric per defecte):** L'amplada (`width`) i alçada (`height`) s'apliquen exclusivament a la caixa de contingut. Si afegim `padding: 20px` i `border: 2px`, la mida total creix cap a l'exterior:
  $$	ext{Amplada Total} = 	ext{width} + 2 	imes 	ext{padding} + 2 	imes 	ext{border}$$
  Això trencava contínuament les maquetacions en afegir vores a un element amb `width: 100%`.
- **`border-box` (estàndard professional):** L'amplada i alçada declarades inclouen el contingut, el farciment i la vora. El contingut s'encongeix interiorment per a mantenir les dimensions exactes prefixades.

```css
/* Resolució universal recomanada per a tots els projectes */
*, *::before, *::after {
  box-sizing: border-box;
}
```

## Esquemes de Posicionament CSS

La propietat `position` controla com s'ubica una caixa en el document:

1. **`static` (per defecte):** L'element segueix el flux natural del document. Les propietats `top`, `right`, `bottom`, `left` i `z-index` no tenen cap efecte.
2. **`relative`:** L'element es desplaça respecte a la seua posició original en el flux sense alliberar el seu espai reservat. Serveix habitualment com a marc de referència per a descendents absoluts.
3. **`absolute`:** S'extreu completament del flux normal (altres elements ocupen el seu lloc). Es posiciona respecte al seu **ancestre posicionat més proper** (amb position diferent de `static`) o respecte a l'arrel del document.
4. **`fixed`:** S'extreu del flux i es posiciona respecte a la finestra del navegador (*viewport*). Es manté immòbil en fer scroll.
5. **`sticky`:** Híbrid entre `relative` i `fixed`. L'element flueix de manera normal fins que arriba a un límit de desplaçament indicat (ex. `top: 0`), moment en què es queda enganxat a la pantalla mentre el seu contenidor pare siga visible.

## Càlcul de l'Especificitat dels Selectors CSS

Quan dues regles CSS competeixen per donar estil al mateix element, el navegador calcula una puntuació de 3 columnes `(A, B, C)`:
- **A (IDs):** Cada selector d'identificador (`#meu-id`) suma `(1, 0, 0)`.
- **B (Classes, Pseudo-classes, Atributs):** `.classe`, `[type="text"]`, `:hover` sumen `(0, 1, 0)`.
- **C (Elements, Pseudo-elements):** `p`, `div`, `h1`, `::before` sumen `(0, 0, 1)`.

> Els estils en línia (`style="..."`) superen qualsevol especificitat regular, i `!important` trenca el sistema de cascada (només s'ha d'usar per a sobreescriure estils de tercers impossibles d'alterar d'una altra manera).
