## La Importància de la Semàntica en la Web Moderna

En les primeres versions d'HTML, les pàgines web es construïen encadenant desenes d'etiquetes genèriques sense significat (`<div id="header">`, `<div class="menu">`, `<div class="content">`), una pràctica coneguda despectivament com *"divitis"*. Els motors de cerca i les tecnologies d'assistència (com els lectors de pantalla NVDA o VoiceOver) eren incapaços de discernir quin contingut era principal, quin era accessori i on es trobaven els menús de navegació.

L'arribada d'**HTML5** va introduir un conjunt ric d'etiquetes semàntiques que expressen de manera inequívoca la funció de cada bloc dins del document.

```
+------------------------------------------------------------------+
| <header> (Logotip, títol del portal, formulari de cerca)          |
+------------------------------------------------------------------+
| <nav> (Llistat d'enllaços de navegació principal)                |
+------------------------------------------------------------------+
| <main>                                                           |
|   +------------------------------------+-----------------------+ |
|   | <section> / <article>              | <aside>               | |
|   | (Contingut principal autònom,      | (Barra lateral,       | |
|   |  titulars <h1>-<h6>, paràgrafs)    |  contingut secundari, | |
|   |                                    |  publicitat, enllaços)| |
|   +------------------------------------+-----------------------+ |
+------------------------------------------------------------------+
| <footer> (Drets d'autor, avís legal, contacte, xarxes socials)    |
+------------------------------------------------------------------+
```

---

## Catàleg d'Elements Estructurals Fonamentals

1. **`<main>`:** Representa el contingut central i exclusiu del document. **Només hi pot haver un element `<main>` visible per pàgina**, i no ha de contindre blocs repetitius que es repliquen a tot el lloc web (com menús o peus).
2. **`<header>`:** Capçalera introductòria per a la pàgina o per a una secció concreta. Sol contindre logotips, títols jeràrquics i metadades d'autoria.
3. **`<nav>`:** Agrupa blocs d'enllaços de navegació fonamentals (menú principal, paginació o taula de continguts). No és necessari tancar qualsevol enllaç aïllat dins d'un `<nav>`.
4. **`<article>`:** Peça de contingut completament independent que té sentit per si mateixa fora del context del lloc (un article de premsa, una ressenya, un comentari de fòrum o una targeta de producte).
5. **`<section>`:** Secció genèrica temàtica que agrupa continguts relacionats al voltant d'un mateix objectiu. Cada `<section>` hauria de contindre el seu propi encapçalament (`<h2>` a `<h6>`).
6. **`<aside>`:** Contingut relacionat tangencialment amb el contingut principal que podria ser eliminat sense que l'article perda el seu significat essencial (barres laterals, glossaris, bibliografies o anuncis).
7. **`<footer>`:** Peu de pàgina que conté informació d'autoria, enllaços legals, polítiques de privadesa i llicències.

---

## Bones Pràctiques i Accessibilitat Nativa

L'ús d'etiquetes semàntiques proporciona automàticament punts de referència (*Landmarks*) per als lectors de pantalla, permetent que persones amb ceguesa salten directament al contingut principal (`<main>`) o al menú (`<nav>`) prement una sola tecla ràpida.
