## Variables Natives CSS (*Custom Properties*)

Abans de l'arribada de les propietats personalitzades natives a CSS, era obligatori utilitzar preprocessadors com Sass per a declarar variables (`$color-primary`). No obstant això, les variables de Sass es compilen en temps de construcció i són estàtiques.

Les **variables natives de CSS (*Custom Properties*)** viuen en el DOM en temps d'execució:
- S'hereten pel sistema de cascada habitual.
- Poden canviar dinàmicament mitjançant JavaScript o consultes de mitjans (@media).
- Permeten canviar el tema complet d'un portal a mode fosc (*Dark Mode*) modificant només dues línies.

### Sintaxi de Declaració i Ús
Comencen obligatòriament amb dos guions (`--`):

```css
:root {
  /* Variables globals definides a la pseudoclasse :root */
  --color-primari: #0284c7;
  --color-fons: #ffffff;
  --color-text: #0f172a;
  --radi-vora: 8px;
  --espaiat-base: 1rem;
}

/* Aplicació del tema fosc automàtic amb preferència de sistema */
@media (prefers-color-scheme: dark) {
  :root {
    --color-fons: #0f172a;
    --color-text: #f8fafc;
  }
}

.botó-acció {
  background-color: var(--color-primari);
  color: var(--color-fons);
  border-radius: var(--radi-vora);
  padding: calc(var(--espaiat-base) * 0.75) var(--espaiat-base);
}
```

## Funcions Matemàtiques Modernes: `calc()`, `min()`, `max()` i `clamp()`

CSS3 proporciona eines matemàtiques potents per a evitar l'ús de codi JavaScript per a càlculs d'alçades o mides:

1. **`calc()`:** Permet combinar unitats incompatibles (com percentatges i píxels):
   ```css
   width: calc(100% - 40px);
   ```
2. **`min()` i `max()`:** Retornen el valor més petit o més gran d'un conjunt d'expressions:
   ```css
   width: min(100%, 1200px); /* Mesura el 100% però mai supera 1200px */
   ```
3. **`clamp(MIN, PREFERIT, MAX)`:** Estableix un valor que escala fluidament entre dos límits:
   ```css
   font-size: clamp(1rem, 2vw + 0.5rem, 2.25rem);
   ```

## Estils d'Impressió amb `@media print`

Un bon disseny web ha de preveure com s'imprimirà el document en paper (com una factura, un rebut o un expedient d'aprenentatge):

```css
@media print {
  /* Ocultació de controls no imprimibles */
  nav, footer, .botons-xarxes, .banner-cookies {
    display: none !important;
  }
  
  /* Forçar text negre pur i estalviar tinta */
  body {
    color: #000;
    background: #fff;
    font-size: 12pt;
  }
  
  /* Mostrar l'URL de destí dels enllaços entre parèntesis al paper */
  a[href]::after {
    content: " (" attr(href) ")";
  }
}
```
