## El Poder de CSS Grid Layout

Mentre que Flexbox va néixer per a alinear components en una sola dimensió, **CSS Grid Layout** és el primer sistema natiu de maquetació dissenyat específicament per a gestionar **dues dimensions simultàniament (files i columnes)**. Permet maquetar estructures completes de portals web de manera declarativa, expressiva i sense necessitat de niar desenes de contenidors auxiliars.

---

## Definició de Reixetes i la Unitat Fracció (`fr`)

Una reixeta s'activa amb `display: grid;`. La nova unitat `fr` (*fracció*) representa una part proporcional de l'espai lliure disponible al contenidor:

```css
.portal-layout {
  display: grid;
  /* 3 columnes: una barra lateral fixa de 260px i dues columnes que es reparteixen l'espai restant (1 part i 2 parts) */
  grid-template-columns: 260px 1fr 2fr;
  grid-template-rows: auto 1fr auto;
  gap: 24px; /* Separació neta entre cel·les */
}
```

### Funcions Pràctiques: `repeat()` i `minmax()`
```css
/* Reixeta de targetes auto-ajustables responsive sense necessitat de media queries! */
.targetes-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}
```
- `minmax(280px, 1fr)`: Cada targeta mesurarà com a mínim 280px, però creixerà fins a 1fr si hi ha espai.
- `auto-fit`: Encaixa tantes columnes com caben a l'amplada de la pantalla.

---

## Àrees Nominades de Reixeta (*Grid Template Areas*)

Una de les tècniques més elegants de CSS Grid és el mapa visual d'àrees mitjançant cadenes de text:

```css
.app-shell {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 70px 1fr 60px;
  grid-template-areas:
    "capcalera  capcalera"
    "sidebar    contingut"
    "sidebar    peu";
  min-height: 100vh;
}

header { grid-area: capcalera; }
aside  { grid-area: sidebar; }
main   { grid-area: contingut; }
footer { grid-area: peu; }
```

En canviar de dispositiu mòbil a escriptori, només cal alterar la directiva `grid-template-areas` dins d'un media query, sense moure ni una sola línia d'HTML!
