## Marc Curricular i Alineació Professional

Aquest mòdul professional capacita en la planificació, maquetació, estilització, dinamització i avaluació d'interfícies web accessibles, adaptatives i d'alt rendiment, seguint les directrius del **Reial Decret 686/2010** i el currículum de la Comunitat Valenciana:
- **Codi del mòdul:** MP0615 (DAW).
- **Hores lectives de referència:** 140 hores.
- **Perfil Professional:** Dissenyador d'interfícies web (UI Designer), dissenyador d'experiència d'usuari junior (UX), maquetador web avançat, desenvolupador frontend especialista en HTML5/CSS3, accessibilitat digital i optimització de rendiment web (Core Web Vitals).

## Navegació Ràpida per Unitats de Treball

### [UT 01: Planificació i Disseny d'Interfícies Web](./ut01/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA1`
- Teoria del color: models RGB/HSL, harmonies cromàtiques, psicologia i patrons de lectura visuals en F i Z.
- Experiència d'usuari (UX) vs disseny d'interfícies (UI): lleis de la Gestalt, Llei de Fitts, Llei de Hick i Llei de Miller.
- Arquitectura de la informació: tècniques de Card Sorting, mapes del lloc (*sitemaps*) i diagrames de flux (*user flows*).
- Prototipatge progressiu: esbossos en paper (*sketches*), esquemes Lo-Fi (*wireframes*), maquetes Hi-Fi (*mockups*) i eines Figma/Penpot.
- Guies d'estil corporatives, sistemes de disseny (*Design Systems*) i metodologia *Atomic Design* de Brad Frost.

### [UT 02: Maquetació Avançada amb HTML5 Semàntic i CSS3](./ut02/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA2`
- Estructura semàntica: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` i punts de referència.
- El Model de Caixa (*Box Model*): `box-sizing: border-box`, flux normal, esquemes de posicionament (`static`, `relative`, `absolute`, `fixed`, `sticky`) i especificitat CSS.
- Maquetació unidimensional moderna amb CSS Flexible Box (Flexbox): eixos principal/creuat, alineació biaxial i elements flexibles.
- Maquetació bidimensional amb CSS Grid Layout: definició de columnes/files, unitat `fr`, àrees de plantilla (`grid-template-areas`) i `gap`.
- Variables natives CSS (*Custom Properties*), disseny fluid amb `clamp()`, `min()`, `max()` i estils d'impressió (`@media print`).

### [UT 03: Disseny Web Adaptatiu, Preprocessadors i Frameworks](./ut03/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA3`
- La triada del Responsive Web Design (RWD): reixetes fluides, mitjans flexibles, metaetiqueta viewport i estratègia Mobile First.
- Consultes de mitjans (@media queries), característiques de mitjans, punts de ruptura estàndards i sintaxi moderna de rangs (nivell 4).
- Preprocessadors d'estil: arquitectura modular amb Sass/SCSS, variables, niat amb `&`, mixins parametritzats, parcials i `@use`.
- Frameworks CSS basats en components: Bootstrap 5, reixeta responsive de 12 columnes, utilitats i components interactius.
- Frameworks utilitaris moderns: Tailwind CSS, enfocament *Utility-First*, compilador Just-in-Time (JIT) i variants d'estat/breakpoint.

### [UT 04: Integració d'Elements Multimèdia i Animacions Web](./ut04/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA4`
- Formats d'imatge: JPEG, PNG, WebP i AVIF; imatges responsives amb `srcset`, `sizes` i l'element semàntic `<picture>`.
- Gràfics vectorials escalables (SVG): estructura XML, sistema de coordenades `viewBox`, iconografia neta i estilització amb CSS.
- Àudio i vídeo natiu amb HTML5: `<video>`, `<audio>`, atributs de reproducció, còdecs (H.264, VP9, AV1) i subtítols accessibles WebVTT.
- Transicions i transformacions 2D/3D en CSS3: propietats `transition`, funcions de temporització cúbica, transformacions espacials i perspectiva.
- Animacions avançades amb fotogrames clau (@keyframes), `animation-fill-mode` i disseny de microinteraccions UI respectant `prefers-reduced-motion`.

### [UT 05: Accessibilitat Web (WAI-ARIA i WCAG)](./ut05/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA5`
- Fonaments de l'accessibilitat universal, diversitat funcional, marc normatiu legal (Reial Decret 1112/2018 i norma EN 301 549).
- Els 4 principis WCAG (POUR: Perceptible, Operable, Comprensible, Robust) i nivells de conformitat (A, AA, AAA).
- Accessibilitat pràctica: ràtios de contrast cromàtic (4.5:1 / 3:1), redacció precisa d'atributs `alt`, navegació per teclat i focus visible (`:focus-visible`).
- La suite WAI-ARIA: primera regla d'ús d'ARIA, rols semàntics (`role="dialog"`), estats (`aria-expanded`) i regions vives (`aria-live`).
- Metodologia d'avaluació WCAG-EM, validació automatitzada (axe DevTools, WAVE, Lighthouse) i auditories manuals amb lectors de pantalla (NVDA, VoiceOver).

### [UT 06: Usabilitat, Rendiment Web i Proves entre Navegadors](./ut06/index.md)
`2n DAW · 5 apartats · 19 reptes (+475 XP) · RA6`
- Usabilitat segons ISO 9241-11, les 10 heurístiques d'usabilitat de Jakob Nielsen i proves amb usuaris mitjançant protocol Think-Aloud.
- Rendiment web (WPO) i mètriques Google Core Web Vitals: LCP (Largest Contentful Paint), INP (Interaction to Next Paint) i CLS (Cumulative Layout Shift).
- Optimització del camí crític de renderitzat (CRP): càrrega no bloquejant amb `defer` i `async`, minificació, compressió Brotli i precarregadors.
- Proves de compatibilitat entre navegadors (Cross-Browser Testing): motors Blink, Gecko i WebKit, base de dades Can I Use, Autoprefixer i polifills.
- Eines de depuració en navegadors: panells Elements, Network (cascada de peticions i TTFB), Performance i auditories de rendiment amb DevTools.

### Metodologia Didàctica i Avaluació Formativa

El mòdul està dissenyat seguint els principis d'avaluació contínua, aprenentatge basat en la pràctica (*Learning by Doing*) i ludificació competencial:
- **Reptes Interactius Immediats:** Cada apartat conté 3 reptes de reflexió tècnica (+25 XP cadascun) que ofereixen retroacció explicativa instantània per a consolidar conceptes.
- **Reptes Globals de Síntesi:** Cada unitat conclou amb 4 reptes avançats de presa de decisions arquitecturals (+100 XP totals per unitat).
- **Seguiment i Informes Aules:** Tots els documents incorporen un panell de progrés viu i el generador automàtic d'informes d'evidències oficials per a la plataforma docent Aules de la Generalitat Valenciana.
