## El Camí Crític de Renderitzat (*Critical Rendering Path* - CRP)

El **camí crític de renderitzat** és la seqüència de passos que el navegador executa des de rebre el primer byte HTML fins a pintar els píxels a la pantalla:

```
 [ HTML ] ---> Construcció del DOM (Document Object Model)
                     |
                     v
 [ CSS ]  ---> Construcció del CSSOM (CSS Object Model)
                     |
                     +---> [ RENDER TREE ] (Arbre de Renderitzat)
                                 |
                                 v
                            [ LAYOUT ] (Càlcul geomètric de posicions)
                                 |
                                 v
                            [ PAINT ] (Pintat de píxels a la GPU)
```

Per defecte, tant els fulls d'estil CSS com els scripts JavaScript són **recursos que bloquegen el renderitzat (*render-blocking*)**. Si el navegador troba una etiqueta `<script src="app.js">` al `<head>`, deté completament la construcció del DOM fins a descarregar i executar eix script.

---

## Càrrega No Bloquejant de Scripts: `async` vs `defer`

```html
<!-- Bloqueig tradicional (EVITAR a la capçalera!) -->
<script src="script.js"></script>

<!-- ASYNC: Descarrega en paral·lel i s'executa immediatament en arribar (interrompent el DOM si encara s'està construint). Ordre d'execució impredictible. Ideal per a analítica independent (Google Analytics). -->
<script async src="analytics.js"></script>

<!-- DEFER: Descarrega en paral·lel, NO bloqueja el DOM, i s'executa estrictament en l'ordre declarat un cop el DOM està completament llest. RECOMANAT per a la lògica de l'aplicació. -->
<script defer src="app.js"></script>
```

## Tècniques Clau de Compressió i Optimització

1. **Minificació:** Eliminació d'espais en blanc, salts de línia i comentaris innecessaris del codi CSS i JavaScript, reduint la mida entre un 20% i un 40% (ex. `styles.min.css`).
2. **Compressió Brotli (*br*) i GZIP:** Motors de compressió al servidor web (Nginx o Apache). Brotli aconsegueix reduccions fins a un 25% millors que GZIP en arxius de text web.
3. **Pistes de Recursos (*Resource Hints*):** Instruccions al navegador sobre connexions futures:
   - `<link rel="preconnect" href="https://fonts.googleapis.com">`: Resol el DNS i estableix l'encaixada TLS amb antelació.
   - `<link rel="preload" href="hero.webp" as="image">`: Descarrega amb màxima prioritat la imatge principal LCP.
