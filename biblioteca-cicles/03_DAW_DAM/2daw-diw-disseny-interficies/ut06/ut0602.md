## La Importància del Rendiment Web (*WPO*)

L'**Optimització del Rendiment Web (*Web Performance Optimization* - WPO)** estudia i redueix el temps que tarda una interfície a fer-se visible i interactiva per a l'usuari. Nombrosos estudis de la indústria demostren que:
- Més del 53% dels usuaris mòbils abandonen un portal web si tarda més de **3 segons** a carregar.
- Cada segon de retard en una botiga en línia redueix les conversions de venda en un 7%.
- Des de 2021, Google utilitza la velocitat de càrrega com un factor decisiu de posicionament en el seu motor de cerca (*Search Engine Ranking*).

## Les Tres Mètriques Clau: Google Core Web Vitals

Google sintetitza l'experiència tècnica d'usuari en tres indicadors concrets (*Core Web Vitals*):

```
+-------------------------------------------------------------------------+
|                       GOOGLE CORE WEB VITALS (2024-2026)                |
+----------------------------+-----------------------+--------------------+
| LCP: Largest Contentful    | INP: Interaction to   | CLS: Cumulative    |
| Paint (Velocitat Càrrega)  | Next Paint (Resposta) | Layout Shift       |
|                            |                       | (Estabilitat)      |
+----------------------------+-----------------------+--------------------+
| Mesura el temps fins que   | Mesura la latència de | Mesura si els      |
| el bloc visual més gran de | resposta davant qualsevol| elements es mouen |
| la pantalla s'acaba de     | clic o interacció     | sobtadament durant |
| dibuixar                   | durant tota la visita | la càrrega         |
| Òptim: <= 2.5 segons       | Òptim: <= 200 ms      | Òptim: <= 0.1      |
+----------------------------+-----------------------+--------------------+
```

### 1. LCP (*Largest Contentful Paint*)
Informa quan s'ha completat la renderització del bloc de contingut més important visible (com la imatge principal d'un article o un titular gegant).
- **Objectiu:** Menys de **2.5 segons**.
- **Solució:** Precarregar la imatge LCP amb `<link rel="preload" as="image">` i no aplicar-li mai `loading="lazy"` a eixa imatge específica.

### 2. INP (*Interaction to Next Paint*)
Substitueix la mètrica antiga FID. Avalua la fluïdesa general de l'aplicació, mesurant el temps que passa des que l'usuari fa clic o prem una tecla fins que la interfície es redibuixa mostrant el resultat de l'acció.
- **Objectiu:** Menys de **200 mil·lisegons**.
- **Solució:** Evitar tasques pesades de JavaScript de llarga durada (*Long Tasks* de més de 50ms) que bloquegen el fil principal (*Main Thread*).

### 3. CLS (*Cumulative Layout Shift*)
Mesura l'estabilitat visual. Quan els elements es mouen d'imprevist a mesura que es descarreguen imatges o anuncis, l'usuari pot acabar fent clic per error en un botó incorrecte.
- **Objectiu:** Puntuació inferior a **0.1**.
- **Solució:** Fixar sempre atributs `width` i `height` a totes les imatges o utilitzar la propietat CSS `aspect-ratio: 16 / 9;`.
