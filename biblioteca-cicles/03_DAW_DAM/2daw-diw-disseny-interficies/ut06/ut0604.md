## El Repte de la Fragmentació de Motors de Renderització

El mercat de navegadors d'Internet està repartit entre tres grans motors de renderització que interpreten l'HTML i el CSS de maneres lleugerament diferents:

1. **Blink:** Motor de Google Chrome, Microsoft Edge, Brave, Opera i la majoria de navegadors Android.
2. **Gecko:** Motor independent de codi obert de Mozilla Firefox.
3. **WebKit:** Motor d'Apple Safari (que governa obligatòriament **tots els navegadors d'iOS/iPadOS**, inclosos Chrome i Firefox en iPhone per imposició del sistema operatiu d'Apple).

Garantir que una interfície funcione i es veja impecable en tots ells rep el nom de **Cross-Browser Testing**.

## Eines de Referència: *Can I Use* i *Autoprefixer*

Abans d'utilitzar una propietat moderna de CSS (com `subgrid`, `backdrop-filter` o funcions trigonomètriques), és obligatori consultar la base de dades comunitària **Can I Use (*caniuse.com*)**, que detalla el percentatge de suport global i les versions de navegadors compatibles.

### Automatització de Prefixos de Fabricants
Històricament, calia escriure prefixos manuals per a cada motor (`-webkit-`, `-moz-`, `-ms-`). En l'actualitat, s'utilitzen eines automatitzades com **PostCSS** i **Autoprefixer**, que llegeixen la configuració de **Browserslist** (`package.json`) i injecten exclusivament els prefixos estrictament necessaris en el procés de build.

---

## Polifills (*Polyfills*) i Estratègies de Resiliència

Un **polyfill** és un fragment de codi JavaScript que emula i reprodueix una funcionalitat moderna d'un estàndard web en navegadors antics que no la suporten de manera nativa (per exemple, donar suport a l'API `IntersectionObserver` o a l'objecte `fetch`).

### Consultes de Suport Natiu CSS: `@supports`
Permet detectar mitjançant codi CSS si el navegador del client comprèn una propietat determinada abans d'aplicar-la:

```css
/* Estil bàsic de reserva */
.targeta-vidre {
  background-color: rgba(255, 255, 255, 0.9);
}

/* Si el navegador suporta efecte de vidre translúcid */
@supports (backdrop-filter: blur(10px)) {
  .targeta-vidre {
    background-color: rgba(255, 255, 255, 0.5);
    backdrop-filter: blur(10px);
  }
}
```
