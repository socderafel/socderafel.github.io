## La Caixa d'Eines del Desenvolupador Frontend

Les eines de desenvolupament integrades en els navegadors (**Chrome DevTools**, **Firefox Developer Tools**, **Safari Web Inspector**) constitueixen el taller de diagnòstic diari de qualsevol dissenyador i desenvolupador d'interfícies web. S'obrin prement la tecla **F12** o amb **Ctrl + Maj + I**.

---

## Panells Principals i el seu Ús en Disseny Web

### 1. Panell Elements (DOM i Estils)
- Permet inspeccionar i editar en viu el codi HTML i els estils CSS calculats.
- Mostra la representació gràfica interactiva del **Box Model** (farciment, vores, marges).
- Inclou eines de depuració per a **Flexbox** i **CSS Grid** (dibuixant les línies de reixeta i fletxes direccionals sobre la pantalla).
- Mode dispositiu (*Device Mode*): Simula resolucions de telèfons intel·ligents, tauletes, orientació i limitació d'amplada de banda mòbil (*Network Throttling* a 3G/4G).

### 2. Panell Network (Xarxa i Cascada *Waterfall*)
- Registra totes les peticions HTTP/HTTPS realitzades per la pàgina (documents, fulls d'estil, scripts, imatges i tipografies).
- Analitza el diagrama de cascada (*waterfall*): temps de resolució DNS, connexió TCP, espera del primer byte (**TTFB - Time to First Byte**) i temps de descàrrega.
- Permet filtrar per tipus de recurs i mesurar el pes total transferit amb o sense memòria cau (*Disable cache*).

### 3. Panell Performance (Rendiment Gràfic)
- Grava un perfil d'execució complet mentre l'usuari interacciona o fa scroll.
- Detecta caigudes de taxa de fotogrames per sota de 60 fps (*jank*) i identifica les tasques llargues de JavaScript que bloquegen el fil principal.

### 4. Panell Audits / Lighthouse
- Executa una auditoria integral del lloc web, atorgant una puntuació de 0 a 100 en quatre categories fonamentals: **Rendiment (*Performance*)**, **Accessibilitat**, **Bones Pràctiques** i **SEO**, oferint un informe exhaustiu de recomanacions de millora accionables.
