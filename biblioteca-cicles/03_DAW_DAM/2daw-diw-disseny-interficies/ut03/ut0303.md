## Què és Sass i la Sintaxi SCSS

A mesura que un projecte web creix fins a assolir desenes de milers de línies d'estil, mantindre un únic fitxer `styles.css` esdevé una tasca impossible, plena de duplicitat de codi i errades de manteniment.
**Sass (*Syntactically Awesome Style Sheets*)** és un metallenguatge de fulls d'estil que afegeix característiques pròpies dels llenguatges de programació (variables, niat de regles, mixins, funcions matemàtiques, condicionals i bucles) que es compilen en CSS estàndard natiu per al navegador.

La sintaxi universal és **SCSS (*Sassy CSS*)**, que utilitza claus `{}` i punt i coma `;`, sent un superset 100% compatible amb la sintaxi estàndard de CSS.

## Característiques Fonamentals de SCSS

### 1. Variables (`$variable`)
```scss
$color-primari: #0284c7;
$espaiat-base: 1.5rem;

.alerta {
  background-color: lighten($color-primari, 20%);
  padding: $espaiat-base;
}
```

### 2. Niat (*Nesting*) i el Selector Pare (`&`)
```scss
.targeta {
  background: white;
  border-radius: 8px;

  /* Aplica a .targeta__titol */
  &__titol {
    font-size: 1.25rem;
  }

  /* Aplica a .targeta:hover */
  &:hover {
    box-shadow: 0 10px 15px rgba(0,0,0,0.1);
  }
}
```

### 3. Mixins (`@mixin` i `@include`)
```scss
@mixin flex-centrat($direccio: row) {
  display: flex;
  flex-direction: $direccio;
  justify-content: center;
  align-items: center;
}

.panell {
  @include flex-centrat(column);
}
```

### 4. Arquitectura Modular 7-1 i el Nou Sistema `@use`
El model professional d'arquitectura 7-1 divideix el projecte en 7 carpetes (`base/`, `components/`, `layout/`, `pages/`, `themes/`, `abstracts/`, `vendors/`) agrupades en un fitxer `main.scss`.
Amb el nou sistema modular de Sass, la directiva obsoleta `@import` ha estat substituïda per **`@use`**, que aïlla els espais de noms (*namespaces*) evitant col·lisions globals:

```scss
@use 'abstracts/variables' as vars;
@use 'abstracts/mixins' as mix;

.boto {
  background-color: vars.$color-primari;
  @include mix.flex-centrat;
}
```
