## Sintaxi i Tipus de Consultes de Mitjans (@media)

Les **consultes de mitjans** permeten aplicar blocs de regles CSS de manera condicionada a les característiques físiques del client:

```css
@media [TIPUS_MITJÀ] and (CARACTERÍSTICA_CONDICIÓ) {
  /* Regles CSS específiques que només s'executen quan es compleix la condició */
}
```

### Tipus de Mitjans (*Media Types*)
- `all`: Apte per a tots els dispositius (per defecte).
- `screen`: Pantalles d'ordinador, telèfons, tauletes i televisors.
- `print`: Documents dirigits a vista prèvia d'impressió o paper imprès.

---

## Punts de Ruptura (*Breakpoints*) Estàndards de la Indústria

En comptes d'inventar punts de ruptura arbitraris per a cada model específic de telèfon (cosa inassumible atesa la immensa fragmentació del mercat Android/iOS), la comunitat s'ha alineat al voltant de rangs comuns basats en categories de dispositius:

```css
/* 1. Mòbils petits i mitjans: Estils base universals fora de qualsevol media query */
.columna {
  width: 100%;
}

/* 2. Mòbils grans / Tauletes petites en vertical (sm): a partir de 640px */
@media (min-width: 640px) {
  .columna {
    width: 50%;
  }
}

/* 3. Tauletes en horitzontal / Portàtils petits (md): a partir de 768px */
@media (min-width: 768px) {
  .navbar-menu {
    display: flex;
  }
}

/* 4. Pantalles d'escriptori estàndard (lg): a partir de 1024px */
@media (min-width: 1024px) {
  .portal-grid {
    grid-template-columns: repeat(4, 1fr);
  }
}

/* 5. Monitors grans d'alta resolució (xl): a partir de 1280px */
@media (min-width: 1280px) {
  .container {
    max-width: 1200px;
    margin-inline: auto;
  }
}
```

## Nova Sintaxi de Rang de CSS Media Queries Level 4

En navegadors moderns, s'admet una sintaxi matemàtica molt més intuïtiva basada en operadors de comparació (`<`, `<=`, `>`, `>=`):

```css
/* Sintaxi clàssica */
@media (min-width: 768px) and (max-width: 1024px) { ... }

/* Nova sintaxi neta de nivell 4 */
@media (768px <= width <= 1024px) { ... }
```
