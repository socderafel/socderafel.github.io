## El Paradigma de Bootstrap

Creat originàriament per Twitter l'any 2011, **Bootstrap** és el framework de disseny web més utilitzat del món per al prototipatge i desenvolupament ràpid d'interfícies. La seua versió actual (Bootstrap 5) va eliminar completament la dependència de la llibreria jQuery, adoptant JavaScript natiu pur (Vanilla JS), suport complet per a CSS Grid, variables natives CSS i iconografia SVG oficial.

---

## El Sistema de Reixeta de 12 Columnes (*12-Column Grid*)

El nucli operatiu de Bootstrap és la seua reixeta responsive, basada en tres nivells jeràrquics obligatoris:
1. **Contenidor (`.container` o `.container-fluid`):** Centra la pàgina i aporta farciments laterals.
2. **Fila (`.row`):** Agrupa horitzontalment les columnes i contraresta els farciments amb marges negatius.
3. **Columnes (`.col-*`):** Sumen sempre un total de **12 unitats** per fila:

```html
<div class="container">
  <div class="row">
    <!-- En mòbil ocupa les 12 columnes (100%), en escriptori (md) ocupa 4 columnes (33.3%) -->
    <div class="col-12 col-md-4">
      <div class="card p-3 shadow-sm">Targeta 1</div>
    </div>
    <div class="col-12 col-md-4">
      <div class="card p-3 shadow-sm">Targeta 2</div>
    </div>
    <div class="col-12 col-md-4">
      <div class="card p-3 shadow-sm">Targeta 3</div>
    </div>
  </div>
</div>
```

---

## Catàleg de Components Predissenyats

Bootstrap proporciona una àmplia col·lecció d'elements d'interfície llestos per a utilitzar:
- **Navegació:** Barres superiors responsives (`.navbar`) amb menú desplegable tipus hamburguesa automàtic en mòbils (`.navbar-toggler`).
- **Targetes (`.card`):** Contenidors elegants per a imatge, títol, descripció i botons d'acció.
- **Finestres Modals (`.modal`):** Diàlegs superposats per a confirmacions o formularis emergents.
- **Alertes i Insígnies:** Missatges contextuals semàntics (`.alert-success`, `.alert-danger`, `.badge-warning`).
