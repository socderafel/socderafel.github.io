## La Triada del Responsive Web Design (RWD)

L'any 2010, Ethan Marcotte va publicar l'article fundador del **Responsive Web Design**, sintetitzant l'adaptabilitat web en tres pilars tècnics inseparables:

1. **Reixetes Fluides (*Fluid Grids*):** Abandonar l'ús de mides fixes en píxels (`width: 960px`) en favor de percentatges o fraccions proporcionals (`width: 100%`, `max-width: 1200px`, unitats `fr`).
2. **Imatges i Mitjans Flexibles (*Flexible Media*):** Assegurar que els elements multimèdia mai desborden el seu contenidor pare:
   ```css
   img, picture, video, canvas, svg {
     max-width: 100%;
     height: auto;
     display: block;
   }
   ```
3. **Consultes de Mitjans (*Media Queries*):** Regles condicionals que apliquen diferents estils segons la resolució, orientació o capacitats del dispositiu de l'usuari.

## La Metaetiqueta Viewport

Els primers navegadors mòbils (com Mobile Safari en el primer iPhone) tenien pantalles de 320 píxels d'amplada, mentre que les webs estaven dissenyades per a monitors de 1024 píxels. Per a permetre navegar, els enginyers van crear un **viewport virtual** de 980 píxels sobre el qual renderitzaven la pàgina i després l'allunyaven amb un zoom general.

Per a indicar al navegador mòbil que la nostra aplicació està expressament dissenyada per a adaptar-se a qualsevol pantalla, és imprescindible afegir a l'etiqueta `<head>`:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
- `width=device-width`: Iguala l'amplada de la finestra visual als píxels CSS reals del maquinari del dispositiu.
- `initial-scale=1.0`: Estableix una relació de zoom inicial de l'100% (sense allunyament artificial).

---

## Filosofia Mobile First vs Desktop First

- **Desktop First (enfocament antic):** Es dissenyava primer per a pantalles gegants de 1920px amb centenars d'elements, i després s'utilitzaven regles `@media (max-width: 768px)` per a anar retallant, ocultant o reordenant elements a mesura que es baixava cap a mòbil. Genera codi feixuc i redundància d'estils sobreescrits.
- **Mobile First (estàndard professional):** Es dissenya primer per a la pantalla més restrictiva (mòbil), prioritzant el contingut essencial i la màxima velocitat de càrrega. Els estils base s'escriuen sense cap media query. Posteriorment, s'afegeixen consultes `@media (min-width: ...)` per a anar aprofitant progressivament l'espai addicional de tauletes i escriptoris (*Progressive Enhancement*).
