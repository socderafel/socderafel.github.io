## Què és un Gràfic SVG?

A diferència de les imatges de mapa de bits (JPEG, PNG), que defineixen una matriu fixa de píxels de color que es pixelen i perden nitidesa en fer zoom, un fitxer **SVG (*Scalable Vector Graphics*)** és un document de text basat en la gramàtica **XML**.
Defineix formes geomètriques mitjançant fórmules matemàtiques (punts, línies, corbes de Bézier, polígons i cercles). Com a resultat:
- Es renderitza amb **nitidesa infinita** a qualsevol mida o densitat de píxels (pantalles Retina/4K/8K).
- El seu pes és minúscul (habitualment entre 500 bytes i 5 KB).
- Pot ser comprimit amb GZIP/Brotli com qualsevol text.

---

## Estructura XML d'un Document SVG

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" width="48" height="48">
  <!-- Un cercle central -->
  <circle cx="12" cy="12" r="10" fill="#0284c7" />
  <!-- Un camí vectorial (path) per a dibuixar una icona d'acció -->
  <path d="M9 12l2 2 4-4" stroke="#ffffff" stroke-width="2" stroke-linecap="round" fill="none" />
</svg>
```

### L'Atribut `viewBox`
Té 4 paràmetres: `viewBox="min-x min-y amplada alçada"`:
Estableix la finestra virtual sobre la qual es projecten els elements. Si canviem l'amplada de l'SVG amb CSS a `width: 200px;`, tot el contingut interior s'escala proporcionalment de forma automàtica.

---

## Estilització d'SVG Integrat (*Inline SVG*) amb CSS

Quan un gràfic SVG s'incrusta directament al codi HTML (sense usar una etiqueta `<img>` externa), les seues formes passen a formar part del **DOM del navegador**. Això permet manipular els seus estils i animar-lo directament amb CSS:

```css
/* Canvi de color d'una icona SVG en passar el ratolí */
.icona-svg path {
  fill: #64748b;
  transition: fill 0.3s ease;
}

.botó:hover .icona-svg path {
  fill: #0284c7;
}

/* Animació de dibuixat d'un camí amb stroke-dashoffset */
.cami-animat {
  stroke-dasharray: 500;
  stroke-dashoffset: 500;
  animation: dibuixar 2s forwards;
}

@keyframes dibuixar {
  to { stroke-dashoffset: 0; }
}
```
