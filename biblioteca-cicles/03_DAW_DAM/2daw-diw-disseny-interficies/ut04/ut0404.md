## Transicions en CSS3

Una **transició** permet que el canvi d'estat d'una propietat CSS (com el pas de l'estat normal a `:hover`, `:focus` o `:active`) es produïsca de manera **suau i progressiva durant un lapse de temps determinat**, en lloc d'un salt sobtat instantani.

### Sintaxi Abreviada de `transition`
```css
transition: [propietat] [durada] [funció-temporització] [retard];
```

Exemple:
```css
.boto-interactiu {
  background-color: #0284c7;
  color: white;
  transform: translateY(0);
  /* Anima exclusivament el fons i la transformació durant 250ms */
  transition: background-color 0.25s ease, transform 0.25s cubic-bezier(0.4, 0, 0.2, 1);
}

.boto-interactiu:hover {
  background-color: #0369a1;
  transform: translateY(-2px); /* Eleva subtilment el botó */
}
```

### Funcions de Temporització (*Timing Functions*)
- `linear`: Velocitat constant uniforme de principi a fi.
- `ease`: Comença lentament, s'accelera al centre i frena amb suavitat al final (per defecte, la més natural).
- `cubic-bezier(x1, y1, x2, y2)`: Permet definir corbes de Bézier personalitzades (com efectes de rebot elàstic).

## Transformacions 2D i 3D (`transform`)

La propietat `transform` permet alterar visualment la geometria d'un element sense alterar el flux del document al seu voltant:

1. **`translate(x, y)`:** Desplaça l'element horitzontalment o verticalment (ex. `transform: translate(-50%, -50%);` per a centratges absoluts).
2. **`scale(x, y)`:** Augmenta o redueix l'escala de l'element (ex. `scale(1.05)` per a efecte d'ampliació en passar el ratolí).
3. **`rotate(angle)`:** Rota l'element sobre el seu centre (ex. `rotate(45deg)`).
4. **`skew(x, y)`:** Inclina o deforma l'element al llarg dels seus eixos.

### Perspectiva i Espai 3D
Per a aconseguir efectes tridimensionals (com una targeta que gira sobre el seu eix vertical mostrant el seu revers):
```css
.contenidor-3d {
  perspective: 1000px; /* Profunditat d'observació */
}

.targeta-giratòria {
  transform-style: preserve-3d;
  transition: transform 0.6s;
}

.targeta-giratòria:hover {
  transform: rotateY(180deg);
}
```
