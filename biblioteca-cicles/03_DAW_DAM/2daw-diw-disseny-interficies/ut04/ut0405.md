## Animacions Basades en Fotogrames Clau (@keyframes)

Mentre que les transicions necessiten un canvi d'estat disparador (com `:hover`) per a actuar entre dos valors (inicial i final), les **animacions CSS amb `@keyframes`** poden executar-se de manera immediata, repetir-se en bucle indefinit (`infinite`) i passar per múltiples estats intermedis percentuals (0%, 25%, 50%, 100%).

### Declaració i Vinculació d'una Animació
```css
/* 1. Definició dels fotogrames clau */
@keyframes bategar {
  0% {
    transform: scale(1);
    opacity: 1;
  }
  50% {
    transform: scale(1.08);
    opacity: 0.85;
  }
  100% {
    transform: scale(1);
    opacity: 1;
  }
}

/* 2. Assignació a l'element d'interfície */
.insignia-notificacio {
  animation-name: bategar;
  animation-duration: 1.5s;
  animation-timing-function: ease-in-out;
  animation-iteration-count: infinite;
  /* Forma abreujada: */
  /* animation: bategar 1.5s ease-in-out infinite; */
}
```

---

## Propietats Clau del Sistema d'Animació

- `animation-iteration-count`: Nombre de repeticions (un enter o `infinite`).
- `animation-direction`: Direcció de reproducció (`normal`, `reverse`, `alternate` per a anar i tornar suaument).
- `animation-fill-mode`: Controla com s'apliquen els estils abans i després de finalitzar l'animació:
  - `forwards`: L'element conserva els estils definits en l'últim fotograma (100%) en acabar l'animació.
  - `both`: Aplica tant els estils inicials abans de començar com els finals en acabar.

## El Rol de les Microinteraccions en la UX

Una **microinteracció** és un moment breu i subtil de retroacció interactiva dissenyat al voltant d'un únic propòsit (com la pulsació d'un botó d'agrada, l'animació d'un indicador de càrrega o la vibració visual d'un camp amb dades invàlides).

### Principis de les Bones Microinteraccions:
1. **Subtilesa:** No han de distreure ni aclaparar; han d'acompanyar l'acció de l'usuari.
2. **Brevetat:** La durada òptima se situa entre **100 ms i 300 ms**. Qualsevol animació que supere els 400 ms comença a ser percebuda com una pèrdua de temps per part de l'usuari.
3. **Respecte per l'Accessibilitat (*Reduced Motion*):** Les persones que pateixen trastorns vestibulars poden patir marejos greus davant moviments continus. És imperatiu respectar la seua preferència:
   ```css
   @media (prefers-reduced-motion: reduce) {
     *, *::before, *::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
     }
   }
   ```
