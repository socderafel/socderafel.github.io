## Contrast Cromàtic en Disseny Accessible

Milions de persones pateixen baixa visió, pèrdua de sensibilitat al contrast associada a l'edat o daltonisme. El criteri WCAG 1.4.3 estableix les següents ràtios matemàtiques de lluminositat relativa:

- **Text Normal (< 18pt o < 14pt negreta):** Mínim **4.5:1** (Nivell AA) o **7:1** (Nivell AAA).
- **Text Gran (>= 18pt o >= 14pt negreta) i elements gràfics UI (icones, vores de camps):** Mínim **3:1**.

```
Exemple Incorrecte: Text gris clar `#94a3b8` sobre fons blanc `#ffffff` (Ràtio 2.3:1) -> SUSPÈS WCAG
Exemple Correcte:   Text gris fosc `#334155` sobre fons blanc `#ffffff` (Ràtio 9.5:1) -> EXCEL·LENT WCAG
```

> **Regla d'or:** Mai utilitzar el color com a **únic mitjà** per a transmetre un estat o error (per exemple, marcar un camp invàlid només amb una vora roja; cal acompanyar-lo sempre d'una icona explicativa i un text d'error).

## Escriptura Professional d'Alternatives Textuals (`alt`)

L'atribut `alt` d'una imatge és el contingut que llegeixen els lectors de pantalla:

1. **Imatges Informatives:** Han de descriure la informació que transmet la imatge en el seu context, no una descripció visual pedant:
   - *Incorrecte:* `alt="gràfic.png"` o `alt="foto"`.
   - *Correcte:* `alt="Evolució de matriculacions en FP: creixement del 15% en el curs 2025-2026"`.
2. **Imatges Funcionals (Botons o Enllaços):** Han de descriure l'**acció** que es realitza, no la icona:
   - *Incorrecte:* `alt="lupa"`.
   - *Correcte:* `alt="Cercar en el catàleg"`.
3. **Imatges Purament Decoratives:** Han de portar l'atribut buit `alt=""` perquè el programari lector les salte en silenci.

## Navegació per Teclat i Estilització del Focus Visible

Molts usuaris amb discapacitat motriu no poden utilitzar un ratolí o pantalla tàctil; naveguen exclusivament amb la tecla **Tabulador**, **Maj + Tab** i les tecles de fletxa.

- **Mai eliminar l'esquema de focus:** La declaració `outline: none;` sense oferir un estil alternatiu és una de les pitjors infraccions d'accessibilitat:
  ```css
  /* Mala pràctica greu */
  :focus { outline: none; } /* Deixa l'usuari de teclat completament a cegues! */
  
  /* Bona pràctica moderna amb :focus-visible */
  :focus-visible {
    outline: 3px solid #0284c7;
    outline-offset: 2px;
    border-radius: 4px;
  }
  ```
- **L'Atribut `tabindex`:**
  - `tabindex="0"`: Afegeix un element no natiu al flux natural de tabulació del teclat.
  - `tabindex="-1"`: Retira l'element de la tabulació seqüencial, però permet enfocar-lo programàticament amb JavaScript (útil en obrir un modal).
  - *Mala pràctica:* `tabindex="1"` o superior (trenca l'ordre natural i genera desorientació).
