## 1. Concepte i Finalitat de XQuery

**XQuery** (XML Query Language) és per a les dades en format XML el que SQL és per a les bases de dades relacionals. Dissenyat pel W3C, és un llenguatge funcional, fortament tipat i completament lliure d'efectes secundaris que permet consultar, filtrar, transformar i sintetitzar dades provinents tant de fitxers XML independents com de col·leccions completes i bases de dades natives XML (com eXist-db o BaseX).

XQuery 1.0 està construït directament sobre el model de dades i expressions de **XPath 2.0**, fet que significa que qualsevol expressió XPath vàlida és també una consulta XQuery vàlida.

---

## 2. L'Estructura de les Expressions FLWOR

El cor de XQuery és el patró d'expressió **FLWOR** (pronunciat «flower»), acrònim de les seues cinc clàusules estructurals:

1. **`for` (Iteració):** Associa una variable que va prenent d'un en un els valors d'una seqüència de nodes (equivalent a un bucle).
2. **`let` (Assignació):** Associa una seqüència completa o valor calculat a una variable d'una sola vegada (sense iterar).
3. **`where` (Filtratge):** Restringeix els resultats aplicant una condició booleana (equivalent al `WHERE` de SQL).
4. **`order by` (Ordenació):** Ordena la seqüència resultant segons un o més criteris ascendents o descendents.
5. **`return` (Projecció i Construcció):** Construeix i retorna el resultat final per a cada iteració, podent generar nous elements XML sobre la marxa.

```xquery
(: Consulta FLWOR que extreu els aprovats ordenats per nota :)
for $alumne in doc("expedients.xml")//alumne
let $notaFinal := $alumne/nota
where $notaFinal >= 5.0
order by $notaFinal descending
return
  <qualificat estat="APTE">
    <estudiant>{ $alumne/nom/text() }</estudiant>
    <puntuacio>{ $notaFinal/text() }</puntuacio>
  </qualificat>
```

## 3. Construcció Dinàmica de Nous Documents (Constructors Directes)

Una de les capacitats més elegants de XQuery és la integració directa d'etiquetes XML o HTML en el cos de la consulta. Qualsevol expressió tancada entre claus `{ ... }` s'avalua dinàmicament en temps d'execució:

```xquery
<taula-resum>
{
  for $modul in doc("cicles.xml")//modul
  let $totalAlumnes := count($modul/matriculats/alumne)
  where $modul/@actiu = "true"
  order by $totalAlumnes descending
  return
    <fila codi="{ $modul/@id }">
      <nom>{ $modul/titol/text() }</nom>
      <ocupacio>{ $totalAlumnes }</ocupacio>
    </fila>
}
</taula-resum>
```
