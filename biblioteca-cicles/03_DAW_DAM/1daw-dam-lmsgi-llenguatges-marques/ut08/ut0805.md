Disposar de les dades emmagatzemats només és útil si sabem **recuperar-los**. Cada tecnologia d'emmagatzematge té el seu llenguatge de consulta: SQL per a bases relacionals, XQuery/XPath per a bases natives XML i JSONPath/jq per a JSON. En aquest apartat ens centramos en **XQuery**, el llenguatge de consulta dels documents XML.

## **Panorama dels llenguatges de consulta**

| Llenguatge | S'usa sobre... | Serveix per a... |
| --- | --- | --- |
| **SQL** | Bases de dades relacionals | Seleccionar, inserir, actualitzar i esborrar dades en taules |
| **XPath** | Documents XML | Localitzar nodes dins d'un document |
| **XQuery** | Documents i col·leccions XML | Consultes i transformacions complexes sobre XML |
| **JSONPath** | Documents JSON | Localitzar elements dins d'un document JSON |
| **jq** | Documents JSON | Filtrar i transformar JSON des de la terminal |

💡 **Clau:** XPath és un subconjunto de XQuery. Tot el que es pot fer amb XPath es pot fer amb XQuery, però XQuery afegeix variables, condicions, ordenació i agregació.

## **XQuery: què és i per a què s'usa**

**XQuery** és un llenguatge estàndard del W3C per a consultar i transformar documents XML. Es sembla a SQL en la seua filosofía (seleccionar informació), però treballa amb l'estructura jeràrquica dels documents en lloc d'amb taules. XQuery és a XML el que SQL és a les bases de dades relacionals.

**Aplicacions:**

- **Recuperar** informació a partir de conjunts de dades XML.

- **Transformar** unes estructures XML en altres que organitzen la informació de forma diferent.

- **Alternativa a XSLT** per a transformar XML a altres formats (HTML, PDF, text).

- Realitzar **agregacions** (comptar, sumar, promediar).

- Combinar informació de diversos documents o col·leccions.

**Requeriments tècnics principals** (definits pel W3C):

- És un llenguatge **declarativo**.

- És **independent de l'origen de les dades**: la mateixa consulta funciona sobre un fitxer local, un fitxer en un servidor web o una base de dades.

- Les consultes i els resultats respetan el **model de dades XML** i suporten *namespaces*, XSD i DTD (encara que també pot treballar sense ells).

- És **independent de l'estructura** del document: funciona sense conocerla.

- Suporta tipus simples (enters, cadenes) i complexos (nodes), cuantificadors universals i existencials, i la combinació de diverses fonts en una consulta.

## **El model de dades de XQuery**

El model de dades sobre el que es sustenta XQuery és molt distint del relacional, perquè XML inclou conceptes com **jerarquia** i **ordre de les dades** que no existeixen en SQL. L'entrada i l'eixida d'una consulta es defineixen en termes d'aquest model, que proporciona una representació abstracta d'un o més documents XML.

Les principals característiques són:

- **Seqüències:** una col·lecció **ordenada** de zero o més ítems. Poden ser heterogéneas (mezclar nodes i valors atòmics), però una seqüència mai pot ser un ítem d'una altra seqüència.

- **Ordre del document:** correspon a l'ordre en que apareixen els nodes si la jerarquia es representara en XML. Si el primer caràcter d'un node ocorre abans que el d'un altre, el precede també en l'ordre del document.

- **Error value:** un valor especial resultat d'avaluar una expressió que conté un error.

💡 **Exemple d'ordre:** no és el mateix cercar una etiqueta `<b>` dins d'una `<a>` (`/root/a/b`) que totes les `<b>` del document (`//b`), que poden estar imbricades o no.

## **Expressions**

Una **consulta** en XQuery és una **expressió** que llegix una seqüència de dades en XML i retorna una altra **seqüència de dades** com **resultat**.

- En XQuery **tot és una expressió** que es avalua a un **valor** (una seqüència heterogénea de nodes i valors atòmics).

- La majoria de les expressions es componen combinant expressions més simples mitjançant operadors i paraules reservades.

- Ja que XQuery es construeix sobre XPath, **tota expressió XPath és també una consulta XQuery vàlida**.

## **Sintaxi de XQuery**

Per a escriure una consulta XQuery cal tindre en compte:

- Els caràcters `{` i `}` delimitan les **expressions** que es **evalúan** per a crear un document nou.

- Els **comentaris** es escriuen entre `(:` i `:)`.

- XQuery admet expressions **condicionals** `if-then-else`, amb la mateixa semàntica que en els llenguatges de programació habituals.

- Les clàusules FLWOR són **case sensitive**: només es escriuen en **minúscules** (`for`, `let`, `where`, `order by`, `return`).

Exemple complet:

```html
(: Selecciona los títulos de los libros de O'Reilly Media :)
<ul>{
    for $x in doc("libros.xml")/biblioteca/libros/libro
    where $x/editorial = "O'Reilly Media"
    order by $x/titulo
    return <li>{data($x/titulo)}</li>
}</ul>
```

## **L'expressió FLWOR**

El corazón de XQuery és l'expressió **FLWOR**, de les quals sigles corresponen a:

| Clàusula | Significat | Exemple |
| --- | --- | --- |
| **F**or | Itera sobre una seqüència de nodes | `for $p in /productos/producto` |
| **L**et | Assigna una variable a un valor | `let $total := 100` |
| **W**here | Filtra els elements de la iteració | `where $p/precio > 50` |
| **O**rder by | Ordena els resultats | `order by $p/precio descending` |
| **R**eturn | Produeix el resultat de la consulta | `return $p/nombre` |

En una sentència FLWOR ha d'existir, almenys, una clàusula `for` o una `let`. El resta, si existeixen, han de respetar l'ordre del nom FLWOR.

### Clàusula `for`

Associa una o més **variables** amb cada **node** de la col·lecció de dades. Si apareix més d'una clàusula `for` (o més d'una variable en una mateixa `for`), el resultat és el **producte cartesiano** de les variables.

```html
for $p in /libros/libro
return $p/titulo
```

Amb filtre en la pròpia expressió:

```html
for $p in /empleados/empleado[apellido = "García"]
return $p/nombre
```

### Clàusula `let`

Assigna un **valor inmutable** a una variable, que es pot utilitzar després. Les variables de XQuery són **inmutables**: una vegada definides no es poden modificar, per la qual cosa es comporten com constants.

```html
let $a := 5
let $b := 10
return $a + $b
```

Combinada amb funcions d'agregació permet obtindre un **únic valor**:

```html
let $nombres := /empleados/empleado[edad >= 18]/nombre
return count($nombres)
```

### Clàusula `where`

Filtra els resultats de les clàusules `for` i `let` segons una **expressió booleana**.

- Amb un **`for`**, la condició es avalua a **cada element** de la llista:

```html
for $libro in //libro
where $libro/precio > 50
return $libro/titulo
```

```html
for $estudiante in //estudiante
where avg($estudiante/calificaciones/calificacion) > 8.5
return $estudiante/nombre
```

- Amb un **`let`**, la condició es avalua a tota la **variable com un únic valor**. No filtra element a element: si el valor de la variable és una llista, es retorna completa o no es retorna res.

```html
let $n := 2
where $n > 1
return $n
```

### Clàusula `order by`

Ordena els resultats segons un o diversos **criteris**. Per defecte l'ordre és **ascendiente**; es afegeix el modificador `descending` per al descendiente.

```html
for $libro in //libro
order by $libro/autor, $libro/titulo
return $libro/titulo
```

```html
for $estudiante in //estudiante
let $promedio := avg($estudiante/calificaciones/calificacion)
order by $promedio descending
return $estudiante/nombre
```

### Clàusula `return`

Especifica **què informació** es retorna. Pot contindre des de valors simples fins a estructures XML complexes, i es poden usar funcions i expressions en el seu interior.

```html
for $libro in //libro
return $libro/titulo
```

```html
for $estudiante in //estudiante[nombre = 'Juan']
let $promedio := avg($estudiante/calificaciones/calificacion)
return $promedio
```

### 💡 Exemples complets

**Exemple 1: seleccionar amb for i return.** Partim del catàleg de productes de la base de dades eXist-db:

```html
for $p in collection('/db/catalogo')/productos/producto
return $p/nombre
```

Resultat: la llista de tots els noms de productes.

**Exemple 2: filtrar amb where.** Productes de la categoria `monitor` amb preu superior a 200:

```html
for $p in collection('/db/catalogo')/productos/producto
where $p/@categoria = 'monitor' and $p/precio > 200
return $p/nombre
```

**Exemple 3: ordenar i construir un document nou.** Generamos un document HTML amb els productes ordenats de més barat a més car:

```html
<ul>{
    for $p in collection('/db/catalogo')/productos/producto
    order by xs:decimal($p/precio)
    return <li>{ $p/nombre } -- { $p/precio } €</li>
}</ul>
```

## **Funcions de XQuery**

XQuery inclou **funcions integrades** per a processar i manipular dades, però també permet definir **funcions pròpies**.

### Funcions numèriques

| Funció | Què calcula |
| --- | --- |
| `floor(secuencia)` | Redondea al valor numèric **inferior** més próximo |
| `ceiling(secuencia)` | Redondea al valor numèric **superior** més próximo |
| `round(secuencia)` | Redondea al valor més próximo |
| `count(secuencia)` | Compta la quantitat d'ítems |
| `min(secuencia)` | Mínim dels valors |
| `max(secuencia)` | Màxim dels valors |
| `avg(secuencia)` | Mitjana aritmética |
| `sum(secuencia)` | Suma dels valors |

### Funcions de cadenes de text

| Funció | Què calcula |
| --- | --- |
| `concat(c1, c2, ...)` | Uneix diverses cadenes de text |
| `string-length(cadena)` | Número de caràcters d'una cadena |
| `starts-with(cadena, sub)` | Comprova si una cadena **comença** per una altra |
| `ends-with(cadena, sub)` | Comprova si una cadena **acaba** per una altra |
| `upper-case(cadena)` | Converteix la cadena a **majúscules** |
| `lower-case(cadena)` | Converteix la cadena a **minúscules** |

### Funcions d'ús general

| Funció | Què calcula |
| --- | --- |
| `empty(secuencia)` | Retorna `true` si la seqüència no conté cap element |
| `exists(secuencia)` | Retorna `true` si la seqüència conté almenys un element |
| `distinct-values(secuencia)` | Retorna els valors **únics** d'una seqüència |
| `data(nodos)` | Retorna el **valor** dels nodes, sense etiquetes |

### Cuantificadors

| Paraula clau | Què comprova |
| --- | --- |
| `some $x in secuencia satisfies condición` | Que **algun** element verifica la condició |
| `every $x in secuencia satisfies condición` | Que **tots** els elements verifican la condició |

### Definició de funcions pròpies

Permet definir operacions que no estan incloses de forma nativa, modularitzar el codi i reutilitzar-lo. S'usa `declare function` seguida del nom, els arguments i el cos:

```html
declare function minPrice($p as xs:decimal?, $d as xs:decimal?) as xs:decimal? {
    let $disc := ($p * $d) div 100
    return ($p - $disc)
}
```

Per a utilitzar la funció en una consulta:

```html
for $libro in /biblioteca/libros/libro
return <minPrice>{ minPrice($libro/precio, $libro/descuento) }</minPrice>
```

## **Operadors**

Els operadors més importants es agrupen segons la seua funcionalitat.

### Comparació de valors

Comparen dos **valors escalars** i produeixen un error si algun dels operands és una seqüència de longitud major que 1.

| Operador | Descripció |
| --- | --- |
| `eq` | Igual a |
| `ne` | Distint de |
| `lt` | Menor que |
| `le` | Menor o igual que |
| `gt` | Major que |
| `ge` | Major o igual que |

### Comparació general

Comparen operands que poden ser **seqüències**.

| Operador | Descripció |
| --- | --- |
| `=` | Igual a |
| `!=` | Distint de |
| `>` | Major que |
| `>=` | Major o igual que |
| `<` | Menor que |
| `<=` | Menor o igual que |

### Comparació de nodes i de la seua ordre

| Operador | Descripció |
| --- | --- |
| `is` | `true` si les dos variables estan ligades al mateix node |
| `is not` | `true` si les dos variables no estan ligades al mateix node |
| `<<` | `true` si el primer node ocorre abans en l'ordre del document |

### Lògics

| Operador | Descripció |
| --- | --- |
| `and` | Operador «i» |
| `or` | Operador «o» |

### Seqüències de nodes

Retornen seqüències en l'ordre del document i eliminen els duplicats.

| Operador | Descripció |
| --- | --- |
| `union` | Nodes que apareixen en algun dels dos operands |
| `intersect` | Nodes que apareixen en els dos operands |
| `except` | Nodes del primer operant que no apareixen en el segon |

### Aritmétics

| Operador | Descripció |
| --- | --- |
| `+` | Suma |
| `-` | Diferència |
| `*` | Producte |
| `div` | Quocient |
| `mod` | Mòdul (resta de la divisió) |

## **Fitxers de consultes**

Les consultes es poden escriure directament en un programari amb motor XQuery, o **almacenar-se en fitxers** per a la seua reutilització. Per a això es crea un fitxer de text amb la consulta i es guarda amb una d'aquestes extensions:

```html
.xq   .xqm   .xqy   .xql   .xqu   .xquery
```

Per exemple, un fitxer `consulta.xq`:

```html
for $libro in /biblioteca/libros/libro
return $libro/titulo
```

## **Comparació: XQuery enfront de SQL**

| Aspecte | SQL | XQuery |
| --- | --- | --- |
| Unitat de treball | Files d'una taula | Nodes d'un document |
| Estructura de les dades | Plana (taules) | Jeràrquica (arbre) |
| Iteració | `SELECT` + `JOIN` | `for` / `let` |
| Filtre | `WHERE` | `where` |
| Ordenació | `ORDER BY` | `order by` |
| Resultat | Conjunt de files | Document o seqüència de nodes |

Tots dos conviven: un sistema real pot tindre les dades en una base relacional (SQL) i exportar-los a XML perquè una base nativa els consulte amb XQuery.

## **Resum**

- XQuery és el **llenguatge de consulta de XML**, estàndard del W3C, equivalent a SQL per a documents.

- Es sustenta en un **model de dades** basat en seqüències ordenades, distint del relacional.

- L'expressió **FLWOR** (for, let, where, order by, return) permet consultes i transformacions completes.

- Disposa de **funcions** (numèriques, de cadenes, d'ús general), **cuantificadors** (`some`, `every`), definició de **funcions pròpies** i una àmplia varietat de **operadors**.

- Les consultes es poden guardar en fitxers `.xq`, `.xqm`, `.xqy`, `.xql`, `.xqu` o `.xquery`.

- SQL consulta **taules**; XQuery consulta **documents**; tots dos es complementan en un sistema real.
