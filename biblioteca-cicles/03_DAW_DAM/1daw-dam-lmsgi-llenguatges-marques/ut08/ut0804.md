## 1. Extracció de Dades i Invocació de Plantilles

- **`<xsl:value-of select="expressioXPath" />`:** Extreu el valor textual del primer node que coincideix amb l'expressió XPath i l'insereix en l'arbre resultat.
- **`<xsl:apply-templates select="expressioXPath?" />`:** Ordena al processador XSLT que continue navegant cap als nodes fills seleccionats buscant les plantilles `<xsl:template match="...">` que s'ajusten a ells.

```xml
<!-- Plantilla específica per a cada alumne -->
<xsl:template match="alumne">
  <article class="fitxa-alumne">
    <h3><xsl:value-of select="nom" /> <xsl:value-of select="cognoms" /></h3>
    <p>Qualificació: <strong><xsl:value-of select="nota" /></strong></p>
  </article>
</xsl:template>
```

## 2. Iteració (`<xsl:for-each>`) i Ordenació (`<xsl:sort>`)

Quan necessitem iterar de forma explícita sobre un conjunt de nodes semblants (per exemple, per a construir les files d'una taula HTML), emprem `<xsl:for-each>`:

```xml
<table border="1">
  <thead>
    <tr><th>Mòdul</th><th>Hores</th><th>Tutor</th></tr>
  </thead>
  <tbody>
    <xsl:for-each select="//modul">
      <!-- Ordenació automàtica dels nodes abans de dibuixar-los -->
      <xsl:sort select="hores" data-type="number" order="descending" />
      <tr>
        <td><xsl:value-of select="nom" /></td>
        <td><xsl:value-of select="hores" /></td>
        <td><xsl:value-of select="@tutor" /></td>
      </tr>
    </xsl:for-each>
  </tbody>
</table>
```

## 3. Estructures Condicionals: `<xsl:if>` i `<xsl:choose>`

XSLT ofereix dues estructures lògiques de decisió:

### Condicional Simple: `<xsl:if test="expressioBooleana">`
S'executa únicament si l'atribut `test` avalua a `true` (no disposa de clàusula «else»):
```xml
<xsl:if test="nota &gt;= 5.0">
  <span class="aprovat">APTE</span>
</xsl:if>
```
*(Nota: L'operador `>=` s'ha d'escriure obligatòriament com a `&gt;=` per a mantindre la conformitat sintàctica d'XML).*

### Condicional Múltiple: `<xsl:choose>` / `<xsl:when>` / `<xsl:otherwise>`
Equival a una estructura `if / else if / else` completa:
```xml
<xsl:choose>
  <xsl:when test="nota &gt;= 9.0">
    <span class="excelent">Excel·lent</span>
  </xsl:when>
  <xsl:when test="nota &gt;= 5.0">
    <span class="aprovat">Aprovat</span>
  </xsl:when>
  <xsl:otherwise>
    <span class="suspens">Suspens</span>
  </xsl:otherwise>
</xsl:choose>
```
