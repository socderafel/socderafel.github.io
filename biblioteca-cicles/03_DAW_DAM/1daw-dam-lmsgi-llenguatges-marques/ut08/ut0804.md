Les bases de dades relacionals guarden les dades en taules. Però quan la informació és **documental i jeràrquica** (catálogos, factures, informes, fitxes), a vegades és més natural guardar el **document XML complet** i consultar-lo amb **XPath i XQuery**. Per a això existeixen les **bases de dades natives XML**.

## **Què és una base de dades nativa XML?**

Una **base de dades nativa XML** (o NXD, de l'anglès *Native XML Database*) és un sistema gestor que:

- Emmagatzema el document XML **com una unitat lògica**, sense descomponer-lo en taules.

- Respeta la **estructura jeràrquica** del document (el model de dades XDM).

- Permet **consultar** els documents amb **XPath** i **XQuery**.

- Permet organitzar els documents en **col·leccions**.

Les més conegudes són:

| Sistema | Llicència | Característiques destacades |
| --- | --- | --- |
| **eXist-db** | Open Source | Servidor web integrat, REST, molt usada en bibliotecas i arxius |
| **BaseX** | Open Source | Ràpida, amb interfície gràfica i consola, bona documentació |
| **Sedna** | Open Source | SGBD nativa académica |

## **Característiques principals**

1. **Emmagatzematge documental:** es guarda el document íntegro (no troceado).

1. **Consultes potents:** XQuery permet filtrar, ordenar, agrupar i transformar documents en una sola consulta.

1. **Col·leccions:** els documents es agrupen en carpetes lògiques anomenades *collections*, equivalents a les taules d'una base relacional.

1. **Validació:** es poden associar esquemes (DTD, XSD, Relax NG) a les col·leccions per a validar els documents a l'insertar-los.

1. **Índexs:** per a acelerar les consultes sobre elements o atributs freqüents.

## **Instal·lació de eXist-db (CE6i)**

Anem a instal·lar **eXist-db**, la base de dades nativa XML més utilitzada en entorns educativos i culturals.

### Pas 1: requisits previos

- Tindre instal·lada una **màquina virtual de Java** (JRE 11 o superior). Comprovem amb:

```html
java -version
```

### Pas 2: descarrega i arrencada

1. Descarrega eXist-db des de la seua pàgina oficial i descomprime l'arxiu.

1. Entra en la carpeta descomprimida i executa el script d'arrencada:

```html
./bin/startup.sh
```

1. A l'acabar l'arrencada, s'obri automàticament la interfície web d'administració en:

```html
http://localhost:8080/exist/
```

💡 **Truco:** si el port 8080 està ocupat, es pot canviar editant l'arxiu `conf.xml` de la instal·lació.

### Pas 3: emmagatzemar documents en col·leccions

1. En la interfície web, entra en **Apps → eXide** (l'editor integrat).

1. Crea una col·lecció `catalogo`.

1. Puja el document `productos.xml` a eixa col·lecció:

```html
<productos>
    <producto id="p1" categoria="portatil">
        <nombre>Portátil Pro 14</nombre>
        <precio>899.00</precio>
    </producto>
    <producto id="p2" categoria="periferico">
        <nombre>Teclado inalámbrico</nombre>
        <precio>34.90</precio>
    </producto>
    <producto id="p3" categoria="monitor">
        <nombre>Monitor 27"</nombre>
        <precio>219.00</precio>
    </producto>
</productos>
```

1. En la finestra de consultes de eXide, comprova que el document es pot recuperar:

```html
collection('/db/catalogo')/productos
```

Si la consulta retorna el document, la base de dades nativa XML està funcionant i emmagatzemant els nostres documents.

## **Gestió de la informació en la base nativa (CE6i)**

Una vegada instal·lada, la informació emmagatzemada es pot gestionar de diverses formes:

### Inserir un document des de la consola

A més de subir-lo per la interfície, es pot emmagatzemar un document mitjançant XQuery:

```html
xquery version "3.1";

let $doc := document {
    <producto id="p4" categoria="raton">
        <nombre>Ratón ergonómico</nombre>
        <precio>22.50</precio>
    </producto>
}
return xmldb:store('/db/catalogo', 'p4.xml', $doc)
```

### Modificar i esborrar documents

Amb l'extensió `xmldb:` es poden actualitzar o eliminar documents de la col·lecció:

```html
xmldb:remove('/db/catalogo', 'p4.xml')
```

### Control de permisos

eXist-db gestiona usuaris, grups i permisos (lectura, escriptura, ejecució) sobre col·leccions i documents, igual que un sistema d'arxius.

## **Quan usar una base de dades nativa XML**

És l'opció natural quan:

- La unitat d'informació és **el document complet** (una factura, una fitxa, un informe), no un registre.

- Les consultes es fan **sobre l'estructura** del document ("dame tots els productes amb preu menor que 50").

- Es necessiten **col·leccions** de documents heterogéneos.

- Interessa **publicar** els documents en la Web (eXist-db trae servidor HTTP i serveis REST).

En canvi, per a dades masivos i molt regulars (milers de files idéntiques), una base relacional segueix sent més eficient.

## **Resum**

- Una **base de dades nativa XML** guarda documents XML íntegros i els consulta amb XPath/XQuery.

- **eXist-db** i **BaseX** són les eines més representativas.

- Els documents es organitzen en **col·leccions** i es gestionen des de la interfície web o mitjançant XQuery (`xmldb:store`, `xmldb:remove`).

- És la millor opció per a informació **documental i jeràrquica**.
