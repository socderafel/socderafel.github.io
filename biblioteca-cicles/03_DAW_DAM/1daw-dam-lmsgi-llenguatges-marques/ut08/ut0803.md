## 1. El Model de Transformació de XSLT

**XSLT** (Extensible Stylesheet Language Transformations) és un llenguatge basat en XML dissenyat específicament per a transformar documents XML estructurats en altres formats de sortida (com HTML5 per a visualització en navegadors, altres dialectes XML, fitxers de text pla CSV o codi JSON).

L'arquitectura d'un procés de transformació es compon de tres elements clau:
1. **Document Font (*Source Tree*):** L'arbre de nodes del document XML d'origen que es vol processar.
2. **Full d'Estil XSLT (*Stylesheet*):** Document XML que conté les regles declaratives i plantilles de transformació.
3. **Processador XSLT (*XSLT Engine*):** El programari (com Saxon, Xalan o el motor natiu integrat en els navegadors com Chrome/Firefox) que pren l'arbre font, executa el full XSLT i emet l'**Arbre Resultat (*Result Tree*)**.

```
+--------------------+      +-----------------------+
| Document XML Font  |      | Full d'Estil XSLT     |
| (dades.xml)        |      | (transformacio.xsl)   |
+--------------------+      +-----------------------+
          |                             |
          +------------+   +------------+
                       |   |
                       v   v
            +-----------------------+
            |   Processador XSLT    |
            |   (Motor de Càlcul)   |
            +-----------------------+
                       |
                       v
            +-----------------------+
            |    Arbre Resultat     |
            | (HTML5 / XML / CSV)   |
            +-----------------------+
```

## 2. L'Element Arrel `<xsl:stylesheet>` i la Declaració d'Eixida

Tot document XSLT comença amb la declaració d'espais de noms oficials del W3C:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

  <!-- Configuració del Format del Document Resultat -->
  <xsl:output method="html" encoding="UTF-8" indent="yes" doctype-system="about:legacy-compat" />

  <!-- Plantilla arrel: punt d'inici de la transformació -->
  <xsl:template match="/">
    <html lang="ca">
      <head>
        <meta charset="UTF-8" />
        <title>Llistat d'Alumnat Transformat</title>
      </head>
      <body>
        <h1>Expedients Acadèmics</h1>
        <xsl:apply-templates select="//alumne" />
      </body>
    </html>
  </xsl:template>

</xsl:stylesheet>
```

### Valors del Mètode d'Eixida (`<xsl:output method="...">`)
- `method="html"`: Genera marcatge HTML, admetent etiquetes buides no tancades com `<br>` o `<img>` segons el format web.
- `method="xml"`: Garanteix que el resultat siga un document XML estrictament ben format, afegint la declaració `<?xml ... ?>`.
- `method="text"`: Emet text pla pur sense cap etiqueta, ideal per a generar fitxers CSV separats per comes o scripts SQL d'inserció.

## 3. Vinculació en Client d'un Full XSLT

Tot i que en entorns de producció la transformació se sol realitzar en el servidor (*Server-Side Processing* mitjançant Java, Python, Node.js o PHP), un document XML pot referenciar directament un full XSLT per a ser processat pel navegador client mitjançant una instrucció de processament:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="estils/transformacio.xsl"?>
<biblioteca>
  <!-- Contingut de la biblioteca -->
</biblioteca>
```
