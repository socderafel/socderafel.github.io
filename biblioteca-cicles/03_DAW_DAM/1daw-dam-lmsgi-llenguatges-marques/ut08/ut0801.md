## 1. El Llenguatge XPath i el Model d'Arbre de Nodes

**XPath** (XML Path Language) és una recomanació del W3C que proporciona una sintaxi no XML per a identificar, seleccionar i navegar nodes dins d'un document XML. Constitueix el nucli de consulta tant per a **XSLT** com per a **XQuery** i eines d'automatització i proves com Selenium o Playwright.

Segons el model de dades de XPath, tot document XML es conceptualitza com un arbre format per **7 tipus de nodes**:
1. **Node Arrel (*Root Node*):** El pare de tot el document (simbolitzat per una barra inclinada `/`). No s'ha de confondre amb l'element arrel.
2. **Nodes d'Element:** Cadascuna de les etiquetes XML (`<llibre>`, `<titol>`).
3. **Nodes d'Atribut:** Metadades declarades en elements (`@isbn`, `@id`).
4. **Nodes de Text:** Les dades de caràcter contingudes a l'interior d'un element.
5. **Nodes d'Espai de Noms:** Prefixos i URIs associats.
6. **Nodes d'Instrucció de Processament:** `<?xml-stylesheet ... ?>`.
7. **Nodes de Comentari:** `<!-- ... -->`.

## 2. Rutes d'Ubicació (Location Paths) i Sintaxi Abreviada

Una ruta d'ubicació està formada per una sèrie de passos de navegació (*steps*) separats per barres `/`:

```
/institut/cicle[@familia='Informatica']/modul[hores > 60]/nom/text()
```

### Principals Metacaràcters de Navegació Abreviada
- `/` : Selecciona des del node arrel o indica un salt de fill directe d'un nivell.
- `//` : Cerca recursiva descendent que selecciona nodes a qualsevol profunditat de l'arbre.
- `.` : Fa referència al node context actual.
- `..` : Fa referència al node pare directe del context actual.
- `@` : Selecciona un atribut (ex: `@id`, `@preu`).
- `*` : Comodí que coincideix amb qualsevol node d'element.
- `@*` : Comodí que coincideix amb qualsevol atribut.
- `node()` : Coincideix amb qualsevol mena de node (element, text, comentari).
- `text()` : Selecciona exclusivament el contingut textual del node.

## 3. Predicats Condicionals [ ] i Eixos de Navegació Complet

Els **predicats** s'escriuen entre claudàtors `[...]` i s'apliquen per a filtrar la seqüència de nodes que compleixen una condició booleana o de posició numèrica:

```xpath
//llibre[1]                 --> El primer llibre del conjunt (en XPath els índexs comencen en 1, NO en 0!)
//llibre[last()]            --> L'últim llibre del conjunt
//llibre[position() <= 3]   --> Els tres primers llibres
//llibre[preu > 25.0]       --> Llibres amb element preu superior a 25.0
//llibre[@idioma = 'ca']    --> Llibres amb atribut idioma igual a "ca"
//llibre[autor and not(any)]--> Llibres que tenen fill autor però no tenen fill any
```

### Eixos de Navegació Formal (Sintaxi Completa: `eix::node[predicat]`)
Quan la sintaxi abreviada no és suficient, XPath ofereix 13 eixos direccionals complets:
- `child::` : Fills directes (per defecte).
- `parent::` : Pare directe.
- `descendant::` : Descendents a qualsevol nivell (fills, néts, besnéts).
- `ancestor::` : Ancestres (pare, avi, besavi fins a l'arrel).
- `following-sibling::` : Germans posteriors en el document.
- `preceding-sibling::` : Germans anteriors en el document.
