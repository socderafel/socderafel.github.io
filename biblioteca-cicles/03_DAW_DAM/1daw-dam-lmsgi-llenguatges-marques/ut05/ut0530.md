## **Consultar o modificar contingut de text**

Les pàgines estan repletas d'elements HTML i és possible que es vulga modificar aquests elements per a canviar el seu contingut de **text** per un altre. En l'apartat anterior es explica com localitzar els elements en el DOM, ara el que es va a veure és com es pot modificar el contingut html.

Les propietats relacionades amb aquest cometido són:

| Propietats | Descripció |
| --- | --- |
| **.textContent** | Retorna (o canvia) el contingut de text de l'element. |
| **.innerText** | Retorna (o canvia) el contingut de text renderitzat (té en compta els estils CSS). |
| **.outerText** | Idem a **.innerText**, però al reemplaçar també reemplaça l'etiqueta contenedora. |

Anem a anar viéndolas detalladament per a comprendre el seu funcionament i característiques.

**textContent**innerText**outerText**

### **La propietat `.textContent`**

La propietat recomanada per a fer modificacions de text és **.textContent**, que ens retorna el **contingut de text** d'un element HTML concret. És molt útil per a obtindre (*o modificar*) **només el text** d'un element, obviant el marcatge o etiquetatge HTML.

Observa el següent exemple, on anem a seleccionar l'element `<p>` amb classe **.message** des de Javascript i a treballar amb ell accedint a diverses de les seues propietats:

<details markdown="1">

<summary>💡 JS</summary>

```html
const element = document.querySelector(".message");

element.textContent;                   // "Mi nombre es Luis."
element.textContent = "Hola a todos";  // Modificamos el contenido de texto
element.textContent;                   // "Hola a todos"
```

</details>

<details markdown="1">

<summary>💡 HTML</summary>

```html
<div class="container">
  <div class="parent">
    <p>Hola a todos.</p>
    <p class="message">Mi nombre es <strong>Luis</strong>.</p>
  </div>
</div>
```

</details>

Com pots veure, no només podem utilitzar la propietat **.textContent** per a accedir a la informació de text que conté, sinó també per a reemplaçar el seu contingut, simplement asignándolo com si fóra una variable o constant.

> **📌 Important**
> 

> Observa que en el HTML tenim una etiqueta `<strong>`. En el cas que l'element tinga imbricades diverses etiquetes HTML una dins d'una altra, la propietat **.textContent** es quedarà només amb el contingut textual.

### **La propietat `.innerText`**

La propietat **.innerText** és molt similar a **.textContent**, però té una diferència clau: accedeix al text **renderitzat visualment pel navegador**.

Observa el següent fragment de codi:

<details markdown="1">

<summary>💡 HTML</summary>

```html
<div class="container">
  <p>Hola a todos.</p>
  <p>Me llamo <strong>Luis</strong>. <mark style="display: none">New message</mark></p>
  <p hidden>Esto es un mensaje posterior oculto semánticamente.</p>
  <details>
    <summary>Más información</summary>
    <div>Esto es un desplegable que está colapsado.</div>
  </details>
</div>
```

</details>

Observa que:

- El contingut de l'etiqueta `<mark>` està ocult mitjançant CSS.

- El contingut de la tercera etiqueta `<p>` està ocult semánticament mitjançant l'atribut **hidden**.

- El contingut de l'etiqueta `<div>` dins del `<details>` està ocult perquè l'acordeón està colapsado.

Si consultamos el contingut de text del **.container** mitjançant la propietat **.textContent** ens devolvería tot el contingut de text de totes les etiquetes de l'interior del **.container**. No obstant això, si el fem mitjançant la propietat **.innerText** ens devolvería **només el renderitzat visualment**:

<details markdown="1">

<summary>💡 JS</summary>

```html
const element = document.querySelector(".container");
element.innerText;

// "Hola a todos.
//
// Me llamo Luis.
//
// Más información"
```

</details>

### **La propietat `.outerText`**

En el cas de la propietat **.outerText**, funciona exactament igual que **.innerText** per a obtindre informació. No obstant això, té una xicoteta diferència si la utilitzem per a modificar text:

- En el cas d'utilitzar **.innerText**, modificamos el contingut de l'etiqueta.

- En el cas d'utilitzar **.outerText**, fem el mateix, però incloent l'etiqueta en sí.

<details markdown="1">

<summary>💡 JS</summary>

```html
// <section><div class="container"></div></section>
const element = document.querySelector(".container");

element.innerText = "Me llamo Luis";
// <section><div class="container">Me llamo Luis</div></section>

element.outerText = "Me llamo Luis";
// <section>Me llamo Luis</section>
```

</details>

Observa que en el primer cas, ha afegit el text en l'interior de l'etiqueta `<iv>`. En el segon cas, està reemplazant la pròpia etiqueta `<div>`, quedándose només amb el text.

### Inserint contingut HTML

Un aspecte molt important a tindre en compte és que les propietats que hem vist serveixen només per a **contingut de text**. Si intentem inserir contingut HTML d'aquesta forma:

<details markdown="1">

<summary>💡 JS</summary>

```html
const element = document.querySelector(".container");
element.textContent = "<h1>Hola</h1>";
```

</details>

Obtindrem que el que ocorre és que s'insereix literalment el text `<h1>Hola</h1>`, en lloc de renderitzar-se una etiqueta `<h1>` com encapçalament, amb el text **Hola**. Si el que volem és renderitzar contingut, el veurem en el següent article.

## **Accedir al contingut d'una etiqueta HTML**

És possible que necessitem afegir **contingut HTML** a les etiquetes existents que ja tenim en el DOM. En l'article anterior, vam veure com afegir contingut de text a les nostres etiquetes HTML, però no com afegir contingut HTML. Per a això utilitzarem les propietats i mètodes que aprendrem en aquest article.

Abans de començar, echemos un cop d'ull a les propietats relacionades que tenim per a açò:

| Propietats | Descripció |
| --- | --- |
| **.innerHTML** | Retorna (o canvia) el contingut HTML de l'interior de l'element. |
| **.outerHTML** | Idem a **.innerHTML** però inclou també la pròpia etiqueta HTML. |

Anem a anar viéndolas detalladament per a comprendre el seu funcionament i característiques.

**innerHTML**outerHTML**

### **La propietat `.innerHTML`**

La propietat **.innerHTML** ens permet accedir al contingut d'un element, però en lloc de retornar el seu contingut de text com el fa **.textContent**, aquesta propietat ens retorna el seu **contingut HTML**, és a dir, el seu marcatge HTML. Açò té diverses implicacions que explicarem més avant.

Primer, un exemple amb la diferència entre **.textContent** i **.innerHTML**:

<details markdown="1">

<summary>💡 JS</summary>

```html
const element = document.querySelector(".message");

element.innerHTML;    // "Mi nombre es <strong>Luis</strong>."
element.textContent;  // "Mi nombre es Luis."
```

</details>

Observa que **.textContent** es enfoca en obtindre el contingut de text, mentre que **.innerHTML** es enfoca en el contingut HTML.

De la mateixa forma que **.textContent**, també podem usar **.innerHTML** per a modificar el contingut. Tingues en compte que el contingut HTML suministrado a **.innerHTML** es interpretará, mentre que el suministrado per **.textContent** s'insereix **literalment com text**:

<details markdown="1">

<summary>💡 JS</summary>

```html
element.innerHTML = "<strong>BOLD</strong>";    // Se lee "BOLD" (en negrita)
element.textContent = "<strong>BOLD</strong>";  // Se lee "<strong>BOLD</strong>"
```

</details>

> **📌 Important**
> 

> Tingues molt cura a l'hora d'inserir contingut HTML utilitzant **.innerHTML** ja que si añades contingut que provenga de l'usuari sense revisar-lo, podrien inserir HTML que realitze accions dañinas com inyecció de codi malicioso.

### **La propietat `.outerHTML`**

La propietat **.outerHTML** és molt similar a **.innerHTML**. Mentre aquest últim retorna el codi HTML del **interior** d'un element HTML, **.outerHTML** retorna el codi HTML **des de l'exterior**, és a dir, incloent al propi element implicado:

<details markdown="1">

<summary>💡 JS</summary>

```html
const data = document.querySelector(".data");
data.innerHTML = "<h1>Tema 1</h1>";

data.textContent;   // "Tema 1"
data.innerHTML;     // "<h1>Tema 1</h1>"
data.outerHTML;     // "<div class="data"><h1>Tema 1</h1></div>"
```

</details>

A l'igual que hem vist anteriorment, es pot utilitzar **.outerHTML** assignant textos per a modificar el seu contingut. Açò pot ser molt útil per a reemplaçar un element HTML, inclòs el propi element HTML contenidor.
