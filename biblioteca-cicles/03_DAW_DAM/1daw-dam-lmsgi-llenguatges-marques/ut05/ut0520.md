Si ens trobem en el nostre codi Javascript i volem obtindre informació del contingut de la nostra pàgina o fer modificacions en un element de la pàgina HTML, el primer que hem de fer és **cercar l'element que ens interessa**. Probablement, la forma més senzilla de fer-ho sol ser intentar identificar l'element a través d'algun dels seus atributs més utilitzats, generalment el **id** o la classe mitjançant l'atribut **class**.

## **Mètodes de cerca**

Hi ha diversos mètodes de cerca d'elements, en la següent taula es mostren els més utilitzats:

| Mètodes de cerca | Descripció | Retorna | Si no el troba... |
| --- | --- | --- | --- |
| **.getElementById(id)** | Cerca l'element HTML pel seu **id**. | **ELEMENT** | Retorna **null**. |
| **.getElementsByClassName(class)** | Cerca elements amb la classe **class**. | **HTMLCollection** | Retorna **[ ]**. |
| **.getElementsByName(value)** | Cerca elements amb l'atribut **name** a **value**. | **NodeList** | Retorna **[ ]**. |
| **.getElementsByTagName(tag)** | Cerca etiquetes HTML **tag**. | **HTMLCollection** | Retorna **[ ]**. |
| **.querySelector(sel)** | Cerca el primer element que coincideix amb el selector CSS **sel**. | **ELEMENT** | Retorna null. |
| **.querySelectorAll(sel)** | Cerca tots els elements que coincideixen amb el selector CSS **sel**. | **NodeList** | Retorna **[ ]**. |

### **getElementById()**

El primer mètode, **.getElementById(id)** cerca un element HTML amb el **id** especificat. En principi, un document HTML bé construido **no hauria de** tindre més d'un element amb el mateix **id**, per tant, aquest mètode retornarà sempre un només element, ja que no hauria d'existir més d'un:

> **📌 Exemple**
> 

> **📌 JS**
> 

```html
const element = document.getElementById("page");

console.log(element); // <div id="page"></div>
```

> **📌 HTML**
> 

```html
<div id="page"></div>
```

En la constant **element** guardaríamos una referència a eixe element `<div>` amb **id** amb valor **page**.En el cas de no trobar l'element indicat, retornarà null.

> **📌 Important**
> 

> Cal tindre en compte que aquest mètode només treballa amb **id**. Hui en dia, és més habitual localitzar elements pels seus classes, ja que no tots els elements són únics o tenen un **id** establit.

### **getElementsByClassName()**

D'altra banda, el mètode **.getElementsByClassName(class)** permet cercar els elements que tinguen la classe especificada en **class**. És important donar-se compta del matís de que el mètode té **getElements** en plural, al contrari de l'anterior.

Açò ocorre perquè en aquest cas cerquem classes, i pot retornar **diversos elements**, ja que al contrari que els **id**, poden existir diversos elements amb la mateixa classe:

> **📌 Exemple**
> 

> **📌 JS**
> 

```html
const elements = document.getElementsByClassName("item");

console.log(elements);         // [div, div, div]
console.log(elements[0]);      // Primer item encontrado: <div class="item"></div>
console.log(elements.length);  // 3
```

> **📌 HTML**
> 

```html
<div class="container">
      <div class="item">Item 1</div>
      <div class="item">Item 2</div>
      <div class="item">Item 3</div>
    </div>
```

> **📌 Important**
> 

> Aquests mètodes retornen sempre un array amb tots els elements encontrats que encajen amb el criteri. En el cas de no trobar cap, retornarà un array buit: **[]**.

### **getElementsByName()**

Exactament igual que el cas anterior funciona el mètode **getElementsByName(name)**. En aquest cas, estem cercant elements HTML pel valor que tenen en l'atribut **name**, alguna cosa molt habitual en **formularis HTML**:

> **📌 Exemple**
> 

> **📌 JS**
> 

```html
const nicknames = document.getElementsByName("nickname");

console.log(nicknames);   // [input]
```

> **📌 HTML**
> 

```html
<form>
      <input type="text" name="nickname">
      <input type="text" name="country">
    </form>
```

Observa que retorna un array d'elements, ja que podria donar-se el cas de tindre diversos elements HTML amb eixe mateix atribut **name**.

### **getElementsByTagName()**

En el cas del mètode **getElementsByTagName(tag)**, el que fem és cercar elements pel tipus d'etiqueta HTML. És a dir, si volem cercar tots els elements `<div>` d'una pàgina, podem fer-ho indicándole el paràmetre **div**:

> **📌 Exemple**
> 

> **📌 JS**
> 

```html
const divs = document.getElementsByTagName("div");

console.log(divs);   //  [div, div, div, div]
```

> **📌 HTML**
> 

```html
<div class="container">
      <div class="item">Item 1</div>
      <div class="item">Item 2</div>
      <div class="item">Item 3</div>
    </div>
```

Observa que en aquest exemple, obtenim un array amb **4 elements**. Açò és així perquè fins i tot l'element `<div>` contenidor també és un `<div>`, per la qual cosa és el primer que troba. Després, afegeix els `<div>` del seu interior, i així amb tot els elements `<div>` que trobe.

En el cas de no trobar cap, ens devolvería un array buit **[]**.

### **querySelector()**

El mètode **.querySelector()** retorna retorna el primer element del document que coincideix amb el **selector CSS** indicat per paràmetre:

> **📌 JS**
> 

```html
const page = document.querySelector("#page");               // <div id="page"></div>
const info = document.querySelector(".main .info");         // <div class="info"></div>
```

El realment interessant d'aquest mètode, és que al permetre suministrarle un selector CSS bàsic o fins i tot un selector CSS avançat, es torna un sistema molt més potent que els tradicionals.

- El primer exemple seria equivalent a utilitzar un **.getElementById()**, només que en la versió de **.querySelector()** indiquem per paràmetre un selector, i en el primer li passem un simple string. Observa que estem indicant un **#** perquè es tracta d'un **id**.

- En el segon exemple, estem recuperant el primer element amb classe **info** que estiga dins d'un altre amb classe **main**. En els mètodes tradicionals, seria menys directe ja que tindríem que realitzar diverses anomenades. Amb **.querySelector()** es fa directament només amb una.

El mètode **querySelector()** sempre retorna un només element: el primer que troba. En el cas de no coincidir amb cap, retorna null.

### **querySelectorAll()**

D'altra banda, el mètode **.querySelectorAll()** realitza una cerca d'elements en el DOM, només que com podrem intuir per eixe **All()**, retorna un  amb tots els elements que coincideixen amb el  CSS:

> **📌 JS**
> 

```html
// Obtiene todos los elementos con clase "info"
const infos = document.querySelectorAll(".info");

// Obtiene todos los elementos con atributo name="nickname"
const nicknames = document.querySelectorAll('[name="nickname"]');

// Obtiene todos los elementos <div> de la página HTML
const divs = document.querySelectorAll("div");
```

El mètode **.querySelectorAll()** sempre ens retornarà un array d'elements. En el cas de no trobar cap coincidencia, ens retornarà un array de 0 elements.

## **Navegar pel DOM**

En algunes ocasions en les que coneixem i controlamos perfectament l'estructura del codi HTML de la pàgina, ens pot resultar interessant utilitzar una forma de **navegar per la jerarquia** d'elements HTML. Per exemple, accedir a l'element que està a continuació d'un altre element del DOM, o accedir a l'últim element d'una estructura contenedora.

> **📌 Alarm**
> 

> **Alt!** Molt cura amb aquesta estratègia de moverse de forma jeràrquica. En general, sol ser una mala opció perquè si l'estructura DOM canvia, el nostre codi dejaría de funcionar correctament. Úsalo només si el teu DOM és una estructura sólida que no canvia i coneixes perfectament.

### **Navegar a través d'elements**

Les propietats que veurem a continuació retornen informació d'altres elements relacionats amb l'element en qüestió. En aquest cas estem treballant amb el tipus **ELEMENT**:

| Propietats d'elements HTML | Descripció | Retorna | Si està buit... |
| --- | --- | --- | --- |
| **.children** | Retorna una llista d'elements HTML fills. | **HTMLCollection** | Retorna **[ ]** |
| **.parentElement** | Retorna el pare de l'element. | **ELEMENT** | Retorna **null**. |
| **.firstElementChild** | Retorna el primer element fill. | **ELEMENT** | Retorna **null**. |
| **.lastElementChild** | Retorna l'últim element fill. | **ELEMENT** | Retorna **null**. |
| **.previousElementSibling** | Retorna l'element germà anterior. | **ELEMENT** | Retorna **null**. |
| **.nextElementSibling** | Retorna l'element germà següent. | **ELEMENT** | Retorna **null**. |

En primer lloc, tenim la propietat **children** que ens ofereix un **HTMLCollection** amb una llista d'elements HTML fills. Podríem accedir a qualsevol fill utilitzant els claudàtors d'array i seguir utilitzant altres propietats en el fill seleccionat.

- La propietat **firstElementChild** seria un accés ràpid a **children[0]**

- La propietat **lastElementChild** seria un accés ràpid a l'últim element fill.

Finalment, tenim les propietats **previousElementSibling** i **nextElementSibling** que ens retornen els elements germans anteriors o posteriors, respectivament. La propietat **parentElement** ens devolvería el pare de l'element en qüestió. En el cas de no existir algun d'aquests elements, ens devolvería **null**.

Observa el següent codi HTML. Si treballem sota aquest document HTML, i utilitzem el següent codi Javascript, podrem «navegar» per la jerarquia d'elements, **moviéndonos entre elements** pare, fill o germans:

> **📌 JS**
> 

```html
// Trabajando sobre <body>
document.body.children.length;  // 1
document.body.children;         // <div id="app">
document.body.parentElement;    // <html>

const app = document.querySelector("#app");

app.children;                   // [div.header, p, a]
app.firstElementChild;          // <div class="header">
app.lastElementChild;           // <a href="/">

const a = app.querySelector("a");

a.previousElementSibling;       // <p>
a.nextElementSibling;           // null
```

> **📌 HTML**
> 

```html
<html>
<body>
    <div id="app">
    <div class="header">
        <h1>Titular</h1>
    </div>
    <p>Párrafo de descripción</p>
    <a href="/">Enlace</a>
    </div>
</body>
</html>
```

### **Navegar a través de nodes**

Si volem hilar més fino, podem treballar a nivell d'elements de tipus **NODE**, utilitzant les següents propietats, que són equivalents a les anteriors, però treballant amb la unitat més bàsica: **nodes**.

| Propietats de nodes HTML | Descripció | Retorna | Si està buit... |
| --- | --- | --- | --- |
| **.childNodes** | Retorna una llista de nodes fills (inclou nodes de text i comentaris). | **HTMLCollection** | Retorna **null** |
| **.parentNode** | Retorna el node pare del node. | **NODE** | Retorna **null** |
| **.firstChild** | Retorna el primer node fill. | **NODE** | Retorna **null** |
| **.lastChild** | Retorna l'últim node fill. | **NODE** | Retorna **null** |
| **.previousSibling** | Retorna el node germà anterior. | **NODE** | Retorna **null** |
| **.nextSibling** | Retorna el node germà següent. | **NODE** | Retorna **null** |

Aquestes propietats solen ser més interesantes quan volem treballar sobre nodes de text, ja que fins i tot els espais en blanc entre elements HTML influyen. Volvamos a treballar sobre el document HTML anterior, però ara utilitzant aquest grup de propietats basades en **NODE**:

> **📌 JS**
> 

```html
// Trabajando sobre <body>
document.body.childNodes.length;  // 3
document.body.childNodes;         // [text, div#app, text]
document.body.parentNode;         // <html>

const app = document.querySelector("#app");

app.childNodes;                   // [text, div.header, text, p, text, a, text]
app.firstChild.textContent;       // "                             "
app.lastChild.textContent;        // "                             "

const a = app.querySelector("a");

a.previousSibling;                // #text
a.nextSibling;                    // #text
```

> **📌 HTML**
> 

```html
<html>
<body>
    <div id="app">
    <div class="header">
        <h1>Titular</h1>
    </div>
    <p>Párrafo de descripción</p>
    <a href="/">Enlace</a>
    </div>
</body>
</html>
```
