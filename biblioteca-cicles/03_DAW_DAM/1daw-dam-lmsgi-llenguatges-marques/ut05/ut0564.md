En JavaScript, **async** i **await** són una sintaxi per a escriure codi asíncron que és més senzill més fàcil de llegir i mantindre que les alternatives anteriors (com els callbacks i les promeses)

Introduït en **ECMAScript 2017**, **async/await** permet escriure codi secuencialment, en lloc d'imbricar callbacks o encadenar promeses.

Internament, **async/await** es basa en promeses. De fet **then/catch** i **async/await** són funcionalment equivalents.

Però **async/await** proporciona una sintaxi més cómoda d'usar, que imbricar promeses (és syntacic sugar per a simplificarnos la vida).

Una altra avantatge de **async/await** és que maneja els errors de manera forma més senzilla. Amb **async/await**, pot usar l'estructura **try/catch** (que és més familiar i fàcil d'entendre per als desenvolupadors).

## **Sintaxi d'async/await**

La sintaxi async/await es basa en dos paraules clau,

- **async** es col·loca abans de la funció per a indicar que conté codi asincrónic.

- **await** es col·loca abans de qualsevol operació que retorne una promesa per a indicar que el codi ha d'esperar a que es resolga la promesa abans de continuar.

**async**"**await**"

### **Async**

La paraula clau **async** s'usa per a declarar una funció asincrónica. Una funció marcada amb **async** sempre retorna una promesa.

- Si la funció retorna un valor, la promesa es resol amb eixe valor.

- Si la funció llança una excepció, la promesa es rebutja amb eixa excepció.
  !!!js "JS"
    

```html
async function miFuncion() {
  return 'Hola, mundo';
}

miFuncion().then(console.log); // 'Hola, mundo'
```

En l'exemple anterior, **miFuncion** és una funció asincrónica que retorna una promesa que es resol amb el valor 'Hola, món'.

### **Await**

La paraula clau **await** s'utilitza dins d'una funció async per a esperar la resolució d'una promesa.

**await** pausa l'ejecució de la funció async fins a que la promesa es resol o es rebutja.

> **📌 JS**
> 

```html
async function miFuncion() {
  let valor = await Promise.resolve('Hola, mundo');
  console.log(valor); // 'Hola, mundo'
}

miFuncion();
```

En aquest exemple, **await** s'usa per a esperar a que la promesa es resolga, i després es imprime el valor resultant.

<details markdown="1">

<summary>💡 Exemple bàsic</summary>

> **📌 JS**
> 

```html
async function obtenerDatos() {
  //funcion que simula devolver una promesa
  const respuesta = await FuncionQueDevuelvePromesa();

  console.log(respuesta);
}
```

- La funció **obtenerDatos** és asincrónica

- La **FuncionQueDevuelvePromesa** és una funció que simula retornar una promesa ( és la resposta d'una solicitud de xarxa).

- S'usa la paraula clau **await** per a esperar a que es resolga una promesa abans de continuar amb la següent línia de codi.

- Després de que es resol la promesa, podem fer el que vulguem amb resposta.

Açò seria equivalent a aquest codi, sense usar async i await

> **📌 JS**
> 

```html
function obtenerDatos() {
  // Llamar a la función que devuelve una promesa
  FuncionQueDevuelvePromesa()
    .then((respuesta) => {
      // Manejar la respuesta cuando la promesa se resuelve
      console.log(respuesta);
    })
    .catch((error) => {
      // Manejar errores si la promesa se rechaza
      console.error(error);
    });
}
```

</details>

## **Manejant errors**

Per a manejar **errors** en funcions **async**, pots usar **try/catch** en lloc de **.catch()** com l'harías amb promeses.

> **📌 JS**
> 

```html
async function obtenerDatos() {
  try {
    let respuesta = await fetch('https://api.example.com/data');
    if (!respuesta.ok) {
      throw new Error('Error en la respuesta de la red');
    }
    let datos = await respuesta.json();
    console.log(datos);
  } catch (error) {
    console.error('Error:', error);
  }
}

obtenerDatos();
```

En aquest exemple, si ocorre un error en qualsevol punt dins del bloc try, el flux de control passa al bloc catch, on es maneja l'error.
