D'igual forma que podem modificar els elements i estructura del DOM, **també podem canviar els seus estils**.

La manipulació d'estils en JavaScript pot hacerse a través de dos principals mètodes:

- **Modificació directa de l'estil**: Canviant els valors d'estil dels elements.

- **Manipulació de classes CSS**: Agregant, eliminant o alternant classes que defineixen els estils.

## **Modificació directa d'estils CSS.**

Amb JavaScript, pots canviar directament les propietats CSS d'un element. Açò es realitza utilitzant la propietat **style** de l'element i assignant valors a les propietats CSS que desees modificar.

| Comanda | Descripció |
| --- | --- |
| **element.style.propiedadCSS = 'valor'** | Canvia l'estil directament. |
| **element.style.propiedadCSS = 'valor'** | Canvia l'estil CSS directament en línia. |
| **element.style.color = 'blue'** | Canvia el color del text. |
| **element.style.backgroundColor = 'yellow'** | Canvia el color de fons de l'element. |
| **element.style.fontSize = '18px'** | Ajusta el mida de la font. |
| **element.style.width = '200px'** | Defineix l'ample de l'element. |
| **element.style.height = '100px'** | Defineix l'alçària de l'element. |
| **element.style.margin = '10px'** | Ajusta el marge de l'element. |
| **element.style.padding = '15px'** | Ajusta el farciment intern de l'element. |
| **element.style.border = '2px solid black'** | Estableix un vora per a l'element. |
| **element.style.borderRadius = '5px'** | Defineix el ràdio de les esquinas del vora. |
| **element.style.boxShadow = '2px 2px 10px gray'** | Aplica sombra a l'element. |

Vegem alguns exemples

**Color i Fons**Mides i Espais**Vores i Sombras**

Pots canviar les propietats de color i fons utilitzant les propietats color i backgroundColor.

> **📌 JS**
> 

```html
elemento.style.color = 'red';
elemento.style.backgroundColor = 'yellow';
```

Propietats com fontSize, width, height, margin, i padding permeten ajustar el mida i l'espaiat dels elements.

> **📌 JS**
> 

```html
elemento.style.fontSize = '18px';
elemento.style.width = '200px';
elemento.style.height = '100px';
elemento.style.margin = '10px';
elemento.style.padding = '15px';
```

Pots afegir vores i sombras utilitzant propietats com border, borderRadius, i boxShadow.

> **📌 JS**
> 

```html
elemento.style.border = '2px solid black';
elemento.style.borderRadius = '5px';
elemento.style.boxShadow = '2px 2px 10px gray';
```

## **Manipulació de Classes CSS**

La manipulació de classes és una tècnica més flexible i organitzada que evita llenar el codi amb estils en línia. Usem les propietats classList de l'element per a agregar, eliminar o alternar classes.

| Comanda | Descripció |
| --- | --- |
| **element.classList.add('classe')** | Agrega una classe a l'element. |
| **element.classList.remove('classe')** | Elimina una classe de l'element. |
| **element.classList.toggle('classe')** | Alterna una classe en l'element. |

**.add ( )**.remove ( )**.toggle ( )**

### **Afegir classe**

El mètode **add()** permet afegir una o més classes a un element, asegurándose de que no estiguen duplicades. Açò és útil per a aplicar estils o indicar un estat específic d'un element.

> **📌 JS**
> 

```html
elemento.classList.add('activo');
```

En aquest exemple, es afegeix la classe activo a l'element, el que podria, per exemple, canviar el seu color o fer-ho visible segons els estils definits en el teu arxiu CSS.

### **Eliminar classe**

El mètode remove() elimina una o més classes d'un element. És una forma pràctica de revertir un estat visual o funcional prèviament aplicat.

> **📌 JS**
> 

```html
elemento.classList.remove('invisible');
```

Ací, la classe invisible s'elimina de l'element, probablement fent que l'element torne a ser visible en la pàgina si eixa classe controlava la seua visibilitat.

### **Alternar classe**

El mètode toggle() afegeix la classe si no està present i l'elimina si ja l'està. Açò és especialment útil per a crear interaccions dinàmiques amb un només comanda.

> **📌 JS**
> 

```html
elemento.classList.toggle('resaltado');
```

Per exemple, aquest codi podria alternar un estil destacat en un botó al ser clicado, millorant l'experiència de l'usuari amb un comportament interactivo.

## **Ús de variables CSS**

Una altra forma de modificar l'estil d'un element és modificar una variable CSS. Aquesta variable actuará de forma conjunta amb les fulls CSS per a donar format a l'element.

| Comanda | Descripció |
| --- | --- |
| **document.documentElement.style.setProperty('--variable', 'valor')** | Modifica dinámicament el valor d'una variable CSS personalitzada. |

> **📌 JS**
> 

> Modificar variables amb JavaScript:

```html
document.documentElement.style.setProperty('--color-principal', 'lightcoral');
```

> **📌 CSS**
> 

> Definir variable en CSS:

```html
:root {
    --color-principal: lightblue;
}

#miElemento {
    background-color: var(--color-principal);
}
```

## **Lectura d'estils computats**

També podem obtindre l'estil actualment aplicat a un element, incloent els estils heretats o calculats pel navegador:

| Comanda | Descripció |
| --- | --- |
| **window.getComputedStyle(element).propietat** | Obté el valor calculat d'una propietat. |

> **📌 JS**
> 

```html
const estiloComputado = window.getComputedStyle(elemento);
console.log(estiloComputado.backgroundColor);
```

## **Aplicar transicions i animacions**

També podem usar JavaScript per a aplicar transicions i animacions CSS. Primer defineix les regles en una full d'estils CSS i després utilitza JavaScript per a modificar les propietats que desencadenan aquestes animacions.

Per exemple per a activar una transició,

> **📌 JS**
> 

> Desencadenar transició amb JavaScript

```html
elemento.style.backgroundColor = 'blue';
```

> **📌 CSS**
> 

> Definir transició en CSS

```html
#miElemento {
    transition: background-color 0.5s ease;
}
```
