En JavaScript les **Promeses** són un mecanisme fonamental per a **facilitar la programació asíncrona**.
Ens permeten gestionar operacions que no es completan inmediatament (com solicitudes de xarxa, operacions de lectura d'arxius o temporizadors) d'una manera més estructurada i menys propensa a errors en comparació amb els callbacks.
Una promesa és com un “contenidor” per a un valor que pot estar disponible ara, en el futuro, o mai (per això es anomena promesa)

## **Funcionament**

Una promesa és un objecte que representa el **possible èxit o fallada** d'una operació asíncrona.
Per a reflejar açò, durant la seua ejecució la promesa té una propietat **Estat**, que pot ser un dels següents:

- **Pendiente (Pending)**: Estat inicial. L'operació asíncrona encara no es ha completat.

- **Cumplida (Fulfilled)**: L'operació es ha completat amb èxit i la promesa té un valor resultant.

- **Rebutjada (Rejected)**: L'operació falló i la promesa té un motiu d'error.

## **Creació**

Podem crear una promesa utilitzant el constructor **Promise**. Aquest constructor pren una funció (anomenada executor) que rep dos funcions com arguments:

- **resolve** es anomena si l'operació és exitosa, i es canvia l'estat de la promesa a **cumplida**.

- **reject** es anomena si hi ha un error, i es canvia l'estat a **rebutjada**.

Aquests arguments són funcions que es anomenen per a canviar l'estat de la promesa.

> **📌 JS**
> 

> En aquest exemple es crea una promesa que rep els seus dos funcions **resolve** i **reject**. Simula fer una operació qualsevol amb èxit. I en funció del resultat de l'operació, es invoca a **resolve** o a **reject**.

```html
const miPromesa = new Promise((resolve, reject) => {
// Simulación de una operación asíncrona
let exito = true; // Simula el resultado de la operación

if (exito) {
    resolve('Operación exitosa');
} else {
    reject('Error en la operación');
}
});
```

## **Maneig**

Per a manejar el resultat d'una **promesa**, normalment s'utilitza els mètodes **.then()** i **.catch()**:

**.then()**.catch()**

> **📌 JS**
> 

```html
miPromesa.then(onFulfilled, onRejected)
```

Aquest mètode es anomena quan la promesa es compleix o es rebutja.

- **onFulfilled** és una funció que es anomena amb el valor de la promesa quan es compleix,

- **onRejected** es anomena amb el motiu del rechazo si la promesa falla.

> **📌 JS**
> 

```html
miPromesa.catch(onRejected)
```

Aquest mètode s'utilitza per a manejar errors. És un atajo per a **.then(null, onRejected)** i es anomena quan la promesa és rebutjada.

En aquest exemple es veu com s'usaría una promesa normalment:

> **📌 JS**
> 

```html
miPromesa
.then(result => {
    console.log(result); // 'Operación exitosa'
})
.catch(error => {
    console.error(error); // 'Error en la operación'
});
```

## **Encadenament**

Les promeses permeten encadenar múltiples **.then()** per a manejar seqüències d'operacions asíncrones.
Cada **.then()** retorna una nova promesa, el que facilita la composició de tasques asíncrones.

> **📌 JS**
> 

```html
miPromesa
.then(result => {
    console.log(result); // 'Operación exitosa'
    return 'Otro valor';
})
.then(otroResultado => {
    console.log(otroResultado); // 'Otro valor'
})
.catch(error => {
    console.error(error);
});
```

## **Promeses imbricades**

També es poden **imbricar** promeses dins d'altres promeses per a gestionar operacions que depenen de resultats anteriors.

> **📌 JS**
> 

```html
miPromesa
.then(result => {
    console.log(result); // 'Operación exitosa'
    return new Promise((resolve, reject) => {
    setTimeout(() => resolve('Operación asíncrona adicional'), 1000);
    });
})
.then(adicional => {
    console.log(adicional); // 'Operación asíncrona adicional'
})
.catch(error => {
    console.error(error);
});
```

> **📌 Important**
> 

> No obstant això, açò pot portar a codi difícil de llegir, per la qual cosa és preferible usar encadenament sempre que siga possible.

## **Mètodes estátics**

JavaScript proporciona diversos **mètodes estátics** en l'objecte **Promise** per a manejar múltiples promeses simultàniament.
Aquests mètodes retornen una nova promesa, que és una composició de les promeses que es passen com arguments.

**all ( )**race ( )**allSettled ( )**any ( )**

### **Promise.all ( )**

**Promise.all ( )** rep un iterable de promeses i retorna una nova promesa que es resol quan totes les promeses de l'iterable es compleixen. Si alguna promesa és rebutjada, la promesa devuelta serà rebutjada inmediatament.

> **📌 JS**
> 

```html
const promesa1 = Promise.resolve(1);
const promesa2 = Promise.resolve(2);
const promesa3 = Promise.resolve(3);

Promise.all([promesa1, promesa2, promesa3])
.then(results => {
    console.log(results); // [1, 2, 3]
})
.catch(error => {
    console.error(error);
});
```

### **Promise.race ( )**

**Promise.race ( )** retorna una promesa que es resol o es rebutja tan pronto com una de les promeses en l'iterable es resol o es rebutja.

> **📌 JS**
> 

```html
const promesaLenta = new Promise(resolve => setTimeout(() => resolve('Lenta'), 2000));
const promesaRápida = new Promise(resolve => setTimeout(() => resolve('Rápida'), 1000));

Promise.race([promesaLenta, promesaRápida])
.then(result => {
    console.log(result); // 'Rápida'
});
```

### **Promise.allSettled ( )**

**Promise.allSettled ( )** retorna una promesa que es resol quan totes les promeses de l'iterable han acabat (ja siga que es hagen cumplido o rebutjat)

> **📌 JS**
> 

```html
const promesa1 = Promise.resolve(1);
const promesa2 = Promise.reject('Error');
const promesa3 = Promise.resolve(3);

Promise.allSettled([promesa1, promesa2, promesa3])
.then(results => {
    console.log(results);
    // [{status: 'fulfilled', value: 1}, {status: 'rejected', reason: 'Error'}, {status: 'fulfilled', value: 3}]
});
```

Retorna un array d'objectes que descriuen el resultat de cada promesa.

### **Promise.any ( )**

**Promise.any ( )** retorna una promesa que es resol tan pronto com una de les promeses en l'iterable es resol.

> **📌 JS**
> 

```html
const promesa1 = Promise.reject('Error 1');
const promesa2 = Promise.reject('Error 2');
const promesa3 = Promise.resolve('Éxito');

Promise.any([promesa1, promesa2, promesa3])
.then(result => {
    console.log(result); // 'Éxito'
});
```

Si totes les promeses són rechazades, la promesa devuelta serà rebutjada amb una **AggregateError**.
