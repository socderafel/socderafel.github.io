## 1. Modificació de Text i Marcatge: textContent vs innerHTML

Quan necessitem alterar el contingut d'un element existent en el DOM, disposem de dues propietats principals:

1. **`element.textContent`:** Insereix o recupera el contingut pur de text pla de l'element i de tots els seus descendents. **No analitza el text com a HTML**: qualsevol caràcter especial com `<` o `>` es codifica automàticament com a entitat de text (`&lt;`), impedint qualsevol injecció de codi. És la propietat més ràpida i segura per a renderitzar dades.
2. **`element.innerHTML`:** Recupera o substitueix tot el marcatge HTML intern com una cadena de caràcters. Obliga el motor del navegador a invocar el seu analitzador HTML complet, la qual cosa comporta un cost de rendiment superior i un risc crític de **seguretat XSS** si el contingut prové d'entrades d'usuari no sanejades.

## 2. Manipulació d'Atributs i Atributs de Dades Personalitzades (data-*)

```javascript
const enllac = document.querySelector("#enllac-document");

// Mètodes universals d'atributs
enllac.setAttribute("href", "https://portal.edu.gva.es");
enllac.setAttribute("target", "_blank");
enllac.setAttribute("rel", "noopener noreferrer");

const teTitol = enllac.hasAttribute("title"); // Retorna booleà
enllac.removeAttribute("disabled");

// Atributs de Dades Personalitzades: data-* i la propietat dataset
// Si tenim en l'HTML: <div id="targeta" data-id-alumne="42" data-estat-matricula="activa"></div>
const targeta = document.querySelector("#targeta");

// Lectura automàtica en camelCase
console.log(targeta.dataset.idAlumne);       // "42"
console.log(targeta.dataset.estatMatricula); // "activa"

// Escriptura dinàmica
targeta.dataset.puntuacioTotal = "150"; // Afegeix data-puntuacio-total="150" a l'HTML
```

## 3. Gestió Dinàmica d'Estils i Classes amb classList

Tot i que és possible modificar estils en línia directament mitjançant `element.style.propiedad = valor` (ex: `targeta.style.backgroundColor = "red"`), la millor pràctica d'enginyeria és **no barrejar disseny en el codi JavaScript**. S'han de definir les classes visuals en els fitxers CSS i limitar el codi JavaScript a aplicar o retirar dites classes utilitzant l'objecte `classList`:

```javascript
const alerta = document.querySelector(".missatge-alerta");

// Afegir una o més classes
alerta.classList.add("activa", "urgent");

// Eliminar classes
alerta.classList.remove("oculta");

// Alternar una classe (si hi és la trau, si no hi és la posa)
// Molt emprat per a menús desplegables o modals
alerta.classList.toggle("obert");

// Comprovar si posseeix una classe (retorna booleà)
if (alerta.classList.contains("urgent")) {
  console.log("Atenció prioritària requerida!");
}

// Substituir una classe per una altra
alerta.classList.replace("estat-pendent", "estat-completat");
```
