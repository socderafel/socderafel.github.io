## **Continguts**

### **Manipulació de documents web JavaScript - DOM:**

- Introducció al DOM. (CE3.c)

- Accés al DOM. (CE3.c)

- Modificar el DOM. (CE3.d)

- Crear en el DOM. (CE3.d, CE3.e)

- Modificar CSS del DOM. (CE3.f)

- DOM dinàmic: asincronia, callbacks, promeses, async/await, ús de Fetch. (CE3.c, CE3.d)

**Qüestionari inicial**

1. Què és el DOM i per a què s'utilitza?

1. Per què una pàgina HTML es representa com un arbre?

1. Què relació hi ha entre HTML i JavaScript a través del DOM?

1. Com es seleccionan i accedeixen els elements d'un document web?

1. Com es creen, modifiquen i eliminen elements del DOM?

1. Com es modifiquen els estils d'una pàgina mitjançant JavaScript?

1. Què és l'asincronia i què eines s'utilitzen per a trabajar-la (callbacks, promeses, async/await)?
