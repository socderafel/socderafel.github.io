## 1. El Cicle de Creació i Connexió de Nodes

En el desenvolupament d'aplicacions web riques en client (com aplicacions SPA o catàlegs de comerç electrònic), és constant la necessitat de generar nous components d'interfície en memòria a partir de dades JSON rebudes d'un servidor.

```javascript
// 1. Crear el node d'element en memòria (desconnectat del DOM viu)
const novaTargeta = document.createElement("article");
novaTargeta.classList.add("targeta-modul");

// 2. Crear elements fills i assignar contingut i propietats
const titol = document.createElement("h3");
titol.textContent = "Desenvolupament d'Aplicacions Web";

const descripcio = document.createElement("p");
descripcio.textContent = "Cicle formatiu de grau superior d'informàtica.";

const boto = document.createElement("button");
boto.textContent = "Més informació";
boto.classList.add("btn-detall");

// 3. Acoblar la jerarquia interna amb el mètode modern append()
novaTargeta.append(titol, descripcio, boto);

// 4. Inserir en el document viu
const contenidor = document.querySelector("#cataleg-cursos");
contenidor.appendChild(novaTargeta);
```

### Mètodes Moderns d'Inserció i Eliminació
- **`parent.append(...nodesOMirallsText)`:** Permet afegir múltiples nodes i cadenes de text al mateix temps al final de l'element (substitueix l'antic `appendChild`, que només admetia un únic node d'objecte).
- **`parent.prepend(...)`:** Insereix els elements al principi del contenidor com a primers fills.
- **`element.before(...)` / `element.after(...)`:** Insereixen els elements just abans o després de l'element de referència (com a germans).
- **`element.remove()`:** Elimina l'element directament del DOM (substitueix el complex patró clàssic `element.parentNode.removeChild(element)`).

## 2. Optimització de Rendiment: DocumentFragment

Cada vegada que s'afig o modifica un element directament en l'arbre DOM viu del document, el navegador es veu obligat a executar dos processos interns costosos:
1. **Reflow (Reflux):** Càlcul geomètric de la mida i posició de tots els elements afectats a la pantalla.
2. **Repaint (Repintat):** Dibuix físic dels píxels en la targeta gràfica.

Si afegim 500 ítems d'una llista en un bucle fent `contenidor.appendChild(li)` en cada volta, provoquem 500 refluxos consecutius que congelen la interfície d'usuari (*UI freeze*).

### La Solució: `document.createDocumentFragment()`
Un **DocumentFragment** és un contenidor virtual lleuger que viu exclusivament en memòria. Quan afegim nodes a un fragment, no hi ha cost de reflux. Quan el fragment finalment s'insereix en el document viu mitjançant `contenidor.appendChild(fragment)`, **tots els seus fills es bolquen d'un sol colp i el fragment es buida**, produint exactament **un únic reflux i repintat**.

```javascript
const llistaAlumnes = document.querySelector("#llista-alumnat");
const fragment = document.createDocumentFragment();

dadesAlumnes.forEach(alumne => {
  const li = document.createElement("li");
  li.textContent = `${alumne.cognoms}, ${alumne.nom} - Nota: ${alumne.nota}`;
  li.dataset.id = alumne.id;
  fragment.appendChild(li); // No produeix cap repintat al DOM viu!
});

// Una sola operació d'inserció global
llistaAlumnes.appendChild(fragment);
```
