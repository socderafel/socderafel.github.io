## 1. El Format JSON (JavaScript Object Notation - RFC 8259)

El format **JSON** és l'estàndard *de facto* universal per a l'intercanvi de dades entre servidors d'aplicacions i clients web moderns. És un format de text lleuger, independent del llenguatge de programació i directament interpretable per motors de JavaScript:

```json
{
  "modul": "LMSGI",
  "horesSetmanals": 4,
  "actiu": true,
  "unitats": [
    { "id": 1, "titol": "XML i Llenguatges de Marques" },
    { "id": 2, "titol": "HTML5 i Sindicació Web" }
  ],
  "coordinacio": null
}
```

### Regles Estrictes de la Sintaxi JSON
- Totes les claus de propietat han d'anar **obligatòriament envoltades per cometes dobles** (`"clau"`).
- Les cadenes de text només admeten cometes dobles (les cometes simples `'` són invàlides).
- No s'admeten comes finals sobrants (*trailing commas*).
- Valors acceptats: `string`, `number`, `boolean`, `null`, `object`, `array`. (No admet funcions, dates natives ni `undefined`).
- Mètodes de conversió natius:
  - `JSON.stringify(objecteJS)`: Converteix una estructura de JavaScript en una cadena de text JSON.
  - `JSON.parse(textJSON)`: Deserialitza una cadena JSON transformant-la en un objecte en memòria.

## 2. La Fetch API i les Promeses (Promises)

Abans de la Fetch API, les peticions asíncrones depenien de l'objecte complex i enfarfegós `XMLHttpRequest` (base de l'antic model AJAX). La **Fetch API** utilitza el concepte de **Promeses** (*Promises*), que representen el resultat eventual (èxit o fallada) d'una operació asíncrona.

```javascript
// Petició GET clàssica amb promeses encadenades (.then)
fetch("https://api.ies-monastil.es/alumnat")
  .then(resposta => {
    if (!resposta.ok) {
      throw new Error(`Error HTTP: ${resposta.status} - ${resposta.statusText}`);
    }
    return resposta.json(); // Deserialitza el flux JSON de la resposta
  })
  .then(dades => {
    console.log("Dades d'alumnat rebudes:", dades);
  })
  .catch(error => {
    console.error("Fallada en la comunicació de xarxa:", error);
  });
```

## 3. Asincronia Moderna: async i await

La sintaxi `async` / `await` (introduïda en ES2017) permet escriure codi asíncron amb una claredat seqüencial idèntica al codi síncron tradicional, eliminant l'anomenat «Infern de Callbacks» (*Callback Hell*) i simplificant la gestió d'errors amb blocs estàndard `try...catch`:

```javascript
async function carregarDadesModul(idModul) {
  const zonaMissatges = document.querySelector("#zona-estat");
  zonaMissatges.textContent = "Carregant dades del servidor...";

  try {
    const resposta = await fetch(`https://api.ies-monastil.es/moduls/${idModul}`, {
      method: "GET",
      headers: {
        "Accept": "application/json",
        "Authorization": "Bearer token_jwt_autenticacio"
      }
    });

    if (!resposta.ok) {
      throw new Error(`Codi d'estat inesperat: ${resposta.status}`);
    }

    const modul = await resposta.json();
    renderitzarDetallsModul(modul);
    zonaMissatges.textContent = "Dades sincronitzades correctament.";

  } catch (error) {
    console.error("Error durant la petició:", error.message);
    zonaMissatges.textContent = "No s'ha pogut connectar amb el servidor educatiu.";
  }
}

// Petició POST enviant càrrega útil (Payload) en format JSON
async function registrarNouAlumne(dadesAlumne) {
  const resposta = await fetch("https://api.ies-monastil.es/alumnat", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify(dadesAlumne)
  });

  return await resposta.json();
}
```
