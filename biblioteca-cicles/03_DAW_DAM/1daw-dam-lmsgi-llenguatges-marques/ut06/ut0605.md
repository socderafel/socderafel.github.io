Validar documents és un pilar del RA4.
Les millors pràctiques actuals indiquen validar en tots els punts del flux de dades.

## **Validació XML**

Eines:

- `xmllint --schema fichero.xsd documento.xml`

- Oxygen XML Editor (GUI)

- Eines W3C online

## **Validació JSON**

Eines:

- AJV (Node.js)

- JSON Schema CLI

- JSONLint (només comprova bé format, no validesa)

Important: habilitar el mode estricte en AJV per a evitar esquemes ambiguos.

# **Associació de descripcions amb documents**

Associar la descripció amb el document significa indicar què esquema o definició ha d'utilitzar-se per a validar-lo.

## **En XML**

Amb **DTD**, l'associació es realitza mitjançant la declaració `<!DOCTYPE>`:

```html
<!DOCTYPE libro SYSTEM "libro.dtd">
```

Amb **XSD**, s'usa l'atribut `xsi:noNamespaceSchemaLocation`:

```html
<libro xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:noNamespaceSchemaLocation="libro.xsd">
```

Açò indica al validador on trobar la gramàtica.

## **En JSON**

En JSON no sol hacerse l'associació dins del document del mateix mode que en XML.
Normalment l'associació es realitza des de:

- l'aplicació,

- la documentació de la API,

- l'eina de validació,

- l'entorn de desenvolupament.

Exemple conceptual:

- arxiu `persona.json`

- arxiu `persona.schema.json`

L'aplicació sap que ha de validar `persona.json` amb `persona.schema.json`.
