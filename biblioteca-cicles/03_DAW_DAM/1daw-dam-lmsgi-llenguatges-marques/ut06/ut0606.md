## **Eines per a XML**

- `xmllint` (línia de comandes, estàndard Linux)

- Oxygen XML (editor professional)

- W3C XML Validator (web)

## **Eines per a JSON Schema**

- AJV: el validador més complet i actualitzat; suporta Draft 2020‑12 i funcions modernes.

- JSON Schema Store: repositorio oficial amb schemas de cientos d'eines.

- Validació JSON Schema integrada en VSCode.
