En XML, la informació es modela fonamentalment mitjançant **elements** i **atributs**. A més, per poder incloure caràcters reservats de la sintaxi o fragments de codi font sense interferir amb el parser, s'utilitzen **entitats predefinides** i **seccions CDATA**.

---

## 🥊 Elements vs. Atributs: El Dilema del Dissenyador

- **Element:** Contenidor de dades que pot allotjar text, altres elements niats o romandre buit.
- **Atribut:** Propietat auxiliar situada dins de l'etiqueta d'obertura que afig metadades sobre l'element. El seu valor ha d'anar **obligatòriament entre cometes** (`"` o `'`).

```xml
<!-- Enfocament basat en atributs: -->
<persona dni="12345678A" nom="Carles" edat="25"/>

<!-- Enfocament basat en elements (Molt més recomanat): -->
<persona id="12345678A">
    <nom>Carles</nom>
    <edat>25</edat>
</persona>
```

> **Bona Pràctica de Disseny:** Reserva els **atributs** només per a identificadors únics (`id`), metadades auxiliars o unitats de mesura (`unitat="kg"`). Utilitza **elements** per a les dades pròpiament dites, ja que els elements admeten subestructures niades, múltiples ocurrències i són molt més fàcils d'ampliar en el futur.

---

## 🔣 Les Cinc Entitats Predefinides d'XML

Certes grafies formen part de la sintaxi de control d'XML. Si volem escriure'ls com a text literal hem d'emprar les seues **entitats de referència**:

| Caràcter | Nom | Entitat XML Obligatòria |
| :---: | :--- | :--- |
| `<` | Menor que (*Less Than*) | `&lt;` |
| `>` | Major que (*Greater Than*) | `&gt;` |
| `&` | Et / Ampersand | `&amp;` |
| `"` | Cometes dobles (*Quote*) | `&quot;` |
| `'` | Apòstrof (*Apostrophe*) | `&apos;` |

---

## 📜 Seccions de Text Literal: `<![CDATA[ ... ]]>`

Si hem d'incloure un bloc llarg de text que conté molts símbols `<` o `&` (per exemple, un fragment de codi font Java o una consulta SQL), substituir cada caràcter per entitats fa el document il·legible.
Les **seccions CDATA** (*Character Data*) indiquen al parser que tot el que hi ha dins s'ha d'interpretar com a text pur, sense analitzar cap etiqueta:

```xml
<script_sql>
<![CDATA[
    SELECT * FROM usuaris WHERE edat > 18 AND saldo < 1000;
]]>
</script_sql>
```
