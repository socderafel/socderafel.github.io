## **Què és un llenguatge de marques de propòsit general?**

Un **llenguatge de marques de propòsit general** és aquell que no està restringido a un només àmbit d'ús, sinó que pot adaptar-se per a representar **informació estructurada** en múltiples contextos, gràcies al seu **disseny extensible** i **neutral**.

**Característiques principals**:

- **Versatilitat**: poden aplicar-se a múltiples àrees (documents, bases de dades, aplicacions web, etc.).

- **Extensibilitat**: permeten crear noves etiquetes segons les necessitats.

- **Separació de contingut i presentació**: defineixen l'estructura i el significat, deixant l'aspecte visual a altres llenguatges o eines.

- **Estandarizació**: solen estar regulats per organismes com el W3C.

## **XML com estàndard de propòsit general**

### **Característiques clau**

**Característiques clau de XML**:

- **Extensible**: es poden definir etiquetes personalitzades.

- **Estructurat**: jerarquia clara entre elements.

- **Portàtil**: pot ser llegit i escrit en múltiples plataformes.

- **Validable**: mitjançant DTD o XML Schema.

- **Llegible**: tant per humans com per màquines.

- **Transformable**: mitjançant XSLT o eines personalitzades.

> **📌 Xml**
> 

```html
<cliente>
    <nombre>Lucía</nombre>
    <telefono>654987321</telefono>
    <activo>true</activo>
</cliente>
```

### **Àmbits d'aplicació**

**Àmbits d'aplicació de XML:**

| Context | Exemple d'ús de XML |
| --- | --- |
| **Comunicacions entre sistemes** | Serveis web amb SOAP, intercanvi de dades entre empreses (EDI, UBL). |
| **Configuració de programari** | Arxius `.xml` per a configurar entorns Java, aplicacions Android, frameworks web. |
| **Emmagatzematge de dades** | Bases de dades XML natives (eXistDB, BaseX), exportacions complexes. |
| **Publicació de continguts** | Articles científics, llibres electrònics amb DocBook o TEI. |
| **Representació d'informació tècnica** | Llenguatges com SVG, MathML o GML (geolocalizació) estan basats en XML. |
| **Interoperabilitat en administració pública** | Estructura de factures electròniques (Facturae), catálogos de dades oberts. |
