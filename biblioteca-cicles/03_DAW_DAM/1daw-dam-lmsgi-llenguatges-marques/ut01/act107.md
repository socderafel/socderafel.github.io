## **Exercici 1**

A continuació es mostra un document XML complet. Identifica en ell totes les **parts de la seua estructura** que pugues trobar i respon a les preguntes.

> **📌 Document XML**
> 

```html
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<!DOCTYPE peliculas>
<!-- Documento con las películas del festival -->
<peliculas>
    <pelicula id="F-01" genero="ciencia ficción">
        <titulo>Origen</titulo>
        <director>Christopher Nolan</director>
        <precio divisa="EUR">14.95</precio>
    </pelicula>
    <pelicula id="F-02">
        <titulo>El viaje de Chihiro</titulo>
        <director>Hayao Miyazaki</director>
        <director>Joe Hisaishi</director>
        <precio divisa="EUR">10.50</precio>
    </pelicula>
</peliculas>
```

1. Escriu les línies que formen el **pròleg** i indica què informació aporta cada una d'elles.

1. Quin és el **element arrel** o exemplar? Per què un document XML només pot admetre un?

1. Señala un exemple de cada un dels següents components en el document: **etiqueta d'obertura**, **etiqueta de tancament**, **element buit** (si existeix), **atribut** i **comentari**.

1. Com es denomina la relació entre l'element `<peliculas>` i l'element `<pelicula>`? I entre `<pelicula>` i `<titulo>`?

## **Exercici 2**

Els següents documents XML **no compleixen alguna de les regles sintàctiques** del llenguatge. Per a cada un d'ells:

- Reescribe el document corregit.

## **Exercici 3**

El següent document XML conté **diverses regles sintàctiques** respetades alhora. Léelo amb atenció i respon.

> **📌 Document XML**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<conciertos>
    <concierto fecha="2026-12-05">
        <grupo>Vetusta Morla</grupo>
        <ciudad>Valencia</ciudad>
        <precio>35</precio>
    </concierto>
    <concierto>
        <grupo>Carolina Durante</grupo>
        <ciudad>Madrid</ciudad>
    </concierto>
</conciertos>
```

1. Indica la **regla sintáctica** que està bé aplicada en l'element `<concierto fecha="2026-12-05">` i explica per què el seu valor va entre cometes.

1. Explica per què el segon `<concierto>` està bé format encara que li falte l'element `<precio>`.

1. Què regla sintáctica permet afirmar que els dos elements `<concierto>` són germans i que tots dos descienden de l'element arrel?

1. Escriu aquest mateix document reemplazant cada element i atribut per altres equivalents de la teua elecció, sense canviar l'estructura, de mode que siga cumplent totes les regles sintàctiques.
