## **Què és un espai de noms?**

Un **espai de noms** (*namespace*) és un mecanisme de XML que permet diferenciar elements i atributs que tenen el mateix nom però pertanyen a **vocabularios distints**.

El seu objectiu principal és **evitar conflictos de noms** quan es combinen documents XML procedentes de diferents aplicacions.

Per exemple, l'etiqueta `<carta>` pot representar coses completament distintes:

- Una carta d'una **baralla**.

- La carta (menú) d'un **restaurant**.

Si tots dos documents es uneixen en un només, XML no sabría a quin d'elles pertany cada element.

### **El problema sense namespaces**

Suposem els següents documents XML.

> **📌 Baralla**
> 

```html
<carta>
    <palo>Corazones</palo>
    <numero>7</numero>
</carta>
```

> **📌 Restaurant**
> 

```html
<carta>
    <carnes>
        <solomillo precio="13.60"/>
    </carnes>

    <pescados>
        <merluza precio="15.85"/>
    </pescados>
</carta>
```

Si tots dos documents es fusionan obtenim alguna cosa semblant a açò:

> **📌 Conflicto de noms**
> 

> XML no sap si una etiqueta `<carta>` fa referència a una carta d'una baralla o a la carta d'un restaurant.

> **📌 Document Complet**
> 

```html
<ejemplo>

    <carta>
        <palo>Corazones</palo>
        <numero>7</numero>
    </carta>

    <carta>
        <carnes>
            <solomillo precio="13.60"/>
        </carnes>

        <pescados>
            <merluza precio="15.85"/>
        </pescados>
    </carta>

</ejemplo>
```

Encara que el document és correcte des del punt de vista sintáctic, existeix un **problema semàntic**: apareixen dos elements anomenats `<carta>` que representen conceptes completament distints.

### **La solució: utilitzar namespaces**

Per a evitar aquesta ambigüetat s'utilitzen **espais de noms**. Cada vocabulari rep un **prefix**, que identifica el context al que pertany cada element.

> **📌 Prefijos**
> 

```html
<baraja:carta>
    <baraja:palo>Corazones</baraja:palo>
    <baraja:numero>7</baraja:numero>
</baraja:carta>

<restaurante:carta>
    <restaurante:carnes>
        <restaurante:solomillo precio="13.60"/>
    </restaurante:carnes>
</restaurante:carta>
```

Ara ja no existeix cap duda sobre el significat de cada etiqueta.

### **Noms cualificats (QName)**

Quan una etiqueta està precedida per un prefix separat mitjançant dos punts (`:`), rep el nom de **nom cualificado** (**Qualified Name** o **QName**).

Per exemple:

> **📌 Text**
> 

```html
baraja:palo
```

En aquesta etiqueta:

- **baralla** és el prefix del namespace.

- **palo** és el nom de l'element.

## **Definició d'espais de noms**

Abans d'utilitzar un prefix és necessari declarar-lo mitjançant l'atribut especial `xmlns`. Normalment aquesta declaració es realitza en l'element arrel del document.

> **📌 Declaració namespace**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>

<ejemplo
    xmlns:baraja="https://www.ejemplo.com/baraja"
    xmlns:rest="https://www.ejemplo.com/restaurante">

    <baraja:carta>
        <baraja:palo>Corazones</baraja:palo>
        <baraja:numero>7</baraja:numero>
    </baraja:carta>

    <rest:carta>
        <rest:carnes>
            <rest:solomillo precio="13.60"/>
        </rest:carnes>
    </rest:carta>

</ejemplo>
```

El namespace està compost per un definició `xmlns`, un prefix i una uri, tomamos xmlns:baralla="https://www.ejemplo.com/baraja" d'exemple.

**xmlsn**

La paraula `xmlns` proviene de:

- **xml** → XML

- **ns** → Namespace

**Prefix**

A l'indicar el prefix estem indicant que totes les etiquetes del qual prefix siga `baraja:` pertanyen a l'espai de noms identificat per eixa URI.

**URI**

Cada namespace s'identifica mitjançant una **URI** (*Uniform Resource Identifier*), en aquest cas **https://www.ejemplo.com/baraja**. Normalment té aspecte d'adreça web.

No obstant això, **no és necessari que existisca realment**. La seua funció és únicament identificar de forma única un vocabulari XML.

**Declaració en l'element arrel o en un element concret**

El namespace pot declarar-se en un element arrel o en un element en concret, com podem veure en els següents exemples:

Element raízElemento concret

```html
<ejemplo xmlns:baraja="https://www.ejemplo.com/baraja">

    <baraja:carta>
        <baraja:palo>Corazones</baraja:palo>
    </baraja:carta>

</ejemplo>
```

```html
<ejemplo>

    <baraja:carta
        xmlns:baraja="https://www.ejemplo.com/baraja">

        <baraja:palo>Corazones</baraja:palo>

    </baraja:carta>

</ejemplo>
```

### **Bones pràctiques**

- Utilitzar prefijos cortos i descriptivos.

- Declarar els namespaces en l'element arrel quan siga possible.

- No reutilitzar un mateix prefix per a espais de noms distints.

- Utilitzar una URI única per a cada vocabulari.

> **📌 Idea clau**
> 

> Els **namespaces** no modifiquen el funcionament de XML.

> Simplement permeten distingir elements amb el mateix nom que pertanyen a vocabularios diferents.

> **📌 Exemple Complet**
> 

> Els namespaces són molt habituals quan un document XML combina diferents llenguatges de marques.

> Per exemple, un document pot contindre elements XHTML i SVG simultàniament.

```html
<documento
    xmlns:html="http://www.w3.org/1999/xhtml"
    xmlns:svg="http://www.w3.org/2000/svg">

    <html:p>Ejemplo de gráfico:</html:p>

    <svg:svg width="120" height="120">
        <svg:circle
            cx="60"
            cy="60"
            r="40"
            fill="steelblue"/>
    </svg:svg>

</documento>
```

En aquest document:

- Els elements `html:*` pertanyen al vocabulari **XHTML**.

- Els elements `svg:*` pertanyen al vocabulari **SVG**.

Gràcies als namespaces, tots dos vocabularios poden convivir en un mateix document XML sense produir conflictos de noms.
