## **Ejercicio 1**

**Completa** la següent taula:

| Llenguatge | Descripció | Propòsit | Estructura | Sintaxi | Flexibilitat | Compatibilitat |
| --- | --- | --- | --- | --- | --- | --- |
| **HTML** (HyperText MarkupLanguage) |  |  |  | No és estrictament sensible a majúscules/minúscules. Etiquetes d'obertura i tancament no sempre són obligatòries. |  |  |
| **XML** (eXtensible Markup Language) |  |  |  |  |  | Àmplia compatibilitat amb diferents sistemes i aplicacions per a l'intercanvi de dades. |
| **XHTML** (Extensible HyperText Markup Language) |  |  | Usa les mateixes etiquetes que HTML però seguint les regles de XML. |  |  |  |
| **RSS** (Really Simple Syndication) | Llenguatge de marques basat en XML utilitzat per a la sindicació de contingut web, com blogs o notícies. |  |  |  |  |  |
| **SVG** (Scalable Vector Graphics) |  | Crear gràfics escalables i interactivos. |  |  |  |  |
| **MathML** (Mathematical Markup Language) | Llenguatge XML per a representar expressions matemàtiques. |  |  |  |  |  |
| **Markdown** |  |  |  | Sintaxi simple mitjançant caràcters com `#`, `*`, `>` o ```. |  |  |
| **JSON** (JavaScript Object Notation) |  |  |  |  | Molt compatible amb aplicacions web, APIs i la majoria de llenguatges de programació. |  |
