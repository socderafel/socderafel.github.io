## **Ejercicio 1**

Suposem dos documents que organitzen la informació sobre els professors i els alumnes del Cicle Formativo.

> **📌 XML d'alumnes**
> 

```html
<?xml version="1.0" encoding="iso-8859-1" standalone="yes"?>
<!DOCTYPE alumnos>
<alumnos>
    <nombre>Fernando Fernández González</nombre>
    <nombre>Isabel González Fernández</nombre>
    <nombre>Ricardo Martínez López</nombre>
</alumnos>
```

> **📌 XML de professors**
> 

```html
<?xml version="1.0" encoding="iso-8859-1" standalone="yes" ?>
<!DOCTYPE profesores>
<profesores>
    <nombre>Pilar Ruiz Pérez</nombre>
    <nombre>Tomás Rodríguez Hernández</nombre>
</profesores>
```

Si uniéramos els dos documents en un únic, sense usar espais de noms, no es distinguirían els professors dels alumnes ja que en els dos casos l'etiqueta  es anomena igual.
Per a resolver-lo necessitem definir un espai de noms per a cada context.

## **Ejercicio 2**

El següent document XML presenta conflictos en la nomenclatura dels seus elements. Fent ús dels espais de noms, soluciona aquests conflictos.

> **📌 Xml**
> 

```html
<?xml version="1.0" encoding="iso-8859-1" standalone="yes" ?>
<!DOCTYPE registros>
<registro>
    <persona>
        <nombre>Juan Pérez</nombre>
        <edad>30</edad>
        <direccion>
            <calle>Calle Falsa 123</calle>
            <ciudad>Madrid</ciudad>
        </direccion>
    </persona>
    <producto>
        <nombre>Ordenador Portátil</nombre>
        <precio>1200</precio>
        <caracteristicas>
            <procesador>Intel Core i7</procesador>
            <ram>16GB</ram>
        </caracteristicas>
    </producto>
</registro>
```
