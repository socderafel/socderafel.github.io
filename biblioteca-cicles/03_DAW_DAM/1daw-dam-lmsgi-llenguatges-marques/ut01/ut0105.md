En el tractament professional d'XML és indispensable distingir entre dos nivells de correcció: el **Bon Format sintàctic (*Well-Formed XML*)** i la **Validesa semàntica (*Valid XML*)**.

---

## ⚖️ Bon Format vs. Validesa

```
┌────────────────────────────────────────────────────────┐
│  DOCUMENT BEN FORMAT (Well-Formed XML)                 │
│  - Compleix totes les regles sintàctiques d'XML.       │
│  - Element arrel únic, etiquetes tancades, atributs    │
│    entre cometes, majúscules coincidents.              │
│  - Si NO està ben format, l'SGBD o Parser el REBUTJA   │
│    immediatament amb un Fatal Error.                   │
├────────────────────────────────────────────────────────┤
│  DOCUMENT VÀLID (Valid XML)                            │
│  - És obligatòriament BEN FORMAT.                      │
│  - A més, s'ajusta estrictament a l'esquema d'un       │
│    patró formal definit en un document DTD o XSD.      │
│  - Comprova tipus de dades (enters, dates), camps      │
│    obligatoris, nombre màxim d'elements, etc.          │
└────────────────────────────────────────────────────────┘
```

> **Exemple de la vida real:** 
> - Un text en valencià està "ben format" si compleix la gramàtica i ortografia bàsica (paraules correctes, punts i comes).
> - Està "vàlid" si, a més de complir la gramàtica, s'ajusta exactament al formulari oficial d'una instància administrativa de la Conselleria d'Educació.

---

## 🌳 El Model d'Arbre Lògic d'XML

Els parsers processen el document XML com una estructura jeràrquica d'**arbre en memòria (*DOM Tree*)**:
- **Node Document (Arrel de l'Arbre):** Representa tot el fitxer.
- **Node Element Arrel:** El primer element (`<cataleg>`).
- **Nodes Elements Fills:** branques de l'arbre (`<llibre>`).
- **Nodes de Text:** Les fulles terminals que contenen la informació (`Tirant lo Blanc`).
- **Nodes Atribut:** Propietats associades als elements.
