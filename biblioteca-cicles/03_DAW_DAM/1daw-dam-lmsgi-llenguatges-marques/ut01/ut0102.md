XML és un llenguatge d'una **disciplina sintàctica estricta**. A diferència dels navegadors web clàssics que intentaven "perdonar" errors d'etiquetes mal tancades en HTML, un processador XML (**XML Parser**) està obligat pel W3C a aturar-se immediatament llançant un error fatal (*Fatal Error*) si es vulnera qualsevol de les regles de bon format.

---

## 🏛️ Les 5 Regles d'Or d'un Document XML Ben Format

### 1. El Pròleg XML (Declaració)
Ha d'aparèixer a la primera línia del fitxer, començant exactament al byte zero (sense espais previs):
```xml
<?xml version="1.0" encoding="UTF-8"?>
```
- `version`: Normalment `"1.0"` (la versió universal estàndard).
- `encoding`: Especifica el joc de caràcters (recomanat sempre `"UTF-8"` per admetre accents i caràcters valencians).
- `standalone`: Opcional (`"yes"` o `"no"`), indica si depèn de definicions d'esquema externes.

### 2. Element Arrel Únic (*Root Element*)
Tot document XML ha de tindre **exactament un únic element contenidor arrel** que embolcalla tota la resta de dades:
```xml
<institut> <!-- Element Arrel Únic -->
    <curs>1r DAW</curs>
    <curs>1r DAM</curs>
</institut>
```

### 3. Tancament Estricte d'Etiquetes
Tota etiqueta que s'obre ha de tancar-se obligatòriament. Els elements buits han d'utilitzar la sintaxi d'autotancament:
```xml
<nom>Ausiàs March</nom>
<separador/> <!-- Element buit autotancat -->
```

### 4. Niament Correcte (Prohibit el Solapament)
Les etiquetes s'han de tancar en ordre invers al que s'han obert (estructura d'arbre net):
- ✅ *Correcte:* `<a><b>Contingut</b></a>`
- ❌ *Incorrecte:* `<a><b>Contingut</a></b>`

### 5. Sensibilitat a Majúscules i Minúscules (*Case Sensitive*)
XML distingeix escrupolosament entre lletres majúscules i minúscules:
- `<Producte>` i `</producte>` generen un error fatal immediat. L'etiqueta de tancament ha de coincidir lletra per lletra: `</Producte>`.
