## 1. Mètodes Funcionals d'Iteració d'Arrays (Immutabilitat)

En el desenvolupament web contemporani, s'evita la mutació directa de les estructures de dades en favor de mètodes funcionals purs que retornen una nova còpia de l'array sense alterar l'original:

```javascript
const alumnes = [
  { id: 1, nom: "Joan Garcia", nota: 4.5, cicle: "DAW" },
  { id: 2, nom: "Anna Pons", nota: 8.7, cicle: "DAM" },
  { id: 3, nom: "Marc Valls", nota: 9.2, cicle: "DAW" },
  { id: 4, nom: "Sara Martí", nota: 3.8, cicle: "ASIX" }
];

// 1. Array.prototype.filter() -> Filtra elements segons un predicat booleà
const aprovats = alumnes.filter(a => a.nota >= 5.0);

// 2. Array.prototype.map() -> Transforma cada element en un nou format
const etiquetes = alumnes.map(a => `${a.nom} (${a.cicle}): ${a.nota >= 5 ? 'APTE' : 'NO APTE'}`);

// 3. Array.prototype.reduce() -> Acumula els elements en un sol valor escalar o estructura
const notaMitjana = alumnes.reduce((acumulador, alumne) => acumulador + alumne.nota, 0) / alumnes.length;

// 4. Array.prototype.find() i findIndex() -> Cerca el primer element que compleix la condició
const alumneDestacat = alumnes.find(a => a.nota > 9.0); // Retorna Marc Valls

// 5. Array.prototype.some() i every() -> Verificacions booleanes globals
const hiHaSuspensos = alumnes.some(a => a.nota < 5.0); // true
const totsAprovats = alumnes.every(a => a.nota >= 5.0); // false
```

## 2. Objectes Literals Avançats i Millores Sintàctiques ES6

ECMAScript va simplificar la declaració d'objectes literals permetent la sintaxi reduïda de propietats (*Property Shorthand*) i noms de propietat calculats (*Computed Property Names*):

```javascript
const titol = "Llenguatges de Marques";
const hores = 96;
const clauDinamica = "estat_curs";

const curs = {
  titol,            // Equival a titol: titol
  hores,            // Equival a hores: hores
  [clauDinamica]: "ACTIU", // Propietat computada dinàmica en temps d'execució
  
  // Mètode abreujat (Shorthand method)
  descriure() {
    return `${this.titol} (${this.hores}h) - Estat: ${this.estat_curs}`;
  }
};
```

## 3. Desestructuració (Destructuring) i Operador Spread

La desestructuració permet extreure propietats d'objectes o posicions d'arrays directament en variables independents de forma declarativa:

```javascript
// Desestructuració d'Objectes
const usuari = { id: 101, username: "cferris", rol: "DOCENT", email: "cferris@ies.edu" };
const { username, rol, email, ciutat = "València" } = usuari;
console.log(username); // "cferris"
console.log(ciutat);   // "València" (valor per defecte)

// Desestructuració en Paràmetres de Funció
function renderitzarTargeta({ username, rol }) {
  return `<div class="targeta"><h3>${username}</h3><span class="badge">${rol}</span></div>`;
}

// Operador Spread (...) per a Arrays i Objectes
const notesParcials1 = [7, 8, 9];
const notesParcials2 = [6, 10];
const totesLesNotes = [...notesParcials1, ...notesParcials2]; // [7, 8, 9, 6, 10]

// Clonació no profunda d'Objectes (Shallow Copy)
const usuariModificat = {
  ...usuari,
  rol: "COORDINADOR_TIC", // Sobreescriu la propietat rol
  actiu: true
};
```
