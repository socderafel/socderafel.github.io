## 1. Tipus de Funcions i Mecanismes de Definició

En JavaScript, les funcions són **ciutadans de primera classe** (*First-Class Citizens*): es poden tractar com qualsevol altre valor, assignar a variables, passar com a arguments a altres funcions i retornar des d'altres funcions.

Existeixen tres maneres principals de definir una funció:

```javascript
// 1. Declaració de Funció (Function Declaration)
// Pateix Hoisting: es pot invocar abans de la seua posició en el codi
console.log(sumar(2, 3)); // Retorna 5!
function sumar(a, b) {
  return a + b;
}

// 2. Expressió de Funció (Function Expression)
// Assignada a una variable const/let: NO pateix hoisting
const multiplicar = function(a, b) {
  return a * b;
};

// 3. Funció Fletxa (Arrow Function - ES6)
// Sintaxi compacta amb retorn implícit en una sola expressió
const dividir = (a, b) => a / b;
```

---

## 2. Anatomia de les Funcions Fletxa (Arrow Functions)

Les funcions fletxa (`=>`) no són només una abreviatura estètica; tenen un impacte transcendental en la vinculació del context d'execució:

1. **Retorn Implícit:** Si el cos de la funció no utilitza claus `{ }`, s'avalua i retorna automàticament el resultat de la instrucció única (`const doble = x => x * 2;`). Si volem retornar un objecte literal cal tancar-lo entre parèntesis: `const creaPunt = (x, y) => ({ x, y });`.
2. **Àmbit Lèxic de `this` (Lexical this):** Les funcions clàssiques `function` defineixen el seu propi valor de `this` segons com han estat invocades en temps d'execució. **Les funcions fletxa no tenen el seu propi `this`**: capturen el valor de `this` de l'àmbit que les envolta en el moment de la seua definició (àmbit lèxic), solucionant el típic problema de pèrdua de context en temporitzadors i controladors d'esdeveniments.
3. **Absència d'`arguments`:** Les funcions fletxa no disposen de l'objecte pseudovector `arguments`; s'han d'utilitzar paràmetres rest moderns (`...params`).

## 3. Paràmetres per Defecte i Operador Rest

```javascript
// Paràmetres per Defecte
function calcularPreuFinal(preuBase, iva = 0.21, descompte = 0) {
  return (preuBase * (1 + iva)) - descompte;
}
console.log(calcularPreuFinal(100)); // Aplica iva=0.21 i descompte=0 automàticament

// Paràmetres Rest (...rest)
// Agrupa un nombre indefinit d'arguments en un autèntic Array de JavaScript
function calcularMitjana(nomMòdul, ...notes) {
  const suma = notes.reduce((acc, curr) => acc + curr, 0);
  const mitjana = notes.length > 0 ? (suma / notes.length).toFixed(2) : 0;
  return `Mitjana de ${nomMòdul}: ${mitjana}`;
}
console.log(calcularMitjana("LMSGI", 8.5, 9.0, 7.5, 10)); // notes és [8.5, 9.0, 7.5, 10]
```
