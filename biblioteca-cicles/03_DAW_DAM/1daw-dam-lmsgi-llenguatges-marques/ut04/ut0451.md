A mesura que treballem en el nostre codi, es fa necessari agrupar valors en una mateixa variable, per a representar conjunts de dades amb certa relació entre sí. Per a això, tenim l'opció de crear **objectes**, o unes variables més senzilles anomenades **arrays**.

Un array és una col·lecció o agrupació d'elements en una mateixa variable, cada un d'ells ubicado per la posició que ocupa en l'array. En Javascript, es poden definir de diverses formes:

| Constructor | Descripció |
| --- | --- |
| new Array(size) | Crea un array buit de mida size. Els seus valors no estan definits, però són . |
| new Array(e1, e2...) | Crea un array amb els elements indicats. |
| [e1, e2...] | Simplement, els elements dins de claudàtors: []. **Notació preferida**. |

Per exemple, podríem tindre un array que en la seua primera posició tenim el  'a', en la segona el  'b' i en la tercera el  'c'. En Javascript, açò es crearía d'aquesta forma:

> **📌 JS**
> 

```html
// Forma tradicional (no se suele usar en Javascript)
const letters = new Array("a", "b", "c");   // Array con 3 elementos
const letters = new Array(3);               // Array vacío de tamaño 3

// Mediante literales (notación preferida)
const letters = ["a", "b", "c"];  // Array con 3 elementos
const letters = [];               // Array vacío (0 elementos)
const letters = ["a", 5, true];   // Array mixto (String, Number, Boolean)
```

> **📌 Important**
> 

> Al contrari que molts altres llenguatges de programació, Javascript permet que es puguen realitzar arrays de **tipus mixt**, no sent obligatori que tots els elements siguen del mateix tipus de dada.

> **📌 Nota**
> 

> Al crear un array amb `new Array(size)` hi ha diversos matices que merece la pena mencionar. El primer, si només es indica un paràmetre numèric `size`, Javascript crearà un array buit de `size` elements. És a dir, no és el mateix que `const a = [3]`, on creem un array amb un element `3`. D'altra banda, `new Array(size)` realment crea un array buit que encara no ha sigut rellenado amb res (*açò fa que siga més óptimo per a arrays grans*) i encara que és equivalent, no és exactament igual `new Array(3)` que `[undefined, undefined, undefined]`.

## **Accés a elements de l'array**

A l'igual que els string, saber el número elements que té un array és molt senzill. Només cal accedir a la propietat `.length`, que ens retornarà el número d'elements existents en un array:

| Forma | Descripció |
| --- | --- |
| .length | Propietat que retorna el número d'elements de l'array. |
| [pos] | Operador que retorna (o modifica) l'element número pos de l'array. |
| .at(pos) | Mètode que retorna l'element en la posició pos. Números negativos en ordre invers. |
| .with(pos, el) | Mètode que crea una còpia i modifica l'element de la posició `pos` amb `el`. |

Operador []Mètode .at()Mètode .with

### **L'operador []**

D'altra banda, si el que volem és accedir a un element específic de l'array, no hi ha més que utilitzar l'operador `[]`, a l'igual que el podríem fer amb els  per a accedir a un caràcter concret. En aquest cas, accedim a la posició de l'element que volem recuperar sobre l'array:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c"];

letters.length;   // 3
letters[0];       // 'a'
letters[2];       // 'c'
letters[5];       // undefined
```

Recorda que les posicions comencen a comptar des de `0` i que si intentem accedir a una posició que no existeix (*major del mida de l'array*), ens retornarà un UNDEFINED.

L'operador `[]` no només ens permet obtindre o accedir a un element de l'array, sinó que també ens permet modificar un element específic de l'array, si utilitzem l'assignació:

> **📌 JS**
> 

```html
const letters =  ["a", "b", "c"];

letters[1] = "Z";  // Da "Z" y modifica letters a ["a", "Z", "c"]
letters[3] = "D";  // Da "D" y modifica letters a ["a", "Z", "c", "D"]
letters[5] = "A";  // Da "A" y modifica letters a ["a", "Z", "c", "D", undefined, "A"]
```

### **El mètode .at()**

A més del clàssic operador `[]`, també podem utilitzar el mètode `.at()`, afegit en Javascript . Amb ell, es pot fer exactament el mateix que amb `[pos]`, només que a més permet valors negativos, mitjançant els quals es pot obtindre elements en ordre invers, és a dir, començant a comptar des de l'últim element:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c"];

letters.at(0);    // "a"
letters.at(1);    // "b"
letters.at(3);    // undefined
letters.at(-1);   // "c"
letters.at(-2);   // "b"
```

Aquesta característica fa que accedir a l'últim element (*o cercanos*) siga bastant pràctic, ja que fer la mateixa operació amb l'operador `[]` era alguna cosa menys directe que en alguns casos es podria tornar confuso o poc intuitivo:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c"];
const lastItem = letters.length - 1;

letters[lastItem];    // "c"
```

### **El mètode .with()**

Tingues en compte que amb el nou mètode `.with()`, es pot fer açò d'una forma més cómoda i sense modificar l'array original. Permet encadenar múltiples operacions, però tingues en compte que només modifica, no es poden afegir elements que no existeixen abans en l'array:

> **📌 JS**
> 

```html
const letters =  ["a", "b", "c"];

letters.with(1, "Z");   // Devuelve "Z" y modifica letters a ["a", "Z", "c"]
letters.with(1, "Z")
    .with(3, "D");   // No se puede hacer porque la posición 3 no existe
letters.with(5, "A");   // No se puede hacer porque la posición 5 no existe
```

## **Afegir o eliminar elements**

Existeixen diverses formes d'afegir elements a un array ja existent. Tingues en compte que en tots aquests casos estem **mutant** (*variant els elements de l'array ja existent*).

| Mètode | Descripció |
| --- | --- |
| push(e1, e2, e3...) | Afegeix un o diversos elements al final de l'array. Retorna el mida de l'array. Muta l'array original. |
| pop() | Elimina l'últim element de l'array. Retorna aquest element. Muta l'array original. |
| unshift(e1, e2, e3...) | Afegeix un o diversos elements a l'inici de l'array. Retorna el mida de l'array. Muta l'array original. |
| shift() | Elimina el primer element de l'array. Retorna aquest element. Muta l'array original. |

En els arrays, Javascript proporciona mètodes tant per a inserir o eliminar elements **pel final** de l'array, com **pel principi**:

> **📌 JS**
> 

```html
const elements = ["a", "b", "c"]; // Array inicial

elements.push("d");    // Devuelve 4.   Ahora elements = ['a', 'b', 'c', 'd']
elements.pop();        // Devuelve 'd'. Ahora elements = ['a', 'b', 'c']

elements.unshift("Z"); // Devuelve 4.   Ahora elements = ['Z', 'a', 'b', 'c']
elements.shift();      // Devuelve 'Z'. Ahora elements = ['a', 'b', 'c']
```

## **Alternatives per a crear arrays**

Encara que hem vist les formes principals de crear un array en Javascript, existeixen altres que permeten generar un array partint d'altres (*i molt variades*) estructures de dades.

Alguns d'aquests casos són els següents:

| Mètode | Descripció |
| --- | --- |
| Array.from(obj) | Intenta convertir l'obj en un array. |
| Array.from(obj, fmap) | Idem, però executa la funció fmap per cada element. Equivalent a .map() |
| Array.from({ length:*size*}) | Crea un array a partir d'un object de mida size, farciment de |
| .concat(e1, e2, e3...) | Retorna els elements pasats per paràmetre concatenats al final de l'array. |
| .join(sep) | Uneix els elements de l'array mitjançant separadors sep en un string. |

Analitzarem cada un d'aquests mètodes i posar alguns exemples.

"Array.from o spread"concatjoin/split

### **Convertir a array**

El mètode estàtic Array.from(), es sol utilitzar per a convertir variables «parecides» als **arrays** (*però que no són arrays*) en un array. Aquest és el cas de variables com string.

> **📌 JS**
> 

```html
const text = "12345";
text.constructor.name;                          // "String"

const letters = Array.from(text);               // ["1", "2", "3", "4", "5"]
const letters = [...text];                      // ["1", "2", "3", "4", "5"]

const divs = document.querySelectorAll("div");
divs.constructor.name;                          // "NodeList"

const elements = Array.from(divs);              // [div, div, div]
const elements = [...divs];                     // [div, div, div]
```

Però no tots els elements es poden convertir a arrays. Per exemple, si intentem convertir un `undefined` o un `null`, ens donarà un error similar a **Uncaught TypeError: null is not iterable**.

### **Concatenar arrays**

A l'igual que en els string, en els arrays tenim el mètode `concat()`, que ens permet unir els elements pasats per paràmetre en un array a l'estructura que estem manejant. Es podria pensar que els mètodes `.push()` i `concat()` funcionen de la mateixa forma, però no és exactament així.

> **📌 JS**
> 

```html
const elements = [1, 2, 3];

elements.push(4, 5, 6);     // Devuelve 6. Ahora elements = [1, 2, 3, 4, 5, 6]
elements.push([7, 8, 9]);   // Devuelve 7. Ahora elements = [1, 2, 3, 4, 5, 6, [7, 8, 9]]
```

Ara vegem el mateix exemple realitzat amb el mètode `.concat()`:

> **📌 JS**
> 

```html
const firstPart = [1, 2, 3];
const secondPart = [4, 5, 6];

firstPart.concat(firstPart);              // Devuelve [1, 2, 3, 1, 2, 3]
firstPart.concat(secondPart);             // Devuelve [1, 2, 3, 4, 5, 6]

// Se pueden pasar elementos sueltos
firstPart.concat(4, 5, 6);                // Devuelve [1, 2, 3, 4, 5, 6]

// Se pueden concatenar múltiples arrays e incluso mezclarlos con elementos sueltos
firstPart.concat(firstPart, secondPart, 7);  // Devuelve [1, 2, 3, 1, 2, 3, 4, 5, 6, 7]
```

Observa un detall molt important: El mètode `concat()`, a diferència de `push()`, no modifica l'array sobre el quin treballem i al que li afegim els elements, sinó que simplement el retorna. Al marge d'açò, observa que en el cas de passar un array per paràmetre, `push()` l'insereix com un array, mentre que `concat()` insereix cada un dels seus elements.

### **Separar i unir strings**

A més, també tenim un altre mètode amb el que és possible crear un array a partir d'un string. Es tracta del mètode `.split()` que vam veure en el tema dels string. En aquest cas, el mètode `.join()` és la seua contrapartida. Amb `.join()` podem crear un  amb tots els elements de l'array, separándolo pel text que li pasemos per paràmetre:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c"];

// Une elementos del array por el separador indicado
letters.join("->");       // Devuelve 'a->b->c'
letters.join(".");        // Devuelve 'a.b.c'

// Separa elementos del string por el separador indicado
"a.b.c".split(".");       // Devuelve ['a', 'b', 'c']
"5-4-3-2-1".split("-");   // Devuelve ['5', '4', '3', '2', '1']
```

Tingues en compte que, com es pot veure en els exemples, `.join()` sempre retornarà els elements com string, mentre que `.split()` retornarà un array.

## **Cerca i comprovació**

En moltes ocasions ens interesará cercar elements en un array per a, o bé, trobar l'element i treballar amb ell, o per a saber la posició de l'element en l'array. Per a això, existeixen una sèrie de mètodes mitjançant els quals podem realitzar aquestes accions. Són els següents:

| Mètode | Descripció |
| --- | --- |
| BOOLEAN .includes(element) | Comprova si element està inclòs en l'array. |
| BOOLEAN .includes(element, from) | Idem, però partint des de la posició from de l'array. |
| NUMBER .indexOf(element) | Retorna la posició de la primera aparició d'element o -1 si no existeix. |
| NUMBER .indexOf(element, from) | Idem, però partint des de la posició from de l'array. |
| NUMBER .lastIndexOf(element) | Retorna la posició de la última aparició d'element. Retorna -1 si no existeix. |
| NUMBER .lastIndexOf(element, from) | Idem, però partint des de la posició from de l'array. |

IncludesIndexOfLastIndexOf

### **L'element existeix?**

El mètode `.includes()` comprova si l'element indicat està inclòs en el . És possible indicar un segon paràmetre on indicarem la posició  `from` des d'on comencem a cercar:

> **📌 JS**
> 

```html
const numbers = [5, 10, 15, 20, 25];

numbers.includes(3);    // false
numbers.includes(15);   // true

numbers.includes(15, 1);  // true
numbers.includes(15, 4);  // false
```

Açò pot ser realment útil per a comprovar ràpidament si un element està inclòs en una estructura de tipus . Recorda que el tipus de dada  també té un mètode similar per a comprovar si una subcadena de text està inclosa en un .

### **Cercar la posició (indexOf)**

El mètode `.indexOf()` (*l'índex de..., la posició de...*) fa alguna cosa similar a `.includes()`, però en lloc de retornar un `BOOLEAN`, retorna la posició de l'element cercat. En el cas de no encontrar-lo, retorna un valor negatiu `-1`.

> **📌 JS**
> 

```html
const numbers = [5, 10, 15, 20, 25, 20, 15, 10, 5];

numbers.indexOf(5);   // 0
numbers.indexOf(15);  // 2
numbers.indexOf(25);  // 4
numbers.indexOf(99);  // -1

numbers.indexOf(15, 1); // 2
numbers.indexOf(15, 4); // 6
numbers.indexOf(15, 7); // -1
```

De la mateixa forma que en l'anterior, a `.indexOf()` es li pot passar un segon paràmetre per a indicarle la posició des de la que volem començar a cercar, permetent trobar elements repetits que estiguen després d'ocurrències anteriors.

### **Cercar al final (lastIndexOf)**

Per la seua part, el mètode `.lastIndexOf()` fa exactament el mateix que `.indexOf()`, amb la única diferència que empezará a cercar des del final, en lloc des del principi del .

Vegem el mètode en acció:

> **📌 JS**
> 

```html
const numbers = [5, 10, 15, 20, 25, 20, 15, 10, 5];

numbers.lastIndexOf(5);   // 8
numbers.lastIndexOf(15);  // 6
numbers.lastIndexOf(25);  // 4
numbers.lastIndexOf(99);  // -1

numbers.lastIndexOf(15, 8); // 6
numbers.lastIndexOf(15, 5); // 2
numbers.lastIndexOf(15, 1); // -1
```

D'aquesta forma, pots cercar ràpidament elements que es troben al final de l'array i recuperar la seua posició.

### **Cercar un element en un array**

Ara que coneixem els mètodes anteriors, podem aprovechar-los per a cercar un element en un array. Quan es tracta d'estructures molt simples, no té sentit cercar el mateix element que ja coneixem i tenim prèviament, però en estructures més complexes si pot ser interessant.

Observa el següent exemple on partim d'una estructura `ARRAY` de `OBJECT`, que tenen el nom i l'edat d'una persona. Anem a implementar una funció `findElement()` per a cercar la primera persona amb una certa edat:

> **📌 JS**
> 

```html
const names = [
{ name: "María", age: 20 },
{ name: "Bernardo", age: 28 },
{ name: "Pancracio", age: 22 },
{ name: "Andrea", age: 19 },
{ name: "Sara", age: 29 },
{ name: "Jorge", age: 32 },
{ name: "Yurena", age: 38 },
{ name: "Ayoze", age: 18 }
];

// Busca el primer elemento con la edad indicada, sino devuelve -1
const findElement = (array, searchedAge) => {
for (let i = 0; i < array.length; i++) {
    const element = array[i];
    if (element.age === searchedAge) {
    return element;
    }
}
return -1;
}

findElement(names, 19);     // { name: "Andrea", age: 19 }
findElement(names, 32);     // { name: "Jorge", age: 32 }
findElement(names, 33);     // -1
```

La funció `findElement()` permet cercar en el `array` indicat, l'edat indicada en `searchedAge`. No obstant això, aquesta funció té una **implementació imperativa** (*indiques els passos que vols fer*). També és possible realitzar una **implementació declarativa** (*indiques el que vols obtindre*), que sol ser molt més clara i llegible en aquests casos.

Per a això, usarem la funció `.find()` que veurem més avant. Crearem un exemple que faça exactament el mateix que l'anterior:

> **📌 JS**
> 

```html
const findElement = (array, searchedAge) => {
return array.find(element => element.age === searchedAge) ?? -1;
}

findElement(names, 19);     // { name: "Andrea", age: 19 }
findElement(names, 32);     // { name: "Jorge", age: 32 }
findElement(names, 33);     // -1
```

## **Modificar i Crear Arrays (subarrays)**

Hi ha situacions en les que tenim un `ARRAY` i volem crear nous **subarrays**, és a dir, un xicotet fragment del `ARRAY` original, o simplement **modificar** l'array original per a fer certs canvis, però d'una forma més general i no tindre que fer-ho element a element.

### **Crear fragments**

Per a això, existeixen diversos mètodes relacionats, entre els que es troben els següents:

| Mètode | Descripció |
| --- | --- |
| .slice(start, end) | Retorna els elements des de la posició start fins a end (excluido), sense mutar l'array original. |
| .splice(start, size) | Retorna els size següents elements des de la posició start, canviant l'array original. |
| .splice(start, size, e1, e2...) | Idem. A més, després insereix e1, e2... en la posició start, canviant l'array original.. |
| .toSpliced(start, size) | Idem a splice(start, size), però sense mutar l'array original. |
| .toSpliced(st, sz, e1, e2...) | Idem a splice(st, sz, e1, e2..), però sense mutar l'array original. |

slicetoSpliced / splice

#### **El mètode .slice()**

El mètode `.slice()` retorna els elements de l'array des de la posició `start` fins a la posició `end`, permetent crear un **nou array** més xicotet amb eixe grup d'elements. Recorda que les posicions comencen a comptar des de `0`. En el cas que no es proporcione el paràmetre `end`, es retornen tots els elements des de la posició `start` fins al final de l'array.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d", "e"];

letters.slice(3);         // ["d", "e"]
letters.slice(0, 2);      // ["a", "b"]
letters.slice(4, 5);      // ["e"]
letters.slice(2, 5);      // ["c", "d", "e"]
letters.slice(-2);        // ["d", "e"]
```

Observa que en el primer cas, a l'indicar un només paràmetre, `end` és la posició de l'últim element de l'array. En l'últim cas, a l'indicar un paràmetre negatiu, es comença a comptar des del final. Recorda que en tot moment, el  original `letters` no sufre modificacions.

#### **El mètode .toSpliced() o .splice()**

D'altra banda, el mètode `.splice()` realitza alguna cosa semblant a `.slice()`. Vegem les diferències abans de continuar:

- Mètode `.slice()`: Obté un subarray des d'una **posició inicial** a una **final**

- Mètode `.splice()`: Obté un subarray des d'una **posició inicial**, amb un **mida concret**

> **📌 Warning**
> 

> El mètode `.splice()` té una gran diferència respecte a l'anterior: **muta l'array original**.

Observa que el mètode `.splice()`, en el seu segon paràmetre, `size` no és la posició final del subarray (*com ocorre amb `slice`*), sinó el mida del subarray final, és a dir, el número d'elements que es van a obtindre des de la posició `start`:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d", "e"];

letters.splice(0, 2);       // Crea y devuelve ["a", "b"]
letters                     // Altera el array original: ["c", "d", "e"]

const letters = ["a", "b", "c", "d", "e"];

letters.splice(2, 1);       // Crea y devuelve ["c"]
letters                     // Altera el array original ["a", "b", "d", "e"]

const letters = ["a", "b", "c", "d", "e"];
letters.splice(2, 2);            // Devuelve ['c', 'd']. Ahora array = ['a', 'b', 'e']
letters.splice(1, 0, "z", "x");  // Devuelve []. Ahora array = ['a', 'z', 'x', 'b', 'e']
```

Si no volem mutar l'array original, podem utilitzar `.toSpliced()`, que és un mètode nou que funciona de forma molt similar a `.spliced()`, però sense alterar l'array original. Molt cura a l'hora d'utilitzar-lo com reemplazo, ja que aquest mètode retorna com queda l'array final, però no retorna el que hem extraído.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d", "e"];

letters.toSpliced(0, 2);      // Crea y devuelve ["c", "d", "e"]
letters                       // El array original no cambia ["a", "b", "c", "d", "e"]

letters.toSpliced(2, 1);      // Crea y devuelve ["a, "b, "d", "e"]
letters                       // El array original no cambia ["a", "b", "c", "d", "e"]
```

### **Modificar fragments**

Anem a echar un cop d'ull ara als mètodes i formes de modificar fragments d'un array. Hi ha diverses formes de fer-ho, echemos un cop d'ull:

| Mètode | Descripció |
| --- | --- |
| .copyWithin(pos, start, end) | Muta l'array, canviant en pos i copiant des de start a end. |
| .fill(element, start, end) | Canvia els elements de l'array per element des de start fins a end. Muta l'array. |
| .with(index, item) | Retorna una còpia de l'original, amb l'element index modificat, l'array original no muta. |

copyWithin()fill()with()

#### **Alterar fragment amb .copyWithin()**

copyWithin(pos, start, end) ens permet alterar l'array, de mode que, començant en la posició `pos`, copiará els elements que estan des de la posició `start` fins a la posició `end`. El paràmetre `end` és opcional, de mode que si no es indica, es asume que `end` és el mida de l'array.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d", "e", "f"];

// Estos métodos modifican el array original
letters.copyWithin(3, 0, 3);      // ["a", "b", "c", "a", "b", "c"]
letters.copyWithin(3, 1);         // ["a", "b", "c", "b", "c", "a"]
letters.copyWithin(4, 0, 1);      // ["a", "b", "c", "d", "a", "a"]
```

#### **Emplenar un array amb .fill()**

Existeix un mètode que ens permet **emplenar** l'array amb els elements indicats. Es li pot indicar uns paràmetres opcionals `start` i `end` per a establir la posició d'inici i/o fi on volem emplenar, i així només alterar un fragment de l'array. Amb aquest mètode estem **alterant** l'array.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d", "e", "f"];

// Estos métodos modifican el array original

letters.fill("Z", 0, 5);             // ["Z", "Z", "Z", "Z", "Z", "f"]
letters.fill("AA", 0, 2);            // ["AA", "AA", "Z", "Z", "Z", "f"]
letters.fill(1);                     // [1, 1, 1, 1, 1]
new Array(5).fill(5);                // [5, 5, 5, 5, 5] creamos un array de 5 elementos undefined y lo rellenamos con números `5`
```

#### **Crear modificació amb .with()**

El nou mètode `.with()` ens proporciona una forma on podem fer una xicoteta modificació en un array, sense que alterem l'original.

> **📌 JS**
> 

```html
// Ejemplo 1: Reemplazo con with()
const elements = ["A", "B", "C", "D", "E"];

elements.with(0, "a");  // ["a", "B", "C", "D", "E"]

// Ejemplo 2: Reemplazo múltiple con with()
const elements = ["A", "B", "C", "D", "E"];

elements.with(0, "a")
        .with(2, "c")
        .with(4, "e");  // ["a", "B", "c", "D", "e"]
```

L'important d'usar `.with()` és que l'array original no muta i permanece intacto, simplement es crea un nou array.

## **Ordenar Arrays**

En Javascript, és molt habitual que tinguem una estructura de dades  i vulguem ordenar el seu contingut per un criteri determinat. En aquest apartat, veurem alguns mètodes i formes per a ordenar un array o realitzar modificacions per a canviar la seua ordre:

| Mètode | Descripció |
| --- | --- |
| .reverse() | Invierte l'ordre d'elements de l'array. L'array original **canvia**. |
| .toReversed() | Retorna una còpia de l'array, amb l'ordre dels elements invertido. L'array original **no muta**. |
| .sort() | Ordena els elements de l'array sota un criteri de **ordenació alfabética.** L'array original **canvia**. |
| .sort(criteri) | Idem, però sota un criteri d'ordenació indicat per criteri. L'array original **canvia**. |
| .toSorted() | Retorna una còpia de l'array, amb els elements ordenats. L'array original **no muta**. |
| .toSorted(criteri) | Idem, però ordenat pel criteri establit per paràmetre. L'array original **no muta**. |

### **El mètode .toReversed() i .reverse()**

El mètode `reverse()` reordena els elements de l'array en **ordre invers**, és a dir, si tenim `[5, 4, 3]` el modifica de mode que obtenim `[3, 4, 5]`.

> **📌 JS**
> 

```html
const elements = ["A", "B", "C", "D", "E", "F"];

const reversedElements = elements.reverse();

reversedElements                // ["F", "E", "D", "C", "B", "A"]
elements                        // ["F", "E", "D", "C", "B", "A"] la función ha mutado el original
reversedElements === elements   // true
```

```html
const elements = ["A", "B", "C", "D", "E", "F"];

const reversedElements = structuredClone(elements).reverse(); // Clona el elemento original

reversedElements                 // ["F", "E", "D", "C", "B", "A"]
elements                         // ['A', 'B', 'C', 'D', 'E', 'F'] hemos aplicado el reverse al elemento clonado y el original no sufre cambio.
reversedElements === elements    // false
```

Utilitzant `structuredClone()`, el que fem és crear una còpia de l'estructura original `elements`, i després invertirla. Ara si, tenim dos arrays independents.

Una altra solució, molt més senzilla és utilitzar el nou mètode `.toReversed()` , el quin funciona exactament igual que `.reverse()`, però sense mutar l'original:

> **📌 JS**
> 

```html
const elements = ["A", "B", "C", "D", "E", "F"];

const reversedElements = elements.toReversed();

reversedElements                // ["F", "E", "D", "C", "B", "A"]
elements                        // ["A", "B", "C", "D", "E", "F"]
reversedElements === elements   // false
```

### **El mètode toSorted() i .sort()**

Qualsevol estructura de dades array en Javascript té el mètode `sort()`. Aquest mètode realitza una ordenació dels elements de l'array, amb la peculiaritat que sempre realitzarà una **ordenació alfabética**:

> **📌 JS**
> 

```html
const names = ["Alberto", "Zoe", "Ana", "Mauricio", "Bernardo"];

const sortedNames = names.sort();

sortedNames               // ["Alberto", "Ana", "Bernardo", "Mauricio", "Zoe"]
names                     // ["Alberto", "Ana", "Bernardo", "Mauricio", "Zoe"]
sortedNames === names     // true
```

Efectivament, veiem que ara l'array `sortedNames` està ordenat alfabéticament. No obstant això, ocorre exactament el mateix que en el cas anterior. Novament, hem d'utilitzar la funció `structuredClone()` per a fer una còpia i que siga independent:

> **📌 JS**
> 

```html
const names = ["Alberto", "Zoe", "Ana", "Mauricio", "Bernardo"];

const sortedNames = structuredClone(names).sort();

sortedNames               // ["Alberto", "Ana", "Bernardo", "Mauricio", "Zoe"]
names                     // ["Alberto", "Zoe", "Ana", "Mauricio", "Bernardo"];
sortedNames === names     // false
```

Novament, una altra solució molt més senzilla podria ser utilitzar la funció `.toSorted()` , que funciona exactament igual que `.sort()`, però mantenint intacto l'array original, sense mutar-lo:

> **📌 JS**
> 

```html
const names = ["Alberto", "Zoe", "Ana", "Mauricio", "Bernardo"];

const sortedNames = names.toSorted();

sortedNames               // ["Alberto", "Ana", "Bernardo", "Mauricio", "Zoe"]
names                     // ["Alberto", "Zoe", "Ana", "Mauricio", "Bernardo"]
sortedNames === names     // false
```

No obstant això, l'ordenació anterior es va realitzar sobre un array d'elements string i tot va ser bé. Vegem que ocorre si intentem ordenar un array d'elements number, tant utilitzant el mètode `.sort()` com el mètode `.toSorted()`:

> **📌 JS**
> 

```html
const numbers = [1, 8, 2, 32, 9, 7, 4];

const sortedNumbers = numbers.toSorted();

sortedNumbers   // [1, 2, 32, 4, 7, 8, 9]
numbers         // [1, 8, 2, 32, 9, 7, 4]
```

Açò ocorre perquè, a l'igual que en l'exemple anterior, el tipus d'ordenació que es realitza per defecte és una **ordenació alfabética**, mentre que en aquesta ocasió cerquem una **ordenació natural**, que és la que es sol utilitzar amb números (*no ens interessa que el 32 es trobe abans del 9*).

Açò es pot fer en Javascript, però requereix pasarle per paràmetre al `sort()` el que es anomena una **funció de comparació** o **funció d'ordenació**.
