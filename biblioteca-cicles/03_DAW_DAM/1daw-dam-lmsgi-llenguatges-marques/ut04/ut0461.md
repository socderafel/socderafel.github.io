Un dels aspectes més importants del llenguatge Javascript és el concepte de **objecte**, ja que pràcticament tot el que utilitzem en Javascript, són objectes.

En Javascript, existeix un tipus de dada anomenat **objecte** . Una primera forma de verlo, és com una variable especial que pot contindre més variables en el seu interior. D'aquesta forma, tenim la possibilitat d'organitzar **múltiples variables** de la mateixa temática en l'interior d'un objecte.

En molts llenguatges de programació, per a crear un objecte s'utilitza la paraula clau `new`.

> **📌 JS**
> 

```html
const objeto = new Object();    // Evitar esta sintaxis en Javascript (no se suele usar)
```

## **Declaració d'un objecte**

Els literals dels objectes en Javascript són les claus `{}`. Aquest exemple és equivalent a l'anterior, però és més corto, ràpid i còmode, per la qual cosa es aconseja declarar-los sempre així:

> **📌 JS**
> 

```html
const objeto = {};    // Esto es un objeto vacío
```

No obstant això, en aquesta ocasió hem creat un objecte amb nom `objeto` que està buit. Crearem un nou objecte anomenat `player`, que continga variables amb informació en el seu interior:

> **📌 JS**
> 

```html
const player = {
    name: "Luis",
    life: 99,
    power: 10,
};
```

Aquestes variables dins dels objectes es solen denominar **propietats**. Com es pot veure, un objecte en Javascript ens permet encapsular en el seu interior informació relacionada ràpidament, per a posteriorment poder accedir a ella de forma senzilla i intuitiva.

## **Propietats d'un objecte**

Una vegada tinguem un objecte, podem accedir a les seues propietats de dos formes diferents:

- a través de la notació amb **punts**

- a través de la notació amb **claudàtors**.

> **📌 JS**
> 

```html
// Notación con puntos (preferida)
console.log(player.name);     // Muestra "Luis"
console.log(player.life);     // Muestra 99

// Notación con corchetes
console.log(player["name"]);  // Muestra "Luis"
console.log(player["life"]);  // Muestra 99
```

El programador pot utilitzar la notació que més li guste. La més utilitzada en Javascript sol ser la **notació amb punts**, mentre que la notació amb claudàtors es sol conèixer en altres llenguatges com «arrays asociativos» o «diccionarios».

> **📌 Important**
> 

> Hi ha certs casos en els que només es pot utilitzar la **notació amb claudàtors**, com per exemple quan s'utilitzen espais en el nom de la propietat. És impossible fer-ho amb la notació amb punts.

### **Afegir propietats**

També podem afegir **propietats** al **objecte** després d'haber-lo creat, i no només en el moment de crear l'objecte. Vegem un exemple equivalent a l'anterior on crearem les propietats, però després d'haver creat l'objecte:

> **📌 JS**
> 

```html
// FORMA 1: A través de notación con puntos
const player = {};

player.name = "Luis";
player.life = 99;
player.power = 10;

// FORMA 2: A través de notación con corchetes
const player = {};

player["name"] = "Luis";
player["life"] = 99;
player["power"] = 10;
```

Les **propietats** de l'objecte poden ser utilitzades com variables. De fet, utilitzar els objectes com elements per a organitzar múltiples variables sol ser una primera bona pràctica d'organització en Javascript.

## **Mètodes d'un objecte**

Els objectos no només estan compost per **propietats**, podem crear variables que conté una funció, açò es denomina **mètode d'un objecte**:

> **📌 JS**
> 

```html
const user = {
name: "Luis",
talk: function() { return "Hola"; }
};

user.name;       // Es una variable (propiedad), devuelve "Luis"
user.talk();     // Es una función (método), se ejecuta y devuelve "Hola"
```

### **El mètode .toString()**

Simplement per generar una variable de tipus object, eixa variable «hereda» una sèrie de mètodes que existeixen en qualsevol variable que siga de tipus object. Un bon exemple, seria el mètode `.toString()`, un mètode que intenta representar la informació d'eixe objecte en un string.

Si creem un objecte buit i executem aquest mètode, comprobarem que ocorre el següent:

> **📌 JS**
> 

```html
const objeto = {};
objeto.toString();    // Devuelve "[object Object]"
                    // (representación textual de un objeto genérico)
```

Observa que en cap moment hem afegit una funció `.toString()` a l'objecte, però encara així existeix i la podem executar. Açò ocorre també amb altres tipus de dada que a priori no són , sinó per exemple ,  o :

> **📌 JS**
> 

```html
const number = 42;      // Tipo Number
number.toString();      // Devuelve "42"

const booleano = true;  // Tipo Boolean
booleano.toString();    // Devuelve "true"

const regexp = /.+/;    // Tipo RegExp
regexp.toString();      // Devuelve "/.+/"
```

Al crear una variable d'un determinat tipus de dada, la variable serà sempre també de tipus , ja que totes les variables heredan d'aquest tipus de dada. Per tant, la nostra variable tindrà:

- Els mètodes que implementemos nosaltres personalment

- Els mètodes heretats del seu propi tipus de dada

- Els mètodes heretats del tipus

Observa el següent exemple:

> **📌 JS**
> 

```html
const number = 42.5;
number.toString();          // Devuelve "42.5" (Método de variables de tipo Object)
number.toLocaleString();    // Devuelve "42,5" (Método de variables de tipo Object)
number.toFixed(3);          // Devuelve "42.500" (Método de variables de tipo Number)
```

Hem definit una variable numèrica, de tipus , amb el valor amb decimals `42.5`. En la següent línia, executem el mètode `.toString()` un mètode heredado dels  per a mostrar-lo com text. El mateix ocorre amb el mètode `.toLocaleString()`. No obstant això, el mètode `toFixed()` és un mètode heredado del tipus de dada , i com el tipus de dada de la variable `number` és  tenim disponible eixe mètode.

### **Creant el nostre .toString()**

Si quisiéramos, podríem crear una variable `toString` dins del nostre objecte, que continga una funció que mostre el text ideal per a representar el nostre objecte d'informació. Per exemple:

> **📌 JS**
> 

```html
const player = {
name: "Luis",       // Nombre del jugador
life: 4,            // Cantidad de vida actual
totalLife: 6,       // Máximo de vida posible
toString: function() {
    return `${this.name} (${this.life}/${this.totalLife})`;
}
};
```

Observa que en la funció `.toString()` devolvemos un  que conté el **nom** del jugador i entre parèntesis, la **vida actual** del jugador i després d'un `/` el **màxim possible** de vida que podria tindre. D'aquesta forma, el mètode `.toString()` representa l'objecte de la millor forma possible per a aquest cas particular:

> **📌 JS**
> 

```html
console.log("Mi jugador es " + player);       // "Mi jugador es Luis (4/6)"
```

Ací, el `console.log()` està concatenant un  i un objecte . Com l'objecte `player` no és de tipus , anomena automàticament al mètode `.toString()` i obté un  per a representar-lo.
