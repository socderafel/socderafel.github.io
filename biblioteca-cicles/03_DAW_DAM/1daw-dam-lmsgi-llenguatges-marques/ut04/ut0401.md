## 1. El Model d'Execució de JavaScript en el Navegador

JavaScript és un llenguatge interpretat (amb compilació JIT - Just-In-Time), orientat a objectes basat en prototips, amb tipatge dinàmic i un model d'execució monofil (*single-threaded*) governat per un bucle d'esdeveniments (*Event Loop*).

Quan el motor d'un navegador troba una etiqueta `<script src="fitxer.js">` estàndard enmig del codi HTML:
1. Atura immediatament l'anàlisi de l'arbre DOM (*DOM parsing blocker*).
2. Obre una connexió de xarxa per a descarregar el recurs JavaScript.
3. Executa el codi JavaScript complet.
4. Reprèn la lectura i renderitzat de la resta del document HTML.

Aquest comportament bloquejant clàssic degradava greument el temps de càrrega percebut per l'usuari (*First Contentful Paint*).

---

## 2. Estratègies Modernes de Càrrega: async vs defer vs type="module"

```html
<!-- 1. Bloquejant Clàssic (Desaconsellat al <head>) -->
<script src="script.js"></script>

<!-- 2. Asíncron Independent (Executa immediatament en descarregar) -->
<script async src="analitica.js"></script>

<!-- 3. Diferit Ordenat (Executa en acabar el parsing HTML, abans de DOMContentLoaded) -->
<script defer src="interficie.js"></script>

<!-- 4. Mòdul ECMAScript (Automàticament deferit i amb àmbit privat) -->
<script type="module" src="app.js"></script>
```

### Taula Comparativa de Cicle de Vida

| Mètode | Descàrrega de Xarxa | Bloqueja el Parsing HTML? | Moment d'Execució | Conserva l'Ordre de Codi? |
| :--- | :--- | :--- | :--- | :--- |
| `<script>` | Bloquejant en trobar l'etiqueta | Sí, durant descàrrega i execució | Immediat | Sí |
| `<script async>` | En paral·lel en segon pla | Sí, només durant l'execució | Immediatament quan acaba la seua descàrrega | **No** (qui acaba abans, s'executa abans) |
| `<script defer>` | En paral·lel en segon pla | **No** | En finalitzar l'anàlisi HTML complet | **Sí** (en estricte ordre de declaració) |
| `<script type="module">`| En paral·lel | **No** | Després del parsing HTML (com defer) | Sí |

> [!TIP] Regla d'Or Professional
> Utilitza `defer` (o `type="module"`) per al codi de la teua aplicació que necessite interactuar amb el DOM. Reserva `async` exclusivament per a serveis independents de tercers (com Google Analytics o píxels de telemetria) que no interactuen amb l'estructura de la teua pàgina.

## 3. Depuració Professional mitjançant la Consola del Navegador

L'objecte global `console` ofereix eines avançades per al diagnòstic i auditoria de codi:

```javascript
// Registre bàsic
console.log("Missatge d'informació general.");
console.warn("Advertència de configuració potencialment perillosa.");
console.error("Error crític en la resposta de l'API.");

// Visualització estructurada de dades
const alumnes = [
  { id: 1, nom: "Carles", cicle: "DAW" },
  { id: 2, nom: "Laura", cicle: "DAM" }
];
console.table(alumnes); // Dibuixa una graella interactiva amb camps i columnes

// Mesura precisa de rendiment
console.time("Càlcul d'algorisme");
for (let i = 0; i < 1_000_000; i++) { /* operació */ }
console.timeEnd("Càlcul d'algorisme"); // Mostra: Càlcul d'algorisme: 2.45ms

// Punts d'interrupció condicionals en codi
debugger; // Pausa l'execució i obre automàticament l'inspector de codi del navegador
```
