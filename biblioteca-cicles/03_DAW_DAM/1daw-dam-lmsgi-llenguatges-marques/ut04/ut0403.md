## 1. Coerció de Tipus: Conversió Implícita vs Explícita

La **coerció de tipus** (*Type Coercion*) és la conversió automàtica que realitza el motor de JavaScript quan un operador s'aplica sobre operands de diferent naturalesa:

```javascript
// Coerció Implícita (Font comuna de fallades silents)
console.log("5" + 3);  // "53" (l'operador + amb cadenes afavoreix la concatenació)
console.log("5" - 3);  // 2 (l'operador - converteix la cadena "5" a nombre 5)
console.log("5" * "2");// 10 (ambdós es converteixen a enters)
console.log(true + 1); // 2 (true es converteix en el nombre 1)
console.log([] + {});  // "[object Object]"
```

### Bones Pràctiques: Conversió Explícita
S'ha d'evitar la conversió implícita utilitzant funcions de conversió clares i explícites:
- A nombre: `Number(cadena)`, `parseInt(cadena, 10)` o `parseFloat(cadena)`.
- A text: `String(valor)` o `valor.toString()`.
- A booleà: `Boolean(valor)` o el doble operador lògic de negació `!!valor`.

## 2. Valors Falsos (Falsy) i Valors Vertaders (Truthy)

En contextos condicionals (com `if (condicio)`), qualsevol valor es converteix implícitament a booleà. Només existeixen **8 valors falsos (*falsy*)** en tot el llenguatge JavaScript:
1. `false`
2. `0` i `-0`
3. `0n` (BigInt zero)
4. `""`, `''` (cadena buida)
5. `null`
6. `undefined`
7. `NaN`
8. `document.all` (objecte històric d'IE)

**Tots els altres valors són veritables (*truthy*)**, incloent un array buit `[]`, un objecte buit `{}` i la cadena amb espai `" "`.

### Operadors Moderns de Curtcircuit
- **Operador Nullish Coalescing (`??`):** Retorna l'operand dret **únicament** si l'esquerre és `null` o `undefined` (a diferència de `||`, que també s'activa amb `0` o cadenes buides):
  ```javascript
  const valorConfigurat = 0;
  const resultatOR = valorConfigurat || 100; // Retorna 100 (perquè 0 és falsy!)
  const resultatNC = valorConfigurat ?? 100; // Retorna 0 (perquè 0 NO és null ni undefined!)
  ```
- **Operador d'Encanament Opcional (`?.`):** Permet navegar propietats d'objectes aniuats sense perill de llançar un error si una referència és nul·la:
  ```javascript
  const ciutat = usuari?.adreca?.ciutat ?? "Desconeguda";
  ```

## 3. Estructures de Control de Flux Iteratives i Condicionals

```javascript
// Bucle for...of (Itera sobre els VALORS d'una col·lecció iterable)
const llenguatges = ["HTML5", "CSS3", "JavaScript"];
for (const llenguatge of llenguatges) {
  console.log(`Mòdul actiu: ${llenguatge}`);
}

// Bucle for...in (Itera sobre les CLAUS o propietats d'un objecte)
const configuracio = { port: 8080, host: "localhost", ssl: true };
for (const clau in configuracio) {
  console.log(`Paràmetre: ${clau} -> ${configuracio[clau]}`);
}

// Sentència switch moderna amb avaluació estricta (===)
const rol = "PROFESSOR";
switch (rol) {
  case "ADMIN":
    console.log("Accés total al panell de control.");
    break;
  case "PROFESSOR":
  case "TUTOR":
    console.log("Gestió d'avaluacions i llistes d'alumnat.");
    break;
  default:
    console.log("Accés estàndard de consulta.");
}
```
