**JSON** són les sigles de **JavaScript Object Notation**, i no és més que un **format lleuger** de dades, amb una estructura (*notació*) específica, que és totalment compatible de forma nativa amb Javascript. Com el seu propi nom indica, **JSON** es basa en la sintaxi que té Javascript per a crear objectes.

Un arxiu **JSON** mínim sol tindre la següent sintaxi:

```html
{
}
```

No obstant això, el seu contingut pot ser simplement un **ARRAY**, un **NUMBER**, un **STRING**, un **BOOLEAN** o fins i tot un **NULL**, no obstant això, el més habitual és que parta sent un **OBJECT** o un **ARRAY**. Pots comprovar en [JSONLint](https://jsonlint.com/) si alguna cosa concret és un **JSON** vàlid o no.

Aquest exemple anterior simplement és un objecte buit **{}**. Un arxiu JSON, sol contindre molta informació emmagatzemada.

> **📌 JSON**
> 

```html
{
  "name": "Luis",
  "life": 3,
  "totalLife": 6
  "power": 10,
  "dead": false,
  "props": ["invisibility", "coding", "happymood"],
  "senses": {
    "vision": 50,
    "audition": 75,
    "taste": 40,
    "touch": 80
  }
}
```

Si comparamos un **JSON** amb un objecte Javascript, apareixen algunes ligeras diferències i matices:

- Les propietats de l'objecte han d'estar entrecomillades amb «cometes dobles»

- Els textos **STRING** han d'estar entrecomillats amb «cometes dobles»

- Només es pot emmagatzemar tipus com **STRING**, **NUMBER**, **OBJECT**, **ARRAY**, **BOOLEAN** o **null**.

- Tipus de dades com **FUNCTION**, **DATE**, **REGEXP** o altres, no és possible almacenar-los en un JSON.

- Tampoc és possible afegir **comentaris** en un JSON.

> **📌 Aclaració**
> 

> Hi ha formats derivats de JSON que sí permeten comentaris, com és el cas de [JSON5](https://json5.org/).

Molt cura amb les **cometes malament cerrades** o les **comes sobrantes** (*abans d'un tancament de claus, per exemple*). Solen ser motivos d'error de sintaxi freqüentment. Existeix una cómoda [extensió per a Visual Code](https://manz.dev/software/vscode/) anomenada [Fix JSON](https://marketplace.visualstudio.com/items?itemName=oliversturm.fix-json) que et corregeix els errors de format d'un JSON.

## **Com utilitzar JSON?**

Si analitzem bé la sintaxi d'un JSON, és molt similar a un objecte declarat Javascript, però amb certes diferències:

> **📌 JSON**
> 

```html
const user = {
  name: "Luis",
  life: 99,
};
```

En Javascript hi ha una sèrie de mètodes que faciliten la tasca de passar de  de Javascript a **JSON** i viceversa, podent treballar amb contingut de tipus  (*que continga un JSON*) i objectes Javascript segons interese.

Aquests mètodes són els següents:

| Tipus | Mètode | Descripció |
| --- | --- | --- |
| Parseo (De string a objecte) | **JSON.parse(str)** | Converteix el text **STRING** **str** (si és un JSON vàlid) a un objecte i el retorna. |
| Convertir a text (D'objecte a string) | **JSON.stringify(obj)** | Converteix un objecte **OBJECT** **obj** a la seua representació JSON i la retorna. |
| Convertir a text (D'objecte a string) | **JSON.stringify(obj, props)** | Idem a l'anterior, però filtra i manté només les propietats del **ARRAY** **props**. |
| Convertir a text (D'objecte a string) | **JSON.stringify(obj, props, spaces)** | Idem a l'anterior, però indenta el JSON a **NUMBER** **spaces** espais. |

El primer d'ells, el mètode **.parse()** permet passar el contingut de text **STRING** d'un JSON a **OBJECT**. En contrapartida, el mètode **.stringify()** permet passar de **OBJECT** de Javascript a contingut de text **STRING** amb el JSON en qüestió.

### **Convertir JSON a objecte**

L'acció de **convertir JSON a objecte** Javascript es li sol denominar **parsear**. És una acció que analitza un **STRING** que conté un **JSON** vàlid i retorna un objecte Javascript amb aquesta informació correctament estructurada.

> **📌 JSON**
> 

```html
const json = `{
  "name": "Luis",
  "life": 99
}`;

const user = JSON.parse(json);

user.name;  // "Luis"
user.life;  // 99
```

Com es pot veure, **OBJECT** **user** és un objecte generat a partir del JSON emmagatzemat en la variable STRING **json** i podem consultar les seues propietats i treballar amb elles sense problemes.

### **Convertir objecte a JSON**

L'operació inversa, **convertir un objecte Javascript a JSON** també es pot realitzar fàcilment fent ús del mètode **JSON.stringify()**.

> **📌 JSON**
> 

```html
const user = {
  name: "Luis",
  life: 99,
  talk: function () {
    return "Hola!";
  },
};

JSON.stringify(user);       // '{"name":"Luis","life":99}'
```

> **📌 Important**
> 

> Les funcions no estan soportades per **JSON**, per la qual cosa si convertim un objecte que conté mètodes o funcions, **JSON.stringify()** no fallará, però simplement retornarà un **STRING** omitent les propietats que continguen funcions (*o altres tipus de dades no suportats*).

A més, es li pot passar un segon paràmetre al mètode **.stringify()**, que serà un **ARRAY** que actuará de filtre a l'hora de generar l'objecte.

> **📌 JSON**
> 

```html
const user = {
  name: "Luis",
  life: 99,
  power: 10,
};

JSON.stringify(user, ["life"])            // '{"life":99}'
JSON.stringify(user, ["name", "power"])   // '{"name":"Luis","power":10}'
JSON.stringify(user, [])                  // '{}'
JSON.stringify(user, null)                // '{"name":"Luis","life":99,"power":10}'
```

També es pot afegir un tercer paràmetre en el mètode **.stringify()** que indicará el número d'espais que vol usar al crear el **STRING** del JSON resultant.

> **📌 JSON**
> 

```html
const user = {
  name: "Luis",
  life: 99
};

JSON.stringify(user, null, 2);
// {
//   "name": "Luis",
//   "life": 99
// }

JSON.stringify(user, null, 4);
// {
//     "name": "Luis",
//     "life": 99
// }

JSON.stringify(user, ["name"], 1);
// {
//  "name": "Luis"
// }
```

En el primer cas, **json2**, el resultat es genera indentat a **2 espais**. En el segon cas, **json4**, el resultat es genera indentat a **4 espais**. En el tercer i últim cas, **json1**, es filtran les propietats, deixant només **"name"** i es genera indentant a **1 espai**.

## **Leyendo JSON extern**

En els exemples resultats fins a ara, es està convirtent un **STRING** a **OBJECT** i viceversa. Normalment els continguts de **JSON** solen estar emmagatzemats en un arxiu extern, que hi hauria que llegir des del codi Javascript.

Per a això, hui en dia es sol utilitzar la funció **fetch()** per a fer peticions a llocs que retornen contingut JSON. També es podria llegir fitxers locals amb contingut **.json**.
