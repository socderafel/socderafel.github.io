## **Què és un String?**

En programació, quan parlem d'una variable que posseeix informació de text, diem que el seu tipus de dada és . En Javascript, és molt senzill crear una variable de text. A rasgos generals, hi ha dos formes principals de fer-ho:

| Constructor | Descripció |
| --- | --- |
| new String(text) | Crea un objecte de text a partir del text text passat per paràmetre. **Evitar** |
| "text" | Simplement, escrivim el text entre cometes simples o dobles. **Notació preferida**. |

Els  són un dels tipus de dades bàsics (*primitius*), i com tal, és més senzill utilitzar els literals que la notació que utilitza la paraula clau new.

A continuació, un exemple de declaració de variables de text en Javascript:

> **📌 JS**
> 

```html
// Notación literal (preferida)
const text = "¡Hola a todos!";
const message = "Otro mensaje de texto";

// Notación mediante objeto
const text = new String("¡Hola a todos!");
const message = new String("Otro mensaje de texto");
```

> **📌 Important**
> 

> A diferència d'altres llenguatges de programació, Javascript no diferència entre  (*cadena de text*) i caràcters (*char, un només caràcter*). Javascript manté tots dos dins del tipus de dada , per la qual cosa una variable, encara que només continga un caràcter, segueix sent un .

### **Propietats d'un string**

Al crear una variable amb contingut de text , automàticament, eixa variable passa a tindre a la seua disposició totes les **propietats** (*variables*) i **mètodes** (*funcions*) disponibles per a aquest tipus de dada, per la qual cosa podem utilitzar-los en el nostre codi, com anirem veient a continuació:

| Propietat | Descripció |
| --- | --- |
| .length | Retorna el número de caràcters totals del text. |

En el cas dels strings, només tenim una propietat important, `.length`, que s'encarrega de retornar el mida total de la cadena de text en qüestió, com es pot veure en els següents exemples:

> **📌 JS**
> 

```html
"Hola".length;    // 4
"Adiós".length;   // 5
"".length;        // 0
"¡Yeah!".length;  // 6
```

Nótese que es ha utilitzat  directament, sense necessitat de guardar-los en una variable.

### **Accés a un caràcter**

Si el pensem bé, un  està format per caràcters, de forma que el text `"Hola"`, aquesta format pels caràcters `"H"`, `"o"`, `"l"` i `"a"`. Si volem accedir a cada un d'ells, podem utilitzar l'operador `[]` indicant la posició a la que volem accedir:

> **📌 JS**
> 

```html
const text = "Hola";

text[0];      // "H"
text[1];      // "o"
text[2];      // "l"
text[4];      // undefined
```

Si intentem accedir a una **posició** (*índex*) que no existeix, ens retornarà `undefined` (*no està definit*).

### **Obtindre posició o índex**

Existeixen diversos mètodes que permeten darnos informació sobre la **posició** o **ubicació** que ocupa un determinat caràcter o text. Com ja hem mencionado, aquesta posició també sol denominar-se **índex**. Vegem detalladament aquests mètodes:

| Mètode | Descripció |
| --- | --- |
| .charAt(pos) | Retorna el caràcter de la posició pos. Similar a l'operador [ ]. |
| .indexOf(text) | Retorna la primera posició del text text. |
| .indexOf(text, from) | Idem a l'anterior, partint des de la posició from. |
| .lastIndexOf(text) | Retorna la última posició del text text. |
| .lastIndexOf(text, from) | Idem a l'anterior, partint des de from cap a l'inici. |

> **📌 JS**
> 

```html
“Joan”.charAt(); // 'J’
“Joan”.charAt(0); // 'J’
“Joan”.charAt(1); // 'o’
“Joan”.charAt(10); // ’’

“Joan”[]; // Error
“Joan”[0]; // 'J’
“Joan”[1]; // 'o’
“Joan”[10]; // undefined

"LenguajeJS, página de Javascript".indexOf("n"); // 2
"LenguajeJS, página de Javascript".indexOf("n", 3); // 16
"LenguajeJS, página de Javascript".indexOf("n", 17); // -1

"LenguajeJS, página de Javascript".lastIndexOf("n"); // 16
"LenguajeJS, página de Javascript".lastIndexOf("n", 3); // 2
```

### **Obtindre fragments (substrings)**

Javascript també posseeix una sèrie de **mètodes** mitjançant els quals podem crear **substrings** formats per un fragment del  original. Vegem de que mètodes es tracta:

| Mètode | Descripció |
| --- | --- |
| .repeat(num) | Retorna el repetido num vegades. |
| .substring(start, end) | Retorna el **substring** des de la posició start fins a end. |
| .substr(start, size) | Retorna el **substring** des de la posició start fins a start+size. |
| .slice(start, end) | Idem a .substr() amb [leves diferències](https://stackoverflow.com/a/2243835). |

> **📌 JS**
> 

```html
const text = "Jamón";
text.repeat(4); // "JamónJamónJamónJamón"
text.repeat(1); // "Jamón"
text.repeat(0); // ""
text.repeat(-1); // ERROR (Valor negativo)

const text = "Submarino";
text.substring(3); // 'marino' (desde el 3 en adelante)
text.substring(3, 5); // 'ma' (desde el 3, hasta el 5)
text.substr(3); // 'marino' (desde el 3 en adelante)
text.substr(3, 5); // 'marin' (desde el 3, hasta el 3+5)
text.substr(-3); // 'ino' (desde la posición 3 desde el final, en adelante)
text.substr(-3, 2); // 'in' (desde la posición 3 desde el final, hasta 2 posiciones más)
```

### **Dividir un text en parts (array)**

Un mètode molt útil i versátil és `.split(text)`. Permet **dividir** un  pel substring `text` utilizándolo com separador les vegades que faça falta. Com resultat, retornarà un  amb cada una de les parts dividides. És molt útil per a **crear arrays**, o dividir textos que tenen **separadors** repetits (*comes, punts, etc...*) en diverses parts:

| Mètode | Descripció |
| --- | --- |
| .split(text) | Separa el text en diverses parts, usant text com separador. |
| .split(text, limit) | Idem, però crea com a màxim limit fragments. |
| .split(regexp) | Separa el text usant la regexp com separador. |
| .split(regexp, limit) | Idem, però crea com a màxim limit fragments. |

Vegem alguns exemples indicant un  com separador:

> **📌 JS**
> 

```html
"88.12.44.123".split(".");    // ["88", "12", "44", "123"] (4 elementos)
"1.2.3.4.5".split(".");       // ["1", "2", "3", "4", "5"] (5 elementos)
"Hola a todos".split(" ");    // ["Hola", "a", "todos"] (3 elementos)
"A,B,C,D,E".split(",", 3);    // ["A", "B", "C"] (limitado a los 3 primeros elementos)
"Código".split("");           // ["C", "ó", "d", "i", "g", "o"] (6 elementos)
"88.12,44.123".split(/[.,]/); // ["88", "12", "44", "123"] (4 elements)
```

### **Comprovació en textos**

Els següents mètodes s'utilitzen per a realitzar algun tipus de **comprovació** i saber si un fragment de text **està inclòs** en un :

| Mètode | Descripció | Retorno |
| --- | --- | --- |
| .startsWith(text, from) | Comprova si el text comença per text. | Retornarà true si el string comença per text. En cas contrari, false. |
| .endsWith(text, to) | Comprova si el text acaba per text. | Retornarà true si el string acaba en text. En cas contrari, false. |
| .includes(text, from) | Comprova si el text conté el subtexto text. | Retornarà true si el string conté text. En cas contrari, false. |

> **📌 JS**
> 

```html
"Jose".startsWith("J"); // true ('Jose' empieza por 'J')
"Jose".startsWith("o", 1); // true ('ose' empieza por 'o')

"Jose".endsWith("o"); // false ('Jose' no acaba en 'o')
"Jose".endsWith("s", 3); // true ('Jos' acaba en 's')

"Jose".includes("os"); // true ('Jose' incluye 'os')
"Jose".includes("J", 1); // false ('ose' no incluye 'J')
```

### **Cerca de cadenes de textos**

Si necessitem realitzar una **cerca d'un text** (*que moltes vegades no tenim clar com és*) i volem obtindre informació com la posició o les cerques trobades, i els mètodes del tema anterior de posicions i substrings no ens serveixen (*o es ens queden cortos*), podem utilitzar algun dels següents:

| Mètode | Descripció | Retorno |
| --- | --- | --- |
| .search(regexp) | Cerca un patró que encatge amb regexp i retorna la posició encontrada. | Retorna la posició de la primera ocurrència. -1 si no es troba. |
| .match(regexp) | Idem a l'anterior, però retorna les coincidencias trobades. | Retorna un array amb les coincidencias trobades. null si no es troben. |
| .matchAll(regexp) | Idem a l'anterior, però retorna un iterador per a iterar per cada coincidencia. | Retorna un iterador per a poder recórrer les coincidencias trobades. |

> **📌 JS**
> 

```html
const text = "El gato, el perro y el pato.";
const regexp = /.a.o/g;

text.search(regexp);   // 3, porque la primera coincidencia ocurre en la posición 3 (gato)
text.match(regexp);    // ["gato", "pato"], las dos coincidencias encontradas
```

```html
const text = "El gato, el perro y el pato.";
const regexp = /.a.o/g;

const iterator = text.matchAll(regexp);
for (let ocurrence of iterator) {
    console.log(ocurrence);
}

// ['gato', index: 3, input: 'El gato, el perro y el pato.', groups: undefined]
// ['pato', index: 23, input: 'El gato, el perro y el pato.', groups: undefined]
```

### **Reemplaçar cadenes de text**

Si el que necessitem és reemplaçar un text, tenim a la nostra disposició una sèrie de mètodes, tant en versió on buscas mitjançant un , com en versió on buscas mitjançant una :

| Mètode | Descripció | Retorno |
| --- | --- | --- |
| .replace(text, newText) | Reemplaça la primera aparició del text per newText. | Reemplaça **només la primera aparició** d'un text (*excepte s'use regexp global*) |
| .replace(regexp, newText) | Idem, però cerca a partir d'una en lloc d'un . | Reemplaça **totes les aparicions amb alguns extras**. |
| .replaceAll(text, newText) | Reemplaça totes les aparicions del text text per newText. | Reemplaça **totes les aparicions** d'un text. |
| .replaceAll(regexp, newText) | Idem, però cerca a partir d'una en lloc d'un . | Reemplaça **totes les aparicions** d'un text. |

> **📌 JS**
> 

> 

```html
const text = "Hola gato, ¿eres un perro o eres un pato?";

// *** Reemplazar la primera ocurrencia
// Cambia la primera "a" por una "i"
text.replace("a", "i");       // "Holi gato, ¿eres un perro o eres un pato?"

// Cambia la primera "g" por una "p"
text.replace("g", "p");       // "Hola pato, ¿eres un perro o eres un pato?"

// Dos acciones. Cambia la primera "g" por una "p" y la primera "o" por una "a"
text.replace("g", "p")
    .replace("o", "a");       // "Hala pato, ¿eres un perro o eres un pato?"
```

```html
// *** Reemplazar todas las ocurrencias
text.replaceAll("e", "i");    // "Hola gato, ¿iris un pirro o iris un pato?"
```

```html
const frase = "Javascript es un gran lenguaje";
frase.replace(/[aeou]/g, "i");     // 'Jiviscript is in grin lingiiji'
```

### **Modificar strings**

Els següents mètodes realitzen algun tipus d'operació de modificació sobre un :

| Mètode | Descripció |
| --- | --- |
| .toLowerCase() | Retorna el string transformat a minúscules. |
| .toUpperCase() | Retorna el string transformat a majúscules. |
| .padStart(size, text) | Retorna el string emplenant l'inici amb text fins a arribar al mida size. |
| .padEnd(size, text) | Retorna el string emplenant el final amb text fins a arribar al mida size. |
| .trimStart() | Retorna el string eliminant espais a l'esquerra del text. |
| .trimEnd() | Retorna el string eliminant espais a la dreta del text. |
| .trim() | Retorna el string eliminant espais a l'esquerra i dreta del text. |

Observa que en tots els casos, es retorna un nou , en lloc de **mutar** l'original.

> **📌 JS**
> 

```html
"Nombre".toLowerCase();   // "nombre."
"Nombre".toUpperCase();   // "NOMBRE."

"15".padStart(5, "0");    // "00015"
"15".padStart(2, "0");    // "15" el tamaño es de dos caracteres, no incluye más
"A".padEnd(5, "-");    // "A----"

const text = "  ¡Saludad a vuestro nuevo rey gato!  ";

text.trim();        // "¡Saludad a vuestro nuevo rey gato!"
text.trimStart();   // "¡Saludad a vuestro nuevo rey gato!  "
text.trimEnd();     // "  ¡Saludad a vuestro nuevo rey gato!"

text.trimStart().trimEnd() === text.trim();     // true
```
