En javascript és molt senzill declarar i utilitzar variables, però encara que siga un procediment simple, cal tindre una sèrie de conceptes previos molt clars abans de continuar per a evitar futuras confusions, sobre tot si estem acostumbrats a altres llenguatges més tradicionals.

## **Variables**

En programació, les **variables** són espais o «compartimentos» on es pot guardar informació i asociar-la a un determinat nom al que farem referència durant el programa. D'aquesta forma, cada vegada que es consulte eixe nom posteriorment, et retornarà la informació que conté. La primera vegada que es realitza aquest pas es sol anomenar **inicialitzar una variable**.

### **Inicializació**

En Javascript, utilitzarem la paraula clau `let` per a inicialitzar variables. Si una variable no es inicializa amb un valor concret, contendrá un valor especial anomenat **undefined**, que significa que el seu valor no està definit encara, o el que és el mateix, que no conté informació:

> **📌 JS**
> 

```html
let a;          // Declaramos variable con nombre "a" (no le asociamos contenido)
let b = 0;      // Declaramos variable con nombre "b" (le asociamos el número 0)

console.log(b); // Muestra 0 (el valor guardado en la variable "b")
console.log(a); // Muestra "undefined" (no hay valor guardado en la variable "a")
```

> **📌 Tip**
> 

> Les majúscules i minúscules en els noms de les variables de Javascript **importan**. No és el mateix una variable anomenada **preu** que **Preu**, poden contindre valors diferents.

Si hem de declarar moltes variables consecutivas, una bona pràctica sol ser escriure només el primer `let` i separar per comes les diferents variables amb els seus respectivos continguts (*mètode 3*). Encara que es podria escriure tot en una mateixa línia (*mètode 2*), amb l'últim mètode el codi és molt més fàcil de llegir:

> **📌 JS**
> 

```html
// Método 1: Declaración de variables de forma independiente
let a = 3;
let c = 1;
let d = 2;

// Método 2: Declaración masiva de variables en el mismo let
let a = 3, c = 1, d = 2;

// Método 3: Igual al anterior, pero mejorando la legibilidad del código
let a = 3,
    c = 1,
    d = 2;
```

> **📌 Dada**
> 

> Antiguament, en Javascript es utilizava la paraula clau `var` per a inicialitzar variables. Encara que et el pots trobar o poden existir situacions on pot ser útil, hui en dia no té massa sentit utilitzar `var` en el nostre codi.

### **Reasignació**

Com el seu propi nom indica, una **variable** pot variar el seu contingut, ja que encara que continga una certa informació, es pot tornar a canviar. A aquesta acció ja no es li llamaría «inicialitzar» una variable, sinó «redeclarar» o «reasignar» una variable, ja que li estem canviant el seu contingut. En el codi es pot diferenciar perquè es omite el `let` (*la variable ja existeix*):

> **📌 JS**
> 

```html
// Inicializamos la variable "a" al valor 40.
let a = 40;

// Ahora, hemos redeclarado la variable a, que pasa a contener 50 en lugar de 40.
a = 50;
```

## **Constants**

En ECMAScript 2015 es afegeix la paraula clau **const**, que permet crear «compartimentos» similars a una variable, excepte que els valors que conté no poden ser modificats. Açò té diversos matices, així que anem a explicar-lo poc a poc. Observa el següent exemple:

> **📌 JS**
> 

```html
const name = "MAA";
console.log(name);

name = "Paco";  // Uncaught TypeError: Assignment to constant variable.
```

Com pots veure, la diferència respecte al `let` és que `const` assigna un valor i no permet reasignar-lo o redeclarar-lo posteriorment. A més, tampoc pots crear una constant sense indicarle un valor concret:

> **📌 JS**
> 

```html
const surname;  // Uncaught SyntaxError: Missing initializer in const declaration
```

En Javascript, és molt habitual declarar les variables amb `const` per a anunciar implícitament que eixos valors no cambiarán al llarg del programa, i en el cas que tinguem intencions de que cambien, declarar-les amb `let`. En eixos casos, es sol utilitzar **camelCase** com estratègia de nombrado.

## **Àmbits o contextos**

Un tema complex en el món de la programació és el dels **àmbits**, **scopes** o **contextos**. Quan comenzamos a aprendre sobre variables i constants, és bo aprendre i entendre bé els àmbits, ja que és la zona d'abast que té una variable.

En principi, existeixen dos àmbits molt bé definits:

- **Àmbit global**: Existeix al llarg de tot el programa o aplicació.

- **Àmbit local**: Existeix només en una xicoteta región del programa.

Normalment, açò es determina molt fàcilment observant les claus `{` i `}` (*curly braces*), que abren un nou àmbit o context.

### **Àmbits de variables**

Quan inicializamos una variable al principi del nostre programa i li assignem un valor, eixe valor generalment està disponible al llarg de tot el programa. No obstant això, açò pot variar depenent de múltiples factors. Es coneix com **àmbit d'una variable** a la zona on eixa variable existeix.

Per exemple, si consultamos el valor d'una variable abans d'inicializar-la, no existeix:

> **📌 JS**
> 

```html
console.log(e);  // Uncaught ReferenceError: e is not defined

let e = 40;
console.log(e);  // 40 (existe porque ya se ha inicializado en la línea anterior)
```

En l'exemple anterior, l'àmbit de la variable `e` comença a partir de la seua inicializació i "viu" fins al final del programa. A açò es li anomena **àmbit global** i és el cas més senzill. Observa que en la primera línia la variable `e` no existeix i dóna un error, però després de la linea del `let`, si retorna el seu valor perquè ahí si existeix.

No obstant això, açò es pot anar complicant a mesura que anem abrent claus d'instruccions com `if`, `else`, `for` o `while`. Observa el següent exemple:

> **📌 Exemple**
> 
Primer EjemploSegundo EjemploTercer Exemple 'FOR'

```html
let a = 1;
console.log(e);  // Uncaught ReferenceError: e is not defined

if (a == 1) {
    let e = 40;
    console.log(e);   // 40, existe
}

console.log(e);  // Uncaught ReferenceError: e is not defined
```

Observa que la variable `a` existeix en un àmbit global, mentre que la variable `e` només existeix en l'interior del `if`: és un àmbit local.

```html
let a = 1;
console.log(a); // Aquí accedemos a la "a", con valor 1

function x() {
    let a = 5; // Aquí volvemos a crear la variable.
    console.log(a); // Aquí "a" es 5 (a nivel de función)
}

console.log(a); // Aquí “a” es 1
```

En aquest cas creem la variable "a" i els assignem el valor "1", dins de la funció tornem a crear la variable "a" i li assignem el valor "5". El que veiem en l'exemple és que dins de la funció la variable a té un valor i fora d'eixa funció pren el valor "global", podem dir que les variables nacen i mueren dins dels curly braces.

```html
/** Opción 1: Bucle con let **/
console.log("Antes: ", p);    // Antes: undefined
for (let p = 0; p < 3; p++)
  console.log("- ", p);       // Durante: 0, 1, 2
console.log("Después: ", p);  // Después: undefined

/** Opción 2: Bucle con var **/
console.log("Antes: ", p);    // Antes: undefined
for (var p = 0; p < 3; p++)
  console.log("- ", p);       // Durante: 0, 1, 2
console.log("Después: ", p);  // Después: 3
```

Ací tenim la diferència de declarar una variable amb `let`o amb `var`, amb `let` la variable només té "vida" dins del for, mentre amb `var` la "vida" es estén per tota la funció.

![Scope o àmbits: Simba meme](../img/assets_images_ut04_scope-simba.jpg)

Es pot tornar un poc més complicat depenent de si utilitzar `let`, `const` o `var`, o depenent de l'anidació.

### **Àmbits amb `var` (legacy)**

Encara que declarar variables amb `var` ja es considera legacy (*obsoleto*) i no ha d'usar-se, si et interessa saber un poc més per si et l'encuentras, en aquest enfocament tradicional de Javascript, existeixen àmbits diferents: el **àmbit global** i el **àmbit a nivell de funció**. Aquesta diferència l'hem vist en l'últim exemple de l'apartat anterior.

Ara veurem exemples on veurem la declaració global i declaració a nivell de funció i els seus distints comportaments:

> **📌 JS**
> 

```html
var a = 1;
console.log(a); // Aquí accedemos a la "a" global, que vale 1

function x() {
console.log(a); // En esta línea el valor de "a" es undefined
var a = 5; // Aquí creamos una variable "a" a nivel de función

console.log(a); // Aquí el valor de "a" es 5 (a nivel de función)
console.log(window.a); // Aquí el valor de "a" es 1 (ámbito global)
}

x(); // Aquí se ejecuta el código de la función x()
console.log(a); // En esta línea el valor de "a" es 1
```

En l'exemple anterior veiem que el valor de `a` dins d'una funció no és el `1` inicial, sinó que estem en un altre àmbit diferent on la variable `a` anterior no existeix: un **àmbit a nivell de funció**. Mentre estiguem dins d'una funció, les variables inicialitzades en ella estaran en el **àmbit** de la pròpia funció.

> **📌 Important**
> 

> Estem usant l'objecte especial `window` per a accedir directament a l'àmbit global independentment d'on ens encontremos. Açò ocorre així perquè les variables globals s'emmagatzemen dins de l'objecte `window` (*la pestanya actual del navegador web*). Hui en dia, en lloc d'utilitzar `window` seria preferible utilitzar `globalThis`.
