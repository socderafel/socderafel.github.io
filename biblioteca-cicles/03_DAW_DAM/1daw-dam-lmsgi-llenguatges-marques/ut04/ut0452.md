Així com tenim un conjunt de mètodes per a realitzar sobre variables que siguen  o un altre conjunt de mètodes per a variables que siguen , existeix una sèrie de mètodes que podem utilitzar sobre variables que siguen de tipus . Són les anomenades **array functions** que veurem a continuació.

## **Què són les Array functions?**

Básicament, són mètodes que té qualsevol variable que siga de tipus , i que permet realitzar una operació amb tots els elements d'aquest array (*o part d'ells*) per a aconseguir un objectiu concret, depenent del mètode. En general, a aquests mètodes es els passa per paràmetre una **funció callback** i uns paràmetres opcionals.

Aquestes són les **Array functions** que podem encontrarnos en Javascript:

| Bloc | Mètode | Descripció |
| --- | --- | --- |
| Iteració | **.forEach(ƒ)** | Executa la funció definida en **ƒ** per cada un dels elements de l'array. |
| Comprobacions | **.every(ƒ)** | Comprova si **tots** els elements de l'array compleixen la condició de **ƒ**. |
| Comprobacions | **.some(ƒ)** | Comprova si **almenys** un element de l'array compleix la condició de **ƒ**. |
| Transformadors | **.map(ƒ)** | Construeix un array amb la qual cosa retorna **ƒ** per cada element de l'array. |
| Transformadors | **.filter(ƒ)** | Filtra un array i es queda només amb els elements que compleixen la condició de **ƒ**. |
| Transformadors | **.flat(level)** | Aplana l'array al nivell **level** indicat. |
| Transformadors | **.flatMap(ƒ)** | Aplana cada element de l'array, transformándolo segons **ƒ**. Equival a **.map().flat(1)**. |
| Cerques | **.findIndex(ƒ)** | Retorna la posició de l'element que compleix la condició de **ƒ**. |
| Cerques | **.find(ƒ)** | Retorna l'element que compleix la condició de **ƒ**. |
| Cerques | **.findLastIndex(ƒ)** | Idem a **findIndex()**, però començant a cercar des de l'últim element al primer. |
| Cerques | **.findLast(ƒ)** | Idem a **find()**, però començant a cercar des de l'últim element al primer. |
| Acumuladors | **.redueix(ƒ, initial)** | Executa **ƒ** amb cada element (d'izq a der), acumulant el resultat. |
| Acumuladors | **.reduceRight(ƒ, initial)** | Idem a l'anterior, però en ordre de dreta a esquerra. |

A grans rasgos, a cada un d'aquests mètodes es els passa una funció **callback** que s'executarà per cada un dels elements que conté l'array.

## **Iteració**

### **Bucles .forEach()**

El mètode **forEach()** no retorna res i espera que es li passe per paràmetre una **FUNCTION** que s'executarà **per cada element de l'array**.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d"];

// Con funciones por expresión
const f = function () {
  console.log("Un elemento.");
};
letters.forEach(f);

// Con funciones anónimas
letters.forEach((function () {
  console.log("Un elemento.");
});

// Con funciones flecha
letters.forEach(() => console.log("Un elemento."));
```

A l'anomenada es li poden passar 3 paràmetres, veiem com es pot passar en aquests exemples:

- Si es li passa un **primer paràmetre**, aquest serà l'element de l'array.

- Si es li passa un **segon paràmetre**, aquest serà la posició en l'array.

- Si es li passa un **tercer paràmetre**, aquest serà l'array en qüestió.

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d"];

//primer parámetro
letters.forEach(function(element) {
  console.log(element);
});

letters.forEach((element) => console.log(element));
// Devuelve 'a' / 'b' / 'c' / 'd'

//segundo parámetro
letters.forEach(function(element, index) {
  console.log(element, index);
});

letters.forEach((element, index) => console.log(element, index));
// Devuelve 'a' 0 / 'b' 1 / 'c' 2 / 'd' 3

//tercer parámetro
letters.forEach(function(element, index, array) {
  console.log("elemento:", element, "-", array[index]);
});

letters.forEach((element, index, array) => console.log("elemento: ",element, "-", array[index]));
// Devuelve elemento: 'a' - 'a'/elemento: 'b' - 'b'/elemento: 'c' - 'c'/elemento: 'd' - 'd'
```

En aquest exemple, he nombrado **element** al paràmetre que farà referència al **element**, **index** al paràmetre que farà referència a l'índex (*posició de l'array*) i **array** al paràmetre que farà referència al propi **array** en qüestió. En alguns exemples els abreviaré com **(e, i, a)**, pel seu inicial. Encara així, el programador pot ponerle a aquests paràmetres el nom que prefiera.

## **Comprobacions**

Existeixen dos mètodes per a realitzar comprobacions: el mètode **.every()** i el mètode **.some()**. Tots dos mètodes evalúan els elements de l'array i retornen sempre un **BOOLEAN**, que representa si es compleix o no.

**.every() (Tots)**.some() (Almenys un)**

### **El mètode .every() (Tots)**

El mètode **every()** permet comprovar si **tots i cada un** dels elements d'un array compleixen la condició que es especifique en la  **callback**:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d"];

// función flecha
letters.every((letter) => letter.length === 1); // true

// funsión anónima
letters.every(function(letter) {
  return letter.length === 1;
}); // true
```

La condició és que la longitud de cada element **STRING** de l'array siga **1**. Si aquesta funció retorna **true**, significa que compleix la condició, si retorna **false**, no la compleix. Per tant, si tots els elements de l'array retornen **true**, llavors **every()** retornarà **true**.

També podem fer l'exemple amb una funció per expressions i pot ser més fàcil seguir la traça del codi:

> **📌 JS**
> 

```html
const letters = ["a", "b", "c", "d"];

// Esta función se ejecuta por cada elemento del array
const condition = function (letter) {
  // Si el tamaño del elemento (string) es igual a 1
  if (letter.length == 1) {
    return true;
  }
  else {
    return false;
  }
};

// Si todos los elementos devuelven true, devuelve true
letters.every(condition);   // true
```

### **El mètode .some() (Almenys un)**

De la mateixa forma que el mètode anterior serveix per a comprovar si tots els elements de l'array compleixen una determinada condició, amb **some()** podem comprovar si **almenys un** dels elements de l'array, compleixen aquesta condició definida pel **callback**.

> **📌 Js**
> 

```html
const letters = ["a", "bb", "c", "d"];
//función anónima
letters.some(function(element) {
  return element.length == 2;
}); // true

// función flecha
letters.some((element) => element.length == 2);   // true
```

Observa que en aquest exemple, el mètode  **some()** retorna **true** perquè existeix almenys un element de l'array amb una longitud de **2** caràcters.

## **Transformadors i filtres**

En aquesta categoria es troben diversos mètodes que realitzen operacions de transformació o de filtrat, és a dir, són una variació dels elements d'un array (*transformació*) o filtres i es crea un array amb el resultat de la transformació o del filtre.

**.map()**.filter()**.flatMap()**

### **El mètode .map()**

El mètode **map()** és un mètode molt potent i útil per a treballar amb arrays, ja que el seu objectiu és retornar un nou **array** on cada un dels seus elements serà el que retorne la funció **callback** per cada un dels elements de l'array original:

> **📌 JS**
> 

```html
const names = ["Ana", "Pablo", "Pedro", "Pancracio", "Heriberto"];

// función anónima
const names = ["Ana", "Pablo", "Pedro", "Pancracio", "Heriberto"];
const nameSizes = names.map(function(name) {
  return name.length;
});

// función flecha
const nameSizes = names.map((name) => name.length);

nameSizes; // Devuelve [3, 5, 5, 9, 9]
```

Observa que l'array retornat per **map()** és **nameSizes**, i cada un dels elements que el componen, és el número retornat pel **callback** (name.length), que no és una altra cosa sinó el mida de cada .

Aquest mètode ens permet fer multitud d'operacions, ja que on devolvemos **name.length** podríem retornar el propi  modificat o qualsevol una altra cosa.

### **El mètode .filter()**

El mètode **filter()** permet filtrar els elements d'un array i retornar un nou array amb només els elements filtrats. Per a això, s'utilitza la funció **callback** per a establir una condició que retorna **true** només en els elements que interesan:

> **📌 JS**
> 

```html
const names = ["Ana", "Pablo", "Pedro", "Pancracio", "Heriberto"];

//función anónima
const filteredNames = names.filter(function(name) {
  return name.startsWith("P");
});

//función flecha
const filteredNames = names.filter((name) => name.startsWith("P"));

filteredNames; // Devuelve ['Pablo', 'Pedro', 'Pancracio']
```

En aquest exemple, es filtra només els elements en els que la seua primera lletra siga **P**. Per tant, la variable `filteredNames` serà un array amb només eixos elements.

Si no hi ha cap element que compleix amb la condició del filtre retornarà un **ARRAY** buit.

### **El mètode .flatMap()**

El mètode **.flat(level)** revisa tots els elements de l'array en cerca d'arrays imbricats, i els **aplana** fins al nivell **level** indicat per paràmetre.

Per exemple, considera el següent array:

> **📌 JS**
> 

```html
const values = [10, 15, 20, [25, 30], 35, [40, 45, [50, 55], 60]];

values.flat(0);         // [10, 15, 20, [25, 30], 35, [40, 45, [50, 55], 60]];
values.flat(1);         // [10, 15, 20, 25, 30, 35, 40, 45, [50, 55], 60];
values.flat(2);         // [10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60];

// Idem al anterior, pero si hubieran más niveles los aplanaría todos
values.flat(Infinity);
```

Es observa que l'array **values** té 6 elements, on el quart element i el sisè element són arrays imbricats. En l'array del quart element hi ha dos números, però en l'array del sisè element hi ha a la seua vegada un array amb quatre elements on el seu tercer element és novament un altre array. Estaríamos parlant de que l'array **values** té arrays fins a un **nivell 3**.

Amb **.flat()** es pot indicar el nivell desitjat per a «aplanar-lo».

Aquest mètode **.flat()** és la base del mètode **.flatMap(ƒ)**. Funciona de forma molt semblant al mètode **.map(ƒ)**, aplanant un nivell i transformant cada element de l'array, segons la funció passada per paràmetre. És a dir, el mètode **.flatMap(ƒ)** és l'equivalent a realitzar l'operació **.map(ƒ).flat(1)**:

> **📌 JS**
> 

```html
const values = [10, 15, 20, [25, 30], 35, [40, 45, [50, 55], 60]];
//función anónima
values.flatMap(function(element) {
  return Array.isArray(element) ? element.length : 1;
});

//función flecha
values.flatMap(element => Array.isArray(element) ? element.length : 1 );
// [1, 1, 1, 2, 1, 4]
```

L'exemple anterior, realitza una **.flatMap()** per l'estructura **values**. En primer lloc, recorre cada un dels elements mitjançant un **map()** per a transformar-los: si són un array, retorna la seua quantitat d'elements, si no és un array, retorna **1**. Finalment, si l'array resultant tinguera algun array entre els seus elements (*que en aquest cas és impossible*), li aplicaría un **flat(1)**.

## **Cerques**

Una altra tasca habitual i necessària és la de realitzar cerques d'elements en un array. Mitjançant els següents mètodes es poden realitzar cerques d'elements concrets, ja siga cercant des del principi o des del final, així com quedar-se amb l'element cercat o la posició en l'array de l'element cercat.

**.find() i .findIndex()**.findLast() i .findLastIndex()**

### **El mètode .find() i .findIndex()**

Dins de les **Array functions**, existeixen dos mètodes de cerca **find()**  i **findIndex()** . Tots dos s'utilitzen per a cercar elements d'un array mitjançant una condició, la diferència és que el primer retorna l'element mentre que el segon retorna la seua posició en l'array original.

> **📌 JS**
> 

```html
const names = ["Ana", "Pablo", "Pedro", "Pancracio", "Heriberto"];

//función anónima
names.find(function(name) {
    return name.length == 5;
});       // 'Pablo'

names.findIndex(function(name) {
    return name.length == 5;
});  // 1

//función flecha
names.find((name) => name.length == 5);       // 'Pablo'
names.findIndex((name) => name.length == 5);  // 1
```

La condició que hem utilitzat en aquest exemple és cercar l'element que té **5** caràcters de longitud. Al buscar-lo en l'array original, el primer que trobem és **Pablo**, ja que **find()** retornarà **Pablo** i **findIndex()** retornarà **1**, que és la segona posició de l'array on es troba.

En el cas de no trobar cap element que complisca la condició, **find()** retornarà **UNDEFINED**, mentre que **findIndex()**, que ha de retornar un **NUMBER**, retornarà **-1**.

### **El mètode .findLast() i .findLastIndex()**

De la mateixa forma, tenim **findLastIndex()** i **findLast()**, que són les funcions equivalents a **findIndex()** i **find()**, però cercant elements de dreta a esquerra, en lloc d'esquerra a dreta:

> **📌 JS**
> 

```html
const names = ["Ana", "Pablo", "Pedro", "Pancracio", "Heriberto"];

//función anónima
names.findLast(function(name) {
    return name.length == 5;
});       // 'Pedro'

names.findLastIndex(function(name) {
    return name.length == 5;
});  // 2

//función flecha
names.findLast((name) => name.length == 5);       // 'Pedro'
names.findLastIndex((name) => name.length == 5);  // 2
```

En aquest cas, en lloc de trobar a **Pablo** (*posició 1*), el primer element que té 5 caràcters, com va cercant de dreta a esquerra, el primer que troba és **Pedro** (*posició 2*).

## Acumuladors

Finalment, els acumuladors permeten realitzar tasques per cada element de l'array, acumulant valors per a hacerles una modificació en cada iteració.

Els mètodes **redueix()** i **reduceRight()** s'encarreguen de recórrer tots els elements de l'array, i anar acumulant els seus valors (*o alguna operació diferent*) i sumar-lo tot, per a retornar la seua resultat final.

En aquests mètodes es troba un diferència en la seua funció **callback**, ara no es tenen disponibles els paràmetres opcionals **(element, index, array)** utilitzats fins al moment, ara es tenen disponibles els paràmetres **(first, second, iteration, array)**, que funciona de forma molt similar, però adaptado a aquest tipus d'acumuladors.

**.redueix()**.reduceRight()**

### **El mètode .redueix()**

El mètode **redueix()** recorre l'array d'esquerra a dreta. En el següent exemple en la primera iteració, `first` conté el valor del primer element de l'array i `second` del segon. En següents iteracions, `first` és l'acumulador que conté el que devolvió el **callback** en la iteració anterior, mentre que `second` és el següent element de l'array, i així sucesivament.

> **📌 JS**
> 

```html
const numbers = [95, 5, 25, 10, 25];
numbers.reduce((first, second) => {
  console.log(`F=${first} S=${second}`);
  return first + second;
});

// F=95  S=5    (1ª iteración: elemento 1: 95 + elemento 2: 5) = 100
// F=100 S=25   (2ª iteración: 100 + elemento 3: 25) = 125
// F=125 S=10   (3ª iteración: 125 + elemento 4: 10) = 135
// F=135 S=25   (4ª iteración: 135 + elemento 5: 25) = 160

// Finalmente, devuelve 160
```

### **El mètode .reduceRight()**

Al contrari que **redueix()**, el mètode **reduceRight()** acumula els elements de dreta a esquerra.

> **📌 JS**
> 

```html
const numbers = [95, 5, 25, 10, 25];

numbers.reduce((first, second) => first - second);
// 95 - 5 - 25 - 10 - 25. Devuelve 30

numbers.reduceRight((first, second) => first - second);
// 25 - 10 - 25 - 5 - 95. Devuelve -110
```

### **Paràmetre inicial**

És possible indicar un segon paràmetre opcional en el **.redueix()**. Aquest paràmetre és el valor inicial que vol prendre en el **redueix**, el que pot facilitar bastant la implementació. Es observa que en el primer exemple anterior, es realitzen 4 iteracions. No obstant això, a l'indicar aquest valor inicial de **zero** es realitzen 5 iteracions:

> **📌 JS**
> 

```html
const numbers = [95, 5, 25, 10, 25];
numbers.reduce((accumulator, nextElement) => {
  console.log(`F=${accumulator} S=${nextElement}`);
  return accumulator + nextElement;
}, 0);

// F=0   S=95   (iteración inicial): 0 + elemento 1: 95) = 95
// F=95  S=5    (1ª iteración: elemento 1: 95 + elemento 2: 5) = 100
// F=100 S=25   (2ª iteración: 100 + elemento 3: 25) = 125
// F=125 S=10   (3ª iteración: 125 + elemento 4: 10) = 135
// F=135 S=25   (4ª iteración: 135 + elemento 5: 25) = 160

// Finalmente, devuelve 160
```

Com es pot veure, hi ha una iteració 0 extra que és la que pren el valor inicial indicat, junt al primer element de l'array. Després, segueix iterant amb el resta d'elements.
