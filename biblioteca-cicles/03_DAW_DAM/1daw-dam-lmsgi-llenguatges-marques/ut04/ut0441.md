## **Variables amb contingut numèric**

En Javascript, els **números** són un dels tipus de dades bàsics (*tipus primitius*), que, per a crear-los, simplement basta amb escribirlos literalment. No obstant això, com en Javascript tot es pot representar amb objectes (*com veurem més avant*) també es poden declarar mitjançant la paraula clau `new`:

| Constructor | Descripció |
| --- | --- |
| `new Number(number)` | Crea un objecte numèric a partir del número `number` passat per paràmetre. |
| `number` | Simplement, el número en qüestió. **Notació preferida**. |

No obstant això, encara que existisquen aquestes dos formes de declarar-les, no es sol utilitzar la notació `new` amb números, ja que és bastant més tedioso i complicat, per la qual cosa el preferible és utilitzar la notació de literals:

> **📌 JS**
> 

> 

```html
// Notación literal (preferida)
const number = 4;
const decimal = 15.8;

// Notación con objetos (evitar)
const number = new Number(4);
const decimal = new Number(15.8);
const letter = new Number("A");
```

Qualsevol paràmetre passat al `new Number()` que no siga un número (*per exemple, la `"A"`*), donarà com resultat un valor `NaN` (*Not A Number*), alguna cosa en el que profundizarem un poc més avant, en el següent apartat.

També hi ha casos, on un número molt gran (*o molt xicotet*) tinga un comportament extraño, com el següent:

> **📌 JS**
> 

```html
const incorrectNumber = 482598752875287528533; // 482598752875287540000 (Diferente)
const bigNumber = 482598752875287528533n;      // 482598752875287528533n (El mismo)
```

Observa que `incorrectNumber` no mostra realment el mateix número, sinó que és diferent. No obstant això, si li afegim una `n` al final, si que guarda la quantitat exacta.

- En el primer cas, estem guardant un número més gran dels que Javascript pot representar, llavors **perd precisió**.

- En el segon cas, en lloc de crear un tipus `Number`, afegint la `n` creem un tipus `BigInt`.

### **Constants numèriques**

Existeix una sèrie de **constants** definides per a poder determinar per exemple els límits mínim o màxims d'una un valor numèric. O si estem en un infinit positiu o negatiu.
en relació a aquest tema, que marcan els límits mínim o màxim. Vegem quals són i el seu significat:

| Constant | Valor en Javascript | Descripció |
| --- | --- | --- |
| Number.MAX_VALUE | ~ 21024 | Valor més gran |
| Number.MIN_VALUE | ~ 5×10 -324 | Valor més xicotet |
| Number.MAX_SAFE_INTEGER | 253 -1 | Valor segur més gran |
| Number.MIN_SAFE_INTEGER | -(253-1) | Valor segur més xicotet |
| Number.EPSILON | 2-52 | Número molt xicotet: ε |
| Number.POSITIVE_INFINITY | Infinity | Infinit positiu: +∞ |
| Number.NEGATIVE_INFINITY | -Infinity | Infinit negatiu: -∞ |

### **Comprobacions numèriques**

Si volem conèixer la naturalesa d'una variable numèrica (*número finito, número enter o número segur*), les podem comprovar amb un dels mètodes estátics de `Number` que tenim a continuació:

| Mètode | Descripció |
| --- | --- |
| Number.isFinite(number) | Comprova si number és un número finito. |
| Number.isInteger(number) | Comprova si number és un número enter. |
| Number.isSafeInteger(number) | Comprova si number és un número segur. |
| Number.isNaN(number) | Comprova si number no és un número. |

Tingues en compte que aquestes funcions retornen un  (*vertader o fals*), el que el fa ideals per a usar-les com condicions en bucles o condicionals. A continuació vegem dos exemples per a cada una d'aquestes funcions:

> **📌 JS**
> 

```html
// ¿Número finito?
Number.isFinite(42);          // true
Number.isFinite(551.3);       // true
Number.isFinite(Infinity);    // false, es infinito

// ¿Número entero?
Number.isInteger(5);          // true
Number.isInteger(4.6);        // false, es decimal

// ¿Número seguro?
Number.isSafeInteger(1e15);   // true
Number.isSafeInteger(1e16);   // false

1e309 === Infinity;           // true
Number.isSafeInteger(1e309);  // false

// ¿No es un número?
Number.isNaN(NaN); // true
Number.isNaN(5); // false, es un número
```

### **Conversió numèrica**

Que Javascript no siga un llenguatge fuertement tipat i no tinguem que declarar obligatòriament el seu tipus de dada, no significa que tinguem que despreocuparnos d'això. En moltes ocasions, tindrem variables string que ens interessa convertir a número per molts motivos (realitzar operacions posteriorment, convertirlas a una altra base numèrica, etc...).

#### **Convertir text a número**

Per a convertir un string en number en Javascript, l'ideal és utilitzar les funcions de parseo numèric, .parseInt() i .parseFloat(), que encara que són senzilles, tenen alguns detalls que hauríem de mencionar:

| Mètode | Descripció |
| --- | --- |
| Number.parseInt(s) | Converteix una cadena de text s en un número enter. |
| Number.parseInt(s,radix) | Idem a l'anterior, però des d'una base radix. |
| Number.parseFloat(s) | Converteix una cadena de text s en un número decimal. |
| Number.parseFloat(s,radix) | Idem a l'anterior, però des d'una base radix. |

> **📌 JS**
> 

```html
Number.parseInt("42");      // 42
Number.parseInt("42€");     // 42 (descarta todo desde un carácter no numérico)
Number.parseInt("Núm. 42"); // NaN (empieza a descartar en Núm, descarta también 42)
Number.parseInt("A");       // NaN (No se puede representar como un número)
Number.parseInt("");        // NaN (No se puede representar como un número)

Number.parseFloat("42.5");      // 42.5 (Conserva decimales)
Number.parseFloat("42");        // 42 (El número es entero, convierte a entero)
Number.parseFloat("88.99€");    // 88.99 (Conserva decimales)
Number.parseFloat("42€");       // 42 (El número es entero, convierte a entero)
Number.parseFloat("Núm. 33.5"); // NaN (empieza a descartar en Núm, descarta todo)
```

#### **Convertir número a text**

També ens podria interesar fer l'operació inversa. És a dir, tenim un número en base decimal i volem convertir-lo a una base numèrica diferent. Per a això, l'ideal és utilitzar el mètode .toString() dels string:

| Mètode | Descripció |
| --- | --- |
| Number.toString() | Converteix un número en text. |
| Number.toString(radix) | Converteix un número a la base número radix i el retorna com text. |

> **📌 JS**
> 

```html
(16).toString();        // "16"     (lo convierte a string)
(42.5).toString();      // "42.5"   (lo convierte a string)
(26).toString(2);       // "11010"  (26 en decimal, es 11010 en binario)
(80).toString(8);       // "120"    (80 en decimal, es 120 en octal)
(245123).toString(16);  // "3bd83"  (245123 en decimal, es 3bd83 en hexadecimal)
```

### **Representació numèrica**

En Javascript tenim dos formes de representar els números: la **notació exponencial** (*basada en potències de 10*) i la **notació de punt fix** (*una quantitat de dígitos per a la part entera, i una altra per a la part decimal*).

Podem canviar entre elles utilitzant els següents mètodes:

| Mètode | Descripció |
| --- | --- |
| .toExponential(digits) | Converteix el número a **notació exponencial** amb digits decimals. |
| .toFixed(digits) | Converteix el número a **notació de punt fix** amb digits decimals. |
| .toPrecision(size) | Utilitza size dígitos de precisió en el número. |

A més, el mètode `.toPrecision()` mitjançant el quin pots canviar la precisió d'un número. Observemos ara el següent exemple aplicant les funcions anteriors al número decimal `1.25` i al `523.75` per a canviar la precisió:

> **📌 JS**
> 

```html
// Notación exponencial
(1.25).toExponential(0);     // "1e+0"
(1.25).toExponential(1);     // "1.3e+0"
(1.25).toExponential(2);     // "1.25e+0"
(1.25).toExponential(3);     // "1.250e+0"

// Notación punto fijo
(1.25).toFixed(0);           // "1"
(1.25).toFixed(1);           // "1.3"
(1.25).toFixed(2);           // "1.25"
(1.25).toFixed(3);           // "1.250"

// Cambiando precisión
(523.75).toPrecision(1);      // "5e+2"
(523.75).toPrecision(2);      // "5.2e+2"
(523.75).toPrecision(3);      // "524"
(523.75).toPrecision(4);      // "523.8"
(523.75).toPrecision(5);      // "523.75"
```

## **NaN (Not A Number)**

L'acrónimo NaN és un valor especial de Javascript que significa literalment **Not A Number** (*No és un número*). No obstant això, no cal dejar-se portar pel seu significat literal, ja que ens podria donar lloc a malentendits. El valor NaN, malgrat el seu significat, s'usa per a representar **valors numèrics** (*i ara és on ve el matís*) que són indeterminats o imposibles de representar com número. (*També és un conegut podcast* :-P [NaN - Not a Number](https://www.youtube.com/@NotaNumber_podcast))

Dins d'eixa categoria hi ha diversos:

- **Indeterminació matemática**: Per exemple, 0 / 0.

- **Valors imposibles**: Per exemple, 4 - 'a', ja que és impossible restar una lletra a un número.

- **Operacions amb NaN**: Per exemple, NaN + 4, ja que el primer operant és NaN.

Un dels més freqüents és el segon, ja que Javascript és un llenguatge flexible que no requereix tipus. Això, unido a que la majoria de dades que extraemos d'una pàgina web s'obtenen com strings (cadenes de textos), dóna com resultat operacions d'eixe tipus, o concatenacions inesperades.

Per ací pots trobar les propietats i mètodes relacionats amb NaN que existeixen:

| Propietat o Mètode | Descripció |
| --- | --- |
| Number.NaN | És equivalent a NaN. Valor que no pot representar-se com número. |
| Number.isNaN(number) | Comprova si number no és un número. |

Observa que encara que NaN és un valor global, també existeix un Number.NaN com propietat de Number, per a tener-lo modularitzat i encapsulat com propietat estàtica en l'objecte Number.

### **Tots els NaN són diferents**

Com hem aquest, el valor `NaN` s'utilitza per a intentar representar un valor que no es pot representar. No obstant això, no podem comparar-lo literalment amb `NaN`, sinó que hem d'usar la funció `Number.isNaN()`:

> **📌 JS**
> 

```html
NaN == NaN;         // false (El valor no es el mismo)
NaN === NaN;        // false (Ni el valor, ni el tipo de dato es el mismo)

Number.isNaN(NaN);  // true (Forma correcta de comprobarlo)
Number.isNaN(5);    // false (5 es un número, no es un NaN)
Number.isNaN("A");  // false ("A" es un string, no es un NaN)
```

> **📌 Important**
> 

> Recorda que encara que desafortunadament, `NaN` significa **Not A Number** (*no és un número*), però `NaN` **sí** que és un valor numèric, el que ocorre és que eixe valor no és representable de forma numèrica:

> **📌 JS**
> 

```html
const number = NaN;

typeof number;              // "number"
number.constructor.name;    // "Number"
```

### **Conversions de valors NaN**

Si intentem convertir un valor `NaN` a un altre tipus de dada primitiu utilitzant un **typecast** (*forçar conversió explícita*), ens trobarem el següent:

> **📌 JS**
> 

```html
Boolean(NaN);   // false (convertimos a booleano)
String(NaN);    // "NaN" (convertimos a texto)
Number(NaN);    // NaN (Ya estaba en contexto numérico)
```

## **L'objecte Math**

Quan treballem amb Javascript, és possible realitzar gran quantitat de **operacions matemàtiques** de forma nativa, sense necessitat de llibreries externes. Per a això, farem ús de l'objecte `Math`, un objecte intern de Javascript que té incorporades certes constants i mètodes (*funcions*) per a treballar matemáticament.

### **Constants de Math**

L'objecte `Math` de Javascript incorpora diverses constants que podem necessitar en algunes operacions matemàtiques. Vegem el seu significat i valor aproximado:

| Constant | Descripció | Valor |
| --- | --- | --- |
| Math.E | Número de Euler | 2.718281828459045 |
| Math.LN2 | Equivalent a Math.log(2) | 0.6931471805599453 |
| Math.LN10 | Equivalent a Math.log(10) | 2.302585092994046 |
| Math.LOG2E | Equivalent a Math.log2(Math.E) | 1.4426950408889634 |
| Math.LOG10E | Equivalent a Math.log10(Math.E) | 0.4342944819032518 |
| Math.PI | Número PI o Π | 3.141592653589793 |
| Math.SQRT1_2 | Equivalent a Math.sqrt(1/2). | 0.7071067811865476 |
| Math.SQRT2 | Equivalent a Math.sqrt(2). | 1.4142135623730951 |

A més d'aquestes constants, l'objecte `Math` també ens proporciona gran quantitat de mètodes o funcions per a treballar amb números. Anem a analizar-los.

### **Mètodes matemátics**

Els següents mètodes matemátics estan disponibles en Javascript a través de l'objecte `Math`:

| Mètode | Descripció | Exemple |
| --- | --- | --- |
| Math.abs(x) | Retorna el valor absoluto de x. |  |
| Math.sign(x) | Retorna el signe del número: 1 positiu, -1 negatiu |  |
| Math.exp(x) | Exponenciació. Retorna el número e elevat a x. | ex |
| Math.expm1(x) | Equivalent a Math.exp(x) - 1. | ex-1 |
| Math.max(a, b, c...) | Retorna el número més gran dels indicats per paràmetre. |  |
| Math.min(a, b, c...) | Retorna el número més xicotet dels indicats per paràmetre. |  |
| Math.pow(base, exp) | Potenciació. Retorna el número base elevat a exp. | baseexp |
| Math.sqrt(x) | Retorna l'arrel cuadrad de x. | √x |
| Math.cbrt(x) | Retorna l'arrel cúbica de x. | √3x |
| Math.imul(a, b) | Equivalent a a * b, però a nivell de bits. |  |
| Math.clz32(x) | Retorna el número de zeros a l'esquerra de x en binari (32 bits). |  |

Vegem alguns exemples aplicats a les mencionades funcions anteriorment:

> **📌 JS**
> 

```html
Math.abs(-5);             // 5
Math.sign(-5);            // -1
Math.exp(1);              // e, o sea, 2.718281828459045
Math.expm1(1);            // 1.718281828459045
Math.max(1, 40, 5, 15);   // 40
Math.min(5, 10, -2, 0);   // -2
Math.pow(2, 10);          // 1024 (Equivale a 2**10)
Math.sqrt(2);             // 1.4142135623730951 (Equivale a Math.SQRT2)
Math.cbrt(2);             // 1.2599210498948732
Math.imul(0xffffffff, 7); // -7

// Ejemplo de clz32 (count leading zeros)
const x = 1;
"0".repeat(Math.clz32(x)) + x.toString(2);
// Devuelve "00000000000000000000000000000001"
```

Existeix més mètodes matemátics que veurem a continuació:

Mètode Math.random()Mètodes de logaritmosMétodos de redondeoMétodos trigonométrics

Un dels mètodes més útils i interesantes de l'objecte `Math` és `Math.random()`.

| Mètode | Descripció |
| --- | --- |
| Math.random() | Retorna un número a l'atzar entre 0 i 1 amb 16 decimals. |

Aquest mètode ens dóna un número a l'atzar entre els valors `0` i `1`, amb 16 decimals. Normalment, quan volem treballar amb números aleatorios, el que cerquem és obtindre un número enter a l'atzar entre `a` i `b`. Per a això, es sol fer el següent:

> **📌 JS**
> 

```html
// Obtenemos un número al azar entre [0, 1) con 16 decimales
let x = Math.random();

// Multiplicamos dicho número por el valor máximo que buscamos (5)
x = x * 5;

// Redondeamos inferiormente, quedándonos sólo con la parte entera
x = Math.floor(x);
```

Aquest exemple ens donarà en `x` un valor a l'atzar entre `0` i `5` (*5 no inclòs*). L'hem realitzat per passos per a entender-lo millor, però podem realizar-lo directament com es veu en el següent exemple:

> **📌 JS**
> 

```html
// Número al azar entre 0 y 5 (no incluido)
const x = Math.floor(Math.random() * 5);

// Equivalente al anterior
const x = ~~(Math.random() * 5);
```

Javascript incorpora diversos mètodes en l'objecte `Math` per a treballar amb logaritmes. Des de **logaritmes neperianos** fins a **logaritmes binaris** a través de les següents funcions:

| Mètode | Descripció | Exemple |
| --- | --- | --- |
| Math.log(x) | Retorna el logaritmo natural en base e de x. | loge x o ln x |
| Math.log10(x) | Retorna el logaritmo decimal (en base 10) de x. | log10 x ó log x |
| Math.log2(x) | Retorna el logaritmo binari (en base 2) de x. | log2 x |
| Math.log1p(x) | Retorna el logaritmo natural de (1+x). | loge (1+x) o ln (1+x) |

A continuació, uns exemples d'aquestes funcions aplicades en Javascript:

> **📌 JS**
> 

```html
Math.log(2);    // 0.6931471805599453
Math.log10(2);  // 0.3010299956639812
Math.log2(2);   // 1
Math.log1p(2);  // 1.0986122886681096
```

Com hem vist anteriorment, és molt comú necessitar mètodes per a **redondear números** i reduir el número de decimals o aproximar a una xifra concreta. Per a això, de forma nativa, Javascript proporciona els següents mètodes de redondeo:

| Mètode | Descripció |
| --- | --- |
| Math.round(x) | Retorna x amb **redondeo** (*l'enter més cercano*) |
| Math.ceil(x) | Retorna x amb **redondeo superior** (*l'enter més alt*) |
| Math.floor(x) | Retorna x amb **redondeo inferior** (*l'enter més sota*) |
| Math.fround(x) | Retorna x amb **redondeo** (*flotante amb precisió simple*) |
| Math.trunc(x) | Trunca el número x (*retorna només la part entera*) |

Vegem les diferències d'utilitzar els diferents **mètodes** anteriors per a redondear un número decimal i els resultats obtinguts:

> **📌 JS**
> 

```html
// Redondeo natural, el más cercano
Math.round(3.75);           // 4
Math.round(3.25);           // 3

// Redondeo superior (el más alto)
Math.ceil(3.75);            // 4
Math.ceil(3.25);            // 4

// Redondeo inferior (el más bajo)
Math.floor(3.75);           // 3
Math.floor(3.25);           // 3

// Redondeo con precisión
Math.round(3.123456789);    // 3
Math.fround(3.123456789);   // 3.1234567165374756

// Truncado (sólo parte entera)
Math.trunc(3.75);           // 3
Math.round(-3.75);          // -4
Math.trunc(-3.75);          // -3
```

Finalment, i no per això menys important, l'objecte `Math` ens proporciona de forma nativa una sèrie de mètodes trigonométrics, que ens permeten fer càlculs amb operacions com **seno**, **coseno**, **tangente** i relacionats:

| Mètode | Descripció |
| --- | --- |
| Math.sense(x) | Seno de x |
| Math.asin(x) | Arcoseno de x |
| Math.sinh(x) | Seno hiperbólic de x |
| Math.asinh(x) | Arcoseno hiperbólic de x |
| Math.cos(x) | Coseno de x |
| Math.acos(x) | Arcocoseno de x |
| Math.cosh(x) | Coseno hiperbólic de x |
| Math.acosh(x) | Arcocoseno hiperbólic de x |
| Math.tan(x) | Tangente de x |
| Math.atan(x) | Arcotangente de x |
| Math.tanh(x) | Tangente hiperbólica de x |
| Math.atanh(x) | Arcotangente hiperbólica de x |
| Math.atan2(x, i) | Arcotangente del quocient de x/i |
| Math.hypot(a, b..) | Retorna l'arrel cuadrada de a2 + b2 + ... |
