## **Condicionals**

Al fer un programa necessitarem establir condicions o decisions, on cerquem que el navegador realitze una acció A si es compleix una condició o una acció B si no es compleix. Aquest és el primer tipus d'estructures de control que trobarem. Per a això existeixen diverses estructures de control:

| Estructura de control | Descripció |
| --- | --- |
| `If` | **Condició simple**: Si ocorre alguna cosa, fes el següent... |
| `If/else` | **Condició amb alternativa**: Si ocorre alguna cosa, fes açò, sinó, fes açò un altre... |
| `?:` | **Operador ternario**: Equivalent a `If/else`, forma abreujada. |
| `Switch` | **Estructura per a casos específics**: Similar a diversos `If/else` imbricats. |

### **Condicional If**

Potser, el més conegut d'aquests mecanismes d'estructura de control és el `if` (*condicional*). Amb ell podem indicar en el programa que es tome un camino només si es compleix la **condició** que establezcamos.

> **📌 JS**
> 

```html
let nota = 7;
console.log("He realizado mi examen.");

// Condición (si la nota es mayor o igual a 5)
if (nota >= 5) {
console.log("¡Estoy aprobado!"); //como el valor de `nota`es mayor a 5, por consola aparecerá "¡Estoy aprobado!"
}
```

### **Condicional If / else**

Es pot donar el cas que vulguem establir una **alternativa** a una condició. Per a això utilitzem el `if` seguit d'un `else`. Amb açò podem establir una acció A si es compleix la condició, i una acció B si no es compleix.

Anem a modificar l'exemple anterior per a mostrar també un missatge quan estem suspendits, però en aquest cas, en lloc de mostrar el missatge directament amb un `console.log` anem a guardar eixe text en una nova variable `calificacion`:

> **📌 JS**
> 

```html
let nota = 7;
console.log("He realizado mi examen. Mi resultado es el siguiente:");

if (nota < 5) {
// Acción A: nota es menor que 5
calificacion = "suspendido";
} else {
// Acción B: Cualquier otro caso diferente a A (nota es mayor o igual que 5)
calificacion = "aprobado";
}

console.log("Estoy", calificacion);
```

Novament, en aquest exemple comprobarem que podem aconseguir que es mostre el missatge **Estic aprobado** o **Estic suspendido** depenent del valor que tinga la variable `nota`. La diferència amb l'exemple anterior és que creem una nova variable que contendrá un valor determinat depenent de la condició del `If`.

Finalment, el `console.log` del final, mostra el contingut de la variable `calificacion`, independentment de que siga el primer cas o el segon.

### **Condicional If múltiple**

És possible que necessitem crear un condicional múltiple amb més de 2 condicions, per exemple, per a establir la qualificació específica. Per a això, podem imbricar diversos `if/else` un dins d'un altre, de la següent forma:

> **📌 JS**
> 

```html
let nota = 7;
console.log("He realizado mi examen.");

// Condición
if (nota < 5) {
calificacion = "Insuficiente";
} else if (nota < 6) {
calificación = "Suficiente";
} else if (nota < 8) {
calificacion = "Bien";
} else if (nota <= 9) {
calificacion = "Notable";
} else {
calificacion = "Sobresaliente";
}

console.log("He obtenido un", calificacion);
```

No obstant això, imbricar d'aquesta forma diversos `if` sol ser molt poc llegible i produeix un codi repetitivo alguna cosa feo. En **alguns casos** es podria utilitzar una altra estructura de control anomenada `switch`, que veurem a continuació.

### **Condicional operador ternario**

L'operador ternario és una alternativa de condicional if/else d'una forma molt més corta i, en molts casos, més llegible. Reescribirem l'exemple anterior utilitzant aquest operador:

> **📌 JS**
> 

```html
condición ? valor verdadero : valor falso;
```

> **📌 JS**
> 

```html
let nota = 7;
console.log("He realitzat l’examen. El meu resultat es el següent:");

// Operador ternario: (condición ? verdadero : falso)
let calificacion = nota < 5 ? ”suspés" : "aprobat";
console.log("Estic", calificacion);
```

Aquest exemple fa exactament el mateix que l'exemple primer. La idea de l'operador ternario és que podem condensar molt codi i tindre un if en una sola línia. Obviament, és una opció que només es recomana utilitzar quan són if molt xicotets.

### **Condicional Switch**

L'estructura de control `switch` permet definir casos específics a realitzar quan la variable expuesta com condició siga igual als valors que es especifican a continuació mitjançant cada `case`:

> **📌 JS**
> 

```html
let nota = 7;
console.log("He realizado mi examen. Mi resultado es el siguiente:");

switch (nota) {
case 10:
    calificacion = "Sobresaliente";
    break;
case 9:
case 8:
    calificacion = "Notable";
    break;
case 7:
case 6:
    calificacion = "Bien";
    break;
case 5:
    calificacion = "Suficiente";
    break;
case 4:
case 3:
case 2:
case 1:
case 0:
    calificacion = "Insuficiente";
    break;
default:
    // Cualquier otro caso
    calificacion = "Nota errónea";
    break;
}

console.log("He obtenido un", calificacion);
```

Hi ha diverses puntualizacions que aclarar sobre aquest exemple, així que anem a explicar-lo:

- La sentència `switch` estableix que realitzarem múltiples condicions analitzant la variable `nota`.

- Cada condició es estableix mitjançant un `case`, seguit del valor possible de cada cas.

- El `switch` comença avaluant el primer `case`, i contínua amb el resta, cap a abaix.

- Observa que alguns `case` tenen un `break`. Açò fa que deje d'avaluar i es salga del `switch`.

- Els `case` que no tenen `break`, no es interrumpen, sinó que es salta al següent `case`.

- El cas especial `default` és com un `else`. Si no entra en cap dels anteriors, entra en `default`.

Tingues en compte que aquest exemple **no és exactament equivalent al que vam veure en el tema d'if/else**. Aquest exemple funcionaría si només permitimos notes que siguen **números enters**, és a dir, números del `0` al `10`, sense decimals. En el cas que `nota` tinguera per exemple, el valor `7.5`, mostraría `Nota errónea`, ja que no entraría en els casos anteriors.

> **📌 Important**
> 

> L'exemple dels `if múltiples` si controla casos de números decimals perquè establim comparacions de rangs amb major o menor, cosa que amb el **switch** no es pot fer. El **switch** està indicat per a **casos amb valors concrets i específics**.

Recorda que al final de cada cas és necessari indicar un `break` per a acabar i eixir del `switch`. En el cas que no siga faça, el programa saltará al següent cas, fins i tot encara que no es complisca la condició específica.
