## 1. De DTD a W3C XML Schema (XSD)

Encara que DTD va complir un paper fonamental en els orígens de la web, les necessitats corporatives modernes van posar de manifest greus mancances tècniques:
- **Sintaxi No XML:** DTD utilitza una sintaxi específica heretada de SGML, obligant les empreses a mantindre analitzadors independents.
- **Absència de Tipatge Fort:** DTD no pot validar si una dada és una data (ex: `2026-03-04`), un nombre decimal positiu o una adreça de correu vàlida; pràcticament tot és tractat com a text genèric (`#PCDATA` / `CDATA`).
- **Manca de Suport per a Espais de Noms (Namespaces):** DTD no pot gestionar de forma nativa la col·lisió de noms d'elements provinents de múltiples vocabularis XML diferents.

Per a resoldre aquestes limitacions, el World Wide Web Consortium (W3C) va estandarditzar **XML Schema Definition (XSD)** l'any 2001:
- Un document XSD **és en si mateix un fitxer XML ben format** (`.xsd`).
- Incorpora un catàleg de més de 40 tipus de dades predefinits (*built-in data types*).
- Permet crear tipus derivats per restricció o extensió, oferint una aproximació equivalent a la programació orientada a objectes.
- Suporta plenament els espais de noms XML.

## 2. Els Espais de Noms en XML (XML Namespaces)

Quan combinem dades de diferents vocabularis en un sol document XML, poden produir-se col·lisions de noms. Per exemple, la paraula `<taula>` pot referir-se a un moble en un catàleg de fusteria o a una matriu de dades d'una base de dades.

Un **Espai de Noms XML** (*Namespace*) utilitza un identificador uniforme de recursos (URI/URL) per a atorgar un nom universalment únic a un conjunt d'etiquetes:

```xml
<arrel 
  xmlns:fusteria="https://www.ies.edu/mobles"
  xmlns:bbdd="https://www.ies.edu/bases-dades">

  <!-- Element associat a l'espai de fusteria -->
  <fusteria:taula>
    <fusteria:material>Fusta de pi</fusteria:material>
  </fusteria:taula>

  <!-- Element associat a l'espai de bases de dades -->
  <bbdd:taula>
    <bbdd:nom>usuaris_matriculats</bbdd:nom>
    <bbdd:columnes>8</bbdd:columnes>
  </bbdd:taula>
</arrel>
```

## 3. L'Estructura Canònica d'un Fitxer XML Schema (.xsd)

Tot fitxer d'esquema XML comença amb l'element arrel `<xs:schema>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema"
           targetNamespace="https://www.ies-monastil.es/cicles"
           xmlns="https://www.ies-monastil.es/cicles"
           elementFormDefault="qualified">

  <!-- Definició de l'element arrel del document XML -->
  <xs:element name="modul" type="xs:string" />

</xs:schema>
```

### Atributs Fonamentals de `<xs:schema>`
- **`xmlns:xs="http://www.w3.org/2001/XMLSchema"`:** Declara el vocabulari oficial del W3C per a escriure l'esquema (proporciona els elements `<xs:element>`, `<xs:complexType>`, etc.).
- **`targetNamespace`:** La URI de l'espai de noms de negoci que aquest esquema està definint i protegint.
- **`elementFormDefault="qualified"`:** Estableix que tots els elements que apareguen en el document XML han d'anar qualificats de forma explícita amb el seu espai de noms.

### Vinculació en el Document XML Instància
```xml
<?xml version="1.0" encoding="UTF-8"?>
<modul xmlns="https://www.ies-monastil.es/cicles"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="https://www.ies-monastil.es/cicles esquemes/modul.xsd">
  Llenguatges de Marques i Sistemes de Gestió d'Informació
</modul>
```
