Per a transformar documents és imprescindible poder **localitzar i seleccionar parts concretes** de les dades d'origen. Cada ecosistema disposa del seu propi llenguatge de localització:

- **XPath** per a XML (utilitzat també dins de XSLT).

- **JSONPath** per a JSON.

Tots dos llenguatges comparteixen una idea comú: descriure la **ruta** que cal seguir dins de l'estructura del document per a arribar als nodes o valors desitjats.

## **XPath**

XPath és un llenguatge de consulta del W3C que permet navegar pels elements i atributs d'un document XML. És el mecanisme de selecció que utilitza XSLT.

### **Rutes de localització**

Una expressió XPath descriu la ruta des d'un node fins a un altre. Els elements es separen amb `/` i els atributs es indiquen amb `@`.

Partint d'aquest document:

> **📌 XML**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<catalogo>
    <producto id="p1" categoria="perifericos">
        <nombre>Teclado</nombre>
        <precio>25.50</precio>
    </producto>
    <producto id="p2" categoria="perifericos">
        <nombre>Ratón</nombre>
        <precio>12.00</precio>
    </producto>
    <producto id="p3" categoria="monitores">
        <nombre>Monitor 24"</nombre>
        <precio>199.90</precio>
    </producto>
</catalogo>
```

Algunes expressions XPath útils:

| Expressió | Resultat |
| --- | --- |
| `/catalogo/producto` | Tots els elements `producto`. |
| `/catalogo/producto[1]` | El primer producte. |
| `/catalogo/producto[@id='p2']` | El producte amb `id="p2"`. |
| `/catalogo/producto[@categoria='monitores']` | Els productes de la categoria `monitores`. |
| `/catalogo/producto/precio` | Tots els elements `precio`. |
| `/catalogo/producto/precio/text()` | Els valors de text dels preus. |
| `/catalogo/producto/@id` | Tots els atributs `id`. |
| `//producto` | Tots els productes en qualsevol nivell. |
| `/catalogo/producto[precio > 100]` | Els productes amb preu superior a 100. |

### **Operadors i funcions habituals**

- **Comparació:** `=`, `!=`, `<`, `>`, `<=`, `>=`.

- **Lògics:** `and`, `or`, `not()`.

- **Funcions:** `count()`, `concat()`, `contains()`, `string()`, `number()`.

## **JSONPath**

JSONPath és el llenguatge equivalent per a documents JSON. Va ser inspirado per XPath i segueix unes convencions similars, però adaptades a la sintaxi de JSON (objectes `{}` i arrays `[]`).

Partint d'aquest document:

> **📌 JSON**
> 

```html
{
  "catalogo": {
    "producto": [
      { "id": "p1", "categoria": "perifericos", "nombre": "Teclado", "precio": 25.50 },
      { "id": "p2", "categoria": "perifericos", "nombre": "Ratón", "precio": 12.00 },
      { "id": "p3", "categoria": "monitores", "nombre": "Monitor 24", "precio": 199.90 }
    ]
  }
}
```

Algunes expressions JSONPath útils:

| Expressió | Resultat |
| --- | --- |
| `$.catalogo.producto` | L'array de productes. |
| `$.catalogo.producto[0]` | El primer producte. |
| `$.catalogo.producto[*].nombre` | Tots els noms. |
| `$..nombre` | Tots els `nombre` en qualsevol nivell. |
| `$.catalogo.producto[?(@.precio > 100)]` | Els productes amb preu superior a 100. |
| `$.catalogo.producto[?(@.categoria == 'monitores')]` | Els productes de la categoria `monitores`. |
| `$.catalogo.producto.length` | El número de productes. |

### **Sintaxi dels filtres**

Els filtres de JSONPath es escriuen entre claudàtors i comencen amb `?`:

- `[?(@.campo == valor)]` → igualtat.

- `[?(@.campo != valor)]` → desigualtat.

- `[?(@.campo > valor)]` → comparació numèrica.

- `[?(@.campo =~ /regex/)]` → expressió regular.

### **jq com alternativa a JSONPath**

En la pràctica, l'eina `jq` ofereix una sintaxi molt similar a JSONPath però més potent. Per exemple, el filtre equivalent amb jq seria:

```html
jq '.catalogo.producto[] | select(.precio > 100)' catalogo.json
```

## **XPath enfront de JSONPath**

| Concepte | XPath | JSONPath |
| --- | --- | --- |
| Format | XML | JSON |
| Separador de nivells | `/` | `.` |
| Accés a arrays | `[1]` | `[1]` |
| Filtres | `[condición]` | `[?(condición)]` |
| Comodí | `*` | `*` o `[*]` |
| "En qualsevol nivell" | `//` | `..` |
| Atributs | `@nombre` | no existeixen (només JSON) |
