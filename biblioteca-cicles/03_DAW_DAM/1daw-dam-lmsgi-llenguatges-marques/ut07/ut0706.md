## **Eines de processament**

### **Per a XML / XSLT**

- **Saxon:** el processador XSLT més complet; suporta XSLT 1.0, 2.0 i 3.0.

- **xsltproc:** processador XSLT 1.0 de línia de comandes, estàndard en Linux/macOS.

- **xmllint:** utilitat per a validar i processar documents XML des de la terminal.

- **Oxygen XML Editor:** editor professional amb processament XSLT integrat.

- **Eines W3C online** per a validació i transformacions senzilles.

### **Per a JSON**

- **jq:** eina de terminal per a filtrar i transformar JSON.

- **jqPlay / JSONPath Online:** validadors i probadors d'expressions en el navegador.

- **AJV:** validador de JSON Schema (vist en la UP06).

- **Validació JSON Schema integrada en VSCode.**

### **Per a scripts generals**

- **Python:** bibliotecas `xml.etree.ElementTree`, `lxml`, `json` i `csv`.

- **Node.js:** mòduls `fs`, `xml2js`, `csv-parser`.

## **Casos pràctics**

### **Cas 1: Conversió estructural (XML → XML)**

Adaptar l'estructura d'un document XML a un altre esquema distint. Exemple: reanomenar elements i reorganitzar la seua ordre mitjançant plantilles XSLT.

```html
<xsl:template match="cliente">
    <customer>
        <name><xsl:value-of select="nombre"/></name>
        <id><xsl:value-of select="@codigo"/></id>
    </customer>
</xsl:template>
```

### **Cas 2: Conversió de presentació web (XML → HTML)**

Transformar dades puros en una pàgina web amb format (taules, llistes, estils). És el cas clàssic de XSLT a HTML vist en l'apartat 7.5.

```html
xsltproc catalogo.xsl catalogo.xml > catalogo.html
```

### **Cas 3: Interoperabilitat XML → JSON**

Fer que sistemes antics (XML) i aplicacions modernes (JSON) compartan informació. Es aconsegueix amb una full XSLT d'eixida de text o amb scripts de Python/Node.

```html
xsltproc empleados.xsl empleados.xml > empleados.json
```

### **Cas 4: Exportació plana (JSON → CSV)**

Generar fitxers tabulars a partir de dades JSON per a la seua importació en fulls de càlcul o bases de dades.

```html
jq -r '["producto","total"], (.ventas[] | [.producto, (.unidades * .precio)]) | @csv' ventas.json > ventas.csv
```

## **Flux de treball recomanat**

1. **Validar** el document d'origen (DTD/XSD/JSON Schema, UP06).

1. **Analitzar** l'estructura real de l'origen.

1. **Dissenyar** el document de destí.

1. **Escriure** l'especificació de conversió.

1. **Provar** amb dades reals i comprovar l'eixida.

1. **Automatitzar** el procés (scripts, cron, CI/CD) per a conversions periódiques.
