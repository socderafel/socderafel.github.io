Per a convertir documents entre formats és necessari disposar de tecnologies capaços de **llegir un document d'origen, aplicar unes regles de transformació i generar el document de destí**. En aquest apartat anem a identificar i comparar les principals tecnologies implicades en el processament de dades:

- **XSLT**, per a transformacions de XML.

- **jq**, per al processament de JSON des de la terminal.

- **Scripts** (Python, Node.js…) com alternativa generalista.

## **XSLT (XML Stylesheet Language Transformations)**

XSLT és un llenguatge de transformació basat en XML que permet convertir un document XML en un altre document (XML, HTML, text pla…). Va ser dissenyat pel W3C i és l'estàndard históric per a la conversió de documents XML.

Funciona mitjançant **plantilles** (templates): cada regla indica què elements del document d'origen processar i com transformar-los.

> **📌 Exemple: convertir un catàleg XML en HTML**
> 

> Document d'origen `catalogo.xml`:

> **📌 XML**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<catalogo>
    <producto id="p1">
        <nombre>Teclado</nombre>
        <precio>25.50</precio>
    </producto>
    <producto id="p2">
        <nombre>Ratón</nombre>
        <precio>12.00</precio>
    </producto>
</catalogo>
```

Full d'estils `catalogo.xsl`:

> **📌 XSLT**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0"
                xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="html" encoding="UTF-8"/>

    <xsl:template match="/">
        <html>
            <body>
                <table border="1">
                    <tr><th>Nombre</th><th>Precio</th></tr>
                    <xsl:for-each select="catalogo/producto">
                        <tr>
                            <td><xsl:value-of select="nombre"/></td>
                            <td><xsl:value-of select="precio"/></td>
                        </tr>
                    </xsl:for-each>
                </table>
            </body>
        </html>
    </xsl:template>
</xsl:stylesheet>
```

El resultat és un document HTML amb una taula amb els productes del catàleg.

### **Elements principals de XSLT**

- `<xsl:stylesheet>` → element arrel de la full d'estils.

- `<xsl:output>` → defineix el format d'eixida (xml, html, text).

- `<xsl:template match="...">` → defineix una regla de transformació.

- `<xsl:apply-templates>` → processa els elements fills que coincidan amb altres plantilles.

- `<xsl:value-of select="...">` → insereix el valor d'un element o atribut.

- `<xsl:for-each select="...">` → itera sobre un conjunt de nodes.

- `<xsl:if test="...">` → executa un bloc si es compleix una condició.

- `<xsl:choose>` / `<xsl:when>` / `<xsl:otherwise>` → condicional múltiple.

### **Versions**

- **XSLT 1.0 (1999):** la més extendida i compatible; soportada per tots els procesadors.

- **XSLT 2.0 (2007):** afegeix tipus, agrupacions i més funcions (XPath 2.0).

- **XSLT 3.0 (2017):** incorpora transformacions en streaming, mapes i JSON.

## **jq (JSON Query)**

jq és una eina de línia de comandes, lleugera i de codi obert, dissenyada específicament per a **filtrar, transformar i processar documents JSON**. És l'equivalent pràctic de XSLT per a l'ecosistema JSON i és imprescindible en el treball amb APIs REST.

> **📌 Exemple: filtrar dades d'un JSON**
> 

> Document `empleados.json`:

> **📌 JSON**
> 

```html
{
  "empleados": [
    { "nombre": "Ana",   "departamento": "Informática", "salario": 3000 },
    { "nombre": "Luis",  "departamento": "Ventas",      "salario": 2000 },
    { "nombre": "Elena", "departamento": "Informática", "salario": 3500 }
  ]
}
```

Comandes:

```html
# Mostrar todos los nombres
jq '.empleados[].nombre' empleados.json

# Filtrar los de Informática
jq '.empleados[] | select(.departamento == "Informática")' empleados.json

# Generar un resumen (nombre y salario)
jq '.empleados[] | {nombre, salario}' empleados.json

# Calcular el salario medio
jq '[.empleados[].salario] | add / length' empleados.json
```

### **Característiques de jq**

- Filtres encadenats amb l'operador pipe `|`.

- Selecció condicional mitjançant `select(condición)`.

- Construcció de nous objectes amb `{...}` i arrays amb `[...]`.

- Operacions numèriques i d'agregació (`add`, `length`, `map`…).

- Lectura de dades des d'arxius o des de l'entrada estàndard (`cat datos.json | jq ...`).

## **Scripts de processament**

Per a conversions més complexes o que requereixen lògica de negoci, es solen utilitzar **llenguatges de programació** amb bibliotecas específiques:

- **Python:** `xml.etree.ElementTree`, `lxml`, `json` i `csv`.

- **Node.js:** mòduls natius `fs`, `xml2js`, `csv-parser`.

Aquests scripts permeten combinar lectura, transformació i escriptura de documents amb tota la potència d'un llenguatge de propòsit general.

## **Comparativa de tecnologies**

|  | XSLT | jq | Scripts (Python/Node) |
| --- | --- | --- | --- |
| Format d'origen | XML | JSON | Qualsevol |
| Sintaxi | XML (declarativa) | Filtres de terminal | Codi de programació |
| Curva d'aprenentatge | Mitjana | Baixa | Alta |
| Ús típic | XML → XML/HTML | JSON → JSON/CSV | Processos complexos |
| Idoneitat en DAW | Formativa / legats | APIs i terminal | Projectes reals |
