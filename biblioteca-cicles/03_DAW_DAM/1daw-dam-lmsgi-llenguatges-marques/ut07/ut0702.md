## 1. Concepte i Mecanismes de Vinculació de DTD

Una **Definició de Tipus de Document (DTD)** és un conjunt de regles gramaticals formals que defineixen quins elements, atributs i entitats poden aparèixer en un document XML i quines relacions jeràrquiques i de contingut mantenen entre si.

Un DTD pot vincular-se de dues formes:

### DTD Intern (Definit dins del mateix fitxer XML)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE biblioteca [
  <!ELEMENT biblioteca (llibre+)>
  <!ELEMENT llibre (titol, autor, any)>
  <!ELEMENT titol (#PCDATA)>
  <!ELEMENT autor (#PCDATA)>
  <!ELEMENT any (#PCDATA)>
  <!ATTLIST llibre isbn CDATA #REQUIRED>
]>
<biblioteca>
  <llibre isbn="978-84-123456">
    <titol>Llenguatges de Marques</titol>
    <autor>Equip Docent</autor>
    <any>2026</any>
  </llibre>
</biblioteca>
```

### DTD Extern (Arxiu separat .dtd)
Permet compartir una mateixa gramàtica entre milers de documents XML:
```xml
<!-- DTD de caràcter privat o de sistema local -->
<!DOCTYPE biblioteca SYSTEM "esquemes/biblioteca.dtd">

<!-- DTD de caràcter públic internacional formal -->
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
```

## 2. Declaració d'Elements i Operadors de Cardinalitat

La declaració `<!ELEMENT nom (contingut)>` estableix què pot contindre un element:
- **`#PCDATA` (Parsed Character Data):** Text pla analitzable pel motor XML.
- **`EMPTY`:** L'element ha de ser buit, no pot contindre text ni fills (`<!ELEMENT br EMPTY>`).
- **`ANY`:** L'element pot contindre qualsevol combinació de text i elements declarats en el DTD.

### Operadors d'Agrupació i Cardinalitat

| Operador | Significat i Ocorrències Permeses | Exemple de Declaració |
| :--- | :--- | :--- |
| *(cap)* | Exactament una ocurrència obligatòria (1) | `<!ELEMENT persona (nom, cognoms)>` |
| `?` | Opcional: zero o una ocurrència (0 o 1) | `<!ELEMENT persona (nom, segon_cognom?)>` |
| `*` | Zero, una o múltiples ocurrències (0 o més) | `<!ELEMENT llibre (autor*)>` |
| `+` | Una o múltiples ocurrències obligatòries (1 o més) | `<!ELEMENT comanda (linia_comanda+)>` |
| `,` | Seqüència ordenada estricta (apareixen en aquest ordre) | `<!ELEMENT alumne (dni, nom, email)>` |
| `|` | Elecció exclusiva o disjunció (apareix un o l'altre) | `<!ELEMENT pagament (targeta | transferencia)>` |

## 3. Declaració d'Atributs (ATTLIST) i Entitats

La sintaxi per a declarar atributs és:  
`<!ATTLIST nomElement nomAtribut tipusAtribut comportament>`

```dtd
<!ATTLIST empleat
  id_empleat   ID          #REQUIRED
  departament  IDREF       #IMPLIED
  tipus_jornada (completa | parcial | reduida) "completa"
  observacions CDATA       #IMPLIED
  empresa      CDATA       #FIXED "IES Monastil"
>
```

### Tipus d'Atributs Clau
- **`CDATA`:** Text pla arbitrari.
- **`ID`:** Identificador únic en tot el document (no pot començar per número).
- **`IDREF`:** Referència al valor d'un atribut de tipus ID existent en algun altre element del document (creant relacions clau primària / forana).
- **Enumeració `(op1 | op2)`:** Llista tancada de valors de text permesos.

### Valors per Defecte i Modificadors
- **`#REQUIRED`:** L'atribut és obligatori en tots els elements d'eixe tipus.
- **`#IMPLIED`:** L'atribut és opcional; si no apareix, no s'aplica cap valor.
- **`"valor"`:** L'atribut és opcional; si s'omet, pren aquest valor per defecte.
- **`#FIXED "valor"`:** L'atribut només pot tindre exactament eixe valor constant fixat.
