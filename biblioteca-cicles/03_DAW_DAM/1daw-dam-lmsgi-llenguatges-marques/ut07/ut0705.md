Crear una especificació de conversió és un procés **metódic** que segueix diversos passos. No consisteix en escriure regles a l'atzar, sinó en dissenyar primer la transformació i després implementar-l'amb la tecnologia elegida.

## **Passos per a crear una especificació**

### **1. Analitzar el document d'origen**

Identificar l'estructura real del document que es vol transformar: elements, atributs, repeticions i opcionalitats.

### **2. Definir el document de destí**

Decidir el format d'eixida (XML, HTML, JSON, CSV…) i la seua estructura esperada: què camps, en què ordre i amb què transformacions.

### **3. Establir les regles de transformació**

Connectar origen i destí: què element d'origen produeix cada part de l'eixida, què valors es filtran i què condicions es apliquen.

### **4. Implementar i provar**

Escriure l'especificació (XSLT o jq) i probar-la contra exemples reals, corrigent els errors que apareguen.

## **Exemple guiat: de XML a HTML**

Partim d'un catàleg de productes en XML i volem generar una pàgina HTML amb una taula ordenada.

### **Origen: `catalogo.xml`**

> **📌 XML**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<catalogo>
    <producto id="p1" categoria="perifericos">
        <nombre>Teclado</nombre>
        <precio>25.50</precio>
    </producto>
    <producto id="p2" categoria="perifericos">
        <nombre>Ratón</nombre>
        <precio>12.00</precio>
    </producto>
    <producto id="p3" categoria="monitores">
        <nombre>Monitor 24"</nombre>
        <precio>199.90</precio>
    </producto>
</catalogo>
```

### **Especificació: `catalogo.xsl`**

L'especificació crea un HTML amb una capçalera i una taula. Cada `producto` genera una fila, i s'aplica un estil distint als productes amb preu superior a 100 €.

> **📌 XSLT**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0"
                xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="html" encoding="UTF-8"/>

    <xsl:template match="/">
        <html>
            <head><title>Catálogo</title></head>
            <body>
                <h1>Catálogo de productos</h1>
                <table border="1">
                    <tr><th>ID</th><th>Nombre</th><th>Categoría</th><th>Precio</th></tr>
                    <xsl:for-each select="catalogo/producto">
                        <tr>
                            <td><xsl:value-of select="@id"/></td>
                            <td><xsl:value-of select="nombre"/></td>
                            <td><xsl:value-of select="@categoria"/></td>
                            <td>
                                <xsl:choose>
                                    <xsl:when test="precio &gt; 100">
                                        <b><xsl:value-of select="precio"/> €</b>
                                    </xsl:when>
                                    <xsl:otherwise>
                                        <xsl:value-of select="precio"/> €
                                    </xsl:otherwise>
                                </xsl:choose>
                            </td>
                        </tr>
                    </xsl:for-each>
                </table>
            </body>
        </html>
    </xsl:template>

</xsl:stylesheet>
```

Nota: en XSLT el caràcter `>` ha d'escriure's com `&gt;` dins dels atributs `test`.

### **Conversió**

Amb el processador Saxon (o `xsltproc` en Linux):

```html
xsltproc catalogo.xsl catalogo.xml > catalogo.html
```

El resultat és un HTML complet, listo per a obrir en el navegador.

## **Exemple guiat: de XML a JSON**

### **Origen: `empleados.xml`**

> **📌 XML**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<empleados>
    <empleado id="104">
        <nombre>Laura</nombre>
        <apellidos>García Pérez</apellidos>
        <departamento>Informática</departamento>
    </empleado>
    <empleado id="105">
        <nombre>Carlos</nombre>
        <apellidos>Ruiz López</apellidos>
        <departamento>Ventas</departamento>
    </empleado>
</empleados>
```

### **Especificació: `empleados.xsl`**

L'especificació genera un document JSON equivalent, transformant cada `empleado` en un objecte de l'array `empleados`.

> **📌 XSLT**
> 

```html
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0"
                xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="text"/>

    <xsl:template match="/">
        <xsl:text>{"empleados": [</xsl:text>
        <xsl:for-each select="empleados/empleado">
            <xsl:text>{"id": "</xsl:text>
            <xsl:value-of select="@id"/>
            <xsl:text>", "nombre": "</xsl:text>
            <xsl:value-of select="concat(nombre, ' ', apellidos)"/>
            <xsl:text>", "departamento": "</xsl:text>
            <xsl:value-of select="departamento"/>
            <xsl:text>"}</xsl:text>
            <xsl:if test="position() != last()"><xsl:text>, </xsl:text></xsl:if>
        </xsl:for-each>
        <xsl:text>]}</xsl:text>
    </xsl:template>

</xsl:stylesheet>
```

### **Resultat**

```html
{"empleados": [{"id": "104", "nombre": "Laura García Pérez", "departamento": "Informática"}, {"id": "105", "nombre": "Carlos Ruiz López", "departamento": "Ventas"}]}
```

## **Exemple guiat: de JSON a CSV amb jq**

### **Origen: `ventas.json`**

> **📌 JSON**
> 

```html
{
  "ventas": [
    { "producto": "Teclado", "unidades": 5, "precio": 25.50 },
    { "producto": "Ratón", "unidades": 10, "precio": 12.00 },
    { "producto": "Monitor 24", "unidades": 2, "precio": 199.90 }
  ]
}
```

### **Especificació amb jq**

L'especificació selecciona cada venda, calcula l'importe total i genera una línia CSV (separada per comes) amb encapçalament.

```html
jq -r '
  ["producto", "unidades", "precio", "total"],
  (.ventas[] | [.producto, .unidades, .precio, (.unidades * .precio)])
  | @csv
' ventas.json > ventas.csv
```

### **Resultat**

```html
"producto","unidades","precio","total"
"Teclado",5,25.5,127.5
"Ratón",10,12,120
"Monitor 24",2,199.9,399.8
```

L'opció `-r` de jq genera una eixida en text sense cometes i `@csv` formatea cada fila com CSV.
