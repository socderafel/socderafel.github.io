**RSS** (*Really Simple Syndication*) és part de la família dels formats XML, desenvolupat per a compartir la informació que s'actualitza amb freqüència entre llocs web. A més s'utilitza per a:

- Connectar amb sistemes de mensajería instantánea.

- Conversió RSS en missatges de correu electrònic.

- Transformar els enllaços favoritos del navegador en RSS.

## **Versions de RSS**

RSS ha sigut desenvolupat per tres organitzacions diferents, el que ha donat lloc a múltiples versions de RSS:

| Versió | Origen | Característiques |
| --- | --- | --- |
| **RSS 0.90** | Creat per Netscape en 1999. | Es basa en l'especificació RDF de metadades, amb la intenció de que el seu projecte My Netscape estuviese format per titulars d'altres webs. |
| **RSS 0.91** | Versió simplificada de RSS 0.90 que Netscape lanzó posteriorment. | El desenvolupament d'aquest format es detuvo per falta d'èxit, encara que l'empresa UserLand Programari va decidir usar aquesta versió per a desenvolupar blogs. |
| **RSS 1.0** | Creat pel RSS-DEV Working Group a partir de l'estàndard RSS 0.90. | És més estable i permet definir una quantitat major de dades que el resta de versions de RSS. |
| **RSS 0.92 - 0.94** | UserLand Programari rechazó l'estàndard RSS 1.0 per considerar-lo complex i continuó el desenvolupament del format RSS 0.91. | El seu sintaxi està incompleta i no compleixen totes les normes de XML. |
| **RSS 2.0** | Publicat per a subsanar els problemes de les versions 0.9x. | Un dels majors canvis és la creació d'un mecanisme de **extensions** mitjançant l'ús de *namespaces* de XML. Una extensió, per exemple, és **Mitjana RSS**. |

## **Document RSS**

Per a construir un canal de contingut és necessari crear un fitxer basat en **XML**. Aquest fitxer, que tindrà extensió `.rss`, es publicará en un dels directoris del lloc web des del que es oferta.

Els elements bàsics que formen part d'un document RSS són:

- **Capçalera** del document.

- **Canal** o canals.

- **Seccions**.

### **Capçalera**

La capçalera és la primera línia del document, que consisteix en una **declaració XML**. Per a la codificació s'utilitzarà preferentement **UTF-8**.

```html
<?xml version="1.0" encoding="UTF-8" ?>
```

### **Canal**

A continuació apareix l'etiqueta `<rss>`. La declaració RSS indica que és un document RSS i la versió emprada. L'element `<rss>` és el **element arrel** d'un document RSS.

Dins d'ella apareix un **canal** (etiqueta `<channel>`), que s'encarrega de descriure el feed RSS propiament aquest. El canal és el que determina el lloc web associat a la font web a la que fa referència el fitxer. No existeix cap restricció respecte a la quantitat de canals de continguts que es poden oferir des d'un lloc web.

```html
<rss version="2.0">
```

El canal té **3 elements fills obligatoris**:

| Element | Descripció |
| --- | --- |
| `<title>` | Títol del canal. |
| `<description>` | Descripció del canal. |
| `<link>` | Enllaç del canal. |

També hi ha diversos elements **opcionals**. Alguns d'ells són:

| Element | Descripció |
| --- | --- |
| `<language>` | Defineix l'idioma del canal. |
| `<category>` | Defineix una o més categories a les que pertany la font. |
| `<copyright>` | Indica qui posseeix els drets d'autor. |

> **📌 Elements obligatoris**
> 

> Tant el canal `<channel>` com cada secció `<item>` han d'incloure **obligatòriament** `title`, `description` i `link`.

### **Seccions**

Un canal està format per **seccions o articles**. Cada una de les seccions és una referència a la web que conté un dels serveis que es van a oferir. En un canal poden incluir-se tantes seccions com es vulga, el que fa que un canal de contingut puga tindre un mida enorme si conté un gran número d'enllaços independents.

Una secció es defineix amb l'element **`<item>`** i té **3 elements fills obligatoris**:

| Element | Descripció |
| --- | --- |
| `<title>` | Títol de l'article. |
| `<description>` | Descripció de l'article. |
| `<link>` | Enllaç de l'article. |

També hi ha diversos elements **opcionals**. Alguns d'ells són:

| Element | Descripció |
| --- | --- |
| `<author>` | Defineix l'autor o autora de l'article. |
| `<category>` | Defineix una o més categories a les que pertany la font. |
| `<guid>` | Defineix un identificador únic per a l'element. |

### **Exemple complet**

> **📌 Exemple de document RSS**
> 

```html
<?xml version="1.0" encoding="UTF-8" ?>
<rss version="2.0">
  <channel>
    <title>Mi canal RSS</title>
    <description>Canal de ejemplo del módulo LLMSGI</description>
    <link>http://www.ejemplo.com/</link>
    <language>es</language>
    <item>
      <title>Primer artículo</title>
      <description>Descripción del primer artículo</description>
      <link>http://www.ejemplo.com/articulo1</link>
      <author>alumno@ejemplo.com</author>
    </item>
  </channel>
</rss>
```
