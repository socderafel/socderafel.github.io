# Ejercicios 1-6 JavaScript
## Ejercicio 1

Algoritmo que lea tres números distintos y nos diga cual de ellos es el mayor (recuerda usar la estructura condicional Si y los operadores lógicos).

Número A
Número B
Número C

## Ejercicio 2

Diseñar un algoritmo que pida tres números; si el primero es negativo, debe mostrar el producto de los tres y si no lo es, imprimirá la suma.

Número A
Número B
Número C

## Ejercicio 3

Realizar un algoritmo que dado un número entero, muestre un mensaje diciendo si es par o impar. En el caso de ser 0, debe visualizar “el número no es par ni impar”.

Número
## Ejercicio 4

Un instituto desea saber qué porcentaje de chicos y qué porcentaje de chicas hay en el curso actual. Diseñar un algoritmo para este propósito.

Chicos
Chicas

## Ejercicio 5

Teniendo en cuenta que la clave es “eureka”, escribir un algoritmo que nos pida una clave. Solo tenemos 3 intentos para acertar, si fallamos los 3 intentos nos mostrara un mensaje indicándonos que hemos agotado esos 3 intentos. Si acertamos la clave, mostrará un mensaje de bienvenida a nuestra página web.

Password

## Ejercicio 6
