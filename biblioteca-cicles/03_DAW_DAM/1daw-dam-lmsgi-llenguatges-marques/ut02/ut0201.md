## 1. Evolució de l'Estàndard HTML i el Manifest del WHATWG

El llenguatge de marques d'hipertext va néixer al CERN l'any 1990 de la mà de Sir Tim Berners-Lee com un mecanisme simplificat d'intercanvi de documents acadèmics basat en SGML (Standard Generalized Markup Language). Durant els anys 90 i principis dels 2000, la fragmentació provocada per la «guerra de navegadors» (Netscape vs Internet Explorer) va dur al W3C a intentar una transició estricta cap a **XHTML 1.0** i **XHTML 2.0**, requerint sintaxi XML inflexible que provocava errors fatals en qualsevol xicotet defecte de codificació («Yellow Screen of Death»).

Davant d'aquest carreró sense eixida, l'any 2004 es va fundar el **WHATWG** (Web Hypertext Application Technology Working Group) format per enginyers d'Apple, Mozilla i Opera, amb l'objectiu de crear un estàndard orientat a aplicacions web riques, tolerant a fallades i amb retrocompatibilitat sòlida. Aquest esforç va culminar en **HTML5**, que des de 2019 es manté com un **Living Standard** (estàndard viu contínuament actualitzat) governat pel WHATWG amb el reconeixement oficial del W3C.

```html
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Portal educatiu de Desenvolupament d'Aplicacions Web i Multiplataforma.">
  <title>LMSGI - Estructura Semàntica HTML5</title>
  <link rel="stylesheet" href="css/estils.css">
  <link rel="icon" type="image/svg+xml" href="img/favicon.svg">
</head>
<body>
  <!-- Contingut visible -->
</body>
</html>
```

### Anàlisi del Pròleg i Metadades Crítiques

1. **`<!DOCTYPE html>`:** El preàmbul de document en HTML5 és minimalista i no requereix cap referència a DTDs exteriors complexes (a diferència de `HTML 4.01 Strict` o `XHTML 1.0 Transitional`). La seua funció exclusiva és forçar el motor de renderitzat del navegador a utilitzar el mode estàndard («No-Quirks Mode») evitant el mode de compatibilitat retroactiva amb navegadors obsolets.
2. **`<html lang="ca">`:** L'atribut `lang` declara l'idioma principal del document utilitzant codis BCP 47 (com `ca` per al valencià/català, `es` per al castellà, `en` per a l'anglès). És un requisit d'accessibilitat crític (WCAG 3.1.1) perquè permet als sintetitzadors de veu pronunciar el text amb la fonètica correcta i ajuda als traductors automàtics i cercadors.
3. **`<meta charset="UTF-8">`:** Defineix la codificació de caràcters del document com Unicode UTF-8. Aquesta declaració ha de situar-se imperativament dins dels primers 1024 bytes del document per a evitar atacs de confusió de caràcters i problemes de renderitzat d'accents i caràcters especials.
4. **`<meta name="viewport" content="width=device-width, initial-scale=1.0">`:** Configura la finestra d'enquadrament gràfic (*viewport*). Sense aquesta instrucció, els navegadors mòbils renderitzen la pàgina web assumint un escriptori virtual de 980 píxels d'amplada i apliquen zoom out, inutilitzant les media queries de disseny adaptatiu (Responsive Design).

## 2. L'Arbre Semàntic d'HTML5: Seccions i Fites d'Accessibilitat (Landmarks)

Abans d'HTML5, l'estructura de les pàgines es basava en divisions amorfes `<div>` diferenciades únicament per identificadors arbitraris (`<div id="cabecera">`, `<div id="menu">`, `<div id="cuerpo">`). Aquest enfocament representava una absència absoluta de semàntica que impedia a les tecnologies assistives (com JAWS, NVDA o VoiceOver) i als bots de cerca entendre la jerarquia i rellevància dels continguts.

HTML5 va introduir etiquetes semàntiques estructurals que mapegen directament rols WAI-ARIA d'accessibilitat:

```html
<header>
  <div class="logo">
    <img src="img/logo-ies.png" alt="Logotip de l'IES">
  </div>
  <nav aria-label="Navegació principal">
    <ul>
      <li><a href="#inici">Inici</a></li>
      <li><a href="#moduls">Mòduls</a></li>
      <li><a href="#contacte">Contacte</a></li>
    </ul>
  </nav>
</header>

<main>
  <section id="noticies">
    <h2>Darreres Notícies de Cicles Formatius</h2>
    
    <article>
      <header>
        <h3>Inici de les pràctiques FCT / FP Dual</h3>
        <p>Publicat el <time datetime="2026-03-01">1 de març de 2026</time></p>
      </header>
      <p>L'alumnat de segon curs de DAW i DAM inicia la seua estada formativa a empreses tecnològiques del nostre entorn.</p>
      <footer>
        <p>Categoria: <em>Formació en Centres de Treball</em></p>
      </footer>
    </article>
  </section>

  <aside aria-label="Informació complementària">
    <h3>Calendari Escolar</h3>
    <p>Properes dates d'avaluació final ordinària.</p>
  </aside>
</main>

<footer>
  <p>&copy; 2026 Departament d'Informàtica. Tots els drets reservats.</p>
</footer>
```

### Glossari Tècnic d'Elements Estructurals

| Element | Rol ARIA Natiu | Propòsit Semàntic i Regles d'Ús |
| :--- | :--- | :--- |
| `<header>` | `banner` (si és directe de body) | Capçalera introductòria que agrupa logotips, títols principals, cercadors o controls de navegació. Pot haver-hi múltiples `<header>` dins d'`<article>` o `<section>`. |
| `<nav>` | `navigation` | Bloc que conté vincles de navegació essencials (menús principals, paginacions, rutes de molles de pa). No tots els grups d'enllaços han de ser `<nav>`. |
| `<main>` | `main` | Representa el contingut central i dominant del document. **Només pot existir un únic `<main>` visible per document**, i no ha de contenir continguts repetitius (menús, peus o avisos legals). |
| `<section>` | `region` (si té títol) | Secció temàtica genèrica de contingut que ha d'anar acompanyada habitualment d'un encapçalament propi (`<h2>`-`<h6>`). S'utilitza per a dividir el document en capítols o àrees funcionals. |
| `<article>` | `article` | Contingut independent, autònom i reutilitzable per si mateix en un altre context (notícia, publicació de blog, targeta de producte, comentari d'usuari). |
| `<aside>` | `complementary` | Contingut relacionat tangencialment amb el contingut que l'envolta (barres laterals, glossaris, enllaços relacionats, publicitat contextuada). |
| `<footer>` | `contentinfo` (si és de body) | Peu de pàgina o de secció amb informació sobre autoria, llicències de copyright, termes legals o dades de contacte. |
| `<time>` | - | Representa una data o hora en format llegible per a humans, amb l'atribut `datetime` codificat en format estàndard ISO 8601 (ex: `2026-03-01T09:00:00Z`). |
