> Ejercicios JavaScript 1.- Algoritmo que lea tres números distintos y nos diga cual de ellos es el mayor (recuerda usar la estructura condicional Si y los operadores lógicos). 2.- Diseñar un algoritmo que pida tres números; si el primero es negativo, debe mostrar el producto de los tres y si no lo es, imprimirá la suma.
>
> 3.- Realizar un algoritmo que dado un número entero, muestre un mensaje diciendo si es par o impar. En el caso de ser 0, debe visualizar “el número no es par ni impar”. 4.- Un instituto desea saber qué porcentaje de chicos y qué porcentaje de chicas hay en el curso actual. Diseñar un algoritmo para este propósito.
>
> 5.- Teniendo en cuenta que la clave es “eureka”, escribir un algoritmo que nos pida una clave. Solo tenemos 3 intentos para acertar, si fallamos los 3 intentos nos mostrara un mensaje indicándonos que hemos agotado esos 3 intentos. Si acertamos la clave, mostrará un mensaje de bienvenida a nuestra página web.
>
> 6.- Una tienda ofrece un descuento del 15% sobre el total de la compra durante el mes de octubre. Dado un mes y un importe, calcular cuál es la cantidad que se debe cobrar al cliente. EXTRA.- Se pide representar el algoritmo que nos calcule la suma de los N primeros números pares, a partir del número N introducido por el usuario. Es decir, si insertamos un 5, nos haga la suma de 6+8+10+12+14.

> **✍️ 📋 Exercici / Qüestionari 2.2 — Web Base del Ejercicio JavaScript**
> Os subo la web que tenéis en el ejemplo con los ejercicios 1 y el Extra resueltos.
> Subo este recurso a modo de ayuda, hay alumnos que están teniendo dificultades para empezar a hacer los ejercicios.
> Los ejercicios que quedan por resolver se pueden solucionar con condicionales y para el ejercicio 5 os recomiendo que utilicéis una variable global donde almacene los intentos.
> Entendiendo los ejercicios 1 y el extra es suficiente para resolver el resto.
>
> Nota: Si una función de JS tiene un error el resto de funciones dejan de funcionar. Os podéis encontrar que al principio las funciones os funcionan y seguidamente hacéis una función nueva y dejan de funcionar todas las funciones. Mi consejo es que hagas otro JS solo con la función que no funcione, buscas el error y lo vuelves a copiar a tu JS original.
