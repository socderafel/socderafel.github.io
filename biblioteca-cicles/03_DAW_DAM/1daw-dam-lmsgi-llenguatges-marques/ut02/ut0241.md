## **Encapçalaments i paràgrafs**

Per a agrupar el text en paràgrafs s'usa l'element `<p>`. És un element de bloc (*block*).

Per als encapçalaments, en HTML es defineixen **6 elements (6 nivells)**. Cuanto menor és el número, major és la importància de l'encapçalament: el `<h1>` és el de major relevancia. Els encapçalaments es poden utilitzar per a organitzar jerárquicament el contingut de la pàgina.

```html
<h1>Encabezado de nivel 1</h1>
<h2>Encabezado de nivel 2</h2>
<h3>Encabezado de nivel 3</h3>
<h4>Encabezado de nivel 4</h4>
<h5>Encabezado de nivel 5</h5>
<h6>Encabezado de nivel 6</h6>
<p>Texto del párrafo</p>
```

## **Salts de línia i espais en blanc**

Els navegadors, al processar codi HTML, **ignoran els salts de línia** i, si troben diversos espais consecutius, els redueixen a un només (**colapsar espais**).

> **📌 Colapso d'espais**
> 

> Els navegadors **ignoran els salts de línia** i redueixen els espais consecutius a un només. Per a forzar-los s'utilitzen `<br>`, l'entitat `&nbsp;` o l'element `<pre>`.

- 

Si és necessari introduir un **salt de línia**, s'utilitza l'element `<br>`:

```html
Esto <br> introduce un salto de línea
```

- 

Per a introduir múltiples espais, es pot utilitzar la **entitat** `&nbsp;` (non-breaking space):

```html
<p>Aquí hay &nbsp;&nbsp;&nbsp;&nbsp;&nbsp; espacios</p>
```

- 

Per a conservar els salts de línia i els espais tal qual es escriuen, s'usa l'element `<pre>`:

```html
<pre>Esto es un bloque de código
con saltos de línea
y espacios en blanco</pre>
```

## **Elements que donen format al text d'un paràgraf**

| Element | Descripció |
| --- | --- |
| `<b>` | Indica que el text es pondrá en **negreta**. |
| `<i>` | Indica que el text es pondrá en **itálica o cursiva**. |
| `<u>` | Indica que el text es pondrá en **subratllat**. |
| `<sup>` | Indica que el text és un **supraíndice**. |
| `<sub>` | Indica que el text és un **subíndice**. |
| `<strong>` | Indica que el text estarà **ressaltat**. Habitualment els navegadors el resaltan poniéndolo en negreta. |

## **Elements en el text d'un paràgraf**

| Element | Descripció |
| --- | --- |
| `<a>` | Fa que el text tancat entre les etiquetes es convertisca en un **hipervínculo**. |
| `<em>` | Permet indicar **énfasis** (text en cursiva). |
| `<small>` | Permet inserir comentaris accesorios (lletra xicoteta). |
| `<abbr>` | Permet indicar el significat d'una **abreviatura o sigla**. |

### **L'hipervínculo `<a>`**

L'atribut més important de l'element `<a>` és **`href`**, que indica la URL del vínculo. A vegades s'usa `href="#"` per a referir-se a la pròpia pàgina en la que apareix el vínculo.

L'atribut **`target`** permet triar on s'obrirà el vínculo. Els valors més usats són:

| Valor | Descripció |
| --- | --- |
| `_blank` | L'enllaç s'obri en una finestra/pestanya nova. |
| `_self` | L'enllaç s'obri en la mateixa. És el valor per defecte. |

```html
<a href="https://es.wikipedia.org/" target="_blank">Wikipedia</a>
<a href="https://es.wikipedia.org/" target="_self">Wikipedia</a>
```
