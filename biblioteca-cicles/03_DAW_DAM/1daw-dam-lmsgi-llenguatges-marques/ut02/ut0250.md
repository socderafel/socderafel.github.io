Els llenguatges de marques es escriuen en **text pla**, la qual cosa és una avantatge respecte al processament. En aquest apartat veurem algunes eines per a visualitzar i crear documents HTML des de l'ordinador.

## **Navegadors**

L'opció "**Veure codi font**" de la pàgina apareix en els navegadors Chrome, Firefox i Microsoft Edge. En Opera l'opció equivalent es anomena *Origen de la pàgina*, mentre que en Safari l'opció és *Mostrar codi font de la pàgina*. En qualsevol cas, el resultat és el mateix: el navegador mostra el codi HTML descargado del servidor.

A més de la possibilitat de consultar el codi font, la majoria dels navegadors moderns disposen d'una sèrie d'eines conegudes com **eines per a desenvolupadors** (també denominades informalment *devtools*).

Entre les eines per a desenvolupadors, prenent Google Chrome com referència, es troben les següents pestanyes relativas a HTML:

- **Elements**: permet consultar l'estructura del document HTML i l'estil CSS aplicat a cada element. Es pot modificar els elements HTML i els estils i veure en temps real el resultat de les modificacions.

- **Sources**: es mostren tots els recursos descargats relatius a la pàgina HTML: el propi document, imatges, fulls d'estil CSS, fitxers JavaScript externs, etc. Permet consultar el codi HTML.

> **📌 Provar en el navegador**
> 

> Obri qualsevol pàgina web i polsa F12 (o botó dret → *Inspeccionar*). En la pestanya **Elements** verás l'arbre HTML i podràs modificar-lo en temps real.

## **Editors de text**

Exemples: Visual Studio Code, Atom, Brackets, Sublime Text, UltraEdit, Notepad++.

Val la pena fer referència en aquest punt al complemento **EMMET** ([https://emmet.io/](https://emmet.io/)), disponible en la majoria dels editors moderns i que proporciona una sèrie d'atajos per a la creació automàtica de codi. Funciona escrivint els atajos i polsant **Tab**.

> **📌 Exemple amb EMMET**
> 

> Escriu l'atajo `ul>li*3` i polsa **Tab** per a generar automàticament una llista desordenada amb tres elements `<li>`.

## **Editors visuals (WYSIWYG)**

Un nivell per damunt dels editors de text es troben els editors visuals, també denominats **WYSIWYG** (acrónimo de *What You See Is What You Get*, "el que veus és el que tens").

Algunes d'aquestes eines són Adobe Dreamweaver (comercial), BlueGriffon (gratuït amb alguns components comercials) i HTML Notepad (gratuït).

## **Editors online**

Exemples: JSFiddle, CodePen, CodeSandbox o Liveweave.

Aquests llocs web ofereixen editors en línia que permeten introduir codi HTML, CSS i JavaScript i comprovar en la mateixa pàgina i en temps real el resultat.
