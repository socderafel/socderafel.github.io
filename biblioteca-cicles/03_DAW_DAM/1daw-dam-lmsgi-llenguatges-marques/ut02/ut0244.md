Els **formularis** permeten recoger informació que l'usuari introdueix en el navegador per a un posterior tractament.

És important **validar les dades** introduïts per a detectar els possibles errors cometits per un usuari. La validació consisteix en revisar que les dades introduïts es ajustan a uns requisits. Preferiblement, la validació s'ha de realitzar en **local** (en el propi equip, sense enviar les dades al servidor). Normalment es combinen els formularis amb codi **JavaScript**, encara que HTML5 inclou alguns atributs que permeten realitzar alguns tipus de validacions sense programar codi.

## **Declaració d'un formulari**

L'obertura i tancament d'un formulari es fa mitjançant l'element `<form>`:

```html
<form name="mi-formulario" action="accion.php" method="GET"></form>
```

### **Atributs de `<form>`**

| Atribut | Descripció |
| --- | --- |
| `name` | Nom del formulari. |
| `action` | Acció que s'executa quan es polsa el botó d'enviar formulari. |
| `enctype` | Format en el que s'envien els valors del formulari. |
| `method` | Mètode d'enviament del protocol HTTP. Es pot triar entre el mètode `GET` i `POST`. |

### **Mètodes GET i POST**

| GET | POST |
| --- | --- |
| Permet passar valors en ASCII amb un límit de 100 caràcters. | Permet passar valors de variables i altres elements com arxius. |
| Els valors de les variables es poden veure en la URL (després d'un `?`, separats per `&`). | Carece de restriccions de longitud com el mètode GET. |
| `https://web.com/index.php?variable1=valor1&variable2=valor2` | Les variables i els seus valors no són visibles en la URL. |

> **📌 Dades sensibles amb GET**
> 

> Amb el mètode `GET` els valors són **visibles en la URL**. Per a dades sensibles (contrasenyes) o l'enviament d'arxius s'ha d'utilitzar `POST`.

## **Camps de formulari**

Dins d'un formulari pot haver diversos tipus de controls: camps de text, camps per a contrasenyes, selector de data, botons d'opció múltiple (*ràdio*), etc.

### **Atribut `name`**

Perquè el servidor puga identificar tots els camps d'un formulari s'usa l'atribut **`name`**. El valor indicat serà l'identificador que es haurà d'usar per a obtindre la informació introducida pel usuari.

Amb el mètode `GET`, la informació s'envia a través de la URL:

```html
<form action="" method="GET">
  <input type="text" name="direccion" />
  <input type="submit" value="Enviar" />
</form>
```

```html
https://ejemplo.com/?direccion=Santiago
```

Amb el mètode `POST`, la informació s'envia a través del *payload* de la petició HTTP. Aquest mètode és l'únic que podem utilitzar per a enviar imatges al servidor:

```html
<form action="" method="POST">
  <input type="text" name="direccion" />
  <input type="submit" value="Enviar" />
</form>
```

### **Camp de text `<input>`**

L'element `<input>` es pot usar per a diversos tipus de control. No té etiqueta de tancament. El tipus de control ve donat pel valor de l'atribut `type`.

```html
<input type="text" />
```

Els seus atributs principals són:

| Atribut | Descripció |
| --- | --- |
| `name` | Nom del camp. |
| `size` | Número de caràcters visibles en el camp. Per defecte, 20. |
| `maxlength` | Número màxim de caràcters que l'usuari podrà introduir. |
| `value` | Valor per defecte del camp de text. |
| `placeholder` | Valor sugerido; es presenta en color gris i desaparece al fer focus en el camp. |
| `readonly` | El valor del camp no pot ser modificat pel usuari. |
| `autofocus` | Sitúa el cursor del ratolí en el camp una vegada cargada la pàgina. |
| `required` | No es podrà enviar el formulari fins a que el camp estiga cubierto. |

### **Àrea de text `<textarea>`**

Permet recoger informació oberta de l'usuari permetent un major número de caràcters. Per a especificar un valor previo en el camp ha d'escriure's entre les etiquetes d'obertura i tancament.

Els seus atributs principals són: `name`, `rows` (número de files), `cols` (número de columnes), `wrap` (`soft` o `hard`), `placeholder`, `readonly`, `autofocus`, `required` i `maxlength`.

```html
Describa a continuación sus intereses: <br />
<textarea
  name="area"
  rows="5"
  cols="50"
  wrap="hard"
  placeholder="Escriba aquí sus intereses..."
  maxlength="200"
  required
></textarea>
```

### **Llista desplegable `<select>`**

L'element `<select>` permet crear una llista desplegable on l'usuari seleccione un valor entre diferents opcions. Per a definir cada opció s'utilitza l'element `<option>`.

| Atributs de `<select>` | Descripció |
| --- | --- |
| `name` | Nom de l'element. |
| `size` | Número d'elements de la llista desplegable que es mostraran. |
| `multiple` | Permet seleccionar diverses opcions mantenint pulsada la tecla Ctrl. |

| Atributs de `<option>` | Descripció |
| --- | --- |
| `selected` | Camp que apareix seleccionat per defecte. |
| `value` | Valor que es transmet quan s'envia el formulari. |

### **Botons de formulari**

- 

**Botó d'enviament**: permet enviar el formulari a un destinatari, que depèn del valor de l'atribut `action` de l'etiqueta `<form>`.

```html
<input type="submit" value="Enviar formulario">
```

- 

**Botó d'anulació**: esborra el contingut dels camps cubiertos en el formulari.

```html
<input type="reset" value="Vaciar formulario">
```

### **Altres tipus de `<input>`**

- 

**Checkbox**: permet que l'usuari indique si està conforme amb una o diverses opcions.

```html
<input type="checkbox" name="terminos" checked value="aceptar" /> Acepto las condiciones
```

- 

**Ocult**: camp no visible que transmet informació addicional.

```html
<input type="hidden" name="formulario_enviado" value="true">
```

- 

**Contrasenya**: el text introduït es mostra ocult.

```html
<input type="password" name="contrasena" placeholder="Introduce tu contraseña" />
```

- 

**Fitxers**: requereix formulari definit amb `POST` i `enctype="multipart/form-data"`.

```html
<input type="file" name="archivo"/>
```

- 

**Correu electrònic**, **URL** i **números enters**:

```html
<input type="email" name="email" placeholder="Introduce tu email" required />
<input type="url" name="url" placeholder="Introduce una URL"/>
<input type="number" min="0" max="100" step="10">
```

- 

**Dates** (dia, mes i any; mes i any; setmana; hora; dia, mes, any i hora):

```html
<input type="datetime-local">
<input type="date">
<input type="month">
<input type="week">
<input type="time">
```

- 

**Rangs**: permet seleccionar un valor dins d'un rang.

```html
<input type="range" min="0" max="100" value="25"/>
```

## **Organització de formularis**

### **Element `<label>`**

Permet associar a cada camp del formulari una etiqueta amb el seu nom. S'associa al camp mitjançant l'atribut `for`, que conté el valor de l'identificador (`id`) del camp.

```html
<label for="conforme">Acepto el acuerdo de licencia</label>
<input type="checkbox" name="licencia" id="conforme" value="ok">
```

### **Element `<fieldset>`**

Agrupa els camps de formulari que estiguen entre l'etiqueta d'obertura i tancament, rodeándolos amb un vora. L'element `<legend>` agrega un text relacionat amb els camps agrupats.

```html
<fieldset>
  <legend>Introduzca su nombre de usuario y contraseña</legend>
  <div>
    <label for="username">Usuario</label>
    <input type="text" id="username" name="user" required />
  </div>
  <br />
  <div>
    <label for="password">Contraseña</label>
    <input type="password" id="password" name="pass" required />
  </div>
</fieldset>
```
