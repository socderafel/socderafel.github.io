L'estructura d'una pàgina HTML ha de seguir la mateixa que la de qualsevol document XML. Per això, tindrà:

- Un **pròleg**.

- Un **exemplar**.

Un exemple complet d'un document HTML5 és el següent:

> **📌 Document HTML5 complet**
> 

```html
<!DOCTYPE html>            <!-- prólogo -->
<html>
  <head>
    <meta charset="utf-8" />
    <title>Título del documento</title>
  </head>
  <body>
    <p>LMSXI</p>
  </body>
</html>                    <!-- ejemplar -->
```

## **Pròleg**

Tot document HTML ha de tindre una **declaració del tipus de document** per a la seua correcta interpretació pel navegador web. En eixa declaració es indica:

- El **tipus de document**.

- En versions antigues de HTML, la **versió de HTML** utilitzada per a la codificació del mateix.

En el cas de HTML5, la declaració es defineix de la següent forma:

```html
<!DOCTYPE html>
```

## **Exemplar**

L'exemplar està delimitado pel element `<html>`, el qual defineix el **inici i el final** d'un document HTML. Un document HTML pot dividir-se, a la seua vegada, en dos parts:

- **Capçalera**

- **Cos**

Els elements que defineixen l'estructura bàsica d'un document són `<html>`, `<head>` i `<body>`.

### **Capçalera (`<head>`)**

L'element `<head>` defineix la capçalera d'un document HTML. Conté la informació sobre el títol de la pàgina, l'autor, paraules clau, etc. La informació de la capçalera **no es presentará en la finestra del navegador**, excepte el títol, que apareixerà en la barra de títol de la part superior. El resta de capçaleres habitualment s'utilitzen per a donar informació a buscadors, xarxes socials, etc.

Dins d'aquesta secció és **obligatori** definir el títol del document, usant les etiquetes `<title></title>`. És molt comú, també, incloure el *charset* utilitzat per a la codificació. Generalment, s'utilitza `utf-8`.

```html
<head>
  <meta charset="utf-8">
  <title>HTML document</title>
</head>
```

> **📌 El títol és obligatori**
> 

> L'element `<title>` és l'únic element **obligatori** dins de la capçalera: és el que es mostra en la barra de títol del navegador i en les pestanyes.

Els elements que poden anar dins de l'element `<head>` es classifiquen en dos tipus:

- 

**Elements contenidors**: contenen text i/o altres etiquetes.

| Element | Descripció |
| --- | --- |
| `title` | Títol del document. Element obligatori. |
| `script` | Script incrustado. El seu contingut ha d'anar situat entre les marques de comentaris, ja que no ha de ser interpretat. |
| `style` | Estil aplicat al document utilitzant CSS. El seu contingut ha d'anar situat entre les marques de comentaris, ja que no ha de ser interpretat. |

- 

**Elements no contenidors**: són etiquetes buides, sense contingut.

| Element | Descripció |
| --- | --- |
| `base` | URI base del document. |
| `link` | Enllaços a documents externs de llibreries (JavaScript). Aquest element també pot anar dins del `<body>`. |
| `meta` | Metadades sobre la pàgina, com la codificació de caràcters, descripció o autors. |

> **📌 Capçalera completa**
> 

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>El título es obligatorio</title>
    <base href="https://codesandbox.io/" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.2.1/dist/css/bootstrap.min.css" rel="stylesheet" />
    <style>
      .rojo {
        color: red;
      }
    </style>
    <script src="https://unpkg.com/react@18/umd/react.development.js"></script>
  </head>
  <body>
    <div class="rojo">Texto de color rojo</div>
  </body>
</html>
```

### **Cos (`<body>`)**

El cos conté la **informació que es va a presentar en la pantalla**. L'element `<body>` permet definir formats que es apliquen als elements de la pàgina de manera global, com, per exemple, el color de fons del text o l'amplària dels marges.

```html
<html>
  <head></head>
  <body></body>
</html>
```

### **Comentaris**

Existeix la possibilitat d'introduir comentaris en els fitxers HTML, que també poden ser multilínea:

```html
<!-- comentario -->
```

```html
<!-- comentario
  de varias
  líneas -->
```

Els comentaris **no són processats** pels navegadors. Només serveixen per a documentar el codi. Els comentaris només s'han d'escriure en el **exemplar** i mai en el pròleg.

> **📌 Documentar el codi**
> 

> Aprovecha els comentaris per a explicar seccions del teu codi: faciliten el manteniment i la col·laboració entre desenvolupadors.
