Els atributs es poden classificar segons la seua funcionalitat.

## **Atributs bàsics o globals**

Es poden usar en quasi totes les etiquetes HTML.

- 

`name`: permet assignar un nom a un objecte HTML.

```html
<input name="password" />
```

- 

`title`: assigna un títol a un element HTML, millorant així la **accessibilitat**. Aquest títol és mostrat pels navegadors quan l'usuari passa el ratolí per damunt de l'element. És especialment útil amb els elements `a`, `link`, `img`, `object`, `abbr` i `acronym`.

```html
<a title="Título de etiqueta"></a>
```

- 

`id`: permet identificar a l'element HTML sobre el que s'aplica de forma **única** mitjançant un identificador. Només és útil quan es treballa amb CSS i amb JavaScript. Els identificadors:

  - Poden començar per números.

  - Només poden contindre lletres, números, guions mitjans (`-`) i/o guions bajos (`_`).

```html
<div id="principal"></div>
```

- 

`style`: permet aplicar a un element HTML un estil CSS directament.

```html
<span style="color: red;"></span>
```

- 

`class`: permet aplicar a un element HTML els estils d'una classe definida en una full d'estils CSS. Els noms de les classes segueixen les mateixes regles que els identificadors.

```html
<div class="rojo"></div>
```

```html
.rojo {
  color: red;
}
```

> **📌 `id` i `class`**
> 

> Mentre que `id` identifica un element de forma **única** en el document, `class` pot aplicar-se a **diversos** elements alhora per a compartir els mateixos estils.

## **Atributs per a internacionalizació**

Aquests atributs s'utilitzen en les pàgines que mostren els seus continguts en diversos idiomes, o aquelles que volen indicar de forma explícita l'idioma d'els seus continguts.

- 

`dir`: indica l'adreça d'escriptura del text. Només pot prendre dos valors:

  - `ltr` (*left to right*): d'esquerra a dreta. És el valor per defecte.

  - `rtl` (*right to left*): de dreta a esquerra.

- 

`lang`: especifica l'idioma de l'element mitjançant un codi predefinido. Els possibles valors es defineixen en el RFC 1766, el qual fa referència a la norma ISO 639.

| Codi | Idioma |
| --- | --- |
| `en` | Anglès |
| `es` | Espanyol |
| `ja` | Japonés |
| `fr` | Francés |

```html
<html lang="es"></html>
```

- 

`xml:lang`: a l'igual que l'atribut `lang`, especifica l'idioma de l'element mitjançant un codi definit segons el RFC 1766. En les pàgines XHTML, l'atribut `xml:lang` té més prioritat que `lang` i és **obligatori** incluir-lo sempre que s'incloga l'atribut `lang`.

```html
<html xml:lang="it"></html>
```

> **📌 Indicar l'idioma**
> 

> Declarar l'idioma amb `lang` (i `xml:lang` en XHTML) millora la **accessibilitat** i ajuda als buscadors a mostrar correctament la pàgina.

## **Atributs per a obtindre el focus**

Permet definir el focus en elements com formularis.

- 

`autofocus`: posa el focus de forma automàtica en l'element que el tinga definit.

```html
<input autofocus />
```

## **Atributs d'esdeveniments**

Es entén per **esdeveniment** allò que ocorre quan un usuari interactúa amb la pàgina web (fer clic, fer doble clic, passar el ratolí per damunt d'un element, etc.). Aquests atributs només s'utilitzen en les pàgines web dinàmiques, per a les quals s'utilitza el llenguatge de programació **JavaScript**. Com no és objectiu de la materia, no es va a contemplar.

> **📌 Atributs d'esdeveniments**
> 

> Els atributs d'esdeveniments (`onclick`, `onmouseover`, etc.) es estudiarán en les unitats dedicades a **JavaScript**, on es treballa amb pàgines web dinàmiques.
