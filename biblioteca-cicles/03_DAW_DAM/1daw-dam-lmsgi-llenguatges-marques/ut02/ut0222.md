Un document HTML està format per **etiquetes** i **atributs**.

## **Etiquetes**

Les etiquetes permeten **estructurar el contingut** en un document HTML. A l'igual que en XML, les etiquetes poden ser:

- **D'obertura**: `<etiqueta>`

- **De tancament**: `</etiqueta>`

També existeixen **elements buits**, que es cierran en la pròpia etiqueta d'obertura:

```html
<input />
```

> **📌 Diferència amb XML**
> 

> A diferència de XML, la quantitat d'etiquetes de HTML està **limitada** a aquelles que estan definides pel llenguatge.

## **Atributs**

Encara que HTML defineix una gran quantitat d'etiquetes, éstas no són suficientes per a crear pàgines complexes, ja que la definició completa de certs elements, com les imatges i els enllaços, requereix **informació addicional**. Com no és possible crear una etiqueta per a cada element diferent, es afegeix la informació addicional a les etiquetes mitjançant els **atributs**.

- Per a cada un dels atributs hi ha definit un conjunt de **valors** que es li pot assignar. Si el valor d'un atribut no és vàlid, el navegador el **ignora**.

- Cada una de les etiquetes HTML defineix els atributs que pot utilitzar, encara que alguns d'ells són **comuns** a moltes etiquetes.

```html
<input name="password" />
<a title="Título de etiqueta"></a>
```
