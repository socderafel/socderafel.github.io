Un element HTML està format per:

- Una **etiqueta d'obertura**.

- Zero o més **atributs**.

- Opcionalment, un **text**, tancat entre les etiquetes d'obertura i tancament. No totes les etiquetes poden encerrar text.

- Una **etiqueta de tancament**. Per a alguns elements no hi ha etiqueta de tancament o és opcional.

## **Elements en línia i de bloc**

Segons el mode en que ocupen l'espai disponible en la pàgina, els elements poden ser de dos tipus:

- 

**Elements en línia (*inline*) o lineals**: només ocupen l'espai necessari per a mostrar els seus continguts. El seu contingut pot ser text o altres elements *inline*.

- 

**Elements de bloc (*block*)**: sempre comencen en una **nova línia** i ocupen tot l'espai disponible fins al final de la línia, encara que els seus continguts no ocupen tot l'ample. El seu contingut pot ser text, elements *inline* o altres elements de bloc.

> **📌 Inline o block?**
> 

> Un truco per a distinguirlos: un element **block** comença en una nova línia i ocupa tot l'ample disponible, mentre que un element **inline** es mostra a continuació del contingut anterior ocupant només l'espai necessari.

> **📌 Exemple**
> 

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>Ejemplo de la diferencia entre los elementos inline y los elementos block</title>
  </head>
  <body>
    <h1>Los encabezados son elementos block.</h1>
    <p>Y los párrafos también.</p>
    <a href="#">Los enlaces son elementos inline</a>
    <p>Incluso si está definido dentro de un párrafo, <strong>un texto resaltado</strong> sigue siendo un elemento inline.</p>
  </body>
</html>
```
