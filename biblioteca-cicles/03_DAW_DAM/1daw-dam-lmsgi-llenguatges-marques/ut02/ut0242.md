Les llistes es classifiquen en tres grups:

- **Ordenades**.

- **Desordenades**.

- **De definició**.

## **Llistes ordenades**

- En una llista ordenada, els elements de la llista van identificats per un **número** (1, 2, 3, 4...) o **lletra** (a, b, c, d...).

- L'element `<ol>` delimita els elements que formen una llista ordenada. Té diversos atributs, com `start` per a indicar el número pel que es comença.

- Cada punt de la llista va tancat en un element `<li>`.

> **📌 Atribut `start`**
> 

> La numeració d'una llista ordenada pot començar en qualsevol valor amb l'atribut `start`, per exemple `<ol start="4">`.

```html
<ol>
  <li>Elemento 1 de una lista ordenada</li>
  <li>Elemento 2 de una lista ordenada</li>
  <li>Elemento 3 de una lista ordenada</li>
</ol>
```

## **Llistes desordenades**

- En una llista desordenada, cada entrada s'identifica per un **símbol** (punt, línia, etc.) que és el mateix per a tots.

- L'element `<ul>` delimita els elements que formen una llista desordenada.

- A l'igual que en les llistes ordenades, s'utilitza l'element `<li>` per a encerrar els diferents punts de la llista.

```html
<ul>
  <li>Elemento de una lista desordenada</li>
  <li>Elemento de una lista desordenada</li>
  <li>Elemento de una lista desordenada</li>
</ul>
```

## **Llistes de definicions**

En una llista de definicions, els elements van per **parelles**: element a definir i definició (o definicions), a l'igual que ocorre amb un diccionari. Els elements HTML utilitzats són:

- **`<dl>`**: delimita els elements que formen una llista de definicions.

- **`<dt>`**: conté el terme a definir.

- **`<dd>`**: conté una definició.

```html
<dl>
  <dt>Coche</dt>
  <dd>Automóvil destinado al transporte de personas.</dd>
  <dt>Ordenador</dt>
  <dd>Máquina electrónica que permite almacenar y tratar información.</dd>
</dl>
```
