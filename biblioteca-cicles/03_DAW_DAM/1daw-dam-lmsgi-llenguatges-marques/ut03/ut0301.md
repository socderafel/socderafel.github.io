[**CSS**](https://developer.mozilla.org/en-US/docs/Learn/CSS/First_steps/What_is_CSS) (*Cascading Style Sheets*) permet als desenvolupadors web **maquetar una web**, és a dir, controlar l'estil i el format.

Les fulls d'estils van aparèixer poc després que el llenguatge d'etiquetes SGML, alrededor de l'any 1970. Des de la creació de SGML, es observó la necessitat de definir un mecanisme que permitiera aplicar estils als documents electrònics. La guerra de navegadors i la falta d'un estàndard per a la definició dels estils dificultaven la creació de documents que tingueren igual aparença en distints navegadors.

Abans de l'ús de CSS, els diseñadors de pàgines web debían definir l'aspecte de cada element dins de les etiquetes HTML de la pàgina. El principal problema d'aquesta forma de definir l'aspecte dels elements és que cal definir el format de cada un dels elements que formen la pàgina, la qual cosa fa que siga molt difícil d'actualitzar.

CSS permet **separar** els **continguts** de la pàgina i el seu **aspecte**. Per a això, es defineix en una zona reservada el format de cada un dels elements de la web. Qualsevol canvi en l'estil marcatge per a un element en la full d'estils CSS afectará a totes les pàgines vinculades a ella en les que aparega eixe element. Les fulls d'estil estan compostes per una o més regles d'estil aplicades a un document HTML o XML.

Al crear una pàgina web, s'utilitza en primer lloc el llenguatge HTML/XHTML per a marcar els continguts, és a dir, per a designar la funció de cada element dins de la pàgina: paràgraf, capçalera, text destacat, etc. Una vegada creats els continguts, s'utilitza el llenguatge CSS per a definir el format de cada element.

Entre les avantatges de CSS estan:

- Obliga a crear documents semàntics HTML/XHTML.

- Millora l'accessibilitat del document

- Redueix la complexitat del seu manteniment

- Permet visualitzar el mateix document en infinitat de dispositius diferents.
