## 1. Mètodes d'Inclusió de Fulls d'Estil i Separació de Capes

L'especificació CSS permet associar estils visuals a un document HTML mitjançant tres vies, amb graus molt diferents de mantenibilitat i rendiment:

1. **Full d'Estil Extern (Recomanat per excel·lència):** Es vincula en la capçalera `<head>` mitjançant l'element `<link>`:
   ```html
   <link rel="stylesheet" href="css/principal.css">
   ```
   *Avantatges:* El navegador emmagatzema el fitxer en la memòria cau (*browser cache*), reduint la càrrega de xarxa en les visites posteriors; permet mantenir l'estil de milers de pàgines des d'un únic fitxer centralitzat.
2. **Full d'Estil Intern:** Es defineix dins de l'element `<style>` en el `<head>` del document. S'utilitza exclusivament per a estils crítics del primer renderitzat (*Critical CSS*).
3. **Estils en Línia (Inline styles):** Declarats directament en l'atribut `style` d'una etiqueta HTML (`<p style="color: red;">`). **Estan totalment desaconsellats**: violen la separació de responsabilitats, tenen una especificitat artificialment alta i impedeixen la reutilització i les directrius CSP (*Content Security Policy*).

## 2. L'Algorisme de la Cascada i l'Herència

Quan múltiples regles CSS entren en conflicte sobre una mateixa propietat d'un element, el motor de renderitzat aplica l'**algorisme de cascada** seguint una jerarquia de resolució estricta:

1. **Origen i Importància de la Declaració:**
   - Declaracions del desenvolupador amb `!important`.
   - Declaracions normals del desenvolupador (fulls d'estil de l'aplicació).
   - Estils per defecte del navegador (*User Agent Stylesheet*).
2. **Especificitat del Selector:** Si tenen el mateix origen, guanya la regla amb major pes d'especificitat.
3. **Ordre de Declaració:** Si l'origen i l'especificitat són idèntics, s'aplica l'última regla declarada en el codi font (regla d'aparició posterior).

### Càlcul de l'Especificitat Numèrica (Format A, B, C)

L'especificitat es mesura en una tupla de tres valors `(A, B, C)`:
- **Columna A (IDs):** Suma 1 punt per cada selector d'identificador (`#id`).
- **Columna B (Classes, Atributs, Pseudoclasses):** Suma 1 punt per cada selector de classe (`.classe`), selector d'atribut (`[type="text"]`) o pseudoclasse (`:hover`, `:first-child`, `:not()`).
- **Columna C (Elements i Pseudoelements):** Suma 1 punt per cada selector d'etiqueta (`div`, `p`, `h1`) o pseudoelement (`::before`, `::after`).

> [!IMPORTANT] Independència de Columnes d'Especificitat
> Les columnes d'especificitat no es fusionen en base decimal: una sola declaració d'ID `(1, 0, 0)` guanya sempre contra cent declaracions de classe juntes `(0, 100, 0)`.

## 3. Catàleg de Selectors Avançats

```css
/* Selectors de Combinació */
article p { color: #333; }          /* Selector Descendent: qualsevol <p> dins de <article> */
article > p { font-size: 1.1rem; }  /* Selector de Fill Directe: <p> fill immediat */
h2 + p { font-weight: bold; }       /* Selector de Germà Immediat: el <p> just després de <h2> */
h2 ~ p { line-height: 1.6; }        /* Selector de Germans Generals: qualsevol <p> posterior */

/* Selectors d'Atribut */
a[target="_blank"] { ... }          /* Coincidència exacta */
a[href^="https://"] { ... }         /* Comença per https:// */
a[href$=".pdf"] { ... }             /* Acaba en .pdf */
a[href*="github"] { ... }           /* Conté la subcadena github */

/* Pseudoclasses Estructurals */
li:first-child { ... }
li:last-child { ... }
li:nth-child(2n + 1) { ... }        /* Files imparells (zebra striping) */
input:not([type="checkbox"]) { ... }/* Negació de selector */
```
