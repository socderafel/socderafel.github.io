La W3C defineix el que es denomina [**box model**](https://codepen.io/TrevorWelch/pen/deLoMK) (model de caixa), que no és més que una zona rectangular com la següent que rodea cada un dels elements de la nostra pàgina web.

> **📌 Model caixa**
> 

> 

    MARGE EXTERN
    
        VORA
        
            MARGE INTERN
            
                CONTINGUT
            

        
    

    MARGIN
    
        BORDER
        
            PADDING
            
                CONTINGUT
            
        
    

Cada etiqueta HTML aplica eixe model i per tant té:

- **Contingut**. Contingut que està en l'interior de l'etiqueta.

- **Marge interior**. Distància des del contingut al vora de l'element. Propietat HTML `padding`.

- **Vora**. El vora de l'element. Propietat HTML `border`.

- **Marge exterior**. Distància des del vora de l'element als elements adyacentes. Propietat HTML `margin`.

Cada un d'eixos elements pot definir-se mitjançant propietats CSS.

> **📌 Provar en el navegador - "Propietats caixa"**
> 

> Amb l'aplicació [**Box Model Demo**](https://codepen.io/TrevorWelch/pen/deLoMK), pots experimentar de forma instantánea els canvis sobre les propietats relacionades amb el model de caixes.
