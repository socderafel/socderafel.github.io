## 1. Els Tres Pilars del Responsive Web Design (RWD)

Terme encunyat l'any 2010 pel dissenyador web Ethan Marcotte, el **Responsive Web Design** és una filosofia arquitectònica que permet a un document web adaptar automàticament la seua disposició i elements visuals a les dimensions físiques i resolució del dispositiu que el visualitza (des de rellotges intel·ligents i smartphones fins a pantalles de televisió 4K).

Els tres pilars inseparables del disseny adaptatiu són:
1. **Graelles Fluides (Fluid Grids):** Ús de mides percentuals o unitats relatives en lloc de dimensions fixes en píxels (`px`).
2. **Imatges i Multimèdia Fluids:** Elements gràfics configurats per a no desbordar mai el seu contenidor pare:
   ```css
   img, picture, video {
     max-width: 100%;
     height: auto;
     display: block;
   }
   ```
3. **Media Queries (Consultes de Mitjans):** Regles condicionals de CSS que apliquen blocs d'estil exclusivament quan el dispositiu compleix certs criteris de maquinari (amplada de finestra, orientació, resolució de píxels o preferències d'accessibilitat).

## 2. Unitats Relatives Modernes: rem, em, vw, vh i clamp()

Per a aconseguir interfícies escalables i respectuoses amb la configuració de zoom de l'usuari (WCAG 1.4.4):

- **`rem` (Root EM):** Unitat relativa a la mida de font de l'element arrel `<html>` (habitualment 16px per defecte al navegador). És la unitat recomanada per a mides de font, paddings i marges perquè escala harmònicament si l'usuari augmenta el text per motius d'accessibilitat.
- **`em`:** Unitat relativa a la mida de font de l'element pare directe (pot patir efecte de multiplicació acumulativa si s'aniuada en excés).
- **`vw` i `vh` (Viewport Width/Height):** 1vw equival a l'1% de l'amplada de la finestra d'enquadrament; 1vh equival a l'1% de la seua alçada.
- **Noves unitats mòbils:** `dvh` (Dynamic Viewport Height), `svh` (Small Viewport Height) i `lvh` (Large Viewport Height), que solucionen el problema clàssic de la barra d'adreces emergent en navegadors mòbils com Safari i Chrome per a Android.
- **Funció `clamp(mínim, ideal, màxim)`:** Permet establir tipografies i dimensions completament fluides entre dos límits estrictes:
  ```css
  h1 {
    /* La font serà de mínim 1.8rem, intentarà mesurar 4vw + 1rem, i mai superarà 3.2rem */
    font-size: clamp(1.8rem, 4vw + 1rem, 3.2rem);
  }
  ```

## 3. Media Queries i la Filosofia Mobile First

En el desenvolupament professional actual, el disseny es construeix sota la metodologia **Mobile First**:
1. El codi CSS principal (fora de qualsevol consulta) defineix els estils per a la pantalla més xicoteta i amb menor connectivitat.
2. A mesura que la pantalla s'eixampla, s'afegeixen consultes `@media (min-width: ...)` que afegeixen columnes addicionals o activen menús expandits.

```css
/* 1. Estils Base (Mòbil - 1 columna vertical) */
.contenidor-principal {
  width: 100%;
  padding: 1rem;
}

.llista-articles {
  display: flex;
  flex-direction: column;
  gap: 1.5rem;
}

/* 2. Tauletes (BreakPoint a partir de 768px) */
@media (min-width: 768px) {
  .llista-articles {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 3. Escriptori i Pantalles Grans (BreakPoint a partir de 1024px) */
@media (min-width: 1024px) {
  .contenidor-principal {
    max-width: 1200px;
    margin: 0 auto;
    padding: 2rem;
  }
  
  .llista-articles {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Consultes de Característiques d'Accessibilitat de l'Usuari */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
