En els exemples vistos fins a ara, el navegador representa els elements en l'ordre en el que apareixen, atenent a si són elements *block* o *inline*, entre altres coses.

Utilitzant CSS, és possible modificar el posicionament per defecte dels elements. Les propietats implicades són:

- `position`

- `float`

## float

Amb la propietat `float`, els elements «flotan» cap a l'esquerra o dreta. Tots els elements flotats es van situant un al costat d'un altre. Si no hi ha espai disponible, es passen a una nova línia. Es adapta bastant bé a diferents mides de pantalla.

> **📌 Exemple posicionament**
> 
HTMLCSSNavegador

```html
<body>
  <header>Encabezado</header>
  <nav>Vínculos</nav>
  <section>Contenido principal del página</section>
  <footer>Página creada por...</footer>
</body>
```

```html
body {
  background-color: pink;
}
header {
  background-color: blue;
}
nav {
  background-color: red;
  width: 10%;
}
section {
  background-color: green;
  width: 90%;
}
footer {
  background-color: yellow;
}
nav,
section {
  height: 300px;
  float: left;
}
```

En aquest exemple, s'utilitza la propietat `float` per a maquetar una pàgina senzilla, al costat de les etiquetes semàntiques.
Els elements `<nav>` i `<section>` estan flotats a l'esquerra i es reparten l'amplària disponible.
És necessari fixar l'alçària perquè en la pàgina a penes hi ha contingut.
