## 1. CSS Flexible Box Layout (Flexbox): El Model Unidimensional

CSS Flexbox està dissenyat específicament per a distribuir l'espai i alinear elements al llarg d'**un sol eix dimensional** (o bé en una fila horitzontal o bé en una columna vertical).

Quan s'assigna `display: flex` o `display: inline-flex` sobre un contenidor:
- L'element es converteix en un **Flex Container** (contenidor flexible).
- Tots els seus fills directes esdevenen automàticament **Flex Items** (elements flexibles).

```css
.barra-navegacio {
  display: flex;
  flex-direction: row;            /* Eix principal: horitzontal */
  justify-content: space-between; /* Alineació en l'eix principal */
  align-items: center;            /* Alineació en l'eix secundari (creuat) */
  gap: 1.5rem;                    /* Separació entre elements flexibles */
  flex-wrap: wrap;                /* Permet saltar de línia si no hi ha espai */
}
```

### Propietats Fonamentals de Flexbox

| Propietat en Contenidor | Valors Clau | Descripció |
| :--- | :--- | :--- |
| `flex-direction` | `row`, `row-reverse`, `column`, `column-reverse` | Estableix la direcció de l'eix principal (*main axis*). |
| `justify-content` | `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly` | Governa la distribució de l'espai buit al llarg de l'eix principal. |
| `align-items` | `stretch`, `center`, `flex-start`, `flex-end`, `baseline` | Governa l'alineació dels ítems al llarg de l'eix creuat (*cross axis*). |
| `gap` | Unitats CSS (`1rem`, `20px`) | Defineix la distància entre ítems sense haver d'utilitzar marges en els fills. |

| Propietat en Fill (Item) | Valors Clau | Descripció |
| :--- | :--- | :--- |
| `flex-grow` | Número positiu (`0`, `1`, `2`) | Factor de creixement proporcional per a absorbir l'espai buit restant. |
| `flex-shrink` | Número positiu (`1`, `0`) | Factor d'encongiment proporcional si l'espai és insuficient. |
| `flex-basis` | Mida CSS (`auto`, `250px`, `0`) | Mida inicial de l'ítem abans de distribuir l'espai disponible. |
| `align-self` | `auto`, `center`, `flex-start`, `stretch` | Sobreescriu localment el valor de `align-items` del contenidor per a un ítem concret. |

## 2. CSS Grid Layout: El Model Bidimensional

CSS Grid és el sistema de maquetació més complet i potent de CSS. Permet dividir l'espai disponible d'un contenidor en una graella ortogonal de **files i columnes simultàniament**.

```css
.portal-noticies {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  grid-gap: 2rem;
}

/* Maquetació d'àrees semàntiques de pàgina completa */
.dashboard-layout {
  display: grid;
  grid-template-columns: 260px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "capcalera  capcalera"
    "sidebar    principal"
    "peu        peu";
  min-height: 100vh;
}

.panell-header  { grid-area: capcalera; }
.panell-sidebar { grid-area: sidebar; }
.panell-main    { grid-area: principal; }
.panell-footer  { grid-area: peu; }
```

### Conceptes Clau de CSS Grid
- **Fracció Flexible (`fr`):** Representa una fracció de l'espai restant disponible al contenidor. Si declarem `grid-template-columns: 1fr 2fr`, la segona columna serà exactament el doble d'ampla que la primera.
- **Funció `repeat()`:** Simplifica patrons repetitius: `repeat(3, 1fr)` equival a `1fr 1fr 1fr`.
- **Funció `minmax(min, max)`:** Estableix un interval flexible; molt utilitzat amb `auto-fit` per a generar graelles responsives que s'autoajusten sense necessitat d'escriure cap Media Query:  
  `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));`
- **Línies de Graella (Grid Lines) i Àrees (Grid Areas):** Permeten ancorar elements exactament entre línies numèriques (`grid-column: 1 / 3`) o per noms simbòlics amb `grid-template-areas`.
