## Disseny amb percentatges

El primer pas per a crear un disseny que es adapte correctament, és començar a familiarizar-se amb un tipus d'unitats: [els percentatges](https://manaloarg.github.io/LLMSGI/ut03/ut0362/#unidades-relativas). Recordemos que els percentatges són relatius al contenidor pare, per la qual cosa si especificamos un percentatge a un element, el navegador va a prendre aquest percentatge del contenidor.

Empecemos usant percentatges amb les propietats `width` en un exemple senzill. Anem a establir:

- Un ample de `100%` a `header`, `.page` i `footer`

- Un ample de `30%` a `.menu`

- Un ample de `70%` a `.content`

> **📌 Com quedaria!!**
>

  </div>

> **📌 Nota**
> 

> Nótese que els elements `.menu` i `.content` es troben dins de `.page`.

No obstant això, utilitzar percentatges no ens garanteix un disseny adaptativo de qualitat, cal comprendre bé diversos detalls. El primer problema que trobarem serà que si sumem el mida dels elements `70%` + `30%`, al costat dels vores de cada un, `2px` per cada costat, la suma és superior al `100%` del contenidor pare, per la qual cosa **no cap en el seu interior**. El segon element es desplaza a la zona inferior, descuadrant tot el disseny. El mateix pot ocórrer si intentem afegir `margin` o `padding`.

> **📌 Ojo**
> 

> Açò és alguna cosa molt habitual en CSS. I frustrante al principi quan no es comprèn que ocorre.

Hi ha diverses formes de solucionar-lo:

- Eliminar els vores i reduir els percentatges manualment fins a que quepan en el `100%` del pare.

- Entendre la propietat [`box-sizing`](https://manaloarg.github.io/LLMSGI/ut03/ut0363/) i canviar el mode en el que es gestiona el model de caixes.

- **Opció ideal**: Utilitzar un sistema modern com [Flexbox](https://manaloarg.github.io/LLMSGI/ut03/ut0380/) o [Grid](https://manaloarg.github.io/LLMSGI/ut03/ut0381/).

### Solució recomanada

Com comentamos abans, una forma simple i recomanada de solucionar el problema de l'exemple anterior, és aprendre a utilitzar Flex o Grid. Fem el següent canvi en el codi CSS de l'exemple anterior:

> **📌 CSS**
> 

```html
.page {
  display: flex;
}
```

D'aquesta forma, establim que el pare `.page` siga un element flexible, per tant, conseguimos que el nostre disseny es adapte de forma adequada a la pàgina, sense necessitat de tindre que ajustar els marges, rellenos, vores o mida dels continguts.

## Mides màxims i mínims

Si cerquem un cert grau de control encara major, una opció recomanable seria recurrir a les propietats `max-width` i `min-width`, amb les que podem indicar l'ample d'un element com a màxim i l'ample d'un element com a mínim respectivament, aconseguint així garantir cert grau de control del disseny:

> **📌 Exemple Mides màxims i mínims**
> 
CSSNavegadorCodeSandbox

```html
.picture {
  min-height: 200px;    /* Por defecto, height es 0 */
  background: red;     /* Simplemente, para verlo visualmente */
  max-width: 800px;
  min-width: 600px;
}
```

En aquest cas, l'element té un mida màxim de `800px`, i un mida mínim de `600px`, per la qual cosa si ajustamos l'ample de la finestra del navegador, aquest element iría variant en un rang de `600` a `800` píxels, i mai saldría d'aquests rangs.

> **📌 Important**
> 

> És important donar-se compta de que aquest exemple funciona perquè no hi ha definit un `width` (*per omisió, és igual a `width: 100%`*). Des de que existisca un `width`, les altres propietats pierden efecte perquè es està obligant a que tinga un mida fix concret.

Amb les imatges, videos i continguts multimèdia, podem fer el mateix, aconseguint així que les imatges es escalen i adapten al format especificat o fins i tot al mida de pantalla dels diferents dispositius utilitzats:

> **📌 CSS**
> 

```html
img,
video,
object,
embed {
  max-width: 100%;
  height: auto;
}
```

## El viewport del navegador

En molts casos pot que oigas parlar del **viewport** del navegador. Eixa paraula fa referència a la **región visible del navegador**, és a dir, la part de la pàgina que està visualizándose actualment en el navegador. Els usuaris podem redimensionar la finestra del navegador per a reduir el mida del viewport i simular que es tracta d'una pantalla i dispositiu més xicotet.

Si volem editar certs comportaments del viewport del navegador, podem editar el document HTML per a especificar el següent camp meta, abans de la part del `</head>`:

> **📌 HTML**
> 

```html
<meta name="viewport" content="initial-scale=1, width=device-width">
```

Amb aquesta etiqueta `<meta>`, estem establint uns paràmetres de comportament per al **viewport** del navegador. Vegem que signifiquen i quals més existeixen:

| Paràmetre | Valor | Significat |
| --- | --- | --- |
| `width` | `device-width` | Indica un ample per al viewport. |
| `height` | `device-height` | Indica un alt per al viewport. |
| `initial-scale` | `1` | Escala inicial amb la que es visualitza la pàgina web. |
| `minimum-scale` | `0.1` | Escala mínima a la que es pot reduir al fer zoom. |
| `maximum-scale` | `10` | Escala màxima a la que es pot aumentar al fer zoom. |
| `user-scalable` | `no` o `fixed` | **yes** o **zoom** |

Les propietats `initial-scale` , `minimum-scale` i `maximum-scale` permeten valors des del `0.1` al `10` , encara que certs valors es traducen automàticament a certs números determinats:

- `yes` = `1`

- `no` = `0.1`

- `device-width` = `10`

- `device-height` = `10`

D'altra banda, `user-scalable` permet definir si és possible que l'usuari puga «pellizcar» la pantalla per a ampliar o reduir el zoom.

> **📌 Important**
> 

> Encara que és possible utilitzar alguns d'aquests paràmetres, és aconsejable revisar detalladament les seues conseqüències. El recomanable és utilitzar només els que es mencionan en el fragment de codi superior, per a evitar problemes d'accessibilitat que impidan certes accions.
