## Contingut

Per a definir les dimensions del contingut s'utilitzen les següents propietats:

- `width`

- `height`

Els valors que poden prendre són:

- `auto`

- Longitud en píxels o equivalent

> **📌 CSS**
> 

```html
div {
    width: 400px;
    height: 100px;
}
```

Tant `width` com `height` especifican les dimensions del contingut **sense tindre en compte vora i marges**.

## Marge interior

Amb la propietat `padding` podem definir l'ample del marge intern.

> **📌 CSS**
> 

```html
p {
    padding: 20px;
}
```

Els valors que permeten són:

- `auto`

- Longitud

- Percentatge

> **📌 Variants i Múltiples Valors**
> 
VariantesMultiples Valors

Existeixen quatre variants de la propietat:

```html
p {
    padding-top: 10px;
    padding-bottom: 20px;
    padding-right: 30px;
    padding-left: 40px;
}
```

La propietat `padding` té diferents comportaments segons els valors que li indiquem:

1 Valor2 Valores3 Valores4 Valors

- Amb 1 valor: s'aplica als quatre costats.

```html
.e1 {
    padding: 10px;
    /*
        Todos los lados: 10px
    */
}
```

- Amb 2 valors: el primer s'aplica a superior i inferior i, el segon, als costats esquerre i dret.

```html
.e2 {
    padding: 10px 20px;
    /*
        Arriba/abajo: 10px
        Izquierda/derecha: 20px
    */
}
```

- Amb 3 valors: s'aplica el primer, al superior; el segon, als laterals; i el tercer a l'inferior.

```html
.e3 {
    padding: 10px 20px 30px;
    /*
        Arriba: 10px
        Izquierda/derecha: 20px
        Abajo: 30px
    */
}
```

- Amb 4 valors: s'aplica a superior, dret, inferior, esquerre.

```html
.e4 {
    padding: 10px 20px 30px 40px;
    /*
        Arriba: 10px
        Derecha: 20px
        Abajo: 30px
        Izquierda: 40px
    */
}
```
