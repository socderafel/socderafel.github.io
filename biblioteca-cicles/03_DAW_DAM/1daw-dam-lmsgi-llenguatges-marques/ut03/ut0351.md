## **Introducció**

Es revisarán les propietats principals que s'usen en CSS com són:

- Propietats de color i fons.

- Propietats de font.

- Propietats de text.

- Propietats de llista.

- Propietat `display`.

El ventall de propietats és molt extenso i el més aconsejable és revisar [**MDN Web Docs**](https://developer.mozilla.org/es/docs/Web/CSS) per a conèixer el funcionament de cada una d'elles i anar probándolas amb un editor de text i un navegador.
