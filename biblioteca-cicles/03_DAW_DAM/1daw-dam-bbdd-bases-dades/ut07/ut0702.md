Com en qualsevol un altre llenguatge de programació, tindrem la possibilitat de fer ús de les **variables**. La diferència respecte als *llenguatges tradicionals* és que podem utilitzar aquestes variables per a **guardar resultats de consultes SQL** o utilizar-les com **dades a enviar a ordres SQL** com `INSERT`, `UPDATE`, ...

En **MySQL** hem de considerar dos casos quan utilitzem variables:

- Les utilitzem amb un conjunt d'instruccions que guardarem en un **arxiu amb extensió `.sql`**.

- Les utilitzem dins d'un **procediment emmagatzemat, funció o trigger**.

## **Variables en un fitxer de codi SQL (variables d'usuari)**

Aquest tipus de variables són referenciades per MySQL com **Variables d'usuari** (*User-Defined Variables*).

Les seues característiques principals:

- **No és necessari declarar-les** i les podem utilitzar directament.

- Comencen amb el símbol **`@`**.

- Per a asignarles un valor empleamos l'ordre **`SET`** o **`INTO`**.

- A aquestes variables es els denomina **variables de sessió**.

> **📌 Exemple. Assignar valor a una variable de sessió**
> 

```sql
SET @nombre = 'Joan';
SELECT @nombre;                  -- Mostrará el valor de la variable Joan

SELECT anhos
INTO @anhos
FROM animales
WHERE nombre = 'Caiman';
SELECT @anhos;                  -- Mostrará el valor de la variable 1
```

### **Assignar valor a múltiples variables**

També podem donar valor a múltiples variables:

> **📌 Exemple. Múltiples variables**
> 

```sql
SELECT anhos, peso
INTO @anhos, @peso
FROM animales
WHERE nombre = 'Caiman';
SELECT @anhos, @peso;          -- Mostrará el valor de la variable 1 y 71
```

Podem fer ús de les **funcions integrades** en el gestor per a realitzar qualsevol modificació a les dades de les variables i després fer ús en altres instruccions:

> **📌 Exemple. Usar funcions amb variables**
> 

```sql
SELECT nombre, apellidos
INTO @nombre, @apellidos
FROM artistas
WHERE nif = '11111111A';

SET @nombre_completo = CONCAT(@apellidos, ',', @nombre);
SELECT @nombre_completo;      -- Mostrará Lopez,Juan
```

### **Ús de variables en consultes i INSERTS**

Es pot fer ús de **filtres** i de les variables en els `INSERT` o `UPDATE`:

> **📌 Exemple. Variables com filtre i en un INSERT**
> 

```sql
SELECT AVG(peso)
INTO @peso_medio
FROM animales;

SELECT *
FROM animales
WHERE peso > @peso_medio;

SELECT nombre
INTO @nombreAnimalSinArtista
FROM animales
WHERE nombre NOT IN (SELECT nombre_animal
                     FROM animales_artistas);

INSERT INTO animales_artistas
VALUES (@nombreAnimalSinArtista, '11111111A');
```

### **Característiques de les variables de sessió**

Les variables de sessió han de complir les següents característiques:

- Començar el seu nom amb el símbol **`@`**, per exemple: `@nom`.

- Poden incloure qualsevol **caràcter alfanuméric**.

- Poden incloure els símbols: **`.`**, **`_`**, **`$`**.

- Poden incloure un altre tipus de símbols (inclòs l'espai en blanc) a condició de que es escriga el nom de la variable entre cometes: `@'my var'`, `@'my-var'`, `@"my-var"`.

- **No es distingeixen majúscules de minúscules**.

- Longitud màxima: **64 caràcters**.

## **Variables locals en procediments, funcions o triggers**

Les **variables locals** són les que utilitzarem dins de les estructures de procediments, funcions o triggers. A diferència de les variables de sessió, **només estan disponibles dins de les estructures**.

Per a definirlas farem ús del `DECLARE`:

```sql
DECLARE nombreVar tipoDato [DEFAULT valor_por_defecto];
```

A diferència de les variables d'usuari:

- El nom de les variables **no comença per `@`**.

- S'ha de declarar un **tipus associat** a la variable.

- Si no es inicializan, el valor d'aquestes variables **per defecte és nul**.

> **📌 Exemple. Declaració d'una variable local**
> 

```sql
DECLARE numDepts INT DEFAULT 0;
```

> **📌 Resum**
> 

> - En un fitxer `.sql` s'usen **variables de sessió** (`@variable`), que no necessiten declaració.

> - Per a assignar valor es empren les ordres `SET` o `SELECT ... INTO`.

> - Dins de procediments, funcions o triggers s'usen **variables locals** declarades amb `DECLARE` i amb un tipus de dada associat.
