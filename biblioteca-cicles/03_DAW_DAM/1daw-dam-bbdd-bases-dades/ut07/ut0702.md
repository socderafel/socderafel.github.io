Una **Funció Emmagatzemada (Stored Function)** és un conjunt d'instruccions desat en el catàleg de la base de dades que rep paràmetres d'entrada, executa una seqüència d'operacions lògiques i **retorna obligatòriament un resultat**. 

Les funcions es poden invocar directament dins de consultes SQL convencionals (`SELECT`, `WHERE`, `ORDER BY`), proporcionant una reutilització de codi extraordinària.

---

## 🛠️ Creació de Funcions Escalar en PL/pgSQL

Vegem una funció que calcula l'impost sobre el valor afegit (IVA) d'un import segons el tipus imposable:

```sql
CREATE OR REPLACE FUNCTION fn_calcular_iva(
    p_import NUMERIC,
    p_tipus VARCHAR DEFAULT 'GENERAL'
) 
RETURNS NUMERIC 
LANGUAGE plpgsql
AS $$
DECLARE
    v_percentatge NUMERIC;
BEGIN
    IF p_import IS NULL OR p_import < 0 THEN
        RETURN 0.00;
    END IF;

    CASE UPPER(p_tipus)
        WHEN 'SUPERREDUIT' THEN v_percentatge := 0.04;
        WHEN 'REDUIT'       THEN v_percentatge := 0.10;
        ELSE                    v_percentatge := 0.21;
    END CASE;

    RETURN ROUND(p_import * v_percentatge, 2);
END;
$$;
```

### Invocació en SQL
```sql
SELECT 
    nom, 
    preu, 
    fn_calcular_iva(preu, 'GENERAL') AS iva,
    preu + fn_calcular_iva(preu, 'GENERAL') AS pvp_final
FROM productes;
```

## 📋 Funcions que Retornen Taules (`RETURNS TABLE`)

A PostgreSQL, una funció pot retornar un conjunt complet de files i columnes que es pot consultar com si fóra una taula real en la clàusula `FROM`:

```sql
CREATE OR REPLACE FUNCTION fn_llistar_clients_ciutat(p_ciutat VARCHAR)
RETURNS TABLE (
    id_client INT,
    nom VARCHAR,
    email VARCHAR
)
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN QUERY
    SELECT c.id_client, c.nom, c.email
    FROM clients c
    WHERE c.ciutat = p_ciutat;
END;
$$;

-- Invocació com si fóra una taula:
SELECT * FROM fn_llistar_clients_ciutat('València');
```
