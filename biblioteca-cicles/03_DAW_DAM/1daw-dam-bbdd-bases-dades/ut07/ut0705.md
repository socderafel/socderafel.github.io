L'essència d'SQL és el tractament de conjunts complets de dades (*set-based programming*). No obstant això, en determinats processos de càlcul complexos, simulacions financeres o integracions amb sistemes heretats, és necessari iterar **fila a fila** de manera seqüencial.

Per a aquest propòsit existeixen els **Cursors**: mecanismes que permeten recórrer el resultat d'una consulta registre a registre mitjançant un punter de lectura.

---

## 🔄 El Cicle de Vida d'un Cursor

Un cursor segueix quatre fases ben definides en qualsevol llenguatge procedural:

```
┌────────────────────────────────────────────────────────┐
│ 1. DECLARE   ──► Defineix el nom i la consulta SELECT. │
│ 2. OPEN      ──► Executa la consulta i situa el punter.│
│ 3. FETCH     ──► Llegeix la fila actual a variables.   │
│ 4. CLOSE     ──► Allibera la memòria i recursos.       │
└────────────────────────────────────────────────────────┘
```

---

## 💻 Exemple d'Ús de Cursors en PL/pgSQL

```sql
DO $$
DECLARE
    -- 1. Declaració del cursor
    cur_clients CURSOR FOR 
        SELECT id_client, nom, saldo 
        FROM clients 
        WHERE actiu = TRUE;
        
    v_id INT;
    v_nom VARCHAR;
    v_saldo NUMERIC;
BEGIN
    -- 2. Obertura
    OPEN cur_clients;

    LOOP
        -- 3. Lectura de la fila actual
        FETCH cur_clients INTO v_id, v_nom, v_saldo;
        EXIT WHEN NOT FOUND; -- Eixir quan s'acaben les files

        -- Càlculs fila a fila
        IF v_saldo > 1000 THEN
            RAISE NOTICE 'Client VIP: % (ID: %) - Saldo: % €', v_nom, v_id, v_saldo;
        END IF;
    END LOOP;

    -- 4. Tancament
    CLOSE cur_clients;
END $$;
```

---

## ⚠️ Quan Evitar els Cursors?

> **RECOMANACIÓ PROFESSIONAL:** Els cursors consumeixen molta memòria a l'SGBD i desactiven les capacitats de paral·lelització del motor de bases de dades. Abans d'escriure un cursor de 50 línies, intenta sempre resoldre el problema amb:
> 1. Sentències `UPDATE` o `INSERT` amb expressions i càlculs en línia.
> 2. Funcions de finestra (*Window Functions* com `ROW_NUMBER()`, `RANK()`, `LEAD()`, `LAG()`).
> 3. Consultes agrupades amb `GROUP BY` o CTEs.
