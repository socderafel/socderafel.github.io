Un **cursor** és un recurs de programació que ens ofereixen quasi tots els gestors de bases de dades relacionals i que consisteix en la possibilitat de **recórrer fila a fila** un conjunt de resultats provenientes d'una sentència `SELECT`. L'avantatge que té l'ús de cursors és que podrem **guardar en variables locals cada fila** de resultats i manejar aquesta informació com vulguem.

Un cursor té les següents característiques:

- **Són de només lectura**: només serveixen per a llegir dades. Només podrem declarar un cursor per a llegir les dades que provienen d'una consulta `SELECT` i mai podrem modificar les dades de la taula a través del cursor.

- **D'accés seqüencial**: la informació que procesará el cursor és seqüencial. Recorrerem fila a fila des de la primera a la última, una darrere d'una altra, i no podrem saltar a una fila qualsevol de manera directa.

- **Poden crear-se dins d'un procediment, funció o trigger**.

## **Maneig de cursors**

Per a un cursor es realitzen les següents operacions:

1. **Declaració del cursor**: definim el nom del cursor i la consulta SQL `SELECT` que retornarà el conjunt de resultats.

1. **Obertura del cursor**: per a poder processar la informació que ve en el `SELECT`.

1. **Lectura del cursor**: es realitza amb l'ordre `FETCH`, que permet guardar la informació d'una fila en variables locals i passa a la següent fila del conjunt de resultats. La lectura va en un **bucle** que s'executa fins a que es acaven de llegir totes les files.

1. **Tancament del cursor**: per a liberar de la memòria el cursor creat.

### **Declaració**

```sql
DECLARE nombre_cursor CURSOR FOR sentencia_SELECT;
```

> **📌 Consideracions**
> 

> - Per a eixir del bucle capturarem una excepció de *no hi ha més dades* (`NOT FOUND`). La definició d'aquesta captura ha d'anar **després del `DECLARE`** de variables i abans de les operacions.

> - La declaració del cursor ha d'anar **després de la declaració de les variables i condicions**.

> - En la sentència `SELECT` seleccionarem les columnes que volem guardar *per cada fila* al recórrer el cursor.

> - Dins d'un procediment, trigger o funció podem tindre diversos cursors, però tots ells han de tindre un **nom diferent**.

> **📌 Exemple de declaració**
> 

```sql
DECLARE v_noHayMasDatos INT DEFAULT FALSE;
DECLARE c_artistas CURSOR FOR SELECT apellidos, nombre FROM ARTISTAS WHERE nif_jefe IS NULL;
DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_noHayMasDatos = TRUE;
```

### **Obertura**

```sql
OPEN nombre_cursor;
```

### **Lectura**

```sql
FETCH nombre_cursor INTO variable1[, variable2, ...];
```

> **📌 Consideracions**
> 

> - En la part `INTO` han d'anar **tantes variables com columnes** tinguem en la sentència `SELECT`.

> - Cada variable guardarà el dada de la columna que venga en el `SELECT`: la primera variable, el dada de la primera columna; la segona, el de la segona, i així sucesivament.

> - Cada variable ha d'estar definida amb el **mateix tipus de dada** que la columna a la que està associada.

> **📌 Exemple complet de lectura amb bucle**
> 

```sql
DECLARE v_noHayMasDatos INT DEFAULT FALSE;
DECLARE v_apellidos VARCHAR(100);
DECLARE v_nombre VARCHAR(45);

DECLARE c_artistas CURSOR FOR
    SELECT apellidos, nombre FROM ARTISTAS WHERE nif_jefe IS NULL;

DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_noHayMasDatos = TRUE;

OPEN c_artistas;

read_loop: LOOP
    FETCH c_artistas INTO v_apellidos, v_nombre;

    IF v_noHayMasDatos THEN
        LEAVE read_loop;
    END IF;

    -- Por cada fila disponemos del apellido y nombre.
END LOOP;
```

### **Tancament**

```sql
CLOSE nombre_cursor;
```

> **📌 Exemple complet amb tancament**
> 

```sql
DECLARE v_noHayMasDatos INT DEFAULT FALSE;
DECLARE v_apellidos VARCHAR(100);
DECLARE v_nombre VARCHAR(45);

DECLARE c_artistas CURSOR FOR
    SELECT apellidos, nombre FROM ARTISTAS WHERE nif_jefe IS NULL;

DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_noHayMasDatos = TRUE;

OPEN c_artistas;

read_loop: LOOP
    FETCH c_artistas INTO v_apellidos, v_nombre;

    IF v_noHayMasDatos THEN
        LEAVE read_loop;
    END IF;

    -- Por cada fila disponemos del apellido y nombre.
END LOOP;

CLOSE c_artistas;
```

> **📌 Taules temporals**
> 

> Per a mostrar el resultat d'un recorregut de cursor com **una única consulta** (no valen diversos `SELECT`), farem ús d'una **taula temporal** que vaja guardant les dades i posteriorment farem un `SELECT` d'aquesta taula:

```sql
CREATE TEMPORARY TABLE T_TEMPORAL (...);
-- ...
SELECT * FROM T_TEMPORAL;
DROP TEMPORARY TABLE T_TEMPORAL;
```

Aquesta ordre ha d'anar **després del `DECLARE CONTINUE HANDLER`** del cursor. Recorda esborrar la taula temporal a l'eixir del procediment amb `DROP TEMPORARY TABLE`.

## **Exercicis resolts**

### **Exercici 1**

Crea un procediment de nom `atraccions_checkGanancias` en el que volem comprovar si les guanys totals de cada atracció coincideixen amb la suma de les guanys dels dies en que es celebró. El procediment ha de retornar una cadena amb el format:

- `atraccion1:gananciatotal:gananciasumada`

- `atraccion2:gananciatotal:gananciasumada`

amb les atraccions que no compleixen que la suma siga igual.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_checkGanancias;
DELIMITER $$
CREATE PROCEDURE atracciones_checkGanancias()
COMMENT 'Devuelve las atracciones cuya suma total de ganancias no coincide con la suma de las ganancias diarias.'
BEGIN
    -- Declaración de variables
    DECLARE v_final INTEGER DEFAULT 0;
    DECLARE v_atraccion VARCHAR(50);
    DECLARE v_ganTotales INT;
    DECLARE v_ganTotalesPorDia INT;
    DECLARE v_cadenaSalida VARCHAR(1000) DEFAULT ''; -- Cuidado con el valor (null) por defecto para concatenar.

    -- Declaración del cursor
    DECLARE c_checkGanancias CURSOR FOR
        SELECT nombre, ganancias
        FROM ATRACCIONES;

    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_final = TRUE;

    OPEN c_checkGanancias;

    read_loop: LOOP
        FETCH c_checkGanancias INTO v_atraccion, v_ganTotales;

        IF v_final THEN
            LEAVE read_loop;
        END IF;

        SELECT SUM(ganancias)
        INTO v_ganTotalesPorDia
        FROM ATRACCION_DIA
        WHERE nombre_atraccion = v_atraccion;

        IF (v_ganTotalesPorDia <> v_ganTotales) THEN
            SET v_cadenaSalida = IF (v_cadenaSalida <> '', CONCAT(v_cadenaSalida, ', '), ''); -- Para separar una atracción de otra
            SET v_cadenaSalida = CONCAT(v_cadenaSalida, v_atraccion, ':', v_ganTotales, ':', v_ganTotalesPorDia);
        END IF;
    END LOOP;

    CLOSE c_checkGanancias;

    SELECT v_cadenaSalida AS listaatracciones;
END$$
DELIMITER ;
```

### **Exercici 2**

Crea un procediment de nom `artistas_addSuplementoPorCuidados`, que comprove a quants animals cuida cada un dels artistes. Aquells artistes que cuidan **més d'un número d'animals** indicats per un paràmetre es els donarà un plus en la seua nómina igual al número d'animals que cuida **multiplicado per 100 euros**. Mostra el nom i complemento de cada artista així com la suma de tots els complementos.

> **📌 Notes**
> 

> - El resultat ha d'aparèixer com **una única consulta** (no valen diversos `SELECT`). Per a això farem ús d'una **taula temporal**.

> - Recorda esborrar la taula temporal a l'eixir del procediment amb `DROP TEMPORARY TABLE`.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_addSuplementoPorCuidados;
DELIMITER $$
CREATE PROCEDURE artistas_addSuplementoPorCuidados(p_numAnimales TINYINT)
COMMENT 'Muestra un suplemento para aquellos artistas que cuidan a más animales de lo indicado así como la suma de los complementos.'
BEGIN
    -- Declaración de variables
    DECLARE v_final INTEGER DEFAULT 0;
    DECLARE v_nif CHAR(9);
    DECLARE v_numAnimales TINYINT DEFAULT 0;
    DECLARE v_complementoTotal INT DEFAULT 0;
    DECLARE v_apellidos VARCHAR(100);
    DECLARE v_nombre VARCHAR(45);

    -- Declaración del cursor
    DECLARE c_complemento CURSOR FOR
        SELECT nif_artista, COUNT(*)
        FROM ANIMALES_ARTISTAS
        GROUP BY nif_artista
        HAVING COUNT(*) > p_numAnimales;

    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_final = TRUE;

    CREATE TEMPORARY TABLE T_TEMPORAL (nombre_completo VARCHAR(150), suplemento DECIMAL(6,2));

    OPEN c_complemento;

    read_loop: LOOP
        FETCH c_complemento INTO v_nif, v_numAnimales;

        IF v_final THEN
            LEAVE read_loop;
        END IF;

        IF (v_numAnimales > p_numAnimales) THEN
            SELECT apellidos, nombre
            INTO v_apellidos, v_nombre
            FROM ARTISTAS
            WHERE nif = v_nif;

            INSERT INTO T_TEMPORAL
            VALUES (CONCAT(v_apellidos, ', ', v_nombre), v_numAnimales * 100);

            SET v_complementoTotal = v_complementoTotal + v_numAnimales * 100;
        END IF;
    END LOOP;

    INSERT INTO T_TEMPORAL
    VALUES ('Suplemento total', v_complementoTotal);

    SELECT nombre_completo, suplemento
    FROM T_TEMPORAL;

    CLOSE c_complemento;

    DROP TEMPORARY TABLE T_TEMPORAL;
END$$
DELIMITER ;
```

### **Exercici 3**

Crea un procediment de nom `animals_addAforoPorTipo` al que es li passe un **tipus d'animal** i el **increment d'aforament** i, per cada pista en la que trabatge l'animal d'aquest tipus, es anomene al procediment `pistas_addAforo` (ja implementat en la secció de procediments). No cal anomenar diverses vegades a la mateixa pista.

> **📌 Notes**
> 

> - Ha de mostrar en **una única consulta** la llista de pistes i nou aforament a partir de la informació que retorna el procediment `pistas_addAforo`. Les pistes no poden aparèixer repetides.

> - Per a això farem ús d'una **taula temporal**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS animales_addAforoPorTipo;
DELIMITER $$
CREATE PROCEDURE animales_addAforoPorTipo(p_tipo VARCHAR(9), p_incAforo SMALLINT)
COMMENT 'Hace uso del método animales_addAforo para incrementar el aforo de las pistas donde trabajan los animales del tipo indicado.'
BEGIN
    -- Declaración de variables
    DECLARE v_final INTEGER DEFAULT 0;
    DECLARE v_nombrePista VARCHAR(50);
    DECLARE v_nuevoAforo SMALLINT;

    -- Declaración del cursor
    DECLARE c_pistas CURSOR FOR
        SELECT DISTINCT nombre_pista
        FROM ANIMALES
        WHERE tipo = p_tipo;

    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_final = TRUE;

    CREATE TEMPORARY TABLE T_TEMPORAL (nombrePista VARCHAR(50), nuevoAforo SMALLINT);

    OPEN c_pistas;

    read_loop: LOOP
        FETCH c_pistas INTO v_nombrePista;

        IF v_final THEN
            LEAVE read_loop;
        END IF;

        SET v_nuevoAforo = p_incAforo;
        CALL pistas_addAforo(v_nombrePista, v_nuevoAforo); -- En v_nuevoAforo está el aforo incrementado

        INSERT INTO T_TEMPORAL (nombrePista, nuevoAforo)
        VALUES (v_nombrePista, v_nuevoAforo);
    END LOOP;

    SELECT nombrePista, nuevoAforo
    FROM T_TEMPORAL
    ORDER BY nombrePista;

    CLOSE c_pistas;

    DROP TEMPORARY TABLE T_TEMPORAL;
END$$
DELIMITER ;
```

> **📌 Resum**
> 

> - Un **cursor** permet recórrer fila a fila el resultat d'un `SELECT`.

> - Operacions: **DECLARE** → **OPEN** → **FETCH** (en un bucle) → **CLOSE**.

> - Per a eixir del bucle s'usa `DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;` juntament amb `LEAVE`.

> - Amb **`FETCH ... INTO`** es guarda cada fila en variables locals.

> - Per a mostrar el resultat en **una única consulta** s'usa una **taula temporal** (`CREATE TEMPORARY TABLE`) que s'esborra al final amb `DROP TEMPORARY TABLE`.
