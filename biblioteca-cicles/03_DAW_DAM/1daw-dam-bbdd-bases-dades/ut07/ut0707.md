Un **trigger** ve a ser com un **procediment emmagatzemat que s'executa automàticament** quan sobre una taula es realitza alguna operació que implique **modificar les seues dades** (`DELETE`, `INSERT`, `UPDATE`). Per tant un trigger estarà *associat* a una taula i a un *conjunt d'operacions* sobre la taula.

El trigger pot executar el conjunt d'instruccions **després (AFTER)** o **abans (BEFORE)** de que s'execute aquesta ordre.

> **📌 Usos dels triggers**
> 

> - **Monitorear i registrar** operacions sobre les taules (podem guardar informació sobre qui i quan es va realitzar alguna modificació).

> - **Verificar que les dades siguen correctes** abans de añadirlos o usar-los per a una modificació.

> - **Còpies de seguretat** de les dades abans de que siguen modificats o esborrats.

> **📌 Triggers i operacions en cascada**
> 

> Un trigger **no s'executarà** en cas d'una operació en cascada a causa de les restriccions d'integritat referencial (clau primària-clau forana).

## **Crear un trigger**

És necessari tindre el permís **`TRIGGER`** otorgado per a poder crear un trigger. Aquest permís es troba en el nivell de seguretat de taula, per la qual cosa és necessari indicar sobre què taula tindrà permís.

Per a crear un trigger es necessita determinar:

- **En què taula** s'aplicarà el trigger.

- **Què operació** s'aplicarà (`INSERT` / `DELETE` / `UPDATE`).

- **El moment** en el que s'execute el trigger, abans o després de que es realitze l'operació sobre la taula (`BEFORE`, `AFTER`).

> **📌 Sintaxi bàsica**
> 

```sql
DELIMITER $$
CREATE TRIGGER nombre_trigger
BEFORE | AFTER INSERT | UPDATE | DELETE ON tabla
FOR EACH ROW
BEGIN
    -- Instrucciones del trigger
END$$
DELIMITER ;
```

## **Accés a valors: OLD i NEW**

Dins del trigger es pot accedir als valors de la fila de la taula **anterior i posterior** a l'ejecució de l'ordre SQL. Al realitzar una operació de `UPDATE` sobre una columna, aquesta columna tindrà un valor abans de l'ejecució de l'ordre SQL i un altre després.

- **`OLD`**: taula que posseeix les dades de cada columna amb els **valors antics**.

- **`NEW`**: taula que posseeix les dades de cada columna amb els **valors nous**.

| Operació | NEW | OLD |
| --- | --- | --- |
| **UPDATE** | Valors nous | Valors antics |
| **INSERT** | Valors nous | **NO EXISTEIX** |
| **DELETE** | **NO EXISTEIX** | Valors antics |

## **Altres operacions**

| Operació | Ordre SQL |
| --- | --- |
| Visualitzar triggers | `SHOW TRIGGERS;` — o consultar `information_schema.triggers` |
| Modificar triggers | **NO és possible**: és necessari esborrar i tornar a crear el trigger |
| Esborrar triggers | `DROP TRIGGER [IF EXISTS] nombre_trigger;` |

## **Exercicis resolts**

### **Exercici 1**

Fes que no es puga afegir un nou animal si el tipus és `'León'` i el número d'anys és major que 20. En cas de no complir-se la condició llançarà una excepció.

> **📌 Solució**
> 

```sql
DELIMITER $$
CREATE TRIGGER before_insert_animal_check_leon
BEFORE INSERT ON animales
FOR EACH ROW
BEGIN
    IF NEW.tipo = 'León' AND NEW.anhos > 20 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'El tipo león no puede tener más de 20 años';
    END IF;
END$$
DELIMITER ;
```

### **Exercici 2**

Quan incorpore un nou animal, fer que aquest animal estiga cura pel **artista que cuida a menys animals**. Hauràs de tindre en compte el cas en el que no haja cap artista cuidant animals: en eixe cas has de coger al primer artista que no siga cap. Si no hi ha cap artista hauràs de llançar una excepció.

> **📌 Solució**
> 

```sql
DELIMITER $$
CREATE TRIGGER trg_asignar_artista
AFTER INSERT ON ANIMALES
FOR EACH ROW
BEGIN
    DECLARE v_nif_artista CHAR(9);

    -- Buscar el artista con menos animales
    SELECT A.NIF
    INTO v_nif_artista
    FROM ARTISTAS A
    LEFT JOIN (
        SELECT NIF_ARTISTA, COUNT(*) AS total_animales
        FROM ANIMALES_ARTISTAS
        GROUP BY NIF_ARTISTA
    ) CA ON A.NIF = CA.NIF_ARTISTA
    ORDER BY IFNULL(CA.total_animales, 0) ASC
    LIMIT 1;

    -- Si no se encontró artista, lanzar excepción
    IF v_nif_artista IS NULL THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'No hay artistas para cuidar a animales';
    ELSE
        -- Asignar el nuevo animal al artista con menos animales
        INSERT INTO ANIMALES_ARTISTAS (NOMBRE_ANIMAL, NIF_ARTISTA)
        VALUES (NEW.NOMBRE, v_nif_artista);
    END IF;
END$$
DELIMITER ;
```

> **📌 Transaccions**
> 

> Aquest trigger afegeix dos files (una a `ANIMALES` i una altra a `ANIMALES_ARTISTAS`). Si volem que totes dues operacions es facen juntas, hauria d'anar dins d'una **transacció**, i el `ROLLBACK` no es pot fer dins del trigger: hi hauria que començar la transacció en el codi on es realitza l'ordre `INSERT` (programa client o procediment emmagatzemat).

### **Exercici 3**

Fes tot el necessari perquè el camp de la taula `ATRACCIONES` es actualice quan es añadan, borren o modifiquen dades en la taula `ATRACCION_DIA`. Si a l'afegir una celebració nova (`ATRACCION_DIA`) la `fecha_inicio` en `ATRACCIONES` és `NULL`, ha d'actualitzar-se amb la **data actual**.

> **📌 Nota**
> 

> Tant la data com les guanys poden tindre valors nuls. Fer ús de la funció **`IFNULL`** per a donar un valor a aquestes columnes quan siguen `NULL` (`null + valor = null`).

> **📌 Solució**
> 

```sql
DELIMITER $$
CREATE TRIGGER trg_insert_atraccion_dia
AFTER INSERT ON ATRACCION_DIA
FOR EACH ROW
BEGIN
    -- Actualizar fecha_inicio si es NULL
    UPDATE ATRACCIONES
    SET FECHA_INICIO = IFNULL(FECHA_INICIO, CURDATE()),
        GANANCIAS = IFNULL(GANANCIAS, 0) + IFNULL(NEW.GANANCIAS, 0)
    WHERE NOMBRE = NEW.NOMBRE_ATRACCION;
END$$
DELIMITER ;

DELIMITER $$
CREATE TRIGGER trg_update_atraccion_dia
AFTER UPDATE ON ATRACCION_DIA
FOR EACH ROW
BEGIN
    DECLARE suma_total DOUBLE;

    -- Recalcular suma total de ganancias de toda la atracción
    SELECT SUM(IFNULL(GANANCIAS, 0))
    INTO suma_total
    FROM ATRACCION_DIA
    WHERE NOMBRE_ATRACCION = NEW.NOMBRE_ATRACCION;

    UPDATE ATRACCIONES
    SET GANANCIAS = IFNULL(suma_total, 0)
    WHERE NOMBRE = NEW.NOMBRE_ATRACCION;
END$$
DELIMITER ;

DELIMITER $$
CREATE TRIGGER trg_delete_atraccion_dia
AFTER DELETE ON ATRACCION_DIA
FOR EACH ROW
BEGIN
    DECLARE suma_total DOUBLE;

    -- Recalcular suma total de ganancias tras borrado
    SELECT SUM(IFNULL(GANANCIAS, 0))
    INTO suma_total
    FROM ATRACCION_DIA
    WHERE NOMBRE_ATRACCION = OLD.NOMBRE_ATRACCION;

    UPDATE ATRACCIONES
    SET GANANCIAS = IFNULL(suma_total, 0)
    WHERE NOMBRE = OLD.NOMBRE_ATRACCION;
END$$
DELIMITER ;
```

### **Exercici 4**

Modifica la taula `ATRACCIONES` i afegeix una nova columna de nom **`contador`**, de tipus numèric i valor per defecte de zero, que lleve compta de quantes vegades es ha celebrado l'atracció i que es actualice amb qualsevol operació.

> **📌 Nota**
> 

> Les dades ja añadits tindran com valor `NULL`. Realitza una operació de `UPDATE` per a ponerlos al seu valor correcte.

> **📌 Solució**
> 

```sql
-- Modificar la tabla
ALTER TABLE ATRACCIONES ADD CONTADOR INT DEFAULT 0;

-- Triggers para actualizar el contador automáticamente
DELIMITER $$
CREATE TRIGGER trg_incrementa_contador
AFTER INSERT ON ATRACCION_DIA
FOR EACH ROW
BEGIN
    UPDATE ATRACCIONES
    SET CONTADOR = IFNULL(CONTADOR, 0) + 1
    WHERE NOMBRE = NEW.NOMBRE_ATRACCION;
END$$
CREATE TRIGGER trg_decrementa_contador
AFTER DELETE ON ATRACCION_DIA
FOR EACH ROW
BEGIN
    UPDATE ATRACCIONES
    SET CONTADOR = IFNULL(CONTADOR, 1) - 1
    WHERE NOMBRE = OLD.NOMBRE_ATRACCION;
END$$
DELIMITER ;

-- Inicializar los datos ya existentes
UPDATE ATRACCIONES A
SET CONTADOR = (
    SELECT COUNT(*)
    FROM ATRACCION_DIA D
    WHERE D.NOMBRE_ATRACCION = A.NOMBRE
);
```

> **📌 Resum**
> 

> - Un **trigger** s'executa automàticament ante operacions `INSERT`/`UPDATE`/`DELETE` sobre una taula.

> - S'executa **abans (`BEFORE`)** o **després (`AFTER`)** de l'operació.

> - Amb **`OLD`** i **`NEW`** accedim als valors antics i nous de la fila.

> - Per a llançar una excepció s'usa `SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '...'`.

> - Els triggers **no es poden modificar**: cal borrar-los i tornar a crear-los.
