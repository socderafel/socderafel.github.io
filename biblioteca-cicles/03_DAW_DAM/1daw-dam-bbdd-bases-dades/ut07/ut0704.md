Un **Disparador** o **Trigger** és un bloc de codi procedural que s'executa de manera totalment **automàtica** quan es produeix un esdeveniment determinat sobre una taula (com una inserció, actualització o esborrament). 

Els triggers són una de les eines més potents per a implementar **pistes d'auditoria**, sincronitzacions complexes i validacions avançades que no es poden resoldre amb simples restriccions `CHECK`.

---

## ⏱️ Anatomia d'un Trigger a PostgreSQL

A PostgreSQL, la creació d'un trigger es fa en dos passos:
1. Es crea una funció especial que retorna el tipus `TRIGGER`.
2. Es defineix el trigger lligat a la taula mitjançant `CREATE TRIGGER`.

```
ESDEVENIMENT: INSERT / UPDATE / DELETE / TRUNCATE
MOMENT:       BEFORE  (Abans de desar a disc)
              AFTER   (Després de desar a disc)
              INSTEAD OF (En vistes)
NIVELL:       FOR EACH ROW (Es dispara per a cada fila afectada)
              FOR EACH STATEMENT (Es dispara 1 cop per sentència)
```

---

## 📝 Exemple Pràctic: Auditoria de Canvis amb `OLD` i `NEW`

Suposem que volem registrar qui modifica els salaris dels empleats i quin era el valor antic:

```sql
-- 1. Taula de registre d'auditoria
CREATE TABLE auditories_salaris (
    id_auditoria SERIAL PRIMARY KEY,
    id_empleat INT NOT NULL,
    salari_antic NUMERIC(10,2),
    salari_nou NUMERIC(10,2),
    usuari_db VARCHAR(50) DEFAULT CURRENT_USER,
    data_canvi TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Funció disparadora
CREATE OR REPLACE FUNCTION trg_auditar_salari()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
BEGIN
    -- Comprovem si realment s'ha modificat el camp salari
    IF OLD.salari <> NEW.salari THEN
        INSERT INTO auditories_salaris (id_empleat, salari_antic, salari_nou)
        VALUES (OLD.id_empleat, OLD.salari, NEW.salari);
    END IF;
    RETURN NEW; -- En un trigger BEFORE UPDATE, retorna el registre a desar
END;
$$;

-- 3. Associació del Trigger a la taula
CREATE TRIGGER trigger_auditoria_salaris
AFTER UPDATE OF salari ON empleats
FOR EACH ROW
EXECUTE FUNCTION trg_auditar_salari();
```
