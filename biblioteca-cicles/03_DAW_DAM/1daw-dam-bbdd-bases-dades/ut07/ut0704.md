Aquest tipus de sentències es basen en el concepte de que quan un programa client realitzarà una operació SQL (`SELECT`, `INSERT`, ...) normalment sempre executarà la **mateixa sentència canviant les dades** que es li envien al servidor.

Imaginem que donem d'alta a 10 empleats: hauríem d'enviar 10 sentències `INSERT` amb les dades de cada un, i el gestor hauria d'analitzar la sentència per cada empleat. Amb les sentències *prepared*, **enviem al servidor la sentència SQL sense dades, amb paràmetres**. El gestor l'analitza una sola vegada per a comprovar que no té problemes sintáctics i, una vegada fet, el client només ha d'enviar les dades que seran ejecutats per la sentència.

Les avantatges són:

- Una **major velocitat d'ejecució** perquè les sentències estan pre-compilades.

- Una **major seguretat**, ja que impedeix la inyecció de codi.

- La possibilitat de crear **sentències SQL dinàmiques**, és a dir, construir la sentència com si fóra una cadena a la que anem afegint parts fins a tenerla completa i ejecutar-la.

## **Procés d'ús**

El procés per a poder utilitzar aquest tipus de sentències és el següent, tant si el fem des del client (php, java, ...) com des d'un procediment emmagatzemat:

1. **`PREPARE`**: definim la sentència SQL amb paràmetres que volem executar (per exemple, una sentència `INSERT` porta com paràmetres els valors a afegir, o una sentència `SELECT` porta paràmetres en la part `WHERE`).

1. **`EXECUTE`**: per a executar la sentència.

1. **Pas de dades** als paràmetres que estan definits en la sentència anterior.

1. **`DEALLOCATE PREPARE`**: per a liberar la memòria del servidor de la sentència preparada.

## **Exemple I**

> **📌 Exemple bàsic**
> 

```sql
DELIMITER$$
SET @sentencia = 'SELECT * FROM TABLA WHERE col1=? AND col2=?';
PREPARE stPrepared FROM @sentencia; -- Preparamos la sentencia. El nombre stPrepared lo elegimos nosotros.

SET @valorParam1 = 2;      -- Usamos una variable para establecer el valor del parámetro 1
SET @valorParam2 = 'Angel';-- Usamos una variable para establecer el valor del parámetro 2

EXECUTE stPrepared USING @valorParam1, @valorParam2;

DEALLOCATE PREPARE stPrepared; -- Liberamos la memoria
END$$
DELIMITER ;
```

> **📌 Important**
> 

> - En la sentència `PREPARE` **només podem emprar variables de sessió o literals**. No podem emprar variables locals si estem dins d'un procediment.

> - En la sentència `EXECUTE ... USING` **només podrem utilitzar variables de sessió**.

> - La sentència `PREPARE` és **visible a nivell de sessió**: si no fem un `DEALLOCATE`, podríem utilitzar-l'en qualsevol pestanya SQL de la connexió activa.

## **Exemple II. Sentència SQL dinàmica**

> **📌 Procediment amb PREPARE**
> 

```sql
USE CIRCO;
DELIMITER $$
CREATE PROCEDURE animales_getListPorFiltro (p_nombreColum VARCHAR(20), p_operacion CHAR(2), p_valorParam VARCHAR(10))
COMMENT 'Devuelve todos los animales que cumplan la condición que se le va a pasar como parámetro.'
BEGIN
    SET @v_consulta = CONCAT('SELECT * FROM ANIMALES WHERE ', p_nombreColum, p_operacion, '?');
    SET @v_valor = p_valorParam;

    PREPARE prepConsulta FROM @v_consulta;
    EXECUTE prepConsulta USING @v_valor;
    DEALLOCATE PREPARE prepConsulta;
END $$
DELIMITER ;

CALL animales_getListPorFiltro('tipo', '=', 'Jirafa');
CALL animales_getListPorFiltro('anhos', '>=', '3');
```

## **Exercicis resolts**

### **Exercici 1**

Crea un procediment de nom `animals_getListFiltroNumeroColum` que retorne el número d'animals indicat pel paràmetre (utilitzar `LIMIT`). També es li pasará en un altre paràmetre **les columnes** que ha de mostrar de la forma `'col1, col3, col5'`.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS animales_getListFiltroNumeroColum;
DELIMITER $$
CREATE PROCEDURE animales_getListFiltroNumeroColum (p_columnas VARCHAR(100), p_numero INT)
COMMENT 'Devuelve el número de animales indicado por el parámetro y las columnas indicadas.'
BEGIN
    SET @v_consulta = CONCAT('SELECT ', p_columnas, ' FROM ANIMALES LIMIT ?'); -- Añadir espacios en blanco después del SELECT y antes del FROM

    SET @v_numero = p_numero;

    PREPARE prepConsulta_animales_getListFiltroNumeroColum FROM @v_consulta;
    EXECUTE prepConsulta_animales_getListFiltroNumeroColum USING @v_numero;
    DEALLOCATE PREPARE prepConsulta_animales_getListFiltroNumeroColum;
END $$
DELIMITER ;

CALL animales_getListFiltroNumeroColum('nombre,anhos', 2);
CALL animales_getListFiltroNumeroColum('nombre,tipo,peso', 4);
```

### **Exercici 2**

Crea un procediment de nom `animals_getListFiltroPista` que retorne la llista d'animals que treballen en la pista que s'envia com paràmetre. En cas que **no es envíe dada (valor null) ha de mostrar tots els animals**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS animales_getListFiltroPista;
DELIMITER $$
CREATE PROCEDURE animales_getListFiltroPista (p_pistas VARCHAR(100))
COMMENT 'Devuelve la lista de animales que trabajan en las pistas enviadas como parámetro en formato pista1,pista2,... En caso de null, todos los animales'
BEGIN
    IF (p_pistas IS NOT NULL) THEN
        SET @v_consulta = CONCAT('SELECT * FROM ANIMALES WHERE nombre_pista IN (', p_pistas, ')');
        -- select @v_consulta; => Comentado para saber si la consulta está bien
        -- SET @v_consulta = 'SELECT * FROM ANIMALES WHERE nombre_pista IN (?)'; => No se puede así,
        -- ya que cambiaríamos la ? por una cadena 'valor1,valor2,...'

        PREPARE prepConsulta_animales_getListFiltroPista FROM @v_consulta;
        EXECUTE prepConsulta_animales_getListFiltroPista;
        DEALLOCATE PREPARE prepConsulta_animales_getListFiltroPista;
    ELSE
        SELECT * FROM ANIMALES ORDER BY nombre;
    END IF;
END $$
DELIMITER ;

CALL animales_getListFiltroPista('\'LATERAL1\'');
CALL animales_getListFiltroPista('\'LATERAL2\',\'SUPER\'');
```

### **Exercici 3**

Crea un procediment de nom `animals_getByAnoPeso` al que es li pasen dos paràmetres (**pes i any**) i en funció de si porten valor o no, fes que retorne els animals que complisquen els criteris de cerca.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS animales_getByAnoPeso;
DELIMITER $$
CREATE PROCEDURE animales_getByAnoPeso(p_ano SMALLINT, p_peso FLOAT)
BEGIN
    SET @consulta = 'SELECT * FROM animales WHERE 1=1';

    IF (p_peso IS NOT NULL) THEN
        SET @consulta = CONCAT(@consulta, ' AND peso = ', p_peso);
    END IF;

    IF (p_ano IS NOT NULL) THEN
        SET @consulta = CONCAT(@consulta, ' AND anhos = ', p_ano);
    END IF;

    PREPARE prepareConsulta FROM @consulta;
    EXECUTE prepareConsulta;
    DEALLOCATE PREPARE prepareConsulta;
END $$
DELIMITER ;

CALL animales_getByAnoPeso(2, NULL);
CALL animales_getByAnoPeso(NULL, 2.3);
CALL animales_getByAnoPeso(4, 1);
```

> **📌 Resum**
> 

> - Les sentències **`PREPARE`** pre-compilan una sentència SQL amb paràmetres (`?`), que s'executa amb `EXECUTE ... USING`.

> - Permeten construir **sentències SQL dinàmiques** concatenant cadenes amb `CONCAT`.

> - Només es poden emprar **variables de sessió** (`@variable`) en `PREPARE` i `EXECUTE ... USING`.

> - Es libera la memòria amb `DEALLOCATE PREPARE`.
