SQL estàndard és un llenguatge **declaratiu** i orientat a conjunts. Tanmateix, hi ha regles de negoci complexes que requereixen estructures típiques de la **programació imperativa**: variables, bifurcacions condicionals (`IF`, `CASE`), bucles repetitius i gestió d'errors o excepcions.

Per a satisfer aquesta necessitat, els principals SGBD han incorporat extensions procedurals:
- **PostgreSQL:** **PL/pgSQL** (*Procedural Language / PostgreSQL Structured Query Language*).
- **Oracle:** **PL/SQL**.
- **MySQL / MariaDB:** Llenguatge procedural estàndard SQL/PSM.
- **Microsoft SQL Server:** **Transact-SQL (T-SQL)**.

## 🧱 Estructura d'un Bloc de Codi en PL/pgSQL

La unitat bàsica de programació és el **bloc**, que pot ser anònim (executat una sola vegada amb `DO`) o amb nom (dins d'una funció o procediment):

```sql
DO $$
DECLARE
    -- 1. Secció de declaració de variables
    v_total_usuaris INT := 0;
    v_missatge VARCHAR(100);
BEGIN
    -- 2. Secció executable de lògica
    SELECT COUNT(*) INTO v_total_usuaris FROM usuaris;

    IF v_total_usuaris > 1000 THEN
        v_missatge := 'Comunitat multitudinària';
    ELSIF v_total_usuaris > 100 THEN
        v_missatge := 'Comunitat activa';
    ELSE
        v_missatge := 'Comunitat inicial';
    END IF;

    RAISE NOTICE 'Resultat: % (Usuaris: %)', v_missatge, v_total_usuaris;

EXCEPTION
    -- 3. Secció opcional de control d'errors
    WHEN OTHERS THEN
        RAISE WARNING 'S''ha produït un error inesperat: %', SQLERRM;
END $$;
```

---

## 🔀 Estructures de Control de Flux

### 1. Condicional `IF - ELSIF - ELSE - END IF`
Permet prendre decisions en funció de condicions booleanes.

### 2. Estructura `CASE - WHEN - THEN - ELSE - END CASE`
Ideal quan es compara una mateixa variable contra múltiples valors possibles.

### 3. Bucles
- **Bucle Infinit amb eixida condicional:** `LOOP ... EXIT WHEN condicio; ... END LOOP;`
- **Bucle Mentre:** `WHILE condicio LOOP ... END LOOP;`
- **Bucle Per a Rang Numèric:** `FOR i IN 1..10 LOOP ... END LOOP;`
- **Bucle sobre Consulta:** `FOR fila IN SELECT * FROM productes LOOP ... END LOOP;`
