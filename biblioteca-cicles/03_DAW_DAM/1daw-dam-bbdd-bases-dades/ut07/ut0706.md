Un **esdeveniment** és una tasca programada que s'executa de forma automàtica en moments específics o de manera periódica. Funciona de forma similar a un *cron job* en sistemes Linux, permetent definir **instruccions SQL que es ejecutarán sense intervenció manual**, dins del propi motor de base de dades.

S'utilitzen per a realitzar accions planificades, com l'actualització de dades, l'eliminació de registres obsoletos o la generació d'informes en moments predeterminats. A més, faciliten l'automatització del manteniment i l'administració de la base de dades, ja que centralizan tasques repetitivas en un únic punt. Poden configurar-se per a executar-se **una sola vegada o en intervalos regulars**.

> **📌 Programador d'esdeveniments**
> 

> Per al seu funcionament, és **obligatori** que el programador d'esdeveniments estiga habilitado:

```sql
-- Verificar estado actual
SHOW VARIABLES LIKE 'event_scheduler';

-- Habilitar el programador de eventos (método 1 - sesión actual)
SET GLOBAL event_scheduler = ON;
```

## **Crear esdeveniments**

Per a crear un esdeveniment usarem la sentència **`CREATE EVENT`**, amb la següent sintaxi:

```sql
CREATE
[DEFINER = user]
EVENT
[IF NOT EXISTS]
event_name
ON SCHEDULE schedule
[ON COMPLETION [NOT] PRESERVE]
[ENABLE | DISABLE | DISABLE ON {REPLICA | SLAVE}]
[COMMENT 'string']
DO event_body;

schedule: {
    AT timestamp [+ INTERVAL interval] ...
    | EVERY interval
      [STARTS timestamp [+ INTERVAL interval] ...]
      [ENDS timestamp [+ INTERVAL interval] ...]
}

interval:
    quantity {YEAR | QUARTER | MONTH | DAY | HOUR | MINUTE |
              WEEK | SECOND | YEAR_MONTH | DAY_HOUR | DAY_MINUTE |
              DAY_SECOND | HOUR_MINUTE | HOUR_SECOND | MINUTE_SECOND}
```

on:

- **`SCHEDULE`**: defineix quan i amb què freqüència s'executa, podent ser en una data concreta (`AT`) o de forma repetida (`EVERY`), definint un inici (`STARTS`) i/o un fi (`ENDS`).

- **`ON COMPLETION`**: determina si l'esdeveniment es conserva després de la seua ejecució.

- **`ENABLE`/`DISABLE`**: estat inicial de l'esdeveniment.

- **`DO`**: indica el bloc de codi SQL a executar.

## **Esdeveniments senzills**

Per a provar els esdeveniments, crearem una taula históric que admita una data i una cadena:

> **📌 Taula de prova**
> 

```sql
USE CIRCO;
CREATE TABLE historico (
    id INT AUTO_INCREMENT PRIMARY KEY,
    fecha DATETIME NOT NULL,
    descripcion VARCHAR(255) NOT NULL
);
```

Podem crear esdeveniments que s'executen **una sola vegada**, configurant un horari concret, ja siga un timestamp determinat amb `AT TIMESTAMP`, o un instante temporal calculat (`CURRENT_TIMESTAMP + INTERVAL ...`).

> **📌 Esdeveniment únic i esdeveniment únic calculat**
> 

```sql
CREATE EVENT evento_5min
ON SCHEDULE AT CURRENT_TIMESTAMP + INTERVAL 5 MINUTE
DO
    INSERT INTO historico(fecha, descripcion) VALUES
    (NOW(), 'Evento ejecutado dentro de 5 minutos');

CREATE EVENT evento_unico
ON SCHEDULE AT TIMESTAMP '2025-02-27 06:55:00'
DO
    INSERT INTO historico(fecha, descripcion) VALUES
    (NOW(), 'Evento único ejecutado');
```

## **Esdeveniments recurrentes**

La potència dels esdeveniments és que es ejecuten de forma **periódica**. Per a això, en el schedule usarem la clàusula `EVERY` per a indicar l'intervalo de la repetició:

> **📌 Esdeveniment recurrente**
> 

```sql
CREATE EVENT evento_recurrente
ON SCHEDULE EVERY 1 DAY
STARTS '2025-03-01 00:00:00' ENDS '2025-03-31 23:59:59'
DO
    DELETE FROM historico WHERE fecha < DATE_SUB(NOW(), INTERVAL 30 DAY);
```

A més de l'intervalo de repetició, també podem indicar una data de **inici** per a començar l'esdeveniment periódic mitjançant `STARTS`, una data de **finalizació** perquè termine mitjançant `ENDS` o utilitzar tots dos per a indicar un periodo determinat:

> **📌 Esdeveniments amb inici/fi**
> 

```sql
CREATE EVENT evento_recurrente_con_fin
ON SCHEDULE EVERY 1 WEEK ENDS '2025-12-31 23:59:59'
DO
    CALL actualizar_inventario();

CREATE EVENT evento_recurrente_con_inicio
ON SCHEDULE EVERY 12 HOUR STARTS '2025-03-01 00:00:00'
DO
    CALL actualizar_inventario();

CREATE EVENT evento_recurrente_con_inicio_fin
ON SCHEDULE EVERY 1 DAY + INTERVAL 12 HOUR
STARTS '2025-03-01 00:00:00' ENDS '2025-12-31 23:59:59'
DO
    CALL actualizar_inventario();
```

> **📌 Bona pràctica**
> 

> Una bona pràctica és **encapsular la lògica dels esdeveniments dins de procediments emmagatzemats**, per a poder probar-los sense necessitat de provocar que es dispare l'esdeveniment, a més de poder reutilitzar la lògica entre esdeveniments amb periodicitats distintes.

## **Exercicis resolts**

### **Exercici I. Registrar usuaris connectats**

Volem registrar, cada 1 minut en el dia d'hui i durant uns 10 minuts des del moment de creació de l'esdeveniment, **què usuaris estan accedint a la base de dades** `employees`. Aquests usuaris (els seus noms i equips) hauran de quedar registrats en una taula de nom `historico_usuarios_hora`.

Crea dos usuaris i conéctate a la base de dades. Després fes que un d'ells es desconecte.

> **📌 1. Taules de treball**
> 

```sql
SELECT USER, HOST, NOW()
FROM information_schema.PROCESSLIST;

DROP TABLE IF EXISTS historico_usuarios_hora;
CREATE TABLE historico_usuarios_hora (
    usuario VARCHAR(100),
    host VARCHAR(100),
    fecha DATETIME
);
```

> **📌 2. Crear taula i esdeveniment que registre connexions**
> 

```sql
DROP TABLE IF EXISTS historico_usuarios_hora;
CREATE TABLE historico_usuarios_hora (
    usuario VARCHAR(100),
    host VARCHAR(100),
    fecha DATETIME
);

DELIMITER $$
CREATE EVENT registrar_usuarios_evento
ON SCHEDULE EVERY 1 MINUTE
STARTS CURRENT_TIMESTAMP
ENDS CURRENT_TIMESTAMP + INTERVAL 10 MINUTE
DO
BEGIN
    INSERT INTO historico_usuarios_hora (usuario, host, fecha)
    SELECT USER, HOST, NOW()
    FROM information_schema.PROCESSLIST;
END $$
DELIMITER ;
```

> **📌 3. Crear dos usuaris, connectar i desconectar un**
> 

```sql
-- Crear usuarios
CREATE USER 'usuario1'@'localhost' IDENTIFIED BY '1234';
CREATE USER 'usuario2'@'localhost' IDENTIFIED BY '1234';

-- Dar acceso a base de datos employees
GRANT ALL PRIVILEGES ON employees.* TO 'usuario1'@'localhost';
GRANT ALL PRIVILEGES ON employees.* TO 'usuario2'@'localhost';
FLUSH PRIVILEGES;
```

> **📌 4. Modificar l'esdeveniment perquè NO s'elimine automàticament**
> 

```sql
ALTER EVENT registrar_usuarios_evento
ON COMPLETION PRESERVE;
```

> **📌 5. Modificar perquè s'execute en el próximo minut**
> 

```sql
ALTER EVENT registrar_usuarios_evento
ON SCHEDULE EVERY 1 MINUTE
STARTS CURRENT_TIMESTAMP + INTERVAL 1 MINUTE
ENDS CURRENT_TIMESTAMP + INTERVAL 11 MINUTE;
```

### **Exercici II. Còpia de departaments**

Fes que el dia **15 de Maig del 2025 a les 23:15** es guarde una còpia de les dades de la taula `departments` en una taula creada per ti prèviament de nom `dept_copia_temp`.

> **📌 Solució**
> 

```sql
DROP TABLE IF EXISTS dept_copia_temp;
CREATE TABLE dept_copia_temp AS
SELECT * FROM departments WHERE 1=0;

DELIMITER $$
CREATE EVENT copia_departamentos
ON SCHEDULE AT '2018-04-30 23:15:00'
DO
BEGIN
    INSERT INTO dept_copia_temp
    SELECT * FROM departments;
END $$
DELIMITER ;
```

### **Exercici III. Número d'empleats**

Crea una taula de nom `empleados_numero_mensual` que guarde el **número d'empleats** que té l'empresa. Fes que s'execute **una vegada 4 dies després** de que es creu l'esdeveniment. Executa l'ordre que mostre el moment en que es va a executar. Modifica l'esdeveniment perquè s'execute **des del dia d'hui fins a dins d'un any** i que el faça **cada mes**.

> **📌 Solució**
> 

```sql
DROP TABLE IF EXISTS empleados_numero_mensual;
CREATE TABLE empleados_numero_mensual (
    fecha DATE,
    total_empleados INT
);

-- Evento que se ejecuta 4 días después de su creación
DELIMITER $$
CREATE EVENT contar_empleados_una_vez
ON SCHEDULE AT CURRENT_DATE + INTERVAL 4 DAY
DO
BEGIN
    INSERT INTO empleados_numero_mensual (fecha, total_empleados)
    SELECT CURRENT_DATE, COUNT(*) FROM employees;
END $$
DELIMITER ;

-- Consultar cuándo se ejecutará
SELECT * FROM information_schema.EVENTS WHERE EVENT_NAME = 'contar_empleados_una_vez';

-- Modificar el evento para que se ejecute cada mes durante un año
ALTER EVENT contar_empleados_una_vez
ON SCHEDULE EVERY 1 MONTH
STARTS CURRENT_DATE
ENDS CURRENT_DATE + INTERVAL 1 YEAR;
```

### **Exercici IV. Aumento salarial de managers**

Fes que el dia **1 de Gener de cada any** es actualicen els salarios dels manager de cada departament un **10%** (que estiguen treballant actualment en l'empresa). Aquesta actualització s'ha de produir **durant 5 anys** a partir de l'actual.

> **📌 Solució**
> 

```sql
DELIMITER $$
CREATE EVENT aumento_salario_managers
ON SCHEDULE EVERY 1 YEAR
STARTS '2026-01-01 00:00:00'
ENDS '2031-01-01 00:00:00'
DO
BEGIN
    UPDATE employees
    SET salary = salary * 1.10
    WHERE emp_no IN (
        SELECT emp_no FROM dept_manager
    );
END $$
DELIMITER ;
```

### **Exercici V. Consultar i esborrar esdeveniments**

Mostra tots els esdeveniments creats, tots els esdeveniments creats pel usuari root i esborra un dels esdeveniments.

> **📌 Solució**
> 

```sql
-- Muestra todos los eventos creados
SELECT * FROM information_schema.EVENTS;

-- Muestra todos los eventos creados por el usuario root
SELECT * FROM information_schema.EVENTS WHERE DEFINER LIKE 'root@%';

-- Borra un evento, asegurándonos de que exista
DROP EVENT IF EXISTS registrar_usuarios_evento;
```

> **📌 Resum**
> 

> - Un **esdeveniment** és una tasca programada que s'executa automàticament (`cron` de MySQL).

> - Es crea amb `CREATE EVENT ... ON SCHEDULE ... DO ...`.

> - Pot executar-se una sola vegada (`AT`) o periódicament (`EVERY`), amb `STARTS`/`ENDS`.

> - `ON COMPLETION PRESERVE` evita que l'esdeveniment desaparezca a l'acabar.

> - Es consulten en `information_schema.EVENTS` i s'esborren amb `DROP EVENT`.
