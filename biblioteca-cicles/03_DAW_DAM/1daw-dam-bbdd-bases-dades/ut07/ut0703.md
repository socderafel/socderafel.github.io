A partir de la versió 11 de PostgreSQL (i tradicionalment en MySQL, Oracle i SQL Server), es van introduir els **Procediments Emmagatzemats (Stored Procedures)** mitjançant la sentència `CREATE PROCEDURE`.

A diferència de les funcions, un procediment **no està dissenyat per retornar un valor escalar**, sinó per executar un procés de negoci complet que pot incloure el control explícit de **transaccions internes** (`COMMIT` i `ROLLBACK`).

---

## 🛠️ Creació i Invocació de Procediments

Els procediments s'invoquen mitjançant la instrucció **`CALL`**:

```sql
CREATE OR REPLACE PROCEDURE pr_transferir_fons(
    p_compte_origen INT,
    p_compte_desti INT,
    p_import NUMERIC
)
LANGUAGE plpgsql
AS $$
DECLARE
    v_saldo_actual NUMERIC;
BEGIN
    -- Comprovar saldo disponible
    SELECT saldo INTO v_saldo_actual 
    FROM comptes 
    WHERE id = p_compte_origen;

    IF v_saldo_actual IS NULL OR v_saldo_actual < p_import THEN
        RAISE EXCEPTION 'Saldo insuficient (Disponible: % €, Sol·licitat: % €)', 
            v_saldo_actual, p_import;
    END IF;

    -- Debitar i abonar
    UPDATE comptes SET saldo = saldo - p_import WHERE id = p_compte_origen;
    UPDATE comptes SET saldo = saldo + p_import WHERE id = p_compte_desti;

    -- Confirmació explícita
    COMMIT;
    RAISE NOTICE 'Transferència de % € completada amb èxit.', p_import;

EXCEPTION
    WHEN OTHERS THEN
        ROLLBACK;
        RAISE WARNING 'Operació fallida: %', SQLERRM;
END;
$$;
```

### Invocació:
```sql
CALL pr_transferir_fons(101, 202, 350.00);
```

---

## ⚖️ Taula Comparativa: Funció vs. Procediment

| Característica | Funció (`FUNCTION`) | Procediment (`PROCEDURE`) |
| :--- | :--- | :--- |
| **Objectiu Principal** | Realitzar un càlcul i retornar un valor | Executar una seqüència de tasques de negoci |
| **Retorn de valor** | Obligatori (`RETURNS tipus`) | No té clàusula `RETURNS` (usa `INOUT` si cal) |
| **Invocació** | Dins de consultes `SELECT fn(...)` | Mitjançant ordre `CALL pr(...)` |
| **Control Transaccional** | No pot fer `COMMIT` / `ROLLBACK` intern | **Pot executar `COMMIT` i `ROLLBACK`** |
| **Crida en clàusula WHERE** | Sí, admès directament | No, totalment inviable |
