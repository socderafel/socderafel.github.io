Un **procediment emmagatzemat** és un recurs que incorporen tots els gestors relacionals i que permet **associar un nom** (el nom del procediment) a un **conjunt d'instruccions SQL**.

Cada vegada que es **anomene al procediment**, s'executen totes les instruccions.

A diferència d'un mètode en programació orientada a objectes, podrem emprar **instruccions SQL** que seran ejecutades directament en el gestor.

> **📌 Per què usar procediments?**
> 

> L'ús de procediments emmagatzemats ens proporcionará:

> - **Més rapidesa**: l'ejecució es realitza en la capa de BBDD, sense transformacions de client a servidor.

> - **Més simplicitat en la seguretat**: podem especificar qui té permís per a executar el procediment.

> - **Més seguretat**: l'ús de procediments amb paràmetres evita accions que comprometan la seguretat, com la **inyecció de codi** en formularis.

> - **Estàndard**: existeix un únic lloc centralitzat (el gestor de base de dades) on es troben tots els procediments, evitant duplicitats de codi.

> - **Velocitat**: com el codi ja està en el servidor, els clients només envien les dades que necessiten els procediments.

## **Crear un procediment**

> **📌 Sintaxi**
> 

```sql
CREATE
[DEFINER = user]
PROCEDURE [IF NOT EXISTS] sp_name ([proc_parameter[,...]])
[characteristic ...] routine_body

proc_parameter:
    [ IN | OUT | INOUT ] param_name type

type:
    Any valid MySQL data type

characteristic: {
    COMMENT 'string'
    | LANGUAGE SQL
    | [NOT] DETERMINISTIC
    | { CONTAINS SQL | NO SQL | READS SQL DATA | MODIFIES SQL DATA }
    | SQL SECURITY { DEFINER | INVOKER }
}

routine_body:
    Valid SQL routine statement
```

- Com a mínim hem d'indicar un **nom** per al procediment i un conjunt d'ordres SQL entre les paraules clau `BEGIN` i `END`.

- Un procediment es crea dins d'una **base de dades concreta**.

- Entre les clàusules que podem emprar dins del `CREATE PROCEDURE` estaría **`COMMENT`**, que ens serveix per a documentar quin és l'objecte del procediment.

> **📌 Estructura bàsica**
> 

```sql
USE BD;
DELIMITER $$
CREATE PROCEDURE nombreProc()
COMMENT 'Objetivo del procedimiento'
BEGIN
    -- Instrucciones SQL a ejecutar dentro del procedimiento
END$$
DELIMITER ;
```

### **El DELIMITER**

La primera instrucció d'un procediment emmagatzemat en MySQL és l'ordre SQL **`DELIMITER`**:

> **📌 Exemple. Primer procediment**
> 

```sql
USE CIRCO;
DELIMITER $$
CREATE PROCEDURE animales_getList()
BEGIN
    SELECT nombre
    FROM ANIMALES
    ORDER BY nombre;
END$$
DELIMITER ;
```

MySQL usa com **delimitador de sentències SQL el punt i coma** per defecte. Vol dir que cada vegada que troba un punt i coma intenta executar l'ordre SQL. El procediment emmagatzemat es veu com un **tot**, com si fóra una única instrucció que MySQL execute entera, per això cambiamos temporalment el delimitador a `$$`.

## **Altres operacions**

| Operació | Ordre SQL |
| --- | --- |
| Anomenar a un procediment | `CALL CIRCO.animales_getList();` |
| Llistar procediments | `SHOW PROCEDURE STATUS WHERE Db = 'CIRCO';` |
| Visualitzar el codi d'un procediment | `SHOW CREATE PROCEDURE animales_getList;` |
| Modificar un procediment | `ALTER PROCEDURE animales_getList COMMENT 'Obtiene un listado de todos los animales';` |
| Esborrar un procediment | `DROP PROCEDURE IF EXISTS nombre_proc;` |

## **Exercicis resolts**

### **Exercici 1**

Crea un procediment de nom `artistas_getList()` que retorne el nom i cognoms dels artistes separats per coma amb el format: `apellidos,nombre` ordenats de manera descendent.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_getList;
DELIMITER $$
CREATE PROCEDURE artistas_getList()
COMMENT 'Devuelve el nombre completo de todos los artistas ordenado descendentemente'
BEGIN
    SELECT CONCAT(apellidos, ',', nombre) AS nombreCompleto
    FROM ARTISTAS
    ORDER BY nombreCompleto DESC;
END$$
DELIMITER ;
```

### **Exercici 2**

Crea un procediment de nom `artistas_getListAnimales()` que retorne els noms dels artistes juntament amb el seu nif així com el nom i pes dels animals que estan atendits pels artistes, ordenats per nif de l'artista i nom de l'animal.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_getListAnimales;
DELIMITER $$
CREATE PROCEDURE artistas_getListAnimales()
COMMENT 'Devuelve el nombre, apellidos y nif de los artistas junto con el nombre y peso de los animales que atienden'
BEGIN
    SELECT nif, apellidos, ARTISTAS.nombre AS nombreArtista, ANIMALES.nombre AS nombreAnimal, peso
    FROM ARTISTAS
    INNER JOIN ANIMALES_ARTISTAS ON (ANIMALES_ARTISTAS.nif_artista = ARTISTAS.nif)
    INNER JOIN ANIMALES ON (ANIMALES_ARTISTAS.nombre_animal = ANIMALES.nombre)
    ORDER BY nif, nombreAnimal;
END$$
DELIMITER ;
```

### **Exercici 3**

Crea un procediment de nom `atraccions_getListConAntiguedad5()` que retorne les dades de les atraccions que hagen començat fa 5 anys respecte a la data actual. Hauràs de fer ús d'alguna de les **funcions Time**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_getListConAntiguedad5;
DELIMITER $$
CREATE PROCEDURE atracciones_getListConAntiguedad5()
COMMENT 'Devuelve todos los datos de las atracciones que comenzaron hace 5 años con respecto a la fecha actual'
BEGIN
    SELECT *
    FROM ATRACCIONES
    WHERE fecha_inicio BETWEEN DATE_SUB(curdate(), INTERVAL 5 YEAR) AND curdate()
    ORDER BY nombre;
END$$
DELIMITER ;
```

### **Exercici 4**

Crea un procediment de nom `animals_Leo_getPista()` que mostre les dades de la pista on treballa l'animal de nom `'Leo'`. Fer-ho emprant una **variable local** que guarde el nom de la pista i després consultar les dades de la pista utilitzant aquesta variable local.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS animales_Leo_getPista;
DELIMITER $$
CREATE PROCEDURE animales_Leo_getPista()
COMMENT 'Devuelve los datos de la pista donde trabaja el animal de nombre Leo'
BEGIN
    DECLARE v_nombrePista VARCHAR(50) DEFAULT ''; -- El tipo y tamaño debe de coincidir con el declarado en la tabla.

    SELECT nombre_pista INTO v_nombrePista
    FROM ANIMALES WHERE nombre = 'Leo';

    SELECT * -- Devuelve una única fila. No hace falta order by
    FROM PISTAS
    WHERE nombre = v_nombrePista;
END$$
DELIMITER ;
```

### **Exercici 5**

Crea un procediment de nom `atraccions_getUltima()` que obtenga les dades de la última atracció celebrada (taula `ATRACCION_DIA`), emprant variables locals. Tingues en compte limitar amb `LIMIT` el número de files que retorne una consulta si no saps amb certeza que vaja a retornar una única fila i guardarás les dades en una variable.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_getUltima;
DELIMITER $$
CREATE PROCEDURE atracciones_getUltima()
COMMENT 'Devuelve los datos de la última atracción celebrada'
BEGIN
    DECLARE v_nombreAtraccion VARCHAR(50) DEFAULT '';

    SELECT nombre_atraccion INTO v_nombreAtraccion
    FROM ATRACCION_DIA
    ORDER BY fecha DESC LIMIT 1;

    SELECT *
    FROM ATRACCIONES
    WHERE nombre = v_nombreAtraccion;
END$$
DELIMITER ;
```

### **Exercici 6**

Crea un procediment de nom `atraccions_getArtistaUltima()` que obtenga les dades de l'atracció i de l'artista que treballa en aquesta atracció, de la qual data d'inici ha començat més tarde. Empra **dos variables**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_getArtistaUltima;
DELIMITER $$
CREATE PROCEDURE atracciones_getArtistaUltima()
COMMENT 'Devuelve los datos de la atracción y del artista que trabaja en dicha atracción, cuya fecha de inicio es más tardía'
BEGIN
    DECLARE v_nombreAtraccion VARCHAR(50) DEFAULT '';
    DECLARE v_nifArtista CHAR(9);

    SELECT nombre_atraccion, nif_artista INTO v_nombreAtraccion, v_nifArtista
    FROM ATRACCIONES_ARTISTAS
    ORDER BY fecha_inicio DESC LIMIT 1;

    SELECT *
    FROM ATRACCIONES, ARTISTAS
    WHERE ATRACCIONES.nombre = v_nombreAtraccion
      AND ARTISTAS.nif = v_nifArtista;
END$$
DELIMITER ;
```

## **Paràmetres**

Cada un de les dades que enviem o ens retorna un procediment emmagatzemat es denomina **paràmetre**:

- **Paràmetres d'entrada (`IN`)**: variables del qual valor s'utilitza dins del procediment. És el tipus per defecte.

- **Paràmetres d'eixida (`OUT`)**: paràmetres utilitzats pel procediment per a *informar* a qui anomena, asignándoles un valor dins del procediment que serà utilitzat posteriorment per qui va realitzar el llamament.

- **Paràmetres d'entrada/eixida (`INOUT`)**: poden portar informació al procediment, ser modificats dins d'ell i ser utilitzats per qui va realitzar l'anomenada.

### **Definició i invocació**

> **📌 Sintaxi i invocació**
> 

```sql
DELIMITER $$
CREATE PROCEDURE nombre_proc (IN nombre_parametro tipo_dato)
BEGIN
END $$
DELIMITER ;

-- Invocación con un valor literal
CALL nombre_proc(100);

-- Invocación con una variable de sesión
SET @dato = 100;
CALL nombre_proc(@dato);
```

> **📌 Tipus de dades dels paràmetres**
> 

> Els paràmetres han de tindre el **mateix tipus de dada i mida** que el definit a nivell de columnes en les taules. No fa falta posar un `int`, podem usar `tinyint`, `smallint`, `char(9)`, `varchar(50)`, ...

### **Exercicis resolts amb paràmetres**

#### **Exercici 1**

Crea un procediment de nom `artistas_getAnimalesPorNif` que retorne als animals que cuida un artista. Portarà com paràmetre el **nif d'artista**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_getAnimalesPorNif;
DELIMITER $$
CREATE PROCEDURE artistas_getAnimalesPorNif(p_nif CHAR(9))
COMMENT 'Devuelve los animales que cuida un artista. Llevará como parámetro el nif de artista.'
BEGIN
    SELECT DISTINCT ANIMALES.*
    FROM ANIMALES
    INNER JOIN ANIMALES_ARTISTAS ON (ANIMALES.nombre = ANIMALES_ARTISTAS.nombre_animal)
    WHERE ANIMALES_ARTISTAS.nif_artista = p_nif
    ORDER BY nombre;
END$$
DELIMITER ;

CALL artistas_getAnimalesPorNif('11111111A');
CALL artistas_getAnimalesPorNif('22222222B');
SET @nifBuscar = '44444444D';
CALL artistas_getAnimalesPorNif(@nifBuscar);
```

#### **Exercici 2**

Crea un procediment de nom `artistas_getAnimalesPorNombreApel` que retorne als animals que cuida un artista. Portarà com paràmetre el **nom i cognoms** de l'artista. Suposem que el nom i cognoms conforman una clau alternativa.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_getAnimalesPorNombreApel;
DELIMITER $$
CREATE PROCEDURE artistas_getAnimalesPorNombreApel(p_nombre VARCHAR(45), p_apellidos VARCHAR(100))
COMMENT 'Devuelve los animales que cuida un artista. Llevará como parámetro el nombre y apellidos del artista'
BEGIN
    DECLARE v_nifArtista CHAR(9); -- Si no ponemos valor por defecto vale NULL

    SELECT nif INTO v_nifArtista
    FROM ARTISTAS
    WHERE apellidos = p_apellidos
      AND nombre = p_nombre; -- LIMIT 1: habría que ponerlo para poder emplear INTO en el caso de que hubiera varias personas con el mismo nombre y apellidos

    SELECT DISTINCT ANIMALES.*
    FROM ANIMALES INNER JOIN ANIMALES_ARTISTAS ON (ANIMALES.nombre = ANIMALES_ARTISTAS.nombre_animal)
    WHERE ANIMALES_ARTISTAS.nif_artista = v_nifArtista
    ORDER BY nombre;
END$$
DELIMITER ;

CALL artistas_getAnimalesPorNombreApel('Luis', 'Sanchez');
```

#### **Exercici 3**

Crea un procediment de nom `atraccions_getListConAntiguedad` que retorne les dades de les atraccions que hagen començat fa un **número d'anys** respecte a la data actual.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_getListConAntiguedad;
DELIMITER $$
CREATE PROCEDURE atracciones_getListConAntiguedad(p_antiguedad TINYINT) -- Fijarse en el tipo. No hace falta poner un int.
COMMENT 'Devuelve los datos de las atracciones que hayan comenzado hace un número de años con respecto a la fecha actual.'
BEGIN
    SELECT *
    FROM ATRACCIONES
    WHERE fecha_inicio BETWEEN DATE_SUB(curdate(), INTERVAL p_antiguedad YEAR) AND curdate()
    ORDER BY nombre;
END$$
DELIMITER ;

CALL atracciones_getListConAntiguedad(4);
CALL atracciones_getListConAntiguedad(20);
```

#### **Exercici 4**

Crea un procediment de nom `artistas_getListMasAnimalesCuida` que retorne les dades del/els artista/s que cuidan a **més animals dels indicats** (paràmetre que es li envia).

> **📌 Pista**
> 

> Com la consulta pot retornar més d'un artista **no podrem fer ús de `INTO`**.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS artistas_getListMasAnimalesCuida;
DELIMITER $$
CREATE PROCEDURE artistas_getListMasAnimalesCuida(p_numAnimales TINYINT)
COMMENT 'Devuelve los datos del/os artista/s que cuidan a más animales de los indicados.'
BEGIN
    SELECT *
    FROM ARTISTAS
    WHERE nif IN (SELECT nif_artista
                  FROM ANIMALES_ARTISTAS
                  GROUP BY nif_artista
                  HAVING COUNT(*) > p_numAnimales)
    ORDER BY nif;
END$$
DELIMITER ;

CALL artistas_getListMasAnimalesCuida(2);
```

#### **Exercici 6**

Crea un procediment de nom `pistas_add` que afegisca una nova pista.

> **📌 Pistes**
> 

> - Encara no hem vist la validació de dades que hauria de donar-se en el pas de paràmetres (podríem tindre condicions `IF` en el que es comprove si l'aforament és major que zero).

> - Es pot fer ús de la funció `ROW_COUNT()` per a saber quantes files van ser afegides, borrades o modificades.

> - **Important**: els paràmetres han de tindre el **mateix tipus de dada i mida** que el definit a nivell de columnes en la taula `PISTAS`.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS pistas_add;
DELIMITER $$
CREATE PROCEDURE pistas_add(p_nombre VARCHAR(50), p_aforo SMALLINT)
COMMENT 'Añade una nueva pista'
BEGIN
    INSERT INTO PISTAS (nombre, aforo) -- Mejor poner las columnas, ya que si modificamos la estructura de la tabla, la orden sigue funcionando
    VALUES (p_nombre, p_aforo);
    SELECT ROW_COUNT();
END$$
DELIMITER ;

CALL pistas_add('El gran misil', 134);
```

#### **Exercici 7**

Crea un procediment de nom `atraccions_update` que permeta modificar les dades d'una atracció (no es permet actualitzar la seua clau primària).

> **📌 Pistes**
> 

> - Hauràs de guardar les **guanys i la data d'inici** que té per a poder enviar aquestes dades al procediment.

> - Comprova com a l'anomenar al mètode amb una atracció que no existeix, `ROW_COUNT()` retornarà 0.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP PROCEDURE IF EXISTS atracciones_update;
DELIMITER $$
CREATE PROCEDURE atracciones_update(p_nombre VARCHAR(50), p_fecha DATE, p_ganancias DECIMAL(8,2))
COMMENT 'Modifica una atracción'
BEGIN
    UPDATE ATRACCIONES SET fecha_inicio = p_fecha, ganancias = p_ganancias
    WHERE nombre = p_nombre;
    SELECT ROW_COUNT();
END$$
DELIMITER ;

SELECT ganancias, fecha_inicio INTO @ganancias, @fecha_inicio
FROM ATRACCIONES
WHERE nombre = 'El gran felino';

CALL atracciones_update('El gran felino', DATE_ADD(@fecha_inicio, INTERVAL 1 DAY), @ganancias);
CALL atracciones_update('El gran felino_no_existe', '1890-01-03', 1000.34);
```

#### **Exercici 8**

Crea un procediment de nom `pistas_delete` que esborre una pista pel seu nom. Fes que esborre sobre la base del patró `nombre%` (emprant el `LIKE`).

> **📌 Pista**
> 

> Empra la funció **`CONCAT`** per al `LIKE`.

> **📌 Solució**
> 

```sql
DELIMITER $$
CREATE PROCEDURE pistas_delete(IN nombre_inicio VARCHAR(100))
COMMENT 'Elimina la pista'
BEGIN
    DELETE FROM pistas
    WHERE nombre LIKE CONCAT(nombre_inicio, '%');
END $$
DELIMITER ;

CALL pistas_delete('El gran misil');
```

> **📌 Resum**
> 

> - Un **procediment emmagatzemat** associa un nom a un conjunt d'instruccions SQL que s'executa amb `CALL`.

> - Es crea amb `CREATE PROCEDURE` i, si té diverses instruccions, aquestes van entre `BEGIN` i `END` (canviant el delimitador a `$$`).

> - Pot tindre **paràmetres** d'entrada (`IN`), eixida (`OUT`) o entrada/eixida (`INOUT`).

> - Els paràmetres han de coincidir en **tipus i mida** amb les columnes de les taules.

> - La funció `ROW_COUNT()` informa de quantes files es vieron afectades per la última operació.
