Una **funció** el conforman un bloc d'instruccions que s'executen i que **retornen un dada** el qual és *recogido* pel que realitza l'anomenada a la funció.

> **📌 Funció vs. procediment**
> 

> Podríem veure una funció com un **procediment amb un paràmetre de tipus `OUT`**. Respecte als procediments, la funció es diferència (a majors del fet de retornar un valor) en que es pot usar **dins d'instruccions SQL**, com per exemple:

```sql
SELECT funcion(), col1 FROM Tabla;
SELECT * FROM Tabla WHERE col = funcion();
```

En aquests casos, la funció es va a **anomenar per cada fila** de la taula que complisca els criteris de selecció indicats en la consulta `SELECT`.

- El conjunt d'instruccions van en el *routine_body*. Si el formen diverses (el normal) han d'anar entre les etiquetes `BEGIN` i `END`. Fijar-se que el `END` ha de portar **punt i coma** si a continuació li segueixen noves instruccions.

- Els tipus de dades que va a poder retornar una funció són: **STRING, INTEGER, REAL o DECIMAL**.

- Si la funció retorna un número de tipus `DECIMAL`, és com si devolviera un `String`.

## **Crear una funció**

> **📌 Sintaxi**
> 

```sql
CREATE
[DEFINER = user]
FUNCTION [IF NOT EXISTS] sp_name ([func_parameter[,...]])
RETURNS type
[characteristic ...] routine_body

func_parameter:
    param_name type
```

> **📌 Exemple**
> 

```sql
DELIMITER $$
CREATE FUNCTION ejemploFuncion() RETURNS VARCHAR(20)
BEGIN
    RETURN 'Ejemplo';
END $$
DELIMITER ;

-- Ejemplos de llamada
SELECT ejemploFuncion();   -- Mostrará la cadena 'Ejemplo'
SET @valorDevuelto = ejemploFuncion();
```

- En la definició de la funció indiquem el **tipus de dada que va a retornar** (STRING | INTEGER | REAL | DECIMAL).

- En qualsevol part de la funció fem ús de la instrucció **`RETURN`** passant un dada que ha de ser del mateix tipus que l'indicat en la definició.

### **Ús dins de consultes SQL**

Una de les avantatges que tenen les funcions respecte als procediments és la possibilitat de **emplear-les dins de consultes SQL** i emprar columnes de la consulta com paràmetres d'entrada per a la funció.

Per exemple, si tinc definida una funció que retorna el nom d'un empleat en base al seu id, de la forma `employees_getName(id INTEGER)`, puc llamar-la de la forma:

```sql
SELECT employees_getName(emp_no)
FROM salaries;
```

La funció té com paràmetre un `id` el qual s'obté de **cada fila** de la consulta `SELECT`: per cada fila d'aquesta consulta, s'executarà la funció enviant com paràmetre el `id` de la fila.

## **Característiques de les funcions**

Després de la definició del tipus de dada que retornarà la funció amb la paraula reservada `RETURNS`, hem d'indicar les **característiques de la funció**. Les opcions disponibles són les següents:

| Característica | Descripció |
| --- | --- |
| **`DETERMINISTIC`** | La funció sempre retorna el mateix resultat quan s'utilitzen els mateixos paràmetres d'entrada. |
| **`NOT DETERMINISTIC`** | La funció no sempre retorna el mateix resultat encara que es utilicen els mateixos paràmetres. Opció per defecte. |
| **`CONTAINS SQL`** | La funció conté sentències SQL, però no conté sentències de manipulació de dades (Ej: `SET @x = 1`, `SELECT NOW()`). |
| **`NO SQL`** | La funció no conté sentències SQL. |
| **`READS SQL DATA`** | La funció no modifica les dades i conté sentències de lectura, com `SELECT`. |
| **`MODIFIES SQL DATA`** | La funció sí modifica les dades i conté sentències com `INSERT`, `UPDATE` o `DELETE`. |

> **📌 Restricció de creació**
> 

> Per a poder crear una funció en MySQL és necessari indicar **almenys una** d'aquestes tres característiques:

> - `DETERMINISTIC`

> - `NO SQL`

> - `READS SQL DATA`

> Si no es indica almenys una d'aquestes característiques obtindrem el següent missatge d'error:

```sql
ERROR 1418 (HY000): This function has none of DETERMINISTIC, NO SQL, or
READS SQL DATA in its declaration and binary logging is enabled (you *might*
want to use the less safe log_bin_trust_function_creators variable)
```

És possible configurar la variable global `log_bin_trust_function_creators` a `1` per a eliminar la restricció (requereix privilegi `SUPER`):

```sql
SET GLOBAL log_bin_trust_function_creators = 1;
```

## **Exercicis resolts**

### **Exercici 1**

Crea una funció de nom `utilidades_getMesEnLetra` a la que es li passe un **número** i retorne el **nom del mes**. En cas que el número no es corresponda amb cap mes, ha de retornar `NULL`.

> **📌 Notes**
> 

> - Fijar-se que aquesta funció és **determinista**.

> - MySQL ja disposa d'una funció similar: `MONTHNAME()`, que rep una data i retorna el mes en forma de cadena.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP FUNCTION IF EXISTS utilidades_getMesEnLetra;
DELIMITER $$
CREATE FUNCTION utilidades_getMesEnLetra (p_mes TINYINT) RETURNS VARCHAR(10) DETERMINISTIC NO SQL
COMMENT 'Devuelve el mes en letra que se corresponde con el número de mes.'
BEGIN
    DECLARE v_mesEnLetra VARCHAR(10); -- Valor por defecto NULL

    CASE p_mes
        WHEN 1 THEN SET v_mesEnLetra = 'ENERO';
        WHEN 2 THEN SET v_mesEnLetra = 'FEBRERO';
        WHEN 3 THEN SET v_mesEnLetra = 'MARZO';
        WHEN 4 THEN SET v_mesEnLetra = 'ABRIL';
        WHEN 5 THEN SET v_mesEnLetra = 'MAYO';
        WHEN 6 THEN SET v_mesEnLetra = 'JUNIO';
        WHEN 7 THEN SET v_mesEnLetra = 'JULIO';
        WHEN 8 THEN SET v_mesEnLetra = 'AGOSTO';
        WHEN 9 THEN SET v_mesEnLetra = 'SEPTIEMBRE';
        WHEN 10 THEN SET v_mesEnLetra = 'OCTUBRE';
        WHEN 11 THEN SET v_mesEnLetra = 'NOVIEMBRE';
        WHEN 12 THEN SET v_mesEnLetra = 'DICIEMBRE';
        ELSE SET v_mesEnLetra = NULL;
    END CASE;

    RETURN v_mesEnLetra;
END $$
DELIMITER ;
```

Exemples d'ús:

> **📌 Exemples d'ús**
> 

```sql
-- Llama a la función directamente y guarda el resultado en una variable de sesión.
SET @mes = utilidades_getMesEnLetra(10);
SELECT @mes;

-- Muestra los meses en letra en los que se celebró la atracción 'El gran felino'.
SELECT DISTINCT MONTH(fecha) AS mesNumero, utilidades_getMesEnLetra(MONTH(fecha)) AS mesCadena
FROM ATRACCION_DIA
WHERE nombre_atraccion = 'El gran felino'
ORDER BY mesNumero;

-- Muestra las atracciones que se celebraron en ABRIL (busca por la cadena ABRIL).
SELECT *
FROM ATRACCION_DIA
WHERE utilidades_getMesEnLetra(MONTH(fecha)) = 'ABRIL' COLLATE 'utf8mb4_spanish2_ci'
ORDER BY nombre_atraccion, fecha;
```

```sql
        WHEN 'MARZO' THEN SET v_mesEnNumero = 3;
        WHEN 'ABRIL' THEN SET v_mesEnNumero = 4;
        WHEN 'MAYO' THEN SET v_mesEnNumero = 5;
        WHEN 'JUNIO' THEN SET v_mesEnNumero = 6;
        WHEN 'JULIO' THEN SET v_mesEnNumero = 7;
        WHEN 'AGOSTO' THEN SET v_mesEnNumero = 8;
        WHEN 'SEPTIEMBRE' THEN SET v_mesEnNumero = 9;
        WHEN 'OCTUBRE' THEN SET v_mesEnNumero = 10;
        WHEN 'NOVIEMBRE' THEN SET v_mesEnNumero = 11;
        WHEN 'DICIEMBRE' THEN SET v_mesEnNumero = 12;
    END CASE;

    RETURN v_mesEnNumero;
END $$
DELIMITER ;
```

### **Exercici 3**

Crea una funció de nom `animales_getEstadoPorAnhos` que retorne la cadena:

- Si `tipo = León`:

  - `anhos < 2`: `'JOVEN'`

  - `anhos >= 2` i `<= 5`: `'MADURO'`

  - `anhos > 5`: `'VIEJO'`

- Qualsevol un altre tipus:

  - `anhos < 1`: `'JOVEN'`

  - `anhos >= 1` i `<= 3`: `'MADURO'`

  - `anhos > 3`: `'VIEJO'`

Anomena a la funció per a mostrar l'estat per anys de cada un dels animals del CIRC.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP FUNCTION IF EXISTS animales_getEstadoPorAnhos;
DELIMITER $$
CREATE FUNCTION animales_getEstadoPorAnhos (p_tipo VARCHAR(9), p_anhos TINYINT) -- El tipo se corresponde con el de la tabla
RETURNS CHAR(6) DETERMINISTIC NO SQL
COMMENT 'Devuelve una cadena indicativa de la edad en función de la edad y tipo de animal.'
BEGIN
    DECLARE v_cadena CHAR(6) DEFAULT '';

    IF (p_tipo = 'León') THEN
        CASE
            WHEN p_anhos < 2 THEN SET v_cadena = 'JOVEN';
            WHEN p_anhos >= 2 AND p_anhos <= 5 THEN SET v_cadena = 'MADURO';
            WHEN p_anhos > 5 THEN SET v_cadena = 'VIEJO';
        END CASE;
    ELSE
        CASE
            WHEN p_anhos < 1 THEN SET v_cadena = 'JOVEN';
            WHEN p_anhos >= 1 AND p_anhos <= 3 THEN SET v_cadena = 'MADURO';
            WHEN p_anhos > 3 THEN SET v_cadena = 'VIEJO';
        END CASE;
    END IF;

    RETURN v_cadena;
END $$
DELIMITER ;

-- Ejemplos de uso
SELECT *, animales_getEstadoPorAnhos(tipo, anhos) AS estado
FROM ANIMALES
ORDER BY nombre;
```

### **Exercici 4**

Crea una funció de nom `pistas_getDiferenciaAforo` a la que es li passe el **nou aforament** d'una pista i retorne la diferència entre l'aforament nou i l'aforament anterior.

- Si la diferència `< 100`: retornar `'PEQUEÑA menor que 100'`.

- Si la diferència està entre 100 i 500: retornar `'REGULAR entre 100 y 500'`.

- Si la diferència `> 500`: retornar `'ABISMAL mayor que 500'`.

- Si la pista no existeix: retornar `NULL`.

> **📌 Pistes**
> 

> - Per exemple: `PISTA1, 150` => Si la pista té actualment un aforament de 100, ha de retornar `150 - 100 = 50` => `PEQUEÑA menor que 100`.

> - Acordaos d'afegir els **modificadors adequats** a la creació de la funció.

> **📌 Solució**
> 

```sql
USE CIRCO;
DROP FUNCTION IF EXISTS pistas_getDiferenciaAforo;
DELIMITER $$
CREATE FUNCTION pistas_getDiferenciaAforo (p_nombrePista VARCHAR(50), p_nuevoAforo INT)
RETURNS VARCHAR(30) READS SQL DATA
COMMENT 'Devuelve una cadena con la diferencia entre el aforo nuevo y el aforo actual de la pista.'
BEGIN
    DECLARE v_aforoAnterior INT;
    DECLARE v_diferencia INT;

    SELECT aforo INTO v_aforoAnterior
    FROM PISTAS
    WHERE nombre = p_nombrePista;

    IF v_aforoAnterior IS NULL THEN
        RETURN NULL;
    END IF;

    SET v_diferencia = p_nuevoAforo - v_aforoAnterior;

    IF v_diferencia < 100 THEN
        RETURN 'PEQUEÑA menor que 100';
    ELSEIF v_diferencia BETWEEN 100 AND 500 THEN
        RETURN 'REGULAR entre 100 y 500';
    ELSE
        RETURN 'ABISMAL mayor que 500';
    END IF;
END $$
DELIMITER ;

-- Muestra los datos de todas las pistas junto con la diferencia del aforo (aforo propuesto 600).
SELECT nombre, pistas_getDiferenciaAforo(nombre, 600) AS diferencia_aforo
FROM PISTAS;

-- Muestra las pistas que tengan una diferencia ABISMAL (aforo propuesto 1000).
SELECT nombre
FROM PISTAS
WHERE INSTR(pistas_getDiferenciaAforo(nombre, 1000), 'ABISMAL') > 0;
```

> **📌 Resum**
> 

> - Una **funció** retorna un valor (`RETURN`) i pot usar-se **dins de consultes SQL**.

> - Es declara amb `CREATE FUNCTION ... RETURNS tipo`.

> - Cal indicar una característica (`DETERMINISTIC`, `NO SQL` o `READS SQL DATA`).

> - Es pot invocar directament o com part d'un `SELECT`, ejecutándose per cada fila.
