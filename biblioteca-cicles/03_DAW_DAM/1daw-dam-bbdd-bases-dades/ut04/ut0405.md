# **DCL (Data Control Language)**

El **Llenguatge de Control de Dades (Data Control Language - DCL)** és el conjunt d'instruccions SQL encarregat de gestionar la **seguretat** d'una base de dades.

Mentre que el **DDL** defineix l'estructura i el **DML** manipula les dades, el **DCL** controla **qui pot accedir a la informació i què operacions pot realitzar**.

Gràcies al DCL és possible:

- Crear usuaris.

- Modificar usuaris.

- Eliminar usuaris.

- Assignar permisos.

- Revocar permisos.

- Gestionar la seguretat de la base de dades.

> **📌 Objectiu del DCL**
> 

> El DCL garanteix que **cada usuari només puga realitzar les operacions per a les que ha sigut autoritzat**, protegent la integritat i confidencialitat de la informació.

## **Usuaris**

Abans d'assignar permisos és necessari crear els usuaris que accederán al sistema.

Cada usuari disposa de:

- Un nom.

- Un equip (host) des del que pot connectar-se.

- Una contrasenya.

- Un conjunt de privilegis.

En MySQL un usuari s'identifica mitjançant:

```sql
usuario@host
```

Per exemple:

```sql
profesor@localhost
```

o

```sql
administrador@192.168.1.10
```

### **CREATE USER**

La instrucció `CREATE USER` crea un nou usuari.

> **📌 Sintaxi bàsica**
> 

```sql
CREATE USER
'nombre_usuario'@'localhost'
IDENTIFIED BY 'contraseña';
```

> **📌 Exemple: crear l'usuari 'professor'**
> 

```sql
CREATE USER
'profesor'@'localhost'
IDENTIFIED BY 'abc123';
```

L'usuari podrà connectar-se a MySQL utilitzant eixes credencials.

> **📌 Usuaris i permisos**
> 

> Crear un usuari **no implica que tinga permisos sobre cap base de dades**.

### **ALTER USER**

Permet modificar les característiques d'un usuari existent.

Normalment s'utilitza per a canviar la contrasenya.

> **📌 ALTER USER**
> 

```sql
ALTER USER
'profesor'@'localhost'
IDENTIFIED BY 'NuevaContraseña';
```

### **DROP USER**

Elimina completament un usuari.

> **📌 DROP USER**
> 

```sql
DROP USER
'profesor'@'localhost';
```

Després d'executar aquesta instrucció l'usuari ja no podrà accedir al servidor.

## **Privilegis**

Els privilegis determinan les operacions que un usuari pot realitzar.

Existeixen privilegis per a:

- Consultar dades.

- Inserir registres.

- Modificar informació.

- Eliminar registres.

- Crear taules.

- Modificar taules.

- Crear usuaris.

- Administrar el servidor.

Els permisos es gestionen mitjançant dos instruccions:

- `GRANT`

- `REVOKE`

> **📌 Efecte dels canvis de permisos**
> 

> - Els canvis en els privilegis de **taula i columna** tenen efecte inmediatament, encara que l'usuari ja es trobe connectat.

> - Els canvis a nivell de **base de dades** no tenen efecte fins a que l'usuari executa `USE nombre_db;`.

> - Els canvis en els privilegis **globals** no tenen efecte fins a que el client torna a connectar-se.

### **GRANT**

La instrucció `GRANT` permet conceder permisos a usuaris o rols.

> **📌 Sintaxi general**
> 

```sql
GRANT
privilegios
ON objeto
TO usuario;
```

### **Exemple bàsic**

Conceder tots els permisos sobre una base de dades.

> **📌 GRANT ALL**
> 

```sql
GRANT ALL
ON instituto.*
TO
'profesor'@'localhost';
```

### **Permís de consulta**

> **📌 GRANT SELECT**
> 

```sql
GRANT SELECT
ON instituto.*
TO
'profesor'@'localhost';
```

L'usuari únicament podrà consultar informació.

### **Diversos permisos simultàniament**

És possible conceder diversos permisos en una sola instrucció.

> **📌 GRANT amb diversos permisos**
> 

```sql
GRANT
SELECT,
INSERT,
UPDATE
ON instituto.*
TO
'profesor'@'localhost';
```

### **SHOW GRANTS**

Permet consultar els permisos que posseeix un usuari.

Consultar els permisos de l'usuari actual:

> **📌 SHOW GRANTS**
> 

```sql
SHOW GRANTS;
```

Consultar un altre usuari:

> **📌 SHOW GRANTS FOR**
> 

```sql
SHOW GRANTS
FOR
'profesor'@'localhost';
```

Consultar l'usuari connectat:

> **📌 SHOW GRANTS FOR CURRENT_USER**
> 

```sql
SHOW GRANTS
FOR CURRENT_USER;
```

> **📌 SHOW GRANTS**
> 

> Tot usuari té permís per a consultar els seus propis privilegis. Per a consultar els privilegis d'un altre usuari és necessari tindre permís `SELECT` sobre la base de dades `mysql`.

### **Consultar els usuaris existents**

També és possible consultar els usuaris emmagatzemats per MySQL.

> **📌 Consultar usuaris**
> 

```sql
SELECT *
FROM mysql.user;
```

> **📌 Accés a mysql.user**
> 

> Per a consultar aquesta informació és necessari disposar de privilegis suficientes.

## **Privilegis globals**

Els privilegis globals afecten a **tot el servidor MySQL**.

Per a això s'utilitza:

```sql
ON *.*
```

Exemple:

> **📌 GRANT a nivell global**
> 

```sql
GRANT SELECT
ON *.*
TO
'profesor'@'localhost';
```

Aquest usuari podrà consultar qualsevol taula de qualsevol base de dades.

> **📌 Diversos permisos globals**
> 

```sql
GRANT SELECT, UPDATE
ON *.*
TO
'profesor'@'localhost';
```

> **📌 Efecte dels permisos globals**
> 

> Si l'usuari ja està connectat quan es modifica un permís global, el canvi **no s'aplicarà** fins a que tancament la sessió i torne a connectar-se.

### **Privilegis globals més habituals**

| Privilegi | Descripció |
| --- | --- |
| `SELECT` | Consultar dades |
| `INSERT` | Inserir registres |
| `UPDATE` | Modificar registres |
| `DELETE` | Eliminar registres |
| `CREATE USER` | Crear usuaris |
| `SHOW DATABASES` | Mostrar les bases de dades |
| `EXECUTE` | Executar procediments emmagatzemats |
| `SHUTDOWN` | Apagar el servidor |
| `SUPER` | Operacions administrativas |
| `USAGE` | Permet connectar-se al servidor sense altres permisos |

> **📌 El privilegi USAGE**
> 

> Quan es crea un usuari nou, l'únic privilegi que posseeix és **USAGE**, que únicament permet connectar-se al servidor.

## **Privilegis sobre una base de dades**

És el nivell més utilitzat.

Es conceden permisos únicament sobre una base de dades concreta.

> **📌 GRANT ALL sobre una base de dades**
> 

```sql
GRANT ALL
ON instituto.*
TO
'profesor'@'localhost';
```

### **Exemple**

Permetre consultar i inserir informació.

> **📌 GRANT SELECT, INSERT sobre una base de dades**
> 

```sql
GRANT
SELECT,
INSERT
ON instituto.*
TO
'profesor'@'localhost';
```

### **Permisos disponibles**

| Permís | Funció |
| --- | --- |
| SELECT | Consultar dades |
| INSERT | Inserir registres |
| UPDATE | Modificar registres |
| DELETE | Eliminar registres |
| CREATE | Crear taules |
| DROP | Eliminar taules |
| ALTER | Modificar taules |
| REFERENCES | Crear claus foranes |
| EVENT | Gestionar esdeveniments |
| LOCK TABLES | Bloquejar taules |

> **📌 Permisos CREATE, ALTER i DROP**
> 

> - `CREATE` permet crear taules.

> - `DROP` elimina taules.

> - `ALTER` modifica una taula (requereix el privilegi `CREATE`).

## **Privilegis sobre procediments**

També poden concederse permisos relacionats amb procediments emmagatzemats i funcions.

> **📌 GRANT sobre rutinas**
> 

```sql
GRANT
CREATE ROUTINE,
ALTER ROUTINE
ON instituto.*
TO
'profesor'@'localhost';
```

> **📌 Rutinas**
> 

> No existeix el permís `DROP ROUTINE`. Si un usuari posseeix el permís `ALTER ROUTINE` pot modificar o esborrar una rutina.

## **WITH GRANT OPTION**

Existeix un permís especial denominat **WITH GRANT OPTION**.

Permet que l'usuari puga conceder a altres usuaris els mateixos permisos que ha rebut.

> **📌 Exemple amb WITH GRANT OPTION**
> 

```sql
GRANT
SELECT,
INSERT
ON instituto.*
TO
'profesor'@'localhost'
WITH GRANT OPTION;
```

## **Permisos sobre taules**

En ocasions únicament interessa permetre l'accés a una taula concreta.

> **📌 GRANT sobre una taula**
> 

```sql
GRANT
SELECT,
INSERT
ON instituto.alumno
TO
'profesor'@'localhost';
```

En aquest cas l'usuari únicament podrà treballar amb la taula `alumno`.

> **📌 Privilegis a nivell de taula**
> 

> Els privilegis que manejan l'estructura de la taula són `CREATE`, `ALTER` i `DROP`. Els que manejan les dades de la taula són `DELETE`, `SELECT`, `UPDATE` e `INSERT`. També existeixen privilegis per a vistes (`CREATE VIEW`, `SHOW VIEW`, `DROP VIEW`), índexs (`INDEX`) i disparadors (`TRIGGER`).

## **Permisos sobre columnes**

MySQL també permet conceder permisos únicament sobre determinades columnes.

> **📌 GRANT sobre columnes**
> 

```sql
GRANT
SELECT(nombre),
UPDATE(nombre)
ON instituto.alumno
TO
'profesor'@'localhost';
```

L'usuari únicament podrà consultar i modificar la columna `nombre`.

## **REVOKE**

La instrucció `REVOKE` elimina permisos prèviament concedits.

El seu sintaxi és molt similar a `GRANT`.

> **📌 Sintaxi general**
> 

```sql
REVOKE
privilegios
ON objeto
FROM usuario;
```

### **Exemple**

Eliminar el permís d'inserció.

> **📌 REVOKE INSERT**
> 

```sql
REVOKE
INSERT
ON instituto.*
FROM
'profesor'@'localhost';
```

### **Eliminar tots els privilegis**

També és possible eliminar tots els permisos concedits.

> **📌 REVOKE ALL PRIVILEGES**
> 

```sql
REVOKE
ALL PRIVILEGES,
GRANT OPTION
FROM
'profesor'@'localhost';
```

Després d'executar aquesta instrucció l'usuari únicament conservará el privilegi **USAGE**.

## **Bones pràctiques de seguretat**

> **📌 Recomendacions**
> 

> - Concede únicament els permisos estrictament necessaris.

> - Evita utilitzar l'usuari `root` per a aplicacions.

> - Assigna permisos sobre bases de dades concretes en lloc de privilegis globals.

> - Utilitza contrasenyes seguras.

> - Revisa periódicament els permisos dels usuaris.

> - Elimina els usuaris que ja no siguen necessaris.

## **Resum**

> **📌 Ideas clau**
> 

> - El **DCL** controla l'accés a la base de dades mitjançant usuaris i permisos.

> - `CREATE USER`, `ALTER USER` i `DROP USER` permeten gestionar usuaris.

> - `GRANT` concede privilegis i `REVOKE` els elimina.

> - Els permisos poden aplicar-se a nivell global, de base de dades, de taula o fins i tot de columna.

> - `SHOW GRANTS` permet consultar els privilegis assignats a un usuari.

> - És recomanable aplicar sempre el **principi del mínim privilegi**, concedent únicament els permisos necessaris per a realitzar cada tasca.
