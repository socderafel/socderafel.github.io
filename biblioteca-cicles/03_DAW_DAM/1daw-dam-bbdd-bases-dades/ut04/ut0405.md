El subllenguatge **DCL (Data Control Language)** permet administrar la seguretat de la base de dades. En qualsevol entorn de producció, aplicar el **principi de mínim privilegi** és imperatiu: cada usuari, servei o aplicació web ha de tindre estrictament els permisos indispensables per dur a terme la seua tasca, i cap més.

---

## 👤 Gestió d'Usuaris i Rols

### 1. Creació d'Usuaris
```sql
-- Creació d'un usuari amb contrasenya segura
CREATE USER botiga_app WITH PASSWORD 'ClauSegura_2026!';
```

### 2. Concepte de Rol (Role)
Un **rol** és un grup o perfil de privilegis. En lloc d'assignar permisos individualment a desenes d'empleats un a un, es crea un rol (per exemple, `rol_administratiu`), se li assignen els permisos necessaris, i després s'assigna el rol als usuaris concrets.
```sql
CREATE ROLE rol_consulta;
GRANT rol_consulta TO usuari_joan, usuari_maria;
```

---

## 🛡️ Les Sentències `GRANT` i `REVOKE`

### 1. Atorgar Permisos (`GRANT`)
La sintaxi general és:
```sql
GRANT llista_privilegis ON objecte TO usuari_o_rol [WITH GRANT OPTION];
```

*Exemples pràctics:*
```sql
-- Permís de només lectura sobre una taula
GRANT SELECT ON clients TO botiga_app;

-- Permisos d'escriptura limitats
GRANT SELECT, INSERT, UPDATE ON comandes TO botiga_app;

-- Permís total sobre tot un esquema
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO dba_junior;
```

### 2. Revocar Permisos (`REVOKE`)
```sql
-- Llevar el permís de modificació
REVOKE UPDATE ON comandes FROM botiga_app;

-- Revocar tots els permisos
REVOKE ALL PRIVILEGES ON clients FROM botiga_app;
```
