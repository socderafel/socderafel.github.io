Les **restriccions d'integritat (Constraints)** són regles aplicades directament a la definició DDL de les taules que l'SGBD comprova abans de permetre qualsevol operació d'inserció, actualització o esborrament.

---

## 🔒 Les Restriccions SQL Clau

### 1. `PRIMARY KEY` (Clau Primària)
- Identifica unívocament cada fila de la taula.
- Implica automàticament `UNIQUE` i `NOT NULL`.
- Crea de manera automàtica un índex B-Tree intern per accelerar cerques.
- Pot ser simple (una columna) o composta (diverses columnes):
  ```sql
  CONSTRAINT pk_matricula PRIMARY KEY (id_estudiant, id_curs)
  ```

### 2. `FOREIGN KEY` (Clau Forana)
- Imposa la regla d'integritat referencial respecte a una altra taula:
  ```sql
  CONSTRAINT fk_comanda_client FOREIGN KEY (id_client)
      REFERENCES clients(id_client)
      ON UPDATE CASCADE
      ON DELETE RESTRICT
  ```
- **Polítiques de referència:**
  - `ON DELETE RESTRICT`: Prohibeix esborrar el client si té comandes.
  - `ON DELETE CASCADE`: Esborra automàticament totes les comandes associades si s'esborra el client.
  - `ON DELETE SET NULL`: Posa a `NULL` el camp `id_client` a les comandes si el client s'esborra.

### 3. `NOT NULL`
- Assegura que la columna no puga contindre valors nuls (dades obligatòries).

### 4. `UNIQUE`
- Garanteix que cap fila tinga el mateix valor en eixa columna (ex: `DNI`, `email`), tot i que pot admetre valors `NULL` llevat que s'indique també `NOT NULL`.

### 5. `CHECK`
- Avalua una expressió lògica condicional abans d'acceptar la fila:
  ```sql
  CONSTRAINT ck_empleats_salari CHECK (salari >= 1080.00),
  CONSTRAINT ck_dates CHECK (data_fi >= data_inici)
  ```

### 6. `DEFAULT`
- Assigna un valor automàtic si la instrucció d'inserció no especifica cap dada per a eixe camp:
  ```sql
  actiu BOOLEAN DEFAULT TRUE,
  data_alta DATE DEFAULT CURRENT_DATE
  ```
