A més de les taules bàsiques, els SGBD ofereixen objectes d'alt nivell indispensables per millorar el rendiment, simplificar la programació i protegir la privacitat de les dades: els **índexs**, les **vistes** i les **seqüències**.

---

## ⚡ Els Índexs (Indexes)

Un **índex** és una estructura de dades auxiliar (normalment un arbre B-Tree equilibrat) que l'SGBD manté en disc per a localitzar registres a gran velocitat sense haver d'escanejar seqüencialment tota la taula (*Full Table Scan*).

```sql
-- Creació d'un índex B-Tree sobre la columna email
CREATE INDEX idx_usuaris_email ON usuaris(email);

-- Creació d'un índex compost per a cerques per cognoms i nom
CREATE INDEX idx_usuaris_cognoms_nom ON usuaris(cognoms, nom);

-- Eliminació d'un índex
DROP INDEX idx_usuaris_email;
```

> **Compromís de rendiment:** Els índexs acceleren radicalment les lectures (`SELECT`), però penalitzen les escriptures (`INSERT`, `UPDATE`, `DELETE`), ja que cada modificació de dades obliga l'SGBD a reordenar l'arbre de l'índex.

---

## 👁️ Les Vistes (Views)

Una **vista** és una taula virtual que no emmagatzema dades pròpies en disc, sinó que és el resultat d'una consulta SQL prèviament desada. Quan una aplicació consulta una vista, l'SGBD executa la consulta subjacent de manera transparent.

```sql
CREATE VIEW vista_clients_valencia AS
SELECT id_client, nom, email, telefon
FROM clients
WHERE ciutat = 'València';
```

### Avantatges de les Vistes
1. **Seguretat i privacitat:** Permet mostrar a certs departaments només les columnes no confidencials d'una taula (amagant per exemple sous o contrasenyes).
2. **Simplicitat:** Estalvia haver d'escriure `JOIN` complexes de 4 o 5 taules repetidament en el codi de l'aplicació.

---

## 🔢 Seqüències i Claus Auto-incrementables

Per a generar claus primàries numèriques seqüencials (1, 2, 3...):
- **A PostgreSQL:** S'utilitza el tipus pseudo-enter `SERIAL` / `BIGSERIAL`, o la sintaxi estàndard moderna SQL:
  ```sql
  id INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY
  ```
- **A MariaDB / MySQL:** S'utilitza l'atribut `AUTO_INCREMENT`:
  ```sql
  id INT AUTO_INCREMENT PRIMARY KEY
  ```
