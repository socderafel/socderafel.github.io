La sentència **`UPDATE`** permet alterar els valors d'un o més camps en files ja existents d'una taula. És una ordre d'alt impacte que ha d'utilitzar-se amb rigor, ja que un error en la condició de filtratge pot alterar de manera irreversible milers de registres.

---

## ✏️ Sintaxi General d'UPDATE

```sql
UPDATE nom_taula
SET columna1 = valor1,
    columna2 = valor2
WHERE condicio_filtre;
```

### 1. Actualització amb Condició Simple
```sql
UPDATE usuaris
SET saldo = 250.00,
    ultim_acces = CURRENT_TIMESTAMP
WHERE id_usuari = 42;
```

### 2. Actualització amb Expressió de Càlcul Relatiu
Permet aplicar increments o descomptes sense necessitat de consultar prèviament el valor antic en l'aplicació web:
```sql
-- Augmentar un 5% el preu de tots els llibres de la categoria Informàtica
UPDATE productes
SET preu = preu * 1.05
WHERE id_categoria = 3;
```

### 3. Actualització Basada en Subconsultes
Permet modificar un camp a partir del valor calculat d'una altra taula:
```sql
UPDATE departaments d
SET total_empleats = (
    SELECT COUNT(*) 
    FROM empleats e 
    WHERE e.id_departament = d.id_departament
);
```

---

## ⚠️ El Perill Crític d'un UPDATE sense WHERE

> **REGRA D'OR DEL DBA:** Si executes `UPDATE taula SET camp = valor;` sense una clàusula `WHERE`, **absolutament totes les files de la taula s'actualitzaran amb aquest mateix valor**. 
> Per prevenir catàstrofes en entorns de producció, recomanem:
> 1. Executar abans un `SELECT ... WHERE condicio;` per verificar quines files seran afectades.
> 2. Executar sempre l'UPDATE dins d'un bloc de transacció explícita (`BEGIN ... ROLLBACK`).
