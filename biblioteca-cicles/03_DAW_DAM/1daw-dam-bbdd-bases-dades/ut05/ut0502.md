Per a crear nous registres en les taules utilitzarem la instrucció SQL **`INSERT`**.

## **Sintaxi**

> **📌 Sintaxi de INSERT**
> 

```sql
INSERT INTO {nombre_tabla | nombre_vista} [(columna1 [, columna2]...)]
VALUES (valor1 [, valor2] ...);
```

Indiquem la instrucció, la taula o vista on anem a realizar-la, les columnes afectades i els valors que van a rebre cada columna.

## **Exemple bàsic**

Treballarem amb la taula `EMPLEADOS`:

> **📌 Creació de la taula EMPLEATS**
> 

```sql
CREATE TABLE EMPLEADOS (
    COD INT PRIMARY KEY,
    NOMBRE VARCHAR(50) NOT NULL,
    LOCALIDAD VARCHAR(50) DEFAULT 'Écija',
    FECHANAC DATE
);
```

> **📌 Insercions en EMPLEATS**
> 

```sql
INSERT INTO EMPLEADOS
VALUES (1, 'Pepe', 'Osuna', '1970-01-01');

INSERT INTO EMPLEADOS
VALUES (2, 'Juan', DEFAULT, NULL);

INSERT INTO EMPLEADOS
VALUES (3, 'Sara', NULL, NULL);

INSERT INTO EMPLEADOS (COD, NOMBRE, LOCALIDAD, FECHANAC)
VALUES (4, 'Luis', 'Algemesi', '1987-02-14');
```

En els exemples anteriors podem observar distintes formes d'invocar la sentència `INSERT`:

- Si **no es indiquen les columnes**, s'han de proporcionar valors per a **totes** les columnes en l'ordre en que es definieron.

- `DEFAULT` utilitza el valor per defecte definit en la columna.

- `NULL` assigna valor nul.

## **INSERT amb AUTO_INCREMENT**

Si tenim la clau primària amb autoincremento podrem inserir registres sense indicar el seu valor:

> **📌 Taula amb AUTO_INCREMENT**
> 

```sql
CREATE TABLE EMPLEADOS (
    COD int NOT NULL AUTO_INCREMENT,
    NOMBRE varchar(50) NOT NULL,
    LOCALIDAD varchar(50) DEFAULT 'Écija',
    FECHANAC date DEFAULT NULL,
    PRIMARY KEY (COD)
);
```

Les tres formes següents produeixen el mateix resultat:

> **📌 Inserir sense indicar el codi**
> 

```sql
INSERT INTO EMPLEADOS (COD, NOMBRE, LOCALIDAD) VALUES (null, 'Luis', 'Algemesi');
```

> **📌 Inserir amb valor 0**
> 

```sql
INSERT INTO EMPLEADOS (COD, NOMBRE, LOCALIDAD) VALUES (0, 'Luis', 'Algemesi');
```

> **📌 Inserir omitent la columna**
> 

```sql
INSERT INTO EMPLEADOS (NOMBRE, LOCALIDAD) VALUES ('Luis', 'Algemesi');
```

> **📌 AUTO_INCREMENT**
> 

> A l'indicar `NULL` o `0` en una columna `AUTO_INCREMENT`, MySQL genera automàticament el següent valor disponible.

## **Dates i funcions**

Els camps de tipus `DATE` tenen un format especial, i a més podem utilitzar funcions.

El format és `'YYYY-MM-DD'`, model americano.

> **📌 Inserir amb format de data**
> 

```sql
INSERT INTO EMPLEADOS VALUES (1, 'Pepe', 'Osuna', '1970-01-01');
```

També es pot utilitzar la funció `current_date()`:

> **📌 Inserir amb current_date()**
> 

```sql
INSERT INTO EMPLEADOS VALUES (0, 'Pepe', 'Osuna', current_date());
```

## **INSERT ... SELECT**

La sentència `INSERT` pot nutrir-se de valors utilitzant una consulta a una altra taula. L'únic que hem de fer és **respetar el número d'elements (columnes)** de la taula on anem a inserir.

> **📌 INSERT a partir d'una consulta**
> 

```sql
INSERT INTO EMPLEADOS
SELECT "0", c.nombre, "Algemesi", current_date()
FROM cliente c;
```

> **📌 INSERT ... SELECT indicant columnes**
> 

```sql
INSERT INTO EMPLEADOS (COD, NOMBRE, LOCALIDAD, FECHANAC)
SELECT "0", c.nombre, "Algemesi", current_date()
FROM cliente c;
```

> **📌 INSERT ... SELECT**
> 

> Aquesta variant permet **copiar registres** d'una taula a una altra i fins i tot **construir valors** a partir d'una consulta, el que resulta molt útil per a poblar taules a partir d'altres.

> **📌 Resum**
> 

> - `INSERT` permet crear nous registres en una taula.

> - Si no indiquem les columnes, cal proporcionar valors per a totes elles.

> - `DEFAULT` i `NULL` assignen el valor per defecte i nul respectivament.

> - Amb `AUTO_INCREMENT` no és necessari indicar el valor de la clau.

> - Les dates s'insereixen en format `'YYYY-MM-DD'`.

> - `INSERT ... SELECT` insereix els resultats d'una consulta.
