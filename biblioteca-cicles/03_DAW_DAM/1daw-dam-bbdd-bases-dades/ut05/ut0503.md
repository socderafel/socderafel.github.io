# 5.3 Esborrat de Registres: Sentència DELETE i Clàusula WHERE

Utilizaremos **`DELETE`** para eliminar parte o todos los registres de una taula.

## **Sintaxis**

Sintaxis de DELETE

```sql

```

```sql

```

| 1 2 3 4 5 6 | DELETE FROM nombre_taula;  DELETE FROM <nombre_taula> WHERE <condición> [ {AND | OR} <condición> [, ...] ] [ORDER BY <nombre_camp1> [, <nombre_camp2> [, ...]] [DESC]] [LIMIT [<posición_inicial>], <número_registres>]; |
| --- | --- |

- **Opción 1**: elimina **todos** los registres de la taula.

- **Opción 2**: elimina **solo** los registres que cumplan las condiciones.

DELETE sin WHERE

Si omitimos el `WHERE` en un `DELETE FROM`, se eliminarán **todos** los registres de la taula.

## **Ejemplos**

Eliminar todos los registres

```sql

```

```sql

```

| 1 | DELETE FROM comercial; |
| --- | --- |

Eliminar registres que cumplen una condición

```sql

```

```sql

```

| 1 2 | DELETE FROM comercial WHERE ciudad = 'Vitoria'; |
| --- | --- |

## **DELETE con subconsultes**

En el `DELETE` també usamos las **subconsultes** para hacer de filtro:

DELETE con subconsulta

```sql

```

```sql

```

| 1 2 3 4 5 | DELETE FROM comercial WHERE ciudad =     (SELECT ciudad      FROM cliente      WHERE nombre = 'Luis'); |
| --- | --- |

Otro ejemplo de DELETE con subconsulta

```sql

```

```sql

```

| 1 2 3 4 5 | DELETE FROM comercial WHERE ciudad =     (SELECT ciudad      FROM comercial      WHERE nombre = 'Luis'); |
| --- | --- |

Subconsultes en DELETE

Las subconsultes permeten **seleccionar dinámicamente** qué registres eliminar, en función de los datos almacenados en otras taules.

Resumen

- `DELETE` elimina registres de una taula.

- Sin `WHERE` elimina **todos** los registres.

- `WHERE` permet eliminar solo los registres que cumplen una condición.

- Podemos utilizar **subconsultes** como filtro.

- `ORDER BY` y `LIMIT` permeten controlar el orden y el número de registres eliminados.
