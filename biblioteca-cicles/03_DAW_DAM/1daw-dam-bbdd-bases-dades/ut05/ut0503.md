L'eliminació d'informació d'una base de dades es pot dur a terme mitjançant sentències DML d'esborrament físic (**`DELETE`**) o mitjançant tècniques de programació d'esborrament lògic (**Soft Delete**). Comprendre les diferències entre aquests enfocaments és crucial per complir tant amb normatives com el RGPD com amb els requisits d'auditoria fiscal.

---

## 🗑️ La Sentència DELETE FROM

L'ordre `DELETE FROM` elimina tuples concretes d'una taula que satisfan una condició lògica:
```sql
DELETE FROM sessions_web
WHERE expirada_el < CURRENT_TIMESTAMP;
```

Si s'omet la clàusula `WHERE`, s'esborren **totes les tuples** de la taula:
```sql
DELETE FROM carrets_abandonats; -- Esborra totes les files una a una!
```

---

## 🥊 Comparativa: DELETE vs. TRUNCATE vs. DROP

| Característica | `DELETE FROM` | `TRUNCATE TABLE` | `DROP TABLE` |
| :--- | :--- | :--- | :--- |
| **Subllenguatge** | DML | DDL | DDL |
| **Permet filtre WHERE** | Sí, esborra files selectives | No, buida tota la taula | No, elimina tota la taula |
| **Velocitat** | Més lenta (fila a fila, logs WAL) | Ultra ràpida (desassigna pàgines) | Immediata |
| **Impacte en l'estructura** | Es manté intacta | Es manté intacta | Desapareix completament |
| **Reinici de comptador SERIAL** | No reinicia | Reinicia a 1 (segons opcions) | S'esborra la seqüència |
| **Activació de Triggers** | Dispara triggers `ON DELETE` | Normalment no els dispara | No dispara triggers DML |

---

## 🛡️ Esborrament Lògic (Soft Delete)

En sistemes empresarials de producció (ERPs, botigues online, portals bancaris), quasi **mai s'esborren les dades físicament** de les taules principals. Si s'esborra físicament una comanda o un client, es trencarien les relacions històriques amb factures i albarans.

### Implementació del Patró Soft Delete
1. S'afig a la taula un camp d'estat o marca temporal:
   ```sql
   ALTER TABLE clients ADD COLUMN esborrat_el TIMESTAMP DEFAULT NULL;
   ```
2. Quan un usuari sol·licita "donar-se de baixa", es fa un `UPDATE`:
   ```sql
   UPDATE clients 
   SET esborrat_el = CURRENT_TIMESTAMP 
   WHERE id_client = 120;
   ```
3. Totes les consultes de l'aplicació filtren automàticament els registres no esborrats:
   ```sql
   SELECT * FROM clients WHERE esborrat_el IS NULL;
   ```
