## **Generalització i Especialització**

### **Exercici 1**

**Generalització o Especialització**

Indica si en cada cas és més adequat utilitzar una **generalització** o una **especialització**.

| Cas | Resposta |
| --- | --- |
| Existeixen les entitats COTXE, MOTO i CAMIÓN amb molts atributs comuns. |  |
| L'entitat EMPLEAT té alguns trabajadors que cobran comisió i altres que no. |  |
| Existeixen TARJETA_DÉBITO i TARJETA_CRÉDITO amb atributs comuns. |  |
| Una PERSONA pot ser ALUMNE o PROFESSOR. |  |
| Existeixen GATO, PERRO i AVE amb característiques comuns. |  |

### **Exercici 2**

**Descubre el supertipus**

Indica quin seria el **supertipus**.

- Bicicleta, Patinete i Motocicleta.

- Cercle, Rectangle i Triángulo.

- Professor, Alumne i Personal Administrativo.

- Compta Corriente, Compta Ahorro i Compta Empresa.

### **Exercici 3**

**Descubre els subtipus**

Propón **tres subtipus** per a cada un dels següents supertipos.

- Vehicle

- Animal

- Empleat

- Producte

- Usuari

### **Exercici 4**

**Herencia d'atributs**

Es disposa de l'entitat **EMPLEAT** amb els següents atributs:

- DNI

- Nom

- Adreça

- Telèfon

- Fechacontratació

A més existeixen els següents subtipus:

**Directivo**

- Despatx

- Complemento

**Comercial**

- Comisió

- ZonaVentas

**Tècnic**

- Especialitat

- Certificació

Es demana:

- Dibuixar el model EER.

- Indicar els atributs del supertipus.

- Indicar els atributs propis de cada subtipus.

- Explicar què atributs hereda cada subtipus.

### **Exercici 5**

**Total o Parcial**

Indica el tipus d'especialització.

| Cas | Tipus |
| --- | --- |
| Tot vehicle és cotxe, moto o camión. |  |
| Existeixen empleats que no pertanyen a cap categoria. |  |
| Tots els animals pertanyen a una espècie. |  |

### **Exercici 6**

**Disjunta o Solapada**

Indica el tipus d'especialització.

| Cas | Tipus |
| --- | --- |
| Un estudiant només pertany a un grup. |  |
| Un professor pot ser investigador. |  |
| Un empleat pot ser cap i responsable de qualitat. |  |
| Un vehicle només pot ser cotxe o motocicleta. |  |

### **Exercici 7**

**Classifica la jerarquia**

Indica per a cada cas si l'especialització és:

- Total o Parcial.

- Disjunta o Solapada.

**Cas 1**

Tot empleat pertany a:

- Directivo

- Comercial

- Tècnic

Cap pot pertànyer a dos categories.

**Cas 2**

Un professor pot ser:

- Tutor

- Coordinador

- Cap de Departament

Pot desempeñar diversos cargos i alguns professors no exercixen cap.

### **Exercici 8**

**Disseny d'una especialització**

Dissenya un model EER per a una universitat.

Ha de contindre:

- Supertipus PERSONA.

- Subtipus ALUMNE i PROFESSOR.

- Quatre atributs comuns.

- Dos atributs específics per a cada subtipus.

Indica a més:

- Si és Total o Parcial.

- Si és Disjunta o Solapada.

## **Agregació**

### **Exercici 9**

**Quan utilitzar agregació?**

Indica en què casos utilitzaries una agregació.

- Un professor imparteix una assignatura i un aula on es imparteix.

- Un client compra un producte i posteriorment una empresa de transport realitza l'enviament d'eixa compra.

- Un metge atén pacients.

- Un jugador pertany a un equip.

### **Exercici 10**

**Disseny amb agregació**

Una biblioteca registra:

- Usuaris

- Llibres

Tots dos participen en la relació **PRÉSTAMO**.

Posteriorment un empleat supervisa cada préstamo.

Es demana:

- Dissenyar el model EER utilitzant una agregació.

- Identificar les entitats.

- Identificar les relacions.

## **Exercici Complet**

### **Exercici 11**

**Modelatge complet**

Dissenya el model EER per a una empresa d'alquiler de vehículos.

Ha de contindre:

- Una jerarquia d'especialització.

- Un supertipus.

- Tres subtipus.

- Una especialització Total.

- Una especialització Disjunta.

- Una agregació.

- Almenys deu atributs.

- Dos relacions addicionals.
