## **Exercici 1**

**Base de dades y colecciones.**
Diseñar y gestionar una base de dades NoSQL con MongoDB que represente una plataforma de cursos online. La base de dades se llamará “formacion”.
La base de dades contará con el siguiente listado de colecciones.

| Colección | Descripción |
| --- | --- |
| cursos | Contiene información sobre cada curso ofertado |
| alumnos | Datos de los estudiantes |
| matriculas | Vincula a los alumnos con los cursos |
| docentes | Datos del profesorado |
| evaluaciones | Resultados de los alumnos en cada curso |
