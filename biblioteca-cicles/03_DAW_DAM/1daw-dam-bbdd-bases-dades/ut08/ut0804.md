Les operacions bàsiques de qualsevol motor de bases de dades són les conegudes com a **CRUD** (*Create, Read, Update, Delete*). En MongoDB, aquestes operacions s'executen mitjançant la consola interactiva **`mongosh`** (o a través de drivers per a JavaScript/Node.js, Java, Python o PHP) utilitzant mètodes basats en documents JSON.

---

## 📥 Inserció de Documents (Create)

```javascript
// 1. Inserció d'un sol document
db.productes.insertOne({
    titol: "Portàtil Gamer Pro",
    preu: 1199.99,
    estoc: 15,
    categories: ["Informàtica", "Gaming"],
    actiu: true
});

// 2. Inserció múltiple
db.productes.insertMany([
    { titol: "Ratolí Òptic", preu: 19.99, estoc: 100 },
    { titol: "Teclat Mecànic", preu: 89.50, estoc: 40 }
]);
```

---

## 🔍 Consulta de Documents (Read)

El mètode **`find()`** rep dos arguments opcionals: el filtre de selecció i la projecció de camps:
`db.colleccio.find(filtre, projeccio)`

```javascript
// Tots els productes amb preu superior a 50 € ordenats per preu descendent:
db.productes.find(
    { preu: { $gt: 50.00 } },          // Filtre ($gt = Major que)
    { titol: 1, preu: 1, _id: 0 }       // Projecció (1=mostrar, 0=ocultar)
).sort({ preu: -1 }).limit(5);
```

### Operadors de Consulta Habituals
- **Comparació:** `$eq` (=), `$ne` (!=), `$gt` (>), `$gte` (>=), `$lt` (<), `$lte` (<=), `$in` (dins de llista).
- **Lògics:** `$and`, `$or`, `$not`.
- **D'Arrays:** `$all` (conté tots els elements), `$size` (longitud de l'array).

---

## ✏️ Modificació de Documents (Update)

A MongoDB, és fonamental utilitzar **operadors de modificació atòmics** (`$set`, `$inc`, `$push`):

```javascript
// Incrementar en 5 unitats l'estoc del teclat mecànic
db.productes.updateOne(
    { titol: "Teclat Mecànic" },        // Filtre
    { 
        $inc: { estoc: 5 },             // Incrementa 5
        $set: { actualitzat_el: new Date() } // Modifica o crea el camp
    }
);

// Actualització massiva:
db.productes.updateMany(
    { actiu: { $exists: false } },
    { $set: { actiu: true } }
);
```

---

## 🗑️ Esborrament de Documents (Delete)

```javascript
// Esborrar un sol document coincident
db.productes.deleteOne({ titol: "Ratolí Òptic" });

// Esborrar tots els productes esgotats
db.productes.deleteMany({ estoc: 0 });
```
