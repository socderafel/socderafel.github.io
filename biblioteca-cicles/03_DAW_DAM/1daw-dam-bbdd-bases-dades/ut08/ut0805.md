Per a tasques avançades d'anàlisi de dades, transformació i càlculs agrupats, MongoDB ofereix l'**Aggregation Framework** (Marc d'Agregacions), basat en el concepte de **canonada de processament (pipeline)**. A més, per a garantir que aquestes consultes s'executen en mil·lisegons, cal conèixer la creació i gestió d'**índexs** en col·leccions documentals.

---

## 🚰 El Marc d'Agregació: La Canonada (Pipeline)

La idea d'una canonada és que els documents entren per un extrem i van passant seqüencialment per una sèrie d'**etapes (stages)**, on es filtren, transformen, descomposen o agrupen, eixint un conjunt de documents refinats per l'altre extrem.

```
[ Documents Entrada ] ──► $match ──► $group ──► $project ──► $sort ──► [ Resultat ]
```

### Principals Etapes de la Canonada
1. **`$match`:** Filtra documents (equivalent al `WHERE` d'SQL).
2. **`$group`:** Agrupa documents per un camp clau (`_id`) i calcula sumes, mitjanes, etc. (equivalent a `GROUP BY`).
3. **`$project`:** Modifica l'estructura dels documents, canvia el nom de camps o calcula valors derivats.
4. **`$sort`:** Ordena els documents resultants (1 per ascendent, -1 per descendent).
5. **`$limit` / `$skip`:** Pàgina resultats.
6. **`$unwind`:** Desmunta un camp de tipus array, generant un document independent per a cada element de l'array.

### Exemple Pràctic de Canonada: Total de Vendes per Categoria
```javascript
db.comandes.aggregate([
    // Etapa 1: Només comandes completades
    { $match: { estat: "COMPLETADA" } },

    // Etapa 2: Agrupar per categoria de producte i sumar
    {
        $group: {
            _id: "$categoria",
            total_vendes: { $sum: "$import_total" },
            mitjana_ticket: { $avg: "$import_total" },
            recompte: { $sum: 1 }
        }
    },

    // Etapa 3: Ordenar per total de vendes descendent
    { $sort: { total_vendes: -1 } }
]);
```

## ⚡ Indexació a MongoDB

Sense índexs, MongoDB ha d'escanejar cada document d'una col·lecció per trobar les coincidències (*COLLSCAN*), col·lapsant la memòria.

```javascript
// 1. Creació d'un índex senzill ascendent
db.usuaris.createIndex({ email: 1 }, { unique: true });

// 2. Creació d'un índex compost (cognoms i nom)
db.clients.createIndex({ cognoms: 1, nom: 1 });

// 3. Inspecció del pla d'execució
db.usuaris.find({ email: "anna@correu.org" }).explain("executionStats");
```
