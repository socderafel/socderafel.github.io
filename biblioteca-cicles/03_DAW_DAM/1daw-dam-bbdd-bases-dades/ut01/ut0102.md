Un **Sistema de Gestió de Bases de Dades (SGBD)**, o en anglès *Database Management System (DBMS)*, és un conjunt complex de programari que actua com a intermediari entre la base de dades física (emmagatzemada en disc) i els usuaris o aplicacions que desitgen consultar-la o modificar-la.

L'SGBD proporciona una interfície única, segura i fiable que abstrau la complexitat del maquinari i dels dispositius d'emmagatzematge secundari.

---

## ⚙️ Funcions Principals d'un SGBD

1. **Definició de dades (DDL - Data Definition Language):** Permet descriure l'esquema lògic, els tipus de dades i les regles d'integritat.
2. **Manipulació de dades (DML - Data Manipulation Language):** Facilita la inserció, modificació, consulta i esborrament de dades sense haver de saber on estan guardades físicament.
3. **Seguretat i control d'accés (DCL - Data Control Language):** Garanteix que només els usuaris autoritzats puguen accedir o modificar dades determinades.
4. **Control de concurrència:** Coordina l'accés simultani de milers d'usuaris evitant interferències i corrupció de registres.
5. **Gestió de transaccions i recuperació davant fallades:** Assegura que davant una caiguda del servidor o apagada sobtada, la base de dades torne a un estat consistent mitjançant fitxers de registre (*Write-Ahead Logging* / *WAL* o *redo logs*).
6. **Manteniment de la integritat:** Fa complir les regles de validació (claus primàries, foranes, restriccions CHECK).

## 🧱 Arquitectura i Components Interns d'un SGBD

Un SGBD modern com PostgreSQL o MySQL està compost per diversos subsistemes especialitzats:

```
[ Usuaris / Aplicacions Web / Eines d'administració ]
                      │ (Consultes SQL / Xarxa)
                      ▼
┌────────────────────────────────────────────────────────┐
│  MOTOR DEL SGBD (Database Engine)                      │
│                                                        │
│  ┌────────────────────┐      ┌──────────────────────┐  │
│  │ Processador /      │ ───► │ Optimitzador de      │  │
│  │ Analitzador SQL    │      │ Consultes (Query Opt)│  │
│  └────────────────────┘      └──────────┬───────────┘  │
│                                         │ Pla d'exec.  │
│                                         ▼              │
│  ┌────────────────────┐      ┌──────────────────────┐  │
│  │ Gestor de          │ ◄──► │ Motor d'Execució     │  │
│  │ Seguretat / Usuaris│      │ de Consultes         │  │
│  └────────────────────┘      └──────────┬───────────┘  │
│                                         ▼              │
│  ┌──────────────────────────────────────────────────┐  │
│  │ Gestor d'Emmagatzematge (Storage Manager)        │  │
│  │  - Gestor de memòria cau (Buffer Pool)           │  │
│  │  - Gestor de transaccions (ACID / WAL logs)      │  │
│  │  - Gestor de bloquejos (Lock Manager)            │  │
│  └──────────────────────────┬───────────────────────┘  │
└─────────────────────────────┼──────────────────────────┘
                              ▼
        [ Emmagatzematge Físic: Taules, Índexs, Catàleg ]
```

---

## 👥 Perfils d'Usuaris en un SGBD

- **Administrador de la Base de Dades (DBA - Database Administrator):** Màxim responsable de la instal·lació, rendiment, còpies de seguretat, seguretat d'accés i optimització de l'SGBD.
- **Dissenyadors de BD:** Analitzen els requeriments del negoci i elaboren els esquemes conceptuals (E/R) i lògics (relacionals).
- **Desenvolupadors d'Aplicacions:** Creen el programari (back-end, APIs, front-end) que interactua amb la BD mitjançant SQL o ORMs.
- **Usuaris Finals:** Interactuen amb el sistema mitjançant aplicacions (formularis, informes) sense conèixer l'existència de l'SGBD intern.
