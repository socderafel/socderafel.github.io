Les **subconsultes** són tipus de consultes que usem per a obtindre uns **valors necessaris per a la consulta principal**. Tindrem un `SELECT` principal que d'alguna manera estarà filtrat pel resultat de la consulta `SELECT` secundària, subordinada o imbricada a la principal.

> **📌 Exemple**
> 

```sql
SELECT *
FROM jardineria.pedidos
WHERE pedidos.codigocliente IN (
    SELECT clientes.codigocliente
    FROM jardineria.clientes
    WHERE clientes.ciudad LIKE '%uenlabr%'
);
```

Comptem amb **tres grups** de subconsultes:

- **Escalonades**: retornen un **únic valor**.

- **De llista**: retornen una **llista o conjunt** de resultats.

- **Correlacionades**: tant la consulta principal com les seues subordinades extraen els valors d'aquestes taules.

## **Subconsultes escalonades**

En aquest tipus de subconsultes farem ús dels **operadors de comparació** tradicionals (`<`, `<=`, `>`, `>=`, `<>`, `=`). Aquest tipus de subconsultes **només retorna un valor**.

> **📌 Exemple**
> 

```sql
SELECT *
FROM jardineria.Productos
WHERE CodigoProducto = (
    SELECT CodigoProducto
    FROM jardineria.DetallePedidos
    WHERE PrecioUnidad = (
        SELECT MAX(PrecioUnidad)
        FROM jardineria.DetallePedidos
    )
    LIMIT 1
);
```

## **Subconsultes de llista**

En aquest tipus de subconsulta la `SELECT` secundària pot retornar **més d'un valor**, és a dir, un conjunt de valors. Per a comparar-los utilitzarem els operadors de cerca literals (**`ALL`**, **`ANY`**, **`EXISTS`**) o de comparació literals (**`IN`**).

### **Operador ALL**

Podem traducir-lo per **TOTS** els valors que ens retorne la subconsulta. Principalment s'utilitza amb operadors de comparació tradicionals.

> **📌 Exemple**
> 

```sql
-- ¿Hay un Herramienta más cara que todos los Frutales?
SELECT *
FROM jardineria.productos
WHERE gama = "Herramientas"
  AND precioventa > ALL (
    SELECT precioventa
    FROM jardineria.productos
    WHERE gama = "Frutales"
);
```

### **Operador ANY**

Podem traducir-lo per **ALGUN** dels valors que ens retorne la subconsulta. Principalment s'utilitza amb operadors de comparació tradicionals.

> **📌 Exemple**
> 

```sql
-- ¿Hay un Herramienta más cara que algún Frutal?
SELECT *
FROM jardineria.productos
WHERE gama = "Herramientas"
  AND precioventa > ANY (
    SELECT precioventa
    FROM jardineria.productos
    WHERE gama = "Frutales"
);
```

### **Operador EXISTS**

La sentència `EXISTS` s'utilitza per a filtrar per totes les files que complisquen eixa condició.

> **📌 Exemple**
> 

```sql
-- Obtener todos los "pedidos" si se despiden clientes de Madrid
SELECT *
FROM jardineria.pedidos
WHERE EXISTS (
    SELECT *
    FROM jardineria.clientes
    WHERE clientes.codigocliente = pedidos.codigocliente
      AND clientes.ciudad LIKE "Madrid"
);
```

### **Operador IN**

En aquest cas el que volem obtindre és que el valor comparado **estiga dins d'un llistat**.

> **📌 Exemple**
> 

```sql
-- Obtener todos los "pedidos" de clientes de Madrid
SELECT *
FROM jardineria.pedidos
WHERE pedidos.codigocliente IN (
    SELECT codigocliente
    FROM jardineria.clientes
    WHERE ciudad LIKE "Madrid"
);
```

## **Subconsultes com font de dades**

### **DDL: crear una taula a partir d'una consulta**

Podem crear taules a partir del resultat d'una consulta mitjançant **`CREATE TABLE ... AS SELECT`**, emmagatzemant en estàtic les dades obtinguts, amb la mateixa estructura i tipus de dades de les taules d'origen.

> **📌 Exemple**
> 

```sql
CREATE OR REPLACE TABLE directivo AS
SELECT e.CodEmp, e.NomEmp, d.CodDep, d.NomDep, d.TiDir
FROM empleado e JOIN departamento d ON d.CodEmpDir = e.CodEmp
WHERE d.TiDir = "P";
```

### **DML: inserir dades a partir d'una consulta**

Si volem inserir dades a partir d'una consulta usarem la sentència **`INSERT tabla SELECT ...`**.

> **📌 Exemple**
> 

```sql
INSERT directivo
SELECT e.CodEmp, e.NomEmp, d.CodDep, d.NomDep, d.TiDir
FROM empleado e JOIN departamento d ON d.CodEmpDir = e.CodEmp
WHERE d.TiDir = "F";
```

> **📌 Resum**
> 

> - Una **subconsulta** és un `SELECT` imbricat dins d'un altre `SELECT` que aporta valors a la consulta principal.

> - Les subconsultes poden ser **escalonades** (un valor), **de llista** (un conjunt) o **correlacionades**.

> - Els operadors de comparació s'usen amb subconsultes d'un únic valor; `IN`, `ALL`, `ANY` i `EXISTS` amb subconsultes de llista.

> - `CREATE TABLE ... AS SELECT` e `INSERT ... SELECT` permeten usar el resultat d'una consulta per a crear o poblar taules.
