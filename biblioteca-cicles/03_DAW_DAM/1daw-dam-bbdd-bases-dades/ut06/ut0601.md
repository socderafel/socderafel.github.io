La sentència **`SELECT`** és el pilar fonamental del subllenguatge DQL. Permet recuperar registres de la base de dades seleccionant columnes específiques (projecció), filtrant les files que compleixen determinats criteris (selecció), ordenant el resultat i paginant-lo per a la seua presentació en interfícies d'usuari.

---

## 🏛️ L'Ordre d'Execució Lògic d'un SELECT

Mentre que sintàcticament escrivim `SELECT` en primer lloc, el motor de la base de dades executa les clàusules en un ordre lògic completament diferent:

```
1. FROM / JOIN     ──► Determina i combina les taules d'origen de les dades.
2. WHERE           ──► Filtra les files individuals que compleixen la condició.
3. GROUP BY        ──► Agrupa les files en blocs comuns.
4. HAVING          ──► Filtra els grups resultants.
5. SELECT          ──► Projecta les columnes finals i calcula expressions / àlies.
6. DISTINCT        ──► Elimina files idèntiques si s'ha sol·licitat.
7. ORDER BY        ──► Ordena el resultat final.
8. LIMIT / OFFSET  ──► Pàgina i selecciona el rang de files a retornar.
```

---

## 🔍 Projecció, Filtres i Operadors Especials

### 1. Projecció i Àlies (`AS`)
```sql
SELECT 
    nom AS nom_producte, 
    preu, 
    preu * 1.21 AS preu_amb_iva
FROM productes;
```

### 2. Filtres Avançats en WHERE
- **Comparació:** `=`, `<>`, `!=`, `<`, `>`, `<=`, `>=`.
- **Comprovació de Nuls:** *Mai utilitzar `= NULL`!* S'ha d'utilitzar:
  ```sql
  WHERE data_baixa IS NULL;
  WHERE data_baixa IS NOT NULL;
  ```
- **Intervals (`BETWEEN`):** Inclusiu en ambdós extrems:
  ```sql
  WHERE preu BETWEEN 10.00 AND 50.00;
  ```
- **Llista de Valors (`IN`):**
  ```sql
  WHERE ciutat IN ('València', 'Castelló', 'Alacant');
  ```
- **Patrons de Text (`LIKE` / `ILIKE` a PostgreSQL):**
  - `%` : Representa zero o més caràcters.
  - `_` : Representa exactament un únic caràcter.
  ```sql
  WHERE cognoms LIKE 'Pér%'; -- Comença per Pér
  WHERE dni LIKE '________[A-Z]'; -- 8 caràcters seguits de lletra
  ```

---

## 📑 Ordenació i Paginació Web

Per a no saturar el servidor enviant 100.000 registres al navegador, les aplicacions web empren paginació:
```sql
-- Pàgina 2 d'articles (mostrant 10 articles per pàgina):
SELECT id, titol, preu
FROM articles
ORDER BY preu DESC, titol ASC
LIMIT 10 OFFSET 10;
```
