# 6.1 Estructura Bàsica d'una Consulta SQL: Clàusula SELECT i FROM

El **SQL** (*Structured Query Language*, Lenguaje de Consulta Estructurado) es un **lenguaje específico de dominio** (DSL, *Domain-Specific Language*) que se utiliza para gestionar las bases de dades relacionals y realizar operaciones sobre los datos que contienen.

DQL

El **DQL** (*Data Query Language*) agrupa las instrucciones **`SELECT`** en diferentes niveles. En aquesta unitat trabajaremos desde las consultes más **simples** hasta las **complejas**, para finalmente aplicar criterios de **optimización** y crear **vistes**.

## **Consultes**

Una **consulta** es una instrucción que nos permet **recuperar información** almacenada en la base de dades. Las consultes más sencillas eligen **qué camps de la taula** mostraremos en el resultado, aunque podemos abreviar y mostrarlos todos utilizando el comodín del asterisco `*`.

Resumen

- El **SQL** es un lenguaje específico de dominio para trabajar con bases de dades relacionals.

- Las instrucciones se agrupan en **DDL**, **DML**, **DCL**, **TCL** y **DQL**.

- El **DQL** agrupa las instrucciones `SELECT`, que recuperan información de las taules.

- El comodín `*` selecciona **todos los camps** de una taula.
