El **SQL** (*Structured Query Language*, Llenguatge de consulta Estructurat) és un **llenguatge específic de domini** (DSL, *Domain-Specific Language*) que s'utilitza per a gestionar les bases de dades relacionals i realitzar operacions sobre les dades que contenen.

## **Categories de les instruccions SQL**

Les instruccions SQL es agrupen en **5 categories** segons la funcionalitat que exercixen:

| Categoria | Sigles | Sentències |
| --- | --- | --- |
| Llenguatge de Definició de Dades | **DDL** | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| Llenguatge de Manipulació de Dades | **DML** | `INSERT`, `UPDATE`, `DELETE` |
| Llenguatge de Control de Dades | **DCL** | `GRANT`, `REVOKE` |
| Llenguatge de Control de Transaccions | **TCL** | `COMMIT`, `ROLLBACK`, `SAVEPOINT` |
| Llenguatge de consulta de Dades | **DQL** | `SELECT` |

> **📌 DQL**
> 

> El **DQL** (*Data Query Language*) agrupa les instruccions **`SELECT`** en diferents nivells. En aquesta unitat treballarem des de les consultes més **simples** fins a les **complexes**, per a finalment aplicar criteris de **optimització** i crear **vistes**.

## **Consultes**

Una **consulta** és una instrucció que ens permet **recuperar informació** emmagatzemada en la base de dades. Les consultes més senzilles eligen **què camps de la taula** mostrarem en el resultat, encara que podem abreviar i mostrar-los tots utilitzant el comodí de l'asterisco `*`.

> **📌 Resum**
> 

> - El **SQL** és un llenguatge específic de domini per a treballar amb bases de dades relacionals.

> - Les instruccions es agrupen en **DDL**, **DML**, **DCL**, **TCL** i **DQL**.

> - El **DQL** agrupa les instruccions `SELECT`, que recuperan informació de les taules.

> - El comodí `*` selecciona **tots els camps** d'una taula.
