La instrucció **`SELECT`** ens permet **seleccionar els camps** de la taula que indiquem en la clàusula **`FROM`**. Si utilitzem el comodí `*`, seleccionará tots els camps. Si volem **filtrar el resultat** pel valor d'algun camp concret, el posarem després de la clàusula **`WHERE`**.

> **📌 Sintaxi**
> 

```sql
SELECT [ {ALL | DISTINCT | DISTINCTROW } ]
<nombre_campo> [ , <nombre_campo> [ , ... ] ]
FROM <nombre_tabla> [ , {<nombre_tabla>} [ , ...] ]
[WHERE <condición> [ {AND | OR} <condición> [ , ...] ]]
[ORDER BY <condición> [ {AND | OR} <condición> [ , ...] ]]
[DESC]
[LIMIT [<posición_inicial>], <número_registros>]
```

> **📌 Exemple**
> 

```sql
-- Mostrará todos los campos de la tabla del director
SELECT * FROM Director;

-- Sólo mostrará los registros que cumplen los filtros
SELECT nombreDirector, edadDirector
FROM Director
WHERE salarioDirector > 10000 AND nacionalidadDirector = 1;
```

## **LIMIT**

La clàusula **`LIMIT [<posición_inicial>], <número_registros>`** és molt interessant per a fer aplicacions d'escriptori o web. Permet anar **recuperant els registres** de la consulta en blocs amb el número de registres indicat.

- Si es omite la posició inicial, comenzará pel registre inicial o zero.

- En les següents mostres de dades ja **no podrem omitir** el valor de la posició inicial.

D'aquesta manera podem realitzar consultes amb molts registres (centenares, milers o milions) i anar recuperant la informació a intervalos del mida que vulguem.

> **📌 Exemple**
> 

```sql
SELECT count(*) FROM jardineria.cliente;
SELECT * FROM jardineria.cliente LIMIT 0,10;
SELECT * FROM jardineria.cliente LIMIT 11,10;
SELECT * FROM jardineria.cliente LIMIT 21,10;
SELECT * FROM jardineria.cliente LIMIT 31,6;
```

## **Duplicats. DISTINCT**

Pot que els resultats estiguen **repetits** en la consulta. Per exemple, si volem mostrar la població dels alumnes del centre, aquest camp es repetirá. Si usem la sentència **`DISTINCT`** evitarem els duplicats:

> **📌 Exemple**
> 

```sql
SELECT población FROM centro.alumno;
SELECT DISTINCT población FROM centro.alumno;
```

| Població (amb duplicats) | Població (DISTINCT) |
| --- | --- |
| Alfarb | Alfarb |
| Catadau | Catadau |
| Llombai | Llombai |
| Llombai | Carlet |
| Catadau |  |
| Alfarb |  |
| Carlet |  |

> **📌 Resum**
> 

> - `SELECT` tria els camps a mostrar i `FROM` la taula o taules d'on es extraen.

> - `WHERE` filtra els registres segons una condició.

> - `LIMIT` recupera els registres en blocs, indicant posició inicial i número de registres.

> - `DISTINCT` elimina els resultats duplicats.
