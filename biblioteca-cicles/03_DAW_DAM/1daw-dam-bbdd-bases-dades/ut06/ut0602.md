# 6.2 Consultes Simples: Filtratge amb WHERE i Operadors de Comparació

La instrucción **`SELECT`** nos permet **seleccionar los camps** de la taula que indiquemos en la cláusula **`FROM`**. Si utilizamos el comodín `*`, seleccionará todos los camps. Si queremos **filtrar el resultado** por el valor de algún camp concreto, lo pondremos después de la cláusula **`WHERE`**.

Sintaxis

```sql

```

```sql

```

| 1 2 3 4 5 6 7 | SELECT [ {ALL | DISTINCT | DISTINCTROW } ] <nombre_camp> [ , <nombre_camp> [ , ... ] ] FROM <nombre_taula> [ , {<nombre_taula>} [ , ...] ] [WHERE <condición> [ {AND | OR} <condición> [ , ...] ]] [ORDER BY <condición> [ {AND | OR} <condición> [ , ...] ]] [DESC] [LIMIT [<posición_inicial>], <número_registres>] |
| --- | --- |

Ejemplo

```sql

```

```sql

```

| 1 2 3 4 5 6 7 | -- Mostrará todos los camps de la taula del director SELECT * FROM Director;  -- Sólo mostrará los registres que cumplen los filtros SELECT nombreDirector, edadDirector FROM Director WHERE salarioDirector > 10000 AND nacionalidadDirector = 1; |
| --- | --- |

## **LIMIT**

La cláusula **`LIMIT [<posición_inicial>], <número_registres>`** es muy interesante para hacer aplicaciones de escritorio o web. Permite ir **recuperando los registres** de la consulta en bloques con el número de registres indicado.

- Si se omite la posición inicial, comenzará por el registre inicial o cero.

- En las siguientes muestras de datos ya **no podremos omitir** el valor de la posición inicial.

De esta manera podemos realizar consultes con muchos registres (centenares, miles o millones) e ir recuperando la información a intervalos del tamaño que queramos.

Ejemplo

```sql

```

```sql

```

| 1 2 3 4 5 | SELECT count(*) FROM jardineria.cliente; SELECT * FROM jardineria.cliente LIMIT 0,10; SELECT * FROM jardineria.cliente LIMIT 11,10; SELECT * FROM jardineria.cliente LIMIT 21,10; SELECT * FROM jardineria.cliente LIMIT 31,6; |
| --- | --- |

## **Duplicados. DISTINCT**

Puede que los resultados estén **repetidos** en la consulta. Per exemple, si queremos mostrar la población de los alumnos del centro, este camp se repetirá. Si usamos la sentencia **`DISTINCT`** evitaremos los duplicados:

Ejemplo

```sql

```

```sql

```

| 1 2 | SELECT población FROM centro.alumno; SELECT DISTINCT población FROM centro.alumno; |
| --- | --- |

| Población (con duplicados) | Población (DISTINCT) |
| --- | --- |
| Alfarb | Alfarb |
| Catadau | Catadau |
| Llombai | Llombai |
| Llombai | Carlet |
| Catadau |  |
| Alfarb |  |
| Carlet |  |

Resumen

- `SELECT` elige los camps a mostrar y `FROM` la taula o taules de donde se extraen.

- `WHERE` filtra los registres según una condición.

- `LIMIT` recupera los registres en bloques, indicando posición inicial y número de registres.

- `DISTINCT` elimina los resultados duplicados.
