# **Vistes**

Una **vista** és un **objecte que es defineix amb una consulta** i que es comporta com una **taula virtual**. Quan un usuari accedeix a una vista, aparentement pensa que està accedint a una taula.

> **📌 Sintaxi**
> 

```sql
CREATE
[OR REPLACE]
[ALGORITHM = {UNDEFINED | MERGE | TEMPTABLE}]
[DEFINER = user]
[SQL SECURITY { DEFINER | INVOKER }]
VIEW view_name [(column_list)]
AS select_statement
[WITH [CASCADED | LOCAL] CHECK OPTION]
```

## **Avantatges**

- Al ser **consultes precompilades**, el seu rendiment és alguna cosa millor que fer les consultes directament.

- Permeten **restringir l'accés a certes columnes** (només nom, cognoms i telèfon dels clients), fins i tot a nivell de fila (només els clients de Alicante), de manera que podem restringir que un cert usuari només puga accedir a una vista, ajustant encara més el seu **esquema extern**.

- Faciliten **processos de normalització/desnormalització**.

## **Restriccions**

- No es pot modificar el contingut quan ésta utilitza `HAVING`, `GROUP BY`, `DISTINCT`, `UNION`, `UNION ALL` o funcions agregades (`MAX`, `MIN`, `SUM`, `COUNT`, ...).

- Tots els camps de la vista han de contindre els camps **no nuls de les taules base** que no tenen valors per defecte.

- Els camps de la vista són **camps simples**, sense derivats (càlculs, `LOWERCASE`, ...).

## **Exemple**

> **📌 Empleats que no representen a cap client**
> 

```sql
CREATE OR REPLACE VIEW empleados_noRepresentantes AS
SELECT e.*
FROM empleados e LEFT JOIN clientes c
ON c.codigoempleadorepventas = e.codigoempleado
WHERE c.CodigoEmpleadoRepVentas IS NULL;
```

> **📌 Consultar una vista**
> 

```sql
SELECT * FROM empleados_noRepresentantes;
```

## **Operacions sobre vistes**

| Operació | Ordre SQL |
| --- | --- |
| Crear o reemplaçar una vista | `CREATE OR REPLACE VIEW nombre_vista AS SELECT ...;` |
| Llistar les vistes de la BBDD | `SHOW FULL TABLES WHERE Table_type = 'VIEW';` |
| Veure la definició d'una vista | `SHOW CREATE VIEW nombre_vista;` |
| Eliminar una vista | `DROP VIEW IF EXISTS nombre_vista;` |

> **📌 Resum**
> 

> - Una **vista** és una **taula virtual** definida per una consulta.

> - Millora el **rendiment** (consultes precompilades) i permet **restringir l'accés** a columnes i files.

> - Té restriccions: no es pot modificar si utilitza agregats, `GROUP BY`, `DISTINCT` o `UNION`.

> - Es gestiona amb `CREATE OR REPLACE VIEW`, `SHOW`, `ALTER` i `DROP VIEW`.
