# 6.10 Vistes (CREATE VIEW) i Optimització de Consultes amb EXPLAIN

Una **vista** es un **objeto que se define con una consulta** y que se comporta como una **taula virtual**. Cuando un usuari accede a una vista, aparentemente piensa que está accediendo a una taula.

Sintaxis

```sql

```

```sql

```

| 1 2 3 4 5 6 7 8 | CREATE [OR REPLACE] [ALGORITHM = {UNDEFINED | MERGE | TEMPTABLE}] [DEFINER = user] [SQL SECURITY { DEFINER | INVOKER }] VIEW view_name [(column_list)] AS select_statement [WITH [CASCADED | LOCAL] CHECK OPTION] |
| --- | --- |

## **Ventajas**

- Al ser **consultes precompiladas**, su rendimiento es algo mejor que hacer las consultes directamente.

- Permiten **restringir el acceso a ciertas columnes** (sólo nombre, apellidos y teléfono de los clientes), incluso a nivel de fila (sólo los clientes de Alicante), de manera que podemos restringir que un cierto usuari sólo pueda acceder a una vista, ajustando aún más su **esquema externo**.

- Facilitan **procesos de normalització/denormalització**.

## **Restricciones**

- No es pot modificar el contenido cuando ésta utiliza `HAVING`, `GROUP BY`, `DISTINCT`, `UNION`, `UNION ALL` o funciones agregadas (`MAX`, `MIN`, `SUM`, `COUNT`, ...).

- Todos los camps de la vista deben contener los camps **no nulos de las taules base** que no tienen valores por defecto.

- Los camps de la vista son **camps simples**, sin derivados (cálculos, `LOWERCASE`, ...).

## **Ejemplo**

Empleados que no representan a ningún cliente

```sql

```

```sql

```

| 1 2 3 4 5 | CREATE OR REPLACE VIEW empleados_noRepresentantes AS SELECT e.* FROM empleados e LEFT JOIN clientes c ON c.codigoempleadorepventas = e.codigoempleado WHERE c.CodigoEmpleadoRepVentas IS NULL; |
| --- | --- |



## **Operaciones sobre vistes**

``

``

| Operación | Orden SQL |
| --- | --- |
| Crear o reemplazar una vista | CREATE OR REPLACE VIEW nombre_vista AS SELECT ...; |
| Listar las vistes de la BBDD | SHOW FULL TABLES WHERE Table_type = 'VIEW'; |
| Ver la definición de una vista | SHOW CREATE VIEW nombre_vista; |
| Eliminar una vista | DROP VIEW IF EXISTS nombre_vista; |

Resumen

- Una **vista** es una **taula virtual** definida por una consulta.

- Mejora el **rendimiento** (consultes precompiladas) y permet **restringir el acceso** a columnes y files.

- Tiene restricciones: no es pot modificar si utiliza agregados, `GROUP BY`, `DISTINCT` o `UNION`.

- Se gestiona con `CREATE OR REPLACE VIEW`, `SHOW`, `ALTER` y `DROP VIEW`.
