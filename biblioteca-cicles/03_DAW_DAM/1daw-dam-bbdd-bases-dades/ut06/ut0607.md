Els **operadors de conjunts** no operan sobre tipus de dades simples, sinó sobre els **resultats de dos o més consultes**, les quals han de tindre la **mateixa estructura**: la quantitat de columnes i els tipus de dades han de ser els mateixos.

Els operadors de conjunts són:

| Operador | Descripció |
| --- | --- |
| `UNION` | Retorna el conjunt de files resultant de la unió de les dos consultes, **sense duplicats**. |
| `UNION ALL` | Retorna el conjunt de files resultant de la unió de les dos consultes, **incloent els duplicats**. |
| `INTERSECT` | Retorna la **intersecció** entre els dos conjunts de files. |
| `EXCEPT` | Retorna totes aquelles files de la **primera consulta que no estiguen en la segona**. |

## **UNION**

Unió del resultat de dos consultes. Perquè funcione, les dos consultes han de tindre el **mateix número d'elements** i els **dominis han de ser compatibles**. El resultat retorna els valors que **no es repeteixen**.

> **📌 Exemple**
> 

```sql
SELECT "Cliente" AS tipo, c.nombrecliente AS Nombre, c.apellidocontacto AS apellido
FROM jardineria.clientes c
UNION
SELECT "Empleado" AS tipo, e.nombre AS Nombre, e.apellido1 AS apellido
FROM jardineria.empleados e;
```

A l'operador `UNION` es li pot incloure **`ALL`** per a incloure els elements repetits:

> **📌 Exemple**
> 

```sql
SELECT "Cliente" AS tipo, c.nombrecliente AS Nombre, c.apellidocontacto AS apellido
FROM jardineria.clientes c
UNION ALL
SELECT "Empleado" AS tipo, e.nombre AS Nombre, e.apellido1 AS apellido
FROM jardineria.empleados e;
```

## **INTERSECT**

Mostrarà els registres que **coincidan** en cada una de les consultes.

> **📌 Exemple**
> 

```sql
SELECT "Cliente" AS tipo, c.nombrecliente AS Nombre, c.apellidocontacto AS apellido
FROM jardineria.clientes c
INTERSECT
SELECT "Empleado" AS tipo, e.nombre AS Nombre, e.apellido1 AS apellido
FROM jardineria.empleados e;
```

## **EXCEPT**

Mostrarà els registres que **no coincidan** d'un costat de la unió.

> **📌 Exemple**
> 

```sql
SELECT "Cliente" AS tipo, c.nombrecliente AS Nombre, c.apellidocontacto AS apellido
FROM jardineria.clientes c
EXCEPT
SELECT "Empleado" AS tipo, e.nombre AS Nombre, e.apellido1 AS apellido
FROM jardineria.empleados e;
```

> **📌 Suport en MySQL**
> 

> `INTERSECT` i `EXCEPT` estan suportats en l'estàndard SQL i en altres gestors (Oracle, PostgreSQL, SQL Server). En MySQL clàssic (anterior a les versions recientes) no estan implementats i es poden simular amb `JOIN` o amb `NOT IN`.

> **📌 Resum**
> 

> - Els **operadors de conjunts** (`UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`) combinen els resultats de dos o més consultes.

> - Totes les consultes combinades han de tindre la **mateixa estructura** (mateix número i tipus de columnes).

> - `UNION` elimina duplicats; `UNION ALL` els conserva.

> - `INTERSECT` retorna els registres comuns i `EXCEPT` els de la primera consulta que no estan en la segona.
