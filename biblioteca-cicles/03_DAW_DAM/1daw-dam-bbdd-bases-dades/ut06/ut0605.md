Les **consultes resum o d'agregat** permeten obtindre **un només valor** com resultat d'aplicar una determinada operació als valors continguts en una columna. Són consultes que resum certa informació, extrayendo informació calculada d'un conjunt de registres.

| Funció | Descripció |
| --- | --- |
| `AVG` | Retorna la **mitjana** dels valors de la col·lecció. |
| `MAX` | Retorna el valor **màxim** de la col·lecció. |
| `MIN` | Retorna el valor **mínim** de la col·lecció. |
| `SUM` | Retorna la **suma** dels valors. |
| `COUNT` | Retorna el **número** de registres. |

> **📌 Exemple**
> 

```sql
SELECT COUNT(CodigoEmpleado) FROM jardineria.Empleados;
SELECT MAX(precioventa), MIN(precioventa) FROM productos;
SELECT AVG(cantidad) AS promedio FROM jardineria.pagos;
```

## **Agrupacions o de totals (GROUP BY)**

Per a poder **agrupar** per un camp o diversos camps haurem d'afegir la clàusula **`GROUP BY`**. També comptem amb la clàusula **`HAVING`** per a poder **filtrar els grups** segons la condició que li indiquem.

> **📌 WHERE vs HAVING**
> 

> - `WHERE` filtra les **files** abans d'agrupar.

> - `HAVING` filtra els **grups** després d'agrupar.

> **📌 Exemple**
> 

```sql
SELECT estado, count(*)
FROM jardineria.pedidos
GROUP BY estado;

SELECT estado, count(*)
FROM jardineria.pedidos
GROUP BY estado
HAVING count(*)>25;

SELECT estado, count(*)
FROM jardineria.pedidos
WHERE pedidos.comentarios IS NOT NULL
GROUP BY estado
HAVING count(*)>25;
```

> **📌 Resum**
> 

> - Les **funcions d'agregat** (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) retornen un únic valor resum.

> - `GROUP BY` agrupa els registres per un o diversos camps per a calcular totals per grup.

> - `HAVING` filtra els grups resultantes després de l'agregació.
