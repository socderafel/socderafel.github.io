## **Operadors aritmétics**

Aquests operadors només treballen amb números. Suposem que `operador1` val `23` i `operador2` val `11`:

| Operador | Descripció | Exemple |
| --- | --- | --- |
| Sumar `+` | Suma els valors dels dos operadors. | `operador1 + operador2 = 34` |
| Resta `-` | Resta el valor de la dreta del valor de l'esquerra. | `operador1 - operador2 = 12` |
| Multiplicar `*` | Multiplica els valors dels dos operadors. | `operador1 * operador2 = 253` |
| Dividir `/` | Divideix l'operador de l'esquerra pel de la dreta. | `operador1 / operador2 = 2` |
| Resta `%` | Divideix i retorna el resta. | `operador1 % operador2 = 1` |

> **📌 Exemple**
> 

```sql
SELECT precio_venta + precio_proveedor FROM jardineria.producto;
SELECT precio_venta - precio_proveedor FROM jardineria.producto;
SELECT precio_venta * precio_proveedor FROM jardineria.producto;
SELECT precio_venta / precio_proveedor FROM jardineria.producto;
SELECT precio_venta % precio_proveedor FROM jardineria.producto;
```

## **Operadors de comparació**

Serveixen per a comparar valors i saber si el resultat és **vertader o fals**. Suposem que `op1 = 33` i `op2 = 11`:

| Operador | Descripció | Exemple |
| --- | --- | --- |
| Menor `<` | Comprova si el valor de `op1` és menor que el de `op2`. | `(op1 < op2)` és fals |
| Menor o igual `<=` | Comprova si `op1` és menor o igual que `op2`. | `(op1 <= op2)` és fals |
| Major `>` | Comprova si `op1` és major que `op2`. | `(op1 > op2)` és cert |
| Major o igual `>=` | Comprova si `op1` és major o igual que `op2`. | `(op1 >= op2)` és cert |
| Igual `=` | Comprova si `op1` és igual que `op2`. | `(op1 = op2)` és fals |
| Distint `<>` | Comprova si `op1` és distint de `op2`. | `(op1 <> op2)` és cert |

> **📌 Negació**
> 

> També existeixen aquests operadors combinant el de negació: `!=`.

> **📌 Exemple**
> 

```sql
SELECT precio_venta < precio_proveedor FROM jardineria.producto;
SELECT precio_venta <= precio_proveedor FROM jardineria.producto;
SELECT precio_venta > precio_proveedor FROM jardineria.producto;
SELECT precio_venta >= precio_proveedor FROM jardineria.producto;
SELECT precio_venta = precio_proveedor FROM jardineria.producto;
SELECT precio_venta <> precio_proveedor FROM jardineria.producto;
SELECT precio_venta != precio_proveedor FROM jardineria.producto;

SELECT * FROM jardineria.producto WHERE precio_venta >= 50;
SELECT * FROM jardineria.producto WHERE precio_venta <= 50;
SELECT * FROM jardineria.producto WHERE precio_venta = 50;
```

## **Altres operadors de cerca**

| Operador | Descripció |
| --- | --- |
| `BETWEEN` | Per a cercar valors entre dos rangs. |
| `EXISTS` | Per a cercar l'existència d'una fila que complisca una condició. |
| `DISTINCT` | Per a cercar si no existeixen duplicats. |
| `ALL` | Per a comparar un valor amb tots els valors d'un conjunt. |
| `ANY` | Per a comparar un valor amb qualsevol un altre segons la condició. |
| `IN` | Per a comparar un valor amb una llista de valors donats. |
| `IS NULL` | Per a comparar un valor amb un valor `NULL`. |
| `LIKE` | Per a comparar un valor amb valors similars utilitzant operadors comodí. |

> **📌 Exemple**
> 

```sql
SELECT *
FROM jardineria.cliente
WHERE nombre_cliente BETWEEN "DaraDistribuciones" AND "Madrileña de riesgos";

SELECT *
FROM jardineria.producto
WHERE EXISTS (SELECT count(*) FROM jardineria.pedido HAVING count(*)>114);

SELECT DISTINCT nombre
FROM jardineria.producto;

SELECT *
FROM jardineria.producto
WHERE producto.codigo_producto IN (SELECT codigo_producto FROM jardineria.detalle_pedido);

SELECT *
FROM jardineria.empleado
WHERE empleado.codigo_jefe IS NULL;
```

## **Operadors comodí (LIKE)**

Quan volem cercar dades filtrándolos per la clàusula `WHERE` dins d'un rang de valors alfanumérics, podem utilitzar els operadors comodí `%` i `_`:

| Operador | Descripció |
| --- | --- |
| Símbol del percentatge `%` | Pot coincidir amb un o més caràcters. |
| Símbol del guion sota `_` | Només pot coincidir amb un caràcter. |

> **📌 Exemple**
> 

```sql
SELECT * FROM jardineria.producto WHERE nombre LIKE "Rast%";
SELECT * FROM jardineria.producto WHERE nombre LIKE "%ast%";
SELECT * FROM jardineria.producto WHERE nombre LIKE "_ast%";
SELECT * FROM jardineria.producto WHERE nombre LIKE "_astrillo de Jardí_";
```

## **Operadors d'expressions regulars (REGEXP)**

La clàusula o predicado **`REGEXP`** és més potent que `LIKE` perquè la cadena és un **patró** basat en l'ús d'expressions regulars. Una expressió regular és un patró que descriu un conjunt de cadenes possibles i està formada per caràcters literals i altres caràcters especials.

| Caràcter | Significat | Exemple |
| --- | --- | --- |
| `^` | Principi de cadena | `REGEXP '^A'` (noms que comencen per A) |
| `$` | Final de la cadena | `REGEXP 'A$'` (noms que acaben per A) |
| `.` | Qualsevol caràcter (un) | `REGEXP '....'` (noms de 4 caràcters) |
| `?` | Alternativa | `REGEXP '^A?B'` (noms que comencen per A o B) |
| `*` | Coincideix amb 0 o més caràcters | `REGEXP 'w*'` (que continga zero o més w) |
| `+` | Coincideix amb 1 o més caràcters | `REGEXP 'w+'` (que continga una o més w) |
| `\\|` | Diverses seqüències possibles | `REGEXP '(San\\|Ju)'` (noms que comencen per San o per Ju) |
| `( )` | Seqüència | `REGEXP '(www)+'` (que continga una o més de tres w) |
| `{n}, {n,m}` | Número d'ocurrències | `REGEXP 'w{1,3}'` (que continga entre 1 i tres w) |
| `[a-z], [^a-z]` | Qualsevol caràcter que estiga o no estiga en el rang | `REGEXP '[^aeiou]'` (que no continguen vocals) |

> **📌 Exemple**
> 

```sql
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP '^A';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP 'A$';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP '^A|B';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP 'e*';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP 'e+';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP 'golf';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP 'a{1,3}';
SELECT * FROM jardineria.Clientes WHERE clientes.NombreCliente REGEXP '^[eln]';
```

## **Operadors lògics**

En SQL disposem dels operadors lògics tradicionals **`AND`**, **`OR`** i **`NOT`**:

| Operador | Descripció |
| --- | --- |
| `AND` | Serveix per a poder posar múltiples condicions en la clàusula `WHERE`. |
| `OR` | Serveix per a poder posar múltiples condicions en la clàusula `WHERE`. |
| `NOT` | Serveix per a invertir el valor de l'operador lògic amb el que es aplique. |

> **📌 Exemple**
> 

```sql
SELECT *
FROM jardineria.pedido
WHERE pedido.fecha_pedido > "2008-09-01"
  AND pedido.fecha_entrega IS NOT NULL;

SELECT *
FROM jardineria.pedido
WHERE pedido.fecha_pedido > "2008-09-01"
   OR pedido.fecha_entrega IS NOT NULL;
```

## **Funcions de dates**

En SQL és interessant utilitzar funcions específiques per a treballar amb dates i realitzar operacions amb elles. Veurem algunes d'elles:

| Funció | Descripció |
| --- | --- |
| `NOW()` | Serveix per a obtindre la data d'hui en format `'2024-03-04 19:21'`. |
| `DATEDIFF()` | Serveix per a averiguar la diferència entre dos dates. |
| `DATE_FORMAT()` | Serveix per a formatear la data com ens puga interesar. |
| `ADDDATE()` | Agrega un intervalo de temps especificat a la data indicada. |

> **📌 Exemple**
> 

```sql
SELECT DATE_FORMAT('2009-10-04 22:23:00', '%W %M %Y');
SELECT DATE_FORMAT('2007-10-04 22:23:00', '%H:%i:%s');
SELECT DATE_FORMAT('1900-10-04 22:23:00', '%D %y %a %d %m %b %j');
SELECT DATE_FORMAT('1997-10-04 22:23:00', '%H %k %I %r %T %S %w');
SELECT DATE_FORMAT('2025-01-01', '%X %V');
SELECT DATE_FORMAT('2006-06-01', '%d');
SELECT NOW();

SELECT DATEDIFF(fecha_pedido, fecha_entrega)
FROM jardineria.pedido
WHERE fecha_entrega IS NOT NULL;
```

> **📌 Resum**
> 

> - Els **operadors aritmétics** (`+`, `-`, `*`, `/`, `%`) treballen amb números.

> - Els **operadors de comparació** (`<`, `<=`, `>`, `>=`, `=`, `<>`, `!=`) comparen valors.

> - Els **operadors de cerca** (`BETWEEN`, `IN`, `LIKE`, `IS NULL`, `EXISTS`, ...) filtran els resultats.

> - Els **comodins** `%` i `_` al costat de `LIKE` permeten cerques parcials; `REGEXP` amplia les possibilitats.

> - Els **operadors lògics** (`AND`, `OR`, `NOT`) combinen condicions.

> - Les **funcions de data** (`NOW()`, `DATEDIFF()`, `DATE_FORMAT()`, `ADDDATE()`) faciliten el treball amb dates.
