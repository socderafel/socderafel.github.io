El poder real del model relacional rau en la capacitat de relacionar dades distribuïdes en diferents taules sense duplicar informació. Les sentències **`JOIN`** implementen l'operació d'unió de l'àlgebra relacional, unint files de dues o més taules en funció d'una condició lògica de coincidència (habitualment entre una clau forana i una clau primària).

---

## 🧩 Tipus de Joins Relacionals

```
┌─────────────────────┐       ┌─────────────────────┐
│     TAULA A         │       │     TAULA B         │
│  (Costat Esquerre)  │       │   (Costat Dret)     │
└──────────┬──────────┘       └──────────┬──────────┘
           │                             │
           ├─────────► INNER JOIN ◄──────┤ (Només coincidències en ambdues)
           ├─────────► LEFT JOIN ◄───────┤ (Tot A + coincidències de B)
           ├─────────► RIGHT JOIN ◄──────┤ (Tot B + coincidències de A)
           └─────────► FULL JOIN ◄───────┘ (Tot A i Tot B, coincidint o no)
```

### 1. `INNER JOIN` (Unió Interna)
Retorna exclusivament les files que tenen coincidència en ambdues taules:
```sql
SELECT 
    c.nom AS client, 
    f.numero_factura, 
    f.import_total
FROM clients c
INNER JOIN factures f ON c.id_client = f.id_client;
```

### 2. `LEFT JOIN` (o `LEFT OUTER JOIN`)
Retorna **totes les files de la taula esquerra** (`clients`), tant si tenen correspondència a la taula dreta com si no. Si un client no té factures, les columnes de `factures` mostraran valors `NULL`:
```sql
SELECT 
    c.nom, 
    f.numero_factura
FROM clients c
LEFT JOIN factures f ON c.id_client = f.id_client;
```
> **Patró de cerca d'orfes:** Per trobar quins clients no han comprat mai:
> `WHERE f.numero_factura IS NULL`

### 3. `FULL OUTER JOIN`
Retorna totes les files de totes dues taules, unint les que coincideixen i omplint amb `NULL` quan no hi ha parella ni a l'esquerra ni a la dreta.

### 4. Autounió (*Self-Join*)
Ocorre quan una taula es combina amb si mateixa (típic en relacions reflexives com empleat - cap):
```sql
SELECT 
    e.nom AS empleat, 
    cap.nom AS responsable
FROM empleats e
LEFT JOIN empleats cap ON e.id_cap = cap.id_empleat;
```
