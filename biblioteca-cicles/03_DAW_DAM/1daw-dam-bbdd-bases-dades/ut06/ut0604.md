# 6.4 Camps Calculats, Àlies (AS), Ordenació (ORDER BY) i Limitació (LIMIT)

## **Camps calculats**

En SQL podemos **calcular camps** en la sentencia del `SELECT` para obtener el resultado que buscamos. També podemos utilizar estos camps calculats para **filtrar los resultados** en el `WHERE`.

Ejemplo

```sql

```

```sql

```

| 1 2 3 4 5 6 | SELECT precioventa, PrecioProveedor + PrecioProveedor*0.091 FROM jardineria.Productos WHERE PrecioProveedor < PrecioProveedor + PrecioProveedor*0.091;  SELECT precioventa, PrecioProveedor + PrecioProveedor*0.091 FROM jardineria.Productos; |
| --- | --- |

## **Consultes ordenadas**

Para **ordenar el resultado** de las consultes haremos uso de la cláusula **`ORDER BY`**. A més podemos indicar el sentido del orden: **`ASC`** (ascendente) o **`DESC`** (descendente). Si no indicamos nada, por defecto será `ASC`.

Ejemplo

```sql

```

```sql

```

| 1 2 3 | SELECT * FROM jardineria.Clientes ORDER BY NombreCliente ASC; SELECT * FROM jardineria.Clientes ORDER BY NombreCliente DESC; SELECT * FROM jardineria.Clientes ORDER BY NombreCliente; |
| --- | --- |

## **Consultes con cabecera (alias)**

Si los resultados de nuestras consultes van a mostrarse a otras personas, puede interesarnos **cambiar los nombres de los camps** para que se entienda mejor el informe obtenido. Para conseguirlo crearemos un **alias** con la opción **`AS`** junto con el nuevo título de la columna, normalmente entre comillas simples.

Ejemplo

```sql

```

```sql

```

| 1 2 3 4 | SELECT precioventa AS PPV,        PrecioProveedor + PrecioProveedor*0.091 AS 'Precio IVA' FROM jardineria.Productos WHERE PrecioProveedor < PrecioProveedor + PrecioProveedor*0.091; |
| --- | --- |

Resumen

- Los **camps calculats** se realizan en el `SELECT` operando con los camps de las taules.

- `ORDER BY` ordena el resultado, con `ASC` o `DESC` (por defecto `ASC`).

- El **alias** con `AS` permet renombrar las columnes de la cabecera del resultado.
