## **Camps calculats**

En SQL podem **calcular camps** en la sentència del `SELECT` per a obtindre el resultat que cerquem. També podem utilitzar aquests camps calculats per a **filtrar els resultats** en el `WHERE`.

> **📌 Exemple**
> 

```sql
SELECT precioventa, PrecioProveedor + PrecioProveedor*0.091
FROM jardineria.Productos
WHERE PrecioProveedor < PrecioProveedor + PrecioProveedor*0.091;

SELECT precioventa, PrecioProveedor + PrecioProveedor*0.091
FROM jardineria.Productos;
```

## **Consultes ordenades**

Per a **ordenar el resultat** de les consultes farem ús de la clàusula **`ORDER BY`**. A més podem indicar el sentit de l'ordre: **`ASC`** (ascendent) o **`DESC`** (descendent). Si no indiquem res, per defecte serà `ASC`.

> **📌 Exemple**
> 

```sql
SELECT * FROM jardineria.Clientes ORDER BY NombreCliente ASC;
SELECT * FROM jardineria.Clientes ORDER BY NombreCliente DESC;
SELECT * FROM jardineria.Clientes ORDER BY NombreCliente;
```

## **Consultes amb capçalera (àlies)**

Si els resultats de les nostres consultes van a mostrar-se a altres persones, pot interesarnos **canviar els noms dels camps** perquè es entienda millor l'informe obtingut. Per a conseguir-lo crearem un **àlies** amb l'opció **`AS`** juntament amb el nou títol de la columna, normalment entre cometes simples.

> **📌 Exemple**
> 

```sql
SELECT precioventa AS PPV,
       PrecioProveedor + PrecioProveedor*0.091 AS 'Precio IVA'
FROM jardineria.Productos
WHERE PrecioProveedor < PrecioProveedor + PrecioProveedor*0.091;
```

> **📌 Resum**
> 

> - Els **camps calculats** es realitzen en el `SELECT` operant amb els camps de les taules.

> - `ORDER BY` ordena el resultat, amb `ASC` o `DESC` (per defecte `ASC`).

> - El **àlies** amb `AS` permet reanomenar les columnes de la capçalera del resultat.
