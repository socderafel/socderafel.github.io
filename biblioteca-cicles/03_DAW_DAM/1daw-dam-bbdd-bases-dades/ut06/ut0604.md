Quan la informació que necessitem per filtrar o calcular depèn del resultat d'una altra consulta prèvia, recorrem a les **subconsultes** (o consultes niades) i a les modernes **Expressions de Taula Comunes (CTEs - Common Table Expressions)** mitjançant la sentència `WITH`.

---

## 🎯 Tipus de Subconsultes

### 1. Subconsulta Escalar (Retorna un Únic Valor)
Es pot utilitzar en el `SELECT` o en el `WHERE`:
```sql
-- Productes amb un preu superior a la mitjana de tots els productes
SELECT nom, preu
FROM productes
WHERE preu > (SELECT AVG(preu) FROM productes);
```

### 2. Subconsulta de Conjunt (`IN`, `ANY`, `ALL`)
Retorna una llista d'una sola columna:
```sql
SELECT nom, email
FROM clients
WHERE id_client IN (
    SELECT DISTINCT id_client 
    FROM factures 
    WHERE data_factura >= '2026-01-01'
);
```

### 3. Predicats d'Existència (`EXISTS` / `NOT EXISTS`)
Avaluen si una subconsulta correlacionada retorna almenys una fila. Són altament eficients perquè s'aturen immediatament en trobar el primer registre:
```sql
SELECT c.nom
FROM clients c
WHERE NOT EXISTS (
    SELECT 1 
    FROM comandes co 
    WHERE co.id_client = c.id_client
);
```

## 🏗️ Expressions de Taula Comunes (CTEs amb `WITH`)

Introduïdes en l'estàndard SQL:1999, les CTEs permeten crear resultats intermedis amb nom, transformant consultes niades inintel·ligibles en codi net, modular i llegible de dalt a baix:

```sql
WITH vendes_per_client AS (
    SELECT 
        id_client, 
        SUM(import_total) AS total_gastat
    FROM comandes
    GROUP BY id_client
),
clients_vip AS (
    SELECT id_client
    FROM vendes_per_client
    WHERE total_gastat > 5000.00
)
SELECT c.nom, c.email, v.total_gastat
FROM clients c
INNER JOIN vendes_per_client v ON c.id_client = v.id_client
INNER JOIN clients_vip vip ON c.id_client = vip.id_client
ORDER BY v.total_gastat DESC;
```
