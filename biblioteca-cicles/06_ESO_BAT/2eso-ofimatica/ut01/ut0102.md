# 1.2 Teoria Internet1

🧭 Fitxa teòrica – Internet: Navegadors i Cercadors

### 1. Què és Internet?

Internet és una xarxa mundial de milions d’ordinadors connectats entre si. Permet intercanviar informació, comunicar-se i accedir a continguts com pàgines web, vídeos o correus electrònics.

### 2. La World Wide Web (WWW)

La Web és un dels serveis més coneguts d’Internet. Funciona amb pàgines web que s’identifiquen mitjançant una adreça o URL (Uniform Resource Locator). Exemple: https://www.wikipedia.org Cada pàgina està escrita en llenguatge HTML, i pot incloure text, imatges, vídeos o enllaços.

### 3. Què és un navegador web?

Un navegador web és un programa que ens permet veure i interactuar amb les pàgines web. Exemples

- Google Chrome
- Mozilla Firefox
- Microsoft Edge

Els navegadors interpreten el codi HTML i mostren el contingut de forma entenedora.

### 4. Què és un cercador web?

Un cercador web és una pàgina o servei que ens ajuda a buscar informació a Internet. Exemples

- Google
- Bing

- DuckDuckGo

Els cercadors indexen milions de pàgines web i ens mostren resultats quan escrivim una paraula clau. Diferència principal

- El navegador és el programa que utilitzem per connectar-nos a Internet.
- El cercador és la pàgina dins del navegador que utilitzem per buscar informació.

### 5. Elements principals d’un navegador

- Barra d’adreces: on s’escriu la URL o la cerca.
- Botons de navegació: arrere, avant, recarregar (refrescar).
- Pestanyes: permeten tindre diverses pàgines obertes.
- Marcadors o favorits: guarden pàgines que ens agraden.
- Historial: mostra les pàgines visitades.
- Descàrregues: mostra els fitxers descarregats.

### 6. Navegador Firefox

Firefox és un navegador lliure i gratuït. Alguns aspectes bàsics

- Refrescar una pàgina: botó circular o tecla F5. Afegir marcador: icona

d’estrella a la barra d’adreces.

- Veure historial: menú ☰ → “Historial”.
- Canviar carpeta de baixades

Menú ☰ → Configuració → Baixades → Preguntar on guardar cada fitxer.

- Tornar a pàgina anterior: fletxa esquerra.
- Buscar una paraula dins la pàgina: Ctrl + F.
