## 1.2 Teoria Internet1

🧭 Fitxa teòrica – Internet: Navegadors i Cercadors

### 1. Què és Internet?

Internet és una xarxa mundial de milions d’ordinadors connectats entre si. Permet intercanviar informació, comunicar-se i accedir a continguts com pàgines web, vídeos o correus electrònics.

### 2. La World Wide Web (WWW)

La Web és un dels serveis més coneguts d’Internet. Funciona amb pàgines web que s’identifiquen mitjançant una adreça o URL (Uniform Resource Locator). Exemple: https://www.wikipedia.org Cada pàgina està escrita en llenguatge HTML, i pot incloure text, imatges, vídeos o enllaços.

### 3. Què és un navegador web?

Un navegador web és un programa que ens permet veure i interactuar amb les pàgines web. Exemples

- Google Chrome
- Mozilla Firefox
- Microsoft Edge

Els navegadors interpreten el codi HTML i mostren el contingut de forma entenedora.

### 4. Què és un cercador web?

Un cercador web és una pàgina o servei que ens ajuda a buscar informació a Internet. Exemples

- Google
- Bing

- DuckDuckGo

Els cercadors indexen milions de pàgines web i ens mostren resultats quan escrivim una paraula clau. Diferència principal

- El navegador és el programa que utilitzem per connectar-nos a Internet.
- El cercador és la pàgina dins del navegador que utilitzem per buscar informació.

### 5. Elements principals d’un navegador

- Barra d’adreces: on s’escriu la URL o la cerca.
- Botons de navegació: arrere, avant, recarregar (refrescar).
- Pestanyes: permeten tindre diverses pàgines obertes.
- Marcadors o favorits: guarden pàgines que ens agraden.
- Historial: mostra les pàgines visitades.
- Descàrregues: mostra els fitxers descarregats.

### 6. Navegador Firefox

Firefox és un navegador lliure i gratuït. Alguns aspectes bàsics

- Refrescar una pàgina: botó circular o tecla F5. Afegir marcador: icona

d’estrella a la barra d’adreces.

- Veure historial: menú ☰ → “Historial”.
- Canviar carpeta de baixades

Menú ☰ → Configuració → Baixades → Preguntar on guardar cada fitxer.

- Tornar a pàgina anterior: fletxa esquerra.
- Buscar una paraula dins la pàgina: Ctrl + F.

## 1.3 Internet 2_ Com fer cerques

Com fer cerques en un cercador 1️⃣ Què és una cerca a Internet Quan volem trobar informació a Internet, utilitzem un cercador web com Google, Bing, DuckDuckGo o Ecosia. El cercador explora milions de pàgines i ens mostra les que més coincidixen amb les paraules que escrivim.

> **💡 Apunt Tècnic**
> Exemple: Si escrius 'animales más rápidos del mundo', el cercador buscarà pàgines on apareguen eixes paraules o temes semblants. 2️⃣ Què és una paraula clau Les paraules clau (keywords) són les més importants del que busques. No cal escriure frases llargues com si parlàrem amb una persona.

Exemple pràctic Mala cerca (massa llarga): “Quiero saber cuáles son los animales que viven en la selva tropical del Amazonas.” Problema: • Té moltes paraules innecessàries (“quiero saber”, “cuáles son”). • El cercador es confon i mostra resultats de tot tipus. Cerca millor (paraules clau): animales selva amazónica Resultat

• Mostra pàgines amb imatges, informació i noms d’animals de l’Amazones. • És més ràpida i precisa.

Altres exemples útils Cerca incorrecta Cerca correcta “Cómo puedo hacer un trabajo sobre el reciclaje en mi colegio” trabajo reciclaje alumnos “Dónde puedo encontrar información sobre las fases de la Luna” fases de la luna

Cerca incorrecta Cerca correcta “Me gustaría saber qué significa inteligencia artificial” inteligencia artificial significado “Quiero buscar recetas fáciles de cocina” recetas fáciles

3️⃣ Com millorar les cerques a Internet Els cercadors tenen trucs (anomenats operadors) que t’ajuden a trobar informació més ràpida, precisa i útil. Ací tens els més importants amb exemples que mostren la diferència: Truc / operador Per a què serveix Exemple sense operador Exemple amb operador Què canvia " " (cometes) Busca exactament una frase animales más rápidos del mundo "animales más rápidos del mundo" Resultats molt més concrets i rellevants – (guió) Exclou una paraula dels resultats jaguar → ixen cotxes i animals jaguar -coche → només animals Elimina resultats que no interessen site

Busca dins d’un web concret reciclaje → resultats de tot Internet reciclaje site:wikipedia.org → només articles de Wikipedia Filtra per un lloc web determinat filetype: Busca un tipus de fitxer específic energías renovables → pàgines web normals energías renovables filetype:pdf → només documents PDF Perfecte per trobar apunts, informes o treballs

- (asterisc)

Substitueix una paraula desconeguda “la * más alta del mundo” — Serveix per completar frases quan no recordes una paraula AND / OR Combina o alterna termes gatos perros → resultats barrejats gatos OR perros → pàgines sobre gatos o perros Millora la varietat o l’especificitat dels resultats

Activitat guiada per entendre-ho

- Escriu primer: jaguar i mira els primers resultats.
- Després escriu: jaguar -coche i compara.
- Descriu què ha canviat i per què.
- Repeteix amb 'energías renovables' i després 'energías renovables filetype:pdf'.

Conclusió: Fer servir operadors és com donar-li instruccions més clares al cercador. Així gastem menys temps, trobem fonts millors i aprenem a pensar com busquen els professionals.
