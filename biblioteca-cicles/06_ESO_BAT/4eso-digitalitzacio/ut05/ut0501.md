### 📊 2. ¿Qué son las bases de datos?

- Es un conjunto de datos pertenecientes a un mismo contexto y almacenados sistemáticamente para su posterior uso.
- Biblioteca
- Banco
- Universidad
- Proveedores empresa
- …
- https://www.youtube.com/watch?v=aU6LZ4gihsM

### 📊 3. Historia

- Origen
- X Espacio físico
- X Procesos lentos y laboriosos (copiar, buscar…)
- X Deterioro físico
- X etc
- Archivos digitales
- X Información repetida
- X Datos no concuerdan (inconsistencia)
- X Dispersión de datos
- X Difícil modificación y actualización

### 📊 4. Historia

- SOLUCIÓN
- Que todas las aplicaciones utilicen los mismos datos. Las bases de datos permiten almacenar grandes cantidades de datos relacionados y organizados de forma sistemática y garantiza su gestión.
- MODELO RELACIONAL!!
- V Redundancia mínima
- V Seguridad frente a usuarios malintencionados
- V Respaldo/recuperación mediante copias de seguridad
- V Eficiencia en el acceso de los datos

### 📊 5. SGBD

- ¿Qué es un SGBD?
- Un Sistema de Gestión de Bases de Datos es aquel que permite almacenar y posteriormente acceder a los datos de forma rápida y estructurada.
- Describe los datos, sus relaciones y condiciones de acceso e integridad
- Permite manipular los datos
- Controla la comunicación con la BD
- Realiza copias de seguridad
- Administra los usuarios y sus permisos

### 📊 6. SQL

- ¿Qué es SQL?
- SQL es un lenguaje estándar para la gestión de BD relacionales que se caracteriza por
- Es el lenguaje más usado por los SGBD
- Permite gestionar las BD
- Permite crear tablas
- Permite crear Relaciones
- Permite gestionar Datos
- Permite administrar usuarios

### 📊 8. Fases del diseño de una base de datos

- El diseño de una base de datos consiste en obtener una representación a partir del estudio de los elementos del mundo real
- No es un proceso sencillo por la complejidad de la información y la cantidad de requisitos.
- Es un proceso en fases en el que los resultados de una pasan como entradas a las siguientes.

### 📊 9. Fases de diseño

- Análisis de requerimientos
- Consiste en analizar un problema real
- Observar los elementos que participan
- Entrevistas y cuestionarios para averiguar los datos
- Revisar los documentos
- Diseño conceptual
- Obtiene el modelo conceptual. Estructura de la información de la futura BD.
- Independiente de la tecnología que se usará posteriormente

### 📊 10. Fases de diseño

- Diseño lógico
- Obtiene el modelo lógico
- Representa los datos en un formato más cercano al ordenador
- Orientado al modelo de base de datos elegido
- Fácilmente implementable
- Limita la posibilidad de tener datos incoherentes
- Diseño físico
- Busca conseguir mayor eficiencia
- Describe la forma en que se representarán los datos
- Implementación
- Crea la BD usando el SGBD seleccionado
