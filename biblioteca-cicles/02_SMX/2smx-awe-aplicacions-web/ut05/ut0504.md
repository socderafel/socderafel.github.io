El correu electrònic continua sent el canal de comunicació oficial per excel·lència a les institucions i corporacions. Un servei de **Webmail** és una aplicació web que actua com a client de correu al navegador, connectant-se als servidors de transferència de correu (**SMTP**) i de bústia remota (**IMAP**) sense necessitat d'instal·lar programari com Thunderbird o Outlook als equips clients.

---

## 1. Arquitectura d'un Sistema de Correu Web

```
[ NAVEGADOR DE L'USUARI ]
       │  Peticions HTTP / HTTPS
       v
[ SERVIDOR D'APLICACIONS WEB (Apache + PHP) ] ──> Roundcube Webmail
       │
       ├── Connexió IMAP segura (Port 993 / 143 STARTTLS) ──> [ SERVIDOR DE BÚSTIES (Dovecot) ]
       │   - Consulta bústia d'entrada, llegeix carpetes, marca com a llegit
       │
       └── Connexió SMTP segura (Port 587 / 465) ────────────> [ SERVIDOR DE TRANSPORT (Postfix) ]
           - Envia missatges i cartes a servidors de destinació
```

---

## 2. Roundcube Webmail: El Client de Codi Obert de Referència

**Roundcube** és el programari de webmail més utilitzat a entorns acadèmics i proveïdors de hosting pel seu disseny modern (*Elastic Skin*), rapidesa i seguretat:
- Interfície completa d'escriptori amb arrossegar i deixar anar (*drag & drop*) per a missatges i fitxers adjunts.
- Suport per a llibreta d'adreces compartida mitjançant LDAP o MariaDB.
- Gestió de múltiples identitats i signatures de correu en HTML ric.
- Integració de filtres automàtics del costat del servidor mitjançant el protocol **Sieve**.

---

## 3. Instal·lació i Configuració de Roundcube en Servidor Debian

1. Instal·lar els paquets de Roundcube i el suport per a MariaDB:
   ```bash
   sudo apt update
   sudo apt install -y roundcube roundcube-mysql roundcube-plugins
   ```
2. Configuració de connexió amb el servidor IMAP i SMTP local:
   A `/etc/roundcube/config.inc.php`:
   ```php
   // Connectar amb el servidor IMAP local
   $config['default_host'] = 'ssl://mail.iesrafael.local';
   $config['default_port'] = 993;

   // Servidor SMTP per a enviaments
   $config['smtp_server'] = 'tls://mail.iesrafael.local';
   $config['smtp_port'] = 587;
   $config['smtp_user'] = '%u';
   $config['smtp_pass'] = '%p';

   // Idioma per defecte
   $config['language'] = 'ca_ES';
   ```

3. Integració al servidor Apache mitjançant alias web:
   ```apache
   Alias /webmail /var/lib/roundcube/public_html
   ```
   L'alumnat i professorat pot entrar directament des de `http://correu.iesrafael.local/webmail`.

---

## 4. Regles de Filtratge amb Sieve

El protocol **Sieve** permet a l'usuari programar regles d'organització directa a la bústia que s'executen al servidor fins i tot quan el navegador està tancat:
- Desplaçar automàticament correus que contenen *"Aules"* a la carpeta *Docència*.
- Reenviar automàticament comunicats oficials a un altre compte.
- Configurar respostes automàtiques de vacances (*Out of Office*).
