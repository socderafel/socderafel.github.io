El desplegament d'**ONLYOFFICE Document Server** ofereix una suite ofimàtica completa al núvol corporatiu. Donada la seua arquitectura de múltiples serveis (Node.js, PostgreSQL, RabbitMQ i fonts tipogràfiques), el mètode de desplegament professional més estès és mitjançant contenidors **Docker** o a través del seu repositori oficial de paquets Debian.

---

## 1. Desplegament Mitjançant Contenidor Docker

El desplegament aïllat amb Docker garanteix que les dependències no col·lisionen amb la pila LAMP del servidor principal:

```bash
# 1. Executar el contenidor d'ONLYOFFICE amb el port mapejat i un secret JWT definit
sudo docker run -i -t -d -p 8080:80 --restart always     --name onlyoffice-server     -e JWT_ENABLED=true     -e JWT_SECRET="ClauMoltSecretaJWT#2026"     -v /app/onlyoffice/DocumentServer/data:/var/www/onlyoffice/Data     -v /app/onlyoffice/DocumentServer/logs:/var/log/onlyoffice     onlyoffice/documentserver:latest
```

Paràmetres clau:
- `-p 8080:80`: Mapeja el port intern HTTP 80 del contenidor al port 8080 de la màquina host.
- `-e JWT_ENABLED=true`: Activa obligatòriament la signatura segura de comunicacions.
- `-e JWT_SECRET`: Clau secreta que s'haurà de configurar de manera idèntica a l'aplicació client (Nextcloud).
- `-v ...`: Volums de persistència per a registres i dades de llicència.

---

## 2. Configuració del Virtual Host amb Proxy Invers a Apache

Perquè el servei siga accessible de manera segura per HTTPS i sense indicar números de port a la URL:

```apache
<VirtualHost *:80>
    ServerName office.iesrafael.local

    ProxyPreserveHost On
    ProxyPass / http://127.0.0.1:8080/
    ProxyPassReverse / http://127.0.0.1:8080/

    # Suport obligatori per a WebSockets (canvis en temps real)
    RewriteEngine on
    RewriteCond %{HTTP:Upgrade} websocket [NC]
    RewriteCond %{HTTP:Connection} upgrade [NC]
    RewriteRule ^/?(.*) "ws://127.0.0.1:8080/$1" [P,L]

    ErrorLog ${APACHE_LOG_DIR}/onlyoffice_error.log
</VirtualHost>
```

Habilitar els mòduls de proxy a Apache:
```bash
sudo a2enmod proxy proxy_http proxy_wstunnel rewrite
sudo a2ensite onlyoffice.conf
sudo systemctl restart apache2
```

---

## 3. Connectant ONLYOFFICE amb Nextcloud

Un cop el servidor de documents està actiu:
1. Al tauler de Nextcloud, instal·lar l'aplicació oficial **ONLYOFFICE** des de la botiga d'aplicacions.
2. Anar a **Ajustos d'administració ➔ ONLYOFFICE**.
3. Omplir els camps de connexió:
   - **Adreça del servei d'edició de documents:** `http://office.iesrafael.local/`
   - **Clau secreta (Secret JWT):** `ClauMoltSecretaJWT#2026`
4. Fer clic a **Desa**. Si la configuració és correcta, apareixerà un missatge verd de confirmació i la llista de formats d'arxiu associats (`DOCX`, `XLSX`, `PPTX`, `ODT`).

```
[ Usuari a l'IES ] ──> Clica "Projecte_Final.docx" a Nextcloud
                            │
                            v
[ Nextcloud ] ──── Sol·licitud JWT ────> [ ONLYOFFICE Proxy ]
                            │
                            v
[ Pantalla ] <──── Editor Word complet al navegador en temps real!
```
