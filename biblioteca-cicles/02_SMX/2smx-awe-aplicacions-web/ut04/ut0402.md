A causa de la intensa transferència d'arxius, càlcul de hashes de seguretat i sincronització concurrent de desenes de dispositius mòbils, el servidor Nextcloud requereix una configuració de servei d'alt rendiment que combina Apache, PHP 8.x i un motor de memòria cau en memòria RAM com **Redis**.

---

## 1. Requeriments i Instal·lació de Dependències

A Debian/Ubuntu, instal·lem els mòduls específics que Nextcloud necessita per a generar miniatures d'imatges, xifrar fitxers i gestionar la memòria cau:

```bash
sudo apt update
sudo apt install -y apache2 mariadb-server redis-server     php php-cli php-mysql php-curl php-gd php-mbstring php-xml php-zip     php-intl php-bcmath php-gmp php-imagick php-redis libapache2-mod-php
```

Habilitem els mòduls necessaris d'Apache:
```bash
sudo a2enmod rewrite headers env dir mime ssl
sudo systemctl restart apache2
```

---

## 2. Preparació de la Base de Dades MariaDB

```sql
CREATE DATABASE nextcloud CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'nc_admin'@'localhost' IDENTIFIED BY 'NextcloudClau#2026!';
GRANT ALL PRIVILEGES ON nextcloud.* TO 'nc_admin'@'localhost';
FLUSH PRIVILEGES;
```

---

## 3. Desplegament del Codi Font i Directori de Dades

Descarreguem l'arxiu oficial de Nextcloud:

```bash
wget https://download.nextcloud.com/server/releases/latest.tar.bz2 -P /tmp
sudo tar -xvjf /tmp/latest.tar.bz2 -C /var/www/

# Crear el directori de dades fora de la publicació web
sudo mkdir -p /var/nextcloud-data

# Ajustar propietat a www-data
sudo chown -R www-data:www-data /var/www/nextcloud /var/nextcloud-data
sudo chmod -R 750 /var/nextcloud-data
```

---

## 4. Configuració del Virtual Host a Apache

Creem `/etc/apache2/sites-available/nextcloud.conf`:

```apache
<VirtualHost *:80>
    ServerName nuvol.iesrafael.local
    DocumentRoot /var/www/nextcloud

    <Directory /var/www/nextcloud>
        Require all granted
        AllowOverride All
        Options FollowSymLinks MultiViews

        <IfModule mod_dav.c>
            Dav off
        </IfModule>
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/nextcloud_error.log
    CustomLog ${APACHE_LOG_DIR}/nextcloud_access.log combined
</VirtualHost>
```

> [!IMPORTANT]
> La directiva `Dav off` és imprescindible perquè Apache no intente processar les peticions WebDAV natives mitjançant el seu propi mòdul `mod_dav`, permetent que siga el codi intern de Nextcloud qui gestione el protocol WebDAV.

---

## 5. Integració de Redis per a Bloqueig Transaccional de Fitxers (*File Locking*)

Quan dos dispositius sincronitzen o editen el mateix fitxer a la vegada, es podria produir una condició de carrera o corrupció de dades. **Redis** gestiona aquests bloquejos a la memòria RAM a velocitats de microsegons.

A `/var/www/nextcloud/config/config.php` s'afegeix:

```php
  'memcache.local' => '\OC\Memcache\APCu',
  'memcache.distributed' => '\OC\Memcache\Redis',
  'memcache.locking' => '\OC\Memcache\Redis',
  'redis' => [
    'host' => '127.0.0.1',
    'port' => 6379,
    'timeout' => 0.0,
  ],
```
