Nextcloud és una plataforma modular extensible mitjançant la seua botiga d'aplicacions integrada (*Nextcloud App Store*). No obstant això, per a un tècnic de sistemes, el cor de l'administració diària, el manteniment de bases de dades i les migracions de seguretat resideix en la consola amb la potent comanda **`occ`** (*ownCloud/Nextcloud Console*).

---

## 1. L'Ecosistema d'Aplicacions Oficials de Nextcloud

| Aplicació | Descripció Funcional | Àmbit d'Aplicació |
| :--- | :--- | :--- |
| **Deck** | Gestor de projectes basat en taulers Kanban (a l'estil de Trello). Permet organitzar tasques en columnes, assignar responsables i fixar terminis. | Gestió de projectes d'equip i coordinació docent |
| **Calendar** | Calendari CalDAV corporatiu amb compartició d'esdeveniments entre grups i reserves de sales o recursos (ex: carrets de portàtils). | Gestió d'horaris de centre |
| **Contacts** | Llibreta d'adreces CardDAV accessible des de telèfons intel·ligents i aplicacions de correu com Thunderbird. | Llibreta d'adreces corporativa |
| **Two-Factor Authentication** | Força l'autenticació multifactor mitjançant codis TOTP temporals per a tots els administradors i usuaris. | Enduriment de seguretat (Hardening) |

---

## 2. Què és la Comanda `occ` i Com s'Executa?

El fitxer executable `occ` es troba a l'arrel de Nextcloud (`/var/www/nextcloud/occ`). Com que és un script de PHP que modifica bases de dades i arxius del sistema, **ha d'executar-se sempre com l'usuari `www-data`**:

```bash
# Sintaxi bàsica d'execució:
sudo -u www-data php /var/www/nextcloud/occ <comanda> [arguments]
```

---

## 3. Comandes `occ` Crítiques per a l'Administrador de Sistemes

### A. Estat del Sistema i Mode de Manteniment
```bash
# Comprovar l'estat i versió de la instal·lació
sudo -u www-data php /var/www/nextcloud/occ status

# Activar el mode manteniment (abans d'actualitzar o fer backups de seguretat)
sudo -u www-data php /var/www/nextcloud/occ maintenance:mode --on

# Desactivar el mode manteniment
sudo -u www-data php /var/www/nextcloud/occ maintenance:mode --off
```

### B. Indexació i Resolució d'Arxius Modificats per Fora (`files:scan`)
Si un administrador copia fitxers directament a la carpeta de dades mitjançant la terminal o SCP, Nextcloud no els mostrarà a la interfície web perquè no estan registrats a la taula de la base de dades. Cal forçar un reescaneig:
```bash
# Escanejar tots els fitxers de tots els usuaris
sudo -u www-data php /var/www/nextcloud/occ files:scan --all

# Escanejar únicament la carpeta d'un usuari específic
sudo -u www-data php /var/www/nextcloud/occ files:scan professor1
```

### C. Manteniment i Optimització de la Base de Dades
Després d'una actualització major, és habitual que Nextcloud avise d'índexs o columnes pendents:
```bash
# Afegir índexs que falten per accelerar consultes
sudo -u www-data php /var/www/nextcloud/occ db:add-missing-indices

# Convertir columnes a bigint per suportar volums massius
sudo -u www-data php /var/www/nextcloud/occ db:convert-filecache-bigint
```

### D. Gestió d'Aplicacions per Consola
```bash
# Llistar aplicacions habilitades i disponibles
sudo -u www-data php /var/www/nextcloud/occ app:list

# Instal·lar i habilitar l'aplicació Deck per consola
sudo -u www-data php /var/www/nextcloud/occ app:install deck
sudo -u www-data php /var/www/nextcloud/occ app:enable deck
```

## 4. Automatització del Cron de Nextcloud

De manera idèntica a Moodle, Nextcloud requereix que el cron del sistema operatiu execute tasques cada 5 minuts (neteja de carpetes temporals, càlcul de quotes i notificacions):

1. A **Ajustos ➔ Ajustos bàsics ➔ Tasques de fons**, seleccionar **Cron (Recomanat)**.
2. Programar al crontab de `www-data`:
   ```bash
   sudo crontab -u www-data -e
   ```
   Afegir:
   ```cron
   */5 * * * * php -f /var/www/nextcloud/cron.php > /dev/null 2>&1
   ```
