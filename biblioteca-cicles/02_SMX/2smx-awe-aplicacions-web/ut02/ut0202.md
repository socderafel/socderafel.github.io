El procés d'instal·lació d'un CMS corporatiu com WordPress en un servidor dedicat o VPS requereix quatre fases seqüencials: preparació de la base de dades, descàrrega dels fitxers font, configuració del servidor web (Virtual Host i reescriptura d'adreces) i assignació estricta de permisos al sistema de fitxers.

---

## 1. Creació de la Base de Dades i l'Usuari MariaDB

Per raons de seguretat, **mai** s'ha d'utilitzar l'usuari `root` de la base de dades per a connectar WordPress. Creem una base de dades dedicada i un usuari amb privilegis acotats exclusivament a aquesta base de dades:

```bash
sudo mariadb -u root -p
```

Dins de la consola de MariaDB:
```sql
-- 1. Crear la base de dades amb joc de caràcters recomanat
CREATE DATABASE wp_iesrafael CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. Crear l'usuari amb accés exclusiu des de la màquina local
CREATE USER 'wp_user'@'localhost' IDENTIFIED BY 'WpSecretKey#2026';

-- 3. Concedir privilegis totals únicament sobre la base de dades de WordPress
GRANT ALL PRIVILEGES ON wp_iesrafael.* TO 'wp_user'@'localhost';

-- 4. Recarregar la taula de privilegis
FLUSH PRIVILEGES;
EXIT;
```

---

## 2. Descàrrega i Desplegament del Codi Font

Descarreguem la darrera versió oficial en català/valencià o internacional des del repositori de WordPress:

```bash
# Descarregar el paquet comprimit oficial
wget https://wordpress.org/latest.tar.gz -P /tmp

# Extreure en el directori de publicació web
sudo tar -xvzf /tmp/latest.tar.gz -C /var/www/

# Renombrar la carpeta segons el nom del projecte
sudo mv /var/www/wordpress /var/www/portal-wordpress
```

---

## 3. Configuració del Virtual Host a Apache2

Creem un fitxer de configuració de Virtual Host dedicat a `/etc/apache2/sites-available/wordpress.conf`:

```apache
<VirtualHost *:80>
    ServerName portal.iesrafael.local
    ServerAdmin webmaster@iesrafael.local
    DocumentRoot /var/www/portal-wordpress

    <Directory /var/www/portal-wordpress>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/wordpress_error.log
    CustomLog ${APACHE_LOG_DIR}/wordpress_access.log combined
</VirtualHost>
```

> [!IMPORTANT]
> La directiva `AllowOverride All` és estrictament obligatòria. Si no s'activa, Apache ignorarà el fitxer `.htaccess` de WordPress i les URLs amigables (*Permalinks*) retornaran un error HTTP 404 Not Found.

Activem el lloc web i recarreguem la configuració:
```bash
sudo a2ensite wordpress.conf
sudo a2enmod rewrite
sudo systemctl reload apache2
```

## 4. Política de Permisos i Propietat POSIX

Una mala gestió de permisos és la causa del 90% dels problemes d'actualització o atacs de defacing web:

1. **Usuari propietari:** En entorns Debian/Ubuntu, el servidor Apache s'executa sota l'usuari `www-data` i el grup `www-data`. Assignem la propietat completa del directori:
   ```bash
   sudo chown -R www-data:www-data /var/www/portal-wordpress
   ```
2. **Permisos de directoris i fitxers:**
   - Els directoris han de tenir permisos `755` (`rwxr-xr-x`): l'usuari pot escriure i entrar, la resta només llegir i executar.
   - Els fitxers han de tenir permisos `644` (`rw-r--r--`): lectura i escriptura per al propietari, només lectura per a la resta.
   ```bash
   # Aplicar 755 a totes les carpetes de manera recursiva
   sudo find /var/www/portal-wordpress/ -type d -exec chmod 755 {} \;

   # Aplicar 644 a tots els fitxers de manera recursiva
   sudo find /var/www/portal-wordpress/ -type f -exec chmod 644 {} \;
   ```
3. **Hardening de `wp-config.php`:** Aquest fitxer conté les claus i contrasenyes de la base de dades. Convé assignar-li permisos `600` o `640` perquè altres usuaris locals sense privilegis no el puguen llegir:
   ```bash
   sudo chmod 640 /var/www/portal-wordpress/wp-config.php
   ```

---

## 5. L'Assistent Web d'Instal·lació (5-Minute Install)

Un cop resolta la infraestructura, s'accedeix via navegador a `http://portal.iesrafael.local`:
1. **Selecció d'idioma:** Valencià / Català.
2. **Formulari de base de dades:**
   - Nom de la BD: `wp_iesrafael`
   - Usuari: `wp_user`
   - Contrasenya: `WpSecretKey#2026`
   - Amfitrió: `localhost`
   - Prefix de les taules: Modificar el valor per defecte `wp_` per una cadena aleatòria com `ies_`.
3. **Configuració del lloc:**
   - Títol del lloc: *Portal d'Informàtica IES*
   - Nom d'usuari de l'administrador: Triar un nom propi (mai utilitzar `admin` ni `administrator`).
   - Contrasenya segura i correu de contacte.
