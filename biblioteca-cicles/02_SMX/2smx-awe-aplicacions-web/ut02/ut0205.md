Els **connectors (*plugins*)** permeten estendre les funcionalitats de WordPress fins a convertir-lo en una botiga virtual (WooCommerce), una intranet docent o un portal multilingüe. No obstant això, en l'administració de servidors professionals, la interfície web resulta lenta o inviable quan cal automatitzar tasques en desenes de màquines; ací és on entra en joc la potent eina de línia d'ordres **WP-CLI**.

---

## 1. Categories de Connectors Essencials

| Categoria | Connectors de Referència | Funció Tècnica Principal |
| :--- | :--- | :--- |
| **Seguretat** | Wordfence Security, iThemes Security | Tallafocs a nivell d'aplicació (WAF), detecció de fitxers modificats, bloqueig d'atacs de força bruta |
| **Còpies de Seguretat** | UpdraftPlus, Duplicator | Automatització de còpies de seguretat de fitxers i base de dades amb enviament programat a núvols externs (S3, Google Drive, Nextcloud) |
| **Optimització i Memòria Cau** | LiteSpeed Cache, WP Super Cache, Redis Object Cache | Generació de fitxers HTML estàtics i memòria cau d'objectes en RAM per reduir consultes a MariaDB |
| **Formularis i Contacte** | Fluent Forms, WPForms, Contact Form 7 | Processament segur de missatges amb protecció anti-SPAM (Honeypot, reCAPTCHA v3) |
| **SEO i Metadades** | Yoast SEO, Rank Math | Generació automàtica del mapa del lloc XML (`sitemap.xml`) i etiquetatge OpenGraph per a xarxes socials |

> [!WARNING]
> La proliferació incontrolada de connectors és la causa número u de vulnerabilitats i lentitud a WordPress. Regla d'or d'un tècnic SMX: instal·lar exclusivament connectors mantinguts activament, amb altes valoracions i compatibles amb la versió vigent de PHP.

## 2. Què és WP-CLI?

**WP-CLI** és la interfície de línia d'ordres oficial per a WordPress. Permet als administradors de sistemes actualitzar el nucli, gestionar usuaris, instal·lar connectors, generar còpies de seguretat de la base de dades i executar cerques i reemplaçaments massius sense obrir el navegador.

### Instal·lació de WP-CLI en Servidor Linux:
```bash
# 1. Descarregar l'executable PHAR
curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar

# 2. Comprovar que funciona
php wp-cli.phar --info

# 3. Donar permisos d'execució i moure a la ruta global del sistema
chmod +x wp-cli.phar
sudo mv wp-cli.phar /usr/local/bin/wp

# 4. Verificar la comanda global
wp --info
```

## 3. Gestió de WordPress mitjançant Comandes `wp`

Per executar comandes `wp` en una instal·lació concreta, cal situar-se al directori de WordPress o afegir el paràmetre `--path=/var/www/portal-wordpress`. A més, per evitar problemes de permisos de fitxers, s'ha d'executar com l'usuari del servidor web (`www-data`):

### A. Estat del Sistema i Actualitzacions
```bash
# Comprovar la versió de WordPress instal·lada
sudo -u www-data wp core version --path=/var/www/portal-wordpress

# Actualitzar el nucli de WordPress a l'última versió
sudo -u www-data wp core update --path=/var/www/portal-wordpress

# Actualitzar la base de dades després d'un canvi de versió
sudo -u www-data wp core update-db --path=/var/www/portal-wordpress
```

### B. Gestió de Connectors (*Plugins*)
```bash
# Llistar tots els connectors instal·lats i el seu estat
sudo -u www-data wp plugin list --path=/var/www/portal-wordpress

# Instal·lar i activar el connector UpdraftPlus des del repositori oficial
sudo -u www-data wp plugin install updraftplus --activate --path=/var/www/portal-wordpress

# Actualitzar tots els connectors de cop
sudo -u www-data wp plugin update --all --path=/var/www/portal-wordpress

# Desactivar un connector amb errors que bloqueja el tauler web
sudo -u www-data wp plugin deactivate problematic-plugin --path=/var/www/portal-wordpress
```

### C. Gestió d'Usuaris
```bash
# Llistar els usuaris registrats i els seus rols
sudo -u www-data wp user list --path=/var/www/portal-wordpress

# Crear un nou usuari Administrador de recuperació d'emergència
sudo -u www-data wp user create admin_aux auxiliartir@ies.local --role=administrator --user_pass="SuperSecret#2026" --path=/var/www/portal-wordpress
```

### D. Operacions de Base de Dades i Còpies de Seguretat
```bash
# Exportar una còpia completa de la BD en format SQL
sudo -u www-data wp db export /var/backups/wp_backup_$(date +%F).sql --path=/var/www/portal-wordpress

# Reemplaçament massiu d'URL (indispensable en migracions de domini HTTP a HTTPS)
sudo -u www-data wp search-replace 'http://iesrafael.local' 'https://iesrafael.local' --path=/var/www/portal-wordpress
```

## 4. Automatització de Manteniment amb Cron de Linux

En lloc de dependre del fitxer intern `wp-cron.php` (que només s'executa quan un usuari visita una pàgina), es recomana delegar les tasques al dimoni `cron` del sistema operatiu per a garantir l'execució puntual d'actualitzacions i còpies:

1. Desactivar el cron virtual a `wp-config.php`:
   ```php
   define( 'DISABLE_WP_CRON', true );
   ```
2. Programar l'execució cada 15 minuts en el crontab de l'usuari `www-data`:
   ```bash
   sudo crontab -u www-data -e
   ```
   Afegir la línia:
   ```cron
   */15 * * * * wp cron event run --due-now --path=/var/www/portal-wordpress > /dev/null 2>&1
   ```
