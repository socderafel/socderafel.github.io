El servidor HTTP **Apache (Apache2)** és el servidor web de codi obert més consolidat de la història d'internet. La seua robustesa, arquitectura modular i suport d'allotjament múltiple el converteixen en la base de la pila tecnològica **LAMP (Linux, Apache, MySQL/MariaDB, PHP)**.

Com a administradors de sistemes en SMX, saber instal·lar el servei en servidors Linux (com Ubuntu Server 24.04 LTS), configurar el directori arrel de publicació i gestionar dominis virtuals és una habilitat fonamental.

---

## 1. Instal·lació i Gestió del Servei Apache2 en Ubuntu Server

La instal·lació en sistemes basats en Debian/Ubuntu es realitza a través del gestor de paquets `apt`:

```bash
# Actualitzar repositoris i instal·lar Apache2
sudo apt update && sudo apt install -y apache2

# Comprovar l'estat del servei
sudo systemctl status apache2

# Habilitar l'arrancada automàtica en iniciar el servidor
sudo systemctl enable apache2

# Permetre el trànsit al tallafocs UFW
sudo ufw allow in "Apache Full"
```

El directori arrel per defecte on es col·loquen els fitxers públics és `/var/www/html/`. El fitxer principal de configuració és `/etc/apache2/apache2.conf`.

---

## 2. Allotjament Múltiple: Amfitrions Virtuals (Virtual Hosts)

Un únic servidor físic amb una sola adreça IP pública pot allotjar desenes de llocs web independents (ex: `www.iesrafel.es` i `tenda.iesrafel.es`) mitjançant els **Virtual Hosts basats en nom**:

```apache
# Fitxer: /etc/apache2/sites-available/portal.conf
<VirtualHost *:80>
    ServerName portal.iesrafel.es
    ServerAdmin admin@iesrafel.es
    DocumentRoot /var/www/portal
    
    <Directory /var/www/portal>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/portal_error.log
    CustomLog ${APACHE_LOG_DIR}/portal_access.log combined
</VirtualHost>
```

### Activació del Lloc Web i Recàrrega
```bash
# Crear el directori i assignar propietari a l'usuari www-data
sudo mkdir -p /var/www/portal
sudo chown -R www-data:www-data /var/www/portal

# Habilitar el lloc web i recarregar Apache
sudo a2ensite portal.conf
sudo systemctl reload apache2
```
