Tot i que la terminal és l'eina nativa de qualsevol administrador de sistemes, en entorns de desenvolupament i gestió diària és molt útil comptar amb una interfície web visual. **phpMyAdmin** és l'eina gràfica basada en web més popular per a administrar servidors MySQL i MariaDB a través del navegador.

No obstant això, com que és una eina conegudíssima, és un dels **blancs favorits dels atacs automatitzats (bots)** que rastregen internet buscant rutes públiques `/phpmyadmin` per a llançar atacs de força bruta. Per això, la seua instal·lació exigeix mesures estrictes d'assegurament.

---

## 1. Instal·lació de phpMyAdmin en Ubuntu Server

La instal·lació oficial s'integra directament amb Apache:

```bash
sudo apt install -y phpmyadmin
```
Durant l'assistent de configuració:
1. Triar el servidor web: marcar **`[X] apache2`** prement la barra espaiadora.
2. Configurar la base de dades amb `dbconfig-common`: seleccionar **`Sí`** i assignar una contrasenya interna per a l'usuari del sistema `phpmyadmin`.

---

## 2. Hardening i Seguretat en la Configuració de phpMyAdmin

1. **Canviar l'àlies per defecte (Ofuscació de ruta):**
   Els bots cerquen sempre `http://ip-servidor/phpmyadmin`. Modificant el fitxer `/etc/phpmyadmin/apache.conf`:
   ```apache
   # Substituir la línia Alias /phpmyadmin per una ruta secreta
   Alias /gestio_bbdd_secreta /usr/share/phpmyadmin
   ```
2. **Afegir una segona capa d'autenticació HTTP bàsica (.htaccess):**
   Forçar que l'usuari haja d'introduir un usuari i contrasenya a nivell de servidor web mitjançant `htpasswd` abans de poder ni tan sols veure la pantalla d'inici de sessió de phpMyAdmin.
3. **Bloqueig de l'usuari root per web:** Configurar phpMyAdmin perquè rebutge terminantment connexions amb l'usuari `root`, forçant l'ús de comptes amb privilegis delegats.
