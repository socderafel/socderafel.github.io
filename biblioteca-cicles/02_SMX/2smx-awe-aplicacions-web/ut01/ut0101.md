Una **aplicació web** és un programari distribuït que s'executa en un servidor remot i al qual els usuaris accedeixen a través de la xarxa mitjançant un navegador web (client lleuger). A diferència de les aplicacions d'escriptori clàssiques, les aplicacions web no requereixen instal·lació al terminal del client, faciliten les actualitzacions centralitzades i permeten l'accés des de qualsevol plataforma (Windows, Linux, mòbils).

---

## 1. El Model d'Arquitectura de 3 Capes (Three-Tier Architecture)

L'estàndard arquitectònic de les aplicacions web empresarials és el desacoblament en tres capes independents:

```
[ CAPA 1: PRESENTACIÓ (Client / Frontend) ]
Navegador Web (Chrome, Firefox, Safari)
- Interpreta HTML5 (estructura), CSS3 (estil visual) i JavaScript (interactivitat).
- Envia peticions HTTP/HTTPS i renderitza la interfície d'usuari.
                   |  Peticions HTTP GET / POST (Port 80 / 443)
                   v
[ CAPA 2: LÒGICA DE NEGOCI (Servidor d'Aplicacions / Backend) ]
Servidor Web (Apache / Nginx) + Intèrpret (PHP, Python, Node.js)
- Rep la petició, comprova l'autenticació de la sessió i executa el codi del CMS.
- Genera dinàmicament la resposta HTML o JSON.
                   |  Connexió TCP SQL (Port 3306)
                   v
[ CAPA 3: PERSISTÈNCIA DE DADES (Base de Dades / Backend) ]
SGBD Relacional (MariaDB / MySQL / PostgreSQL)
- Emmagatzema taules d'usuaris, entrades de blog, comandes i configuracions.
- Executa consultes SQL i retorna els conjunts de registres a la Capa 2.
```

---

## 2. El Protocol HTTP i la Transició a HTTPS

El protocol de transferència d'hipertext (**HTTP - HyperText Transfer Protocol**) funciona sobre el protocol de transport TCP:
- **Port 80 (HTTP):** Trànsit en text pla sense xifrar. Si un atacant intercepta el trànsit de xarxa (sniffing), pot llegir usuaris, contrasenyes i dades bancàries.
- **Port 443 (HTTPS - HTTP Secure):** El trànsit s'encapsula dins d'un túnel xifrat mitjançant **TLS (Transport Layer Security)**. Garanteix confidencialitat (ningú pot llegir les dades) i integritat (les dades no es poden alterar en trànsit).

### Mètodes HTTP Fonamentals
- **`GET`:** Sol·licita un recurs al servidor (una pàgina, una imatge). Els paràmetres viatgen visibles a la mateixa URL (`index.php?id=5`).
- **`POST`:** Envia dades des d'un formulari web per a ser processades (crear un usuari, pujar un fitxer). Les dades viatgen ocultes al cos del missatge (*Body*).
