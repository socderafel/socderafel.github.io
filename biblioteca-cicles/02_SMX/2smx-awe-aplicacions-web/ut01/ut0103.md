Apache per si sol només és capaç de servir fitxers estàtics (pàgines HTML planes, imatges, fulls d'estil CSS). Perquè una aplicació web com **WordPress, Moodle o Nextcloud** puga processar codi lògic, consultar una base de dades i generar pàgines al vol, el servidor web necessita un intèrpret de backend: **PHP (Hypertext Preprocessor)**.

---

## 1. Instal·lació de PHP i Mòduls Crítics per a Gestors de Continguts

En instal·lar PHP, cal instal·lar tant el mòdul d'integració amb Apache (`libapache2-mod-php`) com una bateria de biblioteques d'extensió que els CMS exigeixen obligatòriament:

```bash
# Instal·lació de PHP 8.x i extensions bàsiques
sudo apt install -y php libapache2-mod-php php-mysql php-curl php-gd php-xml php-mbstring php-zip php-intl php-soap
```

### Què Fa Cada Mòdul?
- `php-mysql`: Proporciona els controladors PDO i MySQLi per a connectar PHP amb bases de dades MariaDB/MySQL.
- `php-gd`: Biblioteca gràfica per a redimensionar i retallar fotografies pujades per usuaris (avatars, miniatures).
- `php-curl`: Permet que el servidor faça peticions HTTP a altres servidors externs (comprovar actualitzacions de plugins).
- `php-zip`: Permet descomprimir fitxers d'instal·lació de plantilles i extensions al vol.
- `php-mbstring`: Suport per a cadenes de text multibyte en caràcters UTF-8 internacionals i accents en valencià.

---

## 2. Paràmetres Crítics de Configuració al fitxer `php.ini`

El fitxer de configuració mestre de PHP se sol situar a `/etc/php/8.3/apache2/php.ini`. Per defecte, PHP ve configurat amb paràmetres molt restrictius que impedeixen pujar fitxers grans o instal·lar plataformes com Moodle:

```ini
; Límit de memòria RAM que pot consumir un script (imprescindible per a Moodle)
memory_limit = 512M

; Mida màxima permesa d'un fitxer pujat a través d'un formulari web
upload_max_filesize = 64M

; Mida màxima total de la petició POST (ha de ser major que upload_max_filesize)
post_max_size = 80M

; Temps màxim d'execució d'un script abans que el servidor el mate (en segons)
max_execution_time = 300

; Zona horària del servidor
date.timezone = Europe/Madrid
```

> **⚠️ REGLA D'OR:** Sempre que es modifique el fitxer `php.ini`, cal reiniciar el servei d'Apache amb `sudo systemctl restart apache2` perquè els canvis tinguen efecte en el servidor.
