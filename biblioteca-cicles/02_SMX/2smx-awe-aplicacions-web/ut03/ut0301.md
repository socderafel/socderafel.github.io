Un **LMS** (*Learning Management System* o Sistema de Gestió d'Aprenentatge) és una plataforma web especialitzada en la distribució de cursos en línia, administració de continguts docents, seguiment de l'alumnat i avaluació acadèmica. **Moodle** (*Modular Object-Oriented Dynamic Learning Environment*) és la plataforma de programari lliure de referència a l'educació pública valenciana (base de la plataforma Aules de la Conselleria d'Educació).

---

## 1. El Desacoblament de Seguretat: Codi Font vs Directori de Dades

L'arquitectura de fitxers de Moodle es basa en una separació estricta entre el programari públic accessible pel navegador i el magatzem d'arxius confidencials:

```
[ ARREL DEL SERVIDOR WEB ] ──> /var/www/html/moodle/ (Accessible via HTTP)
├── index.php, config.php, admin/, course/, mod/, theme/
│
[ DIRECTORI DE DADES PRIVAT ] ──> /var/moodledata/ (PROHIBIT L'ACCÉS HTTP!)
├── filedir/      # Fitxers reals (PDFs de tasques, imatges) anomenats per hash SHA-1
├── trashdir/     # Paperera temporal de fitxers
├── temp/         # Fitxers de càrrega i descompressió
├── cache/        # Memòria cau de cadenes d'idioma i temes
└── sessions/     # Sessions d'usuaris (si no s'utilitza Redis)
```

> [!CAUTION]
> El directori **`moodledata` MAI s'ha d'ubicar dins de l'arrel de publicació web** (com ara `/var/www/html/moodle/moodledata`). Si un atacant poguera descarregar directament arxius de `moodledata` a través del navegador, accediria als exàmens, dades personals de l'alumnat i còpies de seguretat sense autenticar-se.

## 2. Requeriments de Programari per a Moodle 4.x

| Component | Requisit Mínim | Paràmetres Crítics de Configuració |
| :--- | :--- | :--- |
| **Servidor Web** | Apache 2.4 o Nginx | Apache amb mòduls `rewrite` i `headers` actius |
| **Intèrpret PHP** | PHP 8.1 o 8.2 | Extensions: `php-mysqli`, `php-xml`, `php-gd`, `php-curl`, `php-zip`, `php-intl`, `php-mbstring`, `php-soap`, `php-opcache` |
| **Base de Dades** | MariaDB 10.6+ o MySQL 8.0+ | Motor de taules: `InnoDB`<br>Joc de caràcters: `utf8mb4`<br>Col·lació: `utf8mb4_unicode_ci` |
| **Memòria RAM** | Mínim 2 GB (4 GB recomanat per a concurrència) | `memory_limit = 512M` a `php.ini` |

---

## 3. Paràmetres de `php.ini` Imprescindibles per a Moodle

A `/etc/php/8.2/apache2/php.ini`, cal ajustar aquests valors per suportar càrregues de tasques i sessions exigents:

```ini
memory_limit = 512M
upload_max_filesize = 100M
post_max_size = 100M
max_execution_time = 300
max_input_vars = 5000

; Optimització amb OPcache (reducció dràstica del consum de CPU)
opcache.enable = 1
opcache.memory_consumption = 256
opcache.max_accelerated_files = 10000
opcache.revalidate_freq = 60
opcache.use_cwd = 1
opcache.validate_timestamps = 1
opcache.save_comments = 1
opcache.enable_file_override = 0
```

---

## 4. Estructura de la Base de Dades i Taules Clau

Moodle gestiona més de 400 taules relacionals mitjançant el prefix per defecte `mdl_`:
- `mdl_user`: Registre d'usuaris, correus electrònics, credencials xifrades amb bcrypt i últim accés.
- `mdl_course`: Llista de cursos, categories a què pertanyen, format de plantilla i visibilitat.
- `mdl_role_assignments`: Assignació de rols als usuaris dins de contextos específics (sistema, categoria, curs).
- `mdl_grade_items` i `mdl_grade_grades`: Elements avaluables i qualificacions individuals de l'alumnat.
- `mdl_logstore_standard_log`: Historial complet d'auditoria (qui ha entrat, a quina hora, des de quina IP i a quin recurs ha accedit).
