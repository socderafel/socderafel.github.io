La instal·lació de Moodle es pot realitzar mitjançant l'assistent web gràfic o mitjançant el script de consola oficial `admin/cli/install.php`. En entorns de producció i desplegaments massius, la instal·lació per terminal (CLI) és el mètode professional recomanat: evita temps d'espera que pengen el navegador (*timeouts*) i permet automatitzar tot el procés mitjançant scripts de Bash o Ansible.

---

## 1. Preparació del Servidor i Permisos

```bash
# 1. Crear el directori de dades fora de la publicació web
sudo mkdir -p /var/moodledata
sudo chown -R www-data:www-data /var/moodledata
sudo chmod 775 /var/moodledata

# 2. Descarregar i descomprimir Moodle
wget https://download.moodle.org/download.php/direct/stable404/moodle-latest-404.tgz -O /tmp/moodle.tgz
sudo tar -xvzf /tmp/moodle.tgz -C /var/www/
sudo chown -R www-data:www-data /var/www/moodle
sudo chmod -R 755 /var/www/moodle
```

---

## 2. Creació de la Base de Dades a MariaDB

```sql
CREATE DATABASE moodledb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'moodleuser'@'localhost' IDENTIFIED BY 'MoodlePass#2026!';
GRANT ALL PRIVILEGES ON moodledb.* TO 'moodleuser'@'localhost';
FLUSH PRIVILEGES;
```

---

## 3. Instal·lació Automatitzada per Consola (CLI)

En lloc de passar per desenes de pantalles web, executem el script d'instal·lació com a usuari `www-data`:

```bash
sudo -u www-data php /var/www/moodle/admin/cli/install.php     --lang=ca_valencia     --wwwroot="http://aules.iesrafael.local"     --dataroot="/var/moodledata"     --dbtype="mariadb"     --dbhost="localhost"     --dbname="moodledb"     --dbuser="moodleuser"     --dbpass="MoodlePass#2026!"     --fullname="Plataforma Virtual IES Rafael"     --shortname="Aules IES"     --adminuser="admin_ies"     --adminpass="AdminClauForte.2026!"     --adminemail="admin@iesrafael.local"     --non-interactive     --agree-license
```

El script genera automàticament el fitxer `/var/www/moodle/config.php` i pobla les més de 400 taules de la base de dades en un parell de minuts.

---

## 4. Configuració del Virtual Host a Apache

Creem el fitxer `/etc/apache2/sites-available/moodle.conf`:

```apache
<VirtualHost *:80>
    ServerName aules.iesrafael.local
    DocumentRoot /var/www/moodle

    <Directory /var/www/moodle>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/moodle_error.log
    CustomLog ${APACHE_LOG_DIR}/moodle_access.log combined
</VirtualHost>
```

Activem el Virtual Host:
```bash
sudo a2ensite moodle.conf
sudo systemctl reload apache2
```

---

## 5. El Cron de Moodle: El Cor de la Plataforma

Moodle **no pot funcionar correctament sense el seu servei cron**. Les tasques programades s'encarreguen de:
- Enviar missatges i notificacions de fòrums als correus dels alumnes.
- Calcular qualificacions de qüestionaris automàtics.
- Donar de baixa matriculacions expirades.
- Executar còpies de seguretat automàtiques dels cursos.
- Netejar la paperera de fitxers temporals.

### Programació al Crontab de Linux:
Moodle inclou el script executable `/var/www/moodle/admin/cli/cron.php`. S'ha d'executar **cada 1 minut** sota l'usuari `www-data`:

```bash
sudo crontab -u www-data -e
```
Afegir la següent tasca:
```cron
* * * * * /usr/bin/php /var/www/moodle/admin/cli/cron.php > /dev/null 2>&1
```

> [!IMPORTANT]
> Si el cron s'atura, l'alumnat no rebrà notificacions de lliurament, les tasques programades s'acumularan i el rendiment general del servidor degradarà ràpidament.
