# 💻 Aplicacions Web (2SMX)

Benvingut/da al curs complet d'**Aplicacions Web (Codi Oficial: 0229)** del cicle formatiu de grau mitjà **Sistemes Microinformàtics i Xarxes (SMX)**.

Aquest mòdul professional capacita l'alumnat per a instal·lar, configurar i administrar servidors web, sistemes gestors de continguts (CMS, LMS), plataformes al núvol corporatiu i eines d'ofimàtica col·laborativa, aplicant criteris de seguretat, manteniment i còpies de seguretat.

---

## 🎯 Resultats d'Aprenentatge Oficials (RAs)

D'acord amb el currículum oficial (Reial Decret 1691/2007 i Decret 81/2010 CV), el mòdul aborda els següents Resultats d'Aprenentatge:

- **RA 1:** Instal·la **servidors d'aplicacions web**, descrivint l'arquitectura de 3 capes (LAMP/WAMP) i verificant el funcionament del servidor web, el motor d'execució d'scripts (PHP) i el gestor de bases de dades (MySQL/MariaDB).
- **RA 2:** Instal·la **sistemes gestors de continguts (CMS i LMS)**, identificant els requeriments de la plataforma, creant bases de dades i completant els processos d'instal·lació.
- **RA 3:** **Administra gestors de continguts**, gestionant usuaris, rols i privilegis, personalitzant la interfície amb temes i ampliant funcionalitats mitjançant connectors (*plugins*).
- **RA 4:** Gestiona **aplicacions web d'ofimàtica, treball col·laboratiu i gestió documental**, configurant servidors de núvol privat (Nextcloud) i plataformes SaaS al núvol.
- **RA 5:** Aplica mesures de **seguretat, actualització i còpies de seguretat** en aplicacions web, assegurant la persistència de dades tant del sistema de fitxers com de la base de dades relacional.

## 🛠️ Tecnologies i Laboratori de Pràctiques

- **Pila Servidora:** Ubuntu Server 24.04 LTS amb Apache2, MariaDB 10.11 i PHP 8.3 (LAMP).
- **Entorns de Proves Locals:** XAMPP / WampServer en Windows 11.
- **Aplicacions Web desplegades:** WordPress 6.x, Moodle LMS 4.x, Nextcloud Hub, phpMyAdmin.
- **Eines d'Administració:** WP-CLI, mysqldump, phpMyAdmin, cURL, FileZilla, Let's Encrypt / Certbot.
