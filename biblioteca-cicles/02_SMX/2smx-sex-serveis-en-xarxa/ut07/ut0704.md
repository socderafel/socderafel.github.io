# 7.4 Centraletes Telefòniques IP: Asterisk i FreePBX

Una **Centraleta IP (IP-PBX - *Private Branch Exchange*)** és el servidor de programari encarregat de gestionar totes les comunicacions internes i externes d'una organització: registra les extensions telefòniques dels usuaris, encamina les trucades, gestiona cues d'espera, bústies de veu (*voicemail*) i menús interactius (IVR).

**Asterisk** és el motor de centraleta telefònica de codi obert més utilitzat arreu del món. Per a entorns d'administració gràfica s'acostuma a desplegar juntament amb **FreePBX**, una suite web basada en PHP/MySQL.

---

## 1. Arquitectura de Configuració d'Asterisk

La configuració d'Asterisk es troba al directori `/etc/asterisk/`. En les versions actuals s'utilitza la pila **PJSIP** (més robusta, moderna i capaç de gestionar múltiples dispositius per extensió que l'antiga pila `chan_sip`):

1. `/etc/asterisk/pjsip.conf`: Defineix les extensions, comptes d'usuari, credencials d'autenticació i paràmetres de xarxa.
2. `/etc/asterisk/extensions.conf`: Defineix el **Pla de Marcatge (*Dialplan*)**, que estableix què ha de fer la centraleta quan algú marca un número determinat.
3. `/etc/asterisk/voicemail.conf`: Configura les bústies de veu i les notificacions per correu electrònic.

---

## 2. Creació d'Extensions a `pjsip.conf`

Per a donar d'alta una extensió (per exemple, l'extensió `101` per al departament de Recepció):

```ini
; 1. Definició del transport UDP estàndard
[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0:5060

; 2. Credencials d'autenticació de l'extensió 101
[101-auth]
type=auth
auth_type=userpass
password=ClauMoltSegura101!
username=101

; 3. Endpoint (Dispositiu terminal de l'extensió 101)
[101]
type=endpoint
context=oficina-local
disallow=all
allow=alaw,ulaw,opus
auth=101-auth
aors=101-aor

; 4. AOR (Address of Record: permet el registre del dispositiu)
[101-aor]
type=aor
max_contacts=2

; ===================================================
; Extensió 102: Departament Tècnic
; ===================================================
[102-auth]
type=auth
auth_type=userpass
password=ClauMoltSegura102!
username=102

[102]
type=endpoint
context=oficina-local
disallow=all
allow=alaw,ulaw
auth=102-auth
aors=102-aor

[102-aor]
type=aor
max_contacts=2
```

---

## 3. El Pla de Marcatge (*Dialplan*) a `extensions.conf`

El pla de marcatge és el cor lògic d'Asterisk. Està estructurat en **contextos**, que agrupen extensions i regles:

```ini
[oficina-local]

; Quan algú marca el 101: sona el telèfon durant 20 segons. Si no contesta, passa a la bústia de veu.
exten => 101,1,NoOp(Trucada entrant cap a Recepció 101)
 same => n,Dial(PJSIP/101,20)
 same => n,VoiceMail(101@default,u)
 same => n,Hangup()

; Quan algú marca el 102: Departament Tècnic
exten => 102,1,NoOp(Trucada entrant cap a Suport Tècnic 102)
 same => n,Dial(PJSIP/102,20)
 same => n,VoiceMail(102@default,u)
 same => n,Hangup()

; Extensió especial 500: Prova d'Eco (Echo Test)
; Molt útil per a comprovar el micròfon i els altaveus del client
exten => 500,1,NoOp(Inici de Prova d'Eco)
 same => n,Answer()
 same => n,Playback(demo-echotest)
 same => n,Echo()
 same => n,Playback(demo-echodone)
 same => n,Hangup()
```

---

## 4. Consola de Control d'Asterisk (`rasterisk`)

Els administradors gestionen Asterisk en temps real mitjançant la consola interactiva CLI:

```bash
# Connectar a la consola CLI d'Asterisk amb nivell de depuració alt (-rvvv)
sudo asterisk -rvvv

# Dins de la consola d'Asterisk:
# Comprovar si les extensions PJSIP estan registrades i en línia
ies-pbx*CLI> pjsip show endpoints

# Recarregar la configuració del Dialplan sense reiniciar el servei
ies-pbx*CLI> dialplan reload

# Veure les trucades actives en temps real
ies-pbx*CLI> core show channels
```
