Mentre que Postfix s'encarrega d'enviar i rebre missatges per la xarxa (transport), cal un altre servei especialitzat que emmagatzeme de manera ordenada les bústies de cada usuari i permeta que els clients s'autentiquen per consultar-les mitjançant els protocols **IMAP** o **POP3**. El programari lliure de referència per a aquesta tasca és **Dovecot**.

---

## 1. Formats d'Emmagatzematge de Bústies: `mbox` vs `Maildir`

Com es guarden físicament els correus al disc dur del servidor?

| Format de Bústia | Estructura al Disc Dur | Avantatges | Desavantatges |
| :--- | :--- | :--- | :--- |
| **`mbox` (Format clàssic)** | Un **únic fitxer gegant de text** per usuari a `/var/mail/usuari` on s'encadenen tots els correus un darrere l'altre. | Fàcil de fer còpies d'un sol fitxer. | **Risc de corrupció:** Si dos processos escriuen alhora o un correu es corromp, es destrueix tota la bústia. Bloquejos de fitxer lents. |
| **`Maildir/` (Estàndard Modern)** | Un **directori estructurat** dins de la carpeta personal de l'usuari (`/home/usuari/Maildir/`) amb tres subcarpetes: `cur/`, `new/` i `tmp/`. **Cada correu és un fitxer individual separat**. | **Màxima seguretat i concurrència:** No requereix bloquejos de fitxer. Si un correu falla, la resta no s'afecta. | Major ús d'inodes al sistema de fitxers. |

---

## 2. Instal·lació de Dovecot a Linux

Instal·lem els daemons de Dovecot per a suport d'IMAP i POP3:

```bash
sudo apt update
sudo apt install -y dovecot-imapd dovecot-pop3d
```

Els fitxers de configuració modulars es troben a `/etc/dovecot/conf.d/`:
- `10-mail.conf`: Defineix el format i ruta d'emmagatzematge de les bústies.
- `10-auth.conf`: Mecanismes d'autenticació i contrasenyes.
- `10-master.conf`: Sòcols de comunicació entre Postfix i Dovecot.
- `10-ssl.conf`: Xifratge criptogràfic TLS per a ports 993 i 995.

---

## 3. Configuració del Format `Maildir` i Autenticació

1. A `/etc/dovecot/conf.d/10-mail.conf`:
   ```ini
   # Forçar l'emmagatzematge en format Maildir dins de la carpeta d'usuari
   mail_location = maildir:~/Maildir
   ```
2. A `/etc/dovecot/conf.d/10-auth.conf`:
   ```ini
   # Permetre autenticació en text pla només si la connexió és xifrada amb TLS
   disable_plaintext_auth = yes
   auth_mechanisms = plain login
   ```
3. A `/etc/dovecot/conf.d/10-ssl.conf`:
   ```ini
   # Requerir xifratge SSL/TLS
   ssl = required
   ssl_cert = </etc/ssl/certs/ssl-cert-snakeoil.pem
   ssl_key = </etc/ssl/private/ssl-cert-snakeoil.key
   ```

Reiniciar el servei:
```bash
sudo systemctl restart dovecot
sudo systemctl status dovecot
```

---

## 4. Connexió des d'un Client de Correu (Thunderbird)

Per provar la bústia:
1. Obrir Mozilla Thunderbird a un equip de la xarxa local.
2. Afegir nou compte de correu:
   - Nom: *Alumne 1*
   - Correu: `alumne1@iesrafael.local`
   - Contrasenya: La contrasenya de l'usuari local de Linux.
3. Configuració manual:
   - **Servidor d'Entrada (IMAP):** `mail.iesrafael.local`, Port `993`, Seguretat `SSL/TLS`.
   - **Servidor d'Eixida (SMTP):** `mail.iesrafael.local`, Port `587`, Seguretat `STARTTLS`.
