En servidors empresarials Windows Server 2022, el servei FTP s'integra com una característica dins del servidor web **IIS (*Internet Information Services*)**. Destaca per la seua gestió intuïtiva mitjançant regles d'autorització gràfiques, aïllament d'usuaris basat en carpetes d'Active Directory i control d'accés per quotes de disc del sistema de fitxers NTFS.

---

## 1. Instal·lació del Rol de Servidor FTP a IIS

Des de l'Administrador del Servidor de Windows Server 2022:
1. Afegir rols i característiques ➔ Seleccionar **Servidor Web (IIS)**.
2. Desplegar el servei i marcar les caselles:
   - **Servidor FTP** (*FTP Server*).
   - **Servei FTP** (*FTP Service*).
   - **Extensibilitat de FTP** (*FTP Extensibility*).
3. Finalitzar la instal·lació.

---

## 2. Creació d'un Lloc FTP (*FTP Site*) a la Consola IIS

Obrint la consola gràfica de l'Administrador de IIS:
1. Clic dret sobre **Sitios ➔ Agregar sitio FTP...**
2. **Nom del lloc:** *FTP-Corporatiu-IES*.
3. **Ruta d'accés física:** Seleccionar la carpeta local (ex: `C:\inetpubtproot` o `D:\DadesFTP`).
4. **Enllaços i paràmetres SSL:**
   - Adreça IP: Totes les no assignades (o la IP estàtica de la interfície).
   - Port: `21`.
   - SSL: *Permitir SSL* o *Requerir SSL* (amb certificat de servidor).
5. **Autenticació i Autorització:**
   - Autenticació: **Bàsica** (desmarcant Anònima).
   - Autorització: Donar accés de lectura i escriptura a un grup d'usuaris locals o del domini (ex: `Grup-Professors`).

---

## 3. Aïllament d'Usuaris a Windows Server (*FTP User Isolation*)

IIS FTP disposa d'un sistema d'engabiament natiu anomenat **Aïllament d'Usuaris**:
- **Directori d'usuaris del domini d'Active Directory:** Crea automàticament una gàbia basada en el nom de l'usuari dins de l'estructura `C:\DadesFTP\LocalUser\<nom-usuari>\`.
- Quan l'usuari `joan` es connecta, IIS l'adreça exclusivament a la seua carpeta `LocalUser\joan` i li impedeix pujar al directori pare.

---

## 4. Administració i Ús de Clients Gràfics: FileZilla i WinSCP

El client de transferència de referència és **FileZilla Client**:
- **Gestor de llocs (*Site Manager*):** Permet desar connexions indicant Protocol (FTP, FTPS o SFTP), Tipus d'inici de sessió (Normal, Preguntar contrasenya o Fitxer de clau privada `.ppk`), Joc de caràcters UTF-8 i ajustos de mode passiu.
- **Finestra dividida:** Part esquerra (sistema de fitxers de l'ordinador local) i part dreta (arbres de carpetes del servidor remot). Permet arrossegar i deixar anar (*drag & drop*) arxius i carpetes senceres de manera intuïtiva.
- **Cua de transferències:** Llista d'arxius pendents, transferències satisfactòries i intents fallits amb motiu de l'error.
