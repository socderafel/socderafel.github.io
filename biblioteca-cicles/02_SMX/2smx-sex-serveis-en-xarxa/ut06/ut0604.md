Tot i que l'administració per consola de text (SSH) és l'estàndard per a servidors Linux pel seu baix consum de recursos, moltes aplicacions de gestió empresarial, disseny o entorns Microsoft requereixen interactuar directament amb la **Interfície Gràfica d'Usuari (GUI)**. Per a aquest escenari existeixen dues grans famílies de protocols: **RDP** (*Remote Desktop Protocol*) i **VNC** (*Virtual Network Computing*).

---

## 1. El Protocol RDP (Remote Desktop Protocol) a Windows

Desenvolupat per Microsoft, **RDP escolta al port TCP 3389**:
- **Renderització Intel·ligent:** A diferència d'altres sistemes que transmeten la pantalla com un vídeo o una successió pesada d'imatges JPEG, RDP transmet **ordres gràfiques vectorials de dibuix**. L'equip client és qui dibuixa les finestres i els botons al seu propi monitor, aconseguint una fluïdesa excel·lent fins i tot amb connexions d'ample de banda limitat.
- **Redirecció de Dispositius:** Permet compartir impressores locals, portapapers (copiar i enganxar textos i fitxers entre ordinadors), targetes de so i unitats de disc dur del client cap a la sessió remota.

### Activació a Windows Server / Windows 11:
1. Anar a **Configuració ➔ Sistema ➔ Escriptori remot** i marcar **Activar Escriptori remot**.
2. Afegeix els usuaris autoritzats al grup local **Usuaris d'escriptori remot (*Remote Desktop Users*)**.
3. El client es connecta des de qualsevol màquina amb la comanda `mstsc` (*Microsoft Terminal Services Client*).

---

## 2. Escriptori Remot Gràfic a Linux: XRDP i VNC

| Protocol / Servidor | Mecanisme de Funcionament | Port Estàndard | Cas d'Ús Ideal |
| :--- | :--- | :---: | :--- |
| **XRDP** | Servidor de codi obert per a Linux que **implementa el protocol RDP de Microsoft**. Permet que qualsevol client Windows es connecte a un escriptori Linux usant `mstsc` sense instal·lar res. | TCP **3389** | Administració d'escriptoris Linux des de parcs de PCs Windows |
| **VNC (Virtual Network Computing)** | Independent de la plataforma (TigerVNC, TightVNC). Transmet la pantalla com **mosaics de píxels comprimits (FrameBuffer)**. | TCP **5900** (+ núm. pantalla) | Suport tècnic interactiu compartint la mateixa pantalla amb l'usuari |

---

## 3. Instal·lació de XRDP a Debian/Ubuntu

```bash
# 1. Instal·lar un entorn d'escriptori lleuger (com XFCE) i el servei xrdp
sudo apt update
sudo apt install -y xfce4 xfce4-goodies xrdp

# 2. Configurar XFCE com a gestor de sessions per defecte d'xrdp
echo "xfce4-session" > ~/.xsession

# 3. Donar permisos a l'usuari xrdp sobre el certificat del sistema
sudo adduser xrdp ssl-cert

# 4. Iniciar i activar el servei
sudo systemctl restart xrdp
sudo systemctl enable xrdp
```

Obrir el port al tallafocs: `sudo ufw allow 3389/tcp`. Ara qualsevol alumne pot connectar-se des de Windows escrivint la IP de la màquina Linux a l'assistent `mstsc`!
