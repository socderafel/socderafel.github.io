Qualsevol servidor connectat a Internet amb el port SSH 22 o el port RDP 3389 obert rep diàriament milers de peticions automatitzades provinents de xarxes de robots (*botnets*) que proven combinacions de contrasenyes febles (`admin`, `123456`, `root`, `test`). L'**enduriment (*Hardening*)** i la implementació de sistemes de bloqueig automàtic com **Fail2ban** són obligatoris per garantir la supervivència del sistema.

---

## 1. Directives d'Enduriment d'OpenSSH: `/etc/ssh/sshd_config`

Per blindar el dimoni `sshd`, editem el fitxer de configuració aplicant aquestes bones pràctiques:

```ini
# 1. Canviar el port per defecte per evitar el 95% dels escanejos automatitzats cecs
Port 2222

# 2. Desactivar absolutament l'accés directe amb el superusuari root
PermitRootLogin no

# 3. Limitar quins usuaris concrets de Linux tenen permís per entrar per SSH
AllowUsers administrador professor1

# 4. Limitar el nombre màxim d'intents de contrasenya fallits per sessió
MaxAuthTries 3

# 5. Reduir el temps màxim d'espera per completar l'inici de sessió (evita esgotament de sockets)
LoginGraceTime 30

# 6. Desactivar el reenviament d'entorns gràfics X11 si no són estrictament necessaris
X11Forwarding no

# 7. Forçar l'ús exclusiu de claus criptogràfiques
PasswordAuthentication no
```

Verificar sintaxi abans de reiniciar: `sudo sshd -t`.

---

## 2. Bloqueig Automàtic d'Intrusos amb Fail2ban

**Fail2ban** és un servei de seguretat actiu programat en Python que monitoritza constantment els fitxers de registre del sistema (`/var/log/auth.log`):
- Compta els intents d'inici de sessió fallits que provenen de cada adreça IP.
- Si una IP supera el llindar definit (ex: 3 intents fallits en menys de 10 minuts), **Fail2ban afegeix automàticament una regla al tallafocs de Linux (`iptables` o `nftables`) que bloqueja tot el trànsit d'aquesta IP** durant el temps que s'haja establert (ex: 1 hora o 1 dia).

```
[ Atacant / Bot ] ── 3 intents fallits ──> [ /var/log/auth.log ]
                                                   │
                                                   v
                                           [ Fail2ban Daemon ]
                                                   │
                                                   v Afegeix regla a iptables: DROP
                                           [ TALLAFOCS LINUX ] ──> IP BLOQUEJADA!
```

---

## 3. Instal·lació i Configuració de Fail2ban

```bash
sudo apt update
sudo apt install -y fail2ban
```

Creem un fitxer de configuració local que sobreescriga els valors per defecte a `/etc/fail2ban/jail.local`:

```ini
[DEFAULT]
# Temps de bloqueig en segons (3600s = 1 hora)
bantime = 3600

# Finestra de temps en què es compten els errors (10 minuts)
findtime = 600

# Nombre màxim d'intents fallits abans d'aplicar el bloqueig
maxretry = 3

# Adreces IP de confiança de l'institut que mai s'han de bloquejar (Llista blanca)
ignoreip = 127.0.0.1/8 192.168.10.1

# ==============================================================================
# BLINDATGE DE LA GÀBIA SSH (JAIL)
# ==============================================================================
[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log
```

Reiniciar el servei: `sudo systemctl restart fail2ban`.

---

## 4. Comandes d'Auditoria de Fail2ban per a l'Administrador

```bash
# Consultar l'estat general de Fail2ban i les gàbies actives:
sudo fail2ban-client status

# Consultar quantes IPs han estat bloquejades a la gàbia SSH:
sudo fail2ban-client status sshd

# Desbloquejar manualment la IP d'un company que s'ha equivocat de contrasenya:
sudo fail2ban-client set sshd unbanip 192.168.10.50
```
