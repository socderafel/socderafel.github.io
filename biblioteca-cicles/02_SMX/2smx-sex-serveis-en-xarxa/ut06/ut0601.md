L'administració de servidors remots ubicats a centres de dades (*Data Centers*) o a les sales de comunicacions d'un institut no es realitza connectant un monitor i un teclat físic a cada torre. El protocol **SSH** (*Secure Shell*) és l'estàndard indiscutible de la indústria per accedir de manera remota i segura a la línia d'ordres d'un sistema operatiu a través d'un canal de xarxa completament xifrat, substituint protocols històrics vulnerables com Telnet o Rlogin.

---

## 1. De Telnet (Text Clar) a SSH (Xifrat Criptogràfic)

- **Telnet (Port TCP 23):** Transmet tot el text en clar. Si un administrador tecleja `su -` i la contrasenya de `root`, qualsevol atacant que estiga monitoritzant la xarxa amb un commutador o programa sniffer veu la contrasenya en text pla a la pantalla.
- **SSH (Port TCP 22):** Tota la comunicació (inici de sessió, comandes teclejades, sortida de la terminal i codis d'error) viatja xifrada mitjançant algorismes simètrics d'alta seguretat (AES-256 o ChaCha20) protegits per mecanismes d'integritat SHA-2.

---

## 2. Instal·lació i Gestió del Dimoni OpenSSH a Linux

A Debian/Ubuntu el servei s'implementa mitjançant el paquet **`openssh-server`**:

```bash
sudo apt update
sudo apt install -y openssh-server
```

Comprovar que el servei està en marxa i escoltant al port 22:
```bash
sudo systemctl status ssh
sudo ss -tulpn | grep 22
```

---

## 3. L'Intercanvi Inicial de Claus i el Fitxer `known_hosts`

Quan un client es connecta per primera vegada a un servidor SSH (`ssh usuari@192.168.10.10`):

```
The authenticity of host '192.168.10.10 (192.168.10.10)' can't be established.
ED25519 key fingerprint is SHA256:4d7KjX...Cadena_de_hash...
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

1. El servidor envia al client la seua **Clau Pública d'Amfitrió (*Host Key*)**.
2. El client mostra l'empremta digital (*Fingerprint*) SHA-256 de la clau.
3. Si el client respon `yes`, el client desa aquesta clau pública al fitxer local **`~/.ssh/known_hosts`**.
4. En connexions futures, si un atacant intenta suplantar el servidor (*Man-in-the-Middle*), SSH detectarà que la clau pública ha canviat, bloquejarà la connexió d'immediat i mostrarà un avís en vermell: `WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!`.

---

## 4. Connexió Bàsica des de la Terminal

```bash
# Sintaxi de connexió amb usuari i amfitrió:
ssh alumne1@192.168.10.10

# Si el servidor escolta en un port personalitzat (ex: 2222):
ssh -p 2222 alumne1@192.168.10.10

# Executar una comanda remota directa sense obrir sessió interactiva:
ssh alumne1@192.168.10.10 "df -h && uptime"
```
