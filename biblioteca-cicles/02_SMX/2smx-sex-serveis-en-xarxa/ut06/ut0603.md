Una de les capacitats més poderoses d'OpenSSH és el seu motor d'encapsulament i multiplexació de trànsit. A més d'oferir una consola de text, SSH pot actuar com una autèntica navalla suïssa per **crear túnels xifrats segurs (*SSH Port Forwarding*)** que salten tallafocs corporatius, protegir protocols insegurs i transferir arxius de manera eficient mitjançant **SCP** i **SFTP**.

---

## 1. Redirecció Local de Ports (*Local Port Forwarding: `ssh -L`*)

Imaginem que tenim un servidor de base de dades MariaDB (`port 3306`) o un panell web a una xarxa privada que només admet connexions locals (`127.0.0.1`) i té el port tancat al tallafocs:

```
[ CLIENT LOCAL ] (Port 9000) ══════ TÚNEL SSH XIFRAT (Port 22) ══════> [ SERVIDOR REMOT ] ──> MariaDB (Port 3306)
```

Mitjançant la redirecció local, connectem un port del nostre PC directament al servei remot:
```bash
# Sintaxi: ssh -L [port_local]:[desti_des_del_servidor]:[port_desti] usuari@servidor_ssh
ssh -L 9000:localhost:3306 alumne1@192.168.10.10
```
Ara, si obrim una eina com DBeaver o phpMyAdmin al nostre PC i ens connectem a `localhost:9000`, la petició viatja encapsulada i xifrada pel túnel SSH fins al servidor, que la lliura al seu servei MariaDB local com si provinguera de la mateixa màquina!

---

## 2. Redirecció Dinàmica: Proxy SOCKS5 (*`ssh -D`*)

Quan un treballador es connecta des d'una cafeteria o hotel amb una xarxa Wi-Fi pública insegura, pot convertir qualsevol servidor SSH remot en un servidor intermediari segur (**Proxy SOCKS5**):

```bash
# Obre un proxy SOCKS5 local al port 1080 del nostre PC:
ssh -D 1080 -N -C alumne1@192.168.10.10
```
Paràmetres:
- `-N`: No executa cap comanda remota (només redirigeix ports).
- `-C`: Activa compressió de dades gzip al vol per augmentar la velocitat.

Configurant el navegador Firefox perquè utilitze el proxy `SOCKS v5` a `127.0.0.1:1080`, **tot el trànsit web de l'usuari s'encapsula xifrat pel túnel SSH**, impedint que ningú a la xarxa pública puga espiar la seua navegació.

---

## 3. Transferència Segura de Fitxers: SCP vs SFTP

A més de la consola, OpenSSH incorpora dues eines d'origen per a transmissió d'arxius sobre el mateix port 22:

### A. La Comanda `scp` (*Secure Copy Protocol*):
Ideal per copiar ràpidament un arxiu o carpeta completa d'un equip a un altre en una sola línia de comanda:
```bash
# Copiar un fitxer local cap al directori personal del servidor remot:
scp informe.pdf alumne1@192.168.10.10:~/documents/

# Descarregar una carpeta sencera de manera recursiva des del servidor:
scp -r alumne1@192.168.10.10:/var/log/apache2/ ./registres_locals/
```

### B. El Protocol `sftp` (*SSH File Transfer Protocol*):
Una sessió interactiva amb exploració de directoris, càrrega i descàrrega estructurada:
```bash
sftp alumne1@192.168.10.10
sftp> ls
sftp> cd /var/www/
sftp> put index.html
sftp> get error.log
sftp> bye
```
