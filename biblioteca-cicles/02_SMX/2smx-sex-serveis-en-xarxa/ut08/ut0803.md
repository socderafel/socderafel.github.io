Navegar per Internet mitjançant el protocol HTTP tradicional suposa transmetre totes les dades en clar. Si un alumne o treballador introdueix la seua contrasenya en una web no segura, qualsevol dispositiu a la xarxa local pot capturar-la. El protocol **HTTPS** (*HTTP Secure*) xifra tot el canal d'extrem a extrem mitjançant **TLS**, garantint tres principis essencials: **Confidencialitat** (ningú pot llegir les dades), **Integritat** (ningú pot manipular el contingut) i **Autenticitat** (el lloc web és qui diu ser).

---

## 1. El Cicle de Generació d'un Certificat Digital X.509

Per activar el protocol HTTPS, cal instal·lar al servidor web un certificat digital emès per una autoritat de confiança:

```
[ PAS 1: SERVIDOR WEB ] ── Genera parell de claus (Clau Privada + CSR) ──> [ PAS 2: AUTORITAT DE CERTIFICACIÓ (CA) ]
                                                                                   │
                                                                                   ├── Valida la propietat del domini
                                                                                   v
[ PAS 3: SERVIDOR WEB ] <──── Rep certificat oficial signat (Certificat X.509) ────┘
```

1. **Clau Privada (*Private Key*):** Es guarda exclusivament al servidor amb permisos estrictes (`600`). Mai s'ha de compartir amb ningú.
2. **CSR (*Certificate Signing Request*):** Petició de signatura que conté la clau pública del servidor i les dades de l'organització. S'envia a l'Autoritat de Certificació.
3. **Certificat Digital (.crt / .pem):** Document signat per la CA que certifica davant de tots els navegadors del món que la clau pública pertany legítimament a eixe nom de domini.

---

## 2. Certificats Gratuïts i Automatitzats amb Let's Encrypt i Certbot

A entorns amb nom de domini públic, **Let's Encrypt** ofereix certificats gratuïts reconeguts pel 100% dels navegadors mitjançant el protocol automàtic ACME:

```bash
# 1. Instal·lar el client oficial Certbot per a Apache
sudo apt update
sudo apt install -y certbot python3-certbot-apache

# 2. Sol·licitar i configurar el certificat automàticament
sudo certbot --apache -d portal.iesrafael.es -d aules.iesrafael.es
```

Certbot valida el domini, sol·licita el certificat, modifica el fitxer del Virtual Host afegint les directives SSL i programa una tasca al temporitzador `systemd` per renovar-lo cada 60 dies de manera completament transparent!

---

## 3. Configuració Manual del Virtual Host SSL a Apache2

Per a laboratoris d'aula o dominis locals (`.local`), es pot utilitzar un certificat autofirmat generat amb `openssl`:

```apache
<VirtualHost *:443>
    ServerName aules.iesrafael.local
    DocumentRoot /var/www/aules

    # Habilitar el motor SSL
    SSLEngine on

    # Rutes del certificat públic i de la clau privada
    SSLCertificateFile /etc/ssl/certs/aules.crt
    SSLCertificateKeyFile /etc/ssl/private/aules.key

    <Directory /var/www/aules>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/aules_ssl_error.log
    CustomLog ${APACHE_LOG_DIR}/aules_ssl_access.log combined
</VirtualHost>
```

Activar el mòdul SSL d'Apache i el lloc segur:
```bash
sudo a2enmod ssl headers
sudo a2ensite aules-ssl.conf
sudo systemctl reload apache2
```

---

## 4. Redirecció Forçosa Permanent (301) cap a HTTPS

Per assegurar que cap visitant utilitze la connexió no xifrada del port 80:

```apache
<VirtualHost *:80>
    ServerName aules.iesrafael.local
    # Redirigir de manera permanent totes les peticions cap al mateix recurs sota HTTPS
    Redirect permanent / https://aules.iesrafael.local/
</VirtualHost>
```
