# 8.1 Laboratori de Telefonia IP: Desplegament d'Asterisk i Configuració d'Extensions SIP

Benvingut a la guia pràctica de desplegament de veu sobre IP. En aquesta sessió pràctica de taller instal·laràs un servidor de telefonia IP basat en **Asterisk**, donaràs d'alta dues extensions SIP corporatives per a dos departaments i realitzaràs trucades de veu en temps real utilitzant clients **Softphone** (com MicroSIP o Linphone).

---

## 🎯 Objectius del Laboratori
1. Desplegar el servei Asterisk en una màquina virtual Ubuntu Server.
2. Configurar el fitxer `pjsip.conf` per a definir dues extensions SIP (`101` i `102`) amb autenticació segura.
3. Crear el pla de marcatge bàsic en `extensions.conf` per a permetre trucades internes directes.
4. Instal·lar i connectar dos clients softphone i validar la transmissió d'àudio bidireccional mitjançant RTP.
5. Capturar la sessió amb Wireshark i analitzar els missatges SIP (`INVITE`, `200 OK`, `ACK`, `BYE`) i el flux de veu RTP.

## 📋 Pas 1: Instal·lació d'Asterisk en Ubuntu Server

Actualitza els repositoris i instal·la el paquet d'Asterisk:

```bash
sudo apt update && sudo apt install -y asterisk asterisk-modules asterisk-config
sudo systemctl enable --now asterisk
sudo systemctl status asterisk
```

Comprova que pots accedir a la consola administrativa d'Asterisk mitjançant el comandament:

```bash
sudo asterisk -rvvv
```

*(Per a eixir de la consola d'Asterisk escriu `exit` o `quit`).*

---

## 📋 Pas 2: Configuració del canal PJSIP (`/etc/asterisk/pjsip.conf`)

Fes una còpia de seguretat del fitxer original i afegeix la configuració per a les extensions `101` i `102`:

```ini
; ====================================================
; CONFIGURACIÓ BÀSICA PJSIP - AULA SMX
; ====================================================
[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0:5060

; --- EXTENSIÓ 101 (Vendes) ---
[101]
type=endpoint
context=aula-smx
disallow=all
allow=ulaw
allow=alaw
auth=101-auth
aors=101

[101-auth]
type=auth
auth_type=userpass
password=ClauSegura101!
username=101

[101]
type=aor
max_contacts=1

; --- EXTENSIÓ 102 (Suport) ---
[102]
type=endpoint
context=aula-smx
disallow=all
allow=ulaw
allow=alaw
auth=102-auth
aors=102

[102-auth]
type=auth
auth_type=userpass
password=ClauSegura102!
username=102

[102]
type=aor
max_contacts=1
```

---

## 📋 Pas 3: Configuració del Pla de Marcatge (`/etc/asterisk/extensions.conf`)

Edita el fitxer de pla de marcatge per a associar el context `aula-smx` a les trucades entre les extensions:

```ini
[aula-smx]
; Si algú marca 101, sona l'endpoint 101 durant 25 segons
exten => 101,1,Dial(PJSIP/101,25)
same => n,Hangup()

; Si algú marca 102, sona l'endpoint 102 durant 25 segons
exten => 102,1,Dial(PJSIP/102,25)
same => n,Hangup()
```

Aplica els canvis recarregant els mòduls a la consola d'Asterisk:

```bash
sudo asterisk -rx "pjsip reload"
sudo asterisk -rx "dialplan reload"
sudo asterisk -rx "pjsip show endpoints"
```

---

## 📋 Pas 4: Connexió i Prova amb Clients Softphone

1. **Configuració de MicroSIP (Extensió 101):**
   - **Nom de compte:** Vendes
   - **Servidor SIP:** `192.168.10.50` (IP del vostre servidor Asterisk)
   - **Usuari:** `101`
   - **Contrasenya:** `ClauSegura101!`
   - Comprova que l'estat canvia a color verd: **En línia / Online**.

2. **Configuració del segon Softphone (Extensió 102):**
   - Configura el segon client a l'altra màquina amb l'usuari `102` i la seua contrasenya.

3. **Execució de la Trucada de Prova:**
   - Des del client `101`, marca el número `102` i prem el botó de trucar.
   - Verifica que el client `102` sona i mostra la trucada entrant procedent de `101`.
   - Despenja la trucada, parla pel micròfon i confirma que l'àudio s'escolta nítidament en ambdós sentits.

## 📝 Quadern de Treball de Laboratori

Per a completar el registre d'evidències tècniques d'aquesta sessió, documenta:

1. **Evidència de registre:** Captura de la consola administrativa d'Asterisk executant `pjsip show endpoints` mostrant les dues extensions en estat `Available`.
2. **Evidència de trucada en curs:** Captura de pantalla de la trucada activa entre els dos clients Softphone mostrant el temporitzador de conversa.
3. **Anàlisi Wireshark:** Filtra el trànsit pel protocol `sip || rtp` i fes una captura del diagrama de flux de trucada (*Telephony -> VoIP Calls -> Flow Sequence*) on s'aprecie la seqüència `INVITE`, `180 Ringing`, `200 OK`, `ACK`, el flux `RTP` i el missatge `BYE`.
