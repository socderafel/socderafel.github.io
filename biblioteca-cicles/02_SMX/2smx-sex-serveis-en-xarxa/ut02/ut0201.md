El protocol IP identifica de manera unívoca cada dispositiu a la xarxa mitjançant números (com `193.144.127.10` o `2a00:1450:4003::200e`). No obstant això, per a les persones és pràcticament impossible recordar les adreces numèriques de milers de servidors. El **DNS** (*Domain Name System* o Sistema de Noms de Domini) és la base de dades distribuïda i jeràrquica d'Internet que tradueix noms amigables i fàcils de recordar (com `www.gva.es`) en les seues adreces IP reals.

---

## 1. L'Estructura Jeràrquica de l'Espai de Noms

L'espai de noms de domini té una estructura d'arbre invertit que s'inicia a l'arrel:

```
                                [ . (NIVELL ARREL / ROOT) ]
                                             │
      ┌──────────────────────┬───────────────┴──────────────┬─────────────────────┐
   [ .org ]               [ .com ]                       [ .es ]               [ .edu ]  (TLDs)
      │                      │                              │                     │
 [ wikipedia ]           [ google ]                    [ gva / ies ]          [ upv ]   (2n NIVELL)
      │                      │                              │                     │
   [ www ]                [ mail ]                       [ aules ]             [ intranet ] (SUBDOMINIS)
```

### Els Nivells de l'Arbre DNS:
1. **El Nivell Arrel (*Root Domain*):** Representat per un punt (`.`). Al món hi ha 13 grups de servidors arrel centrals (d'A a M), replicats en centenars d'ubicacions mitjançant la tecnologia *Anycast*.
2. **Dominis de Primer Nivell (*TLD - Top Level Domains*):**
   - **gTLD (Genèrics):** `.com`, `.org`, `.net`, `.info`.
   - **ccTLD (Territorials / Codi de País):** `.es` (Espanya), `.eu` (Unió Europea), `.fr` (França), `.cat`.
3. **Dominis de Segon Nivell (*Second Level Domains*):** Noms registrats per empreses, ciutadans o institucions (ex: `google.com`, `gva.es`, `iesrafael.local`).
4. **Subdominis i Equips (*FQDN - Fully Qualified Domain Name*):** Identificadors concrets de serveis o servidors de la institució (ex: `aules.iesrafael.local.`). El punt final representa l'arrel absoluta.

---

## 2. Tipus de Servidors DNS segons la seua Funció

| Tipus de Servidor | Funció Principal a la Infraestructura |
| :--- | :--- |
| **Servidor Autoritatiu Mestre (*Primary Master*)** | Conté la còpia original i editable dels fitxers de la zona. Les altes i modificacions es fan sempre ací. |
| **Servidor Autoritatiu Secundari (*Slave / Secondary*)** | Manté una còpia de només lectura sincronitzada automàticament des del mestre per transferència de zona (AXFR/IXFR). Ofereix redundància i balanç de càrrega. |
| **Servidor Recursiu / Memòria Cau (*Caching-Only*)** | No té zones pròpies. Resol peticions de clients preguntant a altres servidors d'Internet i desa les respostes a la seua memòria RAM durant el temps definit pel TTL. |

---

## 3. Com Funciona una Resolució DNS: Consultes Recursives vs Iteratives

Quan un usuari escriu `www.iesrafael.es` al seu navegador:

```
[ NAVEGADOR ] ── 1. Consulta Recursiva ──> [ RESOLVEDOR LOCAL / DNS ISP ]
                                                     │
                                                     ├── 2. Consulta Iterativa ──> [ SERVIDOR ARREL (.) ]
                                                     │<── "Ves a consultar el TLD .es" ──┘
                                                     │
                                                     ├── 3. Consulta Iterativa ──> [ SERVIDOR TLD (.es) ]
                                                     │<── "Ves a consultar el servidor de iesrafael.es" ──┘
                                                     │
                                                     ├── 4. Consulta Iterativa ──> [ DNS AUTORITATIU iesrafael.es ]
                                                     │<── "L'adreça de www és 192.168.10.100" ────────────┘
                                                     v
[ NAVEGADOR ] <══ 5. Retorna la IP i la guarda a la memòria cau ══╡
```

- **Consulta Recursiva:** El client demana al seu servidor DNS configurat: *"Digues-me la IP exacta d'aquest nom o dona'm un error; no em faces preguntar a ningú més"*.
- **Consulta Iterativa:** El servidor DNS local va preguntant pas a pas als diferents nivells: *"Coneixes aquesta IP? No, però et dic l'adreça del servidor que potser la sap"*.

---

## 4. Transport del Protocol DNS: UDP 53 vs TCP 53

DNS utilitza el **Port 53**:
- **Port UDP 53:** S'utilitza per a les consultes i respostes habituals de resolució de noms (paquets ràpids i lleugers de menys de 512 bytes o formats EDNS0).
- **Port TCP 53:** S'utilitza obligatòriament quan la resposta supera el límit de mida de paquet o durant les **transferències de zona completes (*Zone Transfers - AXFR*)** entre servidors mestres i esclaus, on es requereix una transmissió fiable lliure d'errors.
