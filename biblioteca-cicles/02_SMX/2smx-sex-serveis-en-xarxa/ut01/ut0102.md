A les distribucions Linux de la família Debian/Ubuntu, el programari de referència tradicional per implementar el servei DHCP és el paquet **`isc-dhcp-server`** desenvolupat pel consorci ISC (*Internet Systems Consortium*). Tot el funcionament del dimoni s'articula al voltant de la selecció de la interfície de xarxa i el fitxer central de configuració `/etc/dhcp/dhcpd.conf`.

---

## 1. Instal·lació del Paquet i Elecció d'Interfície

Abans d'instal·lar el servei, el servidor **ha de tenir configurada una adreça IP estàtica fixa** a la seua targeta de xarxa. Un servidor DHCP mai pot dependre d'una IP dinàmica!

```bash
# 1. Instal·lar el servidor DHCP d'ISC
sudo apt update
sudo apt install -y isc-dhcp-server
```

Indicar a quina targeta de xarxa ha d'escoltar peticions:
A `/etc/default/isc-dhcp-server`:
```ini
# Especificar el nom de la interfície LAN connectada a la xarxa dels clients
INTERFACESv4="enp0s8"
INTERFACESv6=""
```

---

## 2. Anatomia del Fitxer de Configuració: `/etc/dhcp/dhcpd.conf`

El fitxer `dhcpd.conf` es divideix en dues seccions: paràmetres globals (aplicats a totes les declaracions) i declaracions de subxarxa (*subnets*):

```ini
# ==============================================================================
# PARÀMETRES GLOBALS
# ==============================================================================
# Temps de concessió per defecte (en segons: 86400s = 1 dia)
default-lease-time 86400;

# Temps màxim de concessió permès
max-lease-time 172800;

# Declarar que aquest servidor és l'autoritatiu oficial per a aquesta xarxa local
authoritative;

# Servidors DNS corporatius i públics que rebran els clients
option domain-name-servers 192.168.10.1, 1.1.1.1;

# Nom de domini local de recerca
option domain-name "iesrafael.local";

# ==============================================================================
# DECLARACIÓ D'ÀMBIT DE SUBXARXA (SUBNET)
# ==============================================================================
subnet 192.168.10.0 netmask 255.255.255.0 {
    # Rang d'adreces IP dinàmiques que s'entregaran als clients
    range 192.168.10.50 192.168.10.150;

    # Passarel·la per defecte (Router / Gateway) per eixir a Internet
    option routers 192.168.10.1;

    # Adreça de difusió de la subxarxa
    option broadcast-address 192.168.10.255;

    # Servidor NTP per a sincronització horària (opcional)
    option ntp-servers 192.168.10.1;
}
```

> [!IMPORTANT]
> Totes les sentències dins de `dhcpd.conf` han d'acabar obligatòriament amb un **punt i coma (`;`)**. Oblidar un sol punt i coma farà que el servei falle a l'inici amb un error de sintaxi.

---

## 3. Gestió i Verificació del Servei amb Systemd

Un cop desades les regles de configuració, s'aplica el cicle de vida del servei:

```bash
# Comprovar la sintaxi abans de reiniciar
sudo dhcpd -t -cf /etc/dhcp/dhcpd.conf

# Iniciar o reiniciar el servei
sudo systemctl restart isc-dhcp-server

# Habilitar l'arrencada automàtica amb el sistema
sudo systemctl enable isc-dhcp-server

# Comprovar que està actiu (running)
sudo systemctl status isc-dhcp-server
```

---

## 4. Opcions de Xarxa Especials (*DHCP Options*)

El protocol DHCP permet trametre més de 200 paràmetres diferents als clients mitjançant la directiva `option`:
- **Opció 3 (`option routers`):** IP del router per defecte.
- **Opció 6 (`option domain-name-servers`):** Servidors DNS per resoldre noms.
- **Opció 15 (`option domain-name`):** Sufix de domini per a consultes curtes.
- **Opció 42 (`option ntp-servers`):** Servidors de sincronització de temps horari.
- **Opció 66/67 (Arrencada per xarxa PXE):** Adreça IP del servidor TFTP i nom del fitxer d'arrencada (`pxelinux.0`) per arrencar ordinadors sense disc dur instal·lant sistemes operatius per xarxa.
