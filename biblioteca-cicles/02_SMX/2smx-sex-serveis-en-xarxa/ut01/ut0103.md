A qualsevol xarxa d'empresa o centre educatiu hi ha certs equips que requereixen tenir **sempre exactament la mateixa adreça IP**: servidors web o d'arxius locals, impressores multifunció departamentals, punts d'accés Wi-Fi o càmeres de seguretat IP. En lloc de configurar-los manualment amb IP estàtica, la millor pràctica consisteix a crear una **Reserva d'IP** al servidor DHCP vinculada a l'adreça física (**MAC**) de l'equip.

---

## 1. Concepte de Reserva d'Adreça IP (*Static Lease*)

Una reserva DHCP combina els avantatges dels dos mons:
- **Per a l'equip client:** Continua configurat en mode automàtic (DHCP), sense cap manipulació manual.
- **Per a l'administrador:** Garanteix que sempre rebrà la mateixa adreça IP i permet canviar de manera centralitzada els servidors DNS o la passarel·la per a tota la xarxa sense anar dispositiu per dispositiu.

```
[ Impressora Departament ] (MAC: 00:11:22:33:44:55)
             │
             ├── Envia DHCPDISCOVER ──> [ Servidor DHCP ]
             │                               │ Consulta taula de reserves
             │                               │ Troba MAC 00:11:22:33:44:55 = 192.168.10.20
             │<── Entrega sempre la IP 192.168.10.20 reservada ──┘
```

> [!WARNING]
> L'adreça IP reservada ha d'estar dins de la mateixa subxarxa, però **és una bona pràctica ubicar-la fora del rang dinàmic (*range*)** del pool general per evitar que el servidor puga assignar-la temporalment a un altre equip abans que el dispositiu reservat s'encenga.

---

## 2. Declaració de Reserves a `dhcpd.conf`

Al fitxer `/etc/dhcp/dhcpd.conf`, les reserves es defineixen mitjançant blocs `host`:

```ini
# Reserva per a la impressora multifunció de secretaria
host impressora-secretaria {
    hardware ethernet 08:00:27:fa:4b:12;
    fixed-address 192.168.10.20;
    option host-name "impr-sec";
}

# Reserva per al servidor web intern
host servidor-web-intranet {
    hardware ethernet 00:1e:67:89:ab:cd;
    fixed-address 192.168.10.10;
    option routers 192.168.10.1;
    option domain-name-servers 192.168.10.1;
}
```

Paràmetres clau:
- `hardware ethernet`: L'adreça MAC de 48 bits (6 parells hexadecimals separats per dos punts).
- `fixed-address`: L'adreça IPv4 permanent que se li adjudicarà exclusivament a aquest maquinari.

---

## 3. Gestió i Monitoratge de Concessions: `/var/lib/dhcp/dhcpd.leases`

Com sap el servidor quines IPs estan ocupades, qui les té i quan expiren? El servidor ISC-DHCP manté un fitxer de registre dinàmic d'estat a `/var/lib/dhcp/dhcpd.leases`:

```ini
lease 192.168.10.75 {
  starts 2 2026/11/03 08:15:30;
  ends 3 2026/11/04 08:15:30;
  tstp 3 2026/11/04 08:15:30;
  cltt 2 2026/11/03 08:15:30;
  binding state active;
  next binding state free;
  hardware ethernet 08:00:27:3a:9c:81;
  client-hostname "pc-aula2-04";
}
```

Informació del registre:
- `lease`: La IP atorgada.
- `starts` i `ends`: Data i hora UTC d'inici i expiració del lloguer.
- `binding state active`: L'estat actual de la concessió (activa).
- `hardware ethernet`: MAC del terminal que l'està utilitzant.
- `client-hostname`: Nom de màquina informat pel client.

---

## 4. Eines de Supervisió Ràpida per a l'Administrador

Per consultar les concessions en temps real sense navegar manualment pel fitxer de text, es poden utilitzar utilitats com **`dhcp-lease-list`**:

```bash
# Instal·lar o consultar la taula de concessions actives
sudo dhcp-lease-list
```
Mostra un resum net en columnes: Adreça MAC, Adreça IP, Nom de l'equip i Data límit de vigència.
