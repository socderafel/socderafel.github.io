A qualsevol organització és fonamental crear adreces de correu genèriques de departament (com `secretaria@iesrafael.local` o `suport@iesrafael.local`) que redirigeixen automàticament els missatges a una o més persones sense necessitat de crear usuaris addicionals al sistema operatiu. A més, el diagnòstic de problemes d'enviament requereix conèixer la **negociació manual de comandes SMTP per terminal**.

---

## 1. Gestió d'Àlies de Correu a Linux: `/etc/aliases`

El fitxer `/etc/aliases` gestiona el reenviament d'adreces a nivell de sistema:

```ini
# Redirecció d'un correu de servei a l'administrador real del sistema
postmaster: root
root: administrador

# Àlies d'atenció al públic cap a un treballador concret
info: maria.sanchis

# Llista de distribució departamental (un missatge es reparteix a 3 professors)
informatica: joan.garcia, maria.sanchis, pau.vidal
```

> [!IMPORTANT]
> Cada vegada que es modifica `/etc/aliases`, **s'ha d'executar obligatòriament la comanda `newaliases`** (o `postalias /etc/aliases`) per compilar el fitxer de text en la base de dades binària indexada `/etc/aliases.db`. Si no s'executa, Postfix ignorarà els canvis!

---

## 2. Simulació Manual d'una Sessió SMTP amb Telnet / Netcat

Per comprovar si el servidor SMTP respon i diagnosticar errors d'entrega sense dependre de cap client gràfic, podem connectar-nos directament al port 25 mitjançant `telnet` o `nc`:

```bash
telnet localhost 25
```

Diàleg complet de comandes SMTP estàndard:
```smtp
S: 220 mail.iesrafael.local ESMTP Postfix
C: HELO client.local
S: 250 mail.iesrafael.local
C: MAIL FROM:<director@iesrafael.local>
S: 250 2.1.0 Ok
C: RCPT TO:<alumne1@iesrafael.local>
S: 250 2.1.5 Ok
C: DATA
S: 354 End data with <CR><LF>.<CR><LF>
C: Subject: Prova Manual SMTP
C: 
C: Hola! Aquest missatge s'ha enviat escrivint comandes SMTP a mà.
C: .
S: 250 2.0.0 Ok: queued as 4XyZ12345
C: QUIT
S: 221 2.0.0 Bye
```

Significat de les Comandes SMTP:
- `HELO` / `EHLO`: Saluda el servidor i s'identifica.
- `MAIL FROM:`: Especifica el remitent del sobre (*Envelope Sender*).
- `RCPT TO:`: Especifica el destinatari del sobre.
- `DATA`: Inicia el cos del missatge. **Per indicar que el text ha acabat, s'escriu una línia que continga exclusivament un punt (`.`) i es prem Retorn**.
- `QUIT`: Tanca la connexió de manera ordenada.

---

## 3. Proves Segures amb TLS mitjançant OpenSSL

Com que els servidors de producció moderns exigeixen xifratge TLS i autenticació sobre el port 587, `telnet` no serveix perquè no xifra la sessió. S'utilitza la comanda **`openssl s_client`**:

```bash
openssl s_client -connect mail.iesrafael.local:587 -starttls smtp
```
Aquesta comanda inicia la negociació en text pla pel port 587, commuta el canal a xifratge TLS segur i ens retorna el prompt per introduir les comandes `EHLO`, `AUTH LOGIN` i transmetre el correu xifrat.
