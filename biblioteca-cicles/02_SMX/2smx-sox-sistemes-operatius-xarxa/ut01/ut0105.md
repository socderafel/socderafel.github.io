# 1.5 Instal·lació d'Ubuntu Server 24.04 LTS

**Ubuntu Server** és una de les plataformes de codi obert més emprades a nivell global per al desplegament de serveis corporatius, contenidors Docker i servidors d'infraestructura d'alta disponibilitat.

---

## 🛠️ Procediment Pas a Pas

### 1. Paràmetres de la Màquina Virtual a VirtualBox
- **Nom:** `SRV-UBUNTU-2024`
- **Tipus:** `Linux` $\rightarrow$ **Versió:** `Ubuntu (64-bit)`.
- **Memòria RAM:** $2048\text{ MB}$ (2 GiB) són suficients per a un servidor Linux sense interfície gràfica.
- **Processadors:** 2 vCPUs.
- **Disc dur virtual:** 25 GB.
- **Xarxa:** Mode **Xarxa Interna** (*Internal Network*, mateix nom: `xarxa_sox`).

### 2. Procés d'Instal·lació
1. Arrenca la màquina des de la ISO `ubuntu-24.04-live-server-amd64.iso`.
2. Tria l'idioma i el mapa de teclat espanyol.
3. Tipus de base: Tria `Ubuntu Server` estàndard.
4. Particionament: Accepta el particionament automàtic sobre tot el disc (crearà `/boot` i l'arrel `/` amb volum LVM).
5. Perfil d'usuari:
   - El teu nom: `Administrador SOX`
   - Nom del servidor (*hostname*): `srv-linux`
   - Nom d'usuari: `administrador`
   - Contrasenya: `Smx2024!`
6. Marca la casella: **Instal·lar el servidor OpenSSH** (*Install OpenSSH server*) per poder administrar el servidor remotament des de la consola.
7. Finalitza la instal·lació i reinicia la màquina virtual.

## 🌐 Configuració d'IP Estàtica amb Netplan en Linux

En Ubuntu modern, la xarxa s'administra mitjançant fitxers de configuració YAML a `/etc/netplan/`:

1. Edita el fitxer de configuració de xarxa:
   ```bash
   sudo nano /etc/netplan/50-cloud-init.yaml
   ```
2. Ajusta els paràmetres amb la sintaxi d'espais estricta de YAML:
   ```yaml
   network:
     version: 2
     renderer: networkd
     ethernets:
       enp0s3:
         dhcp4: no
         addresses:
           - 192.168.100.20/24
         routes:
           - to: default
             via: 192.168.100.1
         nameservers:
           addresses:
             - 192.168.100.10
             - 8.8.8.8
   ```
3. Aplica els canvis en calent:
   ```bash
   sudo netplan apply
   ```
4. Comprova la nova IP:
   ```bash
   ip a show enp0s3
   ```
