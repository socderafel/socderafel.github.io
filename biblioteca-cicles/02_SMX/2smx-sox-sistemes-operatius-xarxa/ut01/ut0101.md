# 1.1 Arquitectura Client-Servidor i Sistemes Operatius en Xarxa (NOS)

En el món empresarial i institucional, els ordinadors no treballen com a illes aïllades. La necessitat de compartir recursos de maquinari (impressores, sistemes d'emmagatzematge massiu), dades corporatives (bases de dades, documents compartits) i serveis de comunicació (correu electrònic, intranet) requereix una infraestructura coordinada.

Un **Sistema Operatiu en Xarxa** (*Network Operating System* o **NOS**) és un sistema operatiu dissenyat específicament per a gestionar, coordinar i securitzar les comunicacions, les dades, els usuaris i els recursos compartits entre múltiples equips connectats en una xarxa local o corporativa.

```
+-------------------------------------------------------------------------+
|                  ARQUITECTURA DE XARXA CORPORATIVA                      |
+-------------------------------------------------------------------------+
|                                                                         |
|  [Clients Windows / Linux]           [Servidor de Xarxa - NOS]          |
|  +-----------------------+           +-----------------------+          |
|  | Sol·licita serveis:   |  Peticions| Proporciona serveis:  |          |
|  | - Inici de sessió     | --------> | - Active Directory    |          |
|  | - Accés a fitxers     |           | - Servidor SMB / NFS  |          |
|  | - Resolució de noms   | <-------- | - Servidor DNS / DHCP |          |
|  +-----------------------+  Respostes+-----------------------+          |
|                                                                         |
+-------------------------------------------------------------------------+
```

## 1. Models d'Organització de Xarxa: P2P vs. Client-Servidor

Històricament i tecnològicament, podem estructurar les xarxes locals segons dos grans paradigmes:

### A. Xarxes entre Iguals o Grups de Treball (*Peer-to-Peer* / P2P)
En una xarxa P2P o grup de treball (*Workgroup*):
- Tots els ordinadors tenen el mateix rang jeràrquic; qualsevol equip pot actuar alhora com a client i com a servidor.
- **Gestió descentralitzada:** Cada màquina té la seua pròpia base de dades local d'usuaris (com la base de dades SAM a Windows o `/etc/passwd` a Linux).
- Si un usuari necessita accedir a recursos de 5 equips diferents, cal crear el seu compte d'usuari i la seua contrasenya en cadascun d'aquests 5 equips.
- **Inconvenients:** Seguretat molt feble, manteniment inassumible per damunt de 10-15 equips i absència d'auditoria centralitzada.

### B. Xarxes Basades en Servidor (Arquitectura Client-Servidor)
En una xarxa client-servidor:
- Els equips es diferencien clarament segons el seu rol:
  - **Servidors (*Servers*):** Màquines potents dedicades a allotjar serveis, validar identitats i centralitzar la seguretat.
  - **Clients (*Workstations*):** Estacions de treball utilitzades pels usuaris finals per a fer les seues tasques diàries.
- **Gestió centralitzada (Servei de Directori):** Els usuaris, grups, equips i permisos es defineixen una única vegada en una base de dades centralitzada (com l'Active Directory o un servidor LDAP).
- Un usuari pot iniciar sessió des de qualsevol equip connectat a la xarxa corporativa amb les mateixes credencials úniques, rebent les seues polítiques i drets d'accés de manera automàtica.

---

## 2. Serveis Clau que Proporciona un Sistema Operatiu en Xarxa

Un NOS professional integra un conjunt de serveis i rols imprescindibles per al funcionament corporatiu:

1. **Servei d'Autenticació i Directori:** Identifica inequívocament usuaris i equips, verificant credencials mitjançant protocols segurs com Kerberos o NTLMv2.
2. **Serveis d'Infraestructura IP:**
   - **DHCP (*Dynamic Host Configuration Protocol*):** Assigna configuracions de xarxa dinàmiques (IP, màscara, passarel·la, DNS) als clients.
   - **DNS (*Domain Name System*):** Tradueix noms de domini FQDN a adreces IP, indispensable per a localitzar controladors de domini i recursos de xarxa.
3. **Serveis d'Arxius i Impressió:** Permet emmagatzemar documents de manera centralitzada amb control d'accés exhaustiu (NTFS/POSIX, SMB/NFS) i gestionar cues d'impressió compartides.
4. **Serveis d'Aplicació i Base de Dades:** Execució d'ERP, CRM, servidors web o servidors de bases de dades (SQL Server, PostgreSQL, MariaDB).
5. **Seguretat i Monitorització:** Gestió de polítiques de seguretat centralitzades (GPO), auditoria d'esdeveniments, tallafocs perimetral i telemetria de rendiment.

---

## 3. Famílies Principals de Sistemes Operatius en Xarxa

Actualment, el mercat de servidors corporatius es divideix principalment en dos grans ecosistemes que sovint conviuen de forma híbrida:

| Característica | Família Microsoft Windows Server | Família Linux Server (Debian, Ubuntu, RHEL/Rocky) |
| :--- | :--- | :--- |
| **Model de Llicència** | Propietari / Comercial (per nucli de CPU + llicències d'accés CAL) | Codi obert / Lliure (GPL) o subscripció de suport corporatiu |
| **Servei de Directori Principal** | Active Directory Domain Services (AD DS) basat en Kerberos/LDAP | OpenLDAP, FreeIPA, Samba 4 AD DC |
| **Interfície d'Administració** | Server Manager, RSAT, Windows Admin Center, PowerShell | Consola CLI, SSH, Ansible, Cockpit, Webmin |
| **Consum de Recursos** | Mitjà-Alt (Interfície gràfica GUI) / Moderat (Server Core) | Molt baix (execució habitual sense entorn gràfic Desktop) |
| **Usos Predominants** | Gestió de dominis d'oficina, estacions de treball Windows, Exchange | Servidors web, contenidors (Docker/K8s), núvol, bases de dades |
