# 1.4 Instal·lació de Microsoft Windows Server 2022

En aquest taller pràctic instal·larem **Windows Server 2022 Standard** com a màquina virtual per a preparar el nostre futur entorn de domini Active Directory.

---

## 🛠️ Procediment Pas a Pas

### 1. Paràmetres de la Màquina Virtual a VirtualBox
- **Nom:** `SRV-WIN-2022`
- **Tipus:** `Microsoft Windows` $\rightarrow$ **Versió:** `Windows 2022 (64-bit)`.
- **Memòria RAM:** Mínim $4096\text{ MB}$ (4 GiB).
- **Processadors:** 2 vCPUs.
- **Disc dur virtual:** 50 GB (VDI dinàmic).
- **Adaptador de Xarxa:** Mode **Xarxa Interna** (*Internal Network*, nom: `xarxa_sox`) o **Adaptador Pont** (*Bridged Adapter*).

### 2. Procés d'Instal·lació
1. Arrenca la màquina virtual des de la imatge ISO oficial de Windows Server 2022.
2. Tria l'idioma i format horari d'Espanya.
3. Prem **Instal·lar ara**.
4. **Selecció d'edició:** Selecciona:
   `Windows Server 2022 Standard (Experiència d'escriptori)`
   *(Nota: Si tries l'opció sense experiència d'escriptori s'instal·larà Server Core, que només disposa de consola de comandes!)*
5. Accepta la llicència i tria **Personalitzada: instal·lar només el sistema operatiu**.
6. Selecciona l'espai no assignat del disc de 50 GB i prem **Següent**.
7. En finalitzar el reinici, l'assistent sol·licitarà definir la contrasenya del compte d'administrador local (`Administrator`):
   - Contrasenya requerida: `Admin2024!` (ha de complir el patró de complexitat de 8 o més caràcters, majúscula, minúscula, número i símbol).

### 3. Configuració Inicial de Xarxa
Obre la consola PowerShell d'administrador i assigna la IP estàtica fixa:

```powershell
# Obtenir el nom o índex de la targeta de xarxa
Get-NetAdapter

# Assignar IP estàtica 192.168.100.10 amb màscara /24
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.100.10 -PrefixLength 24 -DefaultGateway 192.168.100.1

# Assignar el servidor DNS apuntant a ell mateix (Loopback local)
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses "127.0.0.1"

# Canviar el nom del servidor a 'DC1' i reiniciar
Rename-Computer -NewName "DC1" -Restart
```
