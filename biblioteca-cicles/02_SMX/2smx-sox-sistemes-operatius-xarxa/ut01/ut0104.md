# 1.4 Instal·lació i Configuració Base de Linux Server (Ubuntu/Debian)

Els servidors GNU/Linux dominen àmpliament la infraestructura d'Internet, els centres de dades en el núvol i els serveis d'alt rendiment (servidors web, servidors DNS arrel, clústers de bases de dades i servidors de fitxers). Distribucions com **Ubuntu Server LTS** (*Long Term Support*) o **Debian Stable** proporcionen una estabilitat extraordinària amb un consum mínim de recursos.

---

## 1. Instal·lació d'Ubuntu Server LTS

L'assistent d'instal·lació d'Ubuntu Server (*Subiquity*) s'executa completament en mode text interactiu a través de la consola:
1. **Configuració de teclat i idioma:** Selecció de mapa de teclat espanyol o valencià.
2. **Tipus d'instal·lació:** Selecció de la versió estàndard (*Ubuntu Server*) o minimitzada.
3. **Configuració d'adreçament de xarxa:** L'assistent permet definir de manera immediata una adreça IP estàtica mitjançant format CIDR (ex: `192.168.10.20/24`).
4. **Particionat d'Emmagatzematge:**
   - Ús de **LVM (*Logical Volume Manager*)**: LVM permet redimensionar volums en calent sense necessitat de reiniciar el servidor ni formatar particions.
   - Partició `/boot` (normalment 1-2 GB ext4) i el grup de volums per al volum arrel `/`.
5. **Configuració del perfil:** Creació del compte d'usuari no privilegiat amb permisos `sudo` (a Ubuntu l'usuari `root` està deshabilitat per defecte per seguretat).
6. **Instal·lació del servidor OpenSSH:** Pas indispensable per a poder administrar el servidor de manera remota immediatament després del primer reinici.

---

## 2. Configuració de Xarxa Moderna amb Netplan

En distribucions modernes d'Ubuntu i Debian, la configuració estàtica de xarxa es gestiona mitjançant **Netplan**, un renderitzador que utilitza fitxers descriptius en format **YAML** ubicats a `/etc/netplan/`:

```bash
# Edició del fitxer de configuració de xarxa
sudo nano /etc/netplan/00-installer-config.yaml
```

Exemple de configuració per a assignar IP estàtica a la targeta `enp0s3`:

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: no
      addresses:
        - 192.168.10.20/24
      routes:
        - to: default
          via: 192.168.10.1
      nameservers:
        addresses: [192.168.10.10, 1.1.1.1]
```

> **IMPORTANT:** La sintaxi YAML és extremadament sensible a la indentació. Utilitza exclusivament **espais en blanc** (normalment 2 espais per nivell) i **mai tabuladors**.

Per aplicar els canvis:
```bash
# Comprovar sintaxi i aplicar configuració
sudo netplan try
sudo netplan apply

# Verificar l'adreça assignada
ip addr show enp0s3
```

---

## 3. Gestió de Serveis amb `systemd` i Parxejat del Sistema

En Linux, la gestió de processos i serveis del sistema (*daemons*) es controla mitjançant **`systemctl`**:

```bash
# Actualització immediata dels repositoris i paquets del sistema
sudo apt update && sudo apt upgrade -y

# Comprovar l'estat del servei SSH
sudo systemctl status ssh

# Assegurar que el servei s'inicia automàticament en arrancar l'equip
sudo systemctl enable ssh
sudo systemctl restart ssh
```

---

## 4. Bastionat Inicial del Servei SSH (`/etc/ssh/sshd_config`)

El protocol SSH (*Secure Shell*, port TCP 22) és la porta d'entrada principal per a l'administració de Linux. És obligatori aplicar mesures de bastionat immediatament després de la instal·lació:

```bash
sudo nano /etc/ssh/sshd_config
```

Paràmetres de seguretat recomanats:
- `PermitRootLogin no`: Prohibeix terminantment que l'usuari `root` inicie sessió directament per SSH. L'administrador ha d'entrar amb el seu usuari personal i després elevar privilegis amb `sudo`.
- `PasswordAuthentication no`: (En entorns avançats) Exigeix autenticació basada en parell de claus criptogràfiques asimètriques en lloc de contrasenyes vulnerables a força bruta.
