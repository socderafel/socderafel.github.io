# 1.3 Instal·lació de Windows Server: Interfície Gràfica vs. Server Core

El procés d'instal·lació de Microsoft Windows Server (versions 2022 o 2025) segueix un flux estructurat que va des de l'arrancada del mitjà d'instal·lació (imatge ISO o memòria USB arrencable UEFI) fins a la configuració bàsica post-instal·lació dels paràmetres de xarxa.

---

## 1. Fases de la Instal·lació de Windows Server

1. **Arrencada i Selecció d'Idioma:** S'inicia el sistema mitjançant UEFI/BIOS des del suport d'instal·lació. Es tria l'idioma d'instal·lació, format d'hora i moneda (Espanyol / Valencià) i distribució de teclat.
2. **Introducció de Clau de Producte:** Es pot introduir la llicència o seleccionar *"No tinc clau de producte"* per a utilitzar la versió d'avaluació durant 180 dies.
3. **Selecció de la Imatge del Sistema:**
   - *Windows Server Standard / Datacenter:* Instal·la la versió **Server Core** (sense escriptori).
   - *Windows Server Standard / Datacenter (Experiència d'escriptori):* Instal·la la versió completa amb interfície gràfica.
4. **Particionat d'Emmagatzematge:**
   - Selecció de tipus d'instal·lació: **Personalitzada: instal·lar només el sistema operatiu (avançat)**.
   - Creació del volum d'arrencada sobre taula de particions **GPT** (*GUID Partition Table*). L'assistent crea automàticament les particions necessàries de Recuperació, Sistema EFI (ESP) i Reservada de Microsoft (MSR).
5. **Còpia de Fitxers i Reinici:** El sistema descomprimeix la imatge WIM i realitza el primer reinici autònom.
6. **Assignació de la Contrasenya de l'Administrador:** Es demana obligatòriament definir la contrasenya del compte `Administrator` local, complint requisits de complexitat (mínim 8 caràcters, majúscules, minúscules, números i símbols).

---

## 2. Tasques Post-Instal·lació Fonamentals

Una instal·lació recent de Windows Server no està llesta per a producció fins que es completen quatre passos crítics:

```
+-------------------------------------------------------------------------+
|                  TASQUES POST-INSTAL·LACIÓ OBLIGATÒRIES                 |
+-------------------------------------------------------------------------+
|                                                                         |
|  1. CANVI DE NOM DEL SERVIDOR (HOSTNAME)                                |
|     Exemple: De 'WIN-83JFKD93' a 'SRV-DC01' o 'SRV-FILES01'.            |
|                                                                         |
|  2. CONFIGURACIÓ D'ADREÇA IP FIXA O ESTÀTICA                            |
|     Un servidor MAI ha de dependre d'una IP dinàmica canviant.          |
|                                                                         |
|  3. CONFIGURACIÓ DE ZONA HORÀRIA I SINCRONITZACIÓ DE TEMPS              |
|     Kerberos falla catastròficament si el desfasament horari supera 5m. |
|                                                                         |
|  4. HABILITACIÓ D'ESCRIPTORI REMOT (RDP) I ACTUALITZACIONS WINDOWS      |
|     Permet gestionar el servidor des de l'estació de treball del tècnic |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 3. Configuració a Server Core amb `sconfig` i PowerShell

En instal·lacions Server Core, l'eina basada en menú de text **`sconfig`** (*Server Configuration*) permet fer la configuració essencial en segons sense necessitat d'aprendre sintaxis complexes:

```powershell
# Execució de l'eina de configuració en Server Core
sconfig
```

El menú de `sconfig` ofereix opcions numèriques clares:
- **Opció 2:** Canviar el nom del servidor (*Computer Name*).
- **Opció 8:** Configuració de xarxa (*Network Settings*): Assignar IP estàtica, màscara, passarel·la i servidors DNS.
- **Opció 7:** Habilitar l'Escriptori Remot (*Remote Desktop - RDP*).
- **Opció 6:** Descarregar i instal·lar actualitzacions de Windows (*Windows Update*).

Alternativament, mitjançant ordres directes de **PowerShell**, podem automatitzar aquests paràmetres:

```powershell
# 1. Renombrar l'equip i demanar reinici
Rename-Computer -NewName "SRV-DC01" -Restart

# 2. Configurar IP estàtica a la interfície Ethernet
New-NetIPAddress -InterfaceAlias "Ethernet0" -IPAddress 192.168.10.10 -PrefixLength 24 -DefaultGateway 192.168.10.1

# 3. Configurar servidors DNS (apuntant a si mateix com a futur DC i secundari)
Set-DnsClientServerAddress -InterfaceAlias "Ethernet0" -ServerAddresses ("127.0.0.1", "1.1.1.1")
```
