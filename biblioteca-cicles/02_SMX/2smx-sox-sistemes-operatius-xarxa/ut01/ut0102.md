# 1.2 Planificació de la Instal·lació i Requisits de Maquinari

La instal·lació d'un sistema operatiu en un entorn corporatiu mai no s'ha d'iniciar de manera improvisada. Un servidor és el cor d'una organització i donarà servei a desenes o centenars d'usuaris durant anys. Una mala elecció en la fase de disseny pot comportar colls d'ampolla de rendiment, pèrdua de dades o aturades de servei molt costoses.

---

## 1. Dimensionament del Maquinari per a Servidors

A l'hora de dimensionar un servidor físic o assignar recursos a una màquina virtual, cal analitzar quatre subsistemes fonamentals:

```
+-------------------------------------------------------------------------+
|                  SUBSISTEMES CRÍTICS D'UN SERVIDOR                      |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ PROCESSADOR (CPU) ]    Arquitectura x86-64 multinucli.               |
|                           Compatibilitat amb virtualització VT-x/AMD-V. |
|                                                                         |
|  [ MEMÒRIA (RAM) ]        Memòria ECC (Error-Correcting Code).          |
|                           Requisit clau per a serveis de bases de dades |
|                           i màquines virtuals concurrents.              |
|                                                                         |
|  [ EMMAGATZEMATGE ]       Controladores RAID dedicades per maquinari.   |
|                           Separació de volums: SO vs. Dades. Discs SAS, |
|                           SATA Enterprise o NVMe d'alta durabilitat.    |
|                                                                         |
|  [ COMUNICACIONS (XARXA)] Múltiples interfícies de xarxa (NICs 1/10GbE) |
|                           Agrupament (NIC Teaming / Bonding) per a      |
|                           tolerància a fallades i balanç de càrrega.    |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Memòria RAM amb suport ECC (*Error-Correcting Code*)
En estacions de treball convencionals s'utilitza memòria RAM no-ECC. En un servidor corporatiu és indispensable l'ús de mòduls **RAM ECC**, que incorporen circuits capaços de detectar i corregir automàticament errors d'un sol bit provocats per interferències electromagnètiques o radiació de fons, evitant la caiguda sobtada (*pantallada blava* o *kernel panic*) del sistema operatiu.

### Configuració del Subsistema de Disc
Mai no s'instal·la un servidor de producció en un únic disc dur independent:
- **Separació de volums:** El sistema operatiu ha d'estar allotjat en un volum físic o lògic independent del volum de dades corporatives. Si el volum de dades s'ompli al 100%, el sistema operatiu continuarà funcionant sense bloquejar-se.
- **Tolerància a fallades mitjançant RAID:**
  - **RAID 1 (Mirall):** Recomanat com a mínim per al volum del sistema operatiu (2 discs idèntics).
  - **RAID 5 o RAID 10:** Recomanat per als volums d'emmagatzematge de dades d'usuaris i bases de dades.

---

## 2. Requisits Mínims Oficials vs. Requisits Recomanats de Producció

Hi ha una diferència abismal entre els requisits mínims que marca el fabricant per a engegar el sistema i els recursos reals necessaris per a treballar en producció:

| Component | Windows Server 2022/2025 (Mínim) | Windows Server (Recomanat Producció) | Linux Server (Ubuntu Server) |
| :--- | :--- | :--- | :--- |
| **Processador** | 1.4 GHz x86-64 (1 nucli) | 2.0 GHz+ (4 a 16 nuclis o més) | 1.0 GHz x86-64 (1 nucli) |
| **Memòria RAM** | 512 MB (Server Core) / 2 GB (GUI) | 16 GB - 64 GB+ (segons rols) | 1 GB (mínim) / 4 GB - 16 GB (producció) |
| **Espai en Disc** | 32 GB | 120 GB (SO en RAID 1) + Discs de dades | 10 GB (mínim) / 60 GB+ |
| **Adaptadors Xarxa** | 1 targeta Gigabit Ethernet (1 Gbps) | 2 a 4 targetes Gigabit / 10 GbE en Teaming | 1 a 2 targetes Ethernet |

---

## 3. Selecció de la Modalitat d'Instal·lació a Windows Server

Durant l'assistent d'instal·lació de Windows Server, s'ha de prendre una decisió arquitectònica fonamental:

1. **Windows Server Core (Opció predeterminada i recomanada per Microsoft):**
   - No instal·la cap entorn gràfic d'escriptori tradicional (no hi ha menú Inici, ni Explorer, ni finestres clàssiques).
   - L'administració local es fa exclusivament per consola de comandes (`cmd.exe`), PowerShell o l'eina de text `sconfig`.
   - **Avantatges:** Superfície d'atac molt més reduïda (menys codi susceptible de contindre vulnerabilitats), requereix menys reinicis per actualitzacions i consumeix molt menys espai en disc i memòria RAM.
   - S'administra remotament mitjançant RSAT (*Remote Server Administration Tools*), Windows Admin Center o sessions SSH/WinRM de PowerShell.

2. **Windows Server amb Experiència d'Escriptori (*Desktop Experience*):**
   - Inclou la interfície gràfica completa basada en finestres i el Gestor del Servidor (*Server Manager*).
   - Ideal per a entorns de laboratori educatiu, tècnics novells o quan cal executar aplicacions propietàries que requereixen obligatòriament GUI.
