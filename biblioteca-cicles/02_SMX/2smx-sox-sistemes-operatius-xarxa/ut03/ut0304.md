# 3.4 Desplegament de Polítiques Corporatives amb GPO

Mitjançant la consola d'administració de directives de grup (`gpmc.msc`), els tècnics de sistemes configuren les regles de joc de l'empresa: des de la robustesa de les contrasenyes fins al bloqueig de vectors d'infecció de malware.

---

## 1. Polítiques de Contrasenyes i Bloqueig de Comptes

La política de contrasenyes del domini es defineix de manera predeterminada a la **Directiva Predeterminada del Domini (*Default Domain Policy*)**:

```
+-------------------------------------------------------------------------+
|                  PARÀMETRES CLAU DE LA POLÍTICA DE CONTRASENYES         |
+-------------------------------------------------------------------------+
|                                                                         |
|  - Longitud mínima de la contrasenya:     10 - 12 caràcters mínim.      |
|  - Complexitat de contrasenyes:           Habilitada (Majús, minús,     |
|                                           números i caràcters especials)|
|  - Historial de contrasenyes recordades:  24 contrasenyes anteriors.    |
|  - Edat màxima de la contrasenya:         90 dies (caducitat forçada).  |
|  - Llindar de bloqueig de compte:         5 intents fallits fallats.    |
|  - Duració del bloqueig de compte:        30 minuts o desbloqueig per   |
|                                           administrador (evita atacs de |
|                                           força bruta automatitzats).   |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 2. Restricció de Dispositius d'Emmagatzematge Amovibles (USB)

Els llapis de memòria USB són un dels principals vectors d'exfiltració de dades sensibles i d'entrada de ransomware. Mitjançant GPO podem bloquejar-los fàcilment:

- **Ruta:** `Configuració de l'equip -> Plantilles administratives -> Sistema -> Accés d'emmagatzematge amovible`.
- **Directiva:** *Totes les classes d'emmagatzematge amovible: denegar tot accés*.
- Quan s'habilita aquesta directiva, si qualsevol empleat connecta un pendrive USB al seu ordinador, Windows mostrarà un missatge de *"Accés denegat"* i serà incapaç de llegir o escriure dades.

---

## 3. Personalització de l'Entorn de Treball i Escriptori Corporatiu

En entorns corporatius és habitual estandarditzar la imatge visual i evitar modificacions no desitjades per part dels usuaris:

- **Fons d'escriptori corporatiu:**
  - `Configuració de l'usuari -> Plantilles administratives -> Escriptori -> Escriptori -> Tapís de l'escriptori`.
  - S'estableix una ruta UNC replicada accessible per xarxa (ex: `\\iesrafael.local\SYSVOL\iesrafael.local\imatges\fons.jpg`).
- **Prohibició de l'accés al Tauler de Control i Configuració del Sistema:**
  - `Configuració de l'usuari -> Plantilles administratives -> Tauler de control -> Prohibir l'accés a Configuració de PC i al Tauler de control`.
  - Evita que els usuaris desconfiguren adaptadors de xarxa o desinstal·len eines del sistema.
- **Scripts d'Inici i Tancament de Sessió (*Logon/Logoff Scripts*):**
  - Permeten executar scripts en batch (`.bat`) o PowerShell (`.ps1`) per a connectar automàticament unitats de xarxa compartides (`net use Z: \\server\dades`).
