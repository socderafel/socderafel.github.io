# 3.2 Estratègia i Administració de Grups (Metodologia AGDLP)

Una de les pitjors pràctiques en l'administració de xarxes és assignar permisos sobre fitxers o recursos directament a comptes d'usuari individuals. Quan eixe empleat canvia de departament o marxa de l'empresa, rastrejar on tenia permisos es converteix en un malson d'auditoria.

La solució professional és l'ús estratègic de **Grups** i l'aplicació rigorosa de la metodologia **AGDLP**.

---

## 1. Tipus i Àmbits de Grups a Active Directory

A Active Directory, els grups es classifiquen per dos criteris:

### A. Tipus de Grup
1. **Grup de Seguretat (*Security Group*):** S'utilitza per assignar permisos sobre recursos (fitxers, carpetes compartides, impressores) i per aplicar polítiques GPO. Té un SID assignat.
2. **Grup de Distribució (*Distribution Group*):** S'utilitza exclusivament com a llista de distribució de correu electrònic (amb servidors com Microsoft Exchange). **No té SID i no es pot utilitzar per assignar permisos de seguretat**.

### B. Àmbit del Grup (*Group Scope*)
- **Grup Global (Global Group - GG):** Serveix per a agrupar usuaris amb funcions similars dins del mateix domini (ex: `GG_Comptabilitat`).
- **Grup Local de Domini (Domain Local Group - DL):** Serveix per a definir els permisos concrets d'accés sobre un recurs del domini local (ex: `DL_CarpetaFactures_RW`).
- **Grup Universal (Universal Group - UG):** S'utilitza en boscos amb múltiples dominis per agrupar objectes que travessen fronteres de domini. S'emmagatzema al Catàleg Global.

---

## 2. La Metodologia Professional AGDLP

Microsoft estableix la metodologia **AGDLP** com la millor pràctica innegociable per a la gestió de permisos escalables:

```
+-------------------------------------------------------------------------+
|                        LA METODOLOGIA AGDLP                             |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ A ] ACCOUNTS             Els usuaris individuals                     |
|        (Comptes)            (ex: usuari 'joan.garcia').                 |
|             |                                                           |
|             v                                                           |
|  [ G ] GLOBAL GROUPS        S'afegeixen a Grups Globals segons el       |
|        (Grups Globals)      seu rol empresarial (ex: 'GG_Professors').  |
|             |                                                           |
|             v                                                           |
|  [ DL] DOMAIN LOCAL GROUPS  El Grup Global s'afegeix a un Grup Local    |
|        (Grups Locals)       de Domini creat per al recurs               |
|                             (ex: 'DL_MaterialDidactic_Lectura').        |
|             |                                                           |
|             v                                                           |
|  [ P ] PERMISSIONS          Els permisos NTFS/Share s'assignen          |
|        (Permisos)           EXCLUSIVAMENT al Grup Local de Domini.      |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Per què funciona tan bé AGDLP?
- Si s'incorpora un professor nou a l'institut, simplement se l'afegeix a `GG_Professors`. De manera automàtica, hereta immediatament tots els accessos pertinents de l'institut sense tocar cap carpeta ni cap permís NTFS.
- Si cal auditar qui té accés de lectura a una carpeta, només cal mirar els membres del grup `DL_MaterialDidactic_Lectura`.

---

## 3. Gestió de Grups mitjançant PowerShell

```powershell
# 1. Crear el Grup Global de rol departamental
New-ADGroup -Name "GG_Comptabilitat" -GroupScope Global -GroupCategory Security -Path "OU=Grups,DC=iesrafael,DC=local"

# 2. Crear el Grup Local de Domini associat al recurs
New-ADGroup -Name "DL_InformesFinancers_RW" -GroupScope DomainLocal -GroupCategory Security -Path "OU=Grups,DC=iesrafael,DC=local"

# 3. Niual el Grup Global dins del Grup Local de Domini (G -> DL)
Add-ADGroupMember -Identity "DL_InformesFinancers_RW" -Members "GG_Comptabilitat"

# 4. Afegir l'usuari al Grup Global (A -> G)
Add-ADGroupMember -Identity "GG_Comptabilitat" -Members "jgarcia"
```
