# 3.5 Administració d'Usuaris i Grups en Linux Server (OpenLDAP / FreeIPA)

Tot i que l'Active Directory és el líder en l'escriptori corporatiu, els servidors Linux Server gestionen gran part dels serveis crítics d'infraestructura. Comprendre com s'emmagatzemen, gestionen i autentiquen els comptes d'usuari i grups en entorns Linux és un coneixement indispensable per a qualsevol tècnic de xarxes.

---

## 1. Els Fitxers Fonamentals d'Usuaris i Grups en Linux

En una màquina Linux autònoma, les identitats es gestionen en tres fitxers de text pla protegits dins de `/etc`:

1. **`/etc/passwd`:** Llista pública (però de només lectura) amb tots els comptes d'usuari del sistema.
   - Format: `usuari:x:UID:GID:Comentari:Directori_Home:Shell`
   - Exemple: `jgarcia:x:1001:1001:Joan Garcia:/home/jgarcia:/bin/bash`
   - La 'x' indica que la contrasenya xifrada està protegida al fitxer shadow.
2. **`/etc/shadow`:** Fitxer protegit (només accessible per `root`) que conté els **hashes xifrats** de les contrasenyes (mitjançant algorismes com SHA-512 o yescrypt) i les metadades de caducitat.
3. **`/etc/group`:** Defineix els grups locals del sistema i els seus membres.
   - Format: `nom_grup:x:GID:usuari1,usuari2,...`

---

## 2. Comandes de Gestió d'Usuaris i Grups per Consola

```bash
# 1. Crear un nou grup
sudo groupadd professors

# 2. Crear un nou usuari amb carpeta personal (-m), shell bash (-s) i afegir-lo a un grup secundari (-G)
sudo useradd -m -s /bin/bash -c "Joan Garcia" -G professors jgarcia

# 3. Assignar contrasenya a l'usuari
sudo passwd jgarcia

# 4. Forçar el canvi de contrasenya en el següent inici de sessió
sudo chage -d 0 jgarcia

# 5. Bloquejar o desbloquejar un compte
sudo usermod -L jgarcia  # Bloquejar (Lock)
sudo usermod -U jgarcia  # Desbloquejar (Unlock)
```

---

## 3. Gestió de Privilegis Administratius: El Fitxer `sudoers`

En servidors Linux professionals, mai s'inicia sessió directament com a `root`. S'utilitza el mecanisme **`sudo`** (*SuperUser DO*):
- Permet a usuaris específics executar ordres amb privilegis d'administrador de manera controlada i auditada a `/var/log/auth.log`.
- Per editar la configuració de permisos de sudo, s'utilitza **sempre** la comanda **`sudo visudo`** (que valida la sintaxi abans de desar per evitar deixar el servidor bloquejat):

```bash
# Exemple de línia al fitxer /etc/sudoers
# Permet als membres del grup 'professors' reiniciar el servei web apache2 sense contrasenya
%professors ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart apache2
```

---

## 4. Serveis de Directori Nadius en Linux: OpenLDAP i FreeIPA

Quan una organització disposa exclusivament d'infraestructura de servidors i clients Linux, s'utilitzen solucions de directori de codi obert:
- **OpenLDAP:** El servidor de directori estàndard del món Unix/Linux. Implementa el protocol LDAP (*Lightweight Directory Access Protocol*), organitzant les dades en arbres de components (dc=iesrafael, dc=local, ou=professors, cn=jgarcia).
- **FreeIPA (*Identity, Policy, Audit*):** L'equivalent més complet a Active Directory en el món Linux (desenvolupat per Red Hat). Integra en una única solució: **389 Directory Server** (LDAP), **MIT Kerberos** (autenticació Single Sign-On), **Dogtag Certificate System** (PKI) i servidor **BIND DNS** amb consola web d'administració centralitzada.
