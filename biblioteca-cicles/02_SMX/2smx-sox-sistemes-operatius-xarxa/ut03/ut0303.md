# 3.3 Introducció i Arquitectura dels Objectes de Directiva de Grup (GPO)

En una xarxa amb centenars d'estacions de treball, configurar manualment opcions de seguretat, bloquejar menús perillosos, instal·lar programari o desplegar impressores màquina a màquina seria una tasca inabastable.

La tecnologia més potent de Microsoft per a l'administració centralitzada de sistemes és la **Directiva de Grup** (*Group Policy*), materialitzada mitjançant els **Objectes de Directiva de Grup (GPOs - *Group Policy Objects*)**.

---

## 1. Què és una GPO i on s'emmagatzema?

Una GPO és un conjunt de configuracions de seguretat i preferències d'usuari i màquina que s'aplica automàticament als equips i usuaris d'un domini. Una GPO està formada per dues parts sincronitzades:

1. **GPC (*Group Policy Container*):** S'emmagatzema a la base de dades d'Active Directory (`CN=Policies,CN=System,DC=...`). Conté els atributs de la directiva (nom, versió, estat d'habilitació).
2. **GPT (*Group Policy Template*):** S'emmagatzema a la carpeta compartida replicada **SYSVOL** (`\\domini\SYSVOL\domini\Policies\{GUID}`). Conté els fitxers reals de configuració, scripts (`.bat`, `.ps1`), plantilles administratives (`.admx`) i paràmetres de registre.

---

## 2. Ordre d'Aplicació de les Directives: Regla LSDOU

Quan un equip s'encén o un usuari inicia sessió, el sistema aplica les diferents directives seguint una jerarquia molt estricta coneguda per l'acrònim **LSDOU**:

```
+-------------------------------------------------------------------------+
|                  ORDRE D'APLICACIÓ DE DIRECTIVES (LSDOU)                |
+-------------------------------------------------------------------------+
|                                                                         |
|  1. [ L ] LOCAL             Directiva de seguretat local del propi PC   |
|         |                   (gpedit.msc).                               |
|         v                                                               |
|  2. [ S ] SITE              Directives vinculades al Lloc físic         |
|         |                   d'Active Directory.                         |
|         v                                                               |
|  3. [ D ] DOMAIN            Directives vinculades a l'arrel del domini  |
|         |                   (com la 'Default Domain Policy').           |
|         v                                                               |
|  4. [ OU ] ORGANIZATIONAL   Directives vinculades a la Unitat           |
|            UNIT             Organitzativa on resideix l'objecte         |
|                             (i a les seues sub-OUs heretades).          |
|                                                                         |
+-------------------------------------------------------------------------+
```

> **REGLA D'OR DE PRECEDÈNCIA:** L'última directiva que s'aplica és la que **guanya o sobreescriu** les configuracions anteriors en cas de conflicte. Per tant, **les polítiques d'una OU tenen prioritat sobre les del Domini**, i les del Domini sobre les Locals.

---

## 3. Estructura Interna d'una GPO

Quan editem una GPO mitjançant la consola **Editor d'administració de directives de grup** (`gpmc.msc`), trobem dos blocs clarament separats:

```
[ GPO: Política Corporativa ]
  |
  +-- [ Configuració de l'Equip (Computer Configuration) ]
  |     - S'aplica a la màquina quan s'arrenca el sistema operatiu.
  |     - Afecta a QUALSEVOL usuari que utilitze aquest ordinador.
  |     - Inclou: Polítiques de contrasenyes, serveis del sistema, regles de tallafocs, parxes.
  |
  +-- [ Configuració de l'Usuari (User Configuration) ]
        - S'aplica quan un usuari concret inicia sessió al sistema.
        - Segueix a l'usuari a qualsevol ordinador del domini on entre.
        - Inclou: Fons d'escriptori, bloqueig del Tauler de Control, mapatge d'unitats de xarxa.
```

---

## 4. Eines de Consola per a Gestió de GPOs

A les estacions de treball clients, podem forçar l'aplicació immediata de directives o diagnosticar quines s'estan aplicant:

```cmd
:: Forçar l'actualització immediata de polítiques sense esperar el cicle de 90 minuts
gpupdate /force

:: Generar un informe complet de les polítiques aplicades a l'equip i a l'usuari actual
gpresult /r

:: Generar un informe gràfic HTML per a auditoria tècnica
gpresult /h C:\informe_gpo.html
```
