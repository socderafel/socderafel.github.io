# 3.1 Gestió de Comptes d'Usuari en Sistemes en Xarxa

Un compte d'usuari és l'objecte principal d'Active Directory que permet a una persona física autenticar-se a la xarxa, rebre autorització per a accedir a recursos i quedar auditada per a garantir la traçabilitat de les seues accions.

---

## 1. Usuaris Locals vs. Usuaris de Domini

És primordial distingir entre els dos tipus de comptes que conviuen en un equip:

- **Compte d'Usuari Local:** S'emmagatzema exclusivament a la base de dades local **SAM (*Security Accounts Manager*)** de l'ordinador. Només és vàlid per a iniciar sessió en eixa màquina física concreta i no té validesa per a la resta de servidors del domini.
- **Compte d'Usuari de Domini:** S'emmagatzema a la base de dades centralitzada `ntds.dit` dels controladors de domini. Permet a l'usuari iniciar sessió des de qualsevol estació de treball unida al domini i accedir als serveis autoritzats de la xarxa.

---

## 2. Nomenclatura i Atributs Fonamentals d'Usuari

Quan creem un usuari a Active Directory, definim diferents identificadors:

```
+-------------------------------------------------------------------------+
|                  IDENTIFICADORS D'UN COMPTE D'USUARI                    |
+-------------------------------------------------------------------------+
|                                                                         |
|  1. Nom d'inici de sessió UPN (User Principal Name):                    |
|     Format estil correu electrònic: 'joan.garcia@iesrafael.local'.      |
|     És l'estàndard modern per a iniciar sessió a Windows 10/11 i Azure. |
|                                                                         |
|  2. Nom d'inici de sessió pre-Windows 2000 (sAMAccountName):            |
|     Format tradicional NetBIOS: 'IESRAFAEL\jgarcia'.                    |
|     Màxim 20 caràcters; imprescindible per a compatibilitat antiga.     |
|                                                                         |
|  3. Identificador de Seguretat (SID - Security Identifier):             |
|     Cadena binària única generada automàticament pel DC                 |
|     (ex: S-1-5-21-3623811015-3361044348-30300820-1014).                |
|     El sistema utilitza el SID (i NO el nom) per als permisos ACL.      |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 3. Tipus de Perfils d'Usuari

Quan un usuari inicia sessió en un equip client de Windows, el sistema carrega el seu entorn (escriptori, documents, configuracions del registre `ntuser.dat`):

1. **Perfil Local (*Local Profile*):** S'emmagatzema al disc dur local de la màquina (`C:\Users\%username%`). Si l'usuari canvia de màquina, no tindrà els seus fitxers de l'escriptori ni les seues personalitzacions.
2. **Perfil Mòbil (*Roaming Profile*):** El perfil es guarda en una carpeta compartida al servidor central. Quan l'usuari inicia sessió, el perfil es descarrega automàticament des del servidor cap a l'equip local; quan tanca sessió, els canvis es sincronitzen de tornada al servidor.
3. **Perfil Obligatori (*Mandatory Profile*):** És un perfil mòbil de només lectura (el fitxer `ntuser.dat` es renombra a `ntuser.man`). Si l'usuari canvia el fons de pantalla o desa arxius a l'escriptori, en tancar la sessió es descarten tots els canvis. Ideal per a aules d'informàtica i punts d'accés públics.

---

## 4. Automatització de Comptes amb PowerShell

En entorns educatius o corporatius amb centenars d'usuaris nous cada any, crear usuaris manualment mitjançant la interfície gràfica és inviable. PowerShell permet automatitzar altes massives a partir d'un fitxer CSV:

```powershell
# Creació d'un compte d'usuari individual amb contrasenya segura
$Password = ConvertTo-SecureString "P@ssw0rd2026!" -AsPlainText -Force
New-ADUser -Name "Joan Garcia" `
           -GivenName "Joan" `
           -Surname "Garcia" `
           -SamAccountName "jgarcia" `
           -UserPrincipalName "jgarcia@iesrafael.local" `
           -Path "OU=Professors,OU=Corporatiu,DC=iesrafael,DC=local" `
           -AccountPassword $Password `
           -Enabled $true `
           -ChangePasswordAtLogon $true
```
