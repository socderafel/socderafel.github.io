# 4.1 Sistemes d'Arxius de Xarxa i Protocols de Compartició (SMB/CIFS i NFS)

En qualsevol xarxa d'àrea local, la funció més demandada és la compartició centralitzada de documents, projectes i arxius entre usuaris i equips. Per a fer possible que un client puga obrir, modificar o guardar fitxers en un disc físicament ubicat en un servidor remot com si fora un disc local, s'utilitzen **protocols de sistemes de fitxers en xarxa**.

---

## 1. Els Dos Grans Protocols de Compartició: SMB vs. NFS

Al món dels sistemes operatius en xarxa conviuen dos grans estàndards:

```
+-------------------------------------------------------------------------+
|                  COMPARATIVA DE PROTOCOLS DE COMPARTICIÓ                |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ SMB / CIFS ] (Server Message Block)                                  |
|  - Ecosistema natiu: Windows / Samba (Linux).                           |
|  - Port de transport: TCP 445 (SMB directe sobre TCP/IP).               |
|  - Autenticació: Usuari/Contrasenya integrat amb Kerberos / NTLMv2.     |
|  - Versions modernes: SMB 3.1.1 (xifratge d'extrem a extrem AES-128/256)|
|                                                                         |
|  [ NFS ] (Network File System)                                          |
|  - Ecosistema natiu: UNIX / GNU/Linux.                                  |
|  - Port de transport: TCP 2049 (NFSv4).                                 |
|  - Autenticació: Tradicionalment basada en adreça IP del client (NFSv3) |
|    o mitjançant tiquets Kerberos (NFSv4 sec=krb5p).                     |
|  - Rendiment: Extraordinàriament ràpid per a servidors web o virtualit. |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 2. Creació de Recursos Compartits a Windows Server

A Windows Server podem crear una carpeta compartida mitjançant la interfície gràfica del Gestor del Servidor (*Server Manager -> Serveis d'arxius i emmagatzematge -> Recursos compartits*) o utilitzant comandes de **PowerShell**:

```powershell
# 1. Crear el directori físic al disc
New-Item -ItemType Directory -Path "D:\DadesEmpresa"

# 2. Compartir la carpeta a la xarxa amb el nom 'Projectes'
New-SmbShare -Name "Projectes" -Path "D:\DadesEmpresa" -FullAccess "DL_Projectes_Admin" -ReadAccess "DL_Projectes_Lectura"
```

### Carpetes Ocultes Administratives (El símbol `$`)
Si afegim el caràcter del dòlar `$` al final del nom de la compartició (per exemple `Dades$`), la carpeta es converteix en un **recurs compartit ocult**:
- No apareixerà a la llista d'equips de la xarxa de l'Explorador d'arxius.
- Per accedir-hi cal conéixer la ruta UNC exacta (`\\SRV-DC01\Dades$`).
- Windows Server crea automàticament comparticions administratives ocultes com `C$`, `ADMIN$` o `IPC$`, accessibles només pels Administradors del domini.

---

## 3. Accés a Recursos des dels Equips Client (Rutes UNC)

Per a accedir a una carpeta compartida a través de la xarxa des d'un ordinador client, s'utilitza la nomenclatura **UNC (*Universal Naming Convention*)**:

```
\\NomServidor_o_IP\NomRecursCompartit\Subcarpeta\fitxer.docx
Exemple: \\192.168.10.10\Projectes\pressupost.xlsx
```

Des de la línia de comandes o scripts d'inici, podem connectar una lletra d'unitat local fixa (com `Z:`) apuntant a la ruta UNC:

```cmd
:: Mapatge d'una unitat de xarxa amb persistència
net use Z: \\SRV-DC01\Projectes /persistent:yes
```
