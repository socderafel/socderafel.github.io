# 4.5 Servidor d'Arxius en Linux: Servidors NFS i Exportació de Directoris

Mentre que el protocol SMB domina en els entorns híbrids i estacions de treball Windows, el protocol **NFS (*Network File System*)** és el protocol d'emmagatzematge en xarxa natiu del món UNIX i Linux. És àmpliament utilitzat en clústers de servidors, emmagatzematge compartit per a màquines virtuals (Proxmox, VMware) i sistemes de computació d'alt rendiment per la seua velocitat i baixa sobrecàrrega de processament.

---

## 1. Instal·lació del Servidor NFS a Ubuntu Server

A distribucions Debian i Ubuntu, el servei s'instal·la mitjançant el paquet del nucli:

```bash
# Instal·lació del servei de servidor NFS
sudo apt update
sudo apt install -y nfs-kernel-server
```

---

## 2. Configuració de Directoris Exportats (`/etc/exports`)

En NFS, les carpetes compartides es denominen **exportacions**. La configuració es gestiona en el fitxer de text `/etc/exports`:

```bash
sudo nano /etc/exports
```

Sintaxi bàsica de les regles d'exportació:
```
/ruta/directori   client1(opcions)   client2(opcions)
```

Exemple professional de configuració:
```
/srv/nfs/dades     192.168.10.0/24(rw,sync,no_subtree_check,root_squash)
/srv/nfs/public    *(ro,sync,no_subtree_check)
```

### Significat de les Opcions Principals d'Exportació:
- `rw` (*read-write*): Permet lectures i escriptures des del client.
- `ro` (*read-only*): Accés exclusiu de només lectura.
- `sync`: Assegura que el servidor només respon al client quan les dades s'han gravat físicament al disc dur (màxima integritat davant fallades elèctriques).
- `no_subtree_check`: Millora l'estabilitat i el rendiment evitant verificacions complexes de subarbres de fitxers.
- `root_squash` (**Mecanisme crític de seguretat**): Si un usuari és `root` (UID 0) a la màquina client, el servidor NFS el degrada automàticament a l'usuari anònim `nobody`. Això impedeix que un atacant amb control d'un client Linux puga tindre poders de root sobre el disc del servidor.

Per aplicar els canvis sense reiniciar el servei:
```bash
# Reexportar tots els directoris definits a /etc/exports
sudo exportfs -ra

# Mostrar les exportacions actives del servidor
sudo exportfs -v
```

---

## 3. Muntatge de Recursos NFS en Equips Client Linux

A la màquina client cal instal·lar el paquet client de NFS:

```bash
# Instal·lació del client NFS
sudo apt install -y nfs-common

# 1. Comprovar quins recursos comparteix el servidor remot
showmount -e 192.168.10.20

# 2. Crear el punt de muntatge local
sudo mkdir -p /mnt/dades_remotes

# 3. Muntar manualment el recurs remot
sudo mount -t nfs 192.168.10.20:/srv/nfs/dades /mnt/dades_remotes
```

### Muntatge Automàtic Permanent (`/etc/fstab`)
Perquè el disc remot es munte de manera automàtica cada vegada que arranca l'ordinador client:

```bash
# Afegir al final del fitxer /etc/fstab del client
192.168.10.20:/srv/nfs/dades   /mnt/dades_remotes   nfs   defaults,_netdev   0   0
```

> **NOTA CLAU:** L'opció `_netdev` és vital: indica al sistema operatiu que espere a tindre la interfície de xarxa connectada abans d'intentar muntar el volum, evitant bloquejos durant l'arrancada.
