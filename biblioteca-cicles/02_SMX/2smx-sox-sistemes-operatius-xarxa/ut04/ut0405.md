# 4.5 Compartició de Recursos en Ubuntu Server amb Samba

**Samba** és la suite de programari lliure que implementa el protocol de compartició de xarxa SMB/CIFS sobre sistemes operatius tipus Unix/Linux, permetent que servidors Linux i estacions de treball Windows compartisquen fitxers i impressores de manera transparent.

---

## 🛠️ Procediment de Desplegament de Samba

### Pas 1: Instal·lació dels Paquets
```bash
sudo apt update
sudo apt install -y samba smbclient
```

### Pas 2: Creació de la Carpeta i Permisos Locals POSIX
```bash
# Crear la carpeta compartida
sudo mkdir -p /srv/compartit/projectes

# Crear el grup de seguretat 'projectes_equip'
sudo groupadd projectes_equip

# Assignar el propietari i el grup a la carpeta
sudo chown -R root:projectes_equip /srv/compartit/projectes

# Aplicar permisos 2775 (SGID perquè els nous fitxers pertanyen al grup)
sudo chmod -R 2775 /srv/compartit/projectes
```

### Pas 3: Donar d'alta els Usuaris a la Base de Dades de Samba
> [!IMPORTANT]
> Un usuari de Samba ha d'existir prèviament com a usuari del sistema Linux (`/etc/passwd`), però requereix una contrasenya de xarxa independent emmagatzemada a la base de dades interna de Samba (`passdb.tdb`).

```bash
# Afegir l'usuari 'tecnic1' a Samba
sudo smbpasswd -a tecnic1
# Introduir la contrasenya de xarxa: Smx2024!

# Activar el compte a Samba si cal
sudo smbpasswd -e tecnic1
```

### Pas 4: Configuració de `/etc/samba/smb.conf`
Editem el fitxer principal de configuració:
```bash
sudo nano /etc/samba/smb.conf
```

Afegim la definició del recurs al final del document:
```ini
[Projectes]
   comment = Carpeta Compartida d'Equip de Projectes
   path = /srv/compartit/projectes
   browseable = yes
   read only = no
   guest ok = no
   valid users = @projectes_equip
   create mask = 0664
   directory mask = 0775
```

### Pas 5: Validació de Sintaxi i Reinici del Servei
```bash
# Verificar que el fitxer no conté errors de sintaxi
testparm

# Reiniciar els dimonis de Samba (smbd per a fitxers i nmbd per a resolució NetBIOS)
sudo systemctl restart smbd nmbd

# Comprovar l'estat del servei
sudo systemctl status smbd
```

### Pas 6: Comprovació des del Client Windows
Des d'un ordinador client Windows de la xarxa, prem les tecles Windows + R i escriu la ruta UNC:
`\\192.168.100.20\Projectes`
Introdueix l'usuari `tecnic1` i la contrasenya configurada per accedir a la carpeta compartida de Linux!
