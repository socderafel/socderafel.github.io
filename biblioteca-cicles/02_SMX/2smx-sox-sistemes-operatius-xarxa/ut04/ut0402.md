# 4.2 Permisos de Recursos Compartits vs. Permisos de Seguretat NTFS

Un dels conceptes més importants i que genera més confusió entre els tècnics novells és la coexistència de **dues capes de permisos independents** quan s'accedeix a un fitxer a través de la xarxa:
1. Els **Permisos de Compartició** (*Share Permissions*).
2. Els **Permisos del Sistema de Fitxers NTFS** (*NTFS Permissions* o Seguretat).

---

## 1. Naturalesa de Cadascuna de les Dues Capes

```
+-------------------------------------------------------------------------+
|                  LES DUES BARRERES DE SEGURETAT DE XARXA                |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Usuari Client ]                                                      |
|        |                                                                |
|        v (Accés per xarxa \\server\carpeta)                             |
|  +-------------------------------------------------------------------+  |
|  | BARRERA 1: Permisos de Compartició (Pestanya 'Compartir')         |  |
|  | - S'apliquen NOMÉS quan s'accedeix a través de la xarxa.          |  |
|  | - Opcions simples: Lectura, Canvi (Change) i Control Total.       |  |
|  +-------------------------------------------------------------------+  |
|        |                                                                |
|        v (Si supera la Barrera 1)                                       |
|  +-------------------------------------------------------------------+  |
|  | BARRERA 2: Permisos NTFS (Pestanya 'Seguretat')                   |  |
|  | - S'apliquen SEMPRE (tant per xarxa com si s'inicia en local).    |  |
|  | - Granulars: Lectura, Escriptura, Modificació, Control Total, etc. |  |
|  | - Suporten herència i llistes de control d'accés (ACL).           |  |
|  +-------------------------------------------------------------------+  |
|        |                                                                |
|        v                                                                |
|  [ PERMÍS EFECTIU FINAL = EL MÉS RESTRICTIU DELS DOS ]                  |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 2. La Regla d'Or del Permís Efectiu

Quan un usuari accedeix per xarxa a un recurs protegit per ambdues capes:
> **El permís efectiu final és SEMPRE EL MÉS RESTRICTIU entre el permís de Compartició i el permís NTFS.**

### Exemples d'Avaluació de Permisos Efectius:
1. **Cas 1:** Compartició = *Control Total*, NTFS = *Lectura*.
   - **Permís efectiu:** **Lectura** (NTFS restringeix l'escriptura).
2. **Cas 2:** Compartició = *Lectura*, NTFS = *Modificació*.
   - **Permís efectiu:** **Lectura** (La compartició actua com un embut estret i no deixa passar canvis).
3. **Cas 3:** Compartició = *Canvi*, NTFS = *Modificació*.
   - **Permís efectiu:** **Modificació** (Permet llegir, escriure, modificar i esborrar).

---

## 3. Bona Pràctica Professional Recomanada per Microsoft

Com que gestionar dues capes de permisos granulars simultàniament és propens a errors:
- **Estratègia estàndard:** Es configura la capa de **Compartició** amb permisos amplis per al grup d'usuaris del domini (*Usuaris autenticats -> Canvi* o *Control total*).
- **El control real de la seguretat:** Es delega **al 100% en la pestanya 'Seguretat' (NTFS)**, aplicant la metodologia AGDLP amb llistes ACL precises.
- D'aquesta manera, si un usuari intenta accedir localment o per RDP, tindrà exactament els mateixos permisos que si accedeix per la xarxa.

---

## 4. Herència de Permisos a NTFS

Per defecte, qualsevol subcarpeta o fitxer creat hereta els permisos de la carpeta pare:
- Si volem que una subcarpeta tinga permisos totalment independents (per exemple, una carpeta privada de Direcció dins d'una carpeta general d'Empresa), cal:
  1. Anar a *Propietats -> Seguretat -> Opcions avançades*.
  2. Fer clic al botó **Deshabilitar l'herència**.
  3. L'assistent donarà dues opcions:
     - *Convertir els permisos heretats en permisos explícits* (recomanat per a mantenir una base i eliminar el que no vullgues).
     - *Llevar tots els permisos heretats* (comença des de zero).
