# 4.4 Quotes de Disc i Filtració de Fitxers amb FSRM (File Server Resource Manager)

Si permetem als usuaris guardar lliurement fitxers en un servidor corporatiu sense cap tipus de control, ràpidament ens trobarem amb discs plens de vídeos personals, pel·lícules, música, instal·ladors de jocs o, en el pitjor dels casos, fitxers binaris maliciosos.

A Windows Server, l'eina definitiva per a governar l'ús de l'emmagatzematge és el servei de rol **Administrador de recursos del servidor d'arxius (*File Server Resource Manager* - FSRM)**.

---

## 1. Tipus de Quotes d'Emmagatzematge amb FSRM

FSRM permet establir límits d'espai sobre carpetes o volums sencers:

```
+-------------------------------------------------------------------------+
|                        MODALITATS DE QUOTES A FSRM                      |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ QUOTA RÍGIDA (Hard Quota) ]                                          |
|  - Estableix un límit infranquejable (ex: 5 GB per alumne).             |
|  - Si l'usuari arriba al límit, Windows BLOQUEJA l'escriptura i         |
|    mostra el missatge: 'No hi ha prou espai en disc'.                   |
|                                                                         |
|  [ QUOTA TOVA (Soft Quota) ]                                            |
|  - Permet a l'usuari continuar desant fitxers fins i tot si supera el   |
|    límit establit (ex: 5 GB).                                           |
|  - S'utilitza per a monitorització: envia alertes per correu electrònic |
|    a l'administrador i genera un registre d'auditoria (Event Log).      |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Plantilles de Quota (*Quota Templates*)
FSRM treballa amb plantilles reutilitzables (com *Límit de 10 GB per defecte*). Si modifiquem la plantilla, s'actualitzen automàticament les quotes de tots els usuaris vinculats a eixa plantilla.

---

## 2. Filtració de Fitxers (*File Screening*)

La filtració de fitxers permet bloquejar l'emmagatzematge de determinades tipologies de fitxers basant-se en les seues extensions:

1. **Grups de fitxers (*File Groups*):** Conjunts d'extensions com:
   - *Arxius d'àudio i vídeo:* `*.mp3`, `*.mp4`, `*.avi`, `*.mkv`, `*.mov`.
   - *Fitxers executables:* `*.exe`, `*.msi`, `*.bat`, `*.cmd`, `*.vbs`.
   - *Ransomware conegut:* extensions típiques de xifratge maliciós (ex: `*.locky`, `*.crypto`).
2. **Accions automàtiques:**
   - **Filtració activa (*Active screening*):** Impedeix que l'usuari guarde o copie l'arxiu bloquejat a la carpeta.
   - **Filtració passiva (*Passive screening*):** Deixa desar el fitxer però envia una alerta a l'equip de seguretat.

---

## 3. Instal·lació i Gestió de FSRM per PowerShell

```powershell
# 1. Instal·lar el servei de rol FSRM i les eines de gestió
Install-WindowsFeature -Name FS-Resource-Manager -IncludeManagementTools

# 2. Crear una quota rígida de 2 GB sobre la carpeta de projectes
New-FsrmQuota -Path "D:\DadesEmpresa\Projectes" -Size 2GB -SoftLimit:$false

# 3. Crear una regla de filtració activa contra fitxers d'àudio i vídeo
New-FsrmFileScreen -Path "D:\DadesEmpresa\Projectes" -IncludeGroup "Audio and Video Files" -Active
```
