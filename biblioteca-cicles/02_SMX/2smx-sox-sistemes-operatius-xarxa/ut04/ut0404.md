# 4.4 Compartició de Recursos en Microsoft Windows Server

En Windows Server 2022, la gestió de carpetes compartides es pot realitzar des de la interfície gràfica de l'Administrador del Servidor o mitjançant cmdlets de PowerShell.

---

## 🛠️ Creació d'un Recurs Compartit SMB amb PowerShell

```powershell
# 1. Crear la carpeta física al disc local del servidor
New-Item -ItemType Directory -Path "D:\DadesDepartaments\Administracio" -Force

# 2. Configurar la seguretat NTFS:
# Afegir el grup 'DL_Administracio_Modificar' amb permís Modify
$Acl = Get-Acl "D:\DadesDepartaments\Administracio"
$Ar = New-Object System.Security.AccessControl.FileSystemAccessRule("SMX\DL_Administracio_Modificar", "Modify", "ContainerInherit,ObjectInherit", "None", "Allow")
$Acl.SetAccessRule($Ar)
Set-Acl "D:\DadesDepartaments\Administracio" $Acl

# 3. Publicar el recurs compartit en xarxa SMB
New-SmbShare `
    -Name "Administracio" `
    -Path "D:\DadesDepartaments\Administracio" `
    -FullAccess "Everyone" `
    -Description "Carpeta compartida del Departament d'Administració"

# 4. Comprovar que el recurs està actiu i escoltant connexions
Get-SmbShare -Name "Administracio"
```

## 🛡️ Gestor de Recursos del Servidor de Fitxers (FSRM)

El rol **FSRM (*File Server Resource Manager*)** afegeix capacitats professionals avançades:
1. **Quotes de Disc (*Quotas*):**
   - **Quota dura (*Hard Quota*):** Impedeix que els usuaris continuen desant fitxers quan arriben al límit assignat (ex: màxim 5 GB per alumne).
   - **Quota tova (*Soft Quota*):** Permet sobrepassar el límit però envia un correu d'alerta o registra un avís a l'administrador.
2. **Filtratge de Fitxers (*File Screening*):**
   - Bloqueja l'emmagatzematge de tipus de fitxers no autoritzats (ex: impedir que es guarden fitxers de vídeo `.mp4`, `.mkv` o fitxers executables `.exe` a les carpetes compartides de documents escolars).
