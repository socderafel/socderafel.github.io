# 4.3 Carpetes Personals d'Usuari (Home Folders) i Redirecció de Carpetes per GPO

Si els usuaris guarden els seus documents de treball al disc dur local del seu ordinador d'oficina (com a `C:\Users\nom\Documents`), es generen dos problemes greus:
1. Si el PC pateix una fallada física de disc, les dades es perden per complet en no estar incloses en la còpia de seguretat centralitzada del servidor.
2. Si l'usuari s'asseu en un altre ordinador de l'oficina, no té accés als seus fitxers personals.

La solució professional combina dues tecnologies: les **Carpetes Personals (*Home Folders*)** i la **Redirecció de Carpetes per GPO**.

---

## 1. Configuració de Carpetes Personals (*Home Folders*)

La carpeta personal permet assignar automàticament a cada usuari una lletra d'unitat (típicament `H:` de *Home*) que apunta a una carpeta privada del servidor:

```
Ruta compartida base: \\SRV-DC01\Homes$\%username%
```

A les propietats de l'usuari a Active Directory (pestanya *Perfil -> Carpeta personal*):
- Es marca l'opció **Connectar**.
- Es tria la lletra (ex: `H:`).
- S'introdueix la ruta: `\\SRV-DC01\Homes$\%username%`.
- El sistema operatiu resol la variable d'entorn `%username%`, crea automàticament la subcarpeta amb el nom de l'usuari i li assigna permisos exclusius de *Control Total* (impedint fins i tot l'accés a altres usuaris ordinaris).

---

## 2. Redirecció de Carpetes mitjançant Directiva de Grup (GPO)

Mentre que la carpeta personal requereix que l'usuari s'acostume a desar manualment a la unitat `H:`, la **Redirecció de Carpetes (*Folder Redirection*)** és completament transparent per a l'usuari:
- Redirigeix les carpetes típiques de la biblioteca de Windows (*Documents*, *Escriptori*, *Imatges*, *Descàrregues*) cap a una ruta del servidor de fitxers.
- Quan l'empleat desa un fitxer al seu "Escriptori" o "Documents", el fitxer s'està desant físicament al servidor central sense que l'usuari note cap canvi.

```
+-------------------------------------------------------------------------+
|                  ARQUITECTURA DE LA REDIRECCIÓ DE CARPETES              |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Client Windows 10/11 ]                                               |
|  +---------------------------------+                                    |
|  | C:\Users\jgarcia\Documents       | --(Redirigit transparentment)-->   |
|  | C:\Users\jgarcia\Desktop         |                                    |
|  +---------------------------------+                                    |
|                                                                         |
|                              |                                          |
|                              v                                          |
|  [ Servidor de Fitxers Central ]                                        |
|  +-------------------------------------------------------------------+  |
|  | \\SRV-DC01\Redireccio$\jgarcia\Documents                          |  |
|  | \\SRV-DC01\Redireccio$\jgarcia\Desktop                            |  |
|  +-------------------------------------------------------------------+  |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Configuració a la Consola GPMC (`gpmc.msc`):
1. Navegar a: `Configuració de l'usuari -> Directives -> Configuració de Windows -> Redirecció de carpetes`.
2. Fer clic dret sobre **Documents** -> *Propietats*.
3. Pestanya *Configuració*: Seleccionar **Bàsica: redirigir la carpeta de tots a la mateixa ubicació**.
4. Ubicació de la carpeta de destinació: **Crear una carpeta per a cada usuari sota la ruta d'arrel**.
5. Ruta d'arrel: `\\SRV-DC01\Redireccio$`.

---

## 3. Fitxers sense Connexió (*Offline Files*) i Caching CSC

Quan combinem la redirecció de carpetes amb equips portàtils que ixen fora de l'oficina, entra en joc la tecnologia **Fitxers sense connexió (*Offline Files* / Client-Side Caching - CSC)**:
- Windows manté una còpia en memòria cau local dels documents del servidor.
- Si el treballador s'emporta el portàtil a un viatge sense connexió a la xarxa corporativa, pot continuar treballant amb els seus documents.
- Quan el portàtil es reconnecta a la xarxa de l'oficina o s'estableix una connexió VPN, el **Centre de Sincronització** de Windows detecta els canvis i sincronitza automàticament les versions amb el servidor.
