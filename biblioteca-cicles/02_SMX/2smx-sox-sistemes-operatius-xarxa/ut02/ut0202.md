# 2.2 Promoció d'un Servidor a Controlador de Domini (DC) a Windows Server

Un servidor Windows Server recentment instal·lat és simplement un servidor independent (*Standalone Server*). Perquè es convertisca en el cervell de la xarxa, cal instal·lar el rol **Active Directory Domain Services (AD DS)** i executar el procés de **promoció a Controlador de Domini**.

---

## 1. Requisits Previs Innegociables

Abans d'iniciar la promoció, és obligatori comprovar tres requisits:
1. **Nom del servidor definit:** Canviar el nom aleatori per una nomenclatura estàndard (ex: `SRV-DC01`).
2. **Adreça IP fixa:** Assignar una IP estàtica (ex: `192.168.10.10/24`). El servidor DNS ha d'apuntar a si mateix (`127.0.0.1` o `192.168.10.10`).
3. **Contrasenya d'administrador local forta:** La contrasenya del compte `Administrator` local s'utilitzarà durant el procés de transició.

---

## 2. Procés d'Instal·lació del Rol AD DS

La instal·lació es divideix en dues etapes diferenciades:
- **Etapa 1: Instal·lació dels binaris del rol:** S'instal·len les eines de gestió i els serveis d'AD DS mitjançant el Gestor del Servidor (*Server Manager*) o per PowerShell:

```powershell
# Instal·lació del rol AD DS i les eines RSAT
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
```

- **Etapa 2: Promoció del servidor (Configuració del bosc i domini):**
  Després d'instal·lar els binaris, apareix una notificació al Server Manager: *"Promoure aquest servidor a controlador de domini"*.
  En l'assistent de configuració:
  1. **Operació d'implementació:** Seleccionar **Afegir un nou bosc (*Add a new forest*)** i establir el nom de domini arrel en format FQDN (per exemple: `iesrafael.local` o `corp.val`).
  2. **Nivell funcional del bosc i domini:** Determina quines versions de Windows Server podran actuar com a controladors de domini addicionals (habitualment Windows Server 2016 o superior).
  3. **Capacitats del controlador de domini:** Deixar marcades les opcions **Servidor de sistema de noms de domini (DNS)** i **Catàleg global (GC)**.
  4. **Contrasenya DSRM (*Directory Services Restore Mode*):** Contrasenya d'emergència fonamental per a recuperar o restaurar la base de dades d'Active Directory en cas de fallada greu.
  5. **Nom NetBIOS del domini:** L'assistent assigna el nom curt tradicional (ex: `IESRAFAEL`).
  6. **Rutes de les carpetes de la base de dades:**
     - Base de dades NTDS: `C:\Windows\NTDS\ntds.dit`
     - Fitxers de registre (Logs): `C:\Windows\NTDS`
     - Carpeta SYSVOL: `C:\Windows\SYSVOL` (emmagatzema les GPOs i scripts d'inici compartits).

```powershell
# Promoció automatitzada per PowerShell
Install-ADDSForest `
  -DomainName "iesrafael.local" `
  -DomainNetbiosName "IESRAFAEL" `
  -InstallDns:$true `
  -CreateDnsDelegation:$false `
  -DatabasePath "C:\Windows\NTDS" `
  -LogPath "C:\Windows\NTDS" `
  -SysvolPath "C:\Windows\SYSVOL" `
  -NoRebootOnCompletion:$false
```

---

## 3. Comprovació i Verificació del Desplegament

Un cop reiniciat el servidor, el compte local `Administrator` es converteix en `IESRAFAEL\Administrator` (Administrador del Domini). Per verificar que el servei funciona al 100%, utilitzem tres eines de diagnòstic:

```powershell
# 1. Comprovar que el servidor és reconegut com a DC
Get-ADDomainController

# 2. Executar el diagnòstic integral de salut del controlador de domini
dcdiag /v

# 3. Comprovar que la carpeta SYSVOL està compartida correctament
net share
```
