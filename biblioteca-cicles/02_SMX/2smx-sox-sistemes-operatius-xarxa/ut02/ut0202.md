# 2.2 Serveis de Directori i Nomenclatura LDAP

Un **servei de directori** és un sistema d'emmagatzematge d'informació especialitzat, optimitzat per a una ràpida lectura, cerca i consulta de dades sobre usuaris, equips, impressores i serveis d'una organització.

---

## 📖 El Protocol LDAP (Lightweight Directory Access Protocol)

El protocol estàndard per a interactuar amb serveis de directori és **LDAP** (especificat a l'RFC 4511), que opera sobre el port TCP **389** (o TCP **636** per a connexions xifrades segures amb TLS/SSL - **LDAPS**).

### 🏷️ Nomenclatura X.500 i Rutes Distingides (Distinguished Names - DN)
Cada objecte dins de la base de dades del directori té una ruta jeràrquica unívoca anomenada **DN** (*Distinguished Name*). Està compost per diversos components:

- **CN (*Common Name*):** El nom de l'objecte final o fulla (ex: un usuari o un grup).
- **OU (*Organizational Unit*):** La Unitat Organitzativa on resideix l'objecte.
- **DC (*Domain Component*):** Cada part del nom de domini DNS dividit pels punts.

### Exemple Pràctic de Traducció de Ruta:
Volem identificar l'usuari Joan Garcia (`joan.garcia`), que es troba a la Unitat Organitzativa `Alumnes`, dins del domini `smx.local`:

$$\mathbf{DN} = \text{CN=Joan Garcia, OU=Alumnes, DC=smx, DC=local}$$

- **RDN (*Relative Distinguished Name*):** El primer segment relatiu de l'objecte: `CN=Joan Garcia`.

---

## 🔍 Consulta d'Objectes mitjançant la Comanda `dsquery` i PowerShell

En Windows Server es poden executar consultes de directori immediates des de la consola:

```powershell
# Cercar el DN exacte d'un compte d'usuari pel seu nom de compte SAM
dsquery user -samid "joan.garcia"

# Cercar tots els equips que estan dins de la OU d'Aules
Get-ADComputer -Filter * -SearchBase "OU=Aules,DC=smx,DC=local" | Select-Object Name, IPv4Address

# Cercar usuaris amb el compte deshabilitat
Search-ADAccount -AccountDisabled -UsersOnly
```
