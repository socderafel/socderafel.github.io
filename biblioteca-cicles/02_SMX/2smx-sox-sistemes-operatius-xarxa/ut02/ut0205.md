# 2.5 Instal·lació d'Active Directory i OpenLDAP

L'administrador de xarxa ha de conèixer tant la implementació hegemònica en el món empresarial de Microsoft (AD DS) com l'estàndard obert en entorns Linux (OpenLDAP).

---

## 🪟 Desplegament Gràfic d'Active Directory en Windows Server

1. Obre l'**Administrador del Servidor (*Server Manager*)**.
2. Fes clic a **Administrar** $\rightarrow$ **Afegeix rols i característiques**.
3. Selecciona **Instal·lació basada en característiques o en rols**.
4. A la llista de rols de servidor, marca: **Serveis de domini de l'Active Directory (AD DS)**.
5. Fes clic a Següent fins a finalitzar la instal·lació dels binaris.
6. A la part superior dreta de l'Administrador del Servidor, fes clic sobre la **bandera de notificacions groga** i selecciona: **Promoure aquest servidor a controlador de domini**.
7. A l'assistent de configuració de desplegament:
   - Selecciona: **Afegeix un bosc nou** (*Add a new forest*).
   - Nom de domini arrel: `smx.local`.
   - Nivell funcional del bosc i domini: `Windows Server 2016` o `Windows Server 2022`.
   - Assegura't que la casella **Servidor del sistema de noms de domini (DNS)** estiga marcada.
   - Defineix la contrasenya del mode de restauració de serveis de directori (**DSRM**): `Dsrm2024!`.
8. Accepta les rutes per defecte de les bases de dades (`C:\Windows\NTDS` i `SYSVOL`) i prem **Instal·la**. El servidor es reiniciarà automàticament.

---

## 🐧 Desplegament d'OpenLDAP en Ubuntu Server

En entorns GNU/Linux, el servei de directori obert per excel·lència és **slapd** (*Stand-Alone LDAP Daemon*):

```bash
# Actualitzar repositoris i instal·lar slapd i les utilitats de client LDAP
sudo apt update
sudo apt install -y slapd ldap-utils

# Reconfigurar el paquet per establir el domini base
sudo dpkg-reconfigure slapd
# Triar:
# - Ometre configuració inicial: No
# - Nom de domini DNS: smx.local (crearà la base dc=smx,dc=local)
# - Nom de l'organització: IES SMX
# - Contrasenya d'administrador admin: Admin2024!
# - Motor de base de dades: MDB (recomanat)

# Comprovar que el dimoni slapd està corrent al port 389
sudo systemctl status slapd
ss -tlpn | grep 389

# Realitzar una cerca de prova de l'arrel del directori
ldapsearch -x -b "dc=smx,dc=local" -s base
```
