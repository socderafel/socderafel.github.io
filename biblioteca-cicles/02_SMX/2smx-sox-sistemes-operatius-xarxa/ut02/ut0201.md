# 2.1 Conceptes de Directori i Arquitectura d'Active Directory Domain Services (AD DS)

En una organització amb desenes d'ordinadors, gestionar els usuaris màquina a màquina és inviable. La solució estàndard en xarxes corporatives és la implantació d'un **Servei de Directori**.

Un servei de directori és una base de dades jeràrquica i especialitzada, optimitzada per a lectures ràpides i consultes concurrents, que emmagatzema informació sobre tots els recursos de la xarxa (usuaris, grups, equips, impressores, carpetes compartides) i en centralitza l'autenticació i l'assignació de permisos.

```
+-------------------------------------------------------------------------+
|                  JERARQUIA LÒGICA D'ACTIVE DIRECTORY                    |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ BOSC (Forest) ]               Límit màxim de seguretat.              |
|        |                         Comparteix un únic Esquema i Catàleg.  |
|        v                                                                |
|  [ ARBRE (Tree) ]                Conjunt de dominis amb espai de noms   |
|        |                         DNS contigu (ex: corporacio.val).      |
|        v                                                                |
|  [ DOMINI (Domain) ]             Límit administratiu i de polítiques.   |
|        |                         (ex: seu-valencia.corporacio.val).     |
|        v                                                                |
|  [ UNITAT ORGANITZATIVA (OU) ]   Contenidor lògic per aplicar GPO i     |
|        |                         delegar administració (ex: Vendes).    |
|        v                                                                |
|  [ OBJECTES ]                    Usuaris, Grups, Equips, Impressores.   |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 1. Estructura Lògica d'Active Directory

Active Directory organitza els seus components en una estructura lògica ben definida:

1. **Objectes (*Objects*):** Són les unitats bàsiques d'informació. Cada objecte representa un element físic o lògic (un usuari com `joan.garcia`, un equip com `PC-AULA10`, un grup de seguretat). Cada objecte té **atributs** (nom, correu electrònic, telèfon, contrasenya xifrada, etc.).
2. **Esquema (*Schema*):** És la definició formal que estableix quins tipus d'objectes poden existir a la base de dades i quins atributs obligatoris o opcionals poden tindre. Només hi ha **un únic esquema per a tot el bosc**.
3. **Unitats Organitzatives (*Organizational Units - OUs*):** Són carpetes o contenidors lògics dins d'un domini que serveixen per a agrupar objectes segons criteris funcionals, departamentals o geogràfics. Són l'element de nivell més baix sobre el qual es poden aplicar **Directives de Grup (GPOs)** i sobre el qual es pot **delegar el control administratiu**.
4. **Domini (*Domain*):** És la unitat fonamental d'administració i seguretat. Tots els objectes d'un domini comparteixen una mateixa base de dades (`ntds.dit`), una mateixa política de contrasenyes i una relació de confiança intrínseca.
5. **Arbre (*Tree*) i Bosc (*Forest*):**
   - Un **Arbre** és una agrupació d'un o més dominis que comparteixen un mateix espai de noms DNS contigu (per exemple: `iesrafael.edu`, `alumnes.iesrafael.edu`, `profes.iesrafael.edu`).
   - Un **Bosc** és el límit màxim de seguretat d'Active Directory. Pot contenir múltiples arbres amb espais de noms diferents (per exemple, si dues empreses es fusionen), però tots ells comparteixen un mateix Esquema comú, un mateix Catàleg Global i relacions de confiança transitives bidireccionals.

---

## 2. Estructura Física: Llocs (*Sites*) i Controladors de Domini (*DCs*)

Mentre que l'estructura lògica s'adapta a l'organització de l'empresa, l'estructura física s'adapta a la infraestructura de xarxa real:

- **Controlador de Domini (*Domain Controller - DC*):** És el servidor físic o virtual que allotja la base de dades d'Active Directory (`C:\Windows\NTDS\ntds.dit`), respon a les sol·licituds d'autenticació (via Kerberos o NTLM) i replica els canvis amb altres DCs.
- **Llocs (*Sites*):** Representen una o diverses subxarxes IP connectades mitjançant enllaços de xarxa d'alta velocitat i baixa latència (normalment una seu o edifici físic). Configurar llocs permet optimitzar el trànsit de replicació entre seus remotes i assegurar que un usuari s'autentique contra el controlador de domini més proper geogràficament.

---

## 3. La Dependència Absoluta del Servei DNS

L'Active Directory **no pot funcionar sense un servei DNS actiu i correctament configurat**:
- Quan un equip client vol iniciar sessió al domini, necessita localitzar un controlador de domini disponible.
- Això ho fa consultant al DNS els registres especials de servei: els registres **SRV** (com `_ldap._tcp.dc._msdcs.elmeudomini.lan`).
- Si el client té mal configurada la IP del servidor DNS, serà completament incapaç de contactar amb el controlador de domini, donant el típic error: *"No es pot contactar amb un controlador de domini per al domini..."*.
