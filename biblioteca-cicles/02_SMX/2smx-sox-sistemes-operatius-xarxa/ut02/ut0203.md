# 2.3 Gestió d'Unitats Organitzatives (OU) i Estructuració del Domini

Quan un domini acaba de ser creat, la consola **Usuaris i Equips d'Active Directory** (`dsa.msc`) o el **Centre d'Administració d'Active Directory (ADAC)** mostren uns contenidors per defecte com `Users` i `Computers`. Tanmateix, aquests contenidors són carpetes genèriques del sistema: **no admeten la vinculació directa de Directives de Grup (GPO)**.

Per a organitzar eficaçment una xarxa corporativa, és obligatori dissenyar una jerarquia d'**Unitats Organitzatives (OUs)**.

---

## 1. Criteris per al Disseny d'Unitats Organitzatives

Una Unitat Organitzativa permet complir dos objectius fonamentals:
1. **Aplicació selectiva de directives (GPO):** Els usuaris o equips que resideixen en una OU reben les configuracions i restriccions definides per a eixa OU.
2. **Delegació de control administratiu:** Permet atorgar a un tècnic auxiliar permisos per a restablir contrasenyes o crear usuaris en una OU específica, sense concedir-li permisos d'administrador complet del domini.

```
+-------------------------------------------------------------------------+
|                  EXEMPLE D'ESTRUCTURA JERÀRQUICA D'OUs                  |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ iesrafael.local ]                                                    |
|        |                                                                |
|        +--- [ OU: Corporatiu ]                                          |
|                 |                                                       |
|                 +--- [ OU: Direcció ]                                   |
|                 |         +-- Usuaris                                   |
|                 |         +-- Equips                                    |
|                 |                                                       |
|                 +--- [ OU: Professorat ]                                |
|                 |         +-- Usuaris                                   |
|                 |         +-- Equips                                    |
|                 |                                                       |
|                 +--- [ OU: Alumnat ]                                    |
|                 |         +-- Usuaris                                   |
|                 |         +-- Equips-Aules                              |
|                 |                                                       |
|                 +--- [ OU: Servidors-Membres ]                          |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 2. Creació d'Unitats Organitzatives i Protecció contra Eliminació

Quan creem una OU, hem d'activar sempre la casella **Protegir contenidor contra eliminació accidental**:
- Aquesta opció afegeix una llista de control d'accés (ACL) que impedeix que qualsevol administrador esborre per error una branca sencera d'usuaris amb una simple pulsació de la tecla Supr.

Mitjançant PowerShell, podem crear la jerarquia d'OUs de forma immediata:

```powershell
# Creació d'una Unitat Organitzativa arrel protegida
New-ADOrganizationalUnit -Name "Corporatiu" -Path "DC=iesrafael,DC=local" -ProtectedFromAccidentalDeletion $true

# Creació de sub-OUs per a departaments
New-ADOrganizationalUnit -Name "Professors" -Path "OU=Corporatiu,DC=iesrafael,DC=local" -ProtectedFromAccidentalDeletion $true
New-ADOrganizationalUnit -Name "Alumnes" -Path "OU=Corporatiu,DC=iesrafael,DC=local" -ProtectedFromAccidentalDeletion $true
```

---

## 3. Delegació de Control Administratiu

Un dels grans avantatges de les OUs és el principi de **mínim privilegi**:
- En lloc de donar permisos d'Administrador del Domini a tothom, podem delegar tasques concretes.
- Fent clic dret sobre una OU -> **Delegar control...**, s'obre un assistent que permet assignar a un usuari o grup tasques típiques com:
  - *Restablir contrasenyes d'usuaris i forçar canvi de contrasenya en el següent inici de sessió.*
  - *Crear, eliminar i administrar comptes d'usuari.*
  - *Modificar la pertinença a un grup.*
