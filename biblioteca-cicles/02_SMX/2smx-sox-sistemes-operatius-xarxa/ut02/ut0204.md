# 2.4 Vinculació d'Equips Client al Domini (Windows 10/11 i Linux)

Una vegada configurat el controlador de domini i estructurada la jerarquia d'Unitats Organitzatives, el següent pas operatiu és **unir els ordinadors clients al domini corporatiu**. Quan un equip s'uneix al domini, es crea una relació de confiança segura entre el client i el controlador de domini, establint un canal segur xifrat per a validar credencials i aplicar polítiques GPO.

---

## 1. Requisits Previs del Client Windows

Abans d'intentar unir una màquina Windows al domini:
1. **Edició del sistema operatiu:** Només les edicions **Windows Pro, Enterprise o Education** admeten unir-se a dominis Active Directory. L'edició *Windows Home* **NO ho admet**.
2. **Configuració del Servidor DNS primari:** El client **HA DE tindre configurada com a servidor DNS primari l'adreça IP del Controlador de Domini** (ex: `192.168.10.10`). Si té com a DNS `8.8.8.8` o la IP del router, la unió fallarà immediatament.
3. **Resolució de noms provada:** Executar des de la consola del client:
   ```cmd
   ping iesrafael.local
   nslookup iesrafael.local
   ```
4. **Sincronització horària:** El rellotge del client i del DC no poden diferir en més de 5 minuts (tolerància màxima del protocol Kerberos).

---

## 2. Procés d'Unió d'un Client Windows 10/11

El procés es pot realitzar mitjançant la interfície gràfica clàssica o per PowerShell:

### A. Mitjançant Interfície Gràfica (`sysdm.cpl`)
1. Prémer `Win + R` i escriure **`sysdm.cpl`** (Propietats del sistema).
2. A la pestanya *Nom d'equip*, fer clic al botó **Canviar...**.
3. A la secció *Membre de*, seleccionar l'opció **Domini** i escriure el nom del domini (ex: `iesrafael.local`).
4. S'obrirà una finestra de credencials: cal introduir un compte d'usuari amb permisos per a unir equips al domini (per defecte, qualsevol usuari del domini pot unir fins a 10 equips, o bé l'administrador).
5. Després d'uns segons, apareixerà el missatge: *"Benvingut al domini iesrafael.local"*.
6. Reiniciar l'ordinador per completar la unió.

### B. Mitjançant PowerShell (Comanda professional)
```powershell
# Executar a la consola de PowerShell del client com a administrador
Add-Computer -DomainName "iesrafael.local" -Restart
```

---

## 3. Què passa en un equip client unit al domini?

Un cop reiniciat l'equip:
- La pantalla d'inici de sessió permet triar entre iniciar com a usuari local o iniciar com a usuari del domini (`DOMINI\usuari` o `usuari@domini.local`).
- El grup **Admins. del domini (*Domain Admins*)** s'afegeix automàticament al grup local **Administradors** del client. Això permet que qualsevol tècnic d'Active Directory puga administrar remotament qualsevol ordinador corporatiu.
- El client comença a descarregar i aplicar automàticament les Directives de Grup (GPO) de la seua Unitat Organitzativa.

---

## 4. Vinculació d'un Client Linux Server / Desktop al Domini

Avui en dia, la interoperabilitat permet integrar màquines Linux completament dins d'Active Directory mitjançant **`realmd`** i **`sssd`** (*System Security Services Daemon*):

```bash
# 1. Instal·lar paquets d'integració a Ubuntu/Debian
sudo apt update
sudo apt install -y realmd sssd sssd-tools adcli samba-common-bin packagekit

# 2. Descobrir el domini mitjançant DNS
realm discover iesrafael.local

# 3. Unir la màquina Linux al domini amb credencials d'administrador
sudo realm join -U Administrator iesrafael.local

# 4. Habilitar la creació automàtica del directori home a l'inici de sessió
sudo pam-auth-update --enable mkhomedir
```
