# 5.1 Eines de Monitorització del Sistema i Mètriques Clau

Un bon administrador de sistemes no espera que els usuaris telefonen enfadats perquè el servidor ha col·lapsat o la xarxa va excessivament lenta. La **monitorització proactiva** consisteix a mesurar contínuament la salut i el rendiment dels recursos vitals del servidor per a detectar colls d'ampolla abans que provoquen una caiguda de servei.

---

## 1. Els Quatre Pilars de Rendiment d'un Servidor

La salut d'un sistema operatiu en xarxa s'avalua sobre quatre components fonamentals:

```
+-------------------------------------------------------------------------+
|                  ELS QUATRE RECURSOS VITALES D'UN SERVIDOR              |
+-------------------------------------------------------------------------+
|                                                                         |
|  1. PROCESSADOR (CPU)     Percentatge d'ús total i per procés.          |
|                           Cua de processador (threads en espera).       |
|                                                                         |
|  2. MEMÒRIA (RAM)         Ús de RAM física i memòria paginada (Swap).   |
|                           Taxa de fallades de pàgina per segon.         |
|                                                                         |
|  3. DISC (E/S - I/O)      Longitud mitjana de la cua de disc.           |
|                           Temps de resposta en lectura/escriptura (ms). |
|                                                                         |
|  4. XARXA (Ethernet)      Percentatge d'utilització de l'amplada de     |
|                           banda, paquets descartats i errors de trama.  |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 2. Eines Nadiues de Monitorització a Windows Server

Windows Server ofereix un ventall d'utilitats segons el nivell de detall requerit:

1. **Gestor de Tasques (*Task Manager*):** Permet una visió ràpida en temps real dels processos actius, consum de CPU i consum de RAM.
2. **Monitor de Recursos (*Resource Monitor* - `resmon`):** Proporciona informació detallada dividida en 4 pestanyes (CPU, Memòria, Disc i Xarxa). Permet veure quins processos concrets estan llegint un fitxer, quines connexions TCP estan obertes i en quins ports estan escoltant els serveis.
3. **Monitor de Rendiment (*Performance Monitor* - `perfmon.msc`):**
   - L'eina d'anàlisi professional més avançada de Windows.
   - Permet afegir comptadors detallats (ex: `% Temps de processador`, `Bytes de memòria disponibles`, `Longitud mitjana de cua de disc`).
   - Permet crear **Conjunts de recopiladors de dades (*Data Collector Sets*)** per gravar mètriques durant hores o dies i generar línies base de rendiment (*Baselines*).

---

## 3. Eines de Monitorització per Consola en Linux Server

A Linux Server, la monitorització s'executa principalment des de l'intèrpret d'ordres mitjançant eines clàssiques i modernes:

```bash
# 1. Monitorització interactiva en temps real de processos i CPU
top
htop  # Versió millorada i acolorida amb barres d'ús i suport de ratolí

# 2. Anàlisi de memòria RAM i Swap lliure
free -h

# 3. Mètriques de memòria virtual i canvis de context de CPU
vmstat 2 5  # Mostra estadístiques cada 2 segons, 5 vegades

# 4. Rendiment del subsistema d'emmagatzematge (E/S de disc)
iostat -xz 1  # Requereix el paquet 'sysstat'

# 5. Connexions de xarxa actives i ports en escolta
ss -tulnp  # Substituto modern i ultraràpid de netstat
```
