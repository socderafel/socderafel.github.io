# 5.5 Emmagatzematge RAID i Rendiment de Disc

Per garantir que una fallada física d'un disc dur no destruïsca les dades de l'empresa ni ature l'activitat dels servidors, s'implementen subsistemes **RAID** (*Redundant Array of Independent Disks*).

---

## ⚙️ RAID per Maquinari vs RAID per Programari

- **RAID per Maquinari (*Hardware RAID*):**
  - Requereix una targeta controladora PCIe dedicada (com Broadcom MegaRAID o Dell PERC) amb el seu propi processador, memòria cau DDR dedicada i bateria de suport (**BBU / Flash-Backed Write Cache**).
  - La CPU del servidor queda $100\%$ alliberada dels càlculs de paritat XOR. El sistema operatiu veu directament un únic disc verge ja configurat abans de la instal·lació.
- **RAID per Programari (*Software RAID*):**
  - El propi nucli del sistema operatiu gestiona els discs individuals. És una solució de baix cost ideal per a entorns de proves i laboratoris.

---

## 🐧 Creació d'un Volum RAID 5 en Linux amb l'eina `mdadm`

Suposem que tenim tres discs verges connectats al servidor: `/dev/sdb`, `/dev/sdc` i `/dev/sdd`.

### Pas 1: Instal·lar la utilitat d'administració RAID
```bash
sudo apt update
sudo apt install -y mdadm
```

### Pas 2: Crear la matriu RAID 5
```bash
# Crear el dispositiu virtual /dev/md0 combinant 3 discs en RAID 5
sudo mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb /dev/sdc /dev/sdd

# Comprovar l'estat de sincronització de la matriu en temps real
cat /proc/mdstat
sudo mdadm --detail /dev/md0
```

### Pas 3: Donar format ext4 i muntar el volum
```bash
# Format ext4 sobre el volum lògic RAID
sudo mkfs.ext4 /dev/md0

# Crear punt de muntatge i muntar
sudo mkdir -p /mnt/raid_segur
sudo mount /dev/md0 /mnt/raid_segur

# Guardar la configuració per a reinicis permanents
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
sudo update-initramfs -u
```

### Pas 4: Simulació de fallada de disc i recuperació
```bash
# Simular que el disc /dev/sdb ha fallat
sudo mdadm --manage /dev/md0 --fail /dev/sdb

# Extraure el disc trencat de la matriu
sudo mdadm --manage /dev/md0 --remove /dev/sdb

# Connectar un disc nou de recanvi (/dev/sde) i reconstruir la matriu
sudo mdadm --manage /dev/md0 --add /dev/sde
# La paritat distribuïda reconstruirà totes les dades automàticament sense pèrdua!
```
