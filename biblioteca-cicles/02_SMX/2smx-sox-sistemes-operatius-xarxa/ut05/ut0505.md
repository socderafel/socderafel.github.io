# 5.5 Servidors de Monitorització Centralitzada (SNMP, Zabbix / Prometheus)

En infraestructures empresarials mitjanes o grans, amb desenes de servidors físics, màquines virtuals, commutadors (switches) i punts d'accés WiFi, és completament inviable entrar màquina per màquina a mirar `top` o `perfmon`.

Es requereix una plataforma de **monitorització centralitzada** capaç de recollir telemetria de tots els dispositius, dibuixar gràfics en temps real en un tauler de control (Dashboard) i enviar **alertes automàtiques** (per correu electrònic, Telegram o SMS) quan un servei cau o un disc supera el 90% d'ocupació.

---

## 1. El Protocol Estàndard SNMP (*Simple Network Management Protocol*)

SNMP és el protocol estàndard d'administració de xarxa per excel·lència (ports UDP 161 i 162):

```
+-------------------------------------------------------------------------+
|                  ARQUITECTURA DEL PROTOCOL SNMP                         |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Servidor Central NMS (Zabbix/Nagios) ]                               |
|        |                                                                |
|        | Consulta mètrica (SNMP GET / SNMP WALK)                        |
|        v                                                                |
|  [ Dispositiu Administrat (Servidor, Switch, SAI, Router) ]             |
|  +-------------------------------------------------------------------+  |
|  | Agent SNMP: Escolta en UDP 161.                                    |  |
|  | MIB (Management Information Base): Arbre jeràrquic de dades.      |  |
|  | OID (Object Identifier): Adreça única d'una mètrica (ex:          |  |
|  | 1.3.6.1.2.1.25.3.3.1.2 = Ús de CPU).                              |  |
|  +-------------------------------------------------------------------+  |
|        |                                                                |
|        | Envia alerta sobtada d'emergència (SNMP TRAP a UDP 162)        |
|        v                                                                |
|  [ Servidor Central NMS ]                                               |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Versions de SNMP i Ciberseguretat:
- **SNMPv1 i SNMPv2c:** Obsoletes i extremadament insegures. L'autenticació es fa mitjançant una paraula clau en text clar anomenada **comunitat (*Community string*)** (habitualment `public` per a lectura i `private` per a escriptura). Qualsevol que capture el trànsit pot llegir o alterar configuracions.
- **SNMPv3:** La versió corporativa recomanada. Afegeix **autenticació forta basada en usuaris (SHA-256) i xifratge simètric de la informació (AES)**.

---

## 2. Plataformes de Monitorització Corporativa: Zabbix i Prometheus

1. **Zabbix:**
   - La plataforma de codi obert tot-en-un més utilitzada en pimes i grans empreses.
   - Suporta monitorització amb agent lleuger (**Zabbix Agent**) instal·lat als servidors Windows/Linux i monitorització sense agent mitjançant SNMP, WMI o comprovacions de port TCP (ICMP ping, HTTP, DNS).
   - Inclou tauler de control web completíssim, mapes topològics de xarxa interactius i definició de **disparadors (*Triggers*)** que disparen alertes automàtiques.
2. **Prometheus + Grafana:**
   - L'estàndard emergent al món del núvol, microserveis i contenidors Docker/Kubernetes.
   - Prometheus recull mètriques basades en sèries temporals (*scraping* HTTP) i **Grafana** les visualitza en quadres de comandament espectaculars.
