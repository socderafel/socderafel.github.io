# 6.4 Samba com a Controlador de Domini AD (Samba 4 Active Directory Domain Controller)

Una de les fites més impressionants de l'enginyeria de programari lliure és la suite **Samba 4**:
No solament permet compartir carpetes SMB, sinó que és capaç d'actuar com un **Controlador de Domini d'Active Directory complet (*AD DC*)**, substituint de manera transparent a un servidor Windows Server amb les seues mateixes capacitats.

---

## 1. Què aporta un Controlador de Domini Samba 4?

Quan provisionem Samba 4 com a AD DC:
- Proporciona un servei de directori compatible amb **LDAP** i **Kerberos KDC**.
- Inclou un servidor **DNS intern** (o integrat amb BIND9) que gestiona automàticament els registres SRV del domini.
- Proporciona la carpeta replicada **SYSVOL** per a emmagatzemar Directives de Grup (GPO) i scripts d'inici.
- **Interoperabilitat total amb les eines oficials de Microsoft:** Un administrador de sistemes pot instal·lar les eines **RSAT (*Remote Server Administration Tools*)** en un ordinador amb Windows 10/11 i gestionar el domini Samba 4 amb les mateixes consoles clàssiques:
  - *Usuaris i equips d'Active Directory* (`dsa.msc`).
  - *Administració de directives de grup* (`gpmc.msc`).
  - *Consola DNS* (`dnsmgmt.msc`).

---

## 2. Provisió d'un Domini AD DS amb `samba-tool`

El procés de creació d'un domini a Linux s'executa mitjançant la potent utilitat **`samba-tool`**:

```bash
# 1. Eliminar o reanomenar el smb.conf per defecte abans de la provisió
sudo rm /etc/samba/smb.conf

# 2. Executar l'assistent de provisió interactiva del domini
sudo samba-tool domain provision \
  --realm=IESRAFAEL.LOCAL \
  --domain=IESRAFAEL \
  --server-role=dc \
  --dns-backend=SAMBA_INTERNAL \
  --adminpass='P@ssw0rd2026!'
```

Un cop finalitzada la provisió:
- El fitxer `/etc/samba/smb.conf` es reescriu automàticament amb la configuració de Controlador de Domini.
- Es desactiven els serveis tradicionals `smbd` i `nmbd` i s'activa el dimoni integrat:
  ```bash
  sudo systemctl stop smbd nmbd
  sudo systemctl disable smbd nmbd
  sudo systemctl unmask samba-ad-dc
  sudo systemctl enable --now samba-ad-dc
  ```

---

## 3. Gestió per Consola amb `samba-tool`

Totes les operacions administratives es poden realitzar de forma immediata mitjançant ordres de consola:

```bash
# Crear un nou compte d'usuari al domini Samba 4
sudo samba-tool user create joan.garcia 'ClauSegura123!' --given-name="Joan" --surname="Garcia"

# Crear un nou grup de seguretat
sudo samba-tool group add GG_Professors

# Afegir l'usuari al grup
sudo samba-tool group addmembers GG_Professors joan.garcia

# Comprovar el nivell funcional del domini
sudo samba-tool domain level show
```
