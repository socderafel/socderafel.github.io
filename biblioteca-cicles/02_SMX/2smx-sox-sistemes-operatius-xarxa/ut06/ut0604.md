# 6.4 Integració d'Ubuntu Linux en Domini Active Directory

En aquest taller pràctic unirem una màquina amb **Ubuntu Desktop o Server** a un domini **Microsoft Active Directory (`smx.local`)** de forma completament professional utilitzant **realmd** i **SSSD**.

---

## 🛠️ Procediment Pas a Pas

### Pas 1: Sincronització de Xarxa i DNS
Comprova que la màquina Ubuntu té configurada com a servidor DNS la IP del controlador de domini Windows Server (`192.168.100.10`):
```bash
# Provar resolució del domini
ping -c 2 smx.local
```

### Pas 2: Instal·lació dels Paquets d'Integració
```bash
sudo apt update
sudo apt install -y realmd sssd sssd-tools libnss-sss libpam-sss adcli samba-common-bin oddjob oddjob-mkhomedir packagekit
```

### Pas 3: Descobriment del Domini Active Directory
```bash
# Cercar el domini smx.local a la xarxa
realm discover smx.local
# Hauria de retornar informació del tipus: 'smx.local', type: kerberos, realm-name: SMX.LOCAL...
```

### Pas 4: Unió Oficial al Domini
```bash
# Unir l'equip amb les credencials d'administrador de domini
sudo realm join -U Administrator smx.local
# Introdueix la contrasenya del domini: Admin2024!
```

### Pas 5: Configuració de Creació Automàtica de la Carpeta d'Inici (*Home*)
Perquè quan un usuari de domini s'autentique per primera vegada se li cree automàticament el directori `/home/usuari@smx.local`:
```bash
sudo pam-auth-update --enable mkhomedir
```

### Pas 6: Prova d'Inici de Sessió
```bash
# Canviar a un compte d'usuari del domini
su - joan.garcia@smx.local

# Comprovar la identitat
whoami
id
# Hauries de veure el teu UID i els grups del domini (Domain Users, etc.)
```
Felicitats! L'equip Ubuntu està integrat com un membre de ple dret del domini corporatiu de Microsoft.
