# 6.1 Fonaments d'Interoperabilitat entre Windows i Linux

En l'ecosistema tecnològic real de les empreses i administracions públiques modernes, és extremadament estrany trobar un entorn purament monomarca. La realitat habitual és la **coexistència heterogènia**: estacions de treball amb Windows 10/11 i macOS interactuant diàriament amb servidors de bases de dades i servidors web Linux (Debian, Ubuntu, Red Hat).

La **interoperabilitat** és la capacitat de sistemes informàtics diversos i heterogenis per a comunicar-se, intercanviar dades i compartir serveis de forma transparent, segura i sense fricció per a l'usuari final.

```
+-------------------------------------------------------------------------+
|                  ECOSISTEMA EMPRESARIAL HETEROGENI                      |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Clients Windows 10/11 ]             [ Servidors Linux Server ]       |
|  - Usuaris ofimàtics i gestió.         - Servidor web Nginx / Apache.   |
|  - Autenticació Kerberos AD DS.        - Base de dades PostgreSQL.      |
|  - Accés a recursos SMB.               - Servidor de fitxers Samba.     |
|                                                                         |
|                         \                     /                         |
|                          \                   /                          |
|                     [ ESTÀNDARDS D'INTEROPERABILITAT ]                  |
|                     - Protocol SMB / CIFS                               |
|                     - Protocol LDAP (RFC 4510)                          |
|                     - Protocol Kerberos v5 (RFC 4120)                   |
|                     - Sistema de Noms DNS / TCP/IP                      |
|                                                                         |
+-------------------------------------------------------------------------+
```

---

## 1. Els Principals Reptes de la Integració Heterogènia

Integrar dos mons arquitectònicament diferents com Windows (basat en l'arrel NT) i Linux (basat en la filosofia UNIX/POSIX) implica resoldre tres grans desafiaments:

1. **Model d'Identitat i Identificadors d'Usuari:**
   - **Windows:** Utilitza identificadors binaris de longitud variable anomenats **SIDs (*Security Identifiers*)** com `S-1-5-21-...-1001`.
   - **Linux:** Utilitza números enters simples: **UID (*User ID*)** i **GID (*Group ID*)** (ex: UID 1001, GID 1001).
   - *Solució d'interoperabilitat:* Mòduls de mapatge d'identitats (**idmap**) que converteixen transparentment un SID de Windows en un UID/GID de Linux.
2. **Sistemes de Fitxers i Permisos:**
   - **Windows (NTFS):** Llistes exhaustives de control d'accés (DACL/SACL) amb granularitat extrema.
   - **Linux (ext4/XFS):** Model clàssic POSIX (Propietari, Grup, Altres amb permisos rwx), ampliat modernament amb suport d'ACLs POSIX.
3. **Resolució de Noms i Protocols de Xarxa:**
   - Ús obligatori de **DNS** jeràrquic estàndard com a mecanisme únic de localització de recursos, abandonant vells protocols propietaris com NetBIOS o WINS.

---

## 2. Protocols Estàndard que Fan Possible la Interoperabilitat

La convivència és possible perquè ambdós sistemes han adoptat estàndards oberts de la indústria:

- **SMB (*Server Message Block*):** Gràcies al projecte de programari lliure **Samba**, Linux pot actuar tant de client com de servidor d'arxius SMB, entenent-se a la perfecció amb qualsevol versió de Windows.
- **Kerberos v5:** El protocol d'autenticació criptogràfica basat en tiquets que fa possible el **Single Sign-On (SSO)**: un usuari inicia sessió al seu PC Windows i pot accedir a serveis web o carpetes allotjades a Linux sense haver de tornar a escriure la contrasenya.
- **LDAP (*Lightweight Directory Access Protocol*):** El protocol d'accés a serveis de directori que permet a màquines Linux consultar la base de dades d'Active Directory.
