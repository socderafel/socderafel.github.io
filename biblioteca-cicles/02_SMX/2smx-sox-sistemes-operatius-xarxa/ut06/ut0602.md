# 6.2 Desplegament i Configuració d'un Servidor Samba en Linux

El projecte **Samba** és el pilar absolut de la interoperabilitat entre Linux i Windows. És una reimplementació de codi obert del conjunt de protocols de xarxa SMB/CIFS que permet que un servidor GNU/Linux actue com un servidor d'arxius i impressores nadiu per a clients Windows, macOS i Linux.

---

## 1. Els Dimonis Principals de la Suite Samba

La suite de programari Samba està composta principalment per dos serveis en segon pla (*daemons*):

1. **`smbd` (*Samba Daemon*):** Gestiona la compartició de fitxers i cues d'impressió a través del protocol SMB (port TCP 445). S'encarrega també de l'autenticació dels usuaris i de l'autorització d'accés als recursos compartits.
2. **`nmbd` (*NetBIOS Name Daemon*):** Gestiona la resolució de noms NetBIOS i la navegació d'equips en entorns tradicionals (ports UDP 137 i 138). En xarxes modernes basades exclusivament en DNS directe, el seu ús ha passat a ser secundari.

---

## 2. Instal·lació de Samba a Ubuntu Server

```bash
# Instal·lació de Samba i utilitats client
sudo apt update
sudo apt install -y samba smbclient
```

---

## 3. El Fitxer de Configuració Principal: `/etc/samba/smb.conf`

Tota la configuració de Samba es defineix en un únic fitxer INI dividit en seccions:

```bash
# Fer una còpia de seguretat abans de modificar
sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.bak
sudo nano /etc/samba/smb.conf
```

### Estructura Típica d'un Servidor de Fitxers en Grup de Treball:

```ini
[global]
   workgroup = WORKGROUP
   server string = Servidor d'Arxius Linux Samba
   security = user
   map to guest = bad user
   dns proxy = no

# Recurs Compartit d'Accés Públic (sense contrasenya)
[public]
   path = /srv/samba/public
   browseable = yes
   read only = no
   guest ok = yes
   create mask = 0777
   directory mask = 0777

# Recurs Compartit Privat Departamental (amb contrasenya)
[projectes]
   path = /srv/samba/projectes
   browseable = yes
   read only = no
   guest ok = no
   valid users = @professors
   create mask = 0770
   directory mask = 0770
```

### Validació de Sintaxi amb `testparm`:
Mai s'ha de reiniciar Samba sense comprovar abans la sintaxi del fitxer de configuració:
```bash
# Verifica errors de sintaxi a smb.conf
testparm
```

---

## 4. Gestió d'Usuaris de Samba (`smbpasswd`)

Perquè un usuari puga autenticar-se en un recurs privat de Samba:
1. L'usuari **ha d'existir primer com a compte local a Linux** (a `/etc/passwd`).
2. S'ha d'afegir a la base de dades de contrasenyes de Samba mitjançant **`smbpasswd`** (ja que Samba emmagatzema els hashes NTLM necessaris per a Windows, diferents dels hashes SHA-512 de `/etc/shadow`):

```bash
# Afegir l'usuari local existent a Samba i assignar-li contrasenya SMB
sudo smbpasswd -a jgarcia

# Habilitar l'usuari
sudo smbpasswd -e jgarcia

# Reiniciar el servei smbd per aplicar canvis
sudo systemctl restart smbd
```
