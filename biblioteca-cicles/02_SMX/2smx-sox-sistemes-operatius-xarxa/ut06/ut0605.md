# 6.5 Accés Remot Segur i Administració Multiplataforma

Els administradors de sistemes operatius en xarxa rarament es desplacen físicament a la sala del CPD per asseure's davant de la pantalla d'un servidor. El 99% de les tasques diàries s'executen a través de **connexions remotes segures**.

La integració moderna permet gestionar servidors Linux des d'estacions de treball Windows i administrar servidors Windows Server des de consoles Linux de manera fluida i xifrada.

---

## 1. Administració de Servidors Linux des de Windows mitjançant SSH

El protocol **SSH (*Secure Shell*, port TCP 22)** proporciona un canal de comunicació xifrat d'extrem a extrem:

```
+-------------------------------------------------------------------------+
|                  AUTENTICACIÓ BASADA EN PARELL DE CLAUS SSH             |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ Client d'Administració Windows ]       [ Servidor Linux de Destí ]   |
|  +---------------------------------+      +---------------------------+ |
|  | Clau Privada (id_ed25519)       |      | Clau Pública              | |
|  | (ES QUEDA SEMPRE AL CLIENT,     |      | (id_ed25519.pub) copiada  | |
|  |  PROTEGIDA AMB CONTRASENYA)     |      | a ~/.ssh/authorized_keys  | |
|  +---------------------------------+      +---------------------------+ |
|                   \                             /                       |
|                    \   Repte Criptogràfic      /                        |
|                     +-------------------------+                         |
|                     | Connexió xifrada segura |                         |
|                     | SENSE enviar mai la     |                         |
|                     | contrasenya per la xarxa|                         |
|                     +-------------------------+                         |
|                                                                         |
+-------------------------------------------------------------------------+
```

### Generació de claus i connexió:
Windows 10/11 inclou de sèrie el client **OpenSSH**:

```powershell
# 1. Generar un parell de claus modernes Ed25519 a Windows PowerShell
ssh-keygen -t ed25519 -C "admin@iesrafael.local"

# 2. Copiar la clau pública al servidor Linux remot
ssh-copy-id admin@192.168.10.20

# 3. Connectar-se sense contrasenya de manera instantània i segura
ssh admin@192.168.10.20
```

---

## 2. Administració Remota de Windows Server: PowerShell Remoting i WinRM

Per a gestionar servidors Windows Server per línia de comandes de manera equivalent a SSH, Microsoft utilitza **PowerShell Remoting**, basat en el protocol estàndard **WS-Management** a través del servei **WinRM (*Windows Remote Management*)**:

```powershell
# 1. Habilitar la gestió remota al servidor Windows
Enable-PSRemoting -Force

# 2. Obrir una sessió remota interactiva des de qualsevol estació de treball
Enter-PSSession -ComputerName "SRV-DC01" -Credential (Get-Credential)

# 3. Executar una comanda de forma massiva sobre 10 servidors en paral·lel
Invoke-Command -ComputerName "SRV-DC01", "SRV-DC02", "SRV-FILES01" -ScriptBlock {
    Get-Service -Name "wuauserv" | Restart-Service
}
```

---

## 3. Gestió Moderna Multiplataforma via Web: Windows Admin Center i Cockpit

Per a aquells administradors que prefereixen una experiència visual però sense haver de carregar un escriptori remot complet (RDP), existeixen consoles d'administració basades en navegador web:

1. **Windows Admin Center (WAC):**
   - Consola web moderna i gratuïta de Microsoft que s'executa a través del navegador (port HTTPS 443 o 6516).
   - Permet gestionar servidors Windows Server Core, clústers Hyper-V, xarxes, emmagatzematge i certificats sense necessitat de tenir escriptori gràfic al servidor.
2. **Cockpit (a Linux):**
   - Consola web integrada per defecte a Ubuntu Server, Debian i Rocky Linux (port HTTPS 9090).
   - Permet monitoritzar rendiment en viu, gestionar comptes d'usuari, actualitzar paquets, configurar xarxa i revisar registres de `journalctl` des de qualsevol navegador web.
