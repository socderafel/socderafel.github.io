# 3.5 Pràctiques Tema 7 (Combinar correspondència)

1º SMX.

Tema 07. Combinar correspondencia

EJERCICIO 44

Transportes Urgensur S.L. va a abrir una nueva tienda y quiere invitar a todos sus clientes a la inauguración. Quieren utilizar la herramienta combinar correspondencia para el envio de las cartas de invitación.

En primer lugar, crea una tabla en el procesador de textos, que te servirá como base de datos para combinar. La tabla, que será la lista origen con los datos, tendrá como mínimo los campos nombre, dirección, código postal, población, provincia. Debes añadir como mínimo 5 clientes, tres de ellos, que sean de Madrid El documento con la lista origen, se llamará Ejercicio44_lista.odt.

Después, redacta la carta de invitación, escribiendo un breve texto en el que se le invita al cliente a la inauguración de la tienda, indicando también el domicilio de la nueva tienda, la fecha de inauguración. En la parte superior de la carta, debe aparecer el nombre completo del cliente, la dirección el código postal, la población y la provincia (son los datos que se tienen que combinar con la lista origen).

Guarda la carta como Ejercicio44_principal.odt

Cuando combines el documento, generarás un documento con tantas cartas como registros hayas creado en la lista origen. Guarda el documento combinado como Ejercicio44_combinado.odt

EJERCICIO 45

Transportes Urgensur S.L. quiere crear las cartas de invitación solamente para los clientes que tengan su domicilio en la provincia de Madrid. Para realizar esto, debes modificar el ejercicio anterior, para aplicar los filtros corespondientes. Guarda el documento combinado como Ejercicio45_combinado.odt

EJERCICIO 46

La empresa Seguros Rosales S.L ha incrementado en un 7% de valor de las pólizas de sus clientes. Por este motivo, deben enviar una carta a sus clientes informándoles de dicha modificación.

Para realizar esta actividad, dispones de la carta (R-Ejercicio46_principal.odt) y el archivo de datos (R-Ejercicio46_datos.odt). Genera un nuevo documento combinado a partir de éstos llamado Ejercicio46_combinado.odt.
