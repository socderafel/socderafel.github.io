1º SMX.

Tema 10. Imprimir

EJERCICIO 55

EN CASA: Accede a la dirección http://www.cutepdf.com. Descarga para Windows el archivo de instalación de este simulador de impresora pdf. Una vez efectuada la descarga, instala Cutepdf en Windows.

Crea un documento llamado Ejercicio55.odt , y describe los pasos realizados para instalar esta impresora pdf (incluye pantallas, si lo consideras necesario). A partir del archivo Ejercicio33.doc, genera un archivo llamado Ejercicio55.pdf.

PDFCreator

EJERCICIO 56

EN CASA: Usando el simulador de impresora Cutepdf y a partir de un fichero de texto, que contenga como mínimo 4 páginas, genera un documento llamado Ejercicio56.pdf, que contendrá únicamente 1 página (configurar impresión 4 páginas por hoja).

EJERCICIO 57

EN CASA: Usando el simulador de impresora Cutepdf y a partir de un archivo de texto que tengas de 4 páginas, genera un documento llamado Ejercicio57.pdf, que contendrá un total de 8 páginas (2 copias de cada una).
