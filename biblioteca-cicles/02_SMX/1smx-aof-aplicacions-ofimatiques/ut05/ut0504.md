Mentre que GIMP manipula píxels fixes sobre una quadrícula, **Inkscape** és el programari lliure professional per excel·lència per a crear **gràfics vectorials escalables (SVG)**. Amb Inkscape es dissenyen logotips d'empresa, esquemes de xarxa detallats, iconografia d'interfícies i dissenys per a tall per làser o impressió 3D.

---

## 1. L'Estructura d'un Traçat Vectorial: Nodes i Tiradors

Tot objecte vectorial complex està format per un conjunt de **traçats (paths)** que uneixen punts de control anomenats **nodes**:

```
           Punt de Control (Tirador 1)
                  o
                 /
Node Inicial    /    Corba de Bézier          Node Final
    *----------+--------------------------->*
                                           /
                                          /
                                         o
                           Punt de Control (Tirador 2)
```

### Tipus de Nodes a Inkscape
1. **Node de cantonada (Cúspide / Corner):** Els dos tiradors es mouen de manera totalment independent, creant angles punxeguts o arestes vives.
2. **Node suau (Smooth):** Els dos tiradors estan alineats en línia recta contínua, garantint que la corba no tinga salts bruscos.
3. **Node simètric:** Els tiradors no sols estan alineats sinó que tenen exactament la mateixa longitud a banda i banda.
4. **Node automàtic:** Inkscape calcula automàticament la curvatura més harmònica segons els nodes veïns.

---

## 2. Eines Clau de Creació a Inkscape

- **Eina de selecció i transformació (F1 / Selector):** Permet moure, rotar, escalar i inclinar objectes complets.
- **Eina d'edició de nodes (F2 / Node Tool):** Permet seleccionar els punts interiors, moure tiradors, afegir nous nodes fent doble clic o eliminar-los.
- **Eina de corbes de Bézier i línies rectes (Shift + F6 / Ploma):** Permet traçar segments clicant (rectes) o clicant i arrossegant (corbes fluides).
- **Objectes geomètrics primaris:** Rectangles, cercles/el·lipses, estrelles i polígons regulars configurables en vèrtexs.

---

## 3. Operacions Booleanes entre Objectes

Una de les tècniques més potents per a dibuixar logotips i siluetes professionals és combinar formes geomètriques bàsiques mitjançant les **Operacions de Traçat (Booleanes)** del menú `Traçat`:

```
Forma A: Cercle      Forma B: Quadrat superposat
+-------------------+---------------------------------------------------+
| Operació Booleana | Acció Realitzada                                  |
+-------------------+---------------------------------------------------+
| UNIÓ              | Fon totes dues formes en un sol perímetre continu.|
| DIFERÈNCIA        | Resta la forma superior de la inferior (retall).  |
| INTERSECCIÓ       | Manté únicament la zona on totes dues coincideixen|
| EXCLUSIÓ          | Manté tot excepte la zona on se superposen.       |
| DIVISIÓ           | Talla la forma inferior amb el traçat superior.   |
+-------------------+---------------------------------------------------+
```
