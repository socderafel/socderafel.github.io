# 1.1 Suites Ofimàtiques Lliures i Propietàries

En l'ecosistema empresarial actual, el programari ofimàtic constitueix l'eina principal de productivitat per a la redacció de documents, gestió de dades comptables, anàlisi financera i presentació de projectes. 

Una **suite ofimàtica** és un conjunt integrat d'aplicacions informàtiques dissenyades per interactuar entre si de forma transparent, compartint una interfície d'usuari homogènia, un motor comú de revisió ortogràfica i formats d'arxiu compatibles.

---

## 1. Evolució Històrica i Principals Actors del Mercat

Des de les primeres eines aïllades en MS-DOS (com WordPerfect, Lotus 1-2-3 o dBase), la indústria ha convergit cap a dues grans famílies:

```
+─────────────────────────────────+─────────────────────────────────+
| SUITES DE CODI OBERT (FOSS)     | SUITES COMERCIALS PROPIETÀRIES  |
+─────────────────────────────────+─────────────────────────────────+
| • LibreOffice (The Document Fnd)| • Microsoft Office / M365       |
| • Apache OpenOffice             | • Apple iWork (Pages, Numbers)  |
| • Calligra Suite (KDE)          | • Google Workspace (Cloud)      |
| • OnlyOffice (Open-Core)        | • WPS Office (Kingsoft)         |
+─────────────────────────────────+─────────────────────────────────+
```

* **LibreOffice:** Nascuda el 2010 com una bifurcació (*fork*) comunitària d'OpenOffice.org gestionada per *The Document Foundation*. És la suite de codi obert de referència mundial, disponible de franc per a Windows, macOS i GNU/Linux.
* **Microsoft Office / Microsoft 365:** L'estàndard corporatiu dominant del mercat privat des de 1989. Combina aplicacions d'escriptori tradicionals amb serveis avançats d'intel·ligència artificial i col·laboració en el núvol d'Azure.
* **Google Workspace:** Suite pionera 100% nativa en navegador web (Docs, Sheets, Slides), orientada fonamentalment al treball en equip col·laboratiu en temps real.

---

## 2. Els Mòduls Essencials d'una Suite Ofimàtica

Una suite completa cobreix les necessitats bàsiques d'una oficina mitjançant els seus mòduls especialitzats:

```
+──────────────────────+──────────────────────────+──────────────────────────+
| Tipus d'Aplicació    | LibreOffice              | Microsoft 365            |
+──────────────────────+──────────────────────────+──────────────────────────+
| Processador de text  | Writer                   | Word                     |
| Full de càlcul       | Calc                     | Excel                    |
| Presentacions        | Impress                  | PowerPoint               |
| Gestor de BBDD       | Base                     | Access                   |
| Dibuix i diagrames   | Draw                     | Visio (addicional)       |
| Editor d'equacions   | Math                     | Equation Editor integrat |
+──────────────────────+──────────────────────────+──────────────────────────+
```

---

## 3. Criteris d'Elecció per a una Organització

Com a tècnics de SMX responsables del desplegament tecnològic en una pime o centre educatiu, l'elecció entre una suite o una altra depèn de:
* **Cost total de propietat (TCO):** Preu de les llicències per usuari/any vs cost de formació i suport tècnic.
* **Sobirania tecnològica i formats:** Garantia que els documents emmagatzemats continuaran sent llegibles d'ací a 20 anys sense dependre d'un proveïdor únic (ús de formats oberts ODF).
* **Entorn de treball dels usuaris:** Si la plantilla treballa de forma intensiva en mobilitat (smartphones/tauletes) o en llocs de treball fixes amb sistemes operatius heterogenis (Linux i Windows).
