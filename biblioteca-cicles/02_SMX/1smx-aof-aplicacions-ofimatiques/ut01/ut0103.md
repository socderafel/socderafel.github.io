# 1.3 Instal·lació, Desplegament i Requisits de Sistema

La instal·lació d'una suite ofimàtica en un únic ordinador domèstic és un procés senzill mitjançant un assistent gràfic; tanmateix, en entorns professionals amb desenes o centenars d'equips, el tècnic de SMX ha d'aplicar metodologies de **desplegament automatitzat i desatès**.

---

## 1. Verificació de Requisits de Maquinari i Programari

Abans d'iniciar el desplegament, cal auditar el parc informàtic:
* **Processador (CPU):** Compatible amb arquitectura x86_64 de 64 bits.
* **Memòria RAM:** Mínim 4 GB recomanats per treballar amb fulls de càlcul complexos de més de 50.000 files.
* **Emmagatzematge:** Entre 1,5 GB i 4 GB d'espai lliure en disc SSD per a la suite base i diccionaris.
* **Dependències auxiliars:** Entorn d'execució Java (**JRE**) de 64 bits si es requereix utilitzar el motor intern HSQLDB de LibreOffice Base o filtres XML avançats.

---

## 2. Instal·lació en Microsoft Windows

* **Paquets MSI (Microsoft Installer):** LibreOffice es distribueix oficialment com a fitxer `.msi`.
* **Instal·lació silenciosa desatenta (Silent Install):** Permet instal·lar la suite sense intervenció de l'usuari ni finestres gràfiques mitjançant la comanda CLI:

```powershell
msiexec /i LibreOffice_24.8.x_Win_x86-64.msi /qn /norestart REGISTER_ALL_MSO_TYPES=1
```

* **Desplegament corporatiu per GPO:** A través d'Active Directory en servidors Windows Server, assignant el paquet MSI a la unitat organitzativa d'ordinadors perquè s'instal·le en iniciar sessió.

---

## 3. Instal·lació en Sistemes GNU/Linux

En entorns educatius valencians basats en LliureX o distribucions Debian/Ubuntu:

```bash
# Mitjançant el gestor de paquets natiu APT:
sudo apt update && sudo apt install libreoffice libreoffice-l10n-ca libreoffice-help-ca -y

# Mitjançant paquet universal Flatpak (versió més actualitzada):
flatpak install flathub org.libreoffice.LibreOffice
```
