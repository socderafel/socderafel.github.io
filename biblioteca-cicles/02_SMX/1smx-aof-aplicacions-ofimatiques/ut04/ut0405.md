Els usuaris finals d'una empresa (recepcionistes, operadors de caixa, tècnics d'atenció al client) mai haurien d'interactuar directament amb les taules en brut d'un SGBD, ja que podrien alterar dades protegides o cometre errors catastròfics. Per a garantir la seguretat i la usabilitat, el SGBD disposa de dos objectes de presentació: els **Formularis (Forms)** per a l'entrada interactiva de dades i els **Informes (Reports)** per a la impressió i arxiu formal.

---

## 1. Disseny de Formularis i Controls d'Interfície

Un **formulari** és una pantalla gràfica que presenta un registre a la vegada o un entorn adaptat a la tasca diària:
- **Quadre de text (Text Box):** Permet escriure dades lliures vinculades a un camp.
- **Quadre combinat (Combo Box) / Llista desplegable:** Mostra valors seleccionables per a evitar faltes ortogràfiques (ex: llista de províncies o tipus de RAM).
- **Casella de verificació (Check Box):** Per a camps booleans Sí/No (ex: "Garantia vigent").
- **Botons de comanda (Push Buttons):** Botons programats per a accions com "Desa registre", "Següent registre", "Imprimeix albarà" o "Tanca".

### Formularis amb Subformularis (Mestre-Detall 1:N)
En una relació d'un a molts (ex: un Client té molts Equips), la millor estructura visual és un **formulari principal amb subformulari**:
- **Formulari principal:** Mostra les dades del client actual (`id_client`, `Nom`, `Telèfon`).
- **Subformulari incrustat:** Mostra una taula amb tots els equips d'aquell client concret. En canviar de client al formulari superior, la llista d'equips inferior s'actualitza instantàniament.

```
+-----------------------------------------------------------+
| FITXA DE CLIENT [ Formulari Principal ]                   |
| Codi: [ 104 ]   Nom: [ Joan Cuenca ]  Telf: [ 96 123 45 ] |
+-----------------------------------------------------------+
| EQUIPS ASSIGNATS [ Subformulari 1:N ]                     |
| +-----------+-----------------------+-------------------+ |
| | Núm Sèrie | Tipus Equip           | Estat Taller      | |
| +-----------+-----------------------+-------------------+ |
| | SRV-842   | Servidor Rack 2U      | En diagnòstic     | |
| | PC-112    | Portàtil Lenovo T14   | Finalitzat        | |
| +-----------+-----------------------+-------------------+ |
| [|<] [<] Registre 1 de 2 [>] [>|]    [ + Nou Equip ]      |
+-----------------------------------------------------------+
```

---

## 2. Generació d'Informes (Reports) Imprimibles

Un **informe** té com a finalitat recopilar dades de taules o consultes i formatar-les de manera estètica per a ser impreses en paper o exportades a format **PDF/A**:
- **Encapçalament de l'informe:** Logotip de l'empresa, títol del document i data d'emissió.
- **Encapçalament de grup:** Agrupament lògic (ex: canvi de departament o de client).
- **Secció de detall:** Les files individuals de dades (articles facturats, components instal·lats).
- **Peu de pàgina:** Número de pàgina (`Pàgina 1 de 3`) i avís de confidencialitat RGPD.
- **Peu de l'informe:** Sumatoris totals, base imposable, IVA i signatura del tècnic responsable.
