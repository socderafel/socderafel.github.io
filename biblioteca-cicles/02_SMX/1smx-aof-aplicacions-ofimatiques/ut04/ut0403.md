EJERCICIO 58

Referencias cruzadas. En un texto largo, puede ser necesario hacer referencia a otras páginas del mismo documento con el fin de facilitar su lectura. Una referencia cruzada es una marca que permite saltar o hacer referencia a una parte del documento, ya sea un título, una mesa, una ilustración, o una lista numerada, independientemente de posibles variaciones del número de página. Previamente a la inserción de referencias cruzadas hay que marcar los elementos a referenciar. Para insertar una referencia cruzada a seguir los siguientes pasos

• Seleccionar el texto que se desee utilizar como destino para la referencia • Menú Insertar→Campos→pestaña REMISIONES (o Referencias) • En la lista Tipo, seleccionar Establecer Referencia (ó Define la referencia)

• Escribir un nombre para el destino en el cuadro Nombre. El texto seleccionado aparece en el cuadro Valor. • Click Insertar. El nombre del destino se añade a la lista de Selección. No cerrar el menú. • Ves al sitio del documento donde deseas insertar la palabra de referencia.

• Insertar→Campos→pestaña REMISIONES (o Referencias) • En la lista Tipo, seleccionar Insertar una referencia • En la lista Selección, elegir el destino que se desee referenciar. • Seleccionar el formato para la referencia en la lista Formato.
