Una base de dades no s'utilitza simplement per a acumular informació, sinó per a recuperar-la de manera ràpida i precisa quan es necessita. Una **consulta (query)** és una petició estructurada que demana al sistema operatiu de la base de dades que filtre, ordene i presente només aquells registres i camps que compleixen determinades condicions.

---

## 1. L'Entorn Visual de Disseny QBE (Query by Example)

Tant LibreOffice Base com Access ofereixen una quadrícula gràfica coneguda com a **QBE** dividida en dues zones:
1. **Panell superior:** Mostra les taules involucrades en la consulta amb les seues relacions establertes.
2. **Quadrícula inferior:** Permet arrossegar els camps desitjats i configurar:
   - **Camp:** El nom de la columna seleccionada (ex: `Nom`, `Poblacio`, `Preu`).
   - **Taula:** La taula d'origen d'aquell camp.
   - **Ordre:** Ascendent (A-Z) o Descendent (Z-A).
   - **Visible (Mostra):** Casella de verificació per a triar si el camp apareixerà en la visualització final.
   - **Criteri:** La condició o filtre matemàtic/lògic.
   - **O (Or):** Condicions alternatives addicionals.

```
+----------------------------------------------------------------------------------------+
| PANELL TAULES: [ CLIENTS ] -------- 1:N -------- [ EQUIPS ]                            |
+---------------------+-------------------+---------------------+------------------------+
| Camp:               | Nom               | Poblacio            | Tipus_Dispositiu       |
| Taula:              | CLIENTS           | CLIENTS             | EQUIPS                 |
| Ordre:              | Ascendent         |                     |                        |
| Visible:            | [X]               | [X]                 | [X]                    |
| Criteri:            |                   | = "Catadau"         | = "Servidor"           |
| O:                  |                   | = "Carlet"          |                        |
+---------------------+-------------------+---------------------+------------------------+
```

---

## 2. Operadors de Criteri Fonamentals

| Operador | Sintaxi d'Exemple | Resultat Obtingut |
| :--- | :--- | :--- |
| **Comparació numèrica** | `> 500`, `<= 50` | Filtra preus superiors a 500 € o stocks inferiors a 50 unitats. |
| **Rang de valors** | `Entre 10 I 50` (`Between 10 And 50`) | Retorna registres compresos en l'interval (ambdós inclosos). |
| **Llista de valors** | `En("València"; "Gandia"; "Torrent")` | Retorna clients situats en qualsevol d'aquestes tres poblacions. |
| **Comodins de text** | `Com "Intel*"` / `LIKE "Intel*"` | Cerca qualsevol registre que comence per "Intel" (ex: "Intel i5", "Intel Core Ultra"). |
| **Camps nuls o buits** | `És Nul` (`Is Null`) / `No és Nul` | Troba registres que no tenen telèfon o que ja tenen data de lliurament. |
| **Lògica AND (I)** | Files de criteri mateixes | Totes les condicions de la mateixa fila s'han de complir simultàniament. |
| **Lògica OR (O)** | Línies de criteri diferents | És suficient que es complisca el criteri de la primera línia o de la segona. |

---

## 3. Consultes amb Paràmetres Interactius

Si volem que la consulta siga reutilitzable sense haver de modificar el disseny cada vegada, podem crear una **consulta amb paràmetres**.
- A Access: S'escriu la pregunta entre claudàtors al camp Criteri: `[Introdueix la població a cercar:]`.
- A LibreOffice Base: S'anteposen dos punts al nom del paràmetre: `:poblacio_cercar`.

En executar la consulta, el programa obrirà una finestra emergent sol·licitant a l'usuari que escriga el valor.
