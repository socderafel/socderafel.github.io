Més enllà de recuperar llistats plans de files, les empreses necessiten informació agregada: quant hem facturat aquest mes, quantes reparacions ha realitzat cada tècnic o quin és el cost mitjà de reparació. Això s'aconsegueix mitjançant les **consultes de totals (agrupaments)** i la comprensió del llenguatge estàndard universal: **SQL (Structured Query Language)**.

---

## 1. Consultes d'Agrupament i Funcions d'Agregació

Quan a la barra d'eines activem el botó de **Totals ($\Sigma$)**, a la quadrícula QBE apareix una nova fila anomenada **Total:**. En aquesta fila podem assignar:
- **Agrupa per (GROUP BY):** Defineix les categories per les quals es dividirà el càlcul (ex: per `Poblacio`, per `Marca`, per `Tècnic`).
- **Suma (SUM):** Totalitza els valors numèrics d'aquell grup.
- **Compte (COUNT):** Compta quants registres pertanyen a cada grup.
- **Mitjana (AVG):** Calcula la mitjana aritmètica.
- **Mínim / Màxim (MIN / MAX):** Troba el valor més baix o més alt del grup.

```
Exemple: Facturació Total per Població de Clients
+-----------------------+-----------------------+-----------------------+
| Camp:                 | Poblacio              | Import_Total          |
| Taula:                | CLIENTS               | FACTURES              |
| Total:                | Agrupa per            | Suma                  |
+-----------------------+-----------------------+-----------------------+
Resultat en Vista Full de Dades:
  - Alginet:   3.450,00 €
  - Carlet:    5.120,50 €
  - Catadau:   1.890,00 €
```

## 2. Fonaments del Llenguatge SQL

La interfície visual QBE no és més que un generador de codi **SQL**. Tot administrador i tècnic de sistemes ha de ser capaç de llegir i escriure instruccions SQL bàsiques:

```sql
SELECT camp1, camp2, camp3
FROM nom_taula
WHERE condicio_de_filtre
ORDER BY camp1 ASC;
```

### Les 4 Clàusules Essencials
1. **`SELECT`:** Llista els camps que volem mostrar (o `*` per mostrar-los tots).
2. **`FROM`:** Especifica de quina taula o taules s'extreuen les dades.
3. **`WHERE`:** Aplica els filtres de selecció abans d'agrupar.
4. **`ORDER BY`:** Ordena els resultats (`ASC` ascendent o `DESC` descendent).

### Combinació de Taules (JOIN) i Agrupament en SQL
```sql
SELECT CLIENTS.Nom, COUNT(EQUIPS.num_serie) AS Total_Equips
FROM CLIENTS INNER JOIN EQUIPS ON CLIENTS.id_client = EQUIPS.id_client
GROUP BY CLIENTS.Nom
HAVING COUNT(EQUIPS.num_serie) > 2;
```
- **`INNER JOIN ... ON`:** Enllaça les dues taules mitjançant la relació de clau primària i clau forana.
- **`GROUP BY`:** Agrupa els registres pel camp indicat.
- **`HAVING`:** Aplica un filtre sobre el resultat de l'agrupament (només clients que tinguen més de 2 equips).
