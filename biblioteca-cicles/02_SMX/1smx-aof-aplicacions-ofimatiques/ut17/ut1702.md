EJERCICIOS PROPUESTOS

5.1. Para la realización de los ejercicios se utilizará la base de datos VENTAS. Diseñar los siguientes formularios

A) Formulario Entrada de ventas. Este formulario se encargará de realizar operaciones sobre la tabla Ventas. Estará asociado a la tabla Ventas. Para elegir los códigos de cliente y de producto utilizar controles de cuadro combinado que muestren los nombres de cliente y producto respectivamente. El formulario se muestra en la Figura 5.38.

Fig 5.38. Formulario Entrada de ventas.

Para obtener el total de registros se crea un campo independiente y en la propiedad Origen de control se escribe la fórmula: =Cuenta([CodigoPedido]).

Consta además de 10 botones, los 7 primeros para realizar las operaciones básicas con registros, crear nuevo registro, desplazamiento hacia delante y atrás, guardar los cambios, deshacer los cambios, borrar y buscar registros. Hay dos botones que abrirán los formularios de ventas de clientes y de ventas de productos, que se expondrán a continuación. Y el último botón que se utilizará para cerrar el formulario.

B) Formulario Datos de clientes y ventas. Este formulario se abre al pulsar el botón Abrir formulario de ventas de clientes. Se muestra en la siguiente figura. Consta de dos zonas, en la primera se visualizan los datos del cliente, y el la segunda los datos de las ventas de ese cliente, esto debe ir en un subformulario vinculado con el código de cliente. Para este subformulario es necesario crear una consulta. El total importe se calcula en un campo independiente colocado en el pie del formulario, la fórmula es: Suma([importe]), siendo el importe el campo con el importe de la venta, que será un campo calculado de la consulta. Este formulario sólo se utiliza para ver los datos por lo tanto es necesario bloquear los campos.
