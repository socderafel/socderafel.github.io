En el model ofimàtic clàssic, si cinc persones havien de redactar una memòria tècnica, el document viatjava com a fitxer adjunt per correu electrònic, generant versions caòtiques com `informe_v1.docx`, `informe_v2_revisat.docx` o `informe_final_FINAL_definitiu.docx`. Aquest model s'ha substituït completament per la **coautoria en temps real**, on un únic document central és editat simultàniament per múltiples membres de l'equip.

---

## 1. Coautoria en Temps Real i Bloqueig de Paràgrafs

Quan dos o més usuaris obrin el mateix document a Google Docs o Word Online:
- Cada col·laborador és identificat per un **cursor de color distintiu** amb el seu nom o avatar.
- El sistema aplica un bloqueig a nivell de paràgraf per a evitar que dues persones sobreescriguen la mateixa paraula en la mateixa fracció de segon.
- Els canvis es desen de manera automàtica al núvol contínuament, sense necessitat de prémer cap botó de desat.

---

## 2. Historial de Versions i Auditoria de Canvis

La por tradicional a què un company esborre per error un capítol important s'elimina gràcies a l'**Historial de Versions**:
- El sistema registra una línia de temps de totes les modificacions realitzades.
- Permet comparar visualment què ha escrit o eliminat cada persona (ressaltat en colors associats a cada usuari).
- **Restauració amb un sol clic:** És possible tornar a qualsevol versió anterior del document en cas de discrepància o error tècnic greu.
- **Assignació de noms de versió:** Es poden etiquetar punts d'inflexió clau (ex: *"Versió aprovada per Direcció 15/10"*).

```
+-----------------------------------------------------------+
| PANELL D'HISTORIAL DE VERSIONS                            |
+-----------------------------------------------------------+
| [x] Versió actual (Desada automàticament fa 2 minuts)     |
| [ ] 03 Nov, 16:30 - Laura Vidal (Edició de pressupost)    |
| [ ] 03 Nov, 11:15 - Joan Cuenca (Creació de l'estructura) |
| [ ] 02 Nov, 09:00 - Document en blanc                     |
+-----------------------------------------------------------+
| [ Botó: Restaura aquesta versió ] | [ Descarrega còpia ]  |
+-----------------------------------------------------------+
```

---

## 3. Gestió de Rols i Permisos de Seguretat

El control d'accés és el pilar de la seguretat en la col·laboració corporativa:

| Rol d'Accés | Permisos Concedits | Cas d'Ús Recomanat |
| :--- | :--- | :--- |
| **Lector (Viewer)** | Pot visualitzar i descarregar/imprimir el fitxer (si no s'ha bloquejat expressament). No pot modificar absolutament res. | Publicació de normatives internes de l'empresa o catàlegs de preus oficials. |
| **Comentador (Commenter)** | No pot alterar el text original, però pot deixar comentaris al marge i suggeriments de canvi. | Fase de revisió per part de supervisors o clients abans de l'entrega final. |
| **Editor (Editor)** | Control total sobre el contingut del document: escriure, esborrar, formatar i acceptar/rebutjar canvis. | Membres directes de l'equip tècnic de redacció del projecte. |
| **Propietari (Owner)** | Totes les anteriors, més la capacitat de transferir la propietat, eliminar el fitxer definitivament i revocar accessos a qualsevol usuari. | Responsable del departament o gestor de la spin-off. |
