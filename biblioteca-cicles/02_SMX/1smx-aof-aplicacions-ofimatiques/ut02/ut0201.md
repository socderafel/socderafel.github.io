# 2.1 Jerarquia de Formatació: Caràcter, Paràgraf, Pàgina i Seccions

En l'edició professional de documents, l'aspecte visual i l'estructura lògica s'organitzen seguint una **jerarquia estricta de quatre nivells**: caràcter, paràgraf, pàgina i secció. 

Un error habitual dels usuaris novells és aplicar espais o salts de línia manuals repetits per col·locar el text; el tècnic de SMX ha de dominar els mecanismes formals de composició tipogràfica.

---

## 1. Els Quatre Nivells de Formatació

```
+─────────────────────────────────────────────────────────────────────────────+
| 4. SECCIÓ: Blocs amb nombre de columnes independents (ex: 2 columnes).      |
|  +───────────────────────────────────────────────────────────────────────+  |
|  | 3. PÀGINA: Mida (A4), orientació, marges, capçaleres i peus.          |  |
|  |  +─────────────────────────────────────────────────────────────────+  |  |
|  |  | 2. PARÀGRAF: Alineació, interlineat, espaiat anterior/posterior,  |  |  |
|  |  |    sagnies (primera línia, francesa) i tabuladors.              |  |  |
|  |  |  +───────────────────────────────────────────────────────────+  |  |  |
|  |  |  | 1. CARÀCTER: Tipografia (font), cos (pt), estil (negreta, |  |  |  |
|  |  |  |    cursiva), color, espaiat entre lletres i superíndex.   |  |  |  |
|  |  |  +───────────────────────────────────────────────────────────+  |  |  |
|  |  +─────────────────────────────────────────────────────────────────+  |  |
|  +───────────────────────────────────────────────────────────────────────+  |
+─────────────────────────────────────────────────────────────────────────────+
```

---

## 2. Tipografia i Format de Caràcter

* **Famílies Tipogràfiques:**
  - *Serif (amb remat):* Lletres amb xicotets traços terminals (Times New Roman, Garamond, Libertine). Ideals per a impressió en paper continu perquè guien l'ull al llarg de la línia.
  - *Sans-Serif (pal sec):* Línies netes i geomètriques (Arial, Helvetica, Liberation Sans, Roboto). Òptimes per a lectura en pantalles i títols destacats.
  - *Monoespaiades:* Tots els caràcters tenen exactament la mateixa amplada (Courier New, Consolas). Emprades per a codi font o sortides de terminal CLI.
* **Unitats de Mesura:** El **punt tipogràfic (pt)** equival a $1/72$ de polzada ($0,3528	ext{ mm}$).

---

## 3. Format de Paràgraf i Tabulacions

Un paràgraf comença després d'un salt dur (`Enter` o `¶`) i posseeix propietats geomètriques pròpies:
* **Alineació:** Esquerra, dreta, centrada o **justificada** (alineada a ambdós marges mitjançant microespaiat entre paraules).
* **Sagnies (Indents):**
  - *Sagnia de primera línia:* Desplaça únicament la primera línia del paràgraf cap a la dreta.
  - *Sagnia francesa:* Manté la primera línia a l'esquerra i sagna totes les següents (típica en bibliografies i llistats).
* **Espaiat entre paràgrafs:** S'ha de configurar amb l'espaiat superior i inferior de paràgraf, **mai prement enters buits**.
* **Tabuladors:** Marques a la regla per alinear text en columnes: esquerra, dreta, centrada i **decimal** (alinea números exactament per la coma decimal).
