# 2.5 Combinació de Correspondència i Formularis PDF Interactius

En entorns administratius, empresarials i docents, sovint cal emetre centenars de cartes d'avís, diplomes, certificats o sobres personalitzats a partir d'un llistat de contactes. 

La **combinació de correspondència** (*Mail Merge*) és la tècnica que automatitza aquest procés fusionant un **document model** amb una **font de dades externa**. A més, l'elaboració de **formularis PDF interactius** permet recollir dades de clients sense errors de transcripció.

---

## 1. Els Components de la Combinació de Correspondència

```
+───────────────────────────+         +───────────────────────────+
| DOCUMENT PRINCIPAL        |         | FONT DE DADES EXTERNA     |
| (Model de Carta / Diploma)|         | (Taula Calc / Base / CSV) |
| "Benvolgut/da <Nom>,"     | <─────> | +─────+───────+─────────+ |
| "el seu saldo és <Saldo>" |         | | Nom | Cognom| Saldo   | |
+───────────────────────────+         | +─────+───────+─────────+ |
              │                       | | Pau | Giner | 150 €   | |
              ▼                       | | Ana | Sanchis| 320 €  | |
+───────────────────────────────────+ +───────────────────────────+
| DOCUMENTS PERSONALITZATS INDIVIDUALS                            |
| Carta 1: "Benvolgut Pau, el seu saldo és 150 €"                 |
| Carta 2: "Benvolguda Ana, el seu saldo és 320 €"                |
+─────────────────────────────────────────────────────────────────+
```

1. **Document Principal:** El document de Writer que conté el text comú fix i els **camps de fusió** especials (`<Nom>`, `<Adreça>`, `<DNI>`).
2. **Font de Dades:** Un fitxer estructurat que conté els registres individuals. Pot ser un full de càlcul Calc (`.ods`), un fitxer CSV separat per comes o una taula/consulta d'una base de dades Base/Access (`.odb` / `.accdb`).
3. **Document Resultant:** El lot de cartes generades que es pot enviar directament a la impressora, desar com un únic fitxer amb tantes pàgines com destinataris o enviar com a correus electrònics individuals personalitzats via servidor SMTP.

---

## 2. Creació de Formularis PDF Emplenables

Writer permet crear formularis oficials interactius mitjançant la barra d'eines **Controls de formulari**:
* **Quadre de text:** Per a dades obertes (Nom, Adreça).
* **Casella de verificació (*Checkbox*):** Per a opcions booleanes múltiples (ex: "Accepta la política de privadesa").
* **Botons d'opció (*Radio buttons*):** Per a opcions mútuament excloents on només se'n pot triar una.
* **Quadre de llista desplegable (*Dropdown*):** Per triar entre valors prefixats (províncies, cicles formatius).
* **Botó d'enviament o restabliment:** Per enviar les dades per correu o netejar el formulari.
* **Exportació a PDF:** En exportar, cal assegurar-se de marcar la casella **«Crea un formulari PDF»** triant el format de tramesa (FDF, PDF, HTML o XML).
