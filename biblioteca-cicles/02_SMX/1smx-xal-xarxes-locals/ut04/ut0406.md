# 4.6 Configuració de Routers SOHO

Un **router SOHO** (*Small Office / Home Office*), sovint conegut com a "router domèstic" o mòdem/router de fibra (ONT integrada), és en realitat un dispositiu multifunció tot-en-un que integra:
1. Un **encaminador (Router)** de nivell de xarxa.
2. Un **commutador (Switch)** de 4 o 8 ports Ethernet de nivell 2.
3. Un **punt d'accés Wi-Fi (AP)** de nivell 2.
4. Un **servidor DHCP** i reenviador DNS.
5. Un **tallafocs amb NAT / PAT** (*Network Address and Port Translation*).

---

## 🌐 Configuració de les Interfícies WAN i LAN

- **Interfície LAN (Xarxa Local Privada):**
  - Adreça IP del router (ex: `192.168.1.1/24`).
  - Àmbit del **servidor DHCP**: rang d'adreces que el router repartirà automàticament als ordinadors i mòbils de l'aula (ex: des de `192.168.1.100` fins a `192.168.1.250`).
  - **Reserves d'adreces DHCP:** Permet assignar sempre la mateixa IP fixa a un dispositiu concret (com la impressora de xarxa o el servidor web) vinculant-la a la seua adreça MAC física.
- **Interfície WAN (Internet / Operadora Externa):**
  - Rep l'adreça IP pública de l'ISP (mitjançant client DHCP, IP fixa o connexió PPPoE amb usuari i contrasenya).

---

## 🔀 Com funciona el NAT / PAT?

Com que les adreces privades de la LAN (`192.168.1.x`) no poden viatjar per Internet pública, el router utilitza la **traducció d'adreces i ports (PAT - Port Address Translation)**:
- Quan un PC local amb IP `192.168.1.25` sol·licita una pàgina web des del seu port origen `54120`:
  1. El router substitueix la IP privada del PC per la seua pròpia **IP pública**.
  2. Substitueix el port privat per un port lliure del router (ex: port `61000`).
  3. Guarda aquesta correspondència a la **taula de traducció NAT**.
  4. Quan el servidor web respon al port `61000`, el router consulta la taula i reenvia la resposta de tornada al PC `192.168.1.25:54120`.

---

## 🚪 Reenviament de Ports (*Port Forwarding*) i Zona DMZ

Si volem que un servidor intern de la xarxa local (com un servidor web HTTP al port 80 o un servidor SSH al port 22) siga accessible des de l'exterior d'Internet:
- **Port Forwarding (Mapatge de ports):**
  Es crea una regla al router: *"Qualsevol petició exterior que arribe a la IP Pública pel port 8080, reenvia-la a l'adreça privada interna `192.168.1.50` al port `80`"*.
- **Zona Desmilitaritzada (DMZ Host):**
  Configura una adreça IP interna cap a la qual el router reenvia **tots els ports entrants** no associats a cap altra regla específica. S'ha d'utilitzar amb molta precaució perquè exposa l'equip a possibles atacs directes des d'Internet.
