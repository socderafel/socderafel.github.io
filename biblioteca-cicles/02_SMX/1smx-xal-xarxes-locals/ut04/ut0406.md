# 4.6 Activitat 4.5: Configuració d'un router Soho

Configuració completa d’un Router SOHO amb el simulador TP‑Link

1. Simulador utilitzat

TP‑Link Web GUI Emulator

Accés directe:

🌐

https://www.tp-link.com/us/support/emulator/

[tp-link.com]

Aquest simulador permet practicar amb diferents models de routers TP‑Link de gamma domèstica i professional. Els alumnes poden navegar per totes les seccions del panell d’administració com si estigueren davant d’un dispositiu real.

2. Activitat pas a pas

A. Accés al simulador

Obri el navegador.

Entra a:

https://www.tp-link.com/us/support/emulator/

Selecciona un model de router, per exemple:

Archer C6

,

Archer AX10

,

Archer AX20

, etc.

Router Mode
