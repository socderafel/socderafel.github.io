# 4.10 Introducció a les VLANs (IEEE 802.1Q)

Una **VLAN** (*Virtual Local Area Network* o Xarxa d'Àrea Local Virtual) és una xarxa d'equips que es comporten com si estigueren connectats al mateix cable físic i switch, encara que puguen estar distribuïts en diferents segments físics d'una xarxa local d'edifici.

De manera equivalent, les VLANs permeten que equips connectats al **mateix switch físic** estiguen completament aïllats entre si en dominis de difusió independents, exactament com si es trobaren connectats a commutadors físics diferents.

---

## 🏷️ Etiquetatge de Trames segons l'Estàndard IEEE 802.1Q

Quan una trama viatja a través d'un enllaç troncal (*Trunk*) que connecta dos switches o un switch amb un router:
- S'insereix un camp especial de **4 bytes (32 bits)** a la capçalera de la trama Ethernet clàssica:
  - **TPID (*Tag Protocol Identifier* - 16 bits):** Fixat al valor hexadecimal `0x8100` per indicar que és una trama amb etiqueta 802.1Q.
  - **PCP (*Priority Code Point* - 3 bits):** Per a qualitat de servei (QoS, prioritzar trànsit de veu VoIP sobre descàrregues web).
  - **VID (*VLAN Identifier* - 12 bits):** Identifica el número de la VLAN a la qual pertany la trama ($2^{12} = 4096$ VLANs possibles, de l'1 al 4094).

## 🛠️ Configuració Pràctica de VLANs en Cisco IOS (Packet Tracer)

En el laboratori de xarxes crearem les nostres pròpies VLANs utilitzant commutadors gestionables Cisco Catalyst:

```cisco
! 1. Entrar en mode de configuració global
Switch> enable
Switch# configure terminal

! 2. Crear les dues VLANs departamentals
Switch(config)# vlan 10
Switch(config-vlan)# name ALUMNES
Switch(config-vlan)# exit

Switch(config)# vlan 20
Switch(config-vlan)# name PROFESSORS
Switch(config-vlan)# exit

! 3. Assignar els ports FastEthernet 0/1 a 0/10 a la VLAN 10 (Mode Accés)
Switch(config)# interface range fastEthernet 0/1 - 10
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

! 4. Assignar els ports FastEthernet 0/11 a 0/20 a la VLAN 20 (Mode Accés)
Switch(config)# interface range fastEthernet 0/11 - 20
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config-if-range)# exit

! 5. Configurar el port GigabitEthernet 0/1 com a Troncal cap al Router
Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit

! 6. Comprovar l'estat de les VLANs i dels ports
Switch# show vlan brief
Switch# show interfaces trunk
```

## 🔄 Encaminament Inter-VLAN (*Router-on-a-Stick*)

Com que per definició els equips de la VLAN 10 i la VLAN 20 estan aïllats en capa 2, no es poden comunicar directament.
Per permetre que un professor puga enviar un fitxer a un alumne (o accedir a la mateixa impressora compartida):
- Connectem el port troncal del switch a una interfície física d'un router (ex: `GigabitEthernet 0/0`).
- Al router creem **subinterfícies lògiques** associades a cada VLAN:

```cisco
Router(config)# interface gigabitEthernet 0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

Router(config)# interface gigabitEthernet 0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit

Router(config)# interface gigabitEthernet 0/0
Router(config-if)# no shutdown
```
A partir d'aquest moment, el router actua com a passarel·la per defecte entre totes dues xarxes virtuals!
