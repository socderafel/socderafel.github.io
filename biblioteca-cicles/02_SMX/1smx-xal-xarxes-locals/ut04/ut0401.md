# 4.1 Routers Domèstics i SOHO: NAT, PAT i Encaminament

Un **encaminador** (router) és un dispositiu que opera a la **Capa 3 (Xarxa)** del model OSI i té com a missió principal interconnectar xarxes lògiques diferents, seleccionant el millor camí (*routing*) per enviar els paquets des de l'origen fins a la destinació.

En entorns domèstics i de xicoteta oficina (**SOHO** - *Small Office / Home Office*), el dispositiu que col·loquialment anomenem «router» és en realitat un **equip tot en un** integrat que combina: un router de Capa 3, un commutador Ethernet de 4 ports de Capa 2, un punt d'accés Wi-Fi, un servidor DHCP, un tallafocs bàsic (SPI) i un mòdul de conversió de línia de fibra (ONT) o mòdem.

---

## 1. La Funció d'Encaminament i la Passarel·la per Defecte

Quan un ordinador vol transmetre un paquet IP:
1. Compara la seua pròpia IP i màscara amb la IP de destí.
2. Si la IP de destí pertany a la seua mateixa xarxa local, envia la trama directament al host a través del switch mitjançant resolució ARP de la MAC.
3. Si la IP de destí pertany a una xarxa remota (com qualsevol servidor a Internet), l'ordinador és incapaç d'arribar-hi per si mateix i envia el paquet a la seua **Passarel·la Predeterminada** (*Default Gateway*), que és la IP de la interfície LAN del router local (per exemple `192.168.1.1`).

El router consulta la seua **Taula d'Encaminament** (*Routing Table*), decrementa el camp **TTL** (*Time To Live*) del paquet per evitar bucles infinits, recalcula el checksum i reexpedeix el paquet per la interfície WAN cap al proveïdor d'Internet (ISP).

---

## 2. NAT i PAT (Traducció d'Adreces de Xarxa i Ports)

A causa de l'escassetat d'adreces IPv4, la tecnologia clau que fa possible que desenes de dispositius domèstics naveguen per Internet simultàniament amb **una única adreça IP pública** és **NAT/PAT** (*Network Address Translation / Port Address Translation* o NAT Sobrecarregat):

```
+──────────────────────────────+               +───────────────────+               +─────────────────────+
| Dispositiu LAN Privat        |               | Router Domèstic   |               | Servidor a Internet |
| IP: 192.168.1.15:52341       | ────────────> | NAT / PAT Gateway | ────────────> | Web HTTPS           |
| (Adreça Privada RFC 1918)    |               | IP Pública:       |               | 142.250.184.206:443 |
+──────────────────────────────+               | 80.25.10.14:40001 |               +─────────────────────+
                                               +───────────────────+
```

1. **Sortida:** Quan el PC privat (`192.168.1.15`) envia una sol·licitud web al port 443, el router intercepta el paquet, substitueix la IP d'origen privada per la seua pròpia **IP pública** (`80.25.10.14`) i assigna un port públic aleatori (ex: `40001`). Guarda aquesta correspondència a la seua **Taula de Traducció NAT**.
2. **Entrada:** Quan el servidor web respon enviant el tràfic a `80.25.10.14:40001`, el router cerca a la seua taula, veu que eixe port correspon al PC intern `192.168.1.15:52341`, substitueix les capçaleres i lliura el paquet al client exacte.

---

## 3. Obertura de Ports (Port Forwarding) i DMZ

Com que NAT bloqueja per defecte totes les connexions entrants des d'Internet cap a la xarxa local per seguretat, quan volem allotjar un servei intern (com un servidor web a l'aula, un servidor de fitxers o una partida multijugador) cal configurar regles especials al router:

* **Port Forwarding (Redireccionament de Ports):** Indica al router que qualsevol connexió externa que arribe a un port públic determinat (per exemple, port 80 o 443) siga automàticament reenviada cap a la IP privada d'un equip intern específic (ex: `192.168.1.200:80`).
* **DMZ (Zona Desmilitaritzada):** Configura una IP privada concreta per rebre **tots els ports entrants** que no tinguen una regla específica de port forwarding. És una opció de risc alt perquè exposa l'equip directament a tots els atacs d'Internet.
