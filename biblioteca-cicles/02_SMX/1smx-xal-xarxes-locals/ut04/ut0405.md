# 4.5 Diagnòstic de Xarxes, Eines CLI i Captura de Paquets amb Wireshark

Quan un client o empresa comunica una incidència («no puc obrir el programa de gestió», «Internet va extremadament lent» o «la impressora ha desaparegut»), el tècnic de SMX ha de procedir de forma professional i estructurada, descartant fallades capa a capa del model OSI mitjançant utilitats especialitzades.

---

## 1. El Kit d'Eines CLI Essencial del Tècnic de Xarxes

A més de les comandes bàsiques d'adreçament (`ipconfig` / `ip a` i `ping`), tot tècnic ha de dominar:

* **`tracert` (Windows) / `traceroute` (Linux):** Descobreix la ruta exacta salt a salt (*hop-by-hop*) que segueix un paquet fins al servidor de destí. Utilitza missatges ICMP amb valors creixents de TTL ($TTL=1, 2, 3...$) per provocar que cada router del camí retorne un missatge *ICMP Time Exceeded*, identificant en quin salt exacte es produeix la fallada o el coll d'ampolla.
* **`nslookup` / `dig`:** Consulta directament servidors DNS per verificar la resolució de registres tipus A (IPv4), AAAA (IPv6) o MX (correu).
* **`arp -a`:** Mostra la taula ARP del sistema operatiu, que relaciona les adreces IP locals amb les seues corresponents adreces físiques MAC.
* **`netstat -ano` / `ss -tuln`:** Llista tots els ports TCP i UDP que el sistema té oberts a l'espera de connexions (*LISTENING*) o actius (*ESTABLISHED*), juntament amb el PID del programa responsable.

---

## 2. Anàlisi Profunda de Protocols amb Wireshark

**Wireshark** és l'analitzador de protocols de xarxa (*packet sniffer*) més potent i utilitzat del món:

```
+─────────────────────────────────────────────────────────────────────────────+
| FINESTRA PRINCIPAL DE WIRESHARK:                                            |
| 1. Llista de Paquets: Núm, Temps, IP Origen, IP Destí, Protocol, Longitud   |
|    1   0.000000   192.168.1.15   192.168.1.1    DNS   Standard query A...  |
|    2   0.002145   192.168.1.1    192.168.1.15   DNS   Standard response... |
| 2. Arbre de Detalls de la Capa (Frame -> Ethernet -> IPv4 -> TCP -> HTTP)   |
| 3. Contingut en Bytes Bruts (Hexadecimal i Text ASCII)                      |
+─────────────────────────────────────────────────────────────────────────────+
```

### Filtres de Visualització Crítics en Wireshark:
* `http`: Mostra exclusivament el tràfic web no xifrat.
* `dns`: Filtra totes les consultes i respostes de resolució de dominis.
* `bootp` o `dhcp`: Captura la negociació DORA (Discover, Offer, Request, Acknowledge) de DHCP.
* `ip.addr == 192.168.1.1`: Filtra tot el tràfic amb origen o destí a la passarel·la.
* `tcp.port == 80 || tcp.port == 443`: Filtra el tràfic web general.

---

## 3. Escaneig Bàsic de Seguretat amb Nmap

**Nmap** (*Network Mapper*) és l'eina de referència per a l'auditoria de xarxes i descobriment de vulnerabilitats:
* `nmap -sn 192.168.1.0/24`: Realitza un *ping scan* per descobrir ràpidament quins equips estan encesos i connectats a la xarxa local sense escanejar ports.
* `nmap -sT 192.168.1.50`: Comprova quins ports TCP estan oberts a un equip objectiu realitzant una connexió completa.
