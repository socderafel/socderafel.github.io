# 4.16 Activitat 4.12. Configuració inicial d'un router

1.- Crea un esquema de xarxa com el de la imatge.

Com era d'esperar, no existeix comunicació entre els dos PC. Cada PC està en una xarxa distinta.

2.- Modifica esquema de xarxa substituint el switch central per un router. Aquest dispositiu és l'únic que és capaç de comunicar xarxes distinta. Treballa en el nivell 3 d'ISO/OSI. Utilitza el router 1841

3.- Configura el router

L'encaminador està unint dues xarxes distintes i, per tant hauràs de configurar les seues dues interfícies amb direccions de xarxa diferents.

Ací tens la configuració de la primera interfície

Configuració d'Interfícies mitjançant Comandos (CLI)

Una vegada dins de la consola, els comandos fonamentals són:

Entrar al mode privilegiat: Escriu

enable

Entrar al mode de configuració global: Escriu

configure terminal

Seleccionar la interfície: Per exemple,

interface fastethernet 0/0

Assignar una adreça IP: Usa el comando ip address [adreça_IP] [màscara_de_subxarxa]. Per exemple:

ip address 192.168.0.1 255.255.255.0

Activar la interfície: Per defecte les interfícies estan apagades (down). Has d'executar el comando

no shutdown

per a encendre-la

Eixir de la interfície: Escriu

exit

per a tornar al mode de configuració global.

Repetir el procés amb l'altra interfície 0/1 (evidentment li has de proporcionar una altra adreça ip

Executa el comando

copy run start

en el mode privilegiat per a emmagatzemar la configuració en la memòria NVRAM

4.- Comprova la connectivitat dels PC.

Observa que cada ordinador està en un rang de xarxa distinta i que, per tant, és l'encaminador el que està proporcionant aquesta connectivitat.

5.- Habilita un servidor DHCP

El router está connectat a dos xarxes distintes. Hem de crear un pool (conjunt d'adreces) per a cada xarxa

En el mode de configuració global: ip dhcp pool [nom_de el_pool]. Per exemple

ip dhcp pool xarxa1

Definir la xarxa: network [direcció_de_xarxa] [màscara]. En aquest cas

network 192.168.0.1 255.255.255.0

Definir el Gateway: default-router [IP_de_la_interfície_de el_encaminador] . Per a nosaltres

default-router 192.168.0.1

De vegades es convenient excluir algunes adreces IP perquè no siguen oferides (IP reservades a servidors, routers, etc). Escriu

ip dhcp excluded-address 192.168.0.1 192.168.0.10

i el router no otorgarà aquestes adreces a cap dispositiu

6.- Connecta nous clients DHCP a cada xarxa

Inclou més ordinadors a cada xarxa i comprova que reben IP i que connectivitat entre ells.
