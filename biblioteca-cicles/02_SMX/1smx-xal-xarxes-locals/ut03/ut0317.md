# 3.17 Guia Pràctica de Subnetting de Classe C (Exercici Resolt)

Aquesta guia detalla el mètode estàndard per resoldre problemes de subnetting a les proves teòrico-pràctiques del mòdul.

---

## 📝 Enunciat del Problema Tipus Examen

> Un institut disposa de la xarxa base de Classe C privada **`192.168.50.0/24`** i necessita dissenyar un pla d'adreçament que permeta crear **3 subxarxes independents** (per exemple: Aula 1, Aula 2 i Sala de Professors), garantint un mínim de **25 ordinadors (hosts)** per a cadascuna d'elles.
>
> 1. Quants bits de subxarxa ($s$) cal robar a la porció de host?
> 2. Quina serà la nova màscara de subxarxa en notació CIDR i en format decimal puntejat?
> 3. Quin és el "sal" o mida del bloc entre subxarxes consecutives?
> 4. Construeix la taula d'adreçament completa indicant per a cada subxarxa: Adreça de Xarxa, Primer Host Útil, Últim Host Útil i Adreça de Difusió (*Broadcast*).

---

## 🧠 Resolució Matemàtica Pas a Pas

### 1. Determinació dels bits de subxarxa ($s$):
Apliquem la fórmula de subxarxes:
$$2^s \ge \text{Subxarxes requerides} \implies 2^s \ge 3$$
- Si $s = 1 \implies 2^1 = 2 < 3$ (Insuficient).
- Si $s = 2 \implies 2^2 = \mathbf{4} \ge 3$ (**Vàlid!** Robarem **2 bits** i tindrem capacitat per a 4 subxarxes).

### 2. Comprovació de la capacitat de hosts ($h$):
Com que l'últim octet tenia 8 bits:
$$h = 8 - s = 8 - 2 = \mathbf{6 \text{ bits per a hosts}}$$
Comprovem els hosts útils per subxarxa:
$$\text{Hosts Útils} = 2^h - 2 = 2^6 - 2 = 64 - 2 = \mathbf{62 \text{ hosts per subxarxa}}$$
Com que l'enunciat en demanava un mínim de 25, **compleix el requisit amb escreix!**

### 3. Nova màscara de subxarxa:
- Notació CIDR: $24 + s = 24 + 2 = \mathbf{/26}$.
- Format decimal puntejat:
  L'últim octet té els 2 primers bits a $1$:
  $$11000000_2 = 128 + 64 = \mathbf{192}$$
  $$\text{Màscara} = \mathbf{255.255.255.192}$$

### 4. Càlcul del Sal de Xarxa (*Block Size*):
El sal entre xarxes consecutives és la potència de 2 corresponent al valor del bit menys significatiu robat, o bé restat de 256:
$$\text{Sal de Xarxa} = 256 - 192 = 2^6 = \mathbf{64}$$
