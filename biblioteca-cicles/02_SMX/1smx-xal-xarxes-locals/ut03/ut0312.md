# 3.12 Activitat 3.8: subnetting en la empresa 1

Una empresa dispone de una red privada basada en una

dirección IP de clase B privada

. La empresa está dividida en los siguientes departamentos:

Recursos Humanos

Contabilidad

Ventas

Producción

Cada departamento debe estar ubicado en una

subred independiente

, conectada mediante un

switch de departamento

.

La

interconexión entre los departamentos

se realizará utilizando

fibra óptica

.

Se pide realizar el

esquema de direccionamiento IP utilizando subnetting

, partiendo de una

dirección de clase B privada

, de forma que cada departamento tenga su propia red.

Requisitos del direccionamiento

Para

cada departamento

, el alumno deberá indicar:

Dirección de red

Dirección de broadcast

Primera IP válida

Última IP válida

Todas las direcciones deberán ser

válidas y coherentes con la máscara de subred utilizada

.

Tareas a realizar

Selecciona una

dirección IP privada de clase B

(por ejemplo, dentro del rango 172.16.0.0 – 172.31.255.255).

Aplica

subnetting

para dividir la red en

4 subredes

, una por cada departamento.

Rellena una tabla con los siguientes datos para cada departamento:

Dirección de red

Dirección de broadcast

Primera IP válida

Última IP válida

Diseña la

topología de red en Packet Tracer

, que deberá incluir:

Un switch para cada departamento.

Equipos finales conectados a cada switch.

Enlaces de

fibra óptica

para la comunicación entre los departamentos.

Asigna correctamente las direcciones IP a los dispositivos según el esquema diseñado.
