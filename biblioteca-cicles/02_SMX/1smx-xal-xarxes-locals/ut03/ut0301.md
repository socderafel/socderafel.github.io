# 3.1 Interconnexió d'Equips en Xarxes Locals

Perquè dos dispositius puguen comunicar-se dins d'una xarxa TCP/IP, no n'hi ha prou amb connectar un cable físic de coure o associar-se a una xarxa Wi-Fi. Cal configurar correctament els **paràmetres de nivell de xarxa (Capa 3)**.

---

## ⚙️ Els Quatre Paràmetres IP Obligatoris

1. **Adreça IP (*IP Address*):** L'identificador lògic únic de l'equip dins de la seua xarxa (ex: `192.168.1.50`).
2. **Màscara de Subxarxa (*Subnet Mask*):** Delimita quina part de l'adreça pertany a la xarxa comuna i quina part identifica el dispositiu individual (ex: `255.255.255.0`).
3. **Passarel·la per Defecte (*Default Gateway*):** L'adreça IP de la interfície del router més propera que connecta la xarxa local amb l'exterior (Internet o altres xarxes de l'institut, ex: `192.168.1.1`). Si un equip vol enviar un paquet a una IP fora de la seua xarxa, el lliura a la passarel·la.
4. **Servidor de Noms de Domini (DNS - *Domain Name System*):** L'adreça IP del servidor encarregat de traduir noms fàcils de recordar per humans (`www.google.com`) a les seues adreces IP numèriques reals (`142.250.200.196`). Exemples de servidors DNS públics: `1.1.1.1` (Cloudflare) o `8.8.8.8` (Google).

---

## 🛠️ Comandaments de Diagnòstic de Connectivitat

### En entorns GNU/Linux (Bash):
```bash
# Consultar les adreces IP i màscares assignades a cada targeta
ip a

# Consultar la taula d'encaminament i conèixer la passarel·la per defecte
ip route show

# Comprovar la connectivitat bàsica ICMP amb el router (4 intents)
ping -c 4 192.168.1.1

# Traçar el camí de routers intermedis fins a una destinació
traceroute 8.8.8.8
```

### En entorns Microsoft Windows (CMD / PowerShell):
```cmd
REM Visualitzar tota la configuració de xarxa incloent DNS i DHCP
ipconfig /all

REM Alliberar i renovar la concessió DHCP
ipconfig /release
ipconfig /renew

REM Netejar la memòria cau de resolució DNS local
ipconfig /flushdns

REM Comprovar la taula de correspondències ARP (IP a MAC)
arp -a
```
