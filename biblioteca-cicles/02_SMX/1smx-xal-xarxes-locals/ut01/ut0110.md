# 1.10 Components de les Xarxes Locals

Una xarxa d'àrea local es compon de dispositius terminals (*hosts* o punts finals), adaptadors físics de connexió i equips electrònics intermedis encarregats d'encaminar i commutar el flux de trames.

---

## 💳 La Targeta d'Interfície de Xarxa (NIC)

La **NIC** (*Network Interface Card*) és el component de maquinari que permet a un equip comunicar-se amb el medi físic de transmissió. Pot ser integrada a la placa base, una targeta d'expansió PCIe o un adaptador USB extern.

### 🏷️ L'Adreça MAC Física (48 bits / 6 bytes):
Cada targeta de xarxa porta gravada de fàbrica a la seua memòria ROM una adreça física única en el món anomenada **adreça MAC** (*Media Access Control*):
- Format: 12 dígits hexadecimals separats per dos punts o guions (ex: `00:1A:2B:3C:4D:5E`).
- Estructura:
  $$\underbrace{\text{00 : 1A : 2B}}_{\text{OUI (24 bits)}} \; : \; \underbrace{\text{3C : 4D : 5E}}_{\text{NIC Specific (24 bits)}}$$
  - **OUI (*Organizationally Unique Identifier*):** Els primers 3 bytes identifiquen de forma exclusiva el fabricant del xip (assignat per l'IEEE: Intel, Realtek, Cisco, Apple, etc.).
  - **Identificador de dispositiu:** Els últims 3 bytes són el número de sèrie assignat pel fabricant.

## 🔀 Dispositius Electrònics d'Interconnexió

| Dispositiu | Capa OSI | Funcionament Principal | Comportament davant Col·lisions |
| :--- | :---: | :--- | :--- |
| **Repetidor / Hub (Concentrador)** | **Capa 1 (Física)** | Repeteix el senyal elèctric que entra per un port cap a tots els altres ports sense mirar contingut ni adreces. | Tots els ports comparteixen un únic **domini de col·lisió**. Desfasat en l'actualitat. |
| **Bridge / Switch (Commutador)** | **Capa 2 (Enllaç)** | Llegeix l'adreça MAC de destinació de cada trama i l'envia **únicament al port** on està connectat l'equip receptor (mitjançant la taula MAC / CAM). | Cada port és un **domini de col·lisió independent** (Full-Duplex sense col·lisions). |
| **Router (Encaminador)** | **Capa 3 (Xarxa)** | Llegeix les adreces IP de nivell de xarxa dels paquets i els encamina entre diferents xarxes i subxarxes mitjançant taules d'encaminament. | Cada interfície separa un **domini de difusió (*broadcast domain*)**. |
| **Punt d'Accés (Access Point - AP)** | **Capa 2 (Enllaç)** | Actua com un pont transparent que converteix trames Ethernet cablejades (802.3) en trames sense fil Wi-Fi (802.11) i viceversa. | Medi de ràdio compartit. |
