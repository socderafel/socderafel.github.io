# 2.5 Equips d'Interconnexió: Hub vs Switch, Dominis de Col·lisió i Difusió

Per connectar els equips finals (ordinadors, impressores, càmeres IP) i conformar una xarxa local, és necessari emprar dispositius concentradors d'interconnexió. Històricament es van utilitzar els **hubs**, però han sigut totalment substituïts pels **switches**. 

Entendre les diferències arquitectòniques entre ambdós equips i els conceptes de **domini de col·lisió** i **domini de difusió** és indispensable per al disseny eficient de xarxes de dades.

---

## 1. Hubs (Concentradors) - Capa 1 Física

Un **hub** és un dispositiu purament de **Capa 1 (Física)** que actua com un repetidor multiport:

* **Principi d'inundació cega (*flooding*):** Qualsevol senyal elèctric que arriba per un port es regenera i es reemet per **tots els altres ports**, sense mirar qui és el destinatari.
* **Mètode de transmissió:** Opera exclusivament en mode **Half-Duplex** (només un equip pot transmetre a la vegada; si dos transmeten simultàniament es produeix una col·lisió elèctrica).
* **Accés al medi:** Requereix l'algorisme **CSMA/CD** (*Carrier Sense Multiple Access with Collision Detection*) per gestionar qui transmet i gestionar els reenviaments aleatoris després d'una col·lisió.
* **Seguretat nul·la:** Qualsevol ordinador connectat al hub pot capturar tot el tràfic dels seus companys de classe posant la targeta de xarxa en mode promiscu.

---

## 2. Switches (Commutadors) - Capa 2 Enllaç de Dades

Un **switch** és un dispositiu intel·ligent de **Capa 2 (Enllaç de Dades)** que commuta trames Ethernet analitzant les adreces físiques MAC:

* **Taula de commutació (Taula MAC o memòria CAM):** El switch manté una taula dinàmica a la seua memòria on associa cada adreça MAC amb el número de port físic on es troba connectat eix equip:

```
+--------------------+--------------+
| Adreça MAC         | Port Físic   |
+--------------------+--------------+
| 00:1A:2B:3C:4D:5E  | Fa0/1        |
| 00:1A:2B:3C:4D:6F  | Fa0/2        |
| 00:1A:2B:3C:4D:7A  | Fa0/3        |
+--------------------+--------------+
```

* **Aprenentatge automàtic (*Auto-learning*):** Quan arriba una trama per un port, el switch llegeix la **MAC d'origen** i actualitza la taula. A continuació, llegeix la **MAC de destí**:
  - Si la MAC de destí ja està a la taula, envia la trama **únicament pel port corresponent**.
  - Si la MAC no està registrada (*Unicast desconegut*) o és una adreça de difusió (*Broadcast* `FF:FF:FF:FF:FF:FF`), l'envia per tots els ports excepte pel que ha entrat.
* **Mode Full-Duplex:** Permet transmetre i rebre informació de forma simultània sense risc de col·lisió, duplicant l'amplada de banda efectiva.

---

## 3. Dominis de Col·lisió vs Dominis de Difusió (Broadcast)

Aquest és un dels conceptes més preguntats en certificacions de xarxes com Cisco CCNA i exàmens de cicles formatius:

```
+───────────────────────────+───────────────────────────────────────────────────────+
| Concepte                  | Definició Tècnica i Comportament dels Dispositius    |
+───────────────────────────+───────────────────────────────────────────────────────+
| DOMINI DE COL·LISIÓ       | Àrea de xarxa on dos paquets poden col·lidir entre si.|
| (Collision Domain)        | • Un HUB forma un ÚNIC domini de col·lisió per a tots.|
|                           | • Un SWITCH trenca els dominis: CADA PORT és un       |
|                           |   domini de col·lisió independent.                    |
|                           | • Un ROUTER trenca els dominis de col·lisió a cada port|
+───────────────────────────+───────────────────────────────────────────────────────+
| DOMINI DE DIFUSIÓ         | Àrea de xarxa fins on arriba una trama de difusió     |
| (Broadcast Domain)        | (*Broadcast* MAC FF:FF:FF:FF:FF:FF).                  |
|                           | • Els HUBS i els SWITCHES NO tallen la difusió: tots  |
|                           |   els seus ports pertanyen al MATEIX domini broadcast.|
|                           | • Els ROUTERS SÍ que tallen la difusió: cap paquet de |
|                           |   broadcast creua un router per defecte.             |
|                           | • Les VLANs permeten trencar dominis de difusió en    |
|                           |   switches administrables.                            |
+───────────────────────────+───────────────────────────────────────────────────────+
```
