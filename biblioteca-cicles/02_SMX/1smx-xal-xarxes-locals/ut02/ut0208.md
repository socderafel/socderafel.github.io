# 2.8 Encapsulament PDU i Models en Acció

Quan un usuari escriu una adreça web al navegador (ex: `https://portal.edu.gva.es`), s'inicia una complexa cadena d'encapsulament on les dades es transformen progressivament a través de les capes de la pila de protocols.

---

## 📦 Les Unitats de Dades de Protocol (PDUs)

Cada nivell de la jerarquia anomena la seua unitat bàsica d'informació d'una forma tècnica diferent:

```
[ Capa d'Aplicació ] --------> DADES / MISSATGE (Data)
                                     │  (Afegeix capçalera de transport: Ports)
                                     ▼
[ Capa de Transport ] -------> SEGMENT (TCP) o DATAGRAMA (UDP)
                                     │  (Afegeix capçalera de xarxa: Adreces IP)
                                     ▼
[ Capa d'Internet ] ---------> PAQUET (IP Packet)
                                     │  (Afegeix capçalera Ethernet + Cua FCS)
                                     ▼
[ Capa d'Accés a Xarxa ] ----> TRAMA (Ethernet Frame)
                                     │  (Codificació de senyal elèctric / òptic)
                                     ▼
[ Capa Física ] -------------> BITS (0s i 1s)
```

---

## 🔍 Anatomia d'una Trama Ethernet II

La trama Ethernet és el contenidor final que viatja pel cable d'una xarxa local. Té l'estructura següent:

| Camp | Mida en Bytes | Funció |
| :--- | :---: | :--- |
| **Preàmbul + SFD** | 8 bytes | Sincronitza el rellotge del receptor (`10101010...10101011`). |
| **MAC Destinació** | 6 bytes | Adreça física de la targeta receptora (o `FF:FF:FF:FF:FF:FF` per a broadcast). |
| **MAC Origen** | 6 bytes | Adreça física de la targeta que envia la trama. |
| **EtherType** | 2 bytes | Indica quin protocol viatja dins (ex: `0x0800` per a IPv4, `0x86DD` per a IPv6, `0x0806` per a ARP). |
| **Càrrega Útil (Payload)**| 46 a 1500 bytes | El paquet IP encapsulat (MTU estàndard = 1500 bytes). |
| **FCS / CRC32** | 4 bytes | Codi de redundància cíclica per comprovar que cap bit s'ha corromput durant el viatge elèctric. |
