# 2.1 Models per Capes: Arquitectura OSI i TCP/IP

El disseny de xarxes complexes seria inabastable si un únic programa o protocol haguera de gestionar simultàniament des de l'emissió de fotons per una fibra òptica fins a la representació gràfica d'una pàgina web. Per resoldre aquesta complexitat, l'enginyeria de xarxes empra el principi fonamental de la **modularitat** i la **divisió en capes** (strata).

Cada capa realitza un conjunt ben definit de tasques especialitzades, oferint serveis a la capa immediatament superior i consumint els serveis de la capa inferior mitjançant interfícies estandarditzades.

---

## 1. Per Què S'Utilitzen Models en Capes?

L'estratificació en capes aporta avantatges determinants tant per a la indústria com per als administradors de sistemes:

* **Descomposició del problema:** Divideix la comunicació global de xarxa en mòduls independents i assequibles.
* **Interoperabilitat entre fabricants:** Permet que dispositius de Cisco, HP, Dell o equips basats en Linux i Windows es comuniquen sense cap fricció, sempre que respecten els mateixos protocols per a cada capa.
* **Flexibilitat i evolució tecnològica:** Es pot canviar o millorar la tecnologia d'una capa sense afectar les altres. Per exemple, podem canviar el mitjà físic de cable de coure a fibra òptica (Capa 1) sense haver de modificar l'adreçament IP (Capa 3) ni el navegador web (Capa 7).
* **Facilitat d'aprenentatge i resolució d'incidències:** Permet als tècnics de SMX diagnosticar fallades seguint una metodologia sistemàtica (de baix a dalt: començant pel cable i acabant en l'aplicació).

---

## 2. El Model de Referència OSI (Open Systems Interconnection)

A finals de la dècada del 1970, l'Organització Internacional per a l'Estandardització (**ISO**) va desenvolupar el **Model de Referència OSI** (norma ISO/IEC 7498) per proporcionar un marc teòric universal per a la interconnexió de sistemes oberts. Consta de **7 capes ben diferenciades**:

```
+---+----------------------+----------------------------------------------------------+
| # | Capa OSI             | Funció Principal                                         |
+---+----------------------+----------------------------------------------------------+
| 7 | Aplicació (App)      | Interfície amb els programes d'usuari (HTTP, DNS, SMTP). |
| 6 | Presentació          | Format, codificació, xifratge (TLS) i compressió dades.  |
| 5 | Sessió               | Establiment, manteniment i tancament de sessions.        |
| 4 | Transport            | Comunicació extrem a extrem, control flux i errors (TCP).|
| 3 | Xarxa (Network)      | Adreçament lògic global (IP) i encaminament de paquets.  |
| 2 | Enllaç de Dades (LLC)| Adreçament físic (MAC), trames, control d'accés al medi. |
| 1 | Física               | Transmissió de flux de bits bruts pel mitjà (senyals/Hz).|
+---+----------------------+----------------------------------------------------------+
```

> **Mnemotècnia habitual:** **A**-**P**-**S**-**T**-**X**-**E**-**F** (*«Aprendre Protocols Sense Treball Xoca En Físic»* o en anglès *«All People Seem To Need Data Processing»*).

---

## 3. El Model Pràctic TCP/IP (Model Internet)

Mentre la ISO debatia el model teòric OSI, el Departament de Defensa dels EUA (DARPA) i la comunitat universitària van desenvolupar l'arquitectura **TCP/IP** (Internet Protocol Suite), dissenyada per ser pràctica, robusta i orientada a la interconnectivitat entre xarxes heterogènies. 

El model TCP/IP original consta de **4 capes**, les quals agrupen les funcionalitats de les 7 capes d'OSI:

```
    MODEL OSI (7 capes)                         MODEL TCP/IP (4 capes)
+-------------------------+
|  7. Aplicació           |
+-------------------------+                  +-------------------------+
|  6. Presentació         |  ──────────────> |  4. Aplicació           |
+-------------------------+                  |  (HTTP, DNS, SSH, DHCP) |
|  5. Sessió              |                  +-------------------------+
+-------------------------+                  +-------------------------+
|  4. Transport           |  ──────────────> |  3. Transport           |
|                         |                  |  (TCP, UDP)             |
+-------------------------+                  +-------------------------+
|  3. Xarxa               |  ──────────────> |  2. Internet            |
|                         |                  |  (IP, ICMP, ARP)        |
+-------------------------+                  +-------------------------+
|  2. Enllaç de Dades     |                  +-------------------------+
+-------------------------+  ──────────────> |  1. Accés a la Xarxa    |
|  1. Física              |                  |  (Ethernet, Wi-Fi, MAC) |
+-------------------------+                  +-------------------------+
```

---

## 4. Comparativa Tècnica: OSI vs TCP/IP

| Característica | Model OSI (ISO) | Model TCP/IP (IETF) |
| :--- | :--- | :--- |
| **Origen** | Teòric, impulsat per comitès internacionals formalistes. | Pràctic, impulsat per implementacions reals de programari. |
| **Nombre de capes** | 7 capes clarament separades. | 4 capes (o 5 capes en models didàctics moderns). |
| **Capes superiors** | Distingeix estrictament Aplicació, Presentació i Sessió. | Agrupa totes les funcions d'usuari a la capa d'Aplicació. |
| **Capes inferiors** | Separa estrictament Física i Enllaç de dades. | Agrupa les dues capes a la capa d'Accés a la Xarxa. |
| **Estat actual** | S'utilitza com a model pedagògic i de diagnòstic de fallades. | És l'estàndard real i indiscutible sobre el qual opera Internet. |
