El sistema operatiu (SO) és el programa mestre que controla l'execució de totes les aplicacions i actua com a intermediari entre el maquinari físic de l'ordinador i els usuaris. Sense un sistema operatiu, cada programador hauria d'escriure codi específic per a cada xip de placa base, disc o targeta gràfica, la qual cosa faria inviable la informàtica moderna.

---

## 🎯 Les Tres Grans Funcions d'un Sistema Operatiu

Des del punt de vista de l'enginyeria de sistemes, el SO compleix tres funcions essencials:

```
                            FUNCIONS PRINCIPALS DEL SO
  ┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
  │  1. GESTOR DE RECURSOS   │    2. MÀQUINA VIRTUAL    │      3. PROTECCIÓ I      │
  │     (Arbitratge)         │       (Abstracció)       │        SEGURETAT         │
  ├──────────────────────────┼──────────────────────────┼──────────────────────────┤
  │ Reparteix la CPU, la     │ Ofereix una interfície   │ Aïlla els processos entre│
  │ RAM, l'emmagatzematge i  │ unificada (fitxers,      │ si perquè un error en una│
  │ la xarxa entre múltiples │ sòcols, finestres) que   │ aplicació no col·lapse   │
  │ aplicacions concurrents  │ amaga la complexitat     │ la resta del sistema ni  │
  │ de manera justa i òptima.│ electrònica dels xips.   │ comprometa les dades.    │
  └──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

1. **Gestor de recursos (Resource Manager):** Quan tenim desenes de processos actius (un navegador amb 15 pestanyes, un reproductor de música, un escàner d'antivirus i la descàrrega d'una ISO), el SO decideix quin procés té accés a la CPU en cada mil·lisegon, quanta memòria RAM se li assigna i quina amplada de banda de xarxa pot aprofitar.
2. **Màquina ampliada o màquina virtual (Extended Machine):** Transforma el maquinari brut i hostil (instruccions en codi màquina, senyals de rellotge, interrupcions per maquinari) en un entorn amigable compost per fitxers, carpetes, fils d'execució i protocols de xarxa.
3. **Mecanisme de seguretat i aïllament:** Aplica les polítiques d'autenticació, permisos d'arxius (POSIX en Linux, ACL en NTFS) i anells de protecció per impedir que usuaris no autoritzats o programari maliciós accedisquen a recursos protegits.

## 🏛️ L'Estructura Interna del Nucli (Kernel)

El **nucli** (*Kernel*) és la part central del sistema operatiu que es carrega en memòria RAM durant l'arrencada i s'executa contínuament en **Mode Privilegiat (Ring 0)**. El nucli conté cinc subsistemes bàsics interconnectats:

```
                          SUBSISTEMES INTERNS DEL NUCLI
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │                    INTERFÍCIE DE CRIDES AL SISTEMA (Syscalls)               │
  ├───────────────────┬───────────────────┬──────────────────┬──────────────────┤
  │   GESTOR DE       │   GESTOR DE       │   SISTEMA DE     │   SUBSISTEMA     │
  │   PROCESSOS       │   MEMÒRIA         │   FITXERS (VFS)  │   DE XARXA       │
  │ Planificació CPU, │ Memòria virtual,  │ Arbre directori, │ Piles TCP/IP,    │
  │ estats i fils     │ paginació, swap   │ inodes, MFT      │ sockets, routing │
  ├───────────────────┴───────────────────┴──────────────────┴──────────────────┤
  │                    CONTROLADORS DE DISPOSITIUS (Drivers)                    │
  │               Controlador NVMe, Targeta Gràfica, Xip de Xarxa Ethernet       │
  └─────────────────────────────────────────────────────────────────────────────┘
```

* **Gestor de processos:** Crea, suspèn, assigna prioritats i destrueix processos; s'encarrega del canvi de context ràpid entre ells.
* **Gestor de memòria:** Assigna blocs de memòria física (RAM) i memòria virtual a cada procés, vigilant que cap programa sobreescriga l'espai d'un altre.
* **Virtual File System (VFS):** Capa d'abstracció que permet al sistema operatiu tractar exactament igual un disc ext4, una unitat NTFS o una memòria USB FAT32 mitjançant ordres unificades com `open()`, `read()` o `write()`.
* **Subsistema de xarxa:** Implementa la pila de protocols TCP/IP, gestiona les targetes de xarxa físiques i virtuals i controla el trànsit de paquets.
* **Capa de controladors (Device Drivers):** El programari específic que parla l'idioma de cada controlador electrònic concret.

## ⚖️ Classificació dels Sistemes Operatius

Segons el seu comportament operatiu i les seues capacitats tècniques, els SO es classifiquen en:

| Criteri de Classificació | Categories | Descripció Tècnica | Exemples Reals |
| :--- | :--- | :--- | :--- |
| **Pel nombre d'usuaris** | **Monousuari**<br>**Multiusuari** | Només admet una sessió d'usuari concurrent.<br>Permet múltiples usuaris simultanis amb espais i permisos aïllats. | MS-DOS, Windows 95.<br>**Linux**, Windows Server, macOS. |
| **Pel nombre de tasques** | **Monotasca**<br>**Multitasca** | Només executa un programa cada vegada.<br>Executa desenes de processos concurrentment mitjançant temps compartit (*Time-Sharing*). | MS-DOS.<br>**Windows 11**, **Ubuntu 24.04**. |
| **Pel nombre de CPUs** | **Monoprocessador**<br>**Multiprocessador (SMP)** | Dissenyat per a un sol nucli de CPU.<br>Reparteix processos entre múltiples nuclis/CPUs físiques simètriques (*Symmetric Multiprocessing*). | Versions antigues de DOS/Windows.<br>Tots els sistemes moderns actuals. |
| **Pel temps de resposta** | **Temps real (RTOS)**<br>**Propòsit general** | Garanteix que una tasca crítica respon en un límit de temps rígid en microsegons.<br>Prioritza el rendiment mitjà i l'experiència interactiva de l'usuari. | QNX, FreeRTOS (automoció, robòtica).<br>**Windows**, **Linux**, Android. |
