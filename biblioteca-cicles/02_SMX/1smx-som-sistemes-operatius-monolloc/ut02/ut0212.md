# 2.12 Permisos i Atributs de Fitxers i Directoris

La seguretat d'un sistema operatiu multiusuari comença pel control d'accés als recursos emmagatzemats en disc. Tant Linux com Windows implementen models per restringir o permetre accions sobre fitxers i carpetes.

---

## 🐧 El Model de Permisos Estàndard POSIX (GNU/Linux)

En Linux, cada fitxer o directori té associat un **usuari propietari** (*User / Owner*) i un **grup propietari** (*Group*). A més, es defineix el comportament per a la resta d'usuaris del sistema (*Others*).

Quan executem `ls -l` a la consola, veiem una cadena de 10 caràcters com `-rwxr-xr--`:

```
 -   r w x   r - x   r - -
 |   |___|   |___|   |___|
 |     |       |       |
 |     |       |       +---> Altres usuaris (Others: r--) -> 4 + 0 + 0 = 4
 |     |       +-----------> Grup propietari (Group: r-x)  -> 4 + 0 + 1 = 5
 |     +-------------------> Usuari propietari (User: rwx) -> 4 + 2 + 1 = 7
 +-------------------------> Tipus: '-' fitxer regular, 'd' directori, 'l' enllaç
```

### 🔢 Valor Ponderat Octal dels Permisos

Cada permís bàsic té un pes numèric associat:
- **Lectura (`r` - Read):** $4$ ($2^2$)
- **Escriptura (`w` - Write):** $2$ ($2^1$)
- **Execució (`x` - eXecute):** $1$ ($2^0$)
- **Sense permís (`-`):** $0$

Per a calcular la màscara octal sumem els tres valors per a cada àmbit:
$$\text{Octal} = (\text{User}) \cdot 100_8 + (\text{Group}) \cdot 10_8 + (\text{Others})$$

Exemple:
- Propietari: Lectura, Escriptura i Execució $\rightarrow 4 + 2 + 1 = 7$
- Grup: Lectura i Execució $\rightarrow 4 + 0 + 1 = 5$
- Altres: Lectura $\rightarrow 4 + 0 + 0 = 4$
- **Resultat Octal:** `754`

---

## 🪟 Permisos ACL en Sistemes Windows NTFS

En Windows NTFS, els permisos no es limiten a tres tríades simples, sinó que es gestionen mitjançant **Llistes de Control d'Accés (ACL - Access Control Lists)**:
- Cada element té una DACL (*Discretionary Access Control List*) composta per múltiples ACEs (*Access Control Entries*).
- Permisos típics: **Lectura**, **Escriptura**, **Lectura i execució**, **Modificar** (permet esborrar fitxers) i **Control Total** (permet canviar permisos i prendre possessió).
- **Herència de permisos:** Per defecte, els fitxers i subcarpetes hereten automàticament els permisos assignats a la carpeta contenidora pare.

## 🛠️ Comandaments Pràctics d'Administració

### Canviar permisos en Linux (`chmod`):
```bash
# Notació numèrica octal (Permisos 755: rwxr-xr-x)
chmod 755 script.sh

# Notació simbòlica: afegir execució al propietari (u+x)
chmod u+x backup.sh

# Revocar escriptura a altres usuaris (o-w)
chmod o-w notes.txt

# Aplicar permisos recursivament a tota una carpeta
chmod -R 750 /var/www/privat/
```

### Canviar propietari i grup en Linux (`chown`):
```bash
# Canviar usuari propietari a 'alumne'
chown alumne informe.pdf

# Canviar simultàniament usuari i grup
chown alumne:professors informe.pdf

# Canvi recursiu en tot un directori
chown -R www-data:www-data /var/www/html/
```
