# 2.3 El Sistema Informàtic i les Funcions del Sistema Operatiu

Un **sistema informàtic** és el conjunt integrat de components físics (*hardware*), programari lògic (*software*) i recursos humans (*humanware*) destinats al processament automatitzat de dades.

---

## 🏗️ Estructura en Capes d'un Sistema Informàtic

Per a evitar que cada programa d'usuari haja de conèixer les peculiaritats electròniques de cada model de disc dur, impressora o targeta de xarxa, el sistema s'organitza en una jerarquia d'abstracció:

```
+-------------------------------------------------------+
|             USUARIS I APLICACIONS D'USUARI            |
|       (Navegador web, Ofimàtica, Reproductors)        |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|           INTERFÍCIE DE CRIDES AL SISTEMA             |
|              (System Calls: API POSIX / Win32)         |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|                   SISTEMA OPERATIU                    |
|  - Gestor de Processos       - Gestor de Memòria RAM  |
|  - Gestor d'Entrada/Eixida   - Sistema de Fitxers     |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|         CONTROLADORS DE DISPOSITIU (DRIVERS)          |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|                   MAQUINARI FÍSIC                     |
|           (CPU, RAM, Xipsets, Discos SSD/HDD)         |
+-------------------------------------------------------+
```

---

## ⚙️ Les Quatre Grans Funcions del Sistema Operatiu

1. **Gestió del Processador (CPU):**
   - Reparteix el temps de càlcul de la CPU entre múltiples tasques concurrents.
   - Aplica polítiques de planificació per a garantir equitat i temps de resposta immediat.
2. **Gestió de la Memòria Principal (RAM):**
   - Assigna blocs de memòria als processos quan s'inicien i els protegeix perquè un procés no puga llegir ni sobreescriure la memòria d'altres programes.
   - Implementa **memòria virtual** paginada quan la RAM física s'esgota.
3. **Gestió de l'Entrada/Eixida (E/S) i Dispositius:**
   - Proporciona una capa uniforme per a comunicar-se amb perifèrics a través de *buffers*, cues d'espera i interrupcions (*IRQ*).
4. **Gestió del Sistema de Fitxers i Seguretat:**
   - Organitza els bits de disc en estructures lògiques intel·ligibles (fitxers i directoris).
   - Controla qui pot llegir, escriure o executar cada recurs mitjançant permisos d'accés.

## 🛡️ Nivells de Protecció: Kernel Mode vs User Mode

Els microprocessadors moderns incorporen mecanismes de protecció basats en anells (*Protection Rings*):

| Característica | Mode Nucli (*Kernel Mode* / Ring 0) | Mode Usuari (*User Mode* / Ring 3) |
| :--- | :--- | :--- |
| **Nivell de Privilegi** | Màxim (0) | Mínim (3) |
| **Execució de codi** | Nucli del SO, controladors de maquinari crítics. | Aplicacions d'usuari (Word, Firefox, shell). |
| **Accés a la memòria** | Accés sense restriccions a tot l'espai físic. | Només al seu espai d'adreces virtual assignat. |
| **Instruccions privilegiades** | Sí (modificació de taules de pàgines, gestió d'interrupcions). | No (generen una excepció de violació d'accés). |
| **Conseqüència d'error** | *Kernel Panic* (Linux) o Pantalla Blava *BSOD* (Windows). | L'aplicació es tanca sense afectar el sistema. |
