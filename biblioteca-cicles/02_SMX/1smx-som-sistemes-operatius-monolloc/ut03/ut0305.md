Quan acabem d'instal·lar un sistema operatiu en una màquina virtual neta, l'experiència d'usuari sol ser frustrant: la resolució de pantalla està bloquejada en un xicotet requadre de 800 × 600 o 1024 × 768 píxels, el punter del ratolí queda atrapat dins de la finestra (cal prémer la tecla Host *Ctrl dret* per alliberar-lo), no podem copiar ni apegar text entre l'amfitrió i la VM, i no hi ha manera fàcil de transferir fitxers.

La solució professional definitiva és la instal·lació de les **VirtualBox Guest Additions** (*Complements del Convidat*).

---

## 🚀 Què són les Guest Additions i quins beneficis aporten?

Les Guest Additions són un conjunt de controladors de maquinari virtual i serveis de sistema que s'instal·len **DINS del sistema operatiu convidat**:

```
                       BENEFICIS DE LES GUEST ADDITIONS
  ┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
  │ 1. RESOLUCIÓ DINÀMICA    │ 2. PORTA-RETALLS I D&D   │ 3. CARPETES COMPARTIDES  │
  ├──────────────────────────┼──────────────────────────┼──────────────────────────┤
  │ En estirar la finestra o │ Permet copiar codi o     │ Accés directe des de la  │
  │ passar a pantalla        │ text a l'amfitrió i      │ VM a una carpeta del     │
  │ completa, la resolució   │ apegar-lo a la VM de     │ disc de l'host a màxima  │
  │ de la VM s'ajusta sola   │ manera bidireccional, o  │ velocitat, sense passar  │
  │ al vol sense deformar-se.│ arrossegar fitxers.      │ per xarxa ni servidors.  │
  └──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

Altres millores fonamentals inclouen la integració suau del punter del ratolí (sense captura), l'acceleració 3D per maquinari i la sincronització contínua del rellotge horari amb l'amfitrió.

---

## 🛠️ Instal·lació Pas a Pas en GNU/Linux (Ubuntu 24.04 LTS)

En sistemes Linux, les Guest Additions requereixen compilar mòduls del nucli específics per a la versió exacta del kernel actiu. El procediment professional per terminal és el següent:

### Pas 1: Instal·lar les eines de compilació i capçaleres del nucli
```bash
sudo apt update
sudo apt install -y build-essential dkms linux-headers-$(uname -r)
```

### Pas 2: Inserir i muntar la imatge de CD virtual
Al menú superior de la finestra de la VM, anem a:
**Dispositius -> Inserir imatge de CD de les Guest Additions...**

A la terminal de la VM:
```bash
sudo mount /dev/cdrom /media
cd /media
```

### Pas 3: Executar l'instal·lador oficial
```bash
sudo ./VBoxLinuxAdditions.run
```
L'assistent compilarà els controladors gràfics (`vboxvideo`) i de comunicació amb l'amfitrió (`vboxguest`).

### Pas 4: Reiniciar la màquina virtual
```bash
sudo reboot
```
En reiniciar, la finestra es podrà maximitzar a resolució completa nativa (1080p o superior) automàticament.

---

## 🪟 Instal·lació Pas a Pas en Microsoft Windows 11 / 10

1. Amb la màquina virtual engegada, fes clic al menú superior **Dispositius -> Inserir imatge de CD de les Guest Additions...**
2. Obre l'**Explorador de fitxers** de Windows dins de la VM i entra a la unitat de CD virtual (*VirtualBox Guest Additions*).
3. Fes clic amb el botó dret sobre l'arxiu **`VBoxWindowsAdditions.exe`** i selecciona **Executa com a Administrador**.
4. Completa l'assistent prement *Next* i acceptant la instal·lació dels controladors de dispositius d'Oracle.
5. Reinicia la màquina virtual quan l'instal·lador ho sol·licite.

## 📁 Configuració de Carpetes Compartides (Shared Folders)

Les carpetes compartides permeten intercanviar documents de treball entre l'ordinador amfitrió i la màquina virtual sense necessitat de configurar servidors Samba, ni pujar arxius al núvol, ni utilitzar memòries USB:

```
                            CARPETA COMPARTIDA AMB LA VM
     ORDINADOR AMFITRIÓ (HOST)                        MÀQUINA VIRTUAL (GUEST)
  ┌─────────────────────────────┐                  ┌─────────────────────────────┐
  │ Carpeta física al disc SSD: │                  │ Windows Guest:              │
  │ C:\TallerSMX                │ ───────────────► │ Unitat de xarxa Z:\         │
  │                             │   Controlador    ├─────────────────────────────┤
  │                             │   VBoxShared     │ Linux Guest:                │
  │                             │                  │ Muntada a /media/sf_Taller  │
  └─────────────────────────────┘                  └─────────────────────────────┘
```

### Passos de configuració a VirtualBox:
1. A la configuració de la VM, ves a **Carpetes compartides -> Afegeix carpeta compartida (+)**.
2. **Ruta de la carpeta:** Selecciona la carpeta de l'amfitrió (ex: `C:\TallerSMX`).
3. **Nom de la carpeta:** Posa un nom senzill (ex: `Taller`).
4. Marca les caselles:
   - **Automuntar:** Perquè es munte sola cada vegada que s'inicie la VM.
   - **Fer permanent:** Perquè no es perda en apagar la màquina.

### ⚠️ Resolució del problema de 'Permís denegat' en Linux:
En Ubuntu, la carpeta es munta automàticament a `/media/sf_Taller`. Si intentes entrar amb el teu usuari d'Ubuntu, el sistema donarà un error de **Permís denegat** (*Permission Denied*).

Això passa perquè la carpeta pertany exclusivament a l'administrador i al grup de seguretat **`vboxsf`**.

**Solució tècnica definitiva:**
Afegir el teu compte d'usuari al grup `vboxsf` mitjançant la comanda:
```bash
sudo usermod -aG vboxsf $USER
```
Després d'executar aquesta ordre, **cal tancar la sessió d'usuari i tornar a entrar** (o reiniciar) perquè Linux actualitze el testimoni de grups de l'usuari. Ara ja tindràs accés complet de lectura i escriptura a la carpeta compartida.
