Una de les capacitats més fascinants i útils de la virtualització per a un tècnic en Sistemes Microinformàtics i Xarxes és la creació de **commutadors i targetes de xarxa virtuals**. Sense necessitar cables de parell trenat RJ-45 físics ni switches de laboratori, podem interconnectar servidors, encaminadors i clients virtuals, simulant topologies de xarxa d'empreses senceres.

VirtualBox ofereix quatre grans maneres de connectar una targeta de xarxa virtual (*Network Adapter*). Saber triar el mode correcte per a cada pràctica és clau per garantir la connectivitat o l'aïllament del laboratori.

---

## 🗺️ Els Quatre Modes de Xarxa Principals

```
                         TOPOLOGIES DE XARXA A VIRTUALBOX
  ┌─────────────────────────────────┬─────────────────────────────────┐
  │ 1. NAT (Network Address Trans.) │ 2. ADAPTADOR PONT (Bridged)     │
  │ • VM rep IP privada (10.0.2.15) │ • VM s'enllaça a la targeta host│
  │ • Té accés a Internet           │ • Rep IP real del router físic  │
  │ • L'exterior NO pot veure la VM │ • Visibilitat total en la LAN   │
  ├─────────────────────────────────┼─────────────────────────────────┤
  │ 3. XARXA INTERNA (Internal)     │ 4. NOMÉS AMFITRIÓ (Host-Only)   │
  │ • Aïllament absolut (Air-gap)   │ • Xarxa privada Host <-> VMs    │
  │ • Comunicació només entre VMs   │ • Sense accés a Internet        │
  │ • Ni Internet ni Host tenen pas │ • Ideal per a laboratoris SSH   │
  └─────────────────────────────────┴─────────────────────────────────┘
```

---

### 1. Mode NAT (Network Address Translation - Per Defecte)
És la configuració que VirtualBox assigna automàticament en crear qualsevol màquina nova.

* **Com funciona:** VirtualBox crea un xicotet router i servidor DHCP virtual. La màquina virtual rep de manera immutable l'adreça IP `10.0.2.15` amb passarel·la `10.0.2.2`.
* **Connectivitat:**
  - La VM pot navegar per Internet, actualitzar paquets (`apt update`) i fer descàrregues utilitzant la connexió de l'amfitrió.
  - El sistema amfitrió i la resta d'ordinadors de la classe **no poden accedir a la VM**. La màquina està completament oculta darrere del NAT.
* **Reenviament de ports (Port Forwarding):** Si volem allotjar un servidor web Apache a la VM en el port 80 i veure'l des de l'amfitrió, podem crear una regla de reenviament:
  `Port Amfitrió: 8080 -> Port Convidat: 80`. Des de l'amfitrió obrirem `http://localhost:8080`.

---

### 2. Mode Adaptador Pont (Bridged Adapter)
En aquest mode, VirtualBox instal·la un controlador de filtre a la targeta de xarxa física de l'ordinador (Ethernet o Wi-Fi) per connectar virtualment la VM directament al cable de l'aula.

* **Com funciona:** La màquina virtual es converteix en un equip físic independent a tots els efectes. Sol·licita una adreça IP directament al router de l'institut (per exemple, `192.168.1.145`).
* **Connectivitat:**
  - Accés complet a Internet.
  - La VM pot comunicar-se directament amb altres companys de l'aula, amb impressores de xarxa i amb servidors físics.
  - L'amfitrió pot connectar-se per SSH o escriptori remot a la IP de la VM directament.
* **Atenció al taller:** Si l'aula té un límit d'adreces IP assignades per DHCP o filtratge per adreça MAC, les VMs en mode pont podrien no rebre IP.

---

### 3. Mode Xarxa Interna (Internal Network)
Crea una bombolla virtual absolutament aïllada del món exterior.

* **Com funciona:** Totes les màquines virtuals configurades en mode *Xarxa Interna* amb el mateix nom (per exemple, `lab_segur`) es connecten a un commutador virtual invisible.
* **Connectivitat:**
  - Les VMs es comuniquen entre si a màxima velocitat.
  - **Zero accés a Internet.**
  - **Zero accés des de l'equip amfitrió.**
* **Ús professional:** És el mode obligatori per provar virus, ransomwares, configurar servidors DHCP propis que podrien interferir amb la xarxa de l'institut o practicar exercicis d'encaminament entre xarxes.

---

### 4. Mode Adaptador Només Amfitrió (Host-Only Adapter)
Crea una xarxa privada que connecta de manera exclusiva l'ordinador amfitrió amb les màquines virtuals que s'hi allotgen.

* **Com funciona:** VirtualBox crea una targeta de xarxa virtual a l'amfitrió (*VirtualBox Host-Only Ethernet Adapter*) amb una subxarxa privada (com `192.168.56.1`). Les VMs reben IPs d'eixa mateixa xarxa (`192.168.56.101`).
* **Connectivitat:**
  - L'amfitrió pot accedir a qualsevol servei de la VM (web, base de dades, SSH).
  - Les VMs poden comunicar-se entre si i amb l'amfitrió.
  - **Cap trànsit pot eixir cap a Internet** ni entrar des de la xarxa física de l'institut.

---

## 📊 Matriu Comparativa de Visibilitat de Xarxa

| Mode de Xarxa | Accés de la VM a Internet | Comunicació entre VMs | Connexió de l'Amfitrió cap a la VM | Connexió des de la LAN Física cap a la VM |
| :--- | :---: | :---: | :---: | :---: |
| **NAT (Per defecte)** | **SÍ** | No (cada VM té el seu NAT) | Només amb Port Forwarding | No |
| **Adaptador Pont (Bridged)** | **SÍ** | **SÍ** | **SÍ** (directament per IP) | **SÍ** (com un PC més) |
| **Xarxa Interna (Internal)** | No | **SÍ** (mateix nom) | No | No |
| **Només Amfitrió (Host-Only)** | No | **SÍ** | **SÍ** (directament per IP) | No |
| **Xarxa NAT (NAT Network)** | **SÍ** | **SÍ** | Només amb Port Forwarding | No |
