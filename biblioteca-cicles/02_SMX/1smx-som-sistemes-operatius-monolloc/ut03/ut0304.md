# 3.4 Tipus d'Hipervisors i Màquines Virtuals

Els monitors de màquines virtuals (hipervisors) es classifiquen en dues grans categories segons la seua posició respecte al maquinari físic:

---

## 🏛️ Hipervisors Tipus 1 (Natius / Bare-Metal)

Un hipervisor **Tipus 1** s'instal·la directament sobre el metall buit (*bare-metal*) del servidor, actuant ell mateix com a micro-sistema operatiu altament especialitzat:

```
+-------------------------------------------------------+
|  VM 1 (Debian)   |   VM 2 (Windows)   |   VM 3 (Alpine)   |
+-------------------------------------------------------+
|             HIPERVISOR TIPUS 1 (BARE-METAL)           |
|        (Ex: VMware ESXi, Proxmox VE, Hyper-V)         |
+-------------------------------------------------------+
|                  MAQUINARI FÍSIC                      |
|            (Servidor rack, CPU Xeon/EPYC, RAM)        |
+-------------------------------------------------------+
```

### Característiques clau:
- **Rendiment màxim:** No hi ha un sistema operatiu intermedi que consumisca recursos innecessaris.
- **Seguretat i estabilitat:** Com que té un codi molt compacte, la superfície d'atac és extremadament reduïda.
- **Gestió remota:** Generalment no tenen interfície gràfica d'escriptori pròpia; s'administren via navegador web o consola remota SSH.

---

## 💻 Hipervisors Tipus 2 (Allotjats / Hosted)

Un hipervisor **Tipus 2** és un programa d'aplicació que s'executa damunt d'un sistema operatiu amfitrió preexistent:

```
+-------------------------------------------------------+
|  VM 1 (Ubuntu)   |   VM 2 (Win 11)   |   VM 3 (Kali)  |
+-------------------------------------------------------+
|          HIPERVISOR TIPUS 2 (ALLOTJAT / HOSTED)       |
|      (Ex: Oracle VirtualBox, VMware Workstation)      |
+-------------------------------------------------------+
|            SISTEMA OPERATIU AMFITRIÓ (HOST)           |
|                (Ex: Windows 11 o Ubuntu 24.04)        |
+-------------------------------------------------------+
|                  MAQUINARI FÍSIC                      |
|                  (PC de sobretaula o portàtil)        |
+-------------------------------------------------------+
```

### Característiques clau:
- **Facilitat d'instal·lació:** S'instal·la amb un simple assistent (`.exe` o `.deb`) en el teu ordinador personal habitual.
- **Gran flexibilitat:** Permet compatibilitat immediata amb tots els perifèrics ja reconeguts pel sistema operatiu amfitrió (ratolins, Wi-Fi, càmeres web, Bluetooth).
- **Sobrecàrrega (*Overhead*):** El sistema operatiu amfitrió consumeix part de la RAM i de la CPU per al seu propi funcionament.

---

## 📊 Taula Comparativa: Tipus 1 vs Tipus 2

| Paràmetre | Hipervisors Tipus 1 (Bare-Metal) | Hipervisors Tipus 2 (Hosted) |
| :--- | :--- | :--- |
| **Instal·lació** | Directa sobre disc dur verge. | Dins d'un SO amfitrió com una app. |
| **Rendiment** | Pràcticament idèntic al maquinari real ($\approx 98\%$). | Menor, pèrdua per coordinació amb el Host ($\approx 85-92\%$). |
| **Consum de Recursos Base** | Molt baix (alguns centenars de MiB de RAM). | Elevat (el Host consumeix de 2 a 4 GiB de RAM). |
| **Ús Principal** | Producció, CPDs, Cloud Computing empresarial. | Aprenentatge, desenvolupament, proves de laboratori. |
| **Exemples Representatius** | Proxmox VE, VMware ESXi, Hyper-V Server. | Oracle VirtualBox, VMware Workstation Pro. |
