# 3.14 Pràctica 6: Instal·lació de Guest Additions

Les **Guest Additions** (Complements del convidat) són un paquet de controladors de dispositiu i aplicacions de sistema dissenyats específicament per a optimitzar la integració entre el sistema operatiu amfitrió (*Host*) i la màquina virtual convidada (*Guest*).

---

## 🌟 Avantatges que aporten les Guest Additions

Sense les Guest Additions, la màquina virtual funciona en un mode bàsic molt limitat:
1. **Resolució de pantalla dinàmica:** Permet redimensionar la finestra de la VM o posar-la a pantalla completa (F11 / Host+F) adaptant automàticament la resolució de vídeo nativa del monitor del PC físic.
2. **Acceleració gràfica 3D per maquinari:** El sistema convidat aprofita directament la targeta gràfica de l'amfitrió.
3. **Integració del punter del ratolí:** El ratolí es mou fluidament entre l'escriptori de l'amfitrió i el de la màquina virtual sense haver de prémer la tecla amfitrió (Ctrl dret).
4. **Portapapers compartit i Arrossegar i Deixar anar (*Drag and Drop*):** Permet copiar text o arrossegar fitxers de forma bidireccional entre tots dos sistemes.
5. **Carpetes compartides (*Shared Folders*):** Permet a la màquina virtual accedir de forma transparent a una carpeta del disc dur de l'amfitrió.
6. **Sincronització horària:** Manté el rellotge de la màquina virtual permanentment sincronitzat amb el de l'amfitrió fins i tot després de restaurar un *snapshot*.

---

## 🐧 Procediment d'Instal·lació en Ubuntu Desktop

### Pas 1: Preparar les eines de compilació del nucli
A la màquina virtual Ubuntu, obri un terminal (Ctrl+Alt+T) i instal·la els paquets necessaris per compilar mòduls del nucli:

```bash
sudo apt update
sudo apt install -y build-essential dkms linux-headers-$(uname -r)
```

### Pas 2: Inserir la imatge de Guest Additions
1. Al menú superior de la finestra de VirtualBox de la VM, ves a:
   **Dispositius** $\rightarrow$ **Insereix la imatge de CD de les Guest Additions...**
2. Si apareix un diàleg automàtic d'execució, accepta o bé obri el terminal i executa:

```bash
# Navegar al punt de muntatge del CD
cd /media/$USER/VBox_GAs_*

# Executar l'script d'instal·lació amb privilegis d'administrador
sudo ./VBoxLinuxAdditions.run
```

3. Espera que finalitze la compilació dels mòduls `vboxguest`, `vboxsf` i `vboxvideo`.
4. Reinicia la màquina virtual:
```bash
sudo reboot
```

---

## 📂 Configuració de Carpetes Compartides

1. A la finestra de VirtualBox de la màquina virtual, ves a **Dispositius** $\rightarrow$ **Carpetes compartides** $\rightarrow$ **Paràmetres de carpetes compartides...**
2. Fes clic a la icona d'afegir carpeta:
   - **Ruta de la carpeta:** Tria una carpeta del teu PC amfitrió (ex: `C:\Users\alumne\CompartidaVirtualBox`).
   - **Nom de la carpeta:** `CompartidaVirtualBox`.
   - Marca: **Muntatge automàtic** (*Auto-mount*) i **Fer permanent**.
3. **Important per a Linux:** Per a tindre permís d'accés a la carpeta muntada a `/media/sf_CompartidaVirtualBox`, l'usuari local ha de pertànyer al grup del sistema `vboxsf`:

```bash
# Afegir l'usuari alumne al grup vboxsf
sudo usermod -aG vboxsf $USER

# Tancar sessió i tornar a entrar perquè s'aplique el canvi de grup
```
