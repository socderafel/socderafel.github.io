# 3.7 Oracle VM VirtualBox en Detall

**Oracle VM VirtualBox** és un hipervisor Tipus 2 lliure i de codi obert (sota llicència GPLv2) mantingut per Oracle Corporation. És l'eina de referència per als cicles formatius d'informàtica a tot el món.

---

## ⚙️ Components d'Instal·lació de VirtualBox

1. **VirtualBox Base Package:** El nucli de l'aplicació que inclou el motor de virtualització i la interfície gràfica d'administració (GUI escrita en Qt).
2. **Oracle VM VirtualBox Extension Pack:** Paquet de complements privatiu (gratuït per a ús educatiu i personal) que afig:
   - Suport per a controladors **USB 2.0 i USB 3.0 (xHCI)**.
   - Encriptació de discs virtuals amb algorisme AES de 128 o 256 bits.
   - Arrencada per xarxa mitjançant **PXE Boot** per a targetes Intel.
   - Servidor d'escriptori remot **VRDP** (*VirtualBox Remote Desktop Protocol*).

---

## 🎛️ Paràmetres Crítics de Configuració d'una Màquina Virtual

Quan creem una nova VM a VirtualBox, hem d'ajustar amb precisió els següents apartats de la finestra de **Configuració**:

### 1. Sistema
- **Placa Base / Memòria Base:** No assignar mai més del 50-60% de la memòria RAM física total de l'amfitrió. Si l'amfitrió té 16 GB, assignar com a màxim 8 GB a la VM (recomanat 4 GB per a Ubuntu o Windows 11).
- **Processador:** Assignar entre 2 i 4 nuclis de CPU virtuals (vCPUs), mantenint-se sempre dins de la **zona verda** del selector per no ofegar el sistema amfitrió.
- **Ordre d'arrencada:** Disc òptic (ISO) primer, seguit de Disc dur.
- **Taula de xipsets:** Seleccionar `PIIX3` per a sistemes clàssics o `ICH9` per a sistemes moderns amb PCIe.
- **Habilitar EFI:** Imprescindible per a instal·lacions modernes de Windows 11 o particions GPT.

### 2. Pantalla
- **Memòria de vídeo:** Assignar el màxim permès ($128 \text{ MB}$, o $256 \text{ MB}$ amb acceleració 3D).
- **Controlador gràfic:**
  - `VMSVGA`: Recomanat per a màquines Linux modernes.
  - `VBoxSVGA`: Recomanat per a màquines Windows 10/11.

### 3. Emmagatzematge
- **Controlador SATA (AHCI):** Per a discs durs virtuals estàndard.
- **Controlador NVMe:** Simula una unitat SSD PCIe ultra-ràpida, ideal per a Windows 11.
- **Unitat òptica virtual:** On es munta el fitxer d'imatge `.ISO` descarregat.

### 4. Xarxa
Com hem estudiat a la infografia, cal triar entre **NAT** (per defecte per tindre Internet immediat), **Adaptador Pont** (per interactuar amb la LAN del centre), o **Xarxa Interna** (per a pràctiques aïllades).
