En el camp del manteniment microinformàtic i l'administració de sistemes, provar configuracions, sistemes operatius nous o programari dubtós directament sobre l'ordinador físic de producció és una pràctica temerària que pot ocasionar pèrdua irreversible de dades o deixar l'equip inoperatiu.

La **virtualització** és la tecnologia que permet crear representacions lògiques basades en programari de recursos físics reals (CPU, memòria RAM, discs d'emmagatzematge, controladors de xarxa i targetes gràfiques). D'aquesta manera, un sol ordinador físic pot executar diversos sistemes operatius completament aïllats en paral·lel.

---

## 🏛️ Terminologia Clau: Amfitrió vs Convidat

En qualsevol escenari de virtualització intervenen tres elements fonamentals:

```
                          ARQUITECTURA DE VIRTUALITZACIÓ
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ SISTEMA OPERATIU CONVIDAT (Guest OS):                                       │
  │ El sistema operatiu que s'executa DINS de la màquina virtual (ex: Ubuntu).  │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ HIPERVISOR O MONITOR DE MÀQUINA VIRTUAL (VMM):                             │
  │ La capa de programari que intercepta instruccions i gestiona els recursos.  │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ SISTEMA OPERATIU AMFITRIÓ (Host OS):                                       │
  │ El sistema operatiu instal·lat directament al maquinari físic (ex: Win 11).│
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ MAQUINARI FÍSIC: CPU amb Intel VT-x/AMD-V, RAM DDR4/DDR5, SSD NVMe         │
  └─────────────────────────────────────────────────────────────────────────────┘
```

* **Amfitrió (Host):** L'ordinador físic i el sistema operatiu base que proveeix la potència de càlcul, la memòria i l'electricitat.
* **Convidat (Guest):** El sistema operatiu que viu engabiat dins de la màquina virtual. Creu que té una placa base i un disc dur reals per a ell sol, però en realitat és només un procés controlat per l'hipervisor.
* **Màquina Virtual (VM):** Contenidor lògic aïllat format per fitxers de configuració (`.vbox`) i fitxers de disc virtual (`.vdi`, `.vmdk`).

---

## ⚖️ Els Dos Grans Tipus d'Hipervisors: Tipus 1 vs Tipus 2

El component central que fa possible la màgia de la virtualització és l'**hipervisor** (*Hypervisor* o *Virtual Machine Monitor* - **VMM**). Segons on s'ubique dins de la pila de programari, es classifiquen en:

```
    HIPERVISOR TIPUS 1 (Bare-Metal)               HIPERVISOR TIPUS 2 (Hosted)
  ┌──────────────────────────────────┐        ┌──────────────────────────────────┐
  │ Màquina Virtual  Màquina Virtual │        │ Màquina Virtual  Màquina Virtual │
  │   (Windows 11)     (Debian 12)   │        │   (Windows 11)     (Ubuntu 24.04)│
  ├──────────────────────────────────┤        ├──────────────────────────────────┤
  │       HIPERVISOR TIPUS 1         │        │       HIPERVISOR TIPUS 2         │
  │  (Instal·lat sobre el silici)    │        │      (Oracle VirtualBox 7)       │
  ├──────────────────────────────────┤        ├──────────────────────────────────┤
  │                                  │        │    SISTEMA AMFITRIÓ (Host OS)    │
  │                                  │        │     (Windows 11 / Ubuntu Desktop)│
  ├──────────────────────────────────┤        ├──────────────────────────────────┤
  │        MAQUINARI FÍSIC           │        │        MAQUINARI FÍSIC           │
  │      (Servidor de Datacenter)    │        │      (Ordinador de Taller SMX)   │
  └──────────────────────────────────┘        └──────────────────────────────────┘
```

### 1. Hipervisors de Tipus 1 (Nadius o Bare-Metal)
S'instal·len **directament sobre el maquinari buit de la màquina**, sense necessitat de cap sistema operatiu amfitrió previ. L'hipervisor mateix actua com un micro-nucli ultra-lleuger especialitzat exclusivament en repartir recursos a les VMs:
* **Exemples reals de la indústria:**
  - **VMware ESXi** (líder en centres de dades empresarials).
  - **Proxmox VE** (entorn lliure basat en Debian i KVM molt utilitzat en instituts i empreses).
  - **Microsoft Hyper-V Server** (natiu en Windows Server).
  - **KVM (Kernel-based Virtual Machine)** en servidors Linux.
* **Avantatges:** Rendiment màxim proper al 98-99% del maquinari natiu, mínima latència i màxima estabilitat.
* **Inconvenients:** Requereix maquinari homologat per a servidors i un altre equip separat per a la seua gestió remota web.

### 2. Hipervisors de Tipus 2 (Allotjats o Hosted)
S'instal·len com una **aplicació més** sobre un sistema operatiu amfitrió convencional que ja està funcionant (com Windows 11 o Ubuntu Desktop):
* **Exemples reals:**
  - **Oracle VM VirtualBox** (eina lliure de referència per a educació i tallers SMX).
  - **VMware Workstation Pro / Player**.
  - **Parallels Desktop** (en entorns macOS).
* **Avantatges:** Màxima facilitat d'ús, permet a l'estudiant tindre oberts apunts, el navegador i la VM en finestres paral·leles.
* **Inconvenients:** Sobrecàrrega (*overhead*) superior, ja que cada instrucció ha de passar per l'hipervisor i després pel sistema operatiu amfitrió abans d'arribar als circuits de la CPU.

---

## 🎯 Avantatges de la Virtualització per al Tècnic SMX

1. **Aïllament i seguretat absoluta (Sandbox):** Si una màquina virtual s'infecta amb un ransomware o pateix una fallada crítica de particions, el sistema amfitrió i els discs físics de l'aula queden completament immunes.
2. **Estalvi de costos de maquinari:** Un sol equip amb 16 o 32 GB de RAM permet simular una xarxa corporativa amb dos servidors i tres clients sense necessitar 5 torres físiques connectades.
3. **Immediatesa mitjançant Instantànies (Snapshots):** Abans de fer un canvi arriscat (modificar el registre de Windows o actualitzar el nucli), es fa una "foto" de la VM en 2 segons; si alguna cosa ix malament, es reverteix a l'estat anterior amb un sol clic.
4. **Portabilitat:** Una màquina virtual sencera és només una carpeta amb un parell de fitxers. Es pot copiar a un disc SSD extern i executar-se exactament igual a qualsevol altre ordinador.
