# 3.3 Fonaments de la Virtualització

La **virtualització** és la creació mitjançant programari d'una versió virtual (no física) d'un recurs tecnològic, com ara una plataforma de maquinari, un sistema operatiu, un dispositiu d'emmagatzematge o recursos de xarxa.

---

## 🖥️ Terminologia Clau

- **Màquina Amfitrió (*Host*):** L'ordinador físic real sobre el qual s'executa el programari de virtualització. Proporciona la CPU real, els mòduls de memòria RAM física, els discs SSD i les targetes de xarxa.
- **Màquina Convidada (*Guest* o Màquina Virtual - VM):** L'entorn virtual aïllat que s'executa damunt de l'amfitrió. Té la il·lusió de disposar de la seua pròpia placa base, BIOS/UEFI, CPU, RAM i targeta de so/vídeo virtualitzades.
- **Hipervisor o VMM (*Virtual Machine Monitor*):** La capa de programari encarregada de gestionar els recursos físics i arbitrar el seu ús entre les diferents màquines convidades.

---

## ⚡ Emulació vs Virtualització Nativa

És crucial no confondre aquests dos conceptes:
1. **Emulació (com DOSBox o QEMU en mode TCG):**
   - El programari simula per complet el funcionament d'una CPU diferent instrucció per instrucció (per exemple, executar instruccions ARM64 sobre un processador x86-64).
   - **Rendiment molt lent:** Pot ser entre 10 i 100 vegades més lent que el maquinari real.
2. **Virtualització Assistida per Maquinari (Intel VT-x / AMD-V):**
   - Les instruccions del sistema convidat s'executen directament a la CPU real de l'amfitrió sense traducció de codi, gràcies a noves instruccions del processador (`VMX root / non-root operation`).
   - **Rendiment excel·lent:** Les pèrdues de velocitat són mínimes (inferiors al 2-5%).

---

## 🔍 Comprovació del Suport de Virtualització a la CPU

Per a poder executar màquines virtuals de 64 bits a l'aula, la virtualització per maquinari ha d'estar activada a la BIOS/UEFI del PC:

### En GNU/Linux (Bash):
```bash
# Comprovar si la CPU suporta Intel VT-x ('vmx') o AMD-V ('svm')
egrep -c '(vmx|svm)' /proc/cpuinfo
# Si el resultat és major que 0, la virtualització està suportada!

# Comprovar amb l'eina lscpu
lscpu | grep Virtualization
```

### En Microsoft Windows (PowerShell):
```powershell
# Comprovar l'estat del processador
Get-ComputerInfo | Select-Object HyperVisorPresent, CsProcessors
# O bé obrint l'Administrador de Tasques -> Pestanya 'Rendiment' -> 'CPU' -> 'Virtualització: Habilitada'
```
