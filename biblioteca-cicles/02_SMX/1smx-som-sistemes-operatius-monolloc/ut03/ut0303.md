El disc dur d'una màquina virtual no és un dispositiu físic connectat per un cable SATA o PCIe, sinó un simple fitxer especial emmagatzemat al disc de l'equip amfitrió. Aquest fitxer conté la geometria completa de cilindres, capçals, taula de particions (MBR/GPT) i sistemes de fitxers (NTFS, ext4), enganyant completament el sistema convidat.

Dominar els diferents formats d'imatge, l'assignació dinàmica d'espai i la gestió d'instantànies (*Snapshots*) és indispensable per gestionar laboratoris àgils i estalviar espai a les unitats SSD del centre.

---

## 🗂️ Formats d'Imatge de Disc Suportats

VirtualBox ofereix compatibilitat amb els principals estàndards de la indústria de la virtualització:

```
                            FORMATS D'IMATGE DE DISC VIRTUAL
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ 1. VDI (VirtualBox Disk Image):                                             │
  │    Format natiu i exclusiu d'Oracle VirtualBox. Màxim rendiment i suport    │
  │    complet de totes les funcionalitats de la plataforma.                    │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ 2. VMDK (Virtual Machine Disk):                                             │
  │    Desenvolupat originalment per VMware. Ideal per exportar o migrar màqui- │

  ├─────────────────────────────────────────────────────────────────────────────┤
  │ 3. VHD / VHDX (Virtual Hard Disk):                                          │
  │    Format natiu de Microsoft. Permet muntar el disc directament com una uni-│

  └─────────────────────────────────────────────────────────────────────────────┘
```

## ⚖️ Mida Dinàmica vs Mida Fixa (Pre-allocated)

En crear un disc virtual nou (per exemple, de 50 GB), podem triar entre dos mètodes d'assignació d'emmagatzematge:

```
    ASSIGNACIÓ DINÀMICA (Creixement al vol)           MIDA FIXA (Reserva Total)
  ┌─────────────────────────────────────────┐     ┌─────────────────────────────────────────┐
  │ Límit configurat: 50 GB                 │     │ Límit configurat: 50 GB                 │
  │                                         │     │                                         │
  │ [ Dades: 8 GB ]                         │     │ [ Dades Reals: 8 GB ]                   │
  │ [ Espai no utilitzat: 42 GB (Lliure) ]  │     │ [ Espai Buit Reservat a Disc: 42 GB ]   │
  │                                         │     │                                         │
  │ Fitxer .VDI a l'host ocupa: 8 GB reals  │     │ Fitxer .VDI a l'host ocupa: 50 GB reals │
  └─────────────────────────────────────────┘     └─────────────────────────────────────────┘
```

| Criteri | Assignació Dinàmica (*Dynamically Allocated*) | Mida Fixa (*Fixed Size*) |
| :--- | :--- | :--- |
| **Temps de creació** | **Instantani** (menys d'1 segon). | Lent (ha d'escriure 50 GB de zeros al disc). |
| **Ocupació a l'amfitrió** | Ocupa només el que ocupa el sistema operatiu realment (ex: 8-12 GB). | Ocupa els 50 GB complets des del primer minut. |
| **Velocitat d'E/S (Disc)** | Lleugera sobrecàrrega quan el fitxer s'expandeix per afegir blocs nous. | **Màxima velocitat**, ja que els sectors són contigus a l'amfitrió. |
| **Risc d'espai** | Si tenim moltes VMs dinàmiques i creixen a la vegada, poden omplir el disc físic de l'amfitrió (*Disk Full*). | Cap risc de desbordament sobtat. |
| **Ús a taller SMX** | **Molt recomanat** per a laboratoris amb SSDs de 120-250 GB. | Recomanat per a servidors de bases de dades en producció. |

## 📸 Instantànies (Snapshots): La Màquina del Temps

Una **instantània** (*Snapshot*) desa l'estat complet del disc virtual (i opcionalment de la memòria RAM) en un instant precís. Permet al tècnic experimentar sense cap por:

```
                            ARBRE D'INSTANTÀNIES DE LA VM
                                ┌──────────────────────┐
                                │       ESTAT 0        │
                                │   (SO Netejat)       │
                                └──────────┬───────────┘
                                           │
                                ┌──────────▼───────────┐
                                │     INSTANTÀNIA 1    │
                                │  (Drivers instal·lats│
                                └──────────┬───────────┘
                                           │
                         ┌─────────────────┴─────────────────┐
                         │                                   │
              ┌──────────▼───────────┐            ┌──────────▼───────────┐
              │    RAMA A (Proves)   │            │    RAMA B (Ofimàtica)│
              │  Instal·lar malware  │            │  LibreOffice + GIMP  │
              └──────────────────────┘            └──────────────────────┘
```

### Com funciona internament una Instantània?
1. En fer clic a *Prendre Instantània*, el fitxer de disc base (per exemple, `ubuntu.vdi`) **es bloqueja en mode de només lectura**.
2. VirtualBox crea automàticament un nou fitxer de disc **diferencial** associat (anomenat `{uuid}.vdi` a la carpeta `Snapshots`).
3. Totes les noves escriptures, fitxers descarregats o aplicacions s'escriuen exclusivament al fitxer diferencial.
4. Si volem tornar enrere (*Restaurar Instantània*), VirtualBox simplement descarta el fitxer diferencial i torna a apuntar a la imatge base intacta en menys de 2 segons.
5. Si volem consolidar els canvis (*Eliminar Instantània*), el contingut del diferencial es fon (*merge*) cap a la imatge pare de forma transparent.

---

## 👥 Tipus de Clonació de Màquines Virtuals

Quan volem duplicar una màquina virtual existent per no haver de reinstal·lar el sistema de zero:

* **Clonació Completa (Full Clone):** Copia tots els fitxers de disc i configuració creant una màquina completament independent. Modificar una VM no afecta l'altra, però consumeix el doble d'espai de disc.
* **Clonació Enllaçada (Linked Clone):** Es basa en una instantània de la màquina original. La nova màquina només emmagatzema les diferències respecte a la base. Estalvia molt d'espai, però **depèn de la màquina original**; si s'esborra la màquina pare, el clon queda completament inutilitzable.
