**Oracle VM VirtualBox** és l'eina estàndard de referència mundial en la formació professional de la família d'Informàtica. És un programari de codi obert (llicència GPL v3) potent, multiplataforma (funciona en Windows, GNU/Linux i macOS) i amb un conjunt d'eines que permeten simular amb exactitud qualsevol entorn de producció.

En aquest apartat aprendràs el procés tècnic professional d'instal·lació, configuració de paràmetres globals i creació optimitzada de màquines virtuals.

---

## 📦 Components del Kit VirtualBox

Per disposar de totes les funcionalitats operatives de taller cal instal·lar dos paquets complementaris:

```
                         PAQUETS ESSENCIALS DE VIRTUALBOX
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ 1. PAQUET BASE DE VIRTUALBOX (GPL v3):                                      │
  │    L'hipervisor central, la interfície gràfica de gestió i les eines CLI     │
  │    (VBoxManage).                                                            │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ 2. VIRTUALBOX EXTENSION PACK (Llicència PUEL per a ús educatiu):            │
  │    • Suport complet per a controladors USB 2.0 (EHCI) i USB 3.0 (xHCI).     │
  │    • Controladors NVMe virtuals d'alta velocitat.                           │
  │    • Xifratge AES de discs virtuals amb contrasenya.                        │
  │    • Servidor RDP integrat (VirtualBox Remote Desktop Protocol).            │
  └─────────────────────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> L'**Extension Pack** s'instal·la una sola vegada a l'ordinador amfitrió (anant a *Fitxer -> Eines -> Gestor de Paquets d'Extensió* a la finestra principal de VirtualBox). La seua versió ha de coincidir exactament amb la versió del paquet base (per exemple, 7.0.20 per a la base 7.0.20).

## ⚙️ Creació Pas a Pas d'una Màquina Virtual Òptima

Quan premem el botó **Nova** a la barra d'eines, l'assistent ens guia per una sèrie de decisions crítiques de dimensionament:

```
                            FLUX DE CREACIÓ D'UNA VM
  Nom i Tipus SO ──► Memòria RAM i vCPUs ──► Disc Virtual (VDI) ──► Ajustos Avançats
  (ex: Ubuntu)        (Zona verda segura)     (Assignació Dinàmica)   (UEFI / TPM / VRAM)
```

### 1. Nom, Carpeta i Imatge ISO
* **Nom:** Triar un nom descriptiu i normalitzat (ex: `SMX1-Ubuntu24-GomezM` o `SMX1-Win11-Laboratori`).
* **Carpeta de la màquina:** Assegurar-se que apunta a una unitat SSD ràpida amb espai suficient (mínim 40-50 GB lliures per VM).
* **Imatge ISO:** Si se selecciona la ISO descarregada, VirtualBox 7 detecta automàticament el sistema operatiu i ofereix la instal·lació desatesa (*Unattended Installation*).

### 2. Dimensionament de Memòria RAM i Processadors Virtuals (vCPUs)
VirtualBox mostra una barra de colors verd, taronja i roig:
* **Zona Verda (Segura):** Representa la memòria que podem cedir a la VM sense posar en perill el sistema amfitrió.
* **Criteri de càlcul professional:**
  - **Amfitrió amb 16 GB de RAM:** Assignar 4 GB (4.096 MB) o 6 GB a la VM; l'amfitrió mantindrà 10-12 GB lliures.
  - **CPU de 8 nuclis:** Assignar **2 o 4 vCPUs** a la VM. Mai assignar el 100% dels nuclis físics a la VM, ja que el sistema amfitrió es congelaria.

### 3. Configuració del Firmware: BIOS vs EFI i TPM 2.0
A l'apartat **Sistema -> Placa base**:
* **Habilitar EFI (especial per a sistemes operatius moderns):** Indispensable per simular arrancades UEFI modernes, particions GPT i gestió de claus Secure Boot.
* **TPM 2.0 Virtual:** Per a instal·lar **Windows 11**, cal seleccionar `TPM v2.0` al desplegable. Així Windows 11 reconeix el requisit de seguretat sense necessitat de pedaços al registre.

### 4. Configuració de Pantalla i Memòria de Vídeo (VRAM)
A l'apartat **Pantalla -> Pantalla**:
* **Memòria de vídeo:** Apujar el lliscador al màxim permès (**128 MB**).
* **Controlador gràfic:**
  - Per a **GNU/Linux:** Seleccionar `VMSVGA`.
  - Per a **Microsoft Windows:** Seleccionar `VBoxSVGA`.
* **Habilitar acceleració 3D:** Marcant aquesta casella, l'escriptori gràfic de la VM aprofita la GPU física de l'equip amfitrió per dibuixar finestres i animacions amb gran fluïdesa.

## 🛠️ Resolució de Problemes Freqüents a Taller

| Error Visualitzat | Causa Tècnica | Solució Professional |
| :--- | :--- | :--- |
| `VERR_VMX_NO_VMX` o només deixa crear VMs de 32 bits | La virtualització per maquinari està desactivada al firmware de la placa base física. | Reiniciar l'equip físic, entrar a la BIOS/UEFI i activar **Intel VT-x** o **AMD SVM Support**. |
| Rendiment extremadament lent de la VM en Windows 11 host (icona de tortuga verda) | El subsistema Hyper-V / WSL2 de Windows està monopolitzant les extensions de virtualització en exclusiva. | Executar en PowerShell com admin:<br>`bcdedit /set hypervisorlaunchtype off`<br>i reiniciar l'equip físic. |
| La pantalla de la VM queda en negre amb cursor parpellejant | L'ordre d'arrancada (*Boot Order*) no té la unitat òptica amb la ISO o la imatge ISO està corrompuda. | Comprovar que la unitat de CD virtual té la ISO muntada i verificar el seu hash SHA-256. |
