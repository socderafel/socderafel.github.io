# 4.10 Mètodes d'Instal·lació i Particionament de Disc

El desplegament d'un sistema operatiu pot realitzar-se mitjançant diversos canals segons l'escala del parc informàtic: des d'un únic equip domèstic fins a aules corporatives amb centenars d'ordinadors.

---

## 🚀 Mètodes de Desplegament de Sistemes

1. **Instal·lació Local per Mitjà Físic (USB Flash Drive):**
   - El mètode clàssic per excel·lència. Es grava la imatge ISO en un llapis USB utilitzant eines especialitzades:
     - **Rufus:** Permet triar explícitament l'esquema de partició de destinació (`GPT per a UEFI` o `MBR per a BIOS`).
     - **Ventoy:** Solució moderna que converteix el pendrive en multibootejable; només cal copiar múltiples fitxers `.iso` a la partició de dades per arrencar qualsevol d'ells directament des d'un menú.
2. **Instal·lació per Xarxa PXE (*Preboot eXecution Environment*):**
   - L'equip arrenca sense cap disc local ni USB connectat. La targeta de xarxa sol·licita configuració IP via DHCP, obté la ruta d'un servidor TFTP/HTTP i descarrega la imatge del nucli per arrencar l'instal·lador.
   - Ús professional: Desplegament massiu en aules o empreses amb servidors com WDS (*Windows Deployment Services*) o FOG Project.
3. **Instal·lació Desatesa (*Unattended Installation*):**
   - Automatització total de les respostes de l'assistent mitjançant fitxers de configuració:
     - Fitxer `autounattend.xml` per a instal·lacions de Windows.
     - Fitxer `user-data` (Subiquity / Cloud-init) per a Ubuntu Server/Desktop.

---

## 🪓 Eines de Particionament Pràctic

Abans d'instal·lar el sistema cal establir les particions de disc. Es poden utilitzar utilitats interactives o de línia d'ordres:

### En entorns Windows (`diskpart`):
```cmd
REM Obrir la consola de gestió de disc amb permisos d'administrador
diskpart

REM Llistar els discs físics detectats
list disk

REM Seleccionar el disc de destinació (ex: disc 0)
select disk 0

REM Netejar completament el disc (esborra totes les taules i particions)
clean

REM Convertir el disc a taula de particions GPT
convert gpt

REM Crear la partició de sistema EFI (FAT32) de 260 MB
create partition efi size=260
format quick fs=fat32 label="System"

REM Crear la partició MSR reservada per Microsoft de 16 MB
create partition msr size=16

REM Crear la partició primària principal per a Windows (resta de disc)
create partition primary
format quick fs=ntfs label="Windows11" assign letter=C

exit
```

### En entorns GNU/Linux (`fdisk` / `gdisk` / `parted`):
```bash
# Inspeccionar les taules de particions de tots els discs
sudo fdisk -l

# Crear o modificar una taula de particions GPT interactiva
sudo gdisk /dev/nvme0n1

# Verificar l'estat dels sistemes de fitxers muntats
lsblk -f
```
