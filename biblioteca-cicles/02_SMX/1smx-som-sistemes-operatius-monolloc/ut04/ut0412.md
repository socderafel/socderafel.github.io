# 4.12 Carregadors d'Arrencada (*Boot Loaders*) i Doble Arrencada (*Dual Boot*)

El **carregador d'arrencada** (*Boot Loader*) és el primer programari que pren el control de la màquina un cop el firmware (BIOS o UEFI) ha finalitzat les seues comprovacions inicials. La seua missió fonamental és carregar el nucli del sistema operatiu triat en la memòria RAM i transferir-li l'execució.

---

## 🐧 GNU GRUB 2 (GRand Unified Bootloader)

**GRUB versió 2** és el gestor d'arrencada hegemònic en la pràctica totalitat de les distribucions GNU/Linux. Suporta arrencada tant per BIOS com per UEFI, sistemes de fitxers moderns (ext4, Btrfs, ZFS, NTFS) i detecció automàtica d'altres sistemes operatius instal·lats.

### Fitxers clau de configuració de GRUB 2:
- `/boot/grub/grub.cfg`: Fitxer binari/script generat automàticament. **Mai s'ha d'editar manualment**, ja que serà sobreescrit en la següent actualització del nucli.
- `/etc/default/grub`: Fitxer de text pla on l'administrador defineix els paràmetres globals:
  ```bash
  # Temps d'espera del menú en segons abans d'iniciar el SO per defecte
  GRUB_TIMEOUT=10

  # Entrada per defecte (0 = primera opció)
  GRUB_DEFAULT=0

  # Resolució gràfica del menú de pantalla completa
  GRUB_GFXMODE=1920x1080

  # Paràmetres passats al nucli de Linux
  GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
  ```
- `/etc/grub.d/`: Directori amb scripts modulars (`00_header`, `10_linux`, `30_os-prober`, `40_custom`).

### Aplicar canvis a GRUB:
Cada vegada que es modifica `/etc/default/grub` o s'instal·la un nou nucli, cal regenerar `grub.cfg`:
```bash
sudo update-grub
# (Comandament equivalent en altres distribucions: sudo grub-mkconfig -o /boot/grub/grub.cfg)
```

## 🪟 Windows Boot Manager i BCD

Microsoft Windows utilitza el seu propi gestor:
- **Windows Boot Manager (`bootmgr` o `bootmgfw.efi`):** S'allotja a la partició de sistema EFI (`\EFI\Microsoft\Boot\bootmgfw.efi`).
- **Base de Dades BCD (*Boot Configuration Data*):** Registre binari que substitueix l'antic fitxer de text `boot.ini` de Windows XP.
- **Eina d'administració `bcdedit` (des de consola amb permisos elevats):**
  ```cmd
  REM Llistar totes les entrades d'arrencada registrades
  bcdedit /enum all

  REM Modificar el temps d'espera del menú a 15 segons
  bcdedit /timeout 15
  ```

## 🔄 El Protocol d'Instal·lació de Doble Arrencada (*Dual Boot*)

La regla d'or dels tècnics informàtics per instal·lar un equip amb Windows 11 i Ubuntu en el mateix disc és:

> [!IMPORTANT]
> **Instal·lar sempre Microsoft Windows EN PRIMER LLOC, i instal·lar GNU/Linux EN SEGON LLOC.**

### Per què aquest ordre?
1. L'instal·lador de Windows és restrictiu: assumeix que és l'únic sistema de la màquina i sol sobreescriure el gestor d'arrencada principal a la NVRAM.
2. L'instal·lador d'Ubuntu és cooperatiu: detecta la partició NTFS de Windows mitjançant l'eina **os-prober**, afegeix automàticament l'opció de menú *Windows Boot Manager* dins del menú de GRUB 2 i deixa l'ordinador perfectament operatiu amb un selector d'arrencada dual.
