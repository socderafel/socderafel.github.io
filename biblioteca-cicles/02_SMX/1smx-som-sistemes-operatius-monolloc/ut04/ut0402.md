# 4.2 Introducció a la Instal·lació de Sistemes Operatius

La instal·lació d'un sistema operatiu en un equip informàtic requereix una planificació rigorosa prèvia per garantir que el maquinari complisca amb els requeriments mínims i recomanats del sistema operatiu triat.

---

## 📋 Matriu de Requisits Mínims i Recomanats

| Sistema Operatiu | Arquitectura CPU | RAM Mínima / Recomanada | Espai en Disc Mínim | Firmware Requerit |
| :--- | :---: | :---: | :---: | :---: |
| **Windows 11 Pro** | 64-bit (2+ nuclis $\ge 1 \text{ GHz}$) | 4 GiB / **8-16 GiB** | 64 GB SSD | **UEFI + Secure Boot + TPM 2.0** |
| **Windows 10 Pro** | 32-bit o 64-bit ($\ge 1 \text{ GHz}$) | 2 GiB / **8 GiB** | 32 GB | BIOS Legacy o UEFI |
| **Ubuntu 24.04 LTS** | 64-bit (x86-64 v2 $\ge 2 \text{ GHz}$) | 4 GiB / **8 GiB** | 25 GB | BIOS Legacy o UEFI |
| **Debian 12 (minimal)**| 32-bit, 64-bit o ARM | 512 MiB / **2 GiB** | 5 GB | BIOS Legacy o UEFI |

---

## 🛠️ Fases del Procés de Desplegament

1. **Fase de Planificació:**
   - Triar arquitectura de 64 bits (x86-64).
   - Determinar l'esquema de particions: triar sempre **GPT amb UEFI** llevat que el maquinari tinga més de 15 anys.
   - Definir si l'equip tindrà un únic sistema operatiu o un entorn de doble arrencada (**Dual Boot** Windows + Linux).
2. **Fase de Preparació del Mitjà:**
   - Descàrrega d'imatges ISO oficials verificant la suma criptogràfica de comprovació (**SHA-256**) per descartar fitxers corromputs o alterats:
     ```bash
     sha256sum ubuntu-24.04-desktop-amd64.iso
     ```
   - Creació del dispositiu USB arrencable amb eines com **Ventoy** o **Rufus**.
3. **Fase de Configuració del Firmware (UEFI):**
   - Desactivar *CSM (Compatibility Support Module)* per forçar mode UEFI natiu pur.
   - Comprovar que el controlador SATA està en mode **AHCI** (mai en mode RAID propietari tipus Intel RST, que sol impedir que Linux reconega el disc NVMe).
   - Ajustar la prioritat de dispositius d'arrencada (*Boot Device Priority*).
