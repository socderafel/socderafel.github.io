# 4.5 Gestió de Memòria i Memòria Virtual

La memòria RAM física és un recurs finit i ràpid. Quan la suma dels espais de memòria demandats per tots els processos supera la capacitat física dels mòduls RAM instal·lats, el sistema operatiu utilitza la tècnica de la **memòria virtual**.

---

## 📄 El Mecanisme de Paginació (*Paging*)

La memòria física es divideix en blocs de mida fixa anomenats **marcs de pàgina** (*page frames*, típicament de 4 KiB).
L'espai d'adreces virtual de cada procés es divideix en blocs de la mateixa mida anomenats **pàgines lògiques**.

La unitat de gestió de memòria del processador (**MMU** - *Memory Management Unit*) s'encarrega de traduir en temps real les adreces lògiques generades pel programa a adreces físiques de memòria RAM mitjançant les **taules de pàgines**:

$$\text{Adreça Lògica} \xrightarrow[\text{Taula de Pàgines}]{\text{MMU}} \text{Adreça Física en RAM}$$

### ⚠️ Fallada de Pàgina (*Page Fault*):
Si un procés intenta accedir a una pàgina que actualment no està carregada a la memòria RAM física sinó descarregada al disc d'emmagatzematge secundari:
1. La CPU genera una interrupció de maquinari de fallada de pàgina (*Page Fault Exception*).
2. El nucli suspèn el procés i busca un marc de pàgina lliure a la RAM.
3. Si la RAM està plena, utilitza un algorisme de reemplaçament (com **LRU** - *Least Recently Used*) per expulsar una pàgina inactiva cap al disc (*Page Out / Swap Out*).
4. El nucli carrega la pàgina requerida des del disc cap a la RAM (*Page In / Swap In*).
5. S'actualitza la taula de pàgines i el procés continua la seua execució com si res haguera passat.

## 💽 Implementació de l'Espai d'Intercanvi

### En entorns GNU/Linux:
- **Partició de Swap tradicional:** Una partició dedicada de tipus Linux swap (`82` en MBR, GUID corresponent en GPT).
- **Fitxer de Swap modern (`/swapfile`):** Mètode estàndard en Ubuntu modern que permet redimensionar l'espai d'intercanvi dinàmicament sense necessitat de tocar les particions del disc:
  ```bash
  # Crear un fitxer de swap de 4 GiB
  sudo fallocate -l 4G /swapfile
  sudo chmod 600 /swapfile
  sudo mkswap /swapfile
  sudo swapon /swapfile

  # Fer-lo permanent afegint la línia a /etc/fstab:
  # /swapfile none swap sw 0 0
  ```
- **Paràmetre Swappiness:** Controla la tendència del nucli a utilitzar la memòria swap (de 0 a 100):
  ```bash
  # Consultar swappiness actual (per defecte 60 en Ubuntu)
  cat /proc/sys/vm/swappiness
  ```

### En entorns Microsoft Windows:
- **Fitxer de paginació (`C:\pagefile.sys`):** Fitxer ocult de sistema administrat automàticament per Windows que emmagatzema les pàgines de memòria modificades.
- **Fitxer d'hibernació (`C:\hiberfil.sys`):** Emmagatzema tot el contingut íntegre de la memòria RAM quan el portàtil entra en estat d'hibernació profunda (ACPI S4) o arrencada ràpida (*Fast Startup*).
