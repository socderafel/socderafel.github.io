Com a futur tècnic en **Sistemes Microinformàtics i Xarxes (SMX)**, el sistema operatiu constitueix el fonament sobre el qual descansa qualsevol solució digital. Un conjunt de maquinari d'última generació (processadors multi-nucli, memòria d'alta velocitat DDR5 i unitats d'emmagatzematge NVMe) és incapaç de funcionar de manera autònoma sense un sistema operatiu que actue com a pont intel·ligent entre els components electrònics i les aplicacions de l'usuari.

El mòdul de **Sistemes Operatius Monolloc (SOM)** et capacita per planificar, instal·lar, particionar, configurar, personalitzar, automatitzar i securitzar sistemes operatius tant en equips físics individuals com en entorns virtualitzats avançats.

## 🛠️ Requisits del Taller i Entorn de Pràctiques

Per a dur a terme les activitats pràctiques i desplegar els laboratoris de virtualització, cada estació de treball física ha de complir unes especificacions mínimes recomanades:

| Component de Maquinari | Especificació Mínima | Especificació Recomanada | Finalitat Operativa |
| :--- | :--- | :--- | :--- |
| **Processador (CPU)** | 64 bits x86-64 amb 4 nuclis | 64 bits x86-64 amb 6 o 8 nuclis | Permet assignar 2 o més nuclis dedicats a cada màquina virtual (VM). |
| **Virtualització per Maquinari** | **Intel VT-x** o **AMD-V / SVM** activada al firmware UEFI | **Intel VT-x** o **AMD-V** + **IOMMU/AMD-Vi** | Indispensable perquè l'hipervisor puga executar màquines de 64 bits amb acceleració nativa. |
| **Memòria RAM** | 8 GB DDR4 | 16 GB o 32 GB DDR4/DDR5 | Permet executar el sistema amfitrió (4 GB) i una o dues VMs simultànies (Windows 11 amb 4 GB i Ubuntu amb 2-4 GB). |
| **Emmagatzematge** | 120 GB SSD SATA | 250+ GB SSD NVMe PCIe | Redueix el temps d'arrancada i càrrega d'imatges ISO de 3-4 minuts a menys de 15 segons. |
| **Pantalla / Resolució** | 1366 × 768 px | 1920 × 1080 px (Full HD) | Facilita tindre oberta la consola i la finestra de la VM en paral·lel. |

> [!IMPORTANT]
> Si la virtualització assistida per maquinari està desactivada al firmware (BIOS/UEFI) de la màquina amfitriona, VirtualBox només permetrà crear màquines virtuals de 32 bits amb un rendiment molt reduït o directament mostrarà l'error `VERR_VMX_NO_VMX` o `VT-x is disabled in the BIOS for all CPU modes`.

## 📦 Kit de Programari de Laboratori

Al llarg del curs farem servir un conjunt unificat d'eines lliures i corporatives:

1. **Hipervisor de Virtualització:**
   - **Oracle VM VirtualBox 7.x** juntament amb el paquet complementari **Extension Pack** (suport per a controladors USB 2.0/3.0, xifratge de discs virtuals i arrencada NVMe).
   - Paquet **Guest Additions** per a cada sistema convidat (compartició de carpetes, porta-retalls bidireccional i resolució dinàmica).

2. **Sistemes Operatius Objecte d'Estudi:**
   - **GNU/Linux:** Ubuntu Desktop 24.04 LTS (*Noble Numbat*) x86_64 o Debian 12 (*Bookworm*).
   - **Microsoft Windows:** Windows 11 Pro 64-bit (edició d'avaluació educativa oficial) o Windows 10 Pro.

3. **Utilitats de Diagnòstic, Partició i Desplegament:**
   - **Rufus** i **Ventoy:** Per a la preparació de memòries USB d'arrancada multi-sistema.
   - **GParted Live:** Entorn lleuger Linux per a reparació i redimensionament de taules MBR/GPT.
   - **Visual Studio Code / Notepad++:** Edició de scripts per a automatització (`.sh`, `.ps1`).
