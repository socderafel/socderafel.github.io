# 1.1 Presentació i Entorn de Treball

Com a futur tècnic en Sistemes Microinformàtics i Xarxes, el sistema operatiu és la teua eina diària essencial. Un ordinador sense sistema operatiu és només un conjunt inert de circuits electrònics i xips de silici. El sistema operatiu és el programari fonamental que dota de vida la màquina, administra els seus recursos finits i ofereix una interfície intel·ligible entre l'ésser humà i el maquinari.

---

## 🛠️ Eines i Recursos Digitals Requerits

Per a superar el mòdul amb èxit necessitarem:
1. **Ordinador amfitrió (Host):**
   - Processador de 64 bits amb tecnologia de virtualització activada a la BIOS/UEFI (**Intel VT-x** o **AMD-V / SVM**).
   - Mínim 16 GB de memòria RAM (8 GB com a mínim absolut per a executar una VM de Windows 11 o Ubuntu amb comoditat).
   - Mínim 80 GB d'espai lliure en una unitat SSD (recomanat SSD NVMe per a agilitzar el temps d'arrancada de les màquines virtuals).
2. **Programari de Virtualització:**
   - **Oracle VM VirtualBox versió 7.0 o superior** + **Extension Pack**.
3. **Imatges ISO oficials de laboratori:**
   - `Ubuntu Desktop 24.04 LTS (Noble Numbat) x86_64` (suport estès durant 5 anys).
   - `Windows 11 Pro 64-bit` o `Windows 10 Pro 64-bit` (edició d'avaluació oficial de Microsoft per a entorns educatius).
4. **Programari de terminal i utilitats auxiliars:**
   - Rufus o Ventoy (per a crear mitjans d'instal·lació USB arrencables).
   - Visual Studio Code o Notepad++ per a l'edició de scripts (`.sh`, `.ps1`, `.bat`).
