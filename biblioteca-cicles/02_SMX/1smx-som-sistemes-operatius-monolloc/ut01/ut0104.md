Tot i que les interfícies gràfiques d'usuari (GUI) faciliten les tasques d'ofimàtica domèstica, un tècnic informàtic professional ha de dominar la **interfície de línia d'ordres** (*Command-Line Interface* - **CLI**). En situacions reals d'assistència tècnica, és molt habitual haver de diagnosticar equips en remot mitjançant SSH, servidors sense escriptori gràfic (*headless*) o sistemes amb l'entorn visual danyat en mode de rescat.

En aquest apartat aprendràs les ordres fonamentals d'auditoria de maquinari, memòria i sistema operatiu tant en entorns **Microsoft Windows (PowerShell)** com en **GNU/Linux (Bash)**.

---

## 🪟 Diagnòstic del Sistema en Windows amb PowerShell

PowerShell és una potent consola orientada a objectes integrada en totes les versions modernes de Windows. Per obtindre dades del maquinari i del sistema s'utilitza el proveïdor **CIM (Common Information Model)** mitjançant `Get-CimInstance`:

### 1. Auditoria del Sistema Operatiu i Memòria Física
Obrint una consola de PowerShell com a administrador:

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, OSArchitecture, Version, BuildNumber, TotalVisibleMemorySize, FreePhysicalMemory | Format-List
```

* **Caption:** Nom comercial de l'edició (ex: *Microsoft Windows 11 Pro*).
* **OSArchitecture:** Indica si el sistema és de 64 bits (`64-bit`) o 32 bits (`32-bit`).
* **TotalVisibleMemorySize:** Memòria RAM física total accessible en KiB.
* **FreePhysicalMemory:** Memòria RAM lliure en este instant en KiB.

### 2. Comprovació de Virtualització per Maquinari a la CPU
Abans d'instal·lar VirtualBox, és imprescindible verificar que el processador té activada la tecnologia de virtualització al firmware:

```powershell
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors, VirtualizationFirmwareEnabled | Format-List
```

* Si `VirtualizationFirmwareEnabled` mostra **True**, l'equip està llest per a executar màquines virtuals de 64 bits.
* Si mostra **False**, cal reiniciar l'ordinador, accedir al menú de configuració del firmware UEFI i habilitar l'opció *Intel Virtualization Technology (VT-x)* o *AMD SVM Support*.

### 3. Estat dels Discs i Volums
```powershell
Get-Disk | Select-Object Number, FriendlyName, PartitionStyle, Size, OperationalStatus
Get-Volume | Select-Object DriveLetter, FileSystemLabel, FileSystem, SizeRemaining, Size
```
* **PartitionStyle:** Indica si el disc utilitza el format modern `GPT` o l'antic `MBR`.

## 🐧 Diagnòstic del Sistema en GNU/Linux amb Bash

En GNU/Linux tot el maquinari i les dades del nucli s'exposen a través del sistema de fitxers virtual `/proc` i `/sys`. Els tècnics disposen d'un conjunt d'ordres ràpides i estandarditzades:

```
                      ORDRES BÀSIQUES D'INSPECCIÓ EN LINUX
  ┌─────────────┬────────────────────────────────────────────────────────┐
  │ uname -a    │ Mostra versió del nucli, arquitectura i nom del host   │
  ├─────────────┼────────────────────────────────────────────────────────┤
  │ lscpu       │ Detall complet del processador, nuclis i extensions VT │
  ├─────────────┼────────────────────────────────────────────────────────┤
  │ free -h     │ Estat de la memòria RAM física i espai d'intercanvi    │
  ├─────────────┼────────────────────────────────────────────────────────┤
  │ lsblk -f    │ Arbre de discs, particions, sistemes de fitxers i UUID │
  ├─────────────┼────────────────────────────────────────────────────────┤
  │ df -hT      │ Espai d'emmagatzematge ocupat i lliure en particions   │
  └─────────────┴────────────────────────────────────────────────────────┘
```

### 1. Nucli i Arquitectura
```bash
uname -a
```
Exemple de sortida:
`Linux aula-inf01 6.8.0-40-generic #40-Ubuntu SMP PREEMPT_DYNAMIC x86_64 GNU/Linux`
* `x86_64` confirma que el nucli és de 64 bits.

### 2. Processador i Extensions de Virtualització
```bash
lscpu | grep -E "Model name|Architecture|Virtualization"
```
A la línia `Virtualization:` ha d'aparèixer `VT-x` (Intel) o `AMD-V` (AMD).

### 3. Anàlisi Profunda de la Memòria RAM amb `free -h`
En executar:
```bash
free -h
```
Obtenim una taula semblant a aquesta:
```
               total        used        free      shared  buff/cache   available
Mem:            15Gi       3.2Gi       4.5Gi       210Mi       7.3Gi        11Gi
Swap:          4.0Gi          0B       4.0Gi
```

> [!IMPORTANT]
> **Com s'interpreta la memòria en Linux?**
> - **free (4.5 GiB):** Memòria absolutament buida que no s'està utilitzant per a res.
> - **buff/cache (7.3 GiB):** Memòria que el nucli de Linux ha aprofitat per desar en memòria cau lectures recents de fitxers de disc. Si una aplicació necessita RAM urgentment, el nucli allibera aquest espai a l'instant.
> - **available (11 GiB):** **Aquesta és la xifra real que indica la memòria disponible per a obrir noves aplicacions o màquines virtuals.** Resulta de sumar la memòria `free` més la part reutilitzable de `buff/cache`.

### 4. Estat dels Discs i Sistemes de Fitxers
```bash
df -hT -x tmpfs -x devtmpfs
```
El paràmetre `-h` mostra les mides en unitats humanes (G, M) i `-T` mostra el tipus de sistema de fitxers (`ext4`, `btrfs`, `ntfs`, `vfat`).

## 🔄 Taula Comparativa de Diagnòstic Ràpid (Windows vs Linux)

| Objectiu Tècnic | Ordre en Windows (PowerShell) | Ordre en GNU/Linux (Bash) |
| :--- | :--- | :--- |
| **Arquitectura del SO** | `(Get-CimInstance Win32_OperatingSystem).OSArchitecture` | `uname -m` o `arch` |
| **Versió del Nucli / SO** | `[System.Environment]::OSVersion.Version` | `uname -r` |
| **Suport de Virtualització** | `(Get-CimInstance Win32_Processor).VirtualizationFirmwareEnabled` | `egrep -c '(vmx|svm)' /proc/cpuinfo` |
| **Memòria RAM Total i Ús** | `Get-CimInstance Win32_OperatingSystem \| Format-List *Memory*` | `free -h` |
| **Particions i Punts de Muntatge** | `Get-Volume` o `diskpart` | `lsblk -f` i `df -hT` |
| **Processos en Temps Real** | `Get-Process \| Sort-Object CPU -Descending` | `top` o `htop` |
