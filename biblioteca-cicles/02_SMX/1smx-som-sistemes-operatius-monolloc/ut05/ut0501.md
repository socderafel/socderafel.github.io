# 5.1 Estructura de Directoris i Jerarquia de Fitxers (FHS de Linux vs Windows)

Un cop instal·lat el sistema operatiu, la primera habilitat que ha de dominar qualsevol tècnic informàtic és saber moure's amb total seguretat per l'arbre de directoris, conèixer on s'allotgen els fitxers de configuració del sistema, on es guarden les dades d'usuari i on resideixen els registres (*logs*) d'esdeveniments.

Els dos grans sistemes operatius monolloc del mercat —**GNU/Linux** i **Microsoft Windows**— utilitzen filosofies completament diferents per estructurar el seu emmagatzematge lògic.

---

## 1. La Jerarquia de GNU/Linux: L'Estàndard FHS

En Linux i la família UNIX no existeixen les lletres d'unitat (`C:`, `D:`, `E:`). Tot el sistema s'organitza sota un **arbre únic de jerarquia invertida**, el punt d'origen del qual és la carpeta arrel representada per una barra inclinada cap a la dreta: **`/` (root)**.

Les diferents particions, discs secundaris, memòries USB o carpetes de xarxa "es pengen" (es munten) en diferents directoris d'aquest arbre únic. Aquesta organització està estandarditzada oficialment sota el **FHS (Filesystem Hierarchy Standard)**:

```
/ (Arrel Única)
├── bin -> usr/bin       (Binaris i ordres essencials per a tots els usuaris: ls, cp, bash)
├── sbin -> usr/sbin     (Binaris d'administració per a root: fdisk, iptables, reboot)
├── boot/                (Nucli vmlinuz, initramfs i configuració de GRUB)
│   └── efi/             (Partició ESP FAT32 muntada)
├── dev/                 (Fitxers especials de dispositius: /dev/sda, /dev/nvme0n1, /dev/null)
├── etc/                 (Configuració del sistema en text pla: passwd, fstab, hostname)
├── home/                (Directoris personals dels usuaris ordinaris: /home/alumne/)
├── root/                (Directori personal exclusiu de l'administrador 'root')
├── var/                 (Dades variables: registres de logs /var/log, cues de correu, apt cache)
├── tmp/                 (Arxius temporals d'accés lliure, sovint buidat en cada reinici)
├── proc/                (Pseudo-sistema de fitxers virtual del nucli en RAM: cpuinfo, meminfo)
├── sys/                 (Informació del maquinari i controladors detectats pel kernel)
├── mnt/                 (Punt de muntatge tradicional temporal per a discs o ISOs)
├── media/               (Punts de muntatge automàtics per a mitjans extraïbles: USBs, CDs)
└── opt/                 (Programari addicional de tercers: Google Chrome, Discord, eines)
```

### Els directoris més importants per al tècnic de SMX
1. **`/etc` (Editable Text Configuration):** Conté la configuració de pràcticament tot el sistema en fitxers de text pla que es poden editar amb `nano` o `vim` (com `/etc/network/interfaces`, `/etc/hosts` o `/etc/default/grub`).
2. **`/var/log`:** És el centre de diagnòstic de Linux. Si un servei no arrenca o la màquina falla, el tècnic llegeix fitxers com `/var/log/syslog` o `/var/log/auth.log` amb comandes com `tail -f` o `journalctl`.
3. **`/proc`:** No ocupa espai real en disc; és una finestra directa a la memòria RAM creada pel nucli. Per exemple, llegir `/proc/cpuinfo` mostra les dades del processador, i `/proc/meminfo` la RAM lliure en temps real.

## 2. La Jerarquia de Microsoft Windows: Lletres de Volum i Registre

En Windows, cada volum o partició formatada rep una **lletra d'unitat** seguida de dos punts i una barra invertida (ex: `C:\`, `D:\`). La unitat on s'instal·la el sistema s'anomena **Volum del Sistema** (habitualment `C:\`):

```
C:\
├── Windows\             (El nucli del sistema operatiu, DLLs i controladors)
│   ├── System32\        (Binaris crítics de 64 bits: cmd.exe, ntoskrnl.exe, bcdedit.exe)
│   ├── SysWOW64\        (Capa de compatibilitat de 32 bits en Windows de 64 bits)
│   └── Fonts\           (Tipografies instal·lades)
├── Program Files\       (Instal·lació de programari nadiu de 64 bits)
├── Program Files (x86)\ (Instal·lació d'aplicacions antigues de 32 bits)
├── ProgramData\         (Carpeta oculta amb dades de programes compartides per tots els usuaris)
└── Users\ (Usuaris)     (Perfils personals de cadascun dels usuaris del sistema)
    └── nom_usuari\
        ├── Desktop\     (Escriptori de l'usuari)
        ├── Documents\   (Documents personals)
        ├── Downloads\   (Baixades d'Internet)
        └── AppData\     (Carpeta oculta amb la configuració de les aplicacions de l'usuari)
            ├── Local\   (Dades locals que no es sincronitzen en domini)
            └── Roaming\ (Configuració que viatja amb el perfil mòbil: perfils de Chrome, etc.)
```

### Variables d'entorn d'administració en Windows
En comptes d'escriure rutes fixes que poden canviar segons l'idioma, els administradors i scripts utilitzen **variables d'entorn**:
* `%SystemRoot%` o `%windir%` -> Sol apuntar a `C:\Windows`.
* `%ProgramFiles%` -> Apunta a `C:\Program Files`.
* `%USERPROFILE%` -> Apunta a `C:\Users\nom_usuari`.
* `%APPDATA%` -> Apunta a `C:\Users\nom_usuari\AppData\Roaming`.
* `%TEMP%` -> Apunta a la carpeta temporal de l'usuari actual (`C:\Users\nom_usuari\AppData\Local\Temp`).

## 3. Rutes Absolutes vs Rutes Relatives

Saber expressar rutes és fonamental tant a la terminal de Linux com a CMD i PowerShell:

* **Ruta Absoluta:** Especifica la ubicació exacta d'un fitxer o carpeta començant sempre des de l'arrel del sistema (`/` en Linux, o `C:\` en Windows). Funciona exactament igual independentment d'on estiga situat l'usuari en aquest moment.
  - *Exemple Linux:* `/var/log/apache2/error.log`
  - *Exemple Windows:* `C:\Windows\System32\drivers\etc\hosts`
* **Ruta Relativa:** Especifica la ubicació d'un fitxer prenent com a referència el directori de treball actual (**Current Working Directory**).
  - El símbol `.` representa el directori actual.
  - El símbol `..` representa el directori pare (un nivell amunt en l'arbre).
  - *Exemple Linux:* Si estem a `/home/alumne`, la ruta `Documents/tasca1.txt` fa referència a `/home/alumne/Documents/tasca1.txt`. La ruta `../professora/` fa referència a `/home/professora/`.

## 4. Comparativa d'Ordres de Navegació Bàsica

| Acció administrativa | GNU/Linux (Bash) | Windows (CMD) | Windows (PowerShell) |
| :--- | :--- | :--- | :--- |
| **Saber on estic (Ruta actual)** | `pwd` | `cd` | `Get-Location` (àlies `pwd`, `gl`) |
| **Llistar contingut** | `ls -la` | `dir` | `Get-ChildItem` (àlies `dir`, `ls`) |
| **Canviar de directori** | `cd /ruta/carpeta` | `cd \ruta\carpeta` | `Set-Location /ruta` (àlies `cd`) |
| **Pujar un nivell amunt** | `cd ..` | `cd ..` | `cd ..` |
| **Crear una carpeta nova** | `mkdir projecte` | `mkdir projecte` | `New-Item -ItemType Directory projecte` |
| **Netejar la pantalla** | `clear` | `cls` | `Clear-Host` (àlies `cls`, `clear`) |
