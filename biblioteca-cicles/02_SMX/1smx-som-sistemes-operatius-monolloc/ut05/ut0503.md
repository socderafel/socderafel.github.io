# 5.3 Interfícies d'Usuari: GUI vs CLI

El sistema operatiu ofereix dues maneres fonamentals d'interacció amb l'ésser humà:

1. **Interfície Gràfica d'Usuari (GUI - *Graphical User Interface*):**
   - Basada en el paradigma WIMP (*Windows, Icons, Menus, Pointer*).
   - Molt intuïtiva per a usuaris novells, però consumidora de memòria RAM i recursos gràfics.
   - Dificulta l'automatització de tasques repetitives.
2. **Interfície de Línia d'Ordres (CLI - *Command-Line Interface*):**
   - Basada en text pla mitjançant un intèrpret d'ordres (*Shell*).
   - Lleugera, extremadament ràpida i potent per a administració remota a través de xarxes lentes (SSH).
   - Permet l'automatització total mitjançant scripts i canonades (*pipes*).

## 🌪️ El Poder de la Canonada (*Pipe* `|`) i Redireccions a Linux

Un dels grans principis del disseny Unix és: *"Crea programes que facen una sola cosa bé, i que es comuniquen entre ells mitjançant fluxos de text"*.

### Redireccions d'Entrada i Eixida:
- `>` : Redirigeix l'eixida estàndard (*stdout*) cap a un fitxer, **sobreescrivint** el contingut anterior:
  ```bash
  ls -l /etc > llistat_etc.txt
  ```
- `>>` : Redirigeix l'eixida **afegint** al final del fitxer existent (*append*):
  ```bash
  date >> registre_arrencades.log
  ```
- `<` : Llegeix l'entrada estàndard (*stdin*) des d'un fitxer:
  ```bash
  sort < noms_alumnes.txt
  ```
- `2>` : Redirigeix exclusivament els missatges d'error (*stderr*):
  ```bash
  find / -name "*.conf" 2> /dev/null
  ```

### Canonades (*Pipes* `|`):
Connecta l'eixida estàndard del primer comandament directament amb l'entrada estàndard del segon comandament:
```bash
# Comptar quantes línies conté el fitxer de contrasenyes del sistema
cat /etc/passwd | wc -l

# Trobar processos de l'usuari 'alumne' que continguen la paraula 'python'
ps aux | grep alumne | grep python | awk '{print $2, $11}'
```
