# 5.3 Administració de Windows: PowerShell, Serveis i Permisos NTFS (ACL)

En entorns corporatius i estacions de treball professionals, l'administració de Windows va molt més enllà de fer clic a menús gràfics. Un bon tècnic de SMX ha de saber gestionar els comptes locals, controlar els serveis que corren en segon pla, utilitzar la consola moderna **PowerShell** per automatitzar consultes i configurar les llistes de control d'accés (**ACL**) del sistema de fitxers **NTFS**.

---

## 1. Gestió d'Usuaris Locals i Grups de Seguretat

Encara que en xarxes d'empresa grans els usuaris s'administren centralitzadament amb un domini Active Directory (mòdul de Xarxes / SOX), en equips monolloc la gestió es fa a la base de dades local **SAM (Security Accounts Manager)**:

### Eines Gràfiques i Consoles
* **`lusrmgr.msc`:** Consola de gestió d'Usuaris i Grups Locals (disponible en edicions Pro, Enterprise i Education). Permet crear usuaris, marcar que l'usuari ha de canviar la contrasenya en el següent inici, deshabilitar comptes o afegir membres a grups.
* **Grups integrats clau:**
  - **Administradors:** Tenen control absolut de l'equip i de la configuració del maquinari.
  - **Usuaris:** Poden executar programes i guardar dades personals, però no instal·lar programari que modifique el sistema ni canviar la configuració d'altres usuaris.
  - **Usuaris d'escriptori remot:** Permet connectar-se per RDP a la màquina.

### Ordres ràpides al Símbol del Sistema (CMD com a Administrador)
```cmd
:: Crear un usuari nou amb contrasenya
net user tecnic-suport Password123! /add

:: Afegir l'usuari al grup local d'Administradors
net localgroup Administradores tecnic-suport /add

:: Deshabilitar un compte sense esborrar les seues dades
net user tecnic-suport /active:no
```

---

## 2. Els Serveis de Windows (`services.msc`)

Un **servei** de Windows és un programa que s'executa en segon pla des que l'ordinador arrenca, sense necessitat que cap usuari haja iniciat sessió gràfica. Controlen des de la impressió (`Spooler`) fins a les actualitzacions (`wuauserv`) o el servidor web IIS.

### Tipus d'inici d'un servei
1. **Automàtic:** El servei arrenca immediatament durant l'inici de Windows.
2. **Automàtic (Inici retardat):** Arrenca pocs minuts després de l'arrancada per permetre que la CPU prioritze la càrrega de l'escriptori i reduir la lentitud inicial.
3. **Manual:** El servei només s'executa quan una altra aplicació o el propi usuari el sol·licita explícitament.
4. **Deshabilitat:** El servei no es pot iniciar de cap manera, ni tan sols manualment, fins que no es canvie el seu estat.

---

## 3. Administració Professional amb PowerShell

**Windows PowerShell** és la consola de línia d'ordres avançada de Microsoft basada en el framework .NET. A diferència del CMD antic (que només enviava línies de text mut), PowerShell treballa amb **objectes rics estructurats** amb propietats i mètodes.

Totes les ordres segueixen la nomenclatura estricta **`Verb-Nom`** (per exemple: `Get-Service`, `Start-Process`, `Set-ExecutionPolicy`):

### Cmdlets imprescindibles per al tècnic de SMX
```powershell
# 1. GESTIÓ DE SERVEIS
# Consultar l'estat del servei de cua d'impressió
Get-Service -Name Spooler

# Aturar i tornar a arrencar el servei (reinici de servei)
Restart-Service -Name Spooler

# Deshabilitar el servei de Windows Update
Set-Service -Name wuauserv -StartupType Disabled

# 2. GESTIÓ DE PROCESSOS I FILTRAT AMB CANONADES (PIPELINES |)
# Llistar els 5 processos que consumeixen més memòria RAM
Get-Process | Sort-Object WorkingSet -Descending | Select-Object -First 5

# Tancar forçosament un procés bloquejat pel seu nom
Stop-Process -Name "notepad" -Force

# 3. INFORMACIÓ DEL MAQUINARI I SISTEMA
Get-ComputerInfo | Select-Object WindowsProductName, TotalPhysicalMemory
```

## 4. Permisos NTFS i Llistes de Control d'Accés (ACL)

El sistema de fitxers **NTFS** ofereix una seguretat molt més granular que el clàssic FAT32 mitjançant les **Llistes de Control d'Accés (ACL - Access Control Lists)**:

### Nivells de Permisos NTFS Estàndard
* **Control total (Full Control):** Permet llegir, modificar, esborrar, canviar els permisos NTFS i prendre possessió de la propietat del fitxer.
* **Modificació (Modify):** Permet llegir, escriure i esborrar fitxers, però NO canviar permisos ni la propietat.
* **Lectura i execució (Read & Execute):** Permet veure dades i llançar executables o scripts.
* **Lectura (Read):** Només visualització de dades i atributs.
* **Escriptura (Write):** Permet crear fitxers i sobreescriure dades, però no esborrar.

### Herència de Permisos i Resolució de Conflictes
* **Herència:** Per defecte, qualsevol fitxer o subcarpeta creada dins d'un directori hereta automàticament els permisos de la carpeta pare. L'administrador pot desactivar l'herència per blindar un recurs específic.
* **Denegar mana sobre Permetre:** Si un usuari pertany a dos grups, un que té permís de *"Lectura permesa"* i un altre que té *"Lectura denegada"*, **sempre s'imposa la denegació**.

### Administració per comanda amb `icacls`
En scripts de desplegament s'utilitza l'eina oficial `icacls.exe`:
```cmd
:: Donar permís de Modificació al grup Usuaris sobre la carpeta Dades
icacls "C:\Dades" /grant "Usuarios":(M)

:: Atorgar Control Total a l'Administrador i aplicar herència recursiva a subcarpetes (OI)(CI)
icacls "C:\Dades" /grant "Administradores":(OI)(CI)(F)

:: Denegar l'esborrat (Delete) a un usuari concret
icacls "C:\Dades\Fitxer.docx" /deny "alumne":(DE)
```
