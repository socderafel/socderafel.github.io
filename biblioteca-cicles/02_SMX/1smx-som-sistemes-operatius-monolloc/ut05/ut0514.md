# 5.14 Pràctica 3: Permisos i Seguretat d'Usuaris en Linux

En aquest taller pràctic crearem una estructura d'usuaris i departaments corporatius simulant una petita empresa o un institut, i configurarem els permisos estrictes perquè cada departament tinga una carpeta privada inaccessible per a la resta de treballadors.

---

## 🎯 Objectius del Taller
1. Crear grups del sistema: `departament_it` i `departament_direccio`.
2. Crear usuaris locals amb les seues contrasenyes i assignar-los als seus grups corresponents.
3. Crear carpetes compartides a `/srv/compartit/it` i `/srv/compartit/direccio`.
4. Aplicar permisos octals `770` i bit especial SGID (*Set Group ID*) per herència de grup.
5. Comprovar que un usuari de direcció no pot entrar a la carpeta d'IT i viceversa.

---

## 🛠️ Procediment Pas a Pas

### Pas 1: Creació de Grups i Usuaris
Obri un terminal a la teua màquina virtual Ubuntu i executa:

```bash
# Crear els dos grups departamentals
sudo groupadd departament_it
sudo groupadd departament_direccio

# Crear l'usuari 'tecnic1' i assignar-lo com a membre del grup 'departament_it'
sudo useradd -m -s /bin/bash -g departament_it tecnic1
echo "tecnic1:Smx2024!" | sudo chpasswd

# Crear l'usuari 'directora1' i assignar-la al grup 'departament_direccio'
sudo useradd -m -s /bin/bash -g departament_direccio directora1
echo "directora1:Smx2024!" | sudo chpasswd
```

---

### Pas 2: Creació de les Carpetes Departamentals
```bash
# Crear l'arbre de directoris
sudo mkdir -p /srv/compartit/it
sudo mkdir -p /srv/compartit/direccio

# Assignar els propietaris i grups corresponents
sudo chown -R root:departament_it /srv/compartit/it
sudo chown -R root:departament_direccio /srv/compartit/direccio
```

---

### Pas 3: Aplicar Permisos de Seguretat `770` i herència SGID
Volem que:
- El propietari (`root`) tinga control total (`rwx` = 7).
- El grup departamental tinga control total (`rwx` = 7).
- Els altres no tinguen absolutament cap accés (`---` = 0).
- Els nous fitxers creats dins de la carpeta hereten automàticament el grup departamental (bit SGID = valor 2 en el quart dígit octal):

```bash
# Aplicar permisos 2770 (SGID + rwxrwx---)
sudo chmod 2770 /srv/compartit/it
sudo chmod 2770 /srv/compartit/direccio

# Comprovar el resultat amb ls -ld
ls -ld /srv/compartit/it /srv/compartit/direccio
# Hauries de veure: drwxrws--- 2 root departament_it ...
```

---

### Pas 4: Verificació de Seguretat (Proves de Camp)

1. **Inicia sessió com a l'usuari `tecnic1`:**
   ```bash
   su - tecnic1
   ```
2. **Intentar crear un fitxer a la carpeta del seu departament (èxit permès):**
   ```bash
   cd /srv/compartit/it
   touch informe_xarxes.txt
   ls -l
   # Observa com el fitxer pertany automàticament al grup 'departament_it'!
   ```
3. **Intentar accedir a la carpeta del departament de direcció (bloqueig per seguretat):**
   ```bash
   cd /srv/compartit/direccio
   # Resultat esperat: bash: cd: /srv/compartit/direccio: Permission denied (Permís denegat)
   ```
4. Tanca la sessió d'usuari per tornar a l'administrador:
   ```bash
   exit
   ```
