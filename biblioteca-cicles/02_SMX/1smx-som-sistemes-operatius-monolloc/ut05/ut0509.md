# 5.9 Automatització de Tasques en Sistemes Operatius

En l'administració de sistemes microinformàtics, l'automatització és la clau per a reduir errors humans, garantir que les còpies de seguretat s'executen sense oblits i alliberar el tècnic de treballs rutinaris d'alt desgast.

---

## 🐧 El Dimoni Cron en GNU/Linux

El servei `cron` s'executa en segon pla comprovant cada minut si hi ha tasques que coincideixen amb l'hora actual als fitxers de taula `crontab`.

### Gestió de la taula Crontab:
```bash
# Editar la taula de tasques de l'usuari actual
crontab -e

# Visualitzar les tasques programades sense obrir l'editor
crontab -l

# Esborrar totes les tasques de l'usuari
crontab -r
```

### Format dels 5 camps de planificació:

$$\text{Minut (0-59)} \quad \text{Hora (0-23)} \quad \text{Dia Mes (1-31)} \quad \text{Mes (1-12)} \quad \text{Dia Setmana (0-7)}$$

- `*` : Qualsevol valor (tots).
- `,` : Llista de valors (ex: `1,15,30` en minuts).
- `-` : Rang continu (ex: `1-5` en dia de la setmana per a dilluns a divendres).
- `/` : Pas o interval (ex: `*/15` per a executar cada 15 minuts).

### Script d'exemple de còpia de seguretat diària:
```bash
#!/bin/bash
# /usr/local/bin/backup_alumnes.sh
DATA=$(date +%Y%m%d_%H%M%S)
DEST="/var/backups/alumnes"
ORIGEN="/home/alumne/documents"

mkdir -p $DEST
tar -czf $DEST/backup_$DATA.tar.gz $ORIGEN
echo "Còpia completada el $DATA" >> /var/log/backup.log
```

Afegir a `crontab -e` per executar-se cada dia a les 23:00 de la nit:
```cron
0 23 * * * /usr/local/bin/backup_alumnes.sh > /dev/null 2>&1
```

## 🪟 El Programador de Tasques en Windows (*Task Scheduler*)

En Windows, l'equivalent de `cron` és el **Programador de tasques** (`taskschd.msc`).

També es poden gestionar tasques des de consola mitjançant **PowerShell**:
```powershell
# Definir l'acció (executar un script de manteniment)
$Accio = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-File C:\Scripts\NetejaTemporal.ps1"

# Definir el disparador (cada dia a les 20:00)
$Disparador = New-ScheduledTaskTrigger -Daily -At 20:00

# Registrar la tasca en el sistema amb privilegis elevats de SYSTEM
Register-ScheduledTask -Action $Accio -Trigger $Disparador -TaskName "Neteja_Diaria_SMX" -User "NT AUTHORITY\SYSTEM"
```
