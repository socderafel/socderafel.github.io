# 5.5 Gestió de Sistemes de Fitxers Específics i Muntatge

En sistemes operatius basats en Unix/Linux, els dispositius d'emmagatzematge no s'assignen a lletres de volum independents. Per a poder accedir a les dades d'una partició o d'un disc extern, aquesta s'ha d'integrar dins de l'arbre de directoris únic mitjançant l'operació de **muntatge** (*mount*).

---

## 🔌 Muntatge Manual i Temporal (`mount` / `umount`)

```bash
# Crear el directori que actuarà com a punt de muntatge
sudo mkdir -p /mnt/disc_dades

# Muntar la partició ext4 /dev/sdb1 al punt de muntatge
sudo mount -t ext4 /dev/sdb1 /mnt/disc_dades

# Verificar que la unitat està correctament muntada i consultar espai lliure
df -hT /mnt/disc_dades

# Desmuntar la unitat quan s'haja completat el treball
sudo umount /mnt/disc_dades
```

---

## 📄 Muntatge Permanent: El Fitxer `/etc/fstab`

Perquè un disc o partició es munte automàticament a cada inici del sistema operatiu, s'ha d'afegir una línia a `/etc/fstab` (*Filesystem Table*).

Cada línia conté **6 camps** separats per espais o tabulacions:

```
UUID=3a84b2c1-01f4-4a29-b673-9876543210ab   /mnt/dades   ext4   defaults,noatime   0   2
└─────────────────┬────────────────────┘   └───┬────┘   └─┬──┘   └──────┬─────────┘  │   │
                  │                            │          │             │        │   └─ Ordre de fsck a l'arrencada (1 per a arrel, 2 per altres)
                  │                            │          │             │        └───── Copia de seguretat dump (0 = desactivat)
                  │                            │          │             └────────────── Opcions de muntatge
                  │                            │          └──────────────────────────── Tipus de sistema de fitxers (ext4, ntfs, xfs)
                  │                            └─────────────────────────────────────── Punt de muntatge
                  └──────────────────────────────────────────────────────────────────── Dispositiu o UUID (Universal Unique Identifier)
```

> [!TIP]
> Utilitza sempre l'**UUID** en comptes del nom del dispositiu com `/dev/sdb1`, ja que els noms de dispositius poden canviar si es connecten altres discs o es canvien els ports SATA/NVMe de la placa base!
> Per obtenir l'UUID executa: `sudo blkid`.

## 🔗 Enllaços Durs (*Hard Links*) vs Enllaços Simbòlics (*Symlinks*)

Linux ofereix dues maneres de crear accessos a fitxers existents:

| Característica | Enllaç Dur (*Hard Link*) `ln fitxer enllac` | Enllaç Simbòlic (*Symlink*) `ln -s fitxer enllac` |
| :--- | :--- | :--- |
| **Com funciona?** | Punter directe al mateix número d'**inode**. És una entrada de directori addicional per al mateix fitxer físic. | Fitxer nou xicotet que conté la ruta de text del fitxer original (equivalent a un accés directe). |
| **Si s'esborra l'original?** | Les dades **NO es perden**; continuen existint mentre quede algun enllaç dur actiu. | L'enllaç es **trenca** (*broken link*) i apunta a una ruta inexistent. |
| **Creuar sistemes de fitxers?**| **No permès** (un inode només és vàlid dins de la seua partició). | **Sí permès** (pot apuntar a altres particions, discos o xarxes). |
| **Aplicable a directoris?** | No permès (per evitar bucles infinits a l'arbre). | **Sí permès**. |
