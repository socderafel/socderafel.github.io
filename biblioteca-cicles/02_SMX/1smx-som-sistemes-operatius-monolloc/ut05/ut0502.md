# 5.2 Introducció a la Configuració del Sistema Operatiu

Un cop completada la instal·lació inicial del sistema operatiu, s'inicia la fase de **postinstal·lació i configuració bàsica**. En aquesta fase s'assegura que tots els components del maquinari funcionen amb el seu màxim rendiment, es configuren les actualitzacions de seguretat i s'adapta l'entorn a les necessitats corporatives o domèstiques de l'usuari final.

---

## 🛠️ Tasques Essencials de Postinstal·lació

1. **Verificació de Controladors (*Drivers*):**
   - En Windows: Obrir l'**Administrador de dispositius** (`devmgmt.msc`) i comprovar que no hi haja cap dispositiu marcat amb un signe d'admiració groc (indicador de controlador absent o incompatible).
   - En Linux: Inspeccionar els dispositius PCI i USB reconeguts:
     ```bash
     lspci -nnk  # Mostra els dispositius PCI i el controlador del nucli en ús
     lsusb       # Mostra els dispositius USB connectats
     ```
2. **Actualització Immediata de Seguretat:**
   - Abans de connectar l'equip a serveis de xarxa sensibles o instal·lar aplicacions d'usuari, és imperatiu descarregar els últims pedaços de seguretat:
     - En Windows: Executar **Windows Update**.
     - En Ubuntu/Debian:
       ```bash
       sudo apt update && sudo apt upgrade -y
       ```
3. **Ajust de Paràmetres Regionals i Xarxa:**
   - Establir el fus horari correcte (`timedatectl set-timezone Europe/Madrid` a Linux).
   - Assignar el nom d'equip definitiu (*hostname*) segons la política del centre:
     ```bash
     sudo hostnamectl set-hostname aula102-pc04
     ```
   - Configurar els paràmetres de xarxa estàtica o dinàmica (DHCP) i servidors DNS fiables.
