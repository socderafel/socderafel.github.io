# 5.4 Automatització de Tasques: Crontab en Linux i Programador de Windows

Un dels pilars de l'eficiència en l'administració de sistemes informàtics és l'**automatització**. En lloc de dependre de la memòria d'una persona per buidar arxius temporals, sincronitzar còpies de seguretat nocturnes o generar informes d'estat del disc, configurem el sistema operatiu perquè execute aquests processos de manera totalment desatesa i puntual.

---

## 1. El Dimoni `cron` en GNU/Linux

En sistemes Linux i UNIX el servei encarregat de l'execució periòdica de tasques és el dimoni **`cron`** (o `crond`). Aquest servei s'executa en segon pla des de l'arrancada del sistema i es desperta exactament al començament de cada minut per verificar si alguna tasca programada coincideix amb la data i hora actuals.

### La Taula de 5 Camps de Crontab
Cada línia d'un fitxer crontab té una estructura estricta dividida en 5 camps temporals seguits de l'ordre o script a executar:

```
 ┌───────────── Minut (0 - 59)
 │ ┌────────────── Hora (0 - 23)
 │ │ ┌─────────────── Dia del mes (1 - 31)
 │ │ │ ┌──────────────── Mes de l'any (1 - 12 o JAN-DEC)
 │ │ │ │ ┌───────────────── Dia de la setmana (0 - 7, on 0 i 7 = Diumenge)
 │ │ │ │ │
 * * * * *   /ruta/a/la/comanda.sh  >>  /ruta/a/log.txt  2>&1
```

### Operadors Especials
* `*` (Asterisc): Qualsevol valor possible (tots els minuts, totes les hores...).
* `,` (Coma): Llista de valors discrets (ex: `15,45` en el camp dels minuts).
* `-` (Guió): Interval continu (ex: `1-5` en el camp del dia de la setmana significa de Dilluns a Divendres).
* `/` (Barra): Pas o freqüència de repetició (ex: `*/10` al camp de minuts significa cada 10 minuts).

### Exemples Pràctics de Taller
```bash
# Executar un script de còpia cada dia a les 03:30 de la matinada
30 3 * * * /usr/local/bin/backup_diari.sh

# Netejar la carpeta temporal cada diumenge a les 23:00
0 23 * * 0 rm -rf /tmp/dades_antigues/*

# Executar una sincronització cada 15 minuts de dilluns a divendres en horari lectiu (8h a 14h)
*/15 8-14 * * 1-5 /opt/scripts/sync_aules.sh

# Executar un script automàticament just en arrencar l'equip
@reboot /usr/local/bin/notificar_arrencada.sh
```

### Gestió per a l'usuari
* `crontab -e`: Obre l'editor de text per modificar la taula de tasques de l'usuari actual.
* `crontab -l`: Mostra per pantalla la llista de tasques actives.
* `crontab -r`: Esborra de forma irreversible tot el crontab de l'usuari.

> ⚠️ **Consell d'Or:** Els scripts executats per cron no tenen un terminal gràfic obert ni variables d'entorn d'usuari (`$PATH` és molt reduït). Per això és fonamental utilitzar **rutes absolutes** per als binaris (ex: `/usr/bin/python3` en lloc de `python3`) i redirigir sempre els errors al fitxer de registre amb `>> fitxer.log 2>&1`.

## 2. El Programador de Tasques de Windows (Task Scheduler)

En Microsoft Windows l'eina equivalent és el **Programador de Tasques** (`taskschd.msc`). És un servei visual molt potent que permet llançar tasques basades en temps o en esdeveniments del sistema.

### Estructura d'una Tasca en Windows
Una tasca es compon de quatre pestanyes fonamentals:
1. **General:** Nom de la tasca, compte d'usuari sota el qual s'executarà (per exemple el compte de màxims privilegis `SYSTEM`) i la casella *"Executa tant si l'usuari ha iniciat la sessió com si no"*, així com *"Executa amb els privilegis més alts"*.
2. **Desencadenadors (Triggers):** La condició d'arrancada. Pot ser:
   - Segons una programació horària (diària, setmanal, mensual).
   - En iniciar el sistema (abans que cap usuari entre).
   - En iniciar sessió un usuari específic.
   - En produir-se un esdeveniment concret al Visor d'Esdeveniments (per exemple, si es registra un error de xarxa amb un ID determinat).
3. **Accions (Actions):** Què ha de fer la tasca. Normalment *"Inicia un programa"*.
   - Si és un script PowerShell: Programa `powershell.exe`, Arguments: `-ExecutionPolicy Bypass -File "C:\Scripts\manteniment.ps1"`.
   - Si és un fitxer per lots: `C:\Scripts\neteja.bat`.
4. **Condicions i Configuració:** Permet estipular que la tasca només s'execute si l'ordinador no està utilitzant la bateria, o aturar-la forçosament si triga més de 2 hores.

### Automatització amb PowerShell: Mòdul `ScheduledTasks`
```powershell
# Crear el desencadenador (cada dia a les 02:00)
$trigger = New-ScheduledTaskTrigger -Daily -At 2am

# Crear l'acció (executar un script PowerShell)
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-File C:\Scripts\backup.ps1"

# Registrar la tasca al sistema amb privilegis d'administrador
Register-ScheduledTask -TaskName "CòpiaSeguretatSMX" -Trigger $trigger -Action $action -User "SYSTEM" -RunLevel Highest
```
