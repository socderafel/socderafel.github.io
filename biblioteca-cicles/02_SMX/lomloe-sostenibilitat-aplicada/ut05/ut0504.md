Per a estructurar el compromís ecològic d'una organització de manera metòdica i contrastable davant de tercers, existeixen els **Sistemes de Gestió Ambiental (SGA)**. Un SGA és un conjunt de polítiques, procediments, registres i controls operatius que permeten a una empresa identificar els seus impactes ambientals, complir la legislació vigent i millorar contínuament el seu comportament ecològic.

Els dos marcs de referència indiscutibles a escala internacional i europea són la **Norma ISO 14001** i el **Reglament EMAS**.

---

## 1. El Cicle de Millora Contínua Deming (PDCA) a la ISO 14001

La norma internacional **UNE-EN ISO 14001** es basa en el conegut cicle de millora contínua **PDCA (Plan - Do - Check - Act)**:

```
        +-------------------------------------------+
        |  1. PLANIFICAR (Plan)                     |
        |  Identificar aspectes ambientals (consum  |
        |  elèctric de servidors, residus RAEE) i   |
        |  definir objectius de reducció concrets.  |
        +---------------------+---------------------+
                              |
                              v
        +-------------------------------------------+
        |  2. FER / IMPLEMENTAR (Do)                |
        |  Formar els tècnics, aplicar protocols de |
        |  reparació i contractar energia verda.    |
        +---------------------+---------------------+
                              |
                              v
        +-------------------------------------------+
        |  3. VERIFICAR / REVISAR (Check)           |
        |  Mesurar mètriques reals mitjançant       |
        |  auditories ambientals internes periòdiques.|
        +---------------------+---------------------+
                              |
                              v
        +-------------------------------------------+
        |  4. ACTUAR / AJUSTAR (Act)                |
        |  Corregir desviacions i establir metes    |
        |  encara més ambicioses per a l'any vinent.|
        +-------------------------------------------+
```

---

## 2. Comparativa entre ISO 14001 i el Reglament EMAS

| Característica | Norma ISO 14001 | Reglament Europeu EMAS (*Eco-Management and Audit Scheme*) |
| :--- | :--- | :--- |
| **Abast Geogràfic** | Internacional / Global (mundial). | Unió Europea (i països associats). |
| **Nivell d'Exigència** | Exigeix compromís de millora contínua del sistema de gestió. | **Més exigent:** exigeix demostrar una millora contínua del **rendiment ambiental real** mesurable. |
| **Transparència Pública** | No és obligatori publicar dades ambientals al públic extern. | **Obligatori:** s'ha de redactar i publicar anualment una **Declaració Ambiental pública** validada per un verificador independent acreditat. |
| **Participació dels Treballadors**| Recomanada. | **Preceptiva:** s'ha d'involucrar activament el personal en les comissions de sostenibilitat. |
