En el món financer, corporatiu i de contractació pública actual, les empreses ja no s'avaluen únicament pel seu balanç de comptes o els seus beneficis nets. L'estàndard dominant d'inversió i avaluació de riscos són els **Criteris ESG** (en anglès *Environmental, Social, and Governance* / en català **ASG: Ambiental, Social i Governança**).

Una empresa informàtica amb una puntuació ESG baixa té dificultats per a aconseguir crèdits bancaris, queda exclosa de concursos públics de l'administració i és rebutjada pels clients corporatius de primer nivell.

---

## 1. Els Tres Eixos dels Criteris ESG en el Sector Informàtic

```
+-----------------------------------------------------------------------------------+
| ELS TRES PILARS ESG APLICATS A UNA EMPRESA DE SISTEMES I XARXES                   |
+-------------------+---------------------------------------------------------------+
| Pilar             | Indicadors i Pràctiques Exigibles                             |
+-------------------+---------------------------------------------------------------+
| E: AMBIENTAL      | - Petjada de carboni d'Abast 1, 2 i 3 calculada i auditada.   |
| (Environmental)   | - Ràtio d'energia renovable en la infraestructura.            |
|                   | - Taxa de reciclatge i rebuig zero de RAEE a abocador.        |
+-------------------+---------------------------------------------------------------+
| S: SOCIAL         | - Drets laborals, equitat salarial i conciliació familiar.    |
| (Social)          | - Prevenció de riscos ergonòmics (PVD) i salut mental.        |
|                   | - Traçabilitat de drets humans en proveïdors de components.   |
|                   | - Protecció rigorosa de la privadesa dels usuaris (RGPD).     |
+-------------------+---------------------------------------------------------------+
| G: GOVERNANÇA     | - Transparència fiscal i tolerància zero amb la corrupció.    |
| (Governance)      | - Diversitat i paritat en els òrgans de direcció.             |
|                   | - Canals ètics de denúncia interna (*Whistleblowing*).         |
|                   | - Publicació d'Estats d'Informació No Financera (EINF).       |
+-------------------+---------------------------------------------------------------+
```

---

## 2. La Directiva Europea de Report de Sostenibilitat (CSRD)

La directiva comunitària **CSRD** obliga a estandarditzar la publicació d'aquests indicadors mitjançant els estàndards **ESRS (European Sustainability Reporting Standards)**:
- S'acaba l'època en què cada empresa publicava un fullet publicitari amb fotos d'arbres.
- Les dades ESG s'han d'auditar per un censor de comptes independent amb el mateix rigor legal que els balanços econòmics anuals.
