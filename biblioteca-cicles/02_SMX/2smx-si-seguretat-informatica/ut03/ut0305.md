# 3.5 Permisos en Sistemes de Fitxers: NTFS vs. POSIX/ACLs

La implementació pràctica del control d'accés lògic es concreta en el **sistema de fitxers** del disc dur. Segons el sistema operatiu s'utilitzen models d'assignació diferents: permisos **NTFS** a Windows i permisos **POSIX / ACLs** a Linux.

---

## 1. Permisos NTFS a Windows (Llistes de Control d'Accés - ACL)

A NTFS, cada fitxer o carpeta posseeix una **Llista de Control d'Accés de Seguretat (DACL)** formada per múltiples entrades (**ACE**).

### A. Tipus de Permisos Estàndard NTFS
1. **Lectura (*Read*):** Veure contingut de fitxers i llistar el directori.
2. **Escriptura (*Write*):** Modificar el contingut de fitxers i afegir nous arxius a la carpeta.
3. **Lectura i execució (*Read & Execute*):** Llegir i a més executar programes binaris o scripts.
4. **Modificació (*Modify*):** Inclou lectura, escriptura i **eliminació** de fitxers.
5. **Control Total (*Full Control*):** Tots els anteriors més la capacitat de **canviar els permisos d'accés** i prendre possessió del fitxer.

### B. Regles Fonamentals d'Avaluació NTFS
- **La Denegació Explícita mana sobre la Permissió:** Si un usuari pertany al grup `Professors` (que té permís de lectura) però també està al grup `Rebutjats` (amb denegació explícita de lectura), **preval la denegació i no podrà accedir**.
- **Herència de permisos:** Per defecte, els fitxers i subcarpetes hereten els permisos de la seua carpeta mare superior. L'administrador pot trencar l'herència (*Disable inheritance*) quan desitja crear una carpeta privada.
- **Permisos Acumulatius:** Si un usuari té permís de Lectura individual i pertany a un grup amb permís d'Escriptura, el permís efectiu és **Lectura + Escriptura**.

---

## 2. Permisos Tradicionals POSIX a GNU/Linux

En sistemes Linux clàssics, cada fitxer o directori té assignat:
- Un **Propietari (*Owner/User - u*)**
- Un **Grup propietari (*Group - g*)**
- La resta del món (**Altres / *Others - o*)**

Per a cada entitat s'atorguen tres bits de permís:
- **Lectura ($r$ = 4):** Llegir el fitxer o llistar els elements d'un directori (`ls`).
- **Escriptura ($w$ = 2):** Modificar el fitxer o crear/esborrar fitxers a l'interior del directori.
- **Execució ($x$ = 1):** Executar un programa o binari; en un directori significa poder **entrar-hi** (`cd`).

```bash
# Exemple: -rwxr-xr-- (754)
# Propietari: rwx (4+2+1 = 7)
# Grup: r-x (4+0+1 = 5)
# Altres: r-- (4+0+0 = 4)
chmod 750 /var/dades-privades
chown pepe:professors /var/dades-privades
```

---

## 3. Llistes de Control d'Accés Avançades a Linux (POSIX ACLs)

Quan el model clàssic `u:g:o` és insuficient (perquè volem concedir permís a un segon usuari o a un altre grup sense canviar el grup principal), s'utilitzen les **ACLs de Linux**:

```bash
# Consultar les ACLs d'un fitxer
getfacl /var/dades/informe.pdf

# Concedir permís de lectura i escriptura a l'usuari 'marta'
setfacl -m u:marta:rw /var/dades/informe.pdf

# Concedir permís de lectura al grup 'comptabilitat'
setfacl -m g:comptabilitat:r /var/dades/informe.pdf

# Eliminar totes les ACLs personalitzades
setfacl -b /var/dades/informe.pdf
```
