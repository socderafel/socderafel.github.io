# 4.3 Automatització de Còpies de Seguretat amb rsync i cron

Una política de còpies de seguretat no és efectiva si depèn de la memòria o intervenció manual d'un tècnic humà. Als servidors Linux, l'estàndard professional per a la sincronització diferencial de dades és la utilitat **`rsync`**, combinada amb el planificador de tasques **`cron`**.

---

## 1. La Utilitat `rsync` (Remote Sync)

`rsync` utilitza un algorisme de sincronització diferencial delta que només transmet a través de la xarxa els blocs binaris que han canviat dins d'un fitxer, estalviant fins a un 95% d'ample de banda:

```bash
# Sincronització bàsica local amb paràmetres d'arxiu i neteja
sudo rsync -avzh --delete /var/www/html/ /mnt/backup/web_html/
```

- **`-a` (*archive*):** Mode arxiu equivalent a `-rlptgoD`. Preserva de forma recursiva permisos, propietaris, grups, marques de temps i enllaços simbòlics.
- **`-v` (*verbose*):** Mostra els fitxers que es van sincronitzant en pantalla.
- **`-z` (*compress*):** Comprimeix les dades durant la transferència de xarxa.
- **`-h` (*human-readable*):** Mostra mides en KB, MB o GB.
- **`--delete`:** Elimina a la destinació aquells fitxers que han estat esborrats a l'origen, mantenint un espill exacte.

### Sincronització Remota Xifrada sobre SSH:
```bash
# Copiar les dades cap a un servidor de backup remot
rsync -avz -e "ssh -p 2222" /home/usuaris/ backup_admin@192.168.10.99:/backup/
```

---

## 2. Automatització de Tasques amb `cron`

El dimoni `cron` executa comandes i scripts en segon pla segons un calendari programat. Es configura mitjançant fitxers `crontab`:

```bash
# Editar la taula de tasques de l'administrador root
sudo crontab -e
```

### Sintaxi dels 5 Camps Temporals de crontab:
```
┌───────────── Minut (0 - 59)
│ ┌─────────── Hora (0 - 23)
│ │ ┌───────── Dia del mes (1 - 31)
│ │ │ ┌─────── Mes de l'any (1 - 12)
│ │ │ │ ┌───── Dia de la setmana (0 - 7, on 0 i 7 són Diumenge)
│ │ │ │ │
* * * * * [ordre a executar]
```

### Exemples Corporatius de Programació de Backups:
```bash
# Executar un backup diferencial cada nit de dilluns a divendres a les 23:30 h
30 23 * * 1-5 /opt/scripts/backup_diferencial.sh >> /var/log/backup.log 2>&1

# Executar una còpia completa tots els diumenges a les 02:00 de la matinada
00 02 * * 0 /opt/scripts/backup_complet.sh >> /var/log/backup_full.log 2>&1
```
