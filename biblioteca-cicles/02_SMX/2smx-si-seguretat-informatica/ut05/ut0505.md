# 5.5 Bastionat del Sistema Operatiu (OS Hardening)

El **Bastionat (*Hardening*)** és el procés sistemàtic de configuració i assegurament d'un sistema informàtic amb l'objectiu de **reduir al mínim possible la seua superfície d'atac**, eliminant punts febles, vulnerabilitats potencials i serveis innecessaris que venen activats per defecte.

---

## 1. Principis Fonamentals de Bastionat

```
                           OS Hardening
     ┌───────────────────────────┼───────────────────────────┐
     ▼                           ▼                           ▼
Minimització                 Pegats de                   Polítiques de
de Serveis                   Seguretat                     Auditoria
 (Tancar ports)          (Gestió de CVEs)              (Syslog / Lynis)
```

1. **Minimització de Serveis i Protocols:**
   - Si una màquina és un servidor de base de dades, **no ha de tindre instal·lat ni actiu un servidor web Apache, ni impressió CUPS, ni jocs, ni interfície gràfica pesada**.
   - Cada servei addicional afegeix milers de línies de codi i possibles vulnerabilitats.
   - Desactivar protocols insegurs antics que transmeten en text pla (Telnet, FTP sense xifrar, HTTP sense TLS, SMBv1).
2. **Gestió Periòdica de Pegats i Actualitzacions:**
   - La immensa majoria d'intrusions aprofiten fallades de seguretat conegudes (**CVE** - *Common Vulnerabilities and Exposures*) per a les quals el fabricant ja havia publicat un pegat mesos abans.
   - A Ubuntu/Debian: configurar actualitzacions de seguretat automàtiques amb `unattended-upgrades`.
3. **Restricció del Compte Superusuari (*root* / *Administrador*):**
   - Deshabilitar el login remot directe per SSH com a `root` (`PermitRootLogin no` a `/etc/ssh/sshd_config`).
   - Forçar l'ús de claus criptogràfiques asimètriques en comptes de contrasenyes per a administració remota.
4. **Protecció de la Memòria i el Kernel:**
   - Habilitar mecanismes d'espai d'adreces aleatori (**ASLR**) i bit de no execució de dades (**DEP / NX**).

---

## 2. Eines d'Auditoria de Bastionat: Lynis

**Lynis** és una eina d'auditoria de codi obert per a sistemes Unix/Linux que avalua exhaustivament les defenses del sistema contra els estàndards CIS (*Center for Internet Security*):

```bash
# Instal·lar i executar una auditoria completa del sistema
sudo apt install -y lynis
sudo lynis audit system
```

Lynis analitza més de 300 paràmetres de seguretat (gestió d'arrencada, permisos de fitxers sensibles com `/etc/shadow`, configuració de SSH, regles de tallafocs) i genera una qualificació numèrica (**Hardening Index**) juntament amb recomanacions concretes de correcció.
