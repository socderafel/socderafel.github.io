# 5.4 Desplegament d'Antivirus en Linux amb ClamAV

Tot i que els sistemes GNU/Linux gaudeixen d'un model de seguretat robust basat en permisos i aïllament d'usuaris, **no són immunes al programari maliciós**. A més, els servidors Linux que actuen com a servidors de fitxers compartits (Samba / NFS) o passarel·les de correu electrònic (Postfix) tenen la responsabilitat d'evitar transmetre fitxers infectats als clients Windows de la xarxa.

**ClamAV** (*Clam AntiVirus*) és el motor antivirus de codi obert de referència internacional en entorns de servidor.

---

## 1. Instal·lació i Gestió de Signatures amb `freshclam`

En Debian i Ubuntu Server:

```bash
sudo apt update
sudo apt install -y clamav clamav-daemon
```

- **`freshclam`:** El dimoni encarregat de connectar-se periòdicament als servidors oficials per a descarregar les últimes bases de dades de signatures de malware (`main.cvd` i `daily.cvd` a `/var/lib/clamav/`):
  ```bash
  # Actualitzar manualment la base de dades de signatures
  sudo systemctl stop clamav-freshclam
  sudo freshclam
  sudo systemctl start clamav-freshclam
  ```

---

## 2. Escaneig de Sistema amb `clamscan`

La utilitat per línia d'ordres `clamscan` permet auditar directoris concrets:

```bash
# Sintaxi bàsica recomanada:
sudo clamscan -r -i --bell /home/usuaris/
```

- **`-r` (*recursive*):** Escaneja recursivament totes les subcarpetes.
- **`-i` (*infected*):** Mostra en pantalla únicament els fitxers detectats com a infectats, ignorant els sans per a evitar pantalles plenes de línies innecessàries.
- **`--bell`:** Emet un xiulet sonor si localitza una amenaça.
- **`--move=/var/quarantine/`:** Mou automàticament els fitxers infectats a una carpeta de quarantena aïllada per a la seua anàlisi forense posterior.

```
----------- SCAN SUMMARY -----------
Known viruses: 8685124
Engine version: 1.0.5
Scanned directories: 48
Scanned files: 312
Infected files: 1
Data scanned: 142.50 MB
Time: 4.825 sec (0 m 4 s)
```

---

## 3. Automatització mitjançant el Dimoni `clamd`

Per a un escaneig d'alt rendiment en producció s'utilitza **`clamdscan`**, que comunica amb el dimoni en memòria `clamav-daemon`, evitant recarregar els més de 8 milions de signatures a la memòria RAM en cada escaneig i reduint el temps d'anàlisi de minuts a uns pocs segons.
