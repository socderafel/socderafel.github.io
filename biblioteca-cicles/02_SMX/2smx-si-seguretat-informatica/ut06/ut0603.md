# 6.3 Funcions Resum Criptogràfiques (Hash)

Una **Funció Resum Criptogràfica (*Hash*)** és un algorisme matemàtic que pren com a entrada una quantitat arbitrària de dades (des d'una sola lletra fins a una imatge ISO de 50 GB) i produeix com a eixida una cadena de longitud fixa anomenada **resum (*hash* o *digest*)**.

---

## 1. Propietats Fonamentals d'un Hash Segur

```
[Qualsevol dada d'entrada] ──► [Funció Hash H(x)] ──► [Resum de longitud fixa]
(1 caràcter o 10 GB)                                    (Ex: 256 bits SHA-256)
```

1. **Unidireccionalitat (*One-Way*):** És computable ràpidament en el sentit d'anada ($y = H(x)$), però és matemàticament impossible deduir el missatge original $x$ a partir del resum $y$.
2. **Determinisme:** Un mateix missatge generarà sempre, sense excepció, el mateix valor hash exacte.
3. **Efecte Allau (*Avalanche Effect*):** Canviar un únic bit o una coma en el document d'entrada fa que el valor del hash resultant canvie de manera radical i impredictible en més del 50% dels seus dígits.
4. **Resistència a Col·lisions:** Ha de ser computacionalment inviable trobar dos documents diferents $x_1 \neq x_2$ que produïsquen exactament el mateix hash $H(x_1) = H(x_2)$.

---

## 2. Estat dels Algorismes Hash

| Algorisme | Mida del Resum | Estat de Seguretat | Ús Actual |
| :--- | :---: | :--- | :--- |
| **MD5** | 128 bits (32 hex) | **Trencat criptogràficament.** S'han demostrat col·lisions pràctiques en segons. | Desaconsellat per a seguretat. Només vàlid per a sumes de comprovació d'errors accidentals. |
| **SHA-1** | 160 bits (40 hex) | **Vulnerable / Obsolet.** Es van generar col·lisions (atac SHAttered de Google el 2017). | Desterrat de certificats digitals i navegadors web. |
| **SHA-256 (SHA-2)** | **256 bits (64 hex)** | **Estàndard d'alta seguretat.** Inexpugnable en l'actualitat. | Certificats SSL/TLS, signatures digitals, verificació d'ISOs i tecnologia Blockchain. |
| **SHA-512 (SHA-2)** | **512 bits (128 hex)** | **Màxima robustesa.** | Sistemes governamentals i d'intel·ligència. |
| **SHA-3 (Keccak)** | Variable (224 a 512) | **L'estàndard d'última generació del NIST.** Disseny basat en construcció d'esponja. | Criptografia post-quàntica i protocols d'avantguarda. |

---

## 3. Verificació d'Integritat Pràctica

En descarregar una distribució Linux o paquet de programari:

```bash
# Calcular el hash SHA-256 a GNU/Linux
sha256sum ubuntu-24.04-live-server.iso

# Comprovar automàticament amb un fitxer de sumes SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
```

A Windows mitjançant PowerShell:
```powershell
Get-FileHash .\ubuntu-24.04-live-server.iso -Algorithm SHA256
```
