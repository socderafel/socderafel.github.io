# 6.5 Seguretat Perimetral i Tallafocs (UFW i Wireshark)

La **Seguretat Perimetral** controla i filtra tot el flux de tràfic que travessa la frontera entre la xarxa local corporativa (de confiança) i xarxes externes no confiables (com Internet). L'element de control per excel·lència és el **Tallafocs (*Firewall*)**.

---

## 1. Zones de Seguretat i Arquitectura DMZ

```
   [INTERNET] (No confiable)
        │
        ▼
   [TALLAFOCS PERIMETRAL]
        ├─────────────────────────────┐
        ▼                             ▼
   [ZONA DMZ / Desmilitaritzada]  [XARXA LOCAL INTERNA / LAN]
   - Servidor Web (80/443)        - Estacions de treball
   - Servidor de Correu (25)      - Servidors de bases de dades
   - Servidor DNS públic          - Controladors de Domini
```

- **Zona Desmilitaritzada (DMZ):** Una xarxa aïllada situada entre el tallafocs i la xarxa interna. S'hi allotgen els servidors que han de prestar servei al públic des d'Internet.
- **Principi de seguretat de la DMZ:** Si un atacant aconsegueix vulnerar el servidor web de la DMZ, el tallafocs **li impedeix saltar cap a la xarxa interna** on resideixen les bases de dades i estacions d'usuaris.

---

## 2. Tipologies de Tallafocs i Tallafocs d'Estat (*Stateful*)

1. **Filtratge de Paquets Estàtic (Capa 3 i 4 OSI):** Examina cada paquet de forma aïllada segons la IP d'origen/destinació i el port TCP/UDP.
2. **Tallafocs d'Inspecció d'Estat (*Stateful Inspection*):** Manté una taula en memòria de totes les connexions actives. Reconeix si un paquet entrant és la **resposta legítima** a una petició prèvia iniciada per un usuari de la xarxa interna (estat `ESTABLISHED`), permetent-lo automàticament sense obrir el port a tothom.

---

## 3. Gestió Pràctica de Tallafocs a Linux amb UFW

A Ubuntu i Debian, **UFW** (*Uncomplicated Firewall*) gestiona les regles de filtratge del kernel de forma senzilla:

```bash
# 1. Política per defecte: Bloquejar tot el tràfic entrant, permetre tot l'eixint
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 2. Permetre administració remota SSH només des d'una subxarxa d'administració
sudo ufw allow from 192.168.10.0/24 to any port 22 proto tcp

# 3. Permetre tràfic web públic
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 4. Habilitar el tallafocs i comprovar l'estat numerat
sudo ufw enable
sudo ufw status numbered
```

---

## 4. Diagnòstic de Xarxa amb Wireshark

Wireshark permet capturar i analitzar els paquets en trànsit per a descobrir intents d'intrusió o fugides de dades:
- **Filtres de captura útils:**
  - `tcp.flags.syn == 1 and tcp.flags.ack == 0`: Detecta escanejos massius de ports (atacs SYN Flood o Nmap).
  - `http.request.method == "POST"`: Inspecciona formularis d'inici de sessió que transmeten en text pla.
  - `ip.addr == 192.168.10.50`: Analitza tot el tràfic entrant i eixint d'un equip sospitós d'infecció.
