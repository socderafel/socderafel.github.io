# 7.2 Mapejat d'unitats de xarxa en Windows

En lloc d'haver d'escriure cada vegada la ruta de xarxa del servidor, els sistemes Windows permeten **connectar o mapejar una unitat de xarxa**, assignant-li una **lletra de disc local** (com ara `Z:` o `S:`) que apareix directament a l'Explorador d'Arxius al costat del disc dur `C:`.

---

## La Notació de Rutes UNC (*Universal Naming Convention*)

Per accedir a un recurs compartit sense unitat de xarxa mapejada s'utilitzen rutes UNC amb dues barres invertides:
```
\\nom_del_servidor\nom_del_recurs_compartit
o també per adreça IP:
\\192.168.1.10\dades_alumnat
```

---

## Com es mapeja una unitat de xarxa pas a pas
1. Obre l'**Explorador d'Arxius** de Windows i fes clic a **Aquest equip**.
2. Al menú superior (o amb clic dret a "Aquest equip"), selecciona **Connecta a una unitat de xarxa...**.
3. **Tria una lletra d'unitat lliure:** Per exemple `Z:` per a la carpeta de projectes.
4. **Introdueix la carpeta:** Escriu la ruta UNC, per exemple `\\192.168.1.10\projectes`.
5. **Marca la casella:** *Torna a connectar en iniciar la sessió* (perquè cada vegada que l'alumne encenga l'ordinador, la unitat `Z:` torne a aparèixer automàticament).
6. Fes clic a **Finalitzar**. Si el servidor ho demana, introdueix l'usuari i la clau de xarxa.
