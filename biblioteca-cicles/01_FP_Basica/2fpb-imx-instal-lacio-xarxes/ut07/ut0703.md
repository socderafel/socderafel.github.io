# 7.3 Instal·lació i compartició d'impressores de xarxa

En entorns d'oficina i centres educatius, les impressores i equips multifunció làser es comparteixen per la xarxa local per evitar haver de comprar una impressora individual per a cada taula de treball.

---

## Els Dos Mètodes d'Instal·lació d'Impressores de Xarxa

```
MÈTODE A: IMPRESSORA AMB TARGETA DE XARXA PRÒPIA (EL RECOMENAT)
[ PC 1 ] ----+
[ PC 2 ] ----+---> [ SWITCH ] =======( Cable RJ-45 / IP Pròpia )=======> [ IMPRESSORA DE XARXA ]
[ PC 3 ] ----+                                                              (Funciona sempre!)

MÈTODE B: IMPRESSORA COMPARTIDA DES D'UN EQUIP AMFITRIÓ
[ PC 1 ] ----+---> [ SWITCH ] ----> [ PC PROFESSOR (AMFITRIÓ) ] --(USB)--> [ IMPRESSORA USB ]
                                       (Si s'apaga el PC, ningú més pot imprimir!)
```

1. **Impressora de Xarxa Autònoma (Mètode recomanat):**
   - Incorpora la seua pròpia targeta de xarxa Ethernet (port RJ-45) o Wi-Fi.
   - Té la seua **pròpia adreça IP fixa** (per exemple `192.168.1.200`).
   - Funciona de manera completament autònoma: qualsevol ordinador pot imprimir encara que la resta d'ordinadors de l'aula estiguen apagats.
2. **Impressora compartida per USB:**
   - La impressora es connecta per cable USB a un ordinador mestre (*host*). Des de les opcions de Windows es fa clic a "Comparteix aquesta impressora".
   - **Inconvenient greu:** Si l'usuari apaga el seu ordinador, ningú més de la classe pot imprimir.
