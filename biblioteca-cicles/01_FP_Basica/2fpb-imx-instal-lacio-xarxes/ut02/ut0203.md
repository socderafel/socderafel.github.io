# 2.3 Eines de taller per a cablejat de dades

Per realitzar instal·lacions professionals de cablejat de parell trenat, el tècnic o tècnica de xarxes disposa d'un maletí d'eines específiques:

```
        LES 5 EINES BÀSIQUES DEL MALETÍ DE XARXES
+--------------------+--------------------+--------------------+
| 1. PELACABLES      | 2. GRIMPADORA      | 3. PUNXADORA KRONE |
|    ROTATIU         |    RJ-45           |    D'IMPACTE       |
| Pela la coberta    | Fixa els pins      | Insereix fils a    |
| sense danyar coure | metàl·lics als     | rosetes i panells  |
|                    | conductors         | de pegat           |
+--------------------+--------------------+--------------------+
| 4. ALICATES DE     | 5. TESTER DE       |                    |
|    TALL RECTE      |    XARXA RJ-45     |                    |
| Anivella els 8     | Comprova LED a     |                    |
| fils a 13 mm       | LED la continuïtat |                    |
+--------------------+--------------------+--------------------+
```

### 1. Pelacables circular rotatiu
- Disposa d'una roda o ganxo amb ressort i una fulla amb profunditat regulable.
- Permet tallar netament la coberta plàstica exterior (PVC o LSZH) del cable fent-lo girar una volta, **sense marcar ni tallar l'aïllant dels 8 fils interiors de coure**.

### 2. Grimpadora de xarxa (*Crimping Tool*)
- Eina metàl·lica amb mordasses especials per a connectors RJ45 (8P8C) i sovint RJ11 (telefonia).
- En prémer la palanca fins al fons:
  - Empeny els 8 pins metàl·lics daurats per perforar l'aïllant de plàstic i clavar-se en el coure.
  - Acciona la pestanya de plàstic posterior que aprisiona la coberta exterior del cable perquè no es puga soltar per estirades accidentals.

### 3. Eina d'inserció o punxadora d'impacte (Tipus Krone / 110)
- S'utilitza exclusivament per a connectar els fils als connectors femella **Keystone** de les rosetes de paret i als **Patch Panels** del rack.
- En prémer cap a baix, la fulla empeny el fil dins de la ranura de contacte per desplaçament d'aïllant (IDC) i, al mateix cop d'impacte, **talla automàticament l'extrem sobrant de coure**.

### 4. Comprovador de cablejat o Tester de xarxa RJ-45
- Consta de dos mòduls: la unitat principal emissora (*Master*) i la unitat remota (*Remote*).
- Disposa d'una escala de 8 llums LED numerats de l'1 al 8 (més un LED 'G' per a terra/blindatge).
- Engega un corrent de prova pin a pin: si el cable està perfectament construït, els LEDs s'encenen en ordre seqüencial (1-2-3-4-5-6-7-8) tant a l'emissor com al receptor.
