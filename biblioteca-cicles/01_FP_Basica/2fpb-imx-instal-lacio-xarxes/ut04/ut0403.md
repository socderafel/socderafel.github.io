# 4.3 Encaminadors (Routers): interconnexió de xarxes i porta d'enllaç

Mentre que el commutador (Switch) s'encarrega d'unir ordinadors que comparteixen la mateixa xarxa local, l'**encaminador** o **router** és el dispositiu intel·ligent de **Capa 3 (Xarxa/Internet)** que té com a missió fonamental **unir xarxes diferents entre si** i trobar el millor camí perquè els paquets de dades viatgen cap a la seua destinació final.

---

## Les 3 Funcions Clau d'un Router

```
     XARXA LOCAL D'AULA (LAN)                        XARXA EXTERIOR (WAN)
   [PC 1] [PC 2] [PC 3] [PC 4]                             INTERNET
        \    |    |    /                                     ^
       +-----------------+                                    |
       |  SWITCH D'AULA  |                                    |
       +-----------------+                                    |
                | (Cable UTP)                                 | (Fibra Òptica)
                v                                             v
        +-------------------------------------------------------------+
        |                 ENCAMINADOR / ROUTER (CAPA 3)               |
        |  - IP LAN (Porta d'Enllaç): 192.168.1.1                     |
        |  - IP WAN (Pública d'Internet): 84.123.45.67                |
        |  - Mecanisme NAT (Traducció d'adreces)                      |
        +-------------------------------------------------------------+
```

### 1. Interconnexió i Enrutament de Paquets
- El router té com a mínim dues interfícies de xarxa:
  - **Interfície LAN:** Connectada a la xarxa local de l'aula (ex: IP `192.168.1.1`).
  - **Interfície WAN:** Connectada cap a l'exterior (proveïdor de fibra òptica o xarxa troncal).
- Disposa d'una **taula d'enrutament**: quan arriba un paquet, llegeix la IP de destinació i decideix per quina línia d'eixida ha d'enviar-lo per arribar al següent router més proper.

### 2. Porta d'Enllaç Predeterminada (*Default Gateway*)
- Perquè el teu ordinador d'aula puga accedir a Internet (ex: veure un vídeo a YouTube o obrir el correu), ha de conèixer la IP del router local.
- Aquesta IP s'anomena **Porta d'Enllaç Predeterminada (*Default Gateway*)**. Qualsevol paquet dirigit a una IP que no pertanga a l'aula s'envia automàticament a la porta d'enllaç perquè el router el traga a l'exterior.

### 3. Traducció d'adreces NAT (*Network Address Translation*)
- Com que a l'aula s'utilitzen adreces IP privades (`192.168.1.X`), aquestes no poden circular directament per Internet.
- El router fa de frontera màgica: tradueix les IPs privades de tots els ordinadors de la classe en **una única adreça IP pública oficial** quan els paquets ixen a Internet, i recorda a quin ordinador ha de tornar cada resposta quan arriba de fora.
