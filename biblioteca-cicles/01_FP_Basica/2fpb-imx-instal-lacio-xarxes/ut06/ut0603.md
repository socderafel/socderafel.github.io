# 6.3 Servidors DNS i servei d'assignació automàtica DHCP

Perquè els usuaris puguen navegar còmodament per Internet sense haver de configurar a mà cadascun dels paràmetres de xarxa, existeixen dos serveis automàtics imprescindibles: el protocol **DHCP** i el sistema de noms de domini **DNS**.

---

## El Protocol DHCP (*Dynamic Host Configuration Protocol*)

Configurar manualment la IP, la màscara, la porta d'enllaç i els servidors DNS a 30 ordinadors d'una aula és lent i susceptible d'errors (com ara repetir sense voler la mateixa IP a dos equips, provocant un **conflicte d'IPs**).
- **El servei DHCP s'encarrega d'automatitzar-ho:**
  - El router de taller o el servidor del centre té activat un servidor DHCP amb un rang d'adreces lliures (*Pool* d'IPs, per exemple de la `192.168.1.100` a la `192.168.1.200`).
  - Quan un ordinador o mòbil s'encén i es connecta a la xarxa, envia una petició i en menys d'un segon rep una IP lliure durant un temps determinat (*Lease time*).

```
                      EL PROCÉS D'ASSIGNACIÓ DHCP (DORA)
1. DISCOVER  : El PC envia en difusió: "Hola! Sóc nou a la xarxa, algú em dóna una IP?"
2. OFFER     : El Router DHCP contesta: "Tinc lliure la IP 192.168.1.105, la vols?"
3. REQUEST   : El PC demana: "Perfecte, assigna'm la 192.168.1.105 per favor."
4. ACK       : El Router confirma: "Fet! La 192.168.1.105 és teua durant 24 hores."
```

---

## El Servidor DNS (*Domain Name System*)

Els ordinadors i servidors només entenen d'adreces numèriques IP (com ara `142.250.200.67`), però per als éssers humans és molt més fàcil recordar paraules com `www.google.es` o `aules.edu.gva.es`.
- **Funció del DNS:** És la **guia telefònica d'Internet**. Quan escrius un nom de domini al navegador, el teu PC interroga al servidor DNS configurat i aquest li respon amb la IP exacta del servidor web destinatari.

### Servidors DNS públics més ràpids i utilitzats:
- **Google DNS:** `8.8.8.8` (primari) i `8.8.4.4` (secundari).
- **Cloudflare DNS:** `1.1.1.1` (primari) i `1.0.0.1` (secundari).
- **Conselleria d'Educació:** Servidors DNS corporatius de la Generalitat Valenciana assignats per DHCP a la xarxa del centre.
