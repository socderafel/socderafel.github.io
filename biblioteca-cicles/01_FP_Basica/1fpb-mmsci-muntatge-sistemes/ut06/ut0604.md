# 6.4 Connexió física i gestió de controladors (drivers)

Un perifèric connectat físicament a l'ordinador és completament inútil si el sistema operatiu no sap com comunicar-se amb ell. El **controlador de dispositiu (*driver*)** és el programa traductor que fa d'intermediari entre el sistema operatiu (Windows o Linux) i el xip físic del maquinari.

---

## 🛠️ 1. L'Administrador de Dispositius de Windows

L'eina clau per diagnosticar perifèrics i maquinari a Windows és l'**Administrador de Dispositius** (`devmgmt.msc`):

```
  +-- Administrador de Dispositius ------------------------------+
  | > Adaptadors de pantalla (NVIDIA GeForce RTX 4060)           |
  | > Adaptadors de xarxa (Realtek Gaming 2.5GbE Family)         |
  | v Dispositius desconeguts                                    |
  |   [ ! ] Dispositiu base del sistema (Falta controlador!)     |
  |   [ ? ] Dispositiu d'altaveu (Sense controlador d'àudio)     |
  +--------------------------------------------------------------+
```

### Icones d'alerta a l'Administrador de Dispositius:
- **Triangle groc amb signe d'exclamació (!):** El dispositiu s'ha detectat físicament però el seu controlador té errors, no és compatible o està danyat.
- **Interrogant groc (?):** Dispositiu completament desconegut; el sistema no té cap driver instal·lat.
- **Fletxa negra cap avall (🠗):** El dispositiu està manualment **inhabilitat** per l'administrador del sistema.

---

## 🌐 2. On buscar i com instal·lar els controladors oficials?

1. **Web oficial del fabricant del component:** Sempre és la font més fiable (ex: web de suport d'HP, ASUS, Intel, AMD o NVIDIA).
2. **Windows Update:** Descarrega automàticament controladors homologats per Microsoft (WHQL).
3. **Identificadors de maquinari (*Hardware IDs*):** Si tenim un dispositiu desconegut de marca anònima:
   - Fes clic dret ➔ Propietats ➔ pestanya *Detalls* ➔ selecciona *«Identificadors de maquinari»*.
   - Trobaràs una cadena com: `PCI\VEN_10EC&DEV_8168`.
   - **VEN (Vendor ID):** El fabricant (10EC = Realtek).
   - **DEV (Device ID):** El model exacte del xip (8168 = Targeta Ethernet Gigabit).
