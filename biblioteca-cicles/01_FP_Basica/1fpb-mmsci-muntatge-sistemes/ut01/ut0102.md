# 1.2 Corrent continu (DC), corrent altern (AC) i components passius

En electrònica i informàtica conviuen dues formes d'energia elèctrica: el corrent que arriba de la xarxa elèctrica de l'edifici i el corrent que realment necessiten els circuits integrats del nostre ordinador.

---

## 🔄 1. Corrent Altern (AC) vs Corrent Continu (DC)

| Característica | Corrent Altern (AC / CA) | Corrent Continu (DC / CC) |
| :--- | :--- | :--- |
| **Definició** | Els electrons canvien de sentit de circulació periòdicament. | Els electrons circulen sempre en el mateix sentit (del pol negatiu al positiu). |
| **Símbol** | $\sim$ | $=$ o $\underline{\dots}$ |
| **Tensió típica** | $230\text{ V}$ a Espanya (50 Hz de freqüència). | $+12\text{ V}, +5\text{ V}, +3{,}3\text{ V}, +1{,}2\text{ V}$. |
| **Fonts típiques** | Endolls domèstics, xarxa elèctrica general. | Piles, bateries, sortida de la font d'alimentació ATX. |
| **Funció al PC** | Alimenta l'entrada de la font d'alimentació. | Alimenta tots els xips, motors i discs interns. |

> [!IMPORTANT]
> La missió principal de la **font d'alimentació** d'un ordinador és convertir el **corrent altern (230 V AC)** que entra per la paret en **corrent continu net (DC)** amb diferents nivells de tensió (+12 V, +5 V, +3,3 V) adaptats a la placa base i components.

---

## 🎛️ 2. Components Electrònics Passius Bàsics

Un circuit electrònic d'ordinador està compost per components actius (com transistors i xips) i **components passius**, que regulen, emmagatzemen o filtren el senyal elèctric:

### A. Les Resistències (Resistors)
Oposen una resistència fixa al pas del corrent per limitar la intensitat o dividir la tensió.
- **Resistències axials convencionals:** Cos cilíndric amb anells de colors que indiquen el seu valor òhmic.
- **Resistències SMD (Surface Mount Device):** Xicotets blocs rectangulars soldats directament a la superfície de la placa base o targeta gràfica, amb codis numèrics impresos.

---

## 🎨 3. Codi de Colors de les Resistències (4 bandes)

Per llegir una resistència axial de 4 bandes:
1. La **1a banda** indica la primera xifra significativa.
2. La **2a banda** indica la segona xifra significativa.
3. La **3a banda** és el **multiplicador** (potència de 10 o nombre de zeros).
4. La **4a banda** (més separada, normalment d'or o plata) indica la **tolerància** (marge d'error).

| Color | 1a Banda | 2a Banda | Multiplicador | Tolerància |
| :--- | :---: | :---: | :---: | :---: |
| **Negre** | 0 | 0 | $\times 1$ (sense zeros) | - |
| **Marró** | 1 | 1 | $\times 10$ (1 zero) | $\pm 1\%$ |
| **Roig** | 2 | 2 | $\times 100$ (2 zeros) | $\pm 2\%$ |
| **Taronja** | 3 | 3 | $\times 1.000$ (3 zeros) | - |
| **Groc** | 4 | 4 | $\times 10.000$ (4 zeros) | - |
| **Verd** | 5 | 5 | $\times 100.000$ (5 zeros) | $\pm 0{,}5\%$ |
| **Blau** | 6 | 6 | $\times 1.000.000$ | - |
| **Violeta**| 7 | 7 | $\times 10.000.000$ | - |
| **Gris** | 8 | 8 | - | - |
| **Blanc** | 9 | 9 | - | - |
| **Daurat (Or)** | - | - | $\times 0{,}1$ | $\pm 5\%$ |
| **Platejat (Plata)** | - | - | $\times 0{,}01$ | $\pm 10\%$ |

### Exemple de Càlcul de Codi de Colors
Si tenim una resistència amb bandes: **Marró - Negre - Roig - Daurat**:
- Marró = 1
- Negre = 0
- Roig = Multiplicador $\times 100$ (afegir dos zeros)
- Daurat = Tolerància $\pm 5\%$

Valor nominal:
$$R = 10 \times 100 = 1.000\ \Omega = 1\text{ k}\Omega \quad (\pm 5\%)$$
El marge de tolerància serà:
$$1.000 \times 0{,}05 = 50\ \Omega \implies R_{\min} = 950\ \Omega, \quad R_{\max} = 1.050\ \Omega$$

## 🔬 4. Desxifrat de Resistències SMD

Als circuits moderns de plaques base i targetes de vídeo trobem resistències SMD minúscules amb codificació estàndard de 3 dígits:
- Els dos primers dígits són les xifres significatives.
- El tercer dígit és el nombre de zeros a afegir.
- Si apareix la lletra **R**, aquesta funciona com una coma decimal.

| Codi SMD | Desglossament | Valor en Ohms |
| :---: | :---: | :---: |
| **102** | 1, 0, i 2 zeros | $1.000\ \Omega = 1\text{ k}\Omega$ |
| **473** | 4, 7, i 3 zeros | $47.000\ \Omega = 47\text{ k}\Omega$ |
| **220** | 2, 2, i 0 zeros | $22\ \Omega$ |
| **4R7** | 4 coma 7 | $4{,}7\ \Omega$ |
| **0R5** | 0 coma 5 | $0{,}5\ \Omega$ |
| **100** | 1, 0, i 0 zeros | $10\ \Omega$ |

## 🔋 5. Altres Components Passius Fonamentals

- **Condensadors (Capacitors):** Emmagatzemen càrrega elèctrica temporalment per filtrar variacions de tensió i estabilitzar el corrent que arriba a la CPU. A les plaques base s'utilitzen condensadors sòlids d'alumini d'alta durabilitat.
- **Bobines (Inductors / Chokes):** Filtren sorolls elèctrics d'alta freqüència a les fases d'alimentació (VRM) de la placa base.
- **Díodes i LED:** Permeten el pas de corrent en un únic sentit. Els díodes LED emeten llum i indiquen estats (LED d'encesa, activitat del disc dur a la caixa).
