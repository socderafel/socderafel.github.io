# 1.3 Circuits en sèrie, paral·lel i mixtos: Càlculs i aplicació en informàtica

Els components elèctrics d'un sistema informàtic es poden connectar de diferents formes. Comprendre la diferència entre connexions en **sèrie** i en **paral·lel** és fonamental per entendre com es distribueixen la tensió i el corrent elèctric dins del PC.

---

## 🔗 1. Circuits en Sèrie

En un circuit en sèrie, els components estan connectats un darrere de l'altre formant una única cadena, de manera que el mateix flux d'electrons travessa tots els elements de manera consecutiva.

```
       +---[ R1 ]---[ R2 ]---[ R3 ]---+
       |                              |
     ( V ) Font d'alimentació         |
       |                              |
       +------------------------------+
```

### Propietats Fonamentals del Circuit en Sèrie:
1. **Intensitat constant:** El mateix corrent travessa tots els components de la branca:
   $$I_{\text{total}} = I_1 = I_2 = I_3$$
2. **Resistència equivalent (suma directa):** La resistència total és la suma de totes les resistències:
   $$R_{\text{eq}} = R_1 + R_2 + R_3 + \dots$$
3. **Tensió repartida:** La tensió de la font es reparteix proporcionalment segons el valor de cada resistència:
   $$V_{\text{total}} = V_1 + V_2 + V_3$$

> [!WARNING]
> Si un component en sèrie s'avaria o es desconnecta, el circuit queda immediatament **obert** i la resta de components deixen de rebre corrent elèctric (igual que les llums clàssiques d'un arbre de Nadal).

---

## 🔀 2. Circuits en Paral·lel

En un circuit en paral·lel, tots els components comparteixen els mateixos dos punts comuns de connexió: tots els terminals positius van units a la línia positiva i tots els terminals negatius a la línia de massa (GND).

```
          +-------------+-------------+
          |             |             |
         [R1]          [R2]          [R3]
          |             |             |
          +-------------+-------------+
          |                           |
        ( V ) Font d'alimentació      |
          |                           |
          +---------------------------+
```

### Propietats Fonamentals del Circuit en Paral·lel:
1. **Tensió constant:** Tots els components reben exactament la mateixa tensió que la font:
   $$V_{\text{total}} = V_1 = V_2 = V_3$$
2. **Intensitat repartida:** El corrent total de la font és la suma de les intensitats individuals:
   $$I_{\text{total}} = I_1 + I_2 + I_3$$
3. **Resistència equivalent menor:** La resistència equivalent és sempre **menor que la menor de les resistències**:
   $$\frac{1}{R_{\text{eq}}} = \frac{1}{R_1} + \frac{1}{R_2} + \dots \qquad \text{(per a dues resistències: } R_{\text{eq}} = \frac{R_1 \cdot R_2}{R_1 + R_2} \text{)}$$

> [!NOTE]
> **Per què a un ordinador tot va en paral·lel?**
> A l'ordinador, tots els discs durs SATA, ventiladors i mòduls d'il·luminació es connecten en **paral·lel** a les línies de 12 V o 5 V de la font. Així, cada dispositiu rep sempre els seus 12 V estables i, si un disc dur falla o es desconnecta, la resta continua funcionant amb total normalitat.
