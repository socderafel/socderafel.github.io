# 8.4 Procediments de transport, estiba i etiquetatge de paquets fràgils

L'enviament d'ordinadors completament muntats o de servidors és un procés delicat: les empreses de missatgeria sotmeten els paquets a fortes acceleracions, frenades i caigudes a les cintes automatitzades de distribució.

---

## 🏷️ 1. Pictogrames Internacionals d'Etiquetatge

A les caixes de material informàtic fràgil s'han d'imprimir o enganxar etiquetes homologades amb símbols universals:

| Pictograma Internacional | Significat Tècnic de Taller | Instrucció de Manipulació Logística |
| :---: | :--- | :--- |
| 🍷 **Copa de Vidre** | **Fràgil** | Manejar amb compte extrem; conté vidre, sensors òptics o components electrònics delicats. |
| ⬆️⬆️ **Dues Fletxes Amunt** | **Aquest costat amunt** | La caixa s'ha de transportar i apilar sempre amb les fletxes apuntant al sostre. |
| ☂️ **Paraigua amb Gotes** | **Mantenir sec** | Prohibida l'exposició a la pluja, humitat o condensació ambiental. |\    |
         |    |    |                     |    /   \    |                    |    /     \   |
         |   ---   |                     |     | |     |                    |       |      |
         +---------+                     +-------------+                    +--------------+
       MOLT FRÀGIL (Cura)            CAP A DALT (Orientació)            PROTEGIR D'HUMITAT
```

1. **Copa trencada / Copa de vidre:** Material fràgil que conté components electrònics i vidre temperat. Manipular amb compte.
2. **Dues fletxes paral·leles amunt (*This way up*):** Indica quina és la cara superior que ha de mantindre's sempre amunt durant el transport i emmagatzematge.
3. **Paraigua amb pluja:** Prohibició absoluta de mullar el paquet o exposar-lo a la intempèrie.

---

## ⚠️ 2. El Perill de Transportar PCs Muntats amb Gràfiques Gegants

> [!CAUTION]
> **El problema mecànic de les targetes gràfiques modernes:**
> - Les targetes gràfiques actuals (com les RTX 4070/4080 o RX 7800) pesen **entre 1,5 kg i 2,5 kg** a causa dels seus gegantins dissipadors de coure i triples ventiladors.
> - Si s'envia un ordinador amb una GPU tan pesant punxada a la placa base, **un simple sotrac del camió de transport farà palanca mecànica i trencarà la ranura PCIe de plàstic o esquerdarà el circuit de la placa base**.
> - **Protocol de taller obligatori:**
>   - **Opció A:** Desmuntar la targeta gràfica i transportar-la en la seua pròpia caixa protegida.
>   - **Opció B:** Introduir una **bossa d'escuma d'expansió instapak (*Expanding Foam Bag*)** a l'interior de la caixa del PC que s'infla i s'emmotlla al voltant de la GPU i del dissipador de la CPU, bloquejant completament qualsevol moviment durant el viatge.
