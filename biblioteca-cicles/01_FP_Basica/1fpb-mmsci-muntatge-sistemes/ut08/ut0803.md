# 8.3 Materials i tècniques d'embalatge i protecció ESD

L'empaquetament de components electrònics per a transport o emmagatzematge requereix utilitzar materials dissenyats específicament per **esmorteir cops mecànics**, **absorbir la humitat atmosfèrica** i **blindar els circuits contra camps electroestàtics**.

---

## 🛡️ 1. Els Dos Tipus de Bosses Antiestàtiques

```
   Bossa Metal·litzada (Gàbia de Faraday)          Bossa Rosa Dissipativa
   +------------------------------------+          +------------------------------------+
   | Color: Gris platejat brillant      |          | Color: Rosa o blau transparent     |
   | Capa metàl·lica de blindatge (ESD) |          | Plàstic tractat amb agent químic   |
   | Per a components sensibles (Placa) |          | Només per a cables o manuals       |
   +------------------------------------+          +------------------------------------+
```

| Tipus de Bossa | Aspecte Visual | Com protegeix? | Quins components s'hi han de guardar? |
| :--- | :--- | :--- | :--- |
| **Bossa de Blindatge Metal·litzat (*Static Shielding*)** | **Gris platejat brillant semitransparent.** | Té una capa microscòpica d'alumini que actua com una **Gàbia de Faraday**: desvia qualsevol camp electroestàtic exterior per la capa externa sense tocar els xips interns. | **Components altament sensibles:** Plaques base, targetes gràfiques, microprocessadors, mòduls RAM i discs SSD. |
| **Bossa Antiestàtica Dissipativa (Plàstic Rosa)** | **Rosa clar o blavós transparent.** | No crea electricitat estàtica per fregament, però **NO bloqueja els camps estàtics exteriors**. | Elements no sensibles: manuals, cargols, cables SATA o carcasses mecàniques. |

---

## 📦 2. Materials de Farcit i Control d'Humitat

- **Bossa de Gel de Sílice (*Silica Gel*):** Xicotets saquets amb boletes poroses de diòxid de silici. Absorbeixen la humitat ambiental dins de la caixa evitant l'oxidació de les pistes de coure i connectors.
- **Escuma de polietilè (EPE) i plàstic de bombolles:** Esmorteeixen vibracions i caigudes durant el transport.
- **Cantoneres de cartó reforçat:** Protegeixen els angles de la caixa del PC contra cops a les caigudes verticals.
