# 4.6 Unitats d'emmagatzematge: HDD mecànic, SSD SATA i SSD NVMe M.2

A diferència de la memòria RAM, els dispositius d'emmagatzematge secundari són **no volàtils**: conserven totes les dades gravades (fotos, documents, fitxers del sistema operatiu Windows/Linux) encara que l'ordinador estiga mesos apagat. En aquesta sessió analitzarem l'evolució des dels discs durs mecànics tradicionals fins als moderns SSDs d'estat sòlid.

---

## 📊 1. Taula Comparativa Tecnològica

```
   HDD Mecànic (3.5")               SSD SATA (2.5")             SSD NVMe M.2 (2280)
   +----------------------+        +-------------------+       +-----------------------+
   | Platets magnètics    |        | Xips NAND Flash   |       | Xips NAND directes    |
   | Capçal de lectura    |        | Carcassa d'alumini|       | Format targeta        |
   | ~150 MB/s (Lent)     |        | ~550 MB/s (Ràpid) |       | ~7.000 MB/s (Ultraràpid)|
   +----------------------+        +-------------------+       +-----------------------+
```

| Característica | Disc Dur Mecànic (HDD) | SSD SATA (2,5 polzades) | SSD NVMe M.2 (Format 2280) |
| :--- | :--- | :--- | :--- |
| **Tecnologia Interna** | Platets d'alumini girant a 5.400 / 7.200 RPM i capçals electromagnètics. | Xips de memòria **NAND Flash** estàtica d'estat sòlid (sense peces mòbils). | Xips NAND Flash d'alta densitat connectats directament al bus PCIe. |
| **Velocitat de Lectura** | $\approx 120 - 180\text{ MB/s}$ | $\approx 500 - 550\text{ MB/s}$ | **$\approx 3.500 - 7.500+\text{ MB/s}$** |
| **Temps d'accés (Latència)** | $\approx 10 - 15\text{ ms}$ (Lent: ha de moure el braç físic). | $\approx 0,1\text{ ms}$ (Instantani). | $\approx 0,02\text{ ms}$ (Ultra instantani). |
| **Resistència a Cops** | **Molt fràgil:** un cop en funcionament fa que el capçal raye el platet i perda les dades. | **Molt resistent:** suporta caigudes i vibracions. | **Molt resistent:** integrat a la placa base. |
| **Cables necessaris** | Cable de dades SATA + Cable d'alimentació SATA de la font. | Cable de dades SATA + Cable d'alimentació SATA de la font. | **Zero cables:** es cargola directament a la ranura M.2 de la placa. |
| **Ús Recomanat a Taller** | Còpies de seguretat massives de molts Terabytes (econòmic). | Actualització d'equips vells que no tenen ranura M.2. | **Instal·lació de Windows i programes a tots els equips nous.** |
