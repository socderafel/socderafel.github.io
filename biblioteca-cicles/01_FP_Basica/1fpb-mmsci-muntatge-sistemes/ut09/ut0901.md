# 9.1 Protocol de primer encesa: procés POST, xiulets (Beep Codes) i Debug LEDs

El moment més emocionant i decisiu per a qualsevol tècnic de muntatge és el **primer encès de l'ordinador** acabat d'armar. Abans de mostrar qualsevol imatge al monitor, la placa base executa una rutina interna de comprovació de maquinari anomenada **POST** (*Power-On Self-Test*).

---

## 🔊 1. El Procés POST i els Xiulets (*Beep Codes*)

Si la placa base té connectat un xicotet brunzidor (*buzzer/speaker* de 4 pins), comunicarà el seu estat de salut mitjançant patrons sonors:

```
  +-- Brunzidor / Speaker de Placa --+
  |    [+] [ ] [ ] [-]               |  ---> Emet xiulets acústics de diagnòstic
  +----------------------------------+
```

| Codi de Xiulets (Beeps) | Diagnòstic de Maquinari | Què ha de fer el tècnic a taller? |
| :--- | :--- | :--- |
| **1 xiulet curt** | **Tot correcte (POST OK).** El maquinari bàsic ha superat la prova i comença l'arrencada del sistema operatiu. | Cap acció. L'equip funciona amb normalitat. |
| **Xiulets curts continus i repetitius** | **Error de memòria RAM.** La placa no detecta cap mòdul o el mòdul està danyat. | Extreure els mòduls RAM, netejar els contactes amb alcohol isopropílic i reencaixar-los a les ranures A2 i B2 fins a sentir el doble clic. |
| **1 xiulet llarg i 2 o 3 curts** | **Error de la Targeta Gràfica (VGA / GPU).** | Comprovar que la GPU està ben encaixada a la ranura PCIe x16 i que el cable d'alimentació PCIe (6+2 pins) està fermament connectat. |
| **Sense cap so ni moviment** | **Fallada elèctrica o d'alimentació.** | Comprovar que l'interruptor I/O de la font està encès (posició I), el cable de corrent de paret i el connector ATX de 24 pins. |

---

## 💡 2. Els Debug LEDs Moderns (CPU, DRAM, VGA, BOOT)

Les plaques base modernes han substituït els xiulets per **4 LEDs de diagnòstic serografiats** vora les ranures de memòria:

```
  +-- EZ Debug LED --+
  | (o) CPU          |  ---> Roig: Fallada al processador o socket
  | (o) DRAM         |  ---> Taronja/Groc: Fallada de memòria RAM
  | (o) VGA          |  ---> Blanc: Fallada de targeta gràfica o monitor apagat
  | (o) BOOT         |  ---> Verd: No es troba cap disc amb sistema operatiu
  +------------------+
```

> [!TIP]
> **Com interpretar els Debug LEDs:**
> Quan engegues l'equip, els 4 llums s'encenen de manera successiva durant 1 segon en ordre (CPU ➔ DRAM ➔ VGA ➔ BOOT). Si tot està bé, **tots els LEDs s'apaguen**.
> Si un LED queda **encès de manera fixa**, indica exactament el component que està fallant i impedint l'arrencada.

## 📋 Llista de Comprovació de Taller (Checklist Pràctic)
- [ ] Connecte l'altaveu/speaker intern a la placa si no disposa de Debug LEDs.
- [ ] Observe la seqüència d'encesa dels 4 LEDs de depuració (CPU, DRAM, VGA, BOOT).
- [ ] Si un LED queda encès, desconnecte el corrent abans de revisar el component assenyalat.
