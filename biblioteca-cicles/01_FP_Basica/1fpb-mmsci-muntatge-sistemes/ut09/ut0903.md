# 9.3 Creació de suports d'instal·lació d'arrencada USB: Rufus i Ventoy

Un ordinador nou amb totes les peces muntades no pot fer res fins que no se li instal·la un sistema operatiu (com Windows 11 o Ubuntu Linux). Per instal·lar-lo, els tècnics preparem **pendrives USB arrencables (*Bootable USB*)**.

---

## 🛠️ 1. Rufus: L'Eina Clàssica per a Imatges Individuals

**Rufus** és una utilitat de programari lliure portable per a Windows que converteix un fitxer d'imatge **ISO** en un pendrive d'arrencada d'alta velocitat:

```
  +-- Rufus -------------------------------------------------------------+
  | Dispositiu:       [ Kingston DataTraveler 32GB (D:) ]               |
  | Elecció d'arrencada: [ Imatge de disc ISO (Windows11_24H2.iso) ]    |
  | Esquema de partició: [ GPT ]                                         |
  | Sistema de destinació: [ UEFI (sense CSM) ]                         |
  | Sistema de fitxers:    [ NTFS ]                                     |
  | [ Opcions avançades: Ometre requisit de compte Microsoft i TPM 2.0 ]|
  |                                 [ COMENÇAR ]                         |
  +----------------------------------------------------------------------+
```

- **Esquema de partició GPT:** Obligatori per a equips moderns amb firmware UEFI.
- **Esquema MBR:** Únicament per a ordinadors vells de fa més de 10 anys amb BIOS clàssica heredada (*Legacy*).

---

## 🚀 2. Ventoy: La Solució Definitiva Multiarrencada de Taller

**Ventoy** és l'eina més potent per a un tècnic de manteniment informàtic:
1. S'instal·la **una única vegada** al pendrive USB.
2. A partir d'eixe moment, el pendrive es converteix en un disc normal on **només has de copiar i apegar fitxers .ISO directament** (com si fóra una carpeta de fitxers).
3. Pots tindre a la mateixa memòria USB:
   - `Windows11_Pro.iso`
   - `Windows10_Home.iso`
   - `Ubuntu_Desktop_24.04.iso`
   - `Hirens_BootCD_PE.iso` (eines de reparació de discs i rescat).
4. Quan engegues l'ordinador des del pendrive, Ventoy et mostra un **menú interactiu en pantalla** on tries amb les fletxes quina imatge ISO vols arrencar.
