# 9.2 Configuració bàsica de la BIOS/UEFI: Boot Order, perfils XMP/EXPO i paràmetres

Una vegada el maquinari ha superat el POST amb èxit, cal entrar a la interfície de configuració del firmware (**UEFI Setup**) per ajustar la data/hora, activar la velocitat màxima de la memòria RAM i establir la prioritat dels dispositius d'arrencada (*Boot Order*).

---

## ⌨️ 1. Com entrar a la BIOS/UEFI?

Tan bon punt prems el botó d'encesa de la torre, prem de forma repetida (una pulsació per segon) la tecla d'accés de la teua placa base:
- **Tecles universals més comunes:** **`SUPR`** (o *DEL* als teclats en anglès) i **`F2`**.
- **Menú ràpid d'arrencada (*Boot Menu*):** Tecla **`F11`** (MSI, ASRock) o **`F12`** (Gigabyte, Lenovo, Dell) o **`F8`** (ASUS). Permet triar un pendrive USB d'arrencada sense canviar la configuració permanent de la BIOS.

---

## ⚙️ 2. Paràmetres Crítics a Configurar a Taller

```
  +-- BIOS / UEFI Setup Utility ----------------------------------------+
  | Data i Hora del Sistema: [ 03/11/2026 ]  [ 08:30:00 ]               |
  | Perfil de Memòria:       [ XMP Profile 1: DDR5-6000 MHz Actiu ]     |
  | Prioritat d'Arrencada:   1r: [ UEFI: USB Pendrive Ventoy ]          |
  |                          2n: [ NVMe SSD: Kingston KC3000 1TB ]      |
  | Tecnologia Virtualització (VT-x / AMD-V): [ ENABLED ]               |
  | Mòdul TPM 2.0 i Secure Boot:              [ ENABLED ] (Per a Win 11)|
  +---------------------------------------------------------------------+
```

1. **Prioritat d'Arrencada (*Boot Priority / Boot Order*):**
   - Per instal·lar un sistema operatiu nou: col·loca el **pendrive d'instal·lació USB en 1a posició**.
   - Una vegada instal·lat Windows: col·loca el disc **Windows Boot Manager (SSD NVMe)** com a primera opció per arrencar en pocs segons.
2. **Activació de Perfils XMP (Intel) / EXPO (AMD):** Assegura que la memòria funcione als MHz contractats.
3. **Virtualització de la CPU (Intel VT-x o AMD-V / SVM):** Imprescindible activar-la per poder utilitzar màquines virtuals a VirtualBox a cursos superiors.
4. **Guardar canvis i eixir:** Sempre prémer **`F10`** (*Save & Exit*) per confirmar els paràmetres abans de reiniciar.
