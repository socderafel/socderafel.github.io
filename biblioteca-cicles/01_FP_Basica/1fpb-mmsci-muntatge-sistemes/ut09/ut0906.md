# 9.6 Banc de proves pràctiques i avaluació global de taller

En aquesta sessió final avaluarem de manera integral totes les competències professionals, procedimentals i actitudinals adquirides al llarg del curs de **Muntatge i Manteniment de Sistemes i Components (1r FPB)** d'acord amb els Resultats d'Aprenentatge oficials del currículum (RA1 a RA6).

---

## 🏆 1. Rúbrica d'Avaluació de Pràctica de Taller

```
  +-- Rúbrica Professional de Taller FPB -------------------------------+
  | [ RA1 ] Prevenció de riscos, seguretat elèctrica i protecció ESD    |
  | [ RA2 ] Identificació i comprovació de components elèctrics i lògics|
  | [ RA3 ] Ensamblatge correcte i ordenat de la placa base i components |
  | [ RA4 ] Cablejat d'alimentació, dades i panell frontal JFP1         |
  | [ RA5 ] Configuració de la BIOS/UEFI i arrencada de sistemes        |
  | [ RA6 ] Diagnòstic i resolució metòdica d'avaries de maquinari      |
  +---------------------------------------------------------------------+
```

## 📋 Gran Llista de Comprovació Final de Taller
- [ ] Aplique de manera autònoma les mesures de protecció ESD (polsera antiestàtica i estora).
- [ ] Munte la CPU, RAM Dual-Channel i dissipador amb pasta tèrmica de manera professional.
- [ ] Connecte tots els cables interns de corrent, dades i panell frontal JFP1 sense cap error.
- [ ] Configure la BIOS/UEFI per arrencar i comprove l'estabilitat tèrmica i el funcionament general.
