# 2.3 La memòria principal: RAM volàtil vs memòria ROM/Firmware

Tot ordinador necessita dos tipus fonamentals de memòria per funcionar: una memòria **volàtil i ultraràpida** on treballar en temps real (**RAM**), i una memòria **no volàtil i permanent** on guardar les instruccions d'arrencada imprescindibles abans que el disc dur carregue el sistema operatiu (**ROM / UEFI**).

---

## ⚡ 1. La Memòria RAM (Random Access Memory)

La memòria RAM s'anomena d'«Accés Aleatori» perquè el processador pot llegir o escriure en qualsevol posició de memòria en el mateix interval de temps, sense haver de recórrer les posicions anteriors.

```
       +---------------------------------------------------+
       |            Mòdul de Memòria RAM DIMM              |
       |  +----+  +----+  +----+  +----+  +----+  +----+   |
       |  |Xip |  |Xip |  |Xip |  |Xip |  |Xip |  |Xip |   |
       |  +----+  +----+  +----+  +----+  +----+  +----+   |
       |  ||||||||||||||||||  Mussa Central  ||||||||||||| |
       +---------------------------------------------------+
```

- **Característica crítica:** És una memòria **volàtil**: necessita refresc elèctric continu per mantindre les dades. Si l'ordinador s'apaga o hi ha un tall de llum, tot el seu contingut s'esborra instantàniament.
- **Tecnologies actuals:**
  - **DDR4 SDRAM:** Estàndard madur (velocitats habituals de 2.666 a 3.200 MHz, 288 contactes).
  - **DDR5 SDRAM:** Nova generació d'alt rendiment (velocitats de 4.800 a 6.400+ MHz, major amplada de banda, gestor d'energia PMIC integrat al mateix mòdul).

---

## 🔒 2. La Memòria ROM i el Firmware BIOS/UEFI

La memòria **ROM (Read Only Memory)** és una memòria **no volàtil**: reté la informació gravada permanentment, encara que l'ordinador no reba cap tipus d'alimentació elèctrica.

- **On es troba a la placa base?** En un xip de memòria **Flash ROM** soldat a la placa.
- **Què conté?** El **firmware** bàsic del sistema:
  - Antigament: la **BIOS** (*Basic Input/Output System*).
  - Actualment: la **UEFI** (*Unified Extensible Firmware Interface*), amb interfície gràfica, suport per a ratolí, arrencada segura (*Secure Boot*) i discos de més de 2 TB (taula de particions GPT).
- **Funció a l'arrencada:**
  1. Executar el test de maquinari inicial (**POST** - *Power-On Self-Test*).
  2. Inicialitzar la CPU, la RAM i la targeta gràfica.
  3. Localitzar el carregador d'arrencada del disc SSD (*Boot Loader*) i transferir el control a Windows o Linux.
