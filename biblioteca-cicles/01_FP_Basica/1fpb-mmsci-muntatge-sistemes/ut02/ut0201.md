# 2.1 L'arquitectura de Von Neumann i el cicle d'instrucció

Tots els ordinadors personals actuals (des del portàtil més xicotet fins al servidor més potent) continuen basant-se en el model teòric proposat pel matemàtic **John von Neumann l'any 1945**. Conèixer aquest model és clau per entendre com es coordinen el processador, la memòria RAM i els dispositius d'emmagatzematge.

---

## 🏛️ 1. Els 4 Blocs Fonamentals de l'Arquitectura de Von Neumann

El principi clau de Von Neumann és el concepte de **programa emmagatzemat**: les dades i les instruccions del programa comparteixen el mateix espai de memòria principal.

```
       +-----------------------------------------------+
       |             CPU (Processador)                 |
       |  +--------------------+  +-----------------+  |
       |  | Unitat de Control  |  | Unitat Aritmètica|  |
       |  |       (UC)         |  |   Lògica (ALU)  |  |
       |  +--------------------+  +-----------------+  |
       |            ^                      ^           |
       |            |   Registres Interns  |           |
       +------------|----------------------|-----------+
                    |                      |
            [ Bus de Control ]      [ Bus de Dades ]
                    |                      |
       +------------v----------------------v-----------+
       |         Memòria Principal (RAM)               |
       |   (Emmagatzema instruccions i dades)          |
       +-----------------------------------------------+
                    |                      |
       +------------v----------------------v-----------+
       |           Unitat d'Entrada / Eixida           |
       |      (Teclat, Ratolí, Disc SSD, Pantalla)     |
       +-----------------------------------------------+
```

1. **Unitat Central de Processament (CPU):** El «cervell» que interpreta i executa instruccions.
2. **Memòria Principal (RAM):** Espai de treball ràpid on es carreguen el sistema operatiu i els programes en execució.
3. **Unitat d'Entrada/Eixida (E/E):** Mòduls d'interfície que connecten l'ordinador amb l'exterior (perifèrics i discs).
4. **Busos del Sistema:** Pistes i cables per on viatgen les dades, les adreces de memòria i els senyals de control.

---

## 🔄 2. El Cicle d'Instrucció (Cicle Màquina)

La CPU executa milions d'instruccions per segon repetint contínuament un cicle de 3 fases bàsiques:

```
  [ 1. Cerca (Fetch) ]  --->  [ 2. Descodificació (Decode) ]  --->  [ 3. Execució (Execute) ]
   La CPU llig la següent       La Unitat de Control (UC)          L'ALU realitza el càlcul
   instrucció des de la RAM.    esbrina quina operació és.         i guarda el resultat.
```

- **Fase de Cerca (*Fetch*):** El comptador de programa indica quina adreça de la RAM té la instrucció següent; la CPU la porta als seus registres interns.
- **Fase de Descodificació (*Decode*):** La Unitat de Control desxifra el codi d'operació (suma, salt, comparació...).
- **Fase d'Execució (*Execute*):** L'ALU o el mòdul corresponent fa l'operació matemàtica i emmagatzema el resultat a la RAM o en un registre.
