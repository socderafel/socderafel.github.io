# 2.1 Model i arquitectura de Von Neumann

Tots els ordinadors moderns, des d'un telèfon mòbil intel·ligent fins al superordinador més potent del món, es basen en els principis d'arquitectura proposats pel matemàtic **John von Neumann** l'any 1945.

---

## 🏛️ 1. Què és l'Arquitectura de Von Neumann?

Abans de Von Neumann, les primeres màquines de càlcul (com l'ENIAC) havien de ser recablejades manualment cada vegada que es volia canviar de tasca o programa. 

La gran revolució del **model de Von Neumann** va ser introduir el concepte de **programa emmagatzemat**: les dades i les instruccions del programa es guarden conjuntament a la mateixa memòria principal en format binari (zeros i uns).

```
+-------------------------------------------------------------+
|              ARQUITECTURA DE VON NEUMANN                    |
+-------------------------------------------------------------+
|                                                             |
|   +-----------------------+         +-------------------+   |
|   |          CPU          | <=====> | MEMÒRIA PRINCIPAL |   |
|   |  +--------+ +-------+ |  Busos  |       (RAM)       |   |
|   |  |   UC   | |  ALU  | |         | Guarda programes  |   |
|   |  +--------+ +-------+ |         |   i dades         |   |
|   |  |     Registres    | |         +-------------------+   |
|   +-----------------------+                   ^             |
|               ^                               |             |
|               |  Busos del sistema            |             |
|               v                               v             |
|   +-----------------------------------------------------+   |
|   |           SUBSISTEMA D'ENTRADA / EIXIDA (E/S)       |   |
|   |  (Controladors de Teclat, Ratolí, Disc, Monitor...) |   |
|   +-----------------------------------------------------+   |
+-------------------------------------------------------------+
```

---

## 🧱 2. Els Quatre Blocs Funcionals Fonamentals

L'arquitectura es divideix en quatre unitats clarament diferenciades:

1. **Unitat Central de Processament (CPU):** El "cervell" del sistema que interpreta i executa les instruccions dels programes.
2. **Memòria Principal (RAM):** Emmagatzema temporalment les instruccions que la CPU ha d'executar i les dades necessàries durant el processament.
3. **Unitat d'Entrada/Eixida (E/S):** Comunica l'ordinador amb l'exterior, rebent dades d'usuaris o sensors (entrada) i mostrant resultats (eixida).
4. **Busos del Sistema:** Les autopistes elèctriques de coure que interconnecten tots els elements anteriors per transferir informació.

---

## ⚖️ 3. El Coll d'Ampolla de Von Neumann

L'arquitectura presenta una limitació teòrica coneguda com el **coll d'ampolla de Von Neumann** (*Von Neumann bottleneck*):
- Com que la CPU i la memòria principal estan separades físicament i comparteixen el mateix bus, la velocitat total de l'equip està limitada per la velocitat a la qual la memòria pot lliurar dades a la CPU.
- **Solució tecnològica:** Per reduir aquest coll d'ampolla, els processadors moderns incorporen múltiples nivells de **memòria cau (L1, L2, L3)** ultra-ràpida directament integrada dins del mateix xip de silici del processador.
