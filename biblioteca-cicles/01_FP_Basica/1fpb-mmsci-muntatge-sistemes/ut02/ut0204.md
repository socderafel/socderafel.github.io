# 2.4 El subsistema d'entrada/eixida i els busos de comunicació

Perquè la CPU i la memòria puguen comunicar-se entre si i intercanviar informació amb el món exterior, necessiten un conjunt de línies de comunicació electròniques anomenades **busos** i controladors especialitzats d'**Entrada/Eixida (E/S)**.

---

## 🚌 1. Els Busos del Sistema

Un **bus** és un conjunt de pistes elèctriques paral·leles per les quals circulen senyals binaris entre diferents components de la placa base.

Segons el tipus d'informació que transmeten, es divideixen en tres busos especialitzats:

```
+-----+           Bus de Dades (Bidireccional)          +---------+
|     | <=============================================> |         |
|     |           Bus d'Adreces (Unidireccional: CPU ->) | MEMÒRIA |
| CPU | ----------------------------------------------> |    O    |
|     |           Bus de Control (Bidireccional)        |   E/S   |
|     | <---------------------------------------------> |         |
+-----+                                                 +---------+
```

1. **Bus de Dades:** 
   - Transporta les dades reals i els codis d'instrucció que es llegeixen o s'escriuen.
   - És **bidireccional** (les dades viatgen de la memòria a la CPU i de la CPU a la memòria).
   - L'amplada de bus típica actual és de **64 bits** (pot enviar 64 bits d'un sol cop).

2. **Bus d'Adreces:**
   - Transporta la posició o adreça física de memòria (o de port d'E/S) on es troba la dada que la CPU vol llegir o escriure.
   - És **unidireccional** (només la CPU genera les adreces cap a la memòria o els perifèrics).
   - El nombre de línies del bus d'adreces determina la quantitat màxima de memòria RAM que pot direccionar el sistema:
     \[ \text{Capacitat màxima} = 2^{\text{línies d'adreça}} \]
     *Exemple:* Un bus d'adreces de 32 bits només pot adreçar \( 2^{32} = 4.294.967.296\text{ bytes} = 4\text{ GB} \) de RAM. Els busos actuals de 64 bits permeten adreçar milers de Terabytes de memòria RAM.

3. **Bus de Control:**
   - Transporta senyals elèctrics de sincronització, lectura/escriptura (R/W), interrupcions de maquinari i senyals de rellotge per coordinar qui envia i qui rep dades en cada instant.

---

## 🔌 2. El Subsistema d'Entrada/Eixida (E/S)

La CPU no pot connectar-se directament a un teclat, un ratolí o un disc dur perquè:
1. Els perifèrics són molt més lents que la CPU.
2. Cada dispositiu utilitza protocols i nivells de voltatge diferents.

Per resoldre-ho, la placa base utilitza **controladors d'E/S** i el **Chipset**:
- **Controladors de dispositiu (Device Controllers):** Xips electrònics que gestionen cada perifèric (xip de so Realtek, controlador de xarxa Ethernet, controladors de disc SATA/NVMe).
- **Interrupcions de Maquinari (IRQ):** Senyals d'alerta que els perifèrics envien a la CPU quan requereixen atenció immediata (per exemple, quan l'usuari prem una tecla o es mou el ratolí).
