# 2.4 Els busos de comunicació del sistema

Un **bus** és el conjunt de línies conductores físiques (pistes de coure a la placa base o cables) per on viatja la informació en forma d'impulsos elèctrics entre els components d'un ordinador. Sense busos, el processador no podria intercanviar dades amb la memòria RAM ni amb la targeta gràfica.

---

## 🚌 1. Els 3 Busos Fonamentals del Sistema

El bus del sistema es divideix conceptualment en tres canals especialitzats:

```
        +------------------ CPU ------------------+
        |                                         |
        +---+-----------------+---------------+---+
            |                 |               |
      [Bus Dades]       [Bus Adreces]   [Bus Control]
     (Bidireccional)   (Unidireccional)  (Mixt / Ordres)
            |                 |               |
            v                 v               v
        +---+-----------------+---------------+---+
        |               Memòria RAM               |
        +-----------------------------------------+
```

| Tipus de Bus | Direcció del Senyal | Quina informació transporta? | Característica Tècnica |
| :--- | :---: | :--- | :--- |
| **Bus de Dades** | **Bidireccional** (anada i tornada) | Els valors reals que es processen (instruccions, textos, imatges, nombres). | L'amplada es mesura en **bits** (ex: 64 bits = pot transmetre 8 bytes alhora). |
| **Bus d'Adreces** | **Unidireccional** (CPU ➔ Memòria) | Indica a quina cel·la o posició exacta de memòria RAM vol escriure o llegir la CPU. | Determina la **capacitat màxima de memòria RAM** que pot adreçar el processador ($2^n$). |
| **Bus de Control** | Mixt | Senyals elèctrics de sincronització, lectura/escriptura (R/W), interrupcions i cicles de rellotge. | Evita que dos components transmeten alhora provocant col·lisions. |

---

## 🧮 2. L'amplada del Bus d'Adreces i el límit de 4 GB

Per què els sistemes antics de 32 bits no podien utilitzar més de 4 GB de memòria RAM?
- Un processador amb un bus d'adreces de **32 bits** pot generar:
  $$2^{32} = 4.294.967.296\text{ adreces diferents} = 4\text{ GiB}$$
- Per contra, els processadors moderns de **64 bits** tenen un espai d'adreçament teòric de $2^{64}$ bytes (16 Exabytes), eliminant per complet aquesta limitació per a qualsevol ordinador d'avui dia.
