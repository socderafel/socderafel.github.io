# 3.1 Factors de forma de la placa base: ATX, Micro-ATX i Mini-ITX

La **placa base** (o *motherboard*) és el circuit imprès (PCB) principal on s'interconnecten tots els components d'un ordinador. Perquè una placa puga muntar-se correctament dins d'un xassís, la indústria segueix uns **factors de forma estandarditzats** que fixen les mides en mil·límetres i la posició exacta dels forats per als cargols.

---

## 📐 1. Els 3 Factors de Forma Comercials Més Habituals

```
   +---------------------------------+
   |                                 |
   |           E-ATX                 |
   |      (305 x 330 mm)             |
   |                                 |
   |   +-----------------------+     |
   |   |        ATX            |     |
   |   |   (305 x 244 mm)      |     |
   |   |                       |     |
   |   |   +---------------+   |     |
   |   |   |  Micro-ATX    |   |     |
   |   |   | (244 x 244 mm)|   |     |
   |   |   |               |   |     |
   |   |   |  +---------+  |   |     |
   |   |   |  |Mini-ITX |  |   |     |
   |   |   |  |(170x170)|  |   |     |
   +---+---+--+---------+--+---+-----+
```

| Factor de Forma | Mides Exactes | Ranures RAM habituals | Ranures PCIe | Ús típic a l'aula / mercat |
| :--- | :---: | :---: | :---: | :--- |
| **ATX Estàndard** | $305 \times 244\text{ mm}$ | 4 slots DIMM | Fins a 7 ranures | Torres mitjanes (*Mid-Tower*), equips de gaming i estacions de treball. |
| **Micro-ATX (mATX)** | $244 \times 244\text{ mm}$ | 2 o 4 slots DIMM | Fins a 4 ranures | **El més comú a aules d'informàtica i oficines.** Molt bona relació qualitat-preu. |
| **Mini-ITX** | $170 \times 170\text{ mm}$ | 2 slots DIMM | 1 ranura (PCIe x16) | Caixes ultracompactes (SFF - *Small Form Factor*), equips de saló (HTPC) i TPVs de comerç. |

---

## 🛠️ 2. Procediment de Taller: Separadors Metàl·lics (*Standoffs*)

> [!CAUTION]
> **Norma de seguretat número 1 en caragolar una placa base:**
> - La placa base mai es caragola directament sobre la xapa metàl·lica de la caixa del PC.
> - Cal col·locar primer els **separadors de llautó (*standoffs*)** roscats exactament en els forats que coincideixen amb el factor de forma de la placa.
> - **Perill de curtcircuit:** Si deixes un separador col·locat en una posició on la teua placa no té forat, farà contacte amb les soldadures posteriors de la placa, provocant un curtcircuit immediat i cremant la placa en prémer el botó d'engegada.
