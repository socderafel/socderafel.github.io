# 3.1 Funció, estructura i factors de forma de la placa base

La **placa base** (*motherboard* o *mainboard*) és el component central de maquinari on es connecten, directament o mitjançant cables, tots els altres components d'un ordinador: el processador, la memòria RAM, la targeta gràfica, la font d'alimentació i les unitats d'emmagatzematge.

Físicament és una oblea multicapa de material sintètic (fibra de vidre i resina epoxi) travessada per milers de pistes microscòpiques de coure que transporten electricitat i dades binàries.

---

## 📐 1. Els Factors de Forma de les Plaques Base

El **factor de forma** (*form factor*) defineix les dimensions geomètriques de la placa, la posició exacta dels forats de subjecció dels caragols a la caixa, la ubicació del panell posterior d'E/S i la distribució dels connectors d'alimentació.

Els tres estàndards moderns més habituals al mercat són:

| Factor de Forma | Dimensions (Amplada x Fons) | Ranures d'Expansió (PCIe) | Zòcols de RAM | Ús Habitual |
| :--- | :---: | :---: | :---: | :--- |
| **Standard ATX** | \( 305 \times 244\text{ mm} \) (12 x 9,6 polzades) | Fins a 7 ranures | 4 zòcols (fins a 128-192 GB) | Torres estàndard, ordinadors de disseny, gaming i estacions de treball. |
| **Micro-ATX (mATX)** | \( 244 \times 244\text{ mm} \) (9,6 x 9,6 polzades) | 3 a 4 ranures | 2 o 4 zòcols | Torres mitjanes (*semi-torre*), ordinadors d'oficina (el format més venut per preu/prestacions). |
| **Mini-ITX** | \( 170 \times 170\text{ mm} \) (6,7 x 6,7 polzades) | Només 1 ranura (PCIe x16) | 2 zòcols (format compacte) | Caixes molt compactes (SFF - *Small Form Factor*), centres multimèdia de saló o ordinadors portàtils de sobretaula. |

```
    +---------------------------+
    |           ATX             |
    |      (305 x 244 mm)       |
    |                           |
    |   +-------------------+   |
    |   |     Micro-ATX     |   |
    |   |   (244 x 244 mm)  |   |
    |   |                   |   |
    |   |   +-----------+   |   |
    |   |   | Mini-ITX  |   |   |
    |   |   |(170x170mm)|   |   |
    |   |   +-----------+   |   |
    |   +-------------------+   |
    +---------------------------+
```

> [!TIP]
> **Compatibilitat de caixes:** Les caixes que admeten el format gran **ATX** solen incloure forats addicionals per caragolar sense cap problema plaques més petites com **Micro-ATX** o **Mini-ITX**. En canvi, una caixa dissenyada només per a Micro-ATX mai podrà allotjar una placa ATX estàndard per falta d'espai físic.

## 🛠️ 2. Precaucions de Muntatge a la Caixa: Els Separadors (*Standoffs*)

Quan un tècnic munta una placa base a la caixa metàl·lica de l'ordinador:
- S'han de col·locar **obligatòriament els suports separadors de llautó (*standoffs*)** entre el xassís de xapa i la placa base.
- Si la placa base toqués directament la xapa metàl·lica de la caixa, les soldadures inferiors farien curtcircuit immediat, cremant la placa en prémer el botó d'encesa.
- Només s'han de posar separadors en els forats de la caixa que coincideixin exactament amb els forats reforçats de la placa base. Un separador col·locat en un lloc buit pot provocar un curtcircuit fatal.
