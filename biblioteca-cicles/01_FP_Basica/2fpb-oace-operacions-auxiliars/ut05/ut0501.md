# 5.1 Neteja i alliberament d'espai en disc

Amb l'ús continuat d'un ordinador, tant el sistema operatiu com els navegadors web i les aplicacions ofimàtiques generen milers d'arxius temporals, memòries cau i fitxers de registre que ocupen espai valuós al disc dur i poden degradar el rendiment de l'equip.

---

### Principals fonts de residus digitals

1. **Memòria cau dels navegadors web:** Arxius d'imatges, scripts i cookies emmagatzemats per accelerar visites que mai més es tornen a produir.
2. **Carpetes temporals del sistema i d'usuari:**
   - `C:\Windows\Temp`: Arxius temporals utilitzats per actualitzacions i instal·ladors del sistema.
   - `%temp%` (`C:\Users\[Usuari]\AppData\Local\Temp`): Arxius temporals generats per les aplicacions que obre l'usuari diàriament.
3. **Restes d'instal·lacions anteriors de Windows (`Windows.old`):** Quan Windows s'actualitza a una versió gran (ex: de Windows 10 a 11), conserva una còpia de l'antic sistema que sol pesar entre 20 GB i 35 GB.
4. **Fitxers d'informe d'errors i abocaments de memòria (*Memory dumps*):** Quan es produeix una pantalla blava (BSOD), el sistema guarda una captura de la RAM al disc.

---

### Eines d'alliberament integrades en Windows

```text
EINES DE NETEJA INTEGRADES
┌─────────────────────────────────┬─────────────────────────────────┐
│ Sensor d'emmagatzematge         │ Netejador de disc clàssic       │
├─────────────────────────────────┼─────────────────────────────────┤
│ • Configuració > Sistema >      │ • Comanda: cleanmgr.exe         │
│   Emmagatzematge                │ • Permet esborrar fitxers del   │
│ • Funciona de manera automàtica │   sistema (Windows.old, pedaços)│
│ • Buida la paperera i temporals │ • Executar com a administrador  │
│   periòdicament                 │   per a un esborrat profund     │
└─────────────────────────────────┴─────────────────────────────────┘
```

#### Protocol de neteja manual d'emergència en taller:
1. Tanca totes les aplicacions obertes.
2. Prem `Win + R`, escriu `%temp%` i prem Intro.
3. Prem `Ctrl + E` per seleccionar-ho tot i `Maj + Supr` per eliminar-ho directament sense passar per la paperera. *(Si algun arxiu està en ús pel sistema en eixe instant, tria 'Omet').*
4. Obre `cleanmgr.exe`, fes clic a **Neteja els fitxers del sistema** i marca totes les caselles (especialment *Neteja de Windows Update*).
