# 5.5 Gestió d'actualitzacions: Windows Update i pegats de seguretat

Les actualitzacions del sistema operatiu són l'escut fonamental contra vulnerabilitats, fallades de seguretat i atacs de tipus *zero-day*. No obstant això, una actualització mal configurada o interrompuda pot provocar fallades greus, com ara bucles de reinici o incompatibilitats de controladors.

---

### Tipus d'actualitzacions en Windows Update

```text
TIPOLOGIES D'ACTUALITZACIONS WINDOWS
┌───────────────────────────────────────┬───────────────────────────────────────┐
│ Actualitzacions de Seguretat i Qualitat│ Actualitzacions de Característiques   │
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • Publicades periòdicament (Patch Tue)│ • Publicades anualment (ex: 23H2)     │
│ • Pedaços acumulatius (identificats KB)│ • Canvis grans en el sistema operatiu │
│ • Correcció d'errors crítics i forats │ • Incorporen noves eines i disseny    │
│ • Pesen pocs centenars de Megabytes   │ • Pesen diversos Gigabytes (reinstal) │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

---

### Com resoldre una fallada provocada per una actualització defectuosa

Si després d'instal·lar un pedaç l'equip mostra una pantalla blava (BSOD) o falla una aplicació corporativa:
1. Vés a **Configuració > Windows Update > Historial d'actualitzacions**.
2. Baixa fins a l'apartat **Desinstal·la les actualitzacions**.
3. Localitza el pedaç amb codi `KBXXXXXXX` instal·lat el dia de la fallada i fes clic a **Desinstal·la**.
4. *(Si Windows no arrenca):* Encén l'ordinador i força dues apagades consecutives mantenint el botó d'encesa per activar l'entorn de recuperació **WinRE**. Vés a *Resolució de problemes > Opcions avançades > Desinstal·la les darreres actualitzacions de qualitat*.
