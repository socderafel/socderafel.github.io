# 9.1 Amenaces de seguretat: virus, ransomware i phishing

La seguretat de la informació és un dels pilars essencials de qualsevol entorn laboral. Un sol ordinador infectat en una xarxa local pot paralitzar l'activitat de tot un centre educatiu o empresa. Per poder defendre els equips, el tècnic ha de conèixer les característiques del programari maliciós (**Malware**) i les tècniques d'engany humà (**Enginyeria social**).

---

### Principals tipus de Malware

```text
TAXONOMIA DEL PROGRAMARI MALICIÓS
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ RANSOMWARE              │ TROIANS I CUCS          │ SPYWARE I ADWARE        │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Xifra els documents de│ • Troians: Es fan passar│ • Spyware: Espia les te-│
│   l'equip (algoritmes   │   per programes legals  │   cles i credencials de │
│   militars AES/RSA)     │   per obrir portes      │   banca (*Keyloggers*)  │
│ • Exigeix pagament en   │   traseres (*Backdoors*)│ • Adware: Inunda el sis-│
│   criptomonedes         │ • Cucs: S'autopropaguen │   tema de publicitat no │
│ • L'amenaça més greu!   │   per la xarxa local    │   desitjada             │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

---

### Enginyeria Social i Phishing

Més del 80% dels incidents de ciberseguretat no es deuen a fallades del programari, sinó a l'**enginyeria social**: manipular psicològicament l'usuari perquè siga ell mateix qui execute un virus o facilite les seues contrasenyes.

#### Com detectar un correu de Phishing:
1. **Sensació d'urgència extrema:** *"El teu compte bancari serà bloquejat en 2 hores si no verifiques la clau"*.
2. **Remitent fals o sospitós:** L'aparença diu `Banc Santander` però l'adreça real és `info@santander-seguretat-login.xyz`.
3. **Enllaços camuflats:** En passar el ratolí per damunt del botó sense fer clic, la barra d'estat del navegador mostra un enllaç que no pertany a la web oficial de l'entitat.
4. **Fitxers adjunts perillosos:** Fitxers amb doble extensió com `factura_febrer.pdf.exe` o arxius zip amb contrasenya.
