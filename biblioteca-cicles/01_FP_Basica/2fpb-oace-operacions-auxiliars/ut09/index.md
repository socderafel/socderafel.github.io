## 9.1 Amenaces de seguretat: virus, ransomware i phishing

La seguretat informàtica (**ciberseguretat**) no és només qüestió d'experts: la immensa majoria d'atacs i infeccions que pateixen les petites empreses i usuaris domèstics tenen èxit a causa de descits humans o falta de coneixement de les amenaces bàsiques.

### Principals tipus de programari maliciós (*Malware*)

1. **Virus informàtic clàssic:**
   - Programa dissenyat per infectar altres fitxers de l'ordinador i reproduir-se, provocant fallades de sistema o esborrat de dades.
2. **Cuc (*Worm*):**
   - No necessita la intervenció de l'usuari per propagar-se: aprofita fallades de seguretat de la xarxa local per saltar automàticament d'un ordinador infectat a tots els altres equips de la mateixa xarxa d'aula o d'oficina.
3. **Troià (*Trojan*):**
   - Es camufla sota l'aparença d'un programa aparentment útil o desitjable (com un joc gratuït, una pel·lícula o un activador pirata). En executar-lo, obre una porta posterior (*backdoor*) perquè els atacants prenguen el control remot de l'equip.
4. **Segrestador de dades (*Ransomware*):**
   - **L'amenaça més destructiva actualment per a empreses i institucions públiques.**
   - Xifra en silenci tots els documents, fotos i bases de dades de l'equip i de la xarxa mitjançant claus criptogràfiques complexes, i exigeix el pagament d'un rescat en criptomonedes per recuperar les dades.
5. **Engany o pesca de dades (*Phishing*):**
   - Tècnica d'**enginyeria social**.
   - Els atacants envien correus electrònics o SMS falsos suplantant bancs, empreses de missatgeria o l'Agència Tributària per induir la víctima a introduir contrasenyes o dades confidencials en llocs web falsificats.

---

### Matriu de vectors d'amenaça i mesures d'atenuació
| Tipus d'Amenaça | Vector Principal d'Entrada | Objectiu de l'Atac | Mesura Tècnica de Protecció |
| :--- | :--- | :--- | :--- |
| **Virus / Troià** | Descàrregues web no fiables o llapis USB infectats | Execució de codi maliciós i portes posteriors | Protecció en temps real de Windows Defender |
| **Cuc de Xarxa** | Vulnerabilitats en serveis de xarxa sense pegats | Propagació massiva sense intervenció d'usuari | Tallafocs actiu i actualitzacions de Windows Update |
| **Ransomware** | Correus de pesca (*Phishing*) o accessos RDP febles | Xifratge massiu de fitxers per extorsió | Còpies de seguretat 3-2-1 i Control d'Accés a Carpetes |
| **Phishing** | Correu electrònic fraudulent i suplantació web | Robatori de credencials i dades bancàries | Autenticació de doble factor (2FA) i formació d'usuaris |
| **Spyware / Adware** | Instal·ladors brossa descarregats de llocs intermediaris | Robatori d'hàbits de navegació i anuncis intrusius | Descarregar només de llocs oficials i bloquejadors web |

## 9.2 Protecció activa: l'antivirus Windows Defender

En sistemes actuals Windows 10 i 11, Microsoft inclou de sèrie la suite de seguretat **Seguretat del Windows (*Windows Defender*)**, una de les més potents i ben valorades segons laboratoris independents de ciberseguretat (AV-Test).

### Components clau de Seguretat del Windows
1. **Protecció en temps real:**
   - Inspecciona cada fitxer que es descarrega d'Internet o s'introdueix en un llapis USB abans que s'arribe a obrir. Si detecta la signatura d'una amenaça coneguda o un patró heurístic anòmal, el bloqueja a l'instant i el mou a **quarantena**.
2. **Protecció basada en el núvol:**
   - Si apareix una mostra desconeguda, envia metadades anònimes als servidors d'intel·ligència artificial de Microsoft per classificar l'amenaça en temps real.
3. **Protecció contra ransomware (Control d'accés a les carpetes):**
   - Impedeix que aplicacions no autoritzades puguen modificar o xifrar els fitxers guardats a carpetes clau com *Documents*, *Imatges* o *Escriptori*.

---

### Tipus d'anàlisi manual amb Windows Defender
- **Anàlisi ràpida:** Revisa carpetes crítiques del sistema i processos actius en memòria RAM (durada: 2-3 minuts).
- **Anàlisi completa:** Escaneja absolutament tots els fitxers de totes les unitats de disc connectades (durada: 30-90 minuts).
- **Anàlisi personalitzada:** Permet fer clic amb el botó dret sobre una carpeta concreta o dispositiu USB i triar: *"Analitza amb el Microsoft Defender"*.
- **Anàlisi de Microsoft Defender sense connexió (*Offline Scan*):** Reinicia l'equip en un entorn segur abans de carregar Windows per eliminar rootkits o amenaces profundament arrelades.

---

### Gestió del Tallafocs de Windows (*Windows Firewall*)
El tallafocs inspecciona el trànsit de xarxa entrant i eixint filtrant paquets segons l'adreça IP, el protocol (TCP/UDP) i el número de port.
- **Regles d'entrada (*Inbound Rules*):** Controlen quines aplicacions externes poden establir connexió amb serveis allotjats a l'ordinador.
- **Regles d'eixida (*Outbound Rules*):** Regulen les peticions que els programes instal·lats fan cap a Internet o cap a altres màquines de la xarxa local.

Per auditar o crear regles mitjançant PowerShell com a administrador:
```powershell
# Consultar l'estat dels tres perfils del tallafocs (Domini, Privat, Públic)
Get-NetFirewallProfile | Select-Object Name, Enabled

# Bloquejar el port TCP 445 (protocol SMB v1 vulnerable) per a trànsit entrant
New-NetFirewallRule -DisplayName "Bloqueig_SMB_Inbound_Taller" -Direction Inbound -LocalPort 445 -Protocol TCP -Action Block
```

## 9.3 Gestió de contrasenyes robustes i autenticació 2FA

Més del 80% dels accessos no autoritzats a comptes personals o corporatius es produeixen per l'ús de **contrasenyes febles o repetides** (com `123456`, `admin` o dades personals fàcils d'esbrinar).

### Regles d'or per a una contrasenya robusta
1. **Longitud mínima:** Un mínim de **12 a 16 caràcters** (la longitud incrementa exponencialment l'espai de claus frenant atacs de força bruta).
2. **Combinació de caràcters:** Utilitza caràcters de 4 conjunts diferents: majúscules (`A-Z`), minúscules (`a-z`), dígits (`0-9`) i símbols (`#`, `!`, `?`, `%`).
3. **La tècnica de la frase de pas (*Passphrase*):** En lloc de recordar una seqüència caòtica curta, és molt més segur memoritzar una frase llarga amb caràcters especials:
   Exemple: `ElMeuRouterFuncionaCorrectament#2026!`
4. **No reutilització de claus:** Si un servei web extern pateix una bretxa de seguretat, els atacants provaran eixa mateixa credencial als correus d'empresa o accessos administratius.

---

### Autenticació de Doble Factor (2FA - *Two-Factor Authentication*)
El doble factor afegeix una segona capa de verificació independent:
- **Factor 1 (Allò que saps):** La contrasenya o frase de pas mestra.
- **Factor 2 (Allò que tens o ets):** Un codi d'un sol ús (TOTP) generat per una aplicació mòbil d'autenticació (com Google Authenticator o Microsoft Authenticator), una clau de seguretat física USB (YubiKey) o dades biomètriques.
- Encara que un atacant esbrine la contrasenya, **no podrà accedir al servei** en no disposar del segon factor físic.

## 9.4 Navegació segura, certificats web i descàrregues fiables

El navegador web és la via de comunicació amb serveis externs, però també el principal punt d'entrada de riscos si no s'apliquen hàbits prudents.

### Protocols web: HTTP vs HTTPS
- **HTTP (*HyperText Transfer Protocol*):** Les dades viatgen en text pla sense xifrar a través de la xarxa. En xarxes públiques o Wi-Fi obertes, qualsevol intermediari pot interceptar la informació transmesa.
- **HTTPS (*HTTP Secure*):** La comunicació s'estableix mitjançant una connexió xifrada mitjançant protocols **TLS/SSL**.
  - A la barra d'adreces apareix la icona del **cadenat de seguretat**.
  - Assegura dues propietats: **confidencialitat** (les dades són inaccessibles a tercers) i **autenticitat** (un certificat digital emès per una autoritat de certificació valida que el servidor és qui afirma ser).

---

### Bones pràctiques per a descàrregues fiables de programari
1. **Descàrrega directa des de la font oficial:** Descarregar sempre des dels llocs oficials dels desenvolupadors (`libreoffice.org`, `videolan.org`). Evitar servidors intermediaris que inclouen programari brossa publicitari (*adware*).
2. **Desactivació de notificacions de llocs desconeguts:** Molts llocs web enganyosos demanen permís de notificacions que posteriorment inunden l'escriptori amb anuncis emergents d'infeccions inexistents.
3. **Verificació d'extensions de fitxer:** Si es descarrega un suposat document PDF o imatge i l'arxiu té una extensió executable (`.exe`, `.scr`, `.bat` o `.vbs`), cal eliminar-lo immediatament.

## 9.5 Projecte integrador d'explotació i posada a punt

### Objectiu del Projecte Final d'OACE
Com a projecte de cloenda de 2n d'FP Bàsica, cada equip de taller rep una estació de treball per executar un protocol integral de **neteja física, instal·lació de sistema operatiu, configuració de seguretat, paquet d'utilitats i lliurament del servei**.

---

### Fases d'execució del Projecte

#### Fase 1: Recepció i comprovació de maquinari
1. Neteja de pols interna del xassís amb aspirador de taller o aire comprimit sec.
2. Arrencada a la BIOS/UEFI: comprovació de la CPU, quantitat de memòria RAM i detecció de la unitat d'emmagatzematge.
3. Diagnòstic S.M.A.R.T. de la salut del disc dur per descartar sectors danyats.

#### Fase 2: Instal·lació neta del Sistema Operatiu
1. Connexió de la unitat USB d'arrencada amb taula de particions GPT.
2. Instal·lació neta de Windows 10/11 o distribució Linux de taller.
3. Configuració de la política d'usuaris:
   - Compte `administrador` protegit amb contrasenya forta per a manteniment tècnic.
   - Compte `usuari` estàndard d'ús diari sense privilegis administratius.

#### Fase 3: Instal·lació de controladors i actualitzacions
1. Obertura de l'Administrador de dispositius per verificar que no queden controladors absents ni triangles grocs d'alerta (!).
2. Instal·lació de controladors del conjunt de xips (*chipset*), targeta de xarxa i vídeo.
3. Execució de les actualitzacions del sistema fins a deixar l'equip completament al dia.

#### Fase 4: Paquet bàsic d'utilitats d'explotació
Desplegament ràpid mitjançant `winget` de les eines de treball:
- Paquet ofimàtic: **LibreOffice**.
- Compressor d'arxius: **7-Zip**.
- Lector de documents: **Adobe Acrobat Reader**.
- Reproductor multimèdia: **VLC Media Player**.
- Eina d'assistència remota: **AnyDesk**.

#### Fase 5: Seguretat i imatge de fàbrica final
1. Verificació de la protecció en temps real i actualització de signatures de Windows Defender.
2. Neteja de fitxers temporals i residus de la instal·lació (`cleanmgr`).
3. Arrencada amb Clonezilla Live i **generació de la imatge de seguretat neta de fàbrica (*savedisk*)** emmagatzemada al servidor de còpies del taller.

#### Fase 6: Redacció de la Memòria Tècnica de Lliurament
Elaboració del document final amb el full de característiques de l'equip, comprovacions efectuades, documentació de contrasenyes en suport segur i signatura del tècnic responsable.

## 📝 Quadern d'Activitats Pràctiques i Reptes de Laboratori

### Bloc A: Fonaments, Dimensionament i Diagnòstic Tècnic

#### Exercici 1: Càlcul d'espai de cerca, entropia i robustesa de contrasenyes
La resistència d'una contrasenya davant d'atacs automatitzats de força bruta depèn de l'espai total de combinacions possibles ($S$) i de la seua entropia d'informació ($E$):
$$S = N^L \quad , \quad E = L \cdot \log_2(N) \text{ bits}$$
On $L$ és la longitud en nombre de caràcters i $N$ la mida del conjunt de caràcters possibles.

1. **Contrasenya feble (PIN numèric de 6 xifres):**
   - El conjunt numèric conté $N = 10$ caràcters (`0-9`). Longitud $L = 6$.
   - Calcula el nombre total de combinacions possibles:
     $$S_{\text{PIN}} = 10^6 = 1.000.000 \text{ combinacions}$$
   - Si un programa d'atac per força bruta prova $100.000\text{ claus/segon}$, calcula quants segons trigarà com a màxim a trencar el codi PIN:
     $$t = \frac{1.000.000}{100.000} = \dots \text{ segons}$$
2. **Frase de pas robusta de taller ($L = 14$ caràcters):**
   - El conjunt inclou majúscules (26), minúscules (26), números (10) i símbols especials (33): $N = 95$.
   - Calcula el volum total de combinacions possibles ($S = 95^{14}$).
   - Calcula l'entropia de la clau sabent que $\log_2(95) \approx 6{,}57$:
     $$E = 14 \cdot 6{,}57 = \dots \text{ bits d'entropia}$$
   - Si un clúster d'atac modern és capaç de provar $10.000.000.000$ ($10^{10}$) combinacions per segon, quants anys requeriria un atac complet de força bruta per trencar aquesta clau?

#### Exercici 2: Auditoria de regles de tallafocs i protecció de ports de xarxa
Analitza les següents regles de seguretat del tallafocs i completa la matriu d'avaluació de risc:

```powershell
# Comanda 1: Creació de regla de bloqueig per a un port no segur
New-NetFirewallRule -DisplayName "Bloqueig_Telnet_Taller" -Direction Inbound -LocalPort 23 -Protocol TCP -Action Block

# Comanda 2: Consulta de regles entrants que bloquegen trànsit
Get-NetFirewallRule -Direction Inbound -Action Block | Select-Object DisplayName, Enabled, Direction
```

1. Per què el protocol Telnet (port TCP 23) es considera un risc greu de seguretat en una xarxa corporativa i s'ha de substituir sempre per SSH (port TCP 22)?
2. Si un servei web corporatiu necessita publicar un panell d'administració, és convenient canviar el port per defecte o limitar la regla de tallafocs únicament a les adreces IP de la xarxa d'administració? Justifica la resposta.

#### Exercici 3: Pressupost i estimació de temps de posada a punt d'un parc informàtic
Un centre educatiu requereix posar a punt un parc de 15 ordinadors de taller per a les noves aules d'informàtica.
Es comparen dos procediments operatius:

1. **Mètode Tradicional (Configuració manual màquina per màquina):**
   - Neteja de maquinari i canvi de pasta tèrmica: $20\text{ min/equip}$.
   - Instal·lació neta del sistema operatiu i controladors: $35\text{ min/equip}$.
   - Instal·lació manual d'aplicacions des de la web: $25\text{ min/equip}$.
   - Ajustos de seguretat i memòria de lliurament: $10\text{ min/equip}$.
   - Calcula el temps total en minuts i hores per als 15 equips:
     $$T_{\text{manual}} = 15 \times (20 + 35 + 25 + 10) = \dots \text{ minuts} = \dots \text{ hores}$$
2. **Mètode Industrial Professional (Clonat multicast + scripts d'automatització):**
   - Neteja de maquinari (procés físic): $15 \times 20\text{ min} = 300\text{ min}$.
   - Creació de la imatge patró (*Golden Master*) en un equip mestre: $60\text{ min}$.
   - Desplegament massiu simultani dels 15 equips per xarxa multicast amb Clonezilla Server: $25\text{ min}$ (en total per a tota l'aula).

### Bloc B: Reptes Pràctics de Laboratori i Taller / Comandes

#### Repte 1: Auditoria de seguretat en temps real amb Windows Defender i protecció anti-ransomware
- **Objectiu:** Verificar l'estat dels motors de seguretat de l'estació de treball i activar la protecció de carpetes contra xifratge maliciós.
- **Procediment de taller:**
  1. Obre PowerShell com a administrador i consulta l'estat dels mòduls de Windows Defender:
     ```powershell
     Get-MpComputerStatus | Select-Object AntivirusEnabled, RealTimeProtectionEnabled, AntivirusSignatureAge, IoavProtectionEnabled
     ```
  2. Comprova que `RealTimeProtectionEnabled` té el valor `True` i que la signatura d'antivirus té menys de 2 dies d'antiguitat.
  3. Activa la funció de protecció contra segrest de dades (*Controlled Folder Access*):
     ```powershell
     Set-MpPreference -EnableControlledFolderAccess Enabled
     ```
  4. Executa una anàlisi ràpida de seguretat des del terminal:
     ```powershell
     Start-Process -FilePath "C:\Program Files\Windows Defender\MpCmdRun.exe" -ArgumentList "-Scan -ScanType 1" -Wait
     ```
  5. Verifica a l'historial de protecció de *Seguretat del Windows* que no s'ha detectat cap amenaça activa.

#### Repte 2: Configuració de regles de tallafocs per aïllament d'estació de treball
- **Objectiu:** Crear una política de filtratge per bloquejar ports no segurs en la xarxa del taller.
- **Procediment de taller:**
  1. Executa la consola avançada del tallafocs (`wf.msc`) o utilitza PowerShell amb permisos d'administrador.
  2. Crea una regla d'entrada per bloquejar de manera preventiva el port TCP 445 (trànsit de fitxers SMB potencialment vulnerable a atacs tipus WannaCry):
     ```powershell
     New-NetFirewallRule -DisplayName "Bloqueig_SMB_Inbound_FPB" -Direction Inbound -LocalPort 445 -Protocol TCP -Action Block
     ```
  3. Crea una segona regla per permetre el trànsit d'assistència remota RDP (port TCP 3389) únicament si prové de la subxarxa d'aula (per exemple `192.168.1.0/24`):
     ```powershell
     New-NetFirewallRule -DisplayName "Permetre_RDP_Aula_FPB" -Direction Inbound -LocalPort 3389 -Protocol TCP -Action Allow -RemoteAddress "192.168.1.0/24"
     ```
  4. Obre la consola gràfica `wf.msc` i comprova visualment que ambdues regles apareixen a la llista de *Regles d'entrada* amb les seues icones d'estat respectives.

#### Repte 3: Projecte integral d'explotació i posada a punt d'un equip de taller
- **Objectiu:** Completar el cicle integral d'adequació d'una estació de treball de taller d'acord amb les 6 fases professionals.
- **Procediment de taller:**
  1. **Fase 1 (Hardware):** Retira la tapa del xassís, neteja els ventiladors amb brotxa antiestàtica i aire comprimit, i verifica a la UEFI la velocitat de la CPU i reconeixement de la memòria RAM.
  2. **Fase 2 (Sistema Operatiu):** Instal·la Windows 10/11 en net en mode UEFI/GPT. Crea el compte `Administrador` amb contrasenya forta de més de 14 caràcters i el compte `Usuari` estàndard per a ús diari.
  3. **Fase 3 (Controladors):** Obre l'Administrador de dispositius (`devmgmt.msc`) i comprova que no hi ha cap controlador desconegut ni triangles d'avaria.
  4. **Fase 4 (Programari):** Obre PowerShell i instal·la amb `winget` les utilitats corporatives:
     ```powershell
     winget install --id 7zip.7zip -e --silent --accept-package-agreements
     winget install --id VideoLAN.VLC -e --silent
     winget install --id TheDocumentFoundation.LibreOffice -e --silent
     winget install --id AnyDeskSoftwareGmbH.AnyDesk -e --silent
     ```
  5. **Fase 5 (Imatge de Fàbrica):** Executa `cleanmgr` per purgar fitxers temporals, reinicia amb Clonezilla Live i crea la imatge de disc `Imatge_Entrega_Taller_FPB` en un dispositiu extern.
  6. **Fase 6 (Lliurament):** Emplena el formulari tècnic de recepció i entrega amb les característiques del maquinari, sistema operatiu instal·lat, data d'actualització i signatura de conformitat.
