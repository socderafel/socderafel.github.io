# 1.5 Hipervisors de Tipus 1 i Tipus 2 (VirtualBox)

L'**hipervisor** o **VMM (*Virtual Machine Monitor*)** és el programa encarregat de crear, gestionar i coordinar l'accés de les màquines virtuals al maquinari físic de l'ordinador.

---

### 1. Tipus d'Hipervisors

| Tipus d'Hipervisor | Com Funciona | On s'utilitza? | Exemples Reals |
| :--- | :--- | :--- | :--- |
| **Tipus 1 (*Bare-Metal* o Nadiu)** | S'instal·la directament sobre el maquinari físic de l'equip (*sobre el ferro*), sense necessitat de cap sistema operatiu previ. | Centres de dades (CPD) i servidors empresarials d'alt rendiment. | VMware ESXi, Proxmox VE, Microsoft Hyper-V Server. |
| **Tipus 2 (*Hosted* o Allotjat)** | S'instal·la com una aplicació convencional damunt del sistema operatiu amfitrió existent. | Equips personals d'escriptori, tallers d'estudi i desenvolupament. | **Oracle VM VirtualBox**, VMware Workstation Player. |

---

### 2. Modes de Connexió de Xarxa Virtual a VirtualBox
Quan configurem la targeta de xarxa d'una màquina virtual a VirtualBox, podem triar:
- **Mode NAT (*Network Address Translation* - Per defecte):**
  - La màquina virtual rep una IP privada aïllada (habitualment `10.0.2.15`).
  - Té accés directe a Internet, però **cap altre equip de la xarxa física de l'aula pot connectar-se a ella**.
  - És el mode més segur per a navegar i provar eines de forma aïllada.
- **Mode Adaptador Pont (*Bridged Adapter*):**
  - La màquina virtual es connecta a la xarxa física exactament igual que si fóra un ordinador real connectat amb cable a la paret.
  - Rep una adreça IP del mateix rang que els equips de l'aula (per exemple, `192.168.1.X`).
  - Permet compartir carpetes i serveis amb els companys de l'aula.
