# 1.2 Llicències i Tipus de Programari: Lliure vs Propietari

No tots els sistemes operatius ni aplicacions tenen les mateixes condicions legals d'ús, còpia o modificació. Com a tècnic/a de sistemes, has de conèixer les llicències per garantir el compliment de la llei a les empreses.

---

### 1. Programari Propietari (*Privatiu*)
- El codi font està tancat i és secret de l'empresa creadora.
- L'usuari adquireix únicament una **llicència d'ús temporal o per equip**, no la propietat del programa.
- **Prohibicions habituals:** Està prohibit modificar el codi, descompilar-lo, fer-ne còpies per a altres equips o redistribuir-lo.
- *Exemples:* Microsoft Windows 11, Apple macOS, Microsoft Office comercial.

---

### 2. Programari Lliure (*Free Software / Open Source*)
Definit per la *Free Software Foundation* (FSF), respecta les **quatre llibertats fonamentals**:
1. **Llibertat 0:** Executar el programa per a qualsevol propòsit (educatiu, comercial, militar).
2. **Llibertat 1:** Estudiar com funciona el programa i canviar el seu codi font per adaptar-lo a les teues necessitats.
3. **Llibertat 2:** Redistribuir còpies per ajudar el teu veí o companys d'aula.
4. **Llibertat 3:** Millorar el programa i fer públiques les millores perquè se'n beneficie tota la comunitat.
- *Llicència emblemàtica:* **GNU GPL** (*General Public License*).
- *Exemples:* Nucli Linux, **LliureX** (sistema operatiu educatiu de la Generalitat Valenciana basat en Ubuntu), LibreOffice, GIMP.

> [!NOTE]
> **Programari Lliure no és el mateix que Programari Gratuït (*Freeware*):** El *freeware* és gratuït però té el codi tancat i no et permet modificar-lo (com Adobe Acrobat Reader). El programari lliure et dóna accés complet al seu codi font.
