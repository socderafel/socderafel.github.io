# 1.3 Arquitectures de Maquinari i Sistemes (32 bits vs 64 bits)

En informàtica, el terme **amplària de bus o arquitectura** fa referència a la quantitat de bits que el processador (CPU) i el sistema operatiu poden processar en una sola operació de càlcul i utilitzar per adreçar memòria RAM.

---

### 1. El Límit Matemàtic de l'Arquitectura de 32 bits (x86)
- Un sistema de 32 bits utilitza adreces de memòria de 32 dígits binaris.
- **Càlcul matemàtic de capacitat:**
  $$2^{32} = 4.294.967.296\text{ bytes} = 4\text{ Gigabytes (GB)}$$
- **Conseqüència pràctica:** Si instal·les un sistema operatiu de 32 bits en un ordinador amb 16 GB de RAM física, **el sistema només reconeixerà i podrà utilitzar un màxim d'uns 3,5 a 4 GB!** Els altres 12 GB quedaran totalment malbaratats.

---

### 2. L'Arquitectura Moderna de 64 bits (x64 / x86_64)
- Utilitza registres de 64 bits.
- **Capacitat d'adreçament teòrica:** $2^{64}$ bytes (16 Exabytes, milers de milions de Gigabytes).
- **Compatibilitat cap arrere (*Retrocompatibilitat*):** Un processador i sistema operatiu de 64 bits pot executar perfectament aplicacions antigues de 32 bits (en Windows, es guarden a la carpeta `C:\Program Files (x86)`).
- ❌ **Alerta tècnica:** Un sistema o processador de 32 bits **mai no pot executar** programari de 64 bits.

---

### 3. Comprovació de l'Arquitectura per Consola
- **En Windows (PowerShell / CMD):**
  ```powershell
  wmic cpu get architecture, name
  ```
  O bé consultant l'entorn amb `echo %PROCESSOR_ARCHITECTURE%` (retorna `AMD64` per a 64 bits).
- **En Linux / LliureX (Terminal):**
  ```bash
  uname -m
  ```
  - Si respon `x86_64`: Sistema de 64 bits.
  - Si respon `i686` o `i386`: Sistema antic de 32 bits.
