# 4.4 Usuaris, permisos (chmod/chown) i el comandament sudo

En Linux, la seguretat es fonamenta en el control d'accés **POSIX**. Cada arxiu i directori pertany estrictament a un **usuari propietari** i a un **grup de treball**, disposant d'un conjunt de permisos que determinen qui pot llegir-lo, modificar-lo o executar-lo.

---

### La matriu de permisos POSIX (`rwx`)

Quan fem `ls -l` a la terminal, veiem 10 caràcters al començament de cada línia (ex: `-rwxr-xr--`):
- El primer caràcter indica el tipus: `-` per a fitxer ordinari, `d` per a directori (*directory*).
- Els 9 caràcters següents es divideixen en 3 triplets:

```text
TRIPLETS DE PERMISOS LINUX
-  [ r w x ]  [ r - x ]  [ r - - ]
   Propietari    Grup      Altres
```

| Permís | Significat en Fitxer | Significat en Directori | Valor Octal |
| :---: | :--- | :--- | :---: |
| **`r`** (*read*) | Llegir el contingut de l'arxiu | Llistar els arxius de la carpeta (`ls`) | **4** |
| **`w`** (*write*) | Modificar o desar canvis | Crear o esborrar arxius a la carpeta | **2** |
| **`x`** (*execute*) | Executar com a programa/script | Entrar a la carpeta amb `cd` | **1** |

Sumant els valors obtenim els codis numèrics clàssics:
- **`7` (4+2+1):** Permís total (`rwx`).
- **`6` (4+2):** Lectura i escriptura (`rw-`), habitual per a documents.
- **`5` (4+1):** Lectura i execució (`r-x`), habitual per a carpetes o programes.
- **`4`:** Només lectura (`r--`).
- **`0`:** Cap permís (`---`).

Exemples d'ús de `chmod`:
```bash
# Donar permisos 755 (propietari rwx, grup i altres r-x)
chmod 755 script.sh

# Donar permisos 644 (propietari rw-, grup i altres r--)
chmod 644 document.txt
```

---

### Canvi de propietari amb `chown`

Si volem transferir la propietat d'un fitxer o carpeta a un altre usuari i grup, utilitzem `chown`:

```bash
# Canviar el propietari a 'carles' i el grup a 'docents'
sudo chown carles:docents informe.pdf

# Canviar el propietari de forma recursiva a tota una carpeta
sudo chown -R carles:docents /var/www/html/
```

---

### El comandament `sudo` (SuperUser DO)

Linux no permet iniciar sessió gràfica directa com a root per seguretat. En el seu lloc, els usuaris autoritzats utilitzen **`sudo`** al començament de qualsevol ordre d'administració (com ara instal·lar paquets, reiniciar serveis o editar configuracions a `/etc`):

```bash
sudo nano /etc/network/interfaces
```

El sistema demana la contrasenya del propi usuari i li atorga permisos d'administrador durant 15 minuts.
