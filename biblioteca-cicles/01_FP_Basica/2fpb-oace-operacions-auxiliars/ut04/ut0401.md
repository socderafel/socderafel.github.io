# 4.1 L'entorn gràfic en Linux (GNOME/MATE) i l'arbre de directoris FHS

Les distribucions GNU/Linux actuals ofereixen entorns d'escriptori moderns i elegants (**GNOME** en Ubuntu estàndard, **MATE** en LliureX, XFCE per a equips antics) juntament amb l'explorador gràfic de fitxers **Nautilus**. No obstant això, la gran diferència respecte a Windows rau en la seua estructura d'emmagatzematge: **l'estàndard FHS (*Filesystem Hierarchy Standard*)**.

---

### La gran diferència: Lletres d'unitat vs Arrel única `/`

- **En Microsoft Windows:** Cada disc dur, partició o pendrive té una lletra d'unitat assignada (`C:`, `D:`, `E:`).
- **En GNU/Linux:** No existeixen les lletres d'unitat. Tot el sistema comença en un únic punt d'origen anomenat **arrel (`/`)**. Les particions addicionals i els pendrives es connecten ("es munten") com a carpetes dins d'aquest arbre.

```text
JERARQUIA PRINCIPAL DEL SISTEMA DE FITXERS DE LINUX (FHS)
/ (Arrel)
├── bin       -> Comandes binàries essencials del sistema (ls, cp, rm, bash)
├── boot      -> Arxius del nucli Linux (vmlinuz) i menú GRUB d'arrencada
├── dev       -> Fitxers de dispositiu que representen el maquinari (/dev/sda, /dev/nvme)
├── etc       -> Fitxers de configuració de tots els programes del sistema
├── home      -> Carpetes personals dels usuaris ordinaris (/home/alumne)
├── media     -> Punt de muntatge automàtic per a pendrives USB i discs externs
├── opt       -> Programari addicional de tercers (Google Chrome, Discord)
├── root      -> Carpeta personal del superusuari administrador (root)
├── tmp       -> Fitxers temporals (es buiden automàticament en reiniciar)
└── var       -> Dades variables (registres de sistema /var/log, servidors web /var/www)
```

> [!NOTE]
> La carpeta personal de l'usuari ordinari és `/home/[usuari]` (abreujada sovint com `~`). És l'únic lloc on un usuari normal té permís complet d'escriptura per defecte.
