# 4.3 Comandes bàsiques de navegació i gestió de fitxers

Dominar les ordres essencials de terminal permet moure's amb total fluïdesa pel sistema de fitxers, crear carpetes estructurades, copiar arxius de configuració i editar documents sense dependre de cap entorn gràfic.

---

### Taula d'ordres imprescindibles de terminal

| Comanda | Descripció | Exemple d'ús |
| :--- | :--- | :--- |
| **`pwd`** | *Print Working Directory:* Mostra la ruta absoluta de la carpeta actual. | `pwd` -> `/home/alumne/practiques` |
| **`ls`** | Llista els arxius i carpetes del directori actual. | `ls -la` (mostra arxius ocults amb permisos i mides). |
| **`cd`** | Canvia de directori (*Change Directory*). | `cd /var/log` (ruta absoluta) o `cd ..` (puja un nivell). |
| **`mkdir`** | Crea un nou directori (*Make Directory*). | `mkdir -p taller/equips/pc01` (crea l'arbre complet). |
| **`cp`** | Copia fitxers o carpetes senceres. | `cp arxiu.txt copia.txt` o `cp -r carpeta/ backup/` |
| **`mv`** | Mou o canvia el nom d'un fitxer o directori. | `mv antic.txt nou.txt` o `mv fitxer.pdf /home/alumne/` |
| **`rm`** | Elimina fitxers o directoris (*Remove*). | `rm fitxer.txt` o `rm -rf carpeta_vell/` |
| **`cat`** | Mostra tot el contingut d'un fitxer de text per pantalla. | `cat /etc/os-release` |
| **`nano`** | Editor de text senzill integrat en la consola. | `nano configuracio.conf` (Desar: `Ctrl + O`, Eixir: `Ctrl + X`). |

---

### Rutes relatives vs Rutes absolutes

```text
COMPROVACIÓ DE TIPUS DE RUTES
┌─────────────────────────────────┬─────────────────────────────────┐
│ Ruta Absoluta                   │ Ruta Relativa                   │
├─────────────────────────────────┼─────────────────────────────────┤
│ • Comença sempre des de l'arrel │ • Comença des d'on et trobes ara│
│ • Sempre comença per la barra / │ • Mai comença per la barra /    │
│ • Exemple: /home/alumne/notes   │ • Exemples:                     │
│ • Funciona estigues on estigues │   - 'cd notes' (baixa a notes)  │
│                                 │   - 'cd ..' (puja a la mare)    │
└─────────────────────────────────┴─────────────────────────────────┘
```
