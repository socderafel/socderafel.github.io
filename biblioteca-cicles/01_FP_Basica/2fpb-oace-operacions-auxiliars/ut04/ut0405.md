# 4.5 Pràctica: Gestió de paquets i programari amb apt

A diferència de Windows, on cada usuari busca aplicacions en llocs web diferents descarregant fitxers `.exe` desconeguts amb alt risc de malware, en GNU/Linux (Debian, Ubuntu, LliureX) el programari es gestiona des de **repositoris oficials verificats** mitjançant el gestor de paquets **APT** (*Advanced Package Tool*).

---

### El cicle de vida de gestió de paquets APT

```text
CICLE DE GESTIÓ APT
1. sudo apt update
   └─ Consulta a Internet i actualitza la llista local de versions disponibles.
2. sudo apt upgrade
   └─ Descarrega i actualitza tots els programes instal·lats que tinguen versió nova.
3. sudo apt install [paquet]
   └─ Resol dependències automàticament i instal·la l'aplicació.
4. sudo apt remove --purge [paquet]
   └─ Desinstal·la el programa i elimina completament els seus fitxers de configuració.
5. sudo apt autoremove
   └─ Neteja llibreries òrfenes que ja no utilitza cap programa.
```

> [!WARNING]
> La comanda `sudo apt update` **NO instal·la res**. Només refresca l'índex de prestatgeries de la botiga de programari. Per aplicar les actualitzacions s'ha d'executar posteriorment `sudo apt upgrade`.

---

### On es guarden els repositoris d'Ubuntu/LliureX?

La llista de servidors oficials d'on APT descarrega el programari segur està registrada al fitxer de text:

```bash
/etc/apt/sources.list
```

I a la carpeta `/etc/apt/sources.list.d/`. Només els repositoris signats digitalment amb claus GPG vàlides són acceptats pel gestor de paquets, protegint l'ordinador contra virus i programari manipulat.
