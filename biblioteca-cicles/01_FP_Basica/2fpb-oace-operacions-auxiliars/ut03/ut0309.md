# 3.9 Sitios web:  Mi sitio web personal con WordPress

Para obtener un 10 debes

responder afirmativamente a las siguientes preguntas:

1. ¿Tienes cuatro páginas web?:

Portada

Curriculum

Mi grado medio

Mi futuro trabajo

2. ¿Incluye

cada página:

Imágenes (2 o más)?

Diferentes fuentes (para distinguir entre apartados y texto)?

Utilizar diferentes colores?

3. ¿Incluye

el sitio web al menos una tabla?

4. ¿Están publicadas todas las

páginas de tu sitio web?

5. ¿Tiene

tu sitio web un nombre de dominio que siga el formato nombreapellido1apellido2.wordpress.com?

6. ¿Has

creado una entrada por cada una de tus cuatro aficiones?

7. ¿Tiene cada una de las entradas

una imagen?

una extensión de texto de al menos cinco líneas?

8. ¿Has

creado una página llamada Mis aficiones en la que se incluya un bloque que

muestre las cuatro entradas?

9. ¿Has creado en la página de

portada (Página de Inicio) un bloque de navegación que tenga accesos directos a

las páginas

Curriculum?

Mi grado medio?

Mi futuro trabajo?

Mis aficiones?

Crea un documento de Word con el nombre de tu sitio web y súbelo a esta tarea.
