# 3.1 L'entorn gràfic de Windows: Escriptori, barra de tasques i configuració

L'entorn gràfic d'un sistema operatiu permet a l'usuari interactuar amb l'ordinador mitjançant finestres, icones, menús i punters del ratolí. En l'àmbit professional del servei tècnic, és fonamental conèixer tant la interfície d'usuari moderna com les vies ràpides de diagnòstic integrades en el sistema.

---

### Dues vies de configuració en Windows modern

En Windows 10 i 11 conviuen dos panells de control amb propòsits diferents:

```text
VIES DE CONFIGURACIÓ DE WINDOWS
┌─────────────────────────────────┬─────────────────────────────────┐
│ Configuració Moderna (UWP)      │ Panell de Control Clàssic       │
├─────────────────────────────────┼─────────────────────────────────┤
│ • Drecera: Win + I              │ • Comanda: control              │
│ • Disseny tàctil i simplificat  │ • Disseny tècnic detallat       │
│ • Per a usuaris quotidians      │ • Per a administradors de taller│
│ • Xarxes bàsiques, pantalla,    │ • Eines administratives, xarxes │
│   actualitzacions de Windows    │   avançades, gestió de dominis  │
└─────────────────────────────────┴─────────────────────────────────┘
```

---

### Dreceres de teclat essencials per al tècnic de manteniment

Un tècnic d'ordinadors resol incidències molt més ràpid si domina les combinacions de tecles del sistema en lloc de navegar per menús:

| Drecera de Teclat | Acció que executa | Utilitat en taller |
| :--- | :--- | :--- |
| **`Win + R`** | Obre la finestra **Executar** | Permet llançar consoles de gestió directa (`devmgmt.msc`, `diskmgmt.msc`, `cmd`, `ncpa.cpl`). |
| **`Win + X`** | Obre el **Menú d'enllaços ràpids per a administradors** | Accés instantani a Terminal/PowerShell com a administrador, Administrador de tasques i Visor d'esdeveniments. |
| **`Ctrl + Maj + Esc`** | Obre directament l'**Administrador de tasques** | Tanca processos congelats sense passar per la pantalla blava de bloqueig. |
| **`Win + E`** | Obre l'**Explorador de fitxers** | Navegació ràpida per discs, carpetes d'usuari i unitats de xarxa. |
| **`Win + Pause/Break`** | Obre la finestra de **Propietats del sistema** | Consulta instantània de model de CPU, memòria RAM instal·lada i versió de Windows. |

---

### Ajustos de rendiment visual en equips de baixos recursos

Quan un ordinador de taller té pocs recursos de maquinari (processadors antics o menys de 8 GB de RAM), podem alliberar càrrega de targeta gràfica i CPU desactivant les animacions:

1. Prem `Win + R` i escriu: `sysdm.cpl` (Obre Propietats del sistema).
2. Vés a la pestanya **Opcions avançades** i fes clic a **Configuració** sota l'apartat *Rendiment*.
3. Marca l'opció **Ajusta per obtenir el millor rendiment**. Windows desactivarà les transparències, les ombres i les animacions de les finestres, accelerant notablement la resposta de l'equip.
