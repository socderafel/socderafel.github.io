# 2.5 Pràctica: Instal·lació d'Ubuntu Desktop / LliureX

En aquesta segona pràctica de taller instal·laràs un sistema operatiu de programari lliure basat en GNU/Linux (**Ubuntu Desktop** o **LliureX**, el sistema oficial de la Generalitat Valenciana). Aprendràs la importància de separar el sistema operatiu i els documents d'usuari mitjançant el particionament manual amb l'arrel `/` i `/home`.

---

### Procediment d'instal·lació pas a pas

#### Pas 1: Menú d'inici GRUB i mode Live
1. Arrenca l'ordinador o màquina virtual des de la imatge ISO de Linux.
2. Al menú negre d'arrencada (*GRUB*), selecciona: **Try or Install Ubuntu** (o *LliureX*).
3. El sistema carregarà una sessió completa en memòria RAM sense modificar el disc físic. Aquest és el **mode Live**, idoni per provar si el maquinari (tarja de xarxa, so, pantalla) funciona correctament abans d'instal·lar.
4. Fes doble clic a la icona d'escriptori **Instal·la Ubuntu / LliureX**.

#### Pas 2: Llengua i configuració de maquinari
1. Tria l'idioma **Valencià** (o Català) a la columna esquerra.
2. Comprova la distribució de teclat prement tecles com la `ç` i els accents a la caixa de prova.
3. Tria l'opció **Instal·lació normal** i activa la casella de controladors de tercers i formats multimèdia.

#### Pas 3: Particionament manual avançat (Bona pràctica de taller)
A la pantalla de tipus d'instal·lació, tria **Més opcions (*Something else*)** per crear l'esquema òptim de particions:

```text
ESQUEMA DE PARTICIONS EN LINUX RECOMANAT (DISC DE 30 GB)
┌──────────────────────┬──────────────────────┬────────────────────────┐
│ Partició 1: EFI      │ Partició 2: Arrel /  │ Partició 3: /home      │
│ • Mida: 512 MB       │ • Mida: 18.000 MB    │ • Mida: Resta (~11 GB) │
│ • Tipus: EFI System  │ • Format: ext4       │ • Format: ext4         │
│ • Carregador d'inici │ • Sistema i programes│ • Documents personals  │
└──────────────────────┴──────────────────────┴────────────────────────┘
```

1. Fes clic a **Taula de particions nova** si el disc és buit.
2. Crea la **partició 1**:
   - Mida: `512 MB`, Tipus: Primària, Utilitza com a: **Partició del sistema EFI**.
3. Crea la **partició 2 (Arrel)**:
   - Mida: `18000 MB`, Tipus: Primària, Format: `ext4`, Punt de muntatge: **`/`**.
4. Crea la **partició 3 (Dades d'usuaris)**:
   - Mida: Tot l'espai restant, Tipus: Primària o Lògica, Format: `ext4`, Punt de muntatge: **`/home`**.
5. Fes clic a **Instal·la ara** i confirma els canvis en el disc.

#### Pas 4: Usuari, contrasenya i finalització
1. Tria la zona horària (*Madrid / Espanya*).
2. Introdueix el teu nom, el nom de la màquina (ex: `aula-fpb-01`) i una contrasenya segura.
3. Espera que acabe la còpia de paquets i reinicia l'equip retirant el pendrive quan el sistema ho demane.
4. Obre un terminal (`Ctrl + Alt + T`) i executa `df -h` per comprovar que `/` i `/home` estan muntades com a unitats separades.
