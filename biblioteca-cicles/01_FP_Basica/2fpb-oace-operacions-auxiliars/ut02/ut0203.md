# 2.3 Preparació de memòries USB arrancables amb Rufus i Ventoy

Antigament, els sistemes operatius s'instal·laven mitjançant discs òptics CD-ROM o DVD. En l'actualitat, pràcticament cap ordinador incorpora lectors òptics i totes les tasques d'instal·lació, manteniment i rescat es realitzen mitjançant memòries **USB arrencables** (*Bootable USB* o *LiveUSB*).

> [!WARNING]
> No és suficient amb copiar un fitxer `.iso` a dins del pendrive com si fora una pel·lícula o un document de text. Perquè la BIOS/UEFI de l'equip puga reconèixer la memòria USB com a dispositiu d'arrencada, cal escriure un codi de llançament (*bootloader*) al sector d'arrencada del pendrive.

---

### Eina 1: Rufus — Creació d'USB per a una imatge única
**Rufus** és una aplicació portable per a Windows extremadament ràpida i eficient per gravar una imatge ISO en un pendrive:

1. **Dispositiu:** Selecciona el pendrive de destí (mínim 8 GB o 16 GB).
2. **Elecció d'arrencada:** Fes clic a *SELECCIONA* i tria la imatge ISO desitjada (ex: `Win11_23H2_Valencian_x64.iso`).
3. **Esquema de partició:**
   - **GPT:** Si l'equip és modern amb placa **UEFI**.
   - **MBR:** Si es tracta d'un ordinador antic amb BIOS convencional.
4. **Opcions addicionals per a Windows 11:** Rufus permet eliminar automàticament els requisits estrictes de TPM 2.0, Secure Boot i el compte obligatori de Microsoft per permetre la instal·lació en equips de taller veterans.

---

### Eina 2: Ventoy — La navalla suïssa del tècnic de taller (Multiboot)
**Ventoy** és una eina de codi obert revolucionària que canvia completament la forma de treballar del servei tècnic:

- **Com funciona:** S'instal·la una única vegada al pendrive. Ventoy crea automàticament dues particions: una xicoteta partició d'arrencada protegida i una gran partició d'emmagatzematge en format exFAT.
- **Còpia directa d'ISOs:** Un cop instal·lat, **mai més cal tornar a formatejar el pendrive**. Només cal copiar directament els fitxers `.iso` (com ara la ISO d'Ubuntu, de Windows 10, de Windows 11, Clonezilla o eines de diagnòstic de memòria RAM) arrossegant-los a la carpeta del pendrive.
- **Menú d'arrencada automàtic:** En encendre l'ordinador i arrencar des del pendrive, Ventoy mostra una pantalla gràfica amb la llista de totes les ISOs que hi ha guardades perquè el tècnic trie quina vol executar.

```text
ESTRUCTURA DEL PENDRIVE AMB VENTOY
┌───────────────────────────────────────────────────────────────┐
│ Partició 1 (exFAT - Dades):                                   │
│  ├── Windows_11_Pro.iso                                      │
│  ├── LliureX_21_Desktop.iso                                   │
│  ├── Ubuntu_24_04_LTS.iso                                     │
│  ├── Clonezilla_Live.iso                                      │
│  └── Hiren_Boot_CD.iso                                        │
├───────────────────────────────────────────────────────────────┤
│ Partició 2 (VTOYEFI - Arrencada protegida):                   │
│  └── Gestor d'arrencada GRUB2 per a BIOS i UEFI              │
└───────────────────────────────────────────────────────────────┘
```
