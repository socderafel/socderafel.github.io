# 8.3 Imatge de mapa de bits vs vectorial: formats i resolució

En el tractament digital d'imatges, existeixen dues maneres completament diferents de representar gràfics en un ordinador: **mapa de bits** (*Raster Graphics*) i **gràfics vectorials** (*Vector Graphics*). Saber triar el format adequat evita pèrdues de qualitat i estalvia espai.

---

### Mapa de bits vs Gràfics vectorials

```text
COMPARATIVA DE TECNOLOGIES GRÀFIQUES
┌─────────────────────────────────┬─────────────────────────────────┐
│ Imatges de Mapa de Bits         │ Gràfics Vectorials              │
├─────────────────────────────────┼─────────────────────────────────┤
│ • Composta per una quadrícula de│ • Composta per fórmules         │
│   píxels individuals de color   │   geomètriques (punts, rectes)  │
│ • En ampliar-se es nota el píxel│ • Escalable fins a l'infinit    │
│   (*pixelació* o pèrdua nitidesa)│   sense cap pèrdua de qualitat  │
│ • Idoni per a fotografies reals │ • Idoni per a logotips, icones, │
│ • Formats: JPG, PNG, WEBP, GIF  │   senyalística i disseny CAD    │
│                                 │ • Formats: SVG, AI, EPS         │
└─────────────────────────────────┴─────────────────────────────────┘
```

---

### Formats d'imatge més utilitzats

| Format | Tipus | Compressió | Característica distintiva | Ús recomanat |
| :---: | :---: | :---: | :--- | :--- |
| **JPG / JPEG** | Mapa de bits | Amb pèrdua | No suporta transparència; molt lleuger per a fotos. | Fotografies a webs i xarxes. |
| **PNG** | Mapa de bits | Sense pèrdua | **Suporta canal alfa (transparència perfecta)**. | Captures de pantalla i icones amb fons transparent. |
| **SVG** | Vectorial | Codi XML | Text editable, escalable a qualsevol pantalla retina. | Logotips, iconografia web. |
| **WEBP** | Mapa de bits | Amb/sense pèrdua | Desenvolupat per Google, 30% més lleuger que JPG. | Imatges per a llocs web moderns. |

---

### Resolució espacial: DPI (*Dots Per Inch*)

- **Pantalles digitals (Web):** Funcionen a **72 o 96 DPI**. Utilitzar resolucions majors només fa que l'arxiu pese massa sense cap millora visible.
- **Impressió en paper d'alta qualitat:** Exigeix **300 DPI** perquè el text i les vores de les figures es vegen totalment nítids i definits.
