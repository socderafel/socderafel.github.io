# 7.3 Eines d'inventari i informació de maquinari (CPU-Z, HWMonitor, CrystalDiskInfo)

Per poder reparar, ampliar o pressupostar la millora d'un equip informàtic (ampliació de memòria RAM, canvi de pasta tèrmica o substitució de disc), el tècnic ha de conèixer amb precisió mil·limètrica els components instal·lats sense haver de desmuntar necessàriament la torre.

---

### La tríada d'eines portables de taller

```text
TRÍADA D'EINES DE TELEMETRIA
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ CPU-Z                   │ HWMonitor               │ CrystalDiskInfo         │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Model exacte de CPU   │ • Temperatures en viu   │ • Estat de salut S.M.A.R.T.│
│ • Sòcol i litografia    │ • Voltatges font alim.  │ • Sectors reassignats   │
│ • Model de placa base   │ • Velocitat RPM de      │ • Hores d'ús acumulades │
│ • Tipus i canals de RAM │   ventiladors de torre  │ • Temperatura del disc  │
│   (DDR4/DDR5, Dual Chan)│ • Detecció de coll de   │ • Alerta de fallada     │
│ • Freqüències i timmings│   temperatura (Throttl) │   imminent abans de trencar│
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

---

### Interpretació d'atributs S.M.A.R.T. a CrystalDiskInfo

La tecnologia S.M.A.R.T. (*Self-Monitoring, Analysis and Reporting Technology*) està integrada en l'electrònica de tots els discs durs:
- **Estat 'Bo' (Color Blau):** El disc funciona amb normalitat i sense sectors danyats.
- **Estat 'Risc' (Color Groc):** **ALERTA CRÍTICA DE TALLER.** Indica que han aparegut sectors defectuosos que el disc ha hagut de reassignar a la zona de reserva. **Acció immediata:** Fer còpia de seguretat urgent de les dades de l'usuari i canviar el disc abans que muira.
- **Estat 'Dolent' (Color Roig):** El disc té fallades estructurals greus i pot fallar en qualsevol segon.
