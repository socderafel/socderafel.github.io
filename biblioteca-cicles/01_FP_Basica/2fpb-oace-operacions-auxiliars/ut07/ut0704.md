# 7.4 Eines d'assistència i control remot: RDP, AnyDesk i TeamViewer

En el mercat laboral modern, una gran part dels problemes de programari, configuració de correus i resolució d'incidències d'usuaris es gestionen mitjançant **suport remot** (*Helpdesk* o Centre d'Atenció a l'Usuari CAU), estalviant temps i costos de desplaçament físic.

---

### Protocols i eines de control remot

```text
EINES DE CONTROL REMOT
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ RDP (Escriptori Remot)  │ AnyDesk                 │ TeamViewer              │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Natiu de Windows Pro  │ • Lleuger (~5 MB)       │ • Solució empresarial   │
│ • Per a xarxes locals   │ • Connexió per ID de    │   molt consolidada      │
│ • Bloqueja la pantalla  │   9 dígits              │ • ID i contrasenya      │
│   de l'usuari local     │ • L'usuari local VEU    │   aleatòria per sessió  │
│ • Requereix obrir port  │   què fa el tècnic      │ • Transferència de fitxers│
│   TCP 3389 a l'exterior │ • Travessa routers/NAT  │   i trucada de veu      │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

> [!IMPORTANT]
> **Normes ètiques i legals de suport remot:**
> 1. El tècnic **mai ha d'accedir a l'ordinador d'un client sense el seu consentiment explícit**.
> 2. L'usuari local ha de mantindre el control prioritari del ratolí i poder finalitzar la sessió en qualsevol instant prement el botó de desconnexió.
> 3. No s'ha d'obrir cap document personal, carpeta de fotos o correu electrònic privat de l'usuari durant la intervenció.
