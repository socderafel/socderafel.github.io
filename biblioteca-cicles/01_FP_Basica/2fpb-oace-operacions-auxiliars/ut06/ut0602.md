# 6.2 Tipus de còpies de seguretat: completa, incremental i diferencial

Fer una còpia de tots els discs durs cada dia seria inviable en una empresa gran: prendria massa hores i saturaria l'espai d'emmagatzematge dels servidors. Per aquest motiu, els sistemes professionals combinen diferents tipus de còpies segons la freqüència i el volum de dades que han canviat.

---

### Els tres tipus de còpies de seguretat

```text
TIPOLOGIES DE BACKUP
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ CÒPIA COMPLETA (FULL)   │ CÒPIA INCREMENTAL       │ CÒPIA DIFERENCIAL       │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • Copia el 100% de les  │ • Copia només el que ha │ • Copia tot el que ha   │
│   dades i documents     │   canviat des de        │   canviat des de        │
│ • La més lenta de fer   │   L'ÚLTIMA CÒPIA        │   L'ÚLTIMA COMPLETA     │
│ • La més fàcil i ràpida │   (sigui full o incr)   │ • Creix cada dia que    │
│   de restaurar          │ • La més ràpida de fer  │   passa de la setmana   │
│ • Sol fer-se els caps   │ • Per a restaurar cal la│ • Per a restaurar cal la│
│   de setmana            │   completa + TOTES les  │   completa + L'ÚLTIMA   │
│                         │   incrementals d'ordre  │   diferencial           │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

#### Exemple de restauració pràctica de taller:
Suposem que fem una còpia completa el diumenge i un desastre ocorre el dijous al matí:
- **Estratègia Incremental:** Cal restaurar la *Completa (Dg) + Incremental Dl + Incremental Dt + Incremental Dx*. Si una sola de les incrementals intermèdies es corromp, es perden els dies posteriors.
- **Estratègia Diferencial:** Només cal restaurar la *Completa (Dg) + Diferencial Dx*. Si el fitxer de dimarts està corromput, no importa, perquè la diferencial de dimecres ja contenia tots els canvis acumulats!
