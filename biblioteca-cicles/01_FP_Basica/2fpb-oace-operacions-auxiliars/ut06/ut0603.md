# 6.3 Punts de restauració del sistema en Windows

La funció **Restauració del Sistema** (*System Restore*) de Microsoft Windows permet retornar l'estat del sistema operatiu (arxius de sistema, claus del registre, controladors de dispositiu i aplicacions instal·lades) a un moment anterior en el temps sense alterar ni esborrar els documents personals de l'usuari (fotos, fulls de càlcul o tasques d'escriptori).

---

### Com funciona la tecnologia Shadow Copy (VSS)

Windows utilitza el servei de còpies en ombra de volums (*Volume Shadow Copy Service*):
- Quan s'instal·la un controlador nou, un programa gran o una actualització de Windows Update, el sistema crea un **Punt de Restauració** automàtic.
- També és una **bona pràctica de taller** crear un punt de restauració manual abans de fer tasques de manteniment o neteja de virus:
  1. Prem `Win + R`, escriu `sysdm.cpl` i prem Intro.
  2. Vés a la pestanya **Protecció del sistema**.
  3. Fes clic a **Crea...** i posa-li un nom descriptiu (ex: `Abans_Neteja_Driver_Grafica`).

---

### Com revertir el sistema amb `rstrui.exe`

Si l'equip comença a fallar o es bloqueja en obrir programes:
1. Prem `Win + R` i executa la comanda directa:
   ```cmd
   rstrui.exe
   ```
2. Fes clic a *Següent* i selecciona el punt de restauració amb data anterior al problema.
3. Prem **Detecta programes afectats** per veure quins controladors o programes es desinstal·laran.
4. Confirma i reinicia. Windows revertirà el registre i els binaris de sistema en pocs minuts.

> [!NOTE]
> Restaurar el sistema **mai esborra arxius personals** com treballs de classe o fotografies. No obstant això, qualsevol aplicació o controlador instal·lat amb posterioritat a la data del punt de restauració serà eliminat.
