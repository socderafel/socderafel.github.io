# 3.3 Funcions Estadístiques: SUMA, MITJANA, MAX, MIN i CONTAR

Les **funcions** són fórmules predefinides que incorporen els fulls de càlcul per realitzar operacions complexes de manera instantània sobre desenes o centenars de cel·les.

---

### 1. Sintaxi General d'una Funció
Tota funció segueix l'estructura:
`=NOM_FUNCIO(argument1; argument2...)`
Per exemple, `=SUMA(A1:A50)` suma les 50 cel·les sense haver d'escriure `=A1+A2+A3...`.

---

### 2. Les Cinc Funcions Estadístiques Bàsiques de Taller

| Funció a LibreOffice Calc | Exemple d'Ús | Què calcula exactament? |
| :--- | :--- | :--- |
| **`=SUMA(rang)`** | `=SUMA(C2:C20)` | Suma aritmètica total de totes les cel·les numèriques del rang. |
| **`=MITJANA(rang)`** | `=MITJANA(D2:D30)` | Suma tots els números i els divideix pel recompte de dades (promig). |
| **`=MAX(rang)`** | `=MAX(B2:B15)` | Retorna el valor més alt (màxim) de tot el conjunt de cel·les. |
| **`=MIN(rang)`** | `=MIN(B2:B15)` | Retorna el valor més baix (mínim) de tot el conjunt de cel·les. |
| **`=CONTAR(rang)`** | `=CONTAR(A1:A50)` | Compta quantes cel·les del rang contenen valors numèrics. |
