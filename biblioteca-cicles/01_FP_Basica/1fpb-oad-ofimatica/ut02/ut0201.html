) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) MESURES DE SEGURETAT EN L’ENQUADERNACIÓ Seguretat Condicions de seguretat Utilitza la màquina únicament per a la seua finalitat segons les indicacions del fabricant. No col·loques res en l’obertura de perforació de la màquina que no siga el paper i el material de les tapes.

Col·loca la màquina en una àrea segura i estable de treball per a impedir que la màquina caiga danyant-se i causant lesions personals i danys materials. Tin cura en realitzar les primeres perforacions amb la màquina, les fulletes poden tenir grassa. Assegura’t que els documents no continguen grapes, clips i altres objectes aliens al paper del document.

Deus buidar el recipient de residus amb regularitat; de no ser així començaran a eixir per altres ranures de la màquina i provocaran un embós. Perfora sempre amb la palanca en la posició superior.

) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) MESURES DE SEGURETAT EN L’ENQUADERNACIÓ Mesures preventives en aparells elèctrics Pren precaucions bàsiques per a evitar el risc de descàrrega elèctrica. No plastifiques objectes metàl·lics. No manipules aparells elèctrics xafant el terra banyat.

Instal·la la màquina en un lloc accessible i proper a la presa de corrent. Desendolla la màquina quan no l’estigues usant i per a netejar-la. No deus submergir el cable, els endolls o l’aparell elèctric en l’aigua ni en qualsevol altre líquid. No poses la màquina en funcionament amb un cable o endoll danyat. Si l’endoll queda fluix, es produeix un arc elèctric que pot fer que es recalfe arribant inclús a cremar-se.

No neteges la màquina amb netejadors abrasius. No introduïsques cap objecte metàl·lic (tisores, clips...) en les zones d’entrada i eixida. No connectes molts aparells a un mateix endoll, ja que aquest pot recalfar-se.

) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) RESIDUS PERILLOSOS Els productors deuen tenir en compte una sèrie d’obligacions quant al seu envasat, etiquetat i emmagatzematge. Per a la seua eliminació poden entregar-se a un gestor de residus o bé ser gestionats per la mateixa empresa, per al que necessiten autorització.

Entre ells podem citar: Paper d’impressions rebutjat procedents de tractament d’aigües. Restes d’adhesius, guants, mascaretes usades i impregnats de substàncies perilloses o draps impregnats de dissolvents orgànics procedents de la neteja de les màquines. Restes de pel·lícula, paper fotogràfic, solucions fixadores o contenidores de productes químics buits.

Restes de tintes, dissolvents, reveladors, cautxús empleats entre el paper i la tinta, polímers, solucions de gravat, etc. Piles i bateries: deuen depositar-se en contenidors especials, ja que són molt contaminants. )

Paper rebutjat d’impressions rebutjades. Restes procedents de tall i embalatge (cartó, plàstic, etc.). Per a minimitzar l’impacte dels residus podem seguir les següents mesures: Disminuir l’ús de tinta i paper: imprimir sols el necessari, sobretot en el cas de correus electrònics.

Fotocopiar a doble cara o reduir i comprimir per estalviar paper. Aplicar el paper usat en safates i reutilitzar-lo si és possible com a bloc de notes. Separació i reciclatge de paper: restes d’embalatge, retalls, etc. Aprofitament de la tinta en l’etapa d’impressió: els excedents de tinta es poden usar per fer barreges.

Prestar atenció als olis a través de tècniques de prevenció-minimització: ampliar la vida dels olis i utilitzar olis sintètics. )
