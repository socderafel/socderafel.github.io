# 1.3 Tipus de Fitxers, Extensions i Associació d'Aplicacions

L'**extensió** d'un fitxer és el conjunt de caràcters (habitualment 3 o 4 lletres) situat al final del nom, separat per un punt (`.`). Informa el sistema operatiu de quin format tenen les dades i quina aplicació l'ha d'obrir en fer doble clic.

---

### 1. Mapa de Formats Ofimàtics Estàndards

| Categoria Documental | Extensió | Format i Aplicació Associada | Editable? |
| :--- | :--- | :--- | :---: |
| **Documents de text** | `.odt` | OpenDocument Text (LibreOffice Writer, natiu LliureX) | Sí |
| | `.docx` | Microsoft Word (Format propietari de Microsoft) | Sí |
| | `.pdf` | Portable Document Format (Format fix per a impressió/enviament) | Només lectura |
| **Fulls de càlcul** | `.ods` | OpenDocument Spreadsheet (LibreOffice Calc) | Sí |
| | `.xlsx` | Microsoft Excel | Sí |
| **Presentacions** | `.odp` | OpenDocument Presentation (LibreOffice Impress) | Sí |
| | `.pptx` | Microsoft PowerPoint | Sí |
| **Imatges** | `.png` | Portable Network Graphics (Admet transparències) | No |
| | `.jpg` / `.jpeg` | Fotografia comprimida | No |
| | `.svg` | Gràfic vectorial escalable sense pèrdua | Sí (amb Inkscape/Draw) |
| **Fitxers comprimits** | `.zip` / `.7z` | Paquets comprimits de fitxers múltiples | Sí (amb 7-Zip) |

---

### 2. Com Mostrar les Extensions a Windows
Per defecte, Windows amaga les extensions conegudes, cosa que pot fer caure l'usuari en trampes de virus (per exemple, un fitxer anomenat `factura.pdf.exe`).
- **Com activar-les:** A l'Explorador de fitxers ➔ Pestanya **Visualització** (*Vista*) ➔ Marca la casella ☑️ **Extensions de nom de fitxer**.

---

### 3. Associació d'Aplicacions Predeterminades
Si vols que un document s'òbriga sempre amb un programa concret (per exemple, obrir els PDF amb el navegador o amb un lector dedicat):
1. Fes clic amb el botó dret damunt de l'arxiu.
2. Selecciona **Obre amb...** ➔ **Tria una altra aplicació**.
3. Selecciona el programa desitjat i activa la casella **Utilitza sempre aquesta aplicació per obrir els fitxers .ext**.
