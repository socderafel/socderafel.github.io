# 1.3 Extensions de fitxer més comunes i el seu significat

L'**extensió de fitxer** és el conjunt de 3 o 4 lletres situades darrere de l'últim punt del nom que indica al sistema operatiu quin tipus de fitxer és i quin programa l'ha d'obrir.

| Categoria | Extensions Habituals | Programes típics per obrir-los |
| :--- | :--- | :--- |
| **Documents de Text** | `.odt` (OpenDocument), `.docx` (Word), `.txt` (Text pla), `.pdf` (Portable Document Format) | LibreOffice Writer, Microsoft Word, Adobe Reader |
| **Fulls de Càlcul** | `.ods` (OpenDocument), `.xlsx` (Excel), `.csv` (Dades separades per comes) | LibreOffice Calc, Microsoft Excel |
| **Presentacions** | `.odp`, `.pptx` | LibreOffice Impress, Microsoft PowerPoint |
| **Imatge Digital** | `.jpg` / `.jpeg` (Foto comprimida), `.png` (Fons transparents), `.gif` (Animacions), `.svg` (Vectorial) | GIMP, Photoshop, Visor de fotos |
| **Àudio i Vídeo** | `.mp3`, `.wav`, `.mp4`, `.mkv` | VLC Media Player |
| **Executables de Sistema** | `.exe` (Executables Windows), `.bat` / `.cmd` (Scripts), `.sh` (Scripts Linux) | Sistema Operatiu |

> [!WARNING]
> A Windows, l'opció "Amagar extensions per a tipus de fitxers coneguts" està sovint activada per defecte. Un tècnic informàtic ha de desmarcar aquesta casella des de la pestanya *Vista > Opcions de carpeta* per poder veure sempre l'extensió real i evitar estafes amb arxius com `factura.pdf.exe`.
